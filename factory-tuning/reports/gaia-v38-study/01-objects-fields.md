## 1. 创建顺序与依赖

1. 设计期先定关系形态，再进入创建：引用关系两对象可独立存在、父子关系子对象不能独立存在、多对多通常需中间对象承载 —— `01_对象配置 §概述`
2. 固定主干顺序：选项集 → 对象 → 字段 → 表单/列表布局 → 生命周期 → 工作流；布局依赖字段、工作流依赖生命周期与状态 —— `01_对象配置 §2.3`、`01B_对象字段 §1.2`
3. 关系不是独立实体：`对象`/`父对象` 字段**创建后自动生成出站关系**；入站关系是别人引用你的结果，不需单独创建 —— `01C_对象关系 §0.1/§0.2`、`01B_对象字段 §3.9/§3.11`
4. 控制字段的前置：先建父对象字段/上游对象字段，再建被控制的对象字段；候选控制字段要求「同为本对象上的对象字段，且其引用对象的父对象与被控制字段引用对象的父对象一致」 —— `01Q_控制字段 §控制字段的生成规则`
5. 查找字段的前置：查找关系**只能从当前对象的出站关系中选择**，即引用字段必须先存在 —— `01B_对象字段 §3.12`
6. 统计字段的前置：必须已有「一」对「多」的关系（统计来源关系） —— `01B_对象字段 §3.13`
7. 对象类型的前置：对象基础设置先启用 `对象类型` 开关，之后才能创建/管理对象类型并设默认类型 —— `01_对象配置 §2.2`、`01E_对象类型 §概述`
8. 字段选项依赖的前置：控制字段（`选项`/`布尔`）与受控字段（通常 `选项`）都已存在，入口在受控字段详情页右上角 —— `01N_字段选项依赖 §创建入口`
9. 引用约束的前置：字段类型为 `对象`/`父对象`/`对象多选` 且**已选好引用对象**，之后才出现「约束引用对象中的记录」区域 —— `01P_引用约束 §设置引用约束`
10. 输入约束的前置：基准日期字段须已存在，且建议放入同一表单布局并排在被约束字段之前，否则业务端取不到基准值 —— `01R_日期和时间输入约束 §限制与注意事项`
11. 动态引用约束使用 `当前对象字段` 作条件值时，这些字段必须已放入表单布局，否则联动不触发 —— `01P_引用约束 §业务端生效方式`
12. 数据所有权选中的维度会自动创建标准字段（如「所属部门」「所属质量组织」）；启用所属业务模块会带出标准选项集 `业务模块` 与标准字段 `模块` —— `01_对象配置 §2.2`

### 1.1 级联与连带（改/删 A 影响 B）

1. 删字段：引用该字段的**索引规则自动删除**；字段「值必须唯一」属性变更时，系统自动新增/删除对应唯一索引 —— `01K_索引规则 §4.2`
2. 删字段前应确认未被布局、规则、动作、工作流、生命周期或其它配置依赖；删规则后业务端不可再使用该规则 —— `01B_对象字段 §1.3`、`01J_验证规则 §2.3`
3. 删对象要求该对象未被其它配置依赖，删除后即从对象管理中移除 —— `01_对象配置 §3`
4. 改选项集影响**所有引用该选项集的字段**；停用选项值不清除历史记录中的已有值，只是不能再选 —— `02_选项集配置 §4.5`
5. 取消「使用动作安全来控制共享设置」会自动删除系统生成的「共享设置」动作**及其相应权限设置** —— `01_对象配置 §2.2`
6. 取消「启用实例多语言」会同步移除自动创建的「内容翻译」记录动作；启用则自动创建该动作 —— `01_对象配置 §2.2`
7. 控制字段值变化时，被控制的对象多选字段**会清空已选值**（当前版本行为） —— `01B_对象字段 §3.10`
8. 规则冲突时以「字段选项依赖」优先（与表单规则冲突场景） —— `01N_字段选项依赖 §生效范围与优先级`

### 1.2 平台自动带出

1. 启用 `对象类型` → 自动创建对象类型 `基础类型`，无需手工创建 —— `01E_对象类型 §概述`、`§2.3`
2. 启用电子签名 → 自动创建**电子签名子对象**（来源=系统，名称 `{对象名称}电子签名`，Code `{对象Code}_esignature_sys`），并在相关布局中加入电子签名内容 —— `01_对象配置 §2.2`
3. 启用实例锁定 → 自动提供标准字段 `是否锁定`（布尔，默认 false）与 `锁定时间`（日期时间） —— `01I_对象实例锁定 §2`
4. 启用树形结构 → 自动创建两个系统字段：`xx路径`（文本，`File_type_name_path__sys`）与 `xx子级数量`（数字，`File_type_name_child_count__sys`） —— `01S_对象启用树形结构 §自动创建的系统字段`
5. 启用所属业务模块 → 自动带出标准选项集 `业务模块` 与标准字段 `模块` —— `01_对象配置 §关于启用所属业务模块`
6. 启用生命周期 → 自动生成对象生命周期；开启 DAC → 出现共享规则相关能力（需先启用生命周期） —— `01_对象配置 §2.2`
7. DAC 匹配共享规则选定「用户角色设置」对象后，该对象会自动开启「在业务管理菜单中显示」 —— `01_对象配置 §2.2`
8. 大容量对象/启用对象类型/启用生命周期状态后，系统分别提供对应的**默认索引**能力 —— `01K_索引规则 §系统默认索引`

## 2. 不可逆 / 不可删除 / 只能停用

1. **是否大容量**：创建后不可在标准对象与大容量对象之间切换，数据存储类型不支持再次修改 —— `01_对象配置 §2.2/§4.2`、`18_大容量对象 §1`
2. **启用电子签名**：一旦启用不可禁用 —— `01_对象配置 §2.2/§4.2`
3. **启用审计追踪**：开启后不可关闭（编辑页灰显，不能取消） —— `01_对象配置 §2.2/§4.2`
4. **启用对象类型**：一旦开启后不能关闭 —— `01_对象配置 §2.2`、`01E_对象类型 §概述`
5. **生命周期开关**：一旦启用后不可关闭 —— `01_对象配置 §2.2`
6. **开启动态权限控制**：一旦开启后不能关闭；其下的「启用自定义共享规则 / 启用匹配共享规则」可反复开关 —— `01_对象配置 §2.2/§4.2`
7. **启用所属业务模块**：一旦开启后不能关闭 —— `01_对象配置 §2.2/§4.2`
8. **数据所有权**：已添加的数据维度**不能删除**，只能继续新增 —— `01_对象配置 §2.2/§4.1`
9. **数据存储类型的连带不可逆**：选大容量即永久失去审计追踪、电子签名、工作流时间线、DAC、唯一性校验、验证规则、通知、作业，及查找/统计/父对象/附件/对象多选字段与选项多选、字段默认值、字段图标 —— `18_大容量对象 §3.2/§4`
10. **树形结构**：一个对象只能有一个启用树形结构的自引用字段，启用后**该字段属性在创建后不能直接修改，只能新建自引用字段重配** —— `01B_对象字段 §2.8/§3.9`、`01S_对象启用树形结构 §配置说明`
11. **对象基础三件套只读**：`Code`、`来源`、`对象类别` 创建后不可修改 —— `01_对象配置 §4.2`
12. **字段 `Code`**：必填、唯一、1–200 字符，**创建后不可修改** —— `01B_对象字段 §2.2`
13. **索引规则**：创建后仅允许修改「索引备注」；索引方法、是否唯一、索引字段不支持直接改，**只能删除后重建** —— `01K_索引规则 §4.1`
14. **大容量对象的字段属性**：唯一值/默认值/图标（文本、数字、布尔、选项）与引用约束条件、树形展示（对象）均不可用 —— `18_大容量对象 §3.3`
15. **默认对象类型不支持停用** —— `01E_对象类型 §2.3`
16. **无「删除对象类型开关」路径**：对象类型本身可删除，但承载它的开关不可回退 —— `01E_对象类型 §2.2.1` + `01_对象配置 §4.2`
17. **生命周期用户动作/字段变更无删除回退**：实例锁定等状态只能靠系统流程改回 `是否锁定=false` 解锁，平台不提供管理端「解锁」按钮 —— `01I_对象实例锁定 §2`

## 3. 系统内置与强制项

1. 对象来源三值 `系统`/`标准`/`自定义`；**系统对象由平台创建和维护，不开放常规修改**；标准对象仅开放部分配置能力 —— `01_对象配置 §1`
2. 字段来源区分 `标准`/`自定义`；系统字段（如 `xx路径`、`xx子级数量`）字段类别显示为 `系统`、由系统维护，不作为业务手工录入字段 —— `01B_对象字段 §1.3`、`01S_对象启用树形结构 §自动创建的系统字段`
3. 每个对象默认包含系统字段与**系统索引**（对象 ID、创建时间等） —— `01K_索引规则 §系统默认索引`
4. 对象生命周期启用后带初始/终止状态，系统保留状态不可删；工厂侧 `INIT_STATUS_CODE=init_status__c`、`COMPLETE_STATUS_CODE=complete_status__c` 与此对应 —— `01_对象配置 §2.2` + `kernel/endpoints.py`（工厂侧已固化）
5. 状态列相关默认索引由平台随「启用生命周期状态」提供，不需手工建 —— `01K_索引规则 §系统默认索引`
6. `name__ak` 是系统管理字段：多对多「关联多条记录」要求其值由系统管理或保证不设值时仍唯一 —— `01C_对象关系 §连接对象与关联多条记录`
7. 大容量对象**不支持 `name__ak` 字段配置编号规则**（业务编号本身支持） —— `18_大容量对象 §3.4`
8. 对象列表固定列：名称 / Code / 来源 / 生命周期 / 父对象（仅父子关系时显示）/ 操作 —— `01_对象配置 §1`
9. 字段列表固定列：字段名称 / Code / 来源 / 数据类型 / 状态 / 操作；**只有启用状态的字段才能被添加到其它配置中** —— `01B_对象字段 §1.3/§2.2`
10. 对象详情页签固定为：基础 / 对象类型 / 字段 / 搜索字段 / 关系 / 列表布局 / 表单布局 / 动作 / 验证规则 / 索引规则 —— `01_对象配置 §3`
11. 对象类别 7 选项（基础 / 用户任务 / 用户动态角色管理 / 审批矩阵管理 / 审批矩阵职位 / 检验项目 / 检验结果）；**仅「基础」可用于大容量对象**；界面名与产品方案名存在对照（用户动态角色管理 = 用户角色设置） —— `01_对象配置 §2.1`
12. 索引方法论：当前版本默认 `B-Tree`（弹窗中只读显示为「普通索引」） —— `01K_索引规则 §1.2/§3.2`
13. 索引命名由系统生成：普通 `表名_列名`、唯一 `表名_列名_ux` —— `01K_索引规则 §3.5`
14. 平台级上限（强制、不可配）：父子关系 ≤ 3 层（已有三层时字段不允许保存）；关系最多 3 层故控制字段最多 2 级级联；树形 ≤ 5 层 —— `01B_对象字段 §3.11/§3.9/§2.8`
15. 平台级配额：一个对象 ≤ 5 条查找关系、每条关系 ≤ 8 个查找字段、一个源对象最多被 8 条查找关系引用；一个对象 ≤ 10 个统计字段 —— `01B_对象字段 §3.12/§3.13`
16. 强制系统设置项：对象多选字段默认最多可选 `100` 个，可经**系统设置**「对象(多选)字段选择上限」调至 1–1000 —— `01B_对象字段 §3.10`
17. `组件` 字段类型当前仅保留入口，可配置能力以实际界面为准（手册明确不可依赖） —— `01B_对象字段 §3.16`
18. 字段类型硬边界：文本 `1–17`（工厂 `maxLength` ge=1 le=17 与之吻合，手册写「最多 1500 字符」）、数字最大 `99999999999999`/最小 `-99999999999999`/小数位 ≤ 4、长文本与富文本 ≤ 32000、附件数量 1–100 / 单件 1–2048MB、验证表达式 ≤ 3900 字符、文本常量 ≤ 200 字符 —— `01B_对象字段 §3.1–§3.15`、`01J_验证规则 §3.3`、`01M_字段配置条件设置 §字段类型支持矩阵`

### 4.4 工厂缺口候选（按价值排序，供后续建动词）

1. **对象级开关族**（大容量 / 审计追踪 / 实例锁定 / DAC / 所属业务模块）——全部不可逆，漏配后无法在平台上补救，是最该先建的动词。
2. **值必须唯一 + 索引规则**——唯一性是主数据类对象的核心约束，且与「字段值唯一」自动索引双向联动，手工补配成本高。
3. **验证规则**——目前工厂只能靠蓝图模型层校验，平台上零校验落地。
4. **对象类型（含字段矩阵 / 动作矩阵 / 字段覆写）**——多子类型建模的唯一手段，缺口直接排除掉一整类蓝图形态。
5. **引用约束 / 控制字段**——业务端候选范围收缩的两条主力，二者都不需要新对象，属低成本高收益。
6. **默认值（含 URL 参数方式）与字段级展示属性**（图标、字体样式、行内编辑、唯一、帮助内容、复制行为、分面统计）。
7. **字段选项依赖矩阵**——只在选项类对象上有价值，但一旦需要就是硬需求。
8. **多选选项字段**（`是否允许多选`）——工厂当前只建单选选项字段，属类型面缺口而非开关缺口。
