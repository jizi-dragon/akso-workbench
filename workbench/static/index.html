    ⚡ 系统提示词

    这一段是每次对话最先发给模型的内容，决定它的定位与做事方式。留空即用默认—— 默认只说明「你是谁、工具从哪找、信息从哪来」，工具清单由系统按当前已装插件自动下发， 不需要（也不应该）在这里手写。

    改完点「保存提示词」立即生效；⚠️ 会让下一次请求的缓存前缀失效一次（之后恢复命中）。

    ⚡ 工具范围

    只把勾选的工具发给模型。减少工具面能降低每轮 token 与选错概率； 一个都不勾 = 模型没有任何工具（仍可聊天）。清空限制即恢复全部。

    ⚡ 定时任务

    按固定间隔把一条只读提示词跑进新会话（无人值守，不能写平台/文件）。 最小 60 秒；结果在左栏「会话记录」里回看。

    ⚡ 长期目标

    记录跨多轮的长期目标与轮次预算。v1 只做追踪，不自动续跑； 达到上限后在这里标记完成或调整预算。

    ⚡ MCP 服务器

    MCP（Model Context Protocol）把外部工具接进对话。配置文件是 （读取中…），形状与 WorkBuddy / Claude Desktop 一致： {"mcpServers": {"名字": {"command": "...", "args": []}}}。 默认 risk=write（每次调用都要你确认），可在 server 配置里显式写 "risk": "read" 放宽。命令只从配置文件来，模型不能指定。
