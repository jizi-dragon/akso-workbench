## 1. 安装与首次启动

### 1.1 安装

1. 运行 `Workbench-<版本>-setup.exe`（约 350 MB）。
   - 可自选安装目录；**默认不需要管理员权限**。
   - 包内已含 Python 服务端、浏览器内核（Chromium）与浏览器扩展，**无需预装 Python / Node / Playwright**。
   - ⚠️ **2026-09-16 起本应用改名**（原名 `AksoWorkbench`）。安装目录与卸载项是新的一套，
     **旧版不会被覆盖安装**——请先在「添加或删除程序」里卸载旧版，再装新版。
2. 首次启动会自动初始化数据目录 `%APPDATA%\Workbench`。若你电脑上还留着**更名前**的
   `%APPDATA%\AksoWorkbench`（或更早的 Mogul 工作台），首次会**自动复制接管**其中的数据库——
   账号、环境、Fernet 密钥、历史会话都不丢。**旧目录不会被删除**（想回滚就用它）。
3. 接管是**一次性复制**：之后请只用新版本。若在旧版本里继续加账号，两份数据会分叉。

### 1.2 装载浏览器扩展（一次性，只为「快捷登录」）

「多账号快捷登录」需要把浏览器扩展装进**你自己的 Chrome**。Chrome 在 Windows 上禁止非商店扩展静默安装，
所以这一步必须你亲手点四下（这是平台限制，不是应用偷懒——实证见 `EXTENSION-INSTALL.md`（**该文件已于 2026-09-29 删除**））：

1. 打开**账号中心**（左侧「账号中心」），若顶部出现「未检测到浏览器扩展」提示条 → 点 **一键安装引导**；
   （或：右键托盘图标 → 「安装浏览器扩展…」）
2. 弹窗与浏览器会同时打开：`chrome://extensions` 与扩展所在目录；
3. 在 `chrome://extensions` 右上角打开 **开发者模式**；
4. 点 **加载已解压的扩展程序** → 选中已为你打开的那个目录（**选目录本身，不要进子目录**）。

装好后「在线」徽标与 `Alt+Q` 轮盘即可用；**账号数据由桌面端自动下发，不需要在扩展里另建**。

> 若之后不再看到提示条：那是正常的——连接成功过一次后提示条会**永久静默**
> （以「能否连接成功一次」为判据，之后即使 Chrome 没开也不再打扰你）。

### 1.3 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 浏览器 | Chrome 或 Edge（要「快捷登录」时才需要） |
| 网络 | 能访问你的 eGMP 平台；自动更新需要能访问 GitHub（受限网络下见 [CONFIG.md](CONFIG.md) §6 的 `proxy.txt`） |

## 2. 界面总览

- **轮盘窗**：按 `Alt+Q` 呼出（无边框半透明、置顶、**点别处自动关闭**）。
  滚轮或点中心切换盒子；数字键 1–9 直接选人（0 = 第 10 个）；`Esc` 关闭。

| 入口 | 位置 | 用途 |
|---|---|---|
| 账号中心 | 左栏「平台模块」 | 环境 / 账号 / 盒子 / 分配池 / 备份 / 快捷登录 |
| 对象分析 | 左栏「平台模块」 | 登录验证 / 蜘蛛织网 |
| **Skill 管理** | 左栏「Agent 能力」 | 上传 Skill ZIP / 从共享库安装 / 一键卸载 / 停用（§10） |

| 对话 / 设置 | 左栏顶部 | AI 对话、DeepSeek 配置 |
| 托盘菜单 | 任务栏右下角图标右键 | 显示主窗 / 账号轮盘 / 安装扩展 / 检查更新 / 关于 / 退出 |

> **改名与下线记录（2026-09-22）**：两个平台模块原先叫「平台洞察」「配置工厂」，
> 同一天先更名为「**对象分析**」「**配置**」；随后「**配置**」整条链路（配置页、`/api/factory/*`

> 所以老的日志、审计与产物路径仍然对得上。

## 3. 账号中心

打开：左栏 → **账号中心**。

### 3.1 站点管理（先加站点）

- 一个**站点 = 一个平台环境**（一个 `base_url`）。
- 粘贴**完整链接**（如 `https://example-config.example.com/admin/...`）会自动清洗为站点，**保留端口**
  （内网非标端口的站点因此也能正常使用）。
- 站点名称可改，**站点地址不可改**（要换地址就新建站点）。
- ⚠️ 删除站点会**级联删除**它下面的全部账号。

### 3.2 添加账号

- 填「站点 + 用户名 + 密码」即可；`盒子` 可留空（= 默认盒子）。
- **页签名（别名）**：可选。填了之后，浏览器里的页签标题与轮盘扇区名都会用它，
  便于在一堆页签里快速定位（如填 `T0901`）。
- **批量添加**：点「批量添加 ▾」，每行一条 `用户名,密码[,盒子]`。
- 密码用 Fernet 加密存本机，**界面永不回显明文**。

### 3.3 账号卡片墙（盒子收纳 + 四态徽标）

- 卡片按**盒子**分组，顶部芯片切换；点芯片右侧可管理盒子（重命名 / 删除 / 禁用 / 新建）。
- **盒子禁用**：禁用后该盒子在**轮盘**中被跳过（账号中心里照常可见可管理）。
- 卡片上的徽标反映**浏览器扩展里的实时状态**（来自扩展上报，几十秒的延迟是正常的）。
- 卡片操作：
  - **快捷登录**：在**你自己的 Chrome** 里以该身份打开并自动登录（见 §4.1）；
  - **打开**：用**应用内置浏览器**打开并免密直达（见 §4.2）；
  - **监听会话**：在托管会话上开始/停止请求录制（见 §7）。
- **批量管理**：开启后可多选 → 移入盒子… / 删除所选。

### 3.4 分配池

- **分配池 = 给平台「写操作」用的可用账号清单**。它的真实作用是**限制写入权限**：
  开放给 Agent 的写功能，只能从池内选账号与环境，避免乱选账密和环境去写配置。
- 对象分析（只读）的账号下拉**优先**列出配置池成员；**池为空时回退显示全部账号并提示**
  （对象分析不做写入，所以它不该被池卡住）。
- 把常用测试账号加入**配置池**，将来开放写能力时才不会选到不该动的账号。

### 3.5 备份、导入

| 操作 | 说明 |
|---|---|
| **导出备份** | 导出 JSON，含环境 / 账号（密文口令）/ 盒子配置，**并内嵌解密密钥**。⚠️ 该文件等价于凭据，请妥善保管 |
| **导入备份** | 用文件内密钥解密 → 用本机密钥重新加密 → 落库；按「站点 + 用户名」去重 |
| **env 导入** | 只读扫描原项目（akso-cc / akso-auto）的 `env.json`，把环境与账号导入账号库。**原文件绝不修改** |

### 3.6 页面内轮盘（Ctrl+Shift+Q）

在账号中心页面上按 `Ctrl+Shift+Q`（或点顶部「轮盘 Alt+Q」按钮）会呼出页面内的轮盘浮层——
与桌面 `Alt+Q` 轮盘视觉一致，适合「浏览器里直接打开本页」时使用。

## 4. 快捷登录与托管浏览器

这是两条**刻意不同**的路径（设计取舍见 [ADR-0002](adr/0002-browser-allocation-policy.md)）：

| | **快捷登录** | **打开（托管）** |
|---|---|---|
| 用哪个浏览器 | **你自己的 Chrome**（需装扩展） | **应用内置 Chromium** |
| 目的 | 以该身份**真实地干活**（真实 profile / 插件 / 书签） | 可控、可录制、免密、不污染你的浏览器 |
| 自动登录 | 扩展在你的页面里填表 | 内置浏览器里自动填表，成功即**落地免密登录态** |
| 会话保持 | 依赖你的 Chrome 与扩展 | 关闭后仍**免密直达**（下次打开不用再登） |
| 适用于 | 日常点检、演示、需要真实环境的操作 | 需要稳定复现、需要录制、不想动自己浏览器 |

### 4.1 快捷登录（用户 Chrome）

三种触发方式，效果相同：

1. `Alt+Q` 呼出桌面轮盘 → 选账号；
2. 账号中心卡片上的 **快捷登录**；
3. 在**账号中心页面**上按 `Ctrl+Shift+Q`（页面内浮层，见 §3.6）。

> ⚠️ 扩展**不注册任何浏览器快捷键**：`Alt+Q` 由桌面端独占。
> 桌面端没运行时按 `Alt+Q` **不会有任何反应**（这是刻意的——扩展的轮盘只能由桌面触发）。

内部流程：桌面写一条指令 → 扩展取到（长轮询，约 20 毫秒）→ 在你的 Chrome 里开页签 →
按账号的隔离规则绑定 → 自动填表登录。

> ⚠️ **Chrome 没运行时扩展不会工作**。桌面在派发前会自动探测并**拉起 Chrome**，
> 所以第一次点会稍慢（冷启动 1~3 秒）。

### 4.2 打开 / 免密直达（内置浏览器）

- 点卡片上的 **打开** → 内置浏览器窗口打开该平台。
  - 首次：自动填表登录 → 成功后**把登录态落盘**；
  - 之后：**免密直达首页**（不用再登录）。
- 会话失效（被平台踢回登录页）时**自动重新登录**（自愈，最多 2 次；再失败会提示检查凭据）。
- **关闭窗口 ≠ 登出**：登录态已保存，下次打开仍免密。
- 要真正登出：用 `POST /api/browser/forget/{账号id}`（或删除
  `%APPDATA%\Workbench\runtime\browser-states\<账号id>.json`）。

### 4.3 多账号并行（扩展的核心价值）

同一个 Chrome 窗口里可以**同时在线多个账号**，互不串号。这不是靠「多开浏览器」，而是靠**六平面隔离**
逐层切断同源共享资源：

| 平面 | 切断什么 |
|---|---|
| 存储 | `localStorage` 按账号命名空间；`document.cookie` 虚拟化为账号「Cookie 袋」 |
| 鉴权 | 出站 `Authorization: Bearer` 按页签强制改写为该账号的 token |
| Cookie | 出站 `Cookie` 头按账号**回放**（登录时点采集的快照） |
| 缓存 | 同源 GET 追加 `_qlck` 参数，HTTP 缓存按页签硬分区 |
| SW/Cache | 拦截站点 Service Worker 注册；`CacheStorage` 按账号命名空间 |
| IndexedDB | 站点 IndexedDB 按账号前缀化（平台的 `isAdmin` 与菜单树就缓存在共享 IDB 里） |

> 原理与攻防过程见 `EXTENSION-PLANE.md`（**该文件已于 2026-09-29 删除**）。
> 一句话结论：**官方方案下不同账号不会互相串权**；若你观察到相反现象，请立刻导出诊断（见 §12）。

## 5. 对象分析

打开：左栏 → **对象分析**。两个命令：

| 命令 | 作用 | 需要填什么 | 产物 |
|---|---|---|---|
| `login` | 只验连通性并预热 token（55 分钟有效） | 账号 | 无 |
| `spider` | **五步织网**：跨对象的关系网络（networkx 图分析） | 账号 + 对象编码 | `spider-network.{json,md,drawio}` + `step3-attribution.md` + `manifest.json` |

> `inventory`（全量盘点）与 `understand`（三层理解报告）已于 0.3.8 **下线**——应用场景模糊、
> 实际使用效果不理想。历史任务在任务列表里仍可查看产物。

用法：

1. **账号**下拉选账号库里的账号（见 §3.4）；
2. 选命令；`spider` 会要求填对象编码（如 `capa_plan__c,change_control__c`，逗号分隔）；
3. 点 **执行** → 下方实时日志 → 产物区列出文件（`.md`/`.json` 等文本可直接看，其他格式可下载，`.drawio` 用 draw.io 打开）。

**任务历史**在页面底部，可回看每次执行的状态与产物（状态有三态：`succeeded` / `partial` / `failed`）。

> 实现说明：命令已**全部用 Python 原生实现**，运行时不调用原项目、不需要 Node。
> 产物默认写到**你的工作区** `<工作区根>\<对象编码>\<时间戳>\`（工作区根在设置里改，
> 默认 `我的文档\Workbench\洞察`）；工作区根不可写时才退回
> `%APPDATA%\Workbench\runtime\insight\<任务id>\`。

## 6. 对话与设置

### 6.1 对话

- 主区「对话」：与内置的合规智能体对话（面向药企合规 / 实施问题）。
- 支持流式输出、工具调用（联网读官方页面）、会话历史（左栏「会话记录」）。
- 回答可**点赞/反馈**，用于统计采纳率。
- **可以直接把图片或文件交给它**（2026-09-22 起）：点输入框左下角的「📎 附件」、
  直接**粘贴**（截图之后最顺手的动作）、或把文件**拖进**输入框。
  支持 `.png .jpg .jpeg .webp`（图片直接给模型看）、`.docx .xlsx .pdf .md .txt .csv`
  （会解析出正文与**坐标**，所以它能告诉你"在第 3 页 / 明细表第 5 行"）。
  单文件上限 **20 MB**、一条消息最多 **5 个**。
  发出去之后，**消息里会留下这几个文件的 chip**（图片是缩略图，文档是文件图标 ——
  点它用系统浏览器打开原文件）；刷新页面也还在（它跟着那条消息存着）。
  ⚠️ 两条已知边界：**扫描件 PDF 读不出文字**（不做 OCR，改传截图即可）；
  **隔一轮之后再问"刚才那张图"它看不到了**（只有最新一条消息里的附件会随请求发出，
  这是为了不让同一份文件每轮重发、把账单和上下文一起撑爆）——需要时把图再贴一次。

**输入框那行小字（2026-09-22 起）**：输入框**下方**常驻三个数字——
`缓存命中 X tok · NN% · ◔ 上下文 NN%`。

| 数字 | 含义 | 怎么用它 |
|---|---|---|
| **缓存命中** | 这段对话的输入里，有多少 token 是**从 DeepSeek 前缀缓存里读**的 | 命中价是未命中价的 **1/50** ⇒ 这个数字越大越省钱 |
| **命中率** | 命中 ÷（命中 + 未命中） | 颜色会变：≥60% 绿 / 20–60% 灰 / <20% 琥珀。<br>**在同一段对话里连续追问**命中率才高；每次都新开一个会话，它必然很低 |
| **◔ 上下文** | 那个**小圆环**就是**本轮用掉的上下文 ÷ 模型最大上下文**（右边那圈是空轨道）；旁边的百分比是同一个数 | 圆环过半后变琥珀、过 80% 变红——那时该开新会话，或让 Agent 先把结论写下来。<br>**精确 token 数**（如 `66k / 131k`）在鼠标悬停的提示里 |

> 为什么图标旁只放百分比：那两个 token 数不是"一眼要判断的东西"，
> 判断靠的是**比例 + 颜色**；精确数字悬停即得，不占那行位置。

输入框**右侧**（发送键旁边）显示**当前生效的模型名**，点它跳到设置里更换。
这一行**一直在**：还没开始对话时三段都显示「—」（它不是"有数据才冒出来的提示"，
免得第一次问答成功时整行突然出现、把输入框顶上去一格）。

### 6.2 设置

| 项 | 说明 |
|---|---|
| **DeepSeek API Key** | 存本机 SQLite，仅发往 DeepSeek 官方端点。**不填则对话与所有 Agent 能力不可用** |
| **模型选择** | 提供两个选项（经济版 / 旗舰版）。⚠️ 界面**不支持自定义模型名**；若你的账号需要用别的模型名，见 [CONFIG.md](CONFIG.md) §5 |
| **Temperature** | 0（严谨）~ 2（发散），默认 0.7 |
| **单轮工具调用上限** | 默认 **40**。你发一条消息后，Agent 最多调用这么多次工具（只读查询与危险写入一样计费）。<br>**用完了不会丢进度**——它会把已完成的都留着，你回一句「继续」就接着做。<br>对象分析这类多步任务（找账号 → 织网 → 取产物）建议 40 以上；调到 200 以上没有意义，那只是把刹车松开 |

## 7. 监听会话（Monitor）

**用途**：搞清楚「在平台上做这个操作，到底发了哪些请求」，为读懂平台/排查提供实证。

1. 在账号中心卡片上点 **开始监听**（会确保该账号的内置浏览器会话在线——可能需要几秒）；
2. 在打开的窗口里**正常操作**平台（建对象、改字段、走审批……）；
3. 点 **停止监听**（或卡片上的同名按钮）→ 产物落
   `%APPDATA%\Workbench\runtime\monitor\<账号>-<时间戳>\`。

产物内容：请求录制日志（`monitor-log.json`）、断点、降噪统计。录制分三级：**丢弃**（无关流量）、
**精简**（相关但只留摘要）、**完整**（平台业务 API）。

> ⚠️ **危险操作（删除 / 改状态 / 取消 / 停用）会被标记为不可回放**——录制的意义是「看懂」，
> 不是「自动重放」。且本产品**不提供回放执行器**：解读出的 `reproduce-plan.json` 只记平台侧事实
> （方法 / 路径 / 原始参数），`executor` 恒为 `null`；要回放得由人或别的工具照计划手工做。
> 见 [ADR-0010](adr/0010-monitor-no-dangerous-replay.md)。

## 8. 自动更新

> ⚠️ **默认关闭**（2026-09-15 起，应用不再自己替换自己，用户定稿）。下面第 2–3 条描述的是**开启后**的行为；
> 默认状态下应用不检查、不下载、不安装，托盘「检查更新…」只回一句说明。

1. **开启方式**：设置环境变量 `WORKBENCH_AUTO_UPDATE=1` 后重启应用（`1`/`true`/`yes`/`on` 均可）。
   它是**环境变量而不是设置项**——这个开关决定"应用会不会自己替换自己"，属于部署期决定。
2. 开启后：应用**启动 20 秒后**静默检查一次，之后**每 6 小时**一次；
3. 有新版本会**在后台静默下载**（不弹窗、不打断你），**退出应用时自动安装**（不会在你工作途中重启）；
4. 手动查（默认也可用）：托盘右键 → **检查更新…**，或点账号中心右上角的**版本角标**；
5. 升级完成后，账号中心会出现「浏览器扩展版本过旧」提示条 → 点 **重新加载引导**，
   在 `chrome://extensions` 里给扩展点一次「重新加载」。

> 为什么要默认关闭：在需要比对版本、反复构建的机器上，"自动换成新版"出现过
> 「跑的到底是哪个副本」难以判断的事故（见 [PITFALLS.md](PITFALLS.md) #25）。要手动升级时，
> 直接跑新版本的安装包覆盖安装即可。

> ⚠️ 升级后若不做「重新加载」，Chrome 里跑的仍是旧版扩展代码——所以这条提示条别忽略。
> 加载/未加载的状态是应用自动比对的（桌面端与扩展同号发布）。

## 9. 数据位置与安全须知

### 9.1 你的数据在哪

| 内容 | 位置 |
|---|---|
| 账号 / 环境 / 会话 / 任务记录 | `%APPDATA%\Workbench\workbench.db`（SQLite 单文件） |
| 对象分析的产物 | `%APPDATA%\Workbench\runtime\insight\<任务id>\`（目录名仍是 `insight`，更名没动它） |
| 托管浏览器的免密登录态 | `%APPDATA%\Workbench\runtime\browser-states\<账号id>.json` |
| 监听录制产物 | `%APPDATA%\Workbench\runtime\monitor\...` |
| 浏览器缓存与各账号会话分区 | `%APPDATA%\Workbench\Partitions\` 等（删掉只会清掉浏览器的登录态，**不会**丢账号） |

**备份建议**：用账号中心的「导出备份」（账号与盒子），产物目录自行复制即可。

### 9.2 安全须知（请知悉）

- **口令加密存本机**（密钥也在本机数据库里），因此**导出备份文件等价于凭据**，别随手发出去。
- 应用的服务只监听**本机回环**（`127.0.0.1`），**没有登录认证**——所以别把端口暴露到局域网，
  也别在多人共用的电脑上长期挂着。
- 浏览器扩展的同步通道同样只在回环上；它的**已知风险窗口**（明文凭据在会话存储里短暂驻留、
  通道无认证）记录在 [ADR-0007](adr/0007-credentials-never-plaintext.md)。
- 真机操作请只在**测试环境**账号上进行。

## 10. Skill 管理（给 Agent 加能力）

打开：左栏 → **Agent 能力 → Skill 管理**。

Skill 是**一个 ZIP 包**，装上之后会给 Agent 增加若干工具（模型就能"调用"它）。
整个流程是：**上传到共享库 → 从库里安装 → 立刻生效**；不用了**一键卸载**。

### 10.1 上传

1. 点「选择文件」选一个 Skill ZIP（≤10 MB，`SKILL.md` 必须在**压缩包根目录**，
   **不许夹带任何二进制文件**——图片、exe、压缩包都不行）；
2. 点「上传」。系统会做**结构校验 + 可疑模式扫描**，并把扫描到的东西**整条列出来**；
3. **扫描到高危模式时不会直接入库**：先给你看发现清单，确认后才收
   （这一步是刻意的——"点一下上传就生效"不该发生在扫描有警报的包上）。

> ⚠️ **扫描是"准入闸门"，不是"安全鉴定"**。它只把要你亲眼看一看的地方摊开
> （网络访问、子进程、动态执行、凭据字样…），**不判定恶意**，也挡不住刻意混淆的包。
> 真正管住"它到底能干什么"的是 §11 的沙箱与确认门。

### 10.2 从共享库安装 / 卸载

| 动作 | 结果 |
|---|---|
| **安装到 Agent** | 该 Skill 的工具**立刻**对模型可见（不用重启） |
| **卸载** | 工具**立刻**消失；**共享库里的版本一个都不会删**（卸载 = 不再生效，不是销毁） |
| **从库删除** | 真正销毁（所有版本）。若已安装会先卸载 |
| **禁用 / 启用** | 只是不进模型可见的工具表，插件仍在清单里，随时可恢复 |

> **卸载 ≠ 删除**。想彻底清掉必须点「从库删除」——这是刻意的：你可能只是想先停用，
> 或者换个版本再装回来。

### 10.3 装进来的工具会"自己动手"吗

看它的**风险等级**，规则与自带工具完全一样：

- `read`（只读）→ 直接执行；
- `write` / `dangerous` → **必须你确认**（对话里会弹出确认，或走待确认列表批准）。

**带脚本的 Skill 有额外一条**：包内脚本（`script:`）执行的是**上传来的代码**，
所以它的风险**最低就是 `write`**——哪怕作者写 `risk: read` 也一样，**每次调用都要你确认**。

清单里带「**含脚本 N**」徽标的，就是这类 Skill；工具名后面标「(脚本)」的，
就是会执行上传代码的那几个。

### 10.4 数据放在哪

- 共享库：`%APPDATA%\Workbench\skills\library\<能力id>\<版本>\`
- 已安装（生效中的指针）：`%APPDATA%\Workbench\skills\installed\<能力id>\current`

两处都在你的数据目录里，**不会**被提交进代码仓库。想搬到别的机器，直接拷 `skills` 目录即可。

## 11. 沙箱（上传来的代码在哪跑）

打开：左栏 → **Agent 能力 → 沙箱**。这一页回答三个问题：**按什么规则跑、现在在跑什么、跑过什么**。

### 11.1 它能拦什么

| 层 | 做法 |
|---|---|
| 凭据 | 脚本**拿不到**你的环境变量与凭据（只注入 Skill 自己的身份信息） |
| 目录 | 工作目录固定在沙箱根内；敏感路径（凭据库、浏览器 profile、扩展存储）拒绝 |
| 进程 | 超时**连整棵进程树一起终止**（不让一个死循环永久占住） |
| 网络/派生进程 | 默认**不给**（脚本式 Skill 的策略就是"不联网、不派生进程"） |

### 11.2 它**不能**拦什么（请认真读这一条）

**沙箱不是内核级隔离**，它降的是风险，不是"跑恶意脚本也安全"的保证：

- 能跑的代码**仍能读它有权限读的一切**（沙箱不是监狱，是"把门关小 + 看得见"）；
- 沙箱**不替代确认门**——两者是纵深关系，所以带脚本的工具照样每次都要你确认；
- 因此：**只装你信得过的来源的 Skill**（同事给的、自己写的），
  不要装来路不明的包。这一条没有技术兜底。

### 11.3 页面上能看什么

- **策略**：每条策略的名称、超时、能不能联网/派生进程（策略是**具名的**，由平台定，Skill 不能自己挑）；
- **运行状态**：沙箱根目录、当前活跃作业数；
- **执行审计**：跑过的每一次（策略、退出码、耗时、**是否树杀**），
  以及**结果超长被截断**的标记——这条很重要：模型看到的和你以为的不一定是全部；
- **自检**：平台能力探测（作业对象、解释器、目录可写）。

## 12. 常见问题（FAQ）

### 快捷登录点了没反应

1. **Chrome 没开**：桌面会自动拉起，但冷启动要 1~3 秒；再点一次。
2. **扩展没装或没启用**：看账号中心顶部是否有提示条；`chrome://extensions` 里确认扩展存在且为启用态。
3. **扩展是旧版**：出现「浏览器扩展版本过旧」提示条 → 点「重新加载引导」。
4. 仍无反应 → 扩展弹窗右上角 **导出诊断**，把 JSON 发给开发者（里面有每次指令与失败的完整记录）。

### 提示「未检测到浏览器扩展」，但我装了

- 该提示条**只在从未连接成功过**时出现。若它出现，说明扩展尚未成功连上桌面端：
  确认 Chrome 在运行、扩展为启用态，然后重启一次应用（桌面壳会重连）。
- 若你**曾经连上过**却仍看到提示条，说明本地数据库里的「已连接」标记没写进去（DB 权限问题），
  此时按提示重新装载即可，不影响功能。

### 内置浏览器打开后停在「加载中」或一直不登录

- 检查账号密码是否最新（改过平台密码？在账号中心编辑该账号）；
- 该账号权限不足也可能表现成登录后进入受限页；
- 若卡住很久：关闭该会话窗口重开（会自动重登）；仍不行则重启应用
  （可能是浏览器后端卡住，见 [PITFALLS.md](PITFALLS.md) 环境坑）。

### 「打开」能免密，但「快捷登录」仍要我输密码

两条路径是独立的（§4）：**免密登录态只存在于内置浏览器**；你自己的 Chrome 里靠扩展填表，
扩展未装载/未启用时会退化为手动输入。

### 对象分析的账号下拉是空的

先确认账号库里确实有账号（账号中心）。下拉默认先列**配置池**成员，池为空时会**自动回退显示全部账号**
并在选项里提示；连回退后的列表都是空的，说明账号库本身是空的。

### 对话报「请先在设置中配置 DeepSeek API Key」

设置页填 Key。

### 更新一直下载不下来

自动更新要访问 GitHub。先看账号中心版本角标的提示、或托盘「检查更新…」的结论；
若你的网络必须走代理，见 [docs/CONFIG.md](CONFIG.md) §6 的 `proxy.txt`（写一行代理地址即可强制走代理）。

### 应用升级后，功能看起来还是旧的

- 桌面端：完全退出（托盘 → 退出）再启动一次；
- 浏览器扩展：`chrome://extensions` 点一次「重新加载」。

### 想彻底重置

1. 退出应用；
2. 备份/移走 `%APPDATA%\Workbench`（里面是你的全部数据）；
3. 重新启动应用（会新建空数据库）。注意：**账号口令一旦丢失无法恢复**，请先导出备份。
