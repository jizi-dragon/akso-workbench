## 1. 安装与首次启动

### 1.1 安装

1. 运行 `Workbench_<版本>_x64-setup.exe`（Tauri 2 NSIS 安装包）。
   - per-user 安装；**不需要管理员权限**。
   - 包内已含 Python 服务端，**不再携带浏览器内核**，无需预装 Python / Node / Playwright。
   - Windows 10 需要 WebView2 Runtime（Win11 自带；Win10 一般随 Edge 安装）。
   - ⚠️ **2026-09-16 起本应用改名**（原名 `AksoWorkbench`）。安装目录与卸载项是新的一套，
     **旧版不会被覆盖安装**——请先在「添加或删除程序」里卸载旧版，再装新版。
2. 首次启动会自动初始化数据目录 `%APPDATA%\Workbench`。若你电脑上还留着**更名前**的
   `%APPDATA%\AksoWorkbench`（或更早的 Mogul 工作台），首次会**自动复制接管**其中的数据库——
   账号、环境、Fernet 密钥、历史会话都不丢。**旧目录不会被删除**（想回滚就用它）。
3. 接管是**一次性复制**：之后请只用新版本。若在旧版本里继续加账号，两份数据会分叉。

### 1.2 多账号并行（可选，独立仓库）

本应用**不内置浏览器**（2026-10-19 起，内置 Chromium / 托管会话 / 自动登录整体下线）。
需要"在你自己日常的 Chrome 里多账号并行"时，请单独安装
[akso-pass](https://github.com/jizi-dragon/akso-pass)：它是独立的 MV3 扩展，
账号与口令走云端账号库。

### 1.3 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 浏览器 | **无需内置浏览器**；只有在用 akso-pass 扩展时才需要你自己的 Chrome/Edge |
| 网络 | 能访问你的 eGMP 平台；更新安装包可从内部 HTTPS 源获取（受限网络见 [CONFIG.md](CONFIG.md) §6 的 `proxy.txt`） |

## 2. 界面总览

应用有**一个主窗**（Tauri + WebView2；2026-10-09 起不再有轮盘窗，2026-10-19 起不再有 Electron 托盘）：

- 默认窗口居中，占主显示器工作区的 **80%**（不最大化）；分辨率小或缩放高时也不会超出屏幕。
- **主窗**：左侧导航（对话 / 设置 / 平台模块 / **Agent 能力**），主区是对话与设置。
- **关闭主窗 = 退出应用**；没有托盘常驻。

| 入口 | 位置 | 用途 |
|---|---|---|
| 账号中心 | 左栏「平台模块」 | 云端账号 / 站点 / 盒子（未登录时遮罩） |
| 对象分析 | 左栏「平台模块」 | 登录验证 / 蜘蛛织网 |
| 对话 / 设置 | 左栏顶部 | AI 对话、DeepSeek 配置、**MCP 服务器**（§12） |

> Skill 管理 / 沙箱入口自 2026-10-20 起从侧栏隐藏；后端与页面仍保留，暂不面向用户开放。

> **改名与下线记录（2026-09-22）**：两个平台模块原先叫「平台洞察」「配置工厂」，
> 同一天先更名为「**对象分析**」「**配置**」；随后「**配置**」整条链路（配置页、`/api/factory/*`
> 端点与 `factory_*` 工具）**已从产品中删除**——左栏现在只剩「账号中心」「对象分析」两项，
> 也没法再从界面写平台配置。另一半的改名**只改了显示名**：模块 id（`insight`）、
> 工具名（`insight_*`）、落盘目录（`runtime\insight\…` / 文档里的 `…\Workbench\洞察`）都没动，
> 所以老的日志、审计与产物路径仍然对得上。

## 3. 账号中心（云端）

打开：左栏 → **账号中心**。账号中心**只展示云端账号库**；本地不再提供站点/账号/盒子/分配池的增删改。

### 3.1 登录

未登录时页面会被遮罩，中间只有「开始登录」：

1. 点「开始登录」→ 系统浏览器打开 Akso Cloud 授权页；
2. 在浏览器里批准 → 桌面端自动完成登录并读取云端库；
3. 不需要抄验证码；授权超时可重新点一次。

### 3.2 云端账号视图

- 账号卡片、盒子芯片、站点台账、盒子台账全部来自 `/api/vault/library`；
- 顶部统计是云端数量；卡片是**只读**的，没有本地编辑/移盒/删除；
- 右上角「同步云端」绕过 5 分钟缓存；断网时显示上次缓存并标注。

### 3.3 本地数据推送到云端

「本地推到云端」只用于**一次性迁移**旧的本机账号库：

- 需要先登录；
- 按云端 merge 契约上传站点/账号（密码在内存中解密，随 HTTPS 发出）；
- 云端按 `updatedAt` 合并，不会清空云端；
- `revision` 冲突（409）时先「同步云端」，再重新推送。

> 本地账号库不再作为账号中心的数据源；日常增删改请直接在 Akso Cloud 控制台完成。

### 3.4 本地管理已移除

2026-10-20 起账号中心不再提供：站点管理、添加账号、批量添加、编辑/移盒/删除、
分配池、导出/导入备份、env 导入。旧数据仍保留在本机 DB 里，可通过「本地推到云端」迁移。

> 边界：云端增删改仍在 Akso Cloud 控制台完成；账号中心展示的是只读云端视图。
> 会话令牌 Fernet 加密存本机，页面拿不到密文或解密密钥。

## 5. 对象分析

打开：左栏 → **对象分析**。两个命令：

| 命令 | 作用 | 需要填什么 | 产物 |
|---|---|---|---|
| `login` | 只验连通性并预热 token（55 分钟有效） | 账号 | 无 |
| `spider` | **五步织网**：跨对象的关系网络（networkx 图分析） | 账号 + 对象编码 | `spider-network.{json,md,drawio}` + `step3-attribution.md` + `manifest.json` |

> `inventory`（全量盘点）与 `understand`（三层理解报告）已于 0.3.8 **下线**——应用场景模糊、
> 实际使用效果不理想。历史任务在任务列表里仍可查看产物。

用法：

1. **账号**下拉选账号库里的账号（见 §3.4）；
2. 选命令；`spider` 会要求填对象编码（如 `capa_plan__c,change_control__c`，逗号分隔）；
3. 点 **执行** → 下方实时日志 → **产物区**按类型分组（报告 / 图 / 数据 / 日志 / 图片），
   可按键筛选、搜索；点卡片就地预览：Markdown、drawio、JSON、CSV 表格、日志/文本、图片。
   其他格式可下载；`.drawio` 也可下载后用 draw.io 打开。
   > 预览弹窗支持「原始 / 渲染」切换、复制正文、新窗口打开与下载；CSV 只渲染前 500 行 / 60 列，
   > 超长内容会明确提示截断。

**任务历史**在页面底部，可回看每次执行的状态与产物（状态有三态：`succeeded` / `partial` / `failed`）。

> 实现说明：命令已**全部用 Python 原生实现**，运行时不调用原项目、不需要 Node。
> 产物默认写到**你的工作区** `<工作区根>\<对象编码>\<时间戳>\`（工作区根在设置里改，
> 默认 `我的文档\Workbench\洞察`）；工作区根不可写时才退回
> `%APPDATA%\Workbench\runtime\insight\<任务id>\`。

## 6. 对话与设置

### 6.1 对话

- 主区「对话」：与内置的合规智能体对话（面向药企合规 / 实施问题）。
- 支持流式输出、工具调用（联网读官方页面）、会话历史（左栏「会话记录」）。
- 回答可**点赞/反馈**，用于统计采纳率。
- **可以直接把图片或文件交给它**（2026-09-22 起）：点输入框左下角的「📎 附件」、
  直接**粘贴**（截图之后最顺手的动作）、或把文件**拖进**输入框。
  支持 `.png .jpg .jpeg .webp`（图片直接给模型看）、`.docx .xlsx .pdf .md .txt .csv`
  （会解析出正文与**坐标**，所以它能告诉你"在第 3 页 / 明细表第 5 行"）。
  单文件上限 **20 MB**、一条消息最多 **5 个**。
  发出去之后，**消息里会留下这几个文件的 chip**（图片是缩略图，文档是文件图标 ——
  点它用系统浏览器打开原文件）；刷新页面也还在（它跟着那条消息存着）。
  ⚠️ 两条已知边界：**扫描件 PDF 读不出文字**（不做 OCR，改传截图即可）；
  **隔一轮之后再问"刚才那张图"它看不到了**（只有最新一条消息里的附件会随请求发出，
  这是为了不让同一份文件每轮重发、把账单和上下文一起撑爆）——需要时把图再贴一次。

**输入框那行小字（2026-09-22 起）**：输入框**下方**常驻三个数字——
`缓存命中 X tok · NN% · ◔ 上下文 NN%`。

| 数字 | 含义 | 怎么用它 |
|---|---|---|
| **缓存命中** | 这段对话的输入里，有多少 token 是**从 DeepSeek 前缀缓存里读**的 | 命中价是未命中价的 **1/50** ⇒ 这个数字越大越省钱 |
| **命中率** | 命中 ÷（命中 + 未命中） | 颜色会变：≥60% 绿 / 20–60% 灰 / <20% 琥珀。<br>**在同一段对话里连续追问**命中率才高；每次都新开一个会话，它必然很低 |
| **◔ 上下文** | 那个**小圆环**就是**本轮用掉的上下文 ÷ 模型最大上下文**（右边那圈是空轨道）；旁边的百分比是同一个数 | 圆环过半后变琥珀、过 80% 变红——那时该开新会话，或让 Agent 先把结论写下来。<br>**精确 token 数**（如 `66k / 131k`）在鼠标悬停的提示里 |

> 为什么图标旁只放百分比：那两个 token 数不是"一眼要判断的东西"，
> 判断靠的是**比例 + 颜色**；精确数字悬停即得，不占那行位置。

输入框**右侧**（发送键旁边）显示**当前生效的模型名**，点它跳到设置里更换。
这一行**一直在**：还没开始对话时三段都显示「—」（它不是"有数据才冒出来的提示"，
免得第一次问答成功时整行突然出现、把输入框顶上去一格）。

### 6.2 设置

| 项 | 说明 |
|---|---|
| **DeepSeek API Key** | 存本机 SQLite，仅发往 DeepSeek 官方端点。**不填则对话与所有 Agent 能力不可用** |
| **模型选择** | 提供两个选项（经济版 / 旗舰版）。⚠️ 界面**不支持自定义模型名**；若你的账号需要用别的模型名，见 [CONFIG.md](CONFIG.md) §5 |
| **Temperature** | 0（严谨）~ 2（发散），默认 0.7 |
| **单轮工具调用上限** | 默认 **40**。你发一条消息后，Agent 最多调用这么多次工具（只读查询与危险写入一样计费）。<br>**用完了不会丢进度**——它会把已完成的都留着，你回一句「继续」就接着做。<br>对象分析这类多步任务（找账号 → 织网 → 取产物）建议 40 以上；调到 200 以上没有意义，那只是把刹车松开 |

## 8. 升级

> ⚠️ **当前版本没有接入自动更新的 UI**。Tauri updater 的签名、安装包 `.sig` 与 `latest.json`
> 清单已经具备，但“检查 → 提示 → 下载 → 退出安装”的界面还没接；账号中心版本角标只显示版本号。

1. **手动升级**：退出应用，运行新版本的 `Workbench_<版本>_x64-setup.exe` 覆盖安装。
2. 覆盖安装保留 `%APPDATA%\Workbench` 中的账号、环境、数据库与密钥。
3. 回滚：退出应用，运行旧版本安装包；数据库迁移只增不改，旧版本可能打不开新版本库，
   回滚前应先备份 `%APPDATA%\Workbench`。

> Tauri updater 的目标行为是：启动后延迟检查、后台下载、退出时安装；
> 在此之前不要期待自动弹窗。详见 [TAURI-MIGRATION.md](TAURI-MIGRATION.md) §4。

## 9. 数据位置与安全须知

### 9.1 你的数据在哪

| 内容 | 位置 |
|---|---|
| 账号 / 环境 / 会话 / 任务记录 | `%APPDATA%\Workbench\workbench.db`（SQLite 单文件） |
| 对象分析的产物 | `%APPDATA%\Workbench\runtime\insight\<任务id>\`（目录名仍是 `insight`，更名没动它） |
| ~~托管浏览器的免密登录态~~ | 2026-10-19 起不再产生；旧版本残留的 `runtime\browser-states\` 可手工删除 |
| ~~监听录制产物~~ | 2026-10-19 起不再产生；旧版本残留的 `runtime\monitor\` 可手工查看/删除 |
| MCP 配置（可选） | `%APPDATA%\Workbench\mcp.json`（可含外部服务 token，别外发） |
| ~~浏览器缓存与各账号会话分区~~ | 2026-10-19 起不再产生；旧版本残留的 `Partitions\` 可删除，**不会**丢账号 |

**备份建议**：云端账号库以云端为准（跨设备自动可见）；桌面端不再提供账号库导出备份。
旧版本留下的本机数据库仍可能含历史账号凭据，可连同 `%APPDATA%\Workbench` 一起归档，但该目录等价于凭据。

### 9.2 安全须知（请知悉）

- **云端账号库的密码不在桌面端明文保存**；旧本地库的密文与密钥仍在 `%APPDATA%\Workbench`，整体备份等价于凭据。
- 应用的服务只监听**本机回环**（`127.0.0.1`），**没有登录认证**——所以别把端口暴露到局域网，
  也别在多人共用的电脑上长期挂着。
- **MCP 配置**（`mcp.json`）里可能有外部服务的 token，它和账号库一样属于本机凭据：
  不要提交到 git、不要发给别人。
- 真机操作请只在**测试环境**账号上进行。

## 10. Skill 管理（入口已隐藏）

打开：左栏 → **Agent 能力 → Skill 管理**。

Skill 有两种形态：

- **文件夹 Skill（标准 `SKILL.md`）**：直接放进 `WORKBENCH_SKILLS_DIRS`、项目
  `.agents/skills`、`.workbench/skills` 或用户数据目录 `skills/folders`。不需要上传/安装，
  模型用 `list_skills` 看目录、`read_skill` 按需读正文；**不执行任何脚本**。
- **ZIP 工具包**：需要给 Agent **增加工具**时才用。装上之后会给 Agent 增加若干工具
  （模型就能"调用"它）。整个流程是：**上传到共享库 → 从库里安装 → 立刻生效**；
  不用了**一键卸载**。下面 10.1–10.3 讲的是这一种。

### 10.1 上传

1. 点「选择文件」选一个 Skill ZIP（≤10 MB，`SKILL.md` 必须在**压缩包根目录**，
   **不许夹带任何二进制文件**——图片、exe、压缩包都不行）；
2. 点「上传」。系统会做**结构校验 + 可疑模式扫描**，并把扫描到的东西**整条列出来**；
3. **扫描到高危模式时不会直接入库**：先给你看发现清单，确认后才收
   （这一步是刻意的——"点一下上传就生效"不该发生在扫描有警报的包上）。

> ⚠️ **扫描是"准入闸门"，不是"安全鉴定"**。它只把要你亲眼看一看的地方摊开
> （网络访问、子进程、动态执行、凭据字样…），**不判定恶意**，也挡不住刻意混淆的包。
> 真正管住"它到底能干什么"的是 §11 的沙箱与确认门。

### 10.2 从共享库安装 / 卸载

| 动作 | 结果 |
|---|---|
| **安装到 Agent** | 该 Skill 的工具**立刻**对模型可见（不用重启） |
| **卸载** | 工具**立刻**消失；**共享库里的版本一个都不会删**（卸载 = 不再生效，不是销毁） |
| **从库删除** | 真正销毁（所有版本）。若已安装会先卸载 |
| **禁用 / 启用** | 只是不进模型可见的工具表，插件仍在清单里，随时可恢复 |

> **卸载 ≠ 删除**。想彻底清掉必须点「从库删除」——这是刻意的：你可能只是想先停用，
> 或者换个版本再装回来。

### 10.3 装进来的工具会"自己动手"吗

看它的**风险等级**，规则与自带工具完全一样：

- `read`（只读）→ 直接执行；
- `write` / `dangerous` → **必须你确认**（对话里会弹出确认，或走待确认列表批准）。

**带脚本的 Skill 有额外一条**：包内脚本（`script:`）执行的是**上传来的代码**，
所以它的风险**最低就是 `write`**——哪怕作者写 `risk: read` 也一样，**每次调用都要你确认**。

清单里带「**含脚本 N**」徽标的，就是这类 Skill；工具名后面标「(脚本)」的，
就是会执行上传代码的那几个。

### 10.4 数据放在哪

- 共享库：`%APPDATA%\Workbench\skills\library\<能力id>\<版本>\`
- 已安装（生效中的指针）：`%APPDATA%\Workbench\skills\installed\<能力id>\current`

两处都在你的数据目录里，**不会**被提交进代码仓库。想搬到别的机器，直接拷 `skills` 目录即可。

## 11. 沙箱（入口已隐藏）

打开：左栏 → **Agent 能力 → 沙箱**。这一页回答三个问题：**按什么规则跑、现在在跑什么、跑过什么**。

### 11.1 它能拦什么

| 层 | 做法 |
|---|---|
| 凭据 | 脚本**拿不到**你的环境变量与凭据（只注入 Skill 自己的身份信息） |
| 目录 | 工作目录必须在**工作区根**内（可在页面改）；敏感路径（凭据库、浏览器 profile、MCP 配置）拒绝 |
| 进程 | 超时**连整棵进程树一起终止**（不让一个死循环永久占住） |
| 网络/派生进程 | 默认**不给**（脚本式 Skill 的策略就是"不联网、不派生进程"），由工作区权限预检 |

### 11.2 工作区与权限（2026-10-19 新增）

页面最上方是「工作区与权限」：

| 项 | 说明 |
|---|---|
| **工作区根** | Agent 脚本唯一能跑的目录；默认 `%APPDATA%\Workbench\sandbox`，可改成你的项目目录 |
| **权限模式** | 「读写」允许脚本写工作区；「只读」**拒绝所有声明会写的策略**，只允许只读解析类任务 |
| **允许联网 / 派生进程** | 关闭时，声明需要联网 / 派生进程的策略会被拒（不是"警告后照跑"） |
| **恢复默认** | 回到默认根与保守权限（联网 / 派生进程关闭） |

边界必须说清：**只读不是内核级只读**。脚本仍以当前用户权限运行，它自己仍可能写文件；
只读挡的是"执行器明知这份策略会写还放它跑"。真正的隔离需要单独用户 / 容器 / ACL。

### 11.3 它**不能**拦什么（请认真读这一条）

**沙箱不是内核级隔离**，它降的是风险，不是"跑恶意脚本也安全"的保证：

- 能跑的代码**仍能读它有权限读的一切**（沙箱不是监狱，是"把门关小 + 看得见"）；
- 沙箱**不替代确认门**——两者是纵深关系，所以带脚本的工具照样每次都要你确认；
- 因此：**只装你信得过的来源的 Skill**（同事给的、自己写的），
  不要装来路不明的包。这一条没有技术兜底。

### 11.4 页面上能看什么

- **工作区 / 权限**：根目录、读写模式、联网 / 派生进程开关、配置文件路径；
- **策略**：每条策略的名称、超时、能不能联网 / 派生进程 / **写工作区**（策略是**具名的**，由平台定，Skill 不能自己挑）；
- **运行状态**：工作区根目录、当前活跃作业数；
- **执行审计**：跑过的每一次（策略、退出码、耗时、**是否树杀**），
  以及**结果超长被截断**的标记——这条很重要：模型看到的和你以为的不一定是全部；
- **自检**：平台能力探测（作业对象、解释器、工作区可写）。

## 12. MCP 服务器（可选）

MCP 让 Agent 调用**外部工具服务**（消息、数据库、业务 API 等）。它不是必需的：
不配置时工作台与原来完全一样。

1. 在数据目录（默认 `%APPDATA%\Workbench`）新建 `mcp.json`：

   ```json
   {
     "mcpServers": {
       "my-tools": { "command": "uvx", "args": ["my-mcp-server"] }
     }
   }
   ```

2. 打开「设置 → MCP 服务器」→ 点 **重新连接**；
3. 状态显示 `已连接 · N 个工具` 后，工具就进入对话的可用工具面；
4. 默认 `risk=write`：模型每次调用都会**弹确认**，你放行后才执行。
   只读 server 可在配置里写 `"risk": "read"`。

> ⚠️ **命令只从配置文件来，模型不能指定**；`env` 里可以放 server 需要的 token，
> 但不要把宿主的环境变量整份搬进去。详细字段、安全默认与排障见 [MCP.md](MCP.md)。
>
> ⚠️ MCP server 是**按你的用户权限运行**的本地程序，不在沙箱里。只安装你信任的 server。

## 13. 常见问题（FAQ）

### 账号密码改了，平台连不上

- 在账号中心编辑该账号，更新口令；
- 用 Agent 的 `accounts_login`（httpx 直连，不打开浏览器）验证连通；
- 账号权限不足可能表现为登录后进入受限页，这不属于应用故障。

### 对象分析的账号下拉是空的

先确认账号库里确实有账号（账号中心）。下拉默认先列**配置池**成员，池为空时会**自动回退显示全部账号**
并在选项里提示；连回退后的列表都是空的，说明账号库本身是空的。

### 对话报「请先在设置中配置 DeepSeek API Key」

设置页填 Key。

### 更新一直下载不下来

当前版本没有自动更新，升级请从内部 HTTPS 源下载新的 `Workbench_<版本>_x64-setup.exe` 覆盖安装。
如果你在等 Tauri updater 的自动更新，它尚未接入界面；详见 [TAURI-MIGRATION.md](TAURI-MIGRATION.md) §4。
若下载本身需要代理，设置 Windows 系统代理即可；应用不再读取 `proxy.txt`。

### 应用升级后，功能看起来还是旧的

完全退出应用（关闭主窗）再启动一次；如果还有旧进程，用任务管理器确认 `Workbench.exe` 已退出。

### 想彻底重置

1. 退出应用；
2. 备份/移走 `%APPDATA%\Workbench`（里面是本地日志、旧账号库、MCP 配置等）；
3. 重新启动应用（会新建空数据库）。云端账号库不受影响；旧本地账号如果还没
   「本地推到云端」，请先在账号中心推送，否则删除后无法恢复。
