# 生命周期动作类型映射（behaviorType）

> 来源：Akso eGMP 前端入口 bundle `/assets/akso-script-entry-index-1179a4d9.js` 的导出枚举 `el`（双向枚举：数字 → 名称、名称 → 数字）。  
> 抓取环境：`https://standard-val.aksoegmp.com`，2026-11-12。  
> 校验方式：在浏览器里 `import()` 入口模块后读取 `el`，再把配置手册里的动作名称逐条回查数值。

## 1. 怎么用

动作接口返回的 `behaviorType` 是数字；用本表换成中文。典型位置：

- 进入动作：`GET /api/config/lifecycle/EnterAction/GetById?id=<actionId>` → `configs[].behaviorType`；
- 用户动作：`GET /api/config/lifecycle/UserAction/GetById?id=<actionId>` → `actions[].configs[].behaviorType`（列表接口通常已带 `configs`）；
- 工作流动作节点：`stepAction.behaviorType`。

> 注意：`GetListByStatusId` 只回动作壳，进入动作的 `configs` 必须再调 `GetById` 才有；没有 `configs` 就是“未配置具体动作”，不能从名称反推类型。
