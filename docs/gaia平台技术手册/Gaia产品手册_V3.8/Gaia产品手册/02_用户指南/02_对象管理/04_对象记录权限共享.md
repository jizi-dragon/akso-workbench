# 对象记录权限共享
> 本文介绍如何配置对象记录的访问权限。   

---

## 查看权限共享
1. 打开记录详情
2. 点击 **权限共享**
3. 查看当前共享用户

---

## 添加权限共享
1. 点击 **添加用户**
2. 搜索选择用户/用户组/部门
3. 选择角色
4. 点击 **保存**

---

## 移除权限共享
1. 在共享列表中找到用户
2. 点击 **移除**

---

## 编辑权限共享
1. 在共享列表中找到用户
2. 点击 **编辑**
3. 在弹出层中重新选择用户/用户组/部门以及角色
4. 点击 **保存**
