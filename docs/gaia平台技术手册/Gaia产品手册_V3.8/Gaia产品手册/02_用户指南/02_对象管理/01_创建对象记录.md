# 创建对象记录
> 本文介绍如何在 Gaia 平台创建新的对象记录。   

---

## 创建新记录

### 方法一：从列表页创建
1. 进入对象列表页
2. 点击 **创建** 按钮
3. 填写记录信息
4. 点击 **保存**

### 方法二：从关联记录创建
1. 打开父记录详情页
2. 在相关列表中点击 **新建**
3. 填写记录信息（父记录自动关联）
4. 点击 **保存**

### 创建模式下的相关对象

创建新记录时，表单中的相关对象部分和附件部分支持以下行为：

| 功能 | 说明 |
|------|------|
| **在创建模式显示** | 若布局中相关对象或附件部分启用了“在创建模式显示”，创建页面会展示该部分，便于同时录入主记录和子记录 |
| **追加模式** | 添加相关对象数据时，可选择**追加模式**，新添加的记录会与已有记录一起保存，而不会替换现有数据 |
| **行内编辑** | 支持在创建模式下直接创建相关对象并**行内编辑**，无需跳转即可完成主记录与子记录的一体化录入 |
| **隐藏部分不提交** | 若页面部分被隐藏（如通过布局规则），提交时不会保存该部分的相关对象数据，避免产生不必要的临时数据 |
| **扫码添加排序** | 通过扫码添加相关记录时，**最新扫入的记录排在最前面**，便于快速确认刚添加的内容 |

## 填写字段

### 字段类型

| 字段类型 | 输入方式 | 录入提示 |
|------------|------------|------------|
| **文本（Text）** | 单行输入 | 适合编号、简称等短文本 |
| **长文本（Long Text）** | 多行输入 | 适合备注、描述等长内容 |
| **富文本（Rich Text）** | 富文本编辑器 | 可进行基础格式编辑（如加粗、换行等） |
| **数字（Number）** | 数字输入框 | 系统按字段精度和小数位校验 |
| **日期（Date）** | 日期选择器 | 仅选择日期，不包含时间 |
| **日期时间（DateTime）** | 日期时间选择器 | 同时录入日期和时间 |
| **布尔（Boolean）/复选框** | 勾选是/否 | 常用于开关类字段 |
| **选项（Picklist）** | 下拉选择 | 单选字段，按预设选项填写 |
| **对象（Object）/父对象（Parent Object）** | 搜索并选择关联记录 | 用于建立对象之间的关联关系 |
| **附件（Attachment）** | 上传文件 | 文件大小、格式和数量按系统规则限制 |
| **查找（Lookup）/统计（Statistics）/公式（Formula）** | 自动计算或自动带出 | 这类字段通常只读，无需手工录入 |
> 说明：不同对象的创建页面字段并不完全一致，是否显示、是否可编辑、是否必填由对象配置和布局规则决定。   

### 必填字段
- 必填字段标有红色星号 \*
- 必须填写才能保存

---

## 保存选项

| 按钮 | 说明 |
|------|------|
| **保存** | 保存并返回列表 |
| **保存并新建** | 保存并创建下一条 |
| **取消** | 放弃修改 |

### 创建后跳转方式

通过**创建出站对象**类动作创建关联记录时，支持配置创建后的跳转方式，例如：停留在当前页、跳转到新创建记录的详情页等，由管理员在动作配置中设置。

---

## 验证规则

保存时系统会检查：
- 必填字段是否填写
- 字段格式是否正确
- 自定义验证规则是否通过

如不满足条件，会显示错误提示。

---

## 批量创建

如需批量创建记录：
1. 使用 **导入** 功能
2. 下载导入模板
3. 填写数据
4. 上传文件
