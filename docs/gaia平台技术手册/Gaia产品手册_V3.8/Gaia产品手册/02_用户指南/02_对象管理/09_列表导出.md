> **适用角色**：具有对象记录查看权限、并被授予列表导出动作权限的业务用户本文说明如何在对象列表中导出数据。列表导出用于把当前列表结果导出为文件，便于审计留痕、数据分析和跨团队共享；如需带出相关对象数据，需从主对象列表发起导出。   

---

## 概述

列表导出当前仅支持在**对象列表**中直接发起，导出结果受当前列表配置、筛选条件和权限控制。相关对象列表目前不支持直接发起列表导出；如需带出相关对象数据，需要从主对象列表按配置一并导出。

列表导出的典型特点如下：
- 从列表页直接发起，无需跳转到独立导出工具
- 导出字段通常来自当前列表显示列（附件字段不导出）
- 导出数据范围受当前筛选条件和可见权限控制
- 导出结果默认为 Excel；如已配置导出 PDF 动作，可按配置导出 PDF
- Excel 和 PDF 单次最多导出 10000 条记录；超过上限时，需要先缩小筛选范围或分批导出
- 导出 PDF 时当前列表最多导出 15 列；如当前显示列超过 15 列，需先调整列表显示列，或改用 Excel 导出
- 对象若在 [对象配置](../../04_%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97/01_%E5%AF%B9%E8%B1%A1%E9%85%8D%E7%BD%AE.md) 中开启 **导出序号**，导出结果第一列为 `序号`（强制追加，不受导出字段选择影响）。`序号` 计入 PDF 的 15 列上限
- 导出 PDF 且已启用列表导出封面模板时，系统会在第一页自动附加封面页
- 导出 Excel 时，可按当前主对象列表配置同时带出单个相关对象或多个相关对象数据
- 大数据量场景下可通过异步任务执行，导出完成后再下载文件

---

## 适用场景

列表导出适用于以下场景：
- 需要将当前筛选结果导出给审计、质量或管理团队
- 需要把列表数据导出到 Excel 做进一步统计分析
- 需要从主对象列表一并导出相关对象数据用于对账、汇报或归档

列表导出不适用于以下场景：
- 需要修改平台内记录内容（导出本身不改变数据）
- 需要跨权限范围查看不可见数据
- 需要导出附件二进制内容（附件字段不在列表导出范围内）
- 需要在相关对象列表中直接发起导出

---

## 前提条件

使用列表导出前，请确认：
1. 当前列表已配置并显示导出动作（如“导出 Excel”或“导出 PDF”）。
2. 您具备目标对象的查看权限，并具备对应导出动作权限。
3. 如需导出相关对象字段，当前主对象列表视图已配置并展示对应列。
4. 如需在一次导出中同时带出多个相关对象，当前主对象列表已配置关系切换器，且该关系切换器已开启“关系允许多选”。
5. 如需导出带封面的 PDF，当前环境已启用列表导出封面模板。
6. 您已完成必要筛选，确保导出范围与业务预期一致。
7. 如预计导出结果超过 10000 条记录，需先缩小筛选范围或分批导出；如导出 PDF，还需确认当前列表显示列不超过 15 列。

---

## 入口说明

列表导出的入口来自当前列表操作区，可能出现在：
- 对象列表

在列表动作中，常见入口包括：
- 导出 Excel
- 导出 PDF（需已配置）

说明：
- 是否显示导出入口，取决于当前列表配置及权限。
- 同一对象在不同视图下可导出的字段范围可能不同。
- 相关对象列表当前不提供“导出 Excel”或“导出 PDF”入口。

---

## 操作步骤
1. 进入目标对象列表。
2. 根据业务需要设置视图、筛选条件和排序方式。
3. 如需限定记录范围，可先勾选目标记录（若页面支持按勾选范围导出）。
4. 在操作栏中点击导出动作（如“导出 Excel”或“导出 PDF”）。
5. 如需导出 Excel 相关对象数据，先在主对象列表的关系切换器中选择要带出的单个相关对象或多个相关对象，再发起导出；如导出 PDF 且已启用封面模板，无需额外操作，系统会自动附加封面页。
6. 在导出面板中确认导出范围（如页面提供“当前页/选中记录/全部结果”等选项，以界面实际显示为准）。
7. 确认导出字段（如已启用字段选择功能）。
8. 提交导出任务并等待系统处理。
9. 下载导出文件并核对结果。

## 页面行为说明

### 字段来源

列表导出的字段通常来自当前列表视图已显示的列配置。

说明：
- 调整“编辑列”会影响本次导出的字段范围。
- 附件字段不参与列表导出。

### 数据范围

导出记录通常基于当前筛选条件生成结果集。

若页面提供范围选项（例如当前页、选中记录、全部结果），则以用户在导出面板中的选择为准。

### 导出格式规则

常见字段类型导出规则如下：

| 字段类型 | 导出结果 |
|------------|------------|
| 文本 | 文本 |
| 数字/统计 | 数字 |
| 布尔 | 文本 |
| 选项/多选 | 文本（多选值通常以英文逗号分隔） |
| 日期/日期时间 | 日期或时间 |
| 对象/父对象 | 导出对象名称文本 |
| 附件 | 不支持导出 |

### 空值与相关对象
- 平台支持将空白单元格显示为 `N/A`，便于区分“未填写”与空字符串。
- 相关对象列表当前不支持直接列表导出。
- 当主对象列表配置包含相关对象字段时，可按配置一并导出相关对象数据。
- 导出 Excel 时，如当前只选择了一个相关对象，系统会按当前选中的相关对象输出对应数据。
- 导出 Excel 时，如当前同时选择了多个相关对象，系统会按“一个相关对象一个 Sheet”的方式输出；每个相关对象 Sheet 的第一列会显示主对象 `name__ak`，便于对照主对象与相关对象记录。
- 若对象已开启 **导出序号**，每个 Sheet 最左侧再追加 `序号` 列：主对象 Sheet 为 `序号` → 业务列；相关对象 Sheet 为 `序号` → `name__ak` → 其他列。
- 部分场景支持导出时合并主对象字段显示，具体以当前版本页面能力为准。

### PDF 封面
- 导出 PDF 时，如当前环境已启用列表导出封面模板，系统会自动在第一页生成封面页。
- 封面页通常会带出当前用户、当前时间、过滤条件、对象名称、视图名称和总页数等信息，用于标识本次导出结果的来源和范围。
- 如未启用封面模板，导出的 PDF 将直接从列表内容页开始，不额外生成封面。

### 导出上限
- Excel 和 PDF 单次最多导出 10000 条记录；如当前筛选结果超过上限，需先缩小筛选范围或拆分批次后再导出。
- PDF 单次最多导出 15 列；如当前列表显示列超过 15 列，建议先精简列表列，或改为导出 Excel 获取完整列数据。开启导出序号时，`序号` 占用其中 1 列。

### 导出序号

是否输出 `序号` 由对象 **基础 → 设置** 中的 **导出序号** 控制，用户端没有单独开关。配置见 [对象配置](../../04_%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97/01_%E5%AF%B9%E8%B1%A1%E9%85%8D%E7%BD%AE.md)。开启后，导出结果第一列为 `序号`。

编号规则：
- 每个 Sheet / 表格内，按**本次导出结果集**的当前排序从 `1` 连续编到 `N`；多 Sheet 时各 Sheet 独立从 `1` 编号，统一读取主对象开关。
- 非全量导出、或排序/筛选变化后，对本次结果集从 `1` 重编，不要求与列表分页上的行号一致。
- 相关对象 Sheet 把记录拉平为一张表后，序号是整张 Sheet 的全局行序，不按主对象重置。对照归属主对象请看 `name__ak`，不要用序号跨 Sheet 对行。
- 合并主对象时，序号标识的是导出行，不是主对象条数。

跨次导出、跨文件、跨 Sheet 不能用序号对照记录，请用 ID、编号、`name__ak` 等业务字段。批导、报表、仪表盘、审计日志导出不受此开关影响。

## 权限与数据范围

### 权限控制

列表导出受对象动作权限控制，仅在用户具备对应动作权限时可用。

### 可见范围控制

导出结果仅包含当前用户有权查看的记录和字段，不会突破现有数据权限边界。

### 组织/业务单元隔离

导出结果遵循当前组织或业务单元的数据隔离规则，不会导出跨组织不可见数据。

---

## 结果查看

提交导出后，系统会生成导出任务并返回下载结果。

导出完成后，建议核对以下内容：
- 记录数量是否符合预期
- 字段列是否完整
- 关键字段值是否正确（尤其是状态、关系字段、日期字段）

如发现差异，建议先检查当前筛选条件、视图字段配置和权限范围，再重新导出。

---

## 常见注意事项

| 场景 | 建议 |
|------|------|
| 导出数据量较大 | 先加筛选条件分批导出，减少等待时间 |
| 导出字段缺失 | 先在列表“编辑列”中确认已显示目标字段 |
| 导出后看不到部分记录 | 检查筛选条件、记录可见权限和组织范围 |
| 需要导出相关对象数据 | 请从主对象列表发起导出，并先确认列表中已配置相关对象字段 |
| 需要一次导出多个相关对象 | 请从主对象列表发起导出，并先确认关系切换器已开启“关系允许多选” |
| 需要从相关对象列表直接导出 | 当前不支持；请改为返回主对象列表后再发起导出 |
| 导出空值分析困难 | 优先使用空值显示为 `N/A` 的导出文件做分析 |
| 需要 PDF 封面 | 先确认是否已启用列表导出封面模板；未启用时 PDF 不会自动附加封面页 |
| Excel/PDF 导出条数超过上限 | 单次最多导出 10000 条记录；超过上限时请缩小筛选范围或分批导出 |
| PDF 导出列数超过上限 | 单次最多导出 15 列（含开启后的序号列）；超过上限时请减少当前显示列，或改用 Excel 导出 |
| 导出文件没有行号 | 需在对象「基础 → 设置」勾选「导出序号」，见 [对象配置](../../04_%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97/01_%E5%AF%B9%E8%B1%A1%E9%85%8D%E7%BD%AE.md)；用户端不能单独打开 |
| 导出序号与列表第 N 行对不上 | 序号按本次导出结果集重编，不保证与分页列表行号一致；跨文件请用业务编号对照 |
| PDF 导出样式异常 | 检查是否已启用并正确配置导出页面模板 |
