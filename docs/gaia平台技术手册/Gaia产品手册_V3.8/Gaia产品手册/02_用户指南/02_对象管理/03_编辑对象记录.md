# 编辑对象记录
> 本文介绍如何在 Gaia 平台编辑现有对象记录。   

---

## 编辑记录

### 进入编辑模式
1. 打开记录详情页
2. 点击 **编辑** 按钮
3. 修改字段值
4. 点击 **保存**

### 快速编辑

部分列表支持行内编辑：
1. 双击单元格
2. 修改值
3. 点击保存按钮或者按 Enter 保存
> \[!WARNING\]
在记录详情页中，如果存在未保存的行内编辑数据，点击右上角的提交或其他用户动作时，系统会提示：**\{部分名称\}存在未保存的数据**。请先保存行内编辑的数据，再进行其他操作。   

---

## 可编辑字段

| 状态 | 可编辑 |
|------|---------|
| 普通字段 | ✓ |
| 只读字段 | ✗ |
| 公式字段 | ✗ |
| 系统字段 | ✗ |
> \[!NOTE\]
字段的可编辑性可能受生命周期状态和权限控制。当相关分区或部分为只读时，该部分内的**所有单元格**（包括网格视图中的单元格）也会禁止编辑，与整体只读状态保持一致。   

---

## 编辑历史/审计追踪

所有字段修改都会记录：

| 信息 | 说明 |
|------|------|
| **修改人** | 执行修改的用户 |
| **修改时间** | 修改发生的时间 |
| **字段名** | 被修改的字段 |
| **旧值** | 修改前的值 |
| **新值** | 修改后的值 |

查看历史：进入记录详情页 \> **审计追踪**

---

## 批量编辑

### 主列表批量编辑
1. 在列表页勾选多条记录
2. 点击 **批量编辑**
3. 选择要修改的字段
4. 输入新值
5. 点击 **应用**

### 批量编辑相关对象字段

在记录详情页的**相关对象列表**中也支持批量编辑：
1. 在相关对象表头点击 **编辑字段** 动作
2. 勾选要修改的相关对象记录（支持多选）
3. 选择要修改的字段并输入新值
4. 在确认界面检查后点击 **确定** 执行
5. 系统会弹出提示，显示批量编辑的执行结果
> \[!NOTE\] **编辑字段** 动作需要在配置中启用后才会在表头显示。批量编辑相关对象字段的功能与主列表批量编辑功能一致。   

---

## 删除记录

删除入口在**对象列表**的行操作栏，不在记录详情页的「更多」菜单中。
1. 打开目标对象的列表页
2. 在目标记录所在行，打开行操作栏（或操作列菜单）
3. 点击 **删除**
4. 确认删除
> \[!WARNING\]
删除操作不可撤销。如有关联记录，可能无法删除。是否显示删除入口取决于当前用户对该记录的删除权限。
