# 富文本编辑
> 本文介绍 Gaia 平台富文本字段的编辑能力，包括格式设置、表格操作、复制粘贴及显示特性。   

---

## 功能简介

富文本字段支持在对象记录中输入和展示带格式的文本内容，适用于需保留排版、样式或结构化信息的场景。

### 主要能力

| 能力 | 说明 |
|------|------|
| **格式设置** | 支持粗体、斜体、下划线、字体、字号、颜色等 |
| **表格** | 支持创建、编辑表格，合并与拆分单元格 |
| **复制粘贴** | 支持保留原格式或仅保留纯文本 |
| **显示控制** | 内容在控件边界内规范显示，避免溢出 |

---

## 编辑器功能

### 工具栏

富文本编辑器提供常用格式工具：

| 工具栏 | 用途 |
|---------|------|
| **文本格式** | 粗体、斜体、下划线、删除线 |
| **段落** | 标题、有序列表、无序列表、引用 |
| **对齐** | 左对齐、居中、右对齐、两端对齐 |
| **字体** | 字体、字号、文字颜色、背景色 |
| **其他** | 插入链接、图片、表格 |

### 格式设置
1. 选中要设置的文本
2. 在工具栏中选择对应格式
3. 格式即时生效
> \[!TIP\]
工具栏按钮可重复点击以切换格式开关（如粗体、斜体）。   

---

## 表格操作

### 创建表格
1. 将光标置于富文本编辑区
2. 点击工具栏中的 **插入表格** 按钮
3. 选择行数和列数
4. 表格插入到当前光标位置

### 合并单元格
1. 选中要合并的多个连续单元格
2. 右键选择 **合并单元格**，或点击工具栏中的合并按钮
3. 所选单元格合并为一个单元格

### 拆分单元格
1. 将光标置于已合并的单元格内
2. 右键选择 **拆分单元格**，或点击工具栏中的拆分按钮
3. 按需选择拆分为行或列及数量
4. 确认后完成拆分

---

## 复制粘贴

从 Word、Excel 等应用复制包含表格或格式的内容到富文本字段时，系统会提示选择粘贴方式。

### 粘贴选项

| 选项 | 说明 |
|------|------|
| **保留原格式** | 保持原有格式（字体、颜色、表格等） |
| **仅保留文本** | 去除所有格式，仅保留纯文本 |

### 操作步骤
1. 从外部应用复制内容
2. 在富文本字段中粘贴（Ctrl\+V）
3. 粘贴完成后，在内容右下角出现 **粘贴结果处理选项**
4. 选择 **保留原格式** 或 **仅保留文本**

---

## 富文本显示

### 显示范围控制

富文本字段在查看模式下，内容会自动限制在控件边界内，不会超出显示区域，保证与页面布局一致。

### 展示优化
- **对齐**：富文本内容与同页面其他字段对齐，无错位
- **背景**：文本区域背景与页面背景一致，视觉统一

---

## 在文件内容处理中显示富文本表格

在**文件内容处理**相关功能（如运行报告、文件转档）中，富文本字段内的表格会正确渲染和显示，支持在导出或预览时保留表格结构。

---

## 常见问题

**Q：粘贴内容后看不到格式？**   A：请选择 **保留原格式**。若选择了 **仅保留文本**，只会保留纯文本内容。

**Q：表格超出边界怎么办？**   A：系统会自动将富文本内容限制在控件边界内。若表格较宽，可尝试合并或调整列宽，或使用横向滚动查看。

**Q：为什么复制到富文本后没有粘贴选项？**   A：仅当复制内容包含表格或复杂格式时才会出现粘贴选项。纯文本粘贴不会弹出该选项。

**Q：合并后的单元格能否恢复？**   A：可以。将光标置于已合并的单元格内，使用 **拆分单元格** 即可恢复。
