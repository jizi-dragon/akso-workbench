# 对象列表视图
> **适用角色**：需要查询、查看、整理或批量处理对象记录的业务用户本文介绍对象列表视图的主要功能和使用方法。用户可以在列表中查询记录、调整显示字段、查看相关数据，并对记录执行单条或批量操作。   

---

## 概述

打开对象菜单后，系统通常先显示对象列表视图。用户先在列表中找到目标记录，再进入详情页查看完整信息，或直接在列表上执行可用操作。

同一个对象可以有多个视图。每个视图可以有自己的数据范围、显示字段、排序方式和可用操作。例如，“所有偏差”用于查看全部可见偏差，“待我处理”用于查看待办记录，“收藏夹”用于快速打开自己关注的记录。

列表视图只显示当前用户有权限查看的记录和字段。即使同一对象下存在更多数据，用户也只能看到权限范围内的数据。

---

## 主要功能

| 功能 | 作用 |
|------|------|
| 视图切换 | 在不同业务视图之间切换，快速进入“全部记录”“最近记录”“收藏记录”或管理员配置的专题视图 |
| 搜索与筛选 | 按关键词、字段条件、表头条件缩小数据范围 |
| 排序 | 按日期、名称、状态、编号等字段调整记录显示顺序 |
| 显示模式 | 在表格视图、分组视图、树形视图等模式间查看数据，适配不同对象结构和阅读方式 |
| 自定义显示列 | 调整当前列表显示哪些字段，以及字段列的排列顺序 |
| 拖动列宽 | 调整单列宽度，便于阅读长文本、编号、对象引用等内容 |
| 冻结列 | 横向滚动时固定关键列，方便在宽表中对照记录名称或编号 |
| 行高切换 | 在固定行高和自动行高之间切换，平衡单屏记录数量和字段可读性 |
| 行内查看与编辑 | 在权限允许时，直接在列表中查看或修改字段值 |
| 记录选择 | 勾选一条或多条记录，为批量操作、导出等动作确定处理范围 |
| 暂存箱 | 将不同视图中选中的记录临时收集到同一处理范围，再发起批量操作 |
| 表头动作 | 对已勾选记录发起批量修改状态、批量发起工作流、批量编辑字段等操作 |
| 操作列 | 在单条记录所在行直接执行查看、编辑、删除或其他快捷动作 |
| 导入与导出 | 从列表入口导入记录，或把当前筛选结果导出为文件 |

具体能看到哪些功能，由当前对象、视图配置和用户权限决定。不同项目的视图名称、字段和操作可能不一样。

## 进入对象列表视图
1. 登录 Gaia 平台。
2. 在顶部导航或应用菜单中打开目标对象，例如“偏差”“供应商”“产品”。
3. 页面打开后，系统显示该对象的默认列表视图。
4. 如需切换数据范围，点击视图名称或视图切换入口，选择其他视图。

对象菜单通常会提供三个标准视图：

### 所有的

“所有的\{对象\}”显示当前用户有权查看的对象记录。这里的“所有”不是系统中的全部数据，而是当前对象、组织或业务范围内对用户可见的数据。

例如，对象为“偏差”时，视图名称通常显示为“所有的偏差”；对象为“供应商”时，视图名称通常显示为“所有的供应商”。

可以在这些场景使用：
- 需要从完整可见范围中查找某条记录。
- 不确定记录属于哪个状态、负责人或分类，需要先扩大查询范围。
- 需要重新开始查询，避免被其他业务视图的预设条件限制。

进入该视图后，再用搜索、筛选、表头筛选和排序缩小范围。若仍找不到记录，先检查关键词和筛选条件，再确认记录权限或组织范围。

### 最近的

“最近的\{对象\}”显示当前用户最近访问或编辑过的记录。用户不必重新搜索名称或编号，就能回到近期处理过的数据。

例如，用户上午打开过某条偏差记录，下午需要继续处理时，可以进入“最近的偏差”快速找到该记录。

可以在这些场景使用：
- 继续处理近期打开过的记录。
- 快速回到刚查看过但尚未收藏的记录。
- 在多个对象记录之间来回切换工作。

系统会根据用户的访问记录维护该视图。它只显示近期使用过、且当前仍有查看权限的记录。记录权限或可见范围变化后，记录可能不再出现在这里。

### 收藏夹

“收藏夹”集中显示当前用户主动收藏的记录。用户可以把经常查看、需要持续跟踪或短期重点处理的记录加入收藏夹，之后从这里快速打开。

收藏通常通过记录名称旁的收藏图标完成。收藏后，记录会出现在当前对象菜单的“收藏夹”视图中；再次点击收藏图标可取消收藏。

可以在这些场景使用：
- 跟踪长期关注的供应商、产品、偏差或变更记录。
- 暂存近期需要反复查看的记录。
- 把少量重点数据从大量记录中单独拎出来查看。

收藏只影响当前用户自己的快捷访问。它不会改变记录状态，也不会让其他用户看到同样的收藏结果。若用户失去某条记录的查看权限，即使之前收藏过，也可能无法继续在收藏夹中看到它。

管理员还可以配置业务视图，例如“待我审批”“本月新增”“进行中变更”。打开这些视图后，列表会按预设条件显示对应记录。

## 查询和定位记录

查找记录时，建议先选视图，再筛选和排序，最后打开记录详情。

### 选择合适的视图

先选一个接近当前任务的视图，可以少做很多筛选。

例如：
- 要检查所有可见记录，进入“所有的\{对象\}”。
- 要继续处理近期打开过的记录，进入“最近的\{对象\}”。
- 要跟踪固定记录，先收藏记录，再进入“收藏夹”。
- 要处理待办类数据，优先选择“待我处理”“待我审批”等业务视图。

### 搜索记录

在列表搜索框输入记录名称、编号或其他关键词后提交搜索，列表会显示匹配记录。

搜索适合已知关键词的场景。如果只知道状态、类型、日期范围等条件，建议使用筛选。

### 筛选记录

列表筛选按字段条件缩小结果范围。常见筛选字段包括状态、类型、负责人、部门、创建日期、生效日期等。

使用筛选时：
1. 在筛选区域选择字段。
2. 选择运算条件，例如等于、包含、大于、小于、在范围内。
3. 填写或选择筛选值。
4. 应用筛选后查看列表结果。

多个筛选条件会叠加生效。筛选后，列表只显示同时满足条件且当前用户有权查看的记录。

### 使用表头筛选

如果列头显示筛选入口，可以直接在该列设置条件。表头筛选适合临时缩小当前视图结果，例如只看某个状态、部门、负责人或日期范围内的数据。

表头筛选会和当前视图条件一起生效。若列表结果过少，先检查视图是否已有预设条件，再检查列头筛选是否还在生效。
1. 在列表中找到要筛选的字段列。
2. 点击列头中的筛选图标或筛选入口。
3. 按字段类型选择条件。例如文本字段可输入关键词，选项字段可勾选选项，日期字段可选择日期或范围。
4. 应用筛选后，列表只显示符合该列条件的记录。
5. 如需恢复完整结果，清除该列筛选或重置当前筛选条件。

不同字段类型的筛选方式不同：

| 字段类型 | 常见筛选方式 | 结果 |
|------------|------------------|------|
| 文本/编号 | 输入关键词或完整值 | 显示字段值匹配的记录 |
| 选项/状态 | 勾选一个或多个选项 | 显示属于所选选项的记录 |
| 日期/日期时间 | 选择具体日期或日期范围 | 显示落在指定时间范围内的记录 |
| 用户/部门/对象引用 | 选择目标用户、部门或对象记录 | 显示引用该值的记录 |
| 数字 | 输入数值或范围条件 | 显示符合数值条件的记录 |

表头筛选不会修改记录内容，也不会自动保存为新的业务视图。若一组条件需要反复使用，可以保存为个人视图，或请管理员配置业务视图。

### 使用表头排序

点击字段列头，可以按该列排序。排序只调整当前结果的显示顺序，方便先看最新、最早、优先级最高或名称最靠前的记录。

常见用法包括：
- 按创建时间或更新时间倒序，查看最新记录。
- 按名称或编号升序，查找固定编号段数据。
- 按状态排序，把同一状态的记录集中显示。
- 按到期日期排序，优先处理临近到期的记录。
1. 点击需要排序的字段列头。
2. 列表按该字段升序或降序排列。
3. 再次点击同一列头，通常会切换升序、降序或取消排序。
4. 如需换一个字段排序，点击新的字段列头。

排序不会修改记录内容。排序后的结果仍受当前视图、搜索、筛选和权限范围限制。
- 文本字段通常按字母、拼音或系统排序规则排列。
- 日期字段通常按时间先后排列。
- 数字字段按数值大小排列。
- 选项、状态、对象引用等字段的排序方式可能受系统配置或显示值影响。
- 部分字段可能不支持排序；如果列头没有排序入口或点击后无变化，表示该字段当前不可排序。

## 调整列表显示

列表显示设置只影响页面怎么展示，不改变对象记录本身。

### 列表偏好自动保存

用户在列表上的常用显示操作，系统通常会按用户自动保存。下次进入同一列表或同类业务页面时，页面会尽量沿用上次的显示偏好。

系统可能保存这些偏好：

| 操作 | 下次进入时的效果 |
|------|------------------------|
| 调整显示列 | 继续按上次选择的字段和列顺序展示 |
| 拖动列宽 | 继续使用上次调整后的列宽 |
| 切换固定行高/自动行高 | 继续使用上次选择的行高模式 |
| 冻结列/解冻列 | 继续保持上次的冻结或解冻状态 |
| 排序方式 | 继续按上次选择的字段和方向排序，具体以当前视图支持情况为准 |
| 分页方式或每页条数 | 继续使用上次选择的分页偏好，具体以页面配置为准 |
| 视图模式 | 对支持模式切换的列表，继续使用上次选择的表格、分组或树形显示方式 |

自动保存的是当前用户自己的列表偏好，不会影响其他用户。它也不会改变管理员配置的视图范围、字段权限、数据权限或对象动作权限。

如果列表显示与预期不一致，先看当前视图、筛选条件和个人显示偏好；必要时重新调整显示列、列宽、行高或排序方式。

### 自定义显示列

点击“编辑列”或“自定义显示列”后，可以选择列表要显示的字段，并调整列顺序。保存后，列表会按新的字段范围和顺序展示。
- 增加需要对照的业务字段，例如状态、负责人、到期日期。
- 隐藏当前任务不需要的字段，减少横向滚动。
- 把名称、编号、状态等关键字段放在靠前位置。
1. 在列表表头或列表工具区点击“编辑列”。
2. 在可选字段中勾选需要显示的字段。
3. 取消勾选暂时不需要显示的字段。
4. 拖动字段或使用排序控件调整列顺序。
5. 保存后返回列表查看结果。

自定义显示列不会删除字段，也不会修改记录数据。部分导出场景会把当前显示列作为导出字段范围，因此导出前要确认列表已经显示需要的字段。

### 拖动列宽

字段内容较长或列间距不合适时，可以拖动列头边界调整列宽。加宽后，长名称、长编号、对象引用、备注或日期时间等字段更容易看完整。
1. 将鼠标移动到字段列头右侧边界。
2. 当光标变为可拖动状态时，按住并左右拖动。
3. 向右拖动可加宽该列，向左拖动可缩窄该列。
4. 松开鼠标后，列表按新的列宽显示。

列宽缩窄后，单屏能显示更多字段。若内容仍然看不全，可以切换到自动行高，或减少显示列。

### 固定行高与自动行高

列表通常可以在固定行高和自动行高之间切换。

| 行高模式 | 页面效果 | 适用场景 |
|------------|------------|------------|
| 固定行高 | 每行高度一致，超长内容可能被截断或省略 | 快速浏览大量记录，保持列表紧凑 |
| 自动行高 | 行高按内容自动展开，长文本可显示更多内容 | 阅读备注、说明、长名称、多值字段等内容 |

固定行高更紧凑，适合快速扫描和批量勾选。自动行高会占用更多页面空间，但长字段更容易看完整。

切换行高不会修改字段值。页面过高或信息过密时，可以再切回另一种行高模式。

### 冻结列

字段较多、需要横向滚动时，可以用“冻结列”固定关键列。冻结后，横向滚动时该列会留在左侧，便于对照每行记录。

点击“解冻列”后，列表恢复普通横向滚动。
- 列表字段较多，需要横向滚动查看后面的字段。
- 需要始终看见记录名称、编号或主字段。
- 正在对照多条记录的状态、负责人、日期等字段。

冻结列只影响当前列表显示。若不再需要固定列，点击“解冻列”恢复普通显示。

### 列表显示模式

对象列表可能提供不同显示模式。显示模式只改变页面上的组织方式，不修改记录，也不改变用户的数据权限。

常见显示模式包括：

| 模式 | 适用场景 | 页面效果 |
|------|------------|------------|
| 表格视图 | 大多数对象记录查询、对照和批量处理 | 记录按行展示，字段按列展示，适合筛选、排序、编辑列、导出和批量操作 |
| 分组视图 | 需要按状态、部门、类型、负责人等字段查看数据分布 | 记录按分组字段聚合显示，用户可以展开或收起某个分组，集中查看同类记录 |
| 树形视图 | 对象本身存在上下级关系，例如组织、分类、目录、父子层级数据 | 记录按层级结构展示，用户可以展开父节点查看子节点，适合浏览层级关系 |

#### 表格视图

表格视图是最常用的列表模式。每条记录是一行，每个字段是一列。用户可以通过列头排序、表头筛选、编辑列、冻结列和勾选记录完成日常查询与处理。
- 需要快速查找记录并打开详情。
- 需要对照多列字段，例如状态、负责人、到期日期。
- 需要勾选多条记录后执行批量动作。
- 需要按当前显示列导出数据。

如果列表字段较多，可以先通过“编辑列”减少显示字段，再用“冻结列”固定名称或编号列。

#### 分组视图

分组视图按指定字段归类记录。例如按状态分组后，列表可能显示“草稿”“审批中”“已关闭”；按负责人分组后，列表会把各负责人名下的记录分开显示。

分组视图适合先看分布，再处理数据。用户可以展开要看的分组，也可以收起暂时不关心的分组。

分组不等于筛选。分组会保留当前结果集，只是改变排列方式；筛选会减少结果集。若只想查看某一类记录，应使用筛选条件，而不是只依赖收起其他分组。

#### 树形视图

树形视图按层级关系展示记录。展开父级记录后，子级记录或相关对象记录会显示在下方。

树形视图常见有两种展示效果：

| 类型 | 页面效果 | 适用场景 |
|------|------------|------------|
| 树形对象视图 | 对象记录本身存在父子层级，列表直接按对象自身层级展开 | 组织、部门、分类、目录、科目等对象 |
| 相关对象树形视图 | 主对象本身不是树形对象，但列表可在主对象下展开相关对象或子对象记录 | 查看主记录与明细记录、主对象与多个相关对象之间的关系 |

##### 树形对象视图

当对象本身是树形对象时，树形视图会按对象记录自身的父子关系展示数据。用户展开父级记录后，下级记录显示在其下方；继续展开下级记录，可以沿层级向下查看。
- 查看组织架构、部门层级或区域层级。
- 查看分类、目录、科目等父子结构。
- 需要先确认记录所在层级，再打开详情或执行操作。

展开或收起节点只影响当前页面显示，不会改变记录关系。若目标记录不在当前展开层级中，可以继续展开上级节点，或切换回表格视图后搜索。

##### 相关对象树形视图

对象本身不是树形对象时，列表也可能用树形形式展示相关对象数据。此时主对象记录显示在第一层，展开主对象后，与它关联的子对象或相关对象记录会显示在下方。

例如，主对象为“供应商”时，展开供应商记录后，列表可以显示该供应商下的联系人、资质、审计记录或其他相关对象记录；主对象为“变更”时，展开变更记录后，可以查看关联的任务、影响项或明细记录。

如果当前视图配置了多个相关对象，页面可能提供相关对象切换入口。用户可以在同一批主对象下切换查看不同关联数据。切换相关对象只改变展开区显示的内容，不改变主对象记录。

在相关对象树形视图中：
- 主对象记录用于确认当前业务主线。
- 展开的相关对象记录用于查看明细、子记录或关联数据。
- 点击主对象或相关对象名称，通常可进入对应记录详情页。
- 相关对象是否可见，取决于当前用户对相关对象的查看权限。

##### 树形模式下导出

如果当前树形视图提供列表导出入口，导出 Excel 时可以按视图配置带出相关对象数据。导出结果通常以主对象数据为基础，并把相关对象数据一并输出，便于在 Excel 中核对主记录和明细记录。

当前视图只选择一个相关对象时，导出结果通常包含该相关对象的数据。若视图支持切换或选择多个相关对象，导出 Excel 可能按“一个相关对象一个 Sheet”的方式输出。

导出范围仍受当前视图、筛选条件、显示列、导出配置和用户权限控制。若导出文件缺少某类相关对象数据，先确认当前树形视图是否已切换或选择该相关对象，再确认自己是否有相关对象的查看权限。

是否提供分组视图、树形视图、表格视图切换、相关对象切换和树形导出，取决于当前对象和视图配置。普通对象可能只提供表格视图；树形对象或已配置相关对象树形展示的视图，才会出现对应入口。

## 查看和处理记录

### 打开记录详情

在列表中点击记录名称或主字段，可以进入记录详情页。详情页用于查看完整字段、相关对象、附件、时间线、流程信息和活动历史。

返回列表后，系统通常会保留当前视图、筛选和分页上下文，便于继续查看下一条记录。

### 列表中的链接字段

列表中的 `name__ak` 字段通常是记录主名称。点击该字段值，可以跳转到当前对象记录的详情页。

对象引用字段也可以作为链接使用。点击引用对象字段中的记录名称，系统会打开被引用对象的详情页。例如，在偏差列表中点击“产品”字段里的产品名称，可以进入对应产品记录；点击“供应商”字段里的供应商名称，可以进入对应供应商记录。

链接是否可点击，取决于字段展示方式和用户权限。若用户没有被引用记录的查看权限，系统可能不显示链接，或点击后提示无权访问。

### 生命周期状态与活跃工作流

如果列表显示生命周期状态字段，用户可以在列表中直接看到记录当前所处状态，例如“草稿”“审批中”“已批准”“已关闭”等。

在已配置的场景下，生命周期状态字段还可以显示活跃工作流信息。记录存在正在运行的工作流时，状态字段可能同时展示当前流程、任务节点或处理状态，帮助用户判断记录是否正在审批、等待处理或已进入某个流程环节。

活跃工作流信息只反映当前记录的流程状态，不会改变记录内容。用户是否能查看完整流程信息，仍取决于工作流权限、记录权限和当前页面配置。需要查看完整审批路径、任务处理人或流程历史时，进入记录详情页查看工作流时间线或活动历史。

### 收藏记录

如果记录名称旁显示收藏图标，可以点击收藏。收藏后，该记录会出现在“收藏夹”视图中，便于后续快速访问。

再次点击收藏图标可取消收藏。收藏只影响当前用户的快捷访问，不会改变记录状态或其他用户的列表。

### 行内编辑

如果对象列表启用了行内编辑，且用户具备编辑权限，用户可以直接在列表单元格中修改字段值，不必先进入详情页或编辑页。

行内编辑是否可用，取决于以下条件：

| 条件 | 说明 |
|------|------|
| 对象或列表已启用行内编辑 | 未启用时，列表单元格只能查看，不能直接改值 |
| 当前用户有编辑权限 | 没有编辑权限时，字段不会进入可编辑状态 |
| 字段允许编辑 | 只读字段、系统字段、计算字段等通常不能行内编辑 |
| 记录状态允许编辑 | 如果记录被生命周期状态锁定、流程锁定或权限规则限制，字段可能不可编辑 |

行内编辑适合修正少量简单字段，例如负责人、日期、选项值等。对于会触发业务校验、状态变化或需要填写大量字段的修改，建议进入详情页或编辑页处理。

保存后，新值会写入对象记录，并按平台审计规则记录变更。若字段无法编辑，通常是当前列表未启用行内编辑、用户没有编辑权限、字段只读，或记录当前状态不允许修改。

### 操作列快捷动作

如果列表显示操作列，可以在单条记录行内执行快捷动作。常见动作包括查看、编辑、删除、发起流程、修改状态或打开更多操作菜单。

操作列动作只作用于当前行记录。动作是否显示和能否执行，取决于用户权限、记录状态和对象动作配置。

## 批量管理数据

对象列表可以通过勾选记录来确定批量处理范围。

### 选择记录

在列表左侧勾选目标记录。部分视图支持全选当前页，也可能支持按筛选结果选择更多记录，具体以页面显示为准。

执行批量动作前，先用视图和筛选缩小范围，再勾选记录。这样可以降低误处理风险。

### 使用暂存箱

暂存箱用于临时收集需要统一处理的对象记录。用户可以先在列表中选择记录并添加到暂存箱，再切换视图、搜索或筛选，继续添加其他记录。收集完成后，再从暂存箱发起批量操作。

能不能使用暂存箱，取决于当前对象和视图配置。若列表中没有“添加到暂存箱”“移除暂存箱”或暂存箱入口，表示当前对象、当前视图或当前用户权限下暂不提供该功能。

| 操作 | 结果 |
|------|------|
| 添加到暂存箱 | 将当前选中的记录加入暂存箱，供后续统一处理 |
| 从暂存箱移除 | 将记录从暂存箱中移除，不删除对象记录本身 |
| 查看暂存箱 | 打开暂存箱列表，查看已经收集的记录 |
| 清空暂存箱 | 移除暂存箱中的全部记录，便于重新选择处理范围 |
| 从暂存箱发起批量操作 | 对暂存箱中的记录执行批量编辑字段、批量修改状态、批量发起工作流等动作 |

暂存箱可以跨视图使用。例如，用户可以先在“所有的\{对象\}”中添加一批记录，再切换到“待我处理”或其他业务视图继续添加。暂存箱会保留已加入的记录，直到用户移除、清空，或系统按规则清理。
- 暂存箱只保存处理范围，不会修改记录内容。
- 加入暂存箱的记录仍受权限和状态控制；发起批量操作时，不满足条件的记录可能执行失败。
- 跨视图添加记录前，建议确认这些记录属于同一业务处理场景，避免把不应一起处理的数据放到同一批次。
- 如果记录已从当前用户可见范围移出，暂存箱中可能无法继续查看或处理该记录。

### 执行表头动作

表头动作位于列表上方或右上方，用于处理已勾选记录。

| 动作 | 结果 |
|------|------|
| 编辑字段 | 将所选记录的指定字段批量更新为新值 |
| 修改状态 | 将满足条件的记录批量迁移到目标状态 |
| 批量发起工作流 | 为所选记录发起同一审批或处理流程 |
| 创建相关对象 | 基于所选记录批量创建关联数据 |
| 导出权限报告 | 生成所选记录的权限明细文件 |

点击动作后，系统可能要求填写参数或确认操作。提交后，满足条件的记录会执行成功；不满足权限、状态或校验条件的记录会返回失败提示。

### 导入和导出

列表视图也可以作为数据导入、导出的入口。
- 导入用于从模板或文件批量创建、更新对象记录。
- 导出用于把当前筛选结果或选中记录输出为文件。

导入会改变系统数据，提交前要确认文件内容和字段映射。导出不会修改记录，但导出结果仍受当前筛选、显示列和权限范围控制。

## 权限与数据范围

对象列表视图遵循平台权限控制：
- 用户只能看到自己有权限查看的对象记录。
- 字段不可见时，该字段不会在列表中显示，也不会在导出结果中越权出现。
- 操作按钮只在用户具备对应动作权限、且记录满足执行条件时显示或可用。
- 生命周期状态、记录锁定、组织隔离和业务单元隔离都可能影响可见范围和可操作范围。

如果同事能看到某条记录而您看不到，通常是视图、筛选条件、角色权限或组织范围不同。

## 使用建议

| 场景 | 建议 |
|------|------|
| 找不到记录 | 先切换到“所有的\{对象\}”，再清除搜索、筛选和表头筛选 |
| 需要处理待办数据 | 优先使用“待我处理”“待我审批”等业务视图 |
| 列太多看不清 | 使用“编辑列”保留关键字段，并把关键字段放到前几列 |
| 横向滚动时无法对照记录 | 使用“冻结列”固定名称或编号列 |
| 批量修改前不确定范围 | 先筛选，再勾选，最后核对选中数量和动作参数 |
| 行内编辑入口不可见 | 检查当前对象或列表是否启用行内编辑，以及自己是否具备编辑权限 |
| 行内编辑失败 | 检查字段是否只读、记录状态是否允许编辑、字段校验是否通过 |
| 导出字段缺失 | 先确认当前列表显示列是否包含目标字段 |
| 视图与其他项目不同 | 列表视图按项目和对象配置，名称、字段和动作不同属于正常情况 |

## 常见问题

### Q：为什么我看不到某个列表视图？

A：列表视图的可见性受配置和权限控制。先确认是否进入了正确对象菜单；如果仍看不到，联系管理员检查视图是否启用、是否对当前角色可见。

### Q：为什么筛选后没有数据？

A：可能是当前视图已有预设条件，又叠加了搜索、字段筛选或表头筛选。可以先清除临时筛选，或切换到“所有的\{对象\}”后重新查询。

### Q：为什么列表中的字段和同事不一样？

A：不同用户可能使用了不同视图，也可能保存过不同的列显示偏好。权限不同也会影响字段是否可见。

### Q：为什么看到了操作按钮，但执行失败？

A：动作显示不代表所有记录都满足执行条件。常见原因包括记录状态不允许操作、部分记录缺少权限、字段校验未通过，或流程参数不完整。

### Q：列表设置会影响其他用户吗？

A：不会。列宽、列顺序、行高、冻结列、排序、分页、视图模式等偏好通常按个人保存，只影响本人下次进入列表时的显示效果。管理员配置的视图规则、权限和对象动作仍会影响被授权使用该视图的用户。
