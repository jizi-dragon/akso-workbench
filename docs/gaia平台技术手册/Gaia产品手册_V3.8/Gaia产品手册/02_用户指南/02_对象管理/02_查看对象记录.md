# 查看对象记录
> 本文介绍如何在 Gaia 平台中定位并查看对象记录，包括列表页、详情页、相关对象和导出操作。   

---

## 一、适用范围与权限
- 列表页只显示当前用户有权限查看的记录。
- 是否可见由对象权限与记录级权限共同决定。
- 同一对象在不同项目中可能采用不同列表视图与详情布局，最终以当前环境配置为准。

---

## 二、在列表页定位记录

建议按“视图 -\> 筛选 -\> 排序 -\> 分页”顺序定位目标记录。

### 2.1 视图切换

常见视图包括：
- 全部记录：查看当前可见范围内的全部记录。
- 最近查看：快速回到最近打开的记录。
- 收藏记录：仅查看已收藏记录。

系统会记住用户上次使用的视图和部分列表偏好，下次进入时自动沿用。

### 2.2 列表筛选与排序
- 可通过左侧筛选器或表头筛选缩小结果范围。
- 可通过表头升降序查看最新记录、名称顺序或关键字段排序结果。

### 2.3 列表动作与个性化

列表动作通常用于提升浏览效率：
- 编辑列：选择要显示的字段并调整顺序。
- 文本换行 / 截断：控制列表单元格中较长文本的显示方式。开启换行后，长文本在单元格内折行完整展示，便于阅读；切换为截断后，长文本单行显示并以省略号收尾，同一屏可展示更多行，适合快速扫读。可按当前浏览需要在二者间切换。
- 冻结列：横向滚动时固定关键列。

说明：编辑列会影响列表导出时包含的字段范围。

### 2.4 分页与数据范围
- 默认分页显示记录。
- 单页条数、最大可浏览范围受系统配置约束。
- 大数据量场景下建议先筛选再翻页，避免低效遍历。

---

## 三、查看记录详情

在列表页点击记录名称即可进入详情。

### 3.1 详情页核心区域

| 区域 | 用途 |
|------|------|
| 标题区 | 显示记录名称、编号、当前状态 |
| 操作区 | 执行编辑、删除、发起流程等动作（按权限显示） |
| 字段区 | 查看对象字段值与业务信息 |
| 相关列表区 | 查看与当前记录关联的对象数据 |
| 时间线/活动历史 | 查看流程节点、状态变化与操作轨迹 |

### 3.2 生命周期与时间线
- 生命周期用于标识记录当前所处业务阶段。
- 时间线用于追踪流程推进、任务处理和关键事件。
- 活动历史用于核对“谁在何时做了什么变更”。

### 3.3 详情页区块类型（按配置）

以下区块可在对象详情页中按配置显示，不同对象实际显示项可能不同：

| 区块类型 | 说明 |
|------------|------|
| 详情 | 显示当前记录的基础字段和业务字段信息 |
| 相关对象 | 显示与当前记录关联的对象列表 |
| 附件 | 查看与管理当前记录的附件内容 |
| 工作流时间线 | 查看流程节点、审批进度与任务流转 |
| 查询列表 | 展示与当前记录相关的查询结果列表 |
| 报表 | 在详情页内查看关联报表结果 |
| 审批矩阵 | 查看当前记录对应的审批路径或审批规则 |
| 帮助 | 展示当前对象或当前页面的使用说明 |
| 流程图 | 展示流程结构与节点关系 |
| 评论 | 查看和新增评论沟通记录 |
| 重复识别发起记录 | 查看重复识别任务的发起记录 |
| 重复识别结果 | 查看重复识别命中结果与处理状态 |
| 仪表板 | 查看与当前业务相关的数据看板组件 |
| 相关对象（支持行内编辑） | 在相关对象列表中直接行内新增/修改记录（以权限与配置为准） |

### 3.4 全部展开 / 全部折叠

当详情页包含多个可折叠部分时，可在页面头部操作区使用 **全部展开** 或 **全部折叠**，一次控制当前页全部可折叠部分，避免逐个点击。

| 操作 | 说明 |
|------|------|
| 全部展开 | 展开当前页中用户有权查看、且按布局规则可见的可折叠部分 |
| 全部折叠 | 折叠当前页中全部可折叠部分 |

适用范围：
- 对象记录的查看、编辑、创建页详情布局
- 审批等场景中打开的记录详情审阅页
- 支持折叠的部分类型（如详情部分、相关对象部分、帮助部分等）；页面容器本身不作为展开/折叠单元

说明：
- 单个部分仍可单独展开或折叠。
- 被布局规则隐藏、或当前用户无权查看的部分，不会因「全部展开」而显示。
- 展开/折叠状态在同一会话内刷新或再次进入时，会保持用户最近一次操作结果（以系统实际行为为准）。

## 四、查看相关对象
- 可在详情页的相关列表中查看子记录或关联记录。
- 若对象已配置相关操作，可直接从相关列表新建关联记录。
- 相关列表同样支持筛选、排序、列调整、批量处理和导入等操作（以配置结果为准）。

### 4.1 相关对象列表筛选与排序

相关对象列表支持表头筛选和排序。

若列头显示筛选入口，可按状态、负责人、日期、类型、编号等字段筛选当前相关对象记录。筛选只作用于当前相关对象列表，不影响主对象列表。

若列头支持排序，点击列头后，相关对象记录会按该字段升序或降序排列。排序只改变显示顺序，不修改记录数据。

如筛选或排序后结果不符合预期，可先清除相关对象列表的筛选条件，再检查相关对象记录权限。

### 4.2 相关对象批量操作与导入

相关对象列表的批量能力由当前对象、相关列表视图和用户权限共同决定。若相关对象列表左侧出现复选框，并且表头右侧显示批量操作按钮，表示当前相关列表已支持从表头发起批量操作。

使用时，先勾选要处理的相关对象记录，再点击表头右侧的目标动作。可用动作以页面实际显示为准，常见动作包括批量修改字段、修改状态、发起工作流等。提交后，系统只处理当前已选的相关对象记录，不会影响主对象记录或未勾选的相关对象记录。

若相关对象列表没有复选框，或勾选记录后表头右侧没有批量操作按钮，通常表示该相关列表未配置表头动作、当前用户没有对应权限，或该动作不适用于当前视图。

相关对象列表也可以按配置显示“数据导入”入口。出现该入口时，用户可从当前相关列表发起导入，按模板上传 Excel 文件并批量创建相关对象记录；导入后的关联写入结果取决于相关对象配置、关系字段设置和用户的创建/关系写入权限。

---

## 五、导出与后续操作
- 可在列表页勾选记录后导出当前结果集。
- 导出范围受当前筛选条件、显示列与权限控制影响。
- 在详情页可继续执行编辑、流程处理、关联查看等后续操作。
