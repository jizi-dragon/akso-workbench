# 使用网格视图
> 本文介绍如何使用电子表格式网格视图。   

---

## 切换到网格视图
1. 进入对象列表
2. 点击视图切换按钮
3. 选择 **网格视图**

---

## 网格视图功能

| 功能 | 说明 |
|------|------|
| 内联编辑 | 双击单元格编辑 |
| 批量编辑 | 选中多单元格修改 |
| 列调整 | 拖拽调整列宽 |
| 排序 | 点击列标题排序 |

---

## 快捷操作

| 快捷键 | 操作 |
|---------|------|
| Enter | 保存并移到下一行 |
| Tab | 移到下一列 |
| Esc | 取消编辑 |
