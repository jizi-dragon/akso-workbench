# 修改个人信息
> 本文用于指导您在 **个人中心** 修改个人资料与个性化设置。   

---

## 功能说明

在“修改个人信息”页面，您可以完成以下操作：
- 维护基础资料：姓名、手机号、邮箱
- 维护个性化设置：手写签名、语言、时区、头像

---

## 访问入口
1. 点击页面右上角头像。
2. 进入 **个人中心**。
3. 在左侧导航中选择：
- **基本信息**：维护姓名、手机号等基础资料。
- **个性设置**：维护签名、语言、时区、头像等个性化项。

---

## 字段说明

| 分类 | 字段/控件 | 是否可编辑 | 说明 |
|------|-------------|---------------|------|
| 基本信息 | 姓名（\*） | 是 | 必填项，用于系统显示用户姓名。 |
| 基本信息 | 工号 | 是 | 用户工号信息。 |
| 基本信息 | 电话号码 | 是 | 用户联系方式。 |
| 基本信息 | 用户名 | 否 | 系统账号标识，页面中只读展示。 |
| 基本信息 | 是否启用数字签名 | 否 | 展示当前数字签名启用状态。 |
| 个性设置 | 手写签名（修改签名） | 是 | 点击 **修改签名** 更新签名图样。 |
| 个性设置 | 语言 | 是 | 选择界面显示语言。 |
| 个性设置 | 时区 | 是 | 选择时间显示所使用的时区。 |
| 个性设置 | 头像（更换头像） | 是 | 点击 **更换头像** 上传新的个人头像。 |

---

## 操作步骤

### 修改基础资料
1. 在左侧点击 **基本信息**。
2. 按需修改 **姓名（必填）**、**工号**、**电话号码**。
3. 点击右上角 **保存**。

### 修改个性设置
1. 在左侧点击 **个性设置**。
2. 按需完成以下操作：
- 点击 **修改签名**，更新手写签名。
- 在 **语言** 下拉框中选择目标语言。
- 在 **时区** 下拉框中选择目标时区。
- 点击 **更换头像**，上传新的头像图片。
3. 点击右上角 **保存**。

### 放弃修改
1. 在未保存状态下点击右上角 **取消**。
2. 当前未保存的修改将不生效。

---

## 修改后如何确认
- 保存成功后，页面会保留最新值。
- 建议刷新页面或重新进入“个人中心”确认信息是否已更新。
- 若您修改了语言或时区，部分显示内容可能在页面刷新后完全生效。

---

## 常见问题

### 1\. 点击保存后没有更新怎么办？
- 先确认必填项 **姓名** 已填写。
- 检查手机号格式是否符合组织要求。
- 刷新页面后再次查看；若仍未生效，请联系管理员排查权限或数据校验规则。

### 2\. 为什么“用户名”“是否启用数字签名”不能编辑？

这两个字段为系统管理字段，仅用于查看，不能在个人中心直接修改。

### 3\. 看不到“修改签名”或“更换头像”按钮怎么办？

请确认当前账号是否具备个人资料维护权限；如无权限，请联系系统管理员。
