# 保存视图
> 本文介绍如何保存和管理自定义搜索视图。   

---

## 创建视图
1. 在列表页配置筛选条件
2. 调整排序和列显示
3. 点击 **另存为**
4. 输入视图名称、描述、图标
5. 点击 **保存**

---

## 视图属性

| 属性 | 说明 |
|------|------|
| **名称** | 视图显示名称 |
| **筛选条件** | 保存的筛选规则 |
| **排序** | 保存的排序规则 |
| **列配置** | 显示的列和顺序 |

---

## 管理视图

保存视图后，可通过 **视图管理** 对视图顺序和自建视图信息进行维护。

### 打开视图管理
1. 点击视图下拉菜单
2. 点击 **视图管理**

### 切换视图
1. 点击视图下拉菜单
2. 选择目标视图

### 视图排序
1. 在 **视图管理** 中按住左侧拖拽手柄
2. 将视图拖动到目标位置
3. 点击右下角 **确定** 保存排序结果

### 编辑自建视图
1. 进入 **视图管理**
2. 在自建视图行修改图标、名称或描述
3. 点击该行的 **保存**
4. 点击右下角 **确定** 完成提交

### 删除自建视图
1. 点击视图管理
2. 选择要删除的自建视图
3. 点击 **删除**

### 恢复默认顺序
1. 进入 **视图管理**
2. 点击右上角 **恢复默认设置**
3. 点击右下角 **确定**

### 使用限制
- 系统内置视图仅可查看和排序，不支持编辑或删除
- 仅自建视图支持编辑、删除

---

## 视图共享

| 类型 | 说明 |
|------|------|
| **私有** | 仅自己可见 |
| **共享** | 团队成员可见 |
