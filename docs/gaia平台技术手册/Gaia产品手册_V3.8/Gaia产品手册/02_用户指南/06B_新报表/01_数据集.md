> 本文介绍平台新报表模块的数据集能力。数据集与分析图表、仪表盘共同构成新报表三件套，使用顺序为：数据集 → 分析图表 → 仪表盘。注意：本文的「数据集」与[数据迁移](../../03_%E7%AE%A1%E7%90%86%E5%91%98%E6%8C%87%E5%8D%97/18_%E6%95%B0%E6%8D%AE%E8%BF%81%E7%A7%BB.md)中数据包的「数据集」同名不同义——后者指一组待迁移的对象数据配置。   

## 数据集入门

### 简介

数据集模块的核心功能是数据处理与转换。无需编写代码，只需在画布上拖拽预置的功能节点并进行配置，即可像搭建积木一样，构建一条从数据输入到结果输出的自动化处理流程。

**创建数据集**：点击「新建数据集」后，先填写名称、编码等基本信息并确认，再进入数据集编辑画布配置数据流。

### 数据集词汇表

| **名词** | **释义** |
|----------|----------|
| 数据源 | 即数据的来源，通过输入节点进入数据流。相当于生产过程的原材料。 |
| 节点 | 构成数据流的基本功能单元，每个节点执行一项特定的数据处理任务（如筛选、连接、计算）。 |
| 数据流 | 由多个节点按业务逻辑连接而成的数据处理流程，代表完整的数据加工链路。 |
| 输出表 | 数据流终点节点（即“输出节点”）产出的最终结果数据表。只有输出表的数据可被下游使用。 |
| 字段 | 数据表中的列，代表一个具体的数据属性（如“批号”、“检验值”）。 |

### 基础功能认识

（1）数据源

数据处理的原材料来源。数据源特指在对象配置中开启了「用于 QRS 数据源」开关的业务对象（开关配置见[对象配置](../../04_%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97/01_%E5%AF%B9%E8%B1%A1%E9%85%8D%E7%BD%AE.md)）；应用侧可在此基础上提供数据归集模块（如 QRS 的「数据中心」）。

（2）数据流

数据处理的过程本身。它由您在画布上通过连线将各个节点连接而成，直观展示了数据从原始状态到最终结果的“流动”路径。

（3）输出表

输出表就是经数据流计算得出的结果表。它是一张虚拟的数据表，其结构和内容由“输出节点”定义。

## 数据流节点详解

（1）功能简介

目前共有 9 种节点，分别是：
- 输入节点
- 输出节点
- 数据筛选
- 横向连接
- 分组汇总
- 数据去重
- 字段设置
- 行转列
- 数据排序

（2）应用场景

目前的节点可以分为 2 大类。

1）输入/输出节点
- 输入：用来选择要处理的数据，即数据的来源；
- 输出：数据流的出口，也就是数据计算的结果，最终输出为数据流输出表。

2）数据处理节点
- 包括数据筛选、横向连接、分组汇总、数据去重、字段设置、行转列、数据排序这 7 种节点；
- 每种节点的具体用法会在本章节详细叙述。

（3）设置节点
- 添加入口

创建数据流后，在数据流的左侧面板中选择数据流节点进行数据流设计。
- 添加/删除

拖拽即可添加节点；选中节点后，点击「删除」按钮或者使用键盘上的「Delete键」均可删除节点。

删除后，与该节点左右相连接的节点均断除连接关系。
- 添加连接线

为节点之间添加连接线。只有添加了连接线，数据才会按照连接线构建连接关系，按连接规则进行数据计算于处理。
- 节点重命名

为节点重命名，更好区分数据处理节点。
- 数据预览

数据预览可以用来查看处理后的数据，可以辅助判断数据是否正确合理以及是否满足业务需求。

（1）功能简介

（2）设置步骤

- 添加筛选条件

点击「编辑筛选条件」，选择字段：如“名称”，选择运算符：如“等于”，设置值：如“TEST000000007”。设置筛选条件：
- 添加多个条件

可点击“并且”或“或者”添加多组条件，构成复杂筛选逻辑。
- 删除条件

可点击「删除条件」，移除不合适的筛选条件。

（3）注意事项
- 一个数据筛选节点支持添加多个筛选条件，支持设置筛选条件之间的关系（并集或交集）。

### 横向连接

（1）功能简介

横向连接就是将两个不同数据源（或同一数据源的不同流程分支）的数据，根据关键字段进行横向合并，形成一张更宽的表格。横向连接目前支持以下 3 种连接方式：

左连接：保留主表全部数据，子表匹配上的则合并，匹配不上的则留空。

内连接：只保留两表能完全匹配上的数据。

全连接：会生成两个表数据的完整集合，匹配成功的记录合并为一行，任何一侧缺少匹配的记录也会单独保留，缺失部分补空。

（2）设置步骤
- 设置入口

拖拽“横向连接”节点至画布。它有两个输入端口，需连接两个上游节点。
- 选择连接类型

连接方式目前支持全连接、内连接和左连接。横向连接时，是根据关联字段进行匹配的，连接字段相同的数据根据连接方式进行左右拼接。
- 左右表单如何区分

方法一：先连向「横向连接」节点的表单为左侧表单，后连向「横向连接」节点的表单为右侧表单。

方法二：连接以后，在关联字段配置处也可以看到左右两侧的表单分别是哪一张：
- 设置连接规则

点击连接节点，在配置面板设置两表之间的关联字段。
- 设置显示字段

（3）注意事项

连接后字段名可能重复，需进行重命名区分。

### 分组汇总

（1）功能简介

分组汇总就是将所有数据先按照组来进行分类，然后对组内的数据进行汇总计算。

（2）设置步骤
- 添加分组汇总

从左侧拖拽“分组汇总”节点至画布，然后将上游节点连接至“分组汇总”节点。
- 设置分组字段

分组字段就是根据表单中哪个字段的数据进行分类，分类时会将同类数据归为一组。一个分组汇总节点支持添加多个分组字段，添加的分组字段支持排序、删除以及重命名。
- 设置汇总字段

汇总字段就是根据哪个字段进行汇总计算。一个分组汇总节点支持添加多个汇总字段，添加的汇总字段支持排序、删除、重命名以及汇总方式设置。

（3）注意事项
- 分组后，非分组字段且未参与汇总的字段将被自动剔除。
- **多选字段作为分组维度**：分组汇总节点支持选择多选字段，结果按各选项值分别展开为多行；统计口径为「按记录计数」。支持多个分组字段，但**最多 1 个**为多选类型。

### 数据去重

（1）功能简介

数据去重节点可以对数据表中的重复数据进行删除，仅保留一条数据参与数据计算。

（2）设置步骤
- 添加数据去重

从左侧拖拽“数据去重”节点至画布，然后将上游节点连接至“数据去重”节点。
- 设置去重字段

添加去重字段，去重字段即去重的依据，支持添加多个去重字段。多个去重字段的关系为「且」，即必须同时满足多个字段完全重复方进行去重处理。

（3）注意事项
- 去重节点随机保留一条数据参与计算。

### 字段设置

（1）功能简介

对字段进行显示和隐藏、排序、重命名、添加新的计算字段等操作。

（2）设置步骤
- 设置入口

从左侧拖拽“字段设置”节点至画布，然后将上游节点连接至“字段设置”节点。
- 管理现有字段

在字段列表中，可进行隐藏、拖动排序、重命名操作。不勾选字段，即可隐藏该字段；通过拖拽字段输入框右侧图标可以给字段进行排序；点击字段的输入框，即可修改字段名称。
- 新增公式字段

字段设置节点支持添加公式字段。

公式字段的公式目前支持时间函数、数学函数、逻辑函数、文本函数、转换函数、数学运算符、逻辑运算符、文本运算符。

公式计算的数据输出类型需要手动选择，默认文本类型。

常用函数（数据集公式字段）：

| 分类 | 函数 | 说明 | 示例 |
|------|------|------|------|
| 转换 | `Text(值)` | 把数字等转为文本，便于拼接或作为文本维度 | `Text(批次数量)` → `"120"` |
| 时间颗粒度 | `Year(日期)` | 取年份 | `Year(检验日期)` → `2026` |
| 时间颗粒度 | `Quarter(日期)` | 取季度（1～4） | `Quarter(检验日期)` → `3` |
| 时间颗粒度 | `Month(日期)` | 取月份 | `Month(检验日期)` → `8` |
| 时间颗粒度 | `Week(日期)` | 取周 | `Week(检验日期)` |
| 时间颗粒度 | `Day(日期)` | 取日 | `Day(检验日期)` → `27` |

图表 X 轴的「时间颗粒度」是图表配置，在已启用的 6 类图上按年/季/月/周/天分桶。若要在数据流里先算出颗粒度字段再给多张图复用，请用上表时间函数，不要和图表配置项混用。对象公式函数全集见 Gaia [公式配置](../../../Gaia%E4%BA%A7%E5%93%81%E6%89%8B%E5%86%8C/04_%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97/06_%E5%85%AC%E5%BC%8F%E9%85%8D%E7%BD%AE.md)；`Quarter()`、`Week()` 以数据集公式编辑器实际列表为准。

（3）注意事项
- 公式计算的结果需要与设置的输出类型一致。
- 添加公式计算的字段时，还会对公式合规性进行校验，不符合要求的公式将不能保存。

### 行转列

（1）功能简介

行转列可将一维表转成二维表：

一维表也常称为流水线表格。一般有固定的列名，平常输入数据只需要一行一行的添加即可。

二维表格是一种关系型表格，通常数据区域的值需要通过行列同时确定。更符合我们日常的阅读习惯，信息更浓缩，适合展示分析结果。

（2）设置步骤
- 添加行转列

拖拽“行转列”节点至画布。
- 配置转换规则

| **配置项** | **含义** |
|-------------|----------|
| 行转列字段 | 行转列后的行表头。只能设置 1 个。支持字段：文本类、数字类 |
| 新列的值 | 分类汇总后的值。只能设置 1 个。汇总方式支持：\*   数字类型：求和、平均、最大值、最小值、方差、标准差、中位数、首行、末行    \*   非数字类型（文本、时间、对象等）：计数、去重计数、首行、末行 |
| 新生成的列 | 把“新列的值”汇总结果，按你指定的名称一次性展示出来。必须设置 |

点击「数据预览」可以查看行转列后的数据效果。

### 数据排序

（1）功能简介

数据排序节点用于为上游数据流**显式指定排序规则**，使输出顺序确定、可重复，适用于「取最新 N 条」「按时间趋势分析」「取最近 N 批次」等场景。节点不改变字段结构；未启用数据截断时，行数与上游一致。

（2）设置步骤
- 添加数据排序

从左侧拖拽「数据排序」节点至画布，将上游节点连接至该节点。
- 配置排序规则

至少配置 **1 个**排序字段，字段来源于上游节点输出字段。可配置多个排序字段，并拖拽调整优先级：按配置顺序依次比较，前一字段值相同时再比较下一字段。

每个排序字段须指定排序方向：**升序**（默认）或  **降序**。
- 配置数据截断（可选，默认关闭）

在排序结果基础上，从**排序结果顶部**截取前  **N**  行记录（N 为正整数）。适用于 Top N、最新 N 条等场景。

须先配置排序规则后，方可启用数据截断；不允许仅启用截断而不配置排序。

（3）注意事项
- **支持排序的字段类型**：整数、浮点数、日期、日期时间。不支持的字段类型无法在配置中选择。
- **空值处理**：升序、降序排序时，空值均排在最后；若某字段全部为空，则保持其在上游数据流中的原始顺序。
- **排序稳定性**：排序键相同的记录，保持其在上游数据流中的原始顺序，便于多次运行结果一致。
- **保存校验**：保存数据集时，若未配置排序字段，系统将提示「数据排序节点未配置排序规则」；启用数据截断时，须已配置排序规则，且截断数量 N 须为正整数。

## 数据集启用与更新

数据集配置完成后，需要将其「启用」，其输出表才能被「分析图表」等下游模块引用（如 QRS 的「报告」）。保存时系统会校验流程结构、节点必填项及字段有效性；若配置不完整，页面会提示具体原因（如缺少输出节点、节点配置不完整、引用字段已失效等）。

### 启用数据集
- 检查与保存： 在数据流画布完成所有配置后，务必点击“保存”按钮。
- 启用操作： 测试无误后，在数据集列表页或详情页，找到并点击“启用”按钮。
- 生效状态： 启用后，数据集状态变为“已启用”。此时，其输出的数据表即可在“分析图表”模块的“数据源”下拉列表中被选中，也可被应用侧模块引用（如插入 QRS 的“报告模板”）。

### 更新数据集
- 手动更新：
    - 当源业务对象的数据有新增或变更时，需刷新数据集结果。
    - 进入已启用的数据集详情页，点击“手动刷新”按钮。
    - 系统将使用最新的源数据重新执行整个数据流，并更新输出表。
    - 引用此数据集的**分析图表**在数据集刷新后会使用最新结果。在 QRS 等应用的**报告**中，图表与数据以报告保存时的结果为准，不会随单个数据集刷新自动更新；需在报告详情页点击「更新数据」同步最新结果。
- 自动更新（调度）
    - 对于定期回顾（如月度），可以设置调度任务。
    - 在数据集配置中，寻找“调度设置”或“自动更新”选项。
    - 设置更新的频率（如每天凌晨1点）和条件。
    - 系统将按计划自动运行数据集，确保数据结果持续更新。

### 复制数据集

在数据集列表或详情页，选择「复制」。

系统基于原数据集创建副本，名称与编码自动追加后缀以便区分，可在副本上继续调整配置。
