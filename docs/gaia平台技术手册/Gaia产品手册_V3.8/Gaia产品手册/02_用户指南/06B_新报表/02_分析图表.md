> 本文介绍平台新报表模块的分析图表能力。说明：本对象在管理端配置中的名称为「QRS图表」（历史命名），实际为平台级通用分析图表对象，各应用模块均可使用。   

## 分析图表入门

分析图表是平台新报表模块的“可视化与统计工具库”。它将来自“数据集”的、已完成加工的结构化数据，转化为直观的统计图形，帮助您快速识别趋势、发现异常、进行比较，从而将数据转化为有价值的业务洞察。

### 简介

分析图表模块提供从基础到高级的一系列统计图形，用于数据的探索、监控和呈现。所有图表均动态绑定至数据集，当源数据更新后，图表可随之刷新。

### 相关名词

| **名词** | **释义** |
|----------|----------|
| 数据源 | 特指一个已 “启用” 的“数据集”及其“输出表”。这是图表的唯一数据来源。 |
| 图表类型 | 图表类型是用于可视化数据的不同方式和形式。不同的图表类型适用于不同类型的数据和分析目的。 |
| X轴 | 通常用于放置分类、时间或分组字段，作为图形的横轴或类别轴。 |
| Y轴 | 通常用于放置需要测量、统计或分析的数值型指标字段。 |
| 分组 | 用于在单一图表内通过颜色或样式区分不同数据系列。 |
| 时间颗粒度 | 当 X 轴为日期或日期时间字段时，把数据按年、季度、月、周、天分桶聚合的配置项。 |
| 统计方式 | 同一分组或同一时间桶内存在多条记录时的聚合口径，如求和、平均值、计数等。 |
| 子组 | 为分析过程波动而划分的一组观测值，是控制图与过程能力分析的基本单位。 |
| 子组大小 | 每个子组包含的观测值数量。在正态能力六合图中，该值决定控制图类型的自动选择。 |
| 规格上下限（USL/LSL） | 产品或质量特性的合格判定边界。区别于由过程数据计算得出的控制限（UCL/LCL）。 |

### 图表基础设置

图表创建流程：创建图表 → 填写基本信息 → 绑定已“启用”的数据集 → 选择图表类型 → 配置数据字段与显示属性 → 预览/保存图表。

**创建分析图表**：新建图表时，在左侧「基本信息」区域填写名称、编码等（新建时默认展开，编辑已有图表时默认折叠）。
- 图表名称设置

在“名称”输入框中，填写图表的名称。
- 图表code设置

在“Code”输入框中，填写图表的唯一编码。
- 绑定“启用”的数据集

在“数据集”下拉列表中，进行选择。
- 图表类型

在“图表类型”下拉列表中，选择所需的图表（如“趋势分析图”、“控制图”、“帕累托图”等）。
- 设置坐标轴

在统计表中可以自定义图表标题和坐标轴文字内容。
- 设置时间颗粒度

当维度（X轴）选择的是日期或日期时间类型字段时，配置区会出现「时间颗粒度」，可将数据按 **年、季度、月、周、天** 五档聚合展示；X轴为非日期字段时不显示该配置项。
- 默认为空，此时按原始时间戳展示。周按自然周处理，季度按自然季度处理。
- 选择颗粒度后，同一时间桶内可能包含多条记录，需要再指定「统计方式」。该配置项为条件展示，**仅在时间颗粒度有值时出现**：数值型字段可选求和、平均值、最大值、最小值、方差、标准差、中位数；非数值型字段可选计数、去重计数。
- 切换颗粒度立即生效，轴标签、Tooltip 与导出标题同步使用当前颗粒度格式，导出结果与当前颗粒度一致。
- 改选X轴字段后若不再是日期类型，已选颗粒度会被清空；数据聚合失败时保持原图并提示错误。

支持时间颗粒度的图表共 6 类：柱状图、条形图、折线图、散点图、帕累托图、饼图。趋势分析图、运行图、控制图、时间序列图、CPK分析图、正态分析图、离散度分析图、双样本T检验图，以及刻度盘、统计数字、正态能力六合图不支持该配置。
- 设置数据标签

数据标签是指在图表上直接显示数据值的标签或标记。管理员可以根据需求设置要展示的数据标签内容。
- 筛选条件

找到“筛选条件”区域，点击“\+”添加条件。选择要过滤的字段、运算符（如“等于”、“包含于”）并设定值。可添加多个条件，用“并且”、“或者”连接。对当前图表所使用的数据进行最后阶段的视图过滤，不影响数据集中的原始数据。
- 设置控制线

对于控制图、柱状图等统计图表，可在其专属设置区域配置各类参考线。
    - 控制限（UCL/LCL）：通常由系统自动计算，代表过程统计稳定的边界。
    - 规格限（USL/LSL）：需手动输入或关联应用侧的基础数据定义（如 QRS 的「基础数据」模块），代表产品合格的标准。
    - 警戒限：可设置在控制限内侧，提供早期预警。
    - 中心线（CL）：通常为均值线。
- 数据剔除

若发现个别数据点为显著异常值（如设备故障导致），可在图表附带的明细数据表中，勾选该点并点击 “剔除” ，同时记录剔除原因。此操作会将该点从当前图表的计算与显示中临时移除。
- 数据恢复

对于已被剔除的数据点，可以随时在明细数据表中选择 “恢复” ，使其重新参与图表的计算和显示。
- 预览图表

点击配置区顶部的 “预览” 按钮，预览区域将实时刷新，显示当前配置下的图表效果。
- 保存图表

在预览确认无误后，点击「保存」。保存成功后预览区自动刷新为最新效果，图表状态变为「开启」并出现在图表列表中。导出操作见「导出图表」一节。

### 视图尺寸

图表页面右侧提供「视图尺寸」切换，可在 **标准**（默认，适合日常查看）与  **增强**（图表更大，适合演示）之间选择。窗口较窄时图表保持设定大小，可在图表区域横向滚动查看。

### 导出图表

在图表预览或详情页，点击「下载」打开导出中心，支持：
- 导出图片（JPG）
- 导出数据（Excel）
- 导出图表\+数据（Excel：第一页为图表，第二页为数据）
- 导出图表\+数据（PDF：第一页图表，第二页数据）

### 复制分析图表

在分析图表列表或详情页选择「复制」，系统创建副本并自动命名，可在副本上继续修改配置。

## 图表详解与操作指南

以下内容详解 17 类图表的具体配置。操作前提是：已创建图表，并完成图表名称、Code、数据集等基础设置。

其中折线图、刻度盘、统计数字、正态能力六合图为 V3.8.0 新增。

### 帕累托图

（1）功能简介

帕累托图（Pareto chart）是将出现的质量问题和质量改进项目按照重要程度依次排列而采用的一种图表。以意大利经济学家 V.Pareto 的名字而命名的。帕累托图又叫排列图、主次图，是按照发生频率大小顺序绘制的直方图，表示有多少结果是由已确认类型或范畴的原因所造成。。

（2）设置步骤
- 图表类型：选择“帕累托图”
- 设置维度（X轴）：选择问题类别字段。应为文本型字段。
- 设置指标（Y轴）：选择发生频次或影响的数值字段。应为数值型字段。
- 设置合并处理：系统会将累计占比超过设定阈值（如95%）后的多个次要类别合并为“其他”项，使图表更清晰。
- 设置次级分组：可选第二个分类字段，用于分组对比（如按年份、班次对比同一 X 轴类别）。
- 分组展现形式：分组式（默认，各分组独立累积线）、堆叠式、百分比堆叠式。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。

（3）注意事项
- 通常要求“X轴”的类别为文本型字段，“Y轴”为数值型字段。

### 趋势分析图

（1）功能简介

以时间为横轴，观察变量为纵轴，用以反映时间与数量之间的关系。

（2）设置步骤
- 图表类型：选择“趋势分析图”。
- 设置维度（X轴）：选择时间或序列字段。
- 设置指标（Y轴）：选择要观察趋势的数值指标。
- 设置排序方式：选择“顺序”或“倒序”，默认按“顺序”排列。
- 设置拟合：可选择「显示」趋势拟合线，并选择拟合类型（如线性、二次等），用于辅助识别历史走势。
- 设置预测分析：可基于历史数据自动生成未来时段的预测曲线，用于提前识别可能超出管控范围的波动趋势。预测分析与拟合线用途不同：拟合线描述已有数据规律，预测分析面向未来时段的外推估算。

（3）注意事项
- 拟合线用于解读历史数据规律；预测分析用于展示未来趋势预估，二者可同时启用但含义不同。

### 运行图

（1）功能简介

运行图是显示任何测量特性随时间变化的图表。分析运行图的目的是为了确认所出现的波动模式是由普通因素引起的，还是由特殊因素引起的。

（2）设置步骤
- 图表类型：选择“运行图”。
- 设置指标（Y轴）：选择单个观测值字段。
- 设置子组分组方式：
    - 子组大小：定义每个子组包含的连续观测值数量（如每5个数据点为一组）。
    - 子组依据：也可按其他字段自然分组。
- 设置排序字段：选择决定数据点顺序的字段。
- 设置子组数据处理方式：选择“计算均值”或“计算中位数”来代表每个子组的位置。中位数对异常值更稳健。

### 控制图

（1）功能简介

用于统计过程控制（SPC），通过计算并绘制控制限（UCL/LCL），客观地判断生产过程是否处于稳定受控状态，并能及时预警异常波动。

（2）设置步骤
- 图表类型：选择“控制图”。
- 设置维度（X轴）：通常选择子组编号或时间字段。
- 设置指标（Y轴）：选择需要监控的数值。
- 设置排序字段：与X轴字段一致，确保数据顺序正确。
- 选择控制图类型：
    - 单值-移动极差图（I-MR）：适用于单件、长时间间隔取样或成本高的数据。
    - 均值-极差图（Xbar-R）：适用于子组大小较小（通常2-9）且稳定的过程，最常用。
- 设置控制线：这是控制图的核心设置，用于在图上绘制各类参考线。
    - 控制限（UCL/LCL）：通常由系统根据所选数据（如阶段1的稳定数据）自动计算得出，代表过程的自然波动范围。不得与规格限混淆。
    - 规格限（USL/LSL）：【可选】如果需要评估过程输出相对于客户要求的位置，可以手动输入或关联应用侧基础数据（如 QRS「基础数据」模块）中定义的规格上下限。
    - 警戒限：【可选】可在控制限内侧（例如±2σ处）设置警戒线，作为过程可能发生异常的早期提示。
    - 中心线（CL）：通常为过程数据的均值，由系统自动计算并绘制。
- 设置检验方式：用于让系统自动应用设置的规则，检测数据点中是否存在表明特殊原因变异的非随机模式。
    - 不进行检验（默认）：仅绘制图形，不提供模式违反的报警。
    - 仅执行选定的特殊原因检验：允许用户从多条检验规则中选择一部分启用。
    - 执行所有的特殊原因检验：启用全部预设的检验规则，提供最灵敏的异常检测，但也可能增加“误报警”的概率。
    - **超出控制限**：在「检验」页签中可单独启用。系统按当前图上的上、下控制限判断点位是否超限并高亮；不包含规格上下限的判断。

（3）注意事项
- 关注“受控”与“能力”：控制图主要解决过程是否“受控”（稳定）的问题。一个受控的过程仍需通过过程能力分析（如CPK分析图） 来评估其是否“有能力”满足规格要求。

### 时间序列图

（1）功能简介

时间序列图(Time Series Plot)又称时序图，其纵轴为时间序列变量的观测值，横轴均匀的时间刻度，时间序列图是在平面坐标上用折线表现数量变化特征和规律的统计图。

（2）设置步骤
- 图表类型：选择“时间序列图”。
- 设置维度（X轴）：选择具有固定周期的时间字段。
- 设置指标（Y轴）：选择观测指标。
- 设置分组依据：可放入一个分类字段，以对比不同组别的时间序列模式。
- 选择分组：若设置了分组依据，此处需确认要分析的具体分组。
- 设置排序方式：选择“顺序”或“倒序”，默认按“顺序”排列。

### CPK分析图

（1）功能简介

通过 CPK 分析根据正态分布评估过程的潜在（组内）能力和整合能力，通过评估达到 1、确定过程是否能够生成满足要求的输出；2、比较过程的整体能力和其潜在（组内）能力，以评估改善的机会。要执行分析，您必须指定规格下限、规格上限，以定义过程要求。此分析将相对于规格限评估过程数据的展开。当过程有能力时，过程展开小于规格展开。该分析也可以指示过程是否居中并达到目标值。

（2）设置步骤
- 图表类型：在图表类型下拉列表中，选择 “CPK分析图”。
- 设置指标：在“指标”或“Y轴”字段中，选择需要评估过程能力的数值型质量特性字段。
- 设置子组分组方式：
    - 子组大小：定义每个合理子组应包含的观测值数量（例如：连续生产的5个产品为一个子组）。正确的子组划分应能捕捉到短期内的过程变异。
    - 子组依据：如果数据本身已按特定逻辑分组（如“批次号”、“生产班次”），可在此字段选择对应的分组依据。
- 设置排序字段：选择用于确定数据分析顺序的字段，通常为与时间或生产顺序相关的字段，以确保过程能力的计算基于正确的时序。
- 设置排序方式：选择 “顺序” （默认）或 “倒序”，以反映真实的过程演变。
- 设置规格上限：输入该质量特性的规格上限（USL）。此数值必须准确，通常来源于该产品的质量标准，或应用侧基础数据模块中的定义（如 QRS「基础数据」中对关键质量属性 CQA 的定义）。
- 设置规格下限：输入该质量特性的规格下限（LSL）。同样，此数值需准确无误。
- 设置历史均值：【可选】如果该过程具有已知且可靠的历史均值（过程中心），可在此输入。若留空，系统将基于当前分析的数据计算样本均值。
- 设置历史标准差：【可选】如果该过程具有已知且可靠的历史过程标准差（代表过程波动），可在此输入。若留空，系统将基于当前子组内的变异进行估计。
- 设置目标值：【可选】输入该质量特性最理想的目标值。设置后，图表分析会同时考虑过程中心与目标值的偏离。
- 设置变换方式：如果数据严重偏离正态分布，可尝试进行数据变换以满足Cpk计算的前提假设。
    - 无变换：默认选项，假定数据服从或近似服从正态分布。
    - Box-Cox 幂变换：对偏态或不满足正态性的数据做变换后再计算 Cpk，提升过程能力评估准确性。启用前建议先用控制图确认过程受控。

（3）注意事项
- 前提条件：可靠的Cpk分析要求过程处于统计控制状态（建议先使用“控制图”进行验证）且数据近似服从正态分布。非正态数据或不稳定过程下的Cpk值可能产生误导。
- 规格限输入：规格上限（USL）和规格下限（LSL）是必填项，必须确保其准确无误，否则所有计算都将失去意义。
- 结果解读：Cpk值大于1.33通常表示过程能力充足；介于1.0至1.33之间表示能力尚可但需关注；小于1.0则表明过程能力不足，需进行改进。同时应关注过程均值与目标值的偏差。
- 与正态能力六合图的区别：CPK分析图聚焦能力指数本身；若还需同时确认过程是否稳定受控、数据是否服从正态分布，可改用正态能力六合图（见「正态能力六合图」一节），它把控制图、直方图、正态概率图与能力指数组合呈现。

### 正态分析图

（1）功能简介

又称正态概率图，用于检验一组数据是否服从正态分布。正态分布是一种由均值 (μ) 和标准差 (σ) 指定的连续分布。均值是钟形曲线的波峰或中心。标准差决定分布的散布情况。

（2）设置步骤

图表类型：选择“正态分析图”。

设置维度（X轴）：选择待检验的数值字段。

设置区间中的最小总体百分比：用于构建分布拟合带的置信水平（如95%），通常可保持默认。

（3）注意事项

若数据点近似落在一条直线上，则表明服从正态分布；明显偏离则表明非正态。

### 离散度分析图

（1）功能简介

直观展示一组数据的分布、离散程度和异常值。

（2）设置步骤
- 图表类型：选择“离散度分析图”。
- 设置指标（Y轴）：选择需要分析分布和离散度的数值字段。
- 选择显示图形：
    - 箱线图：显示中位数、上下四分位数、触须线和可能的异常值点。
    - 单值图：将所有数据点与组均值线一起显示，适合查看原始数据分布和密度。

（3）注意事项
- 箱线图对异常值的判定有统计标准（如1.5倍IQR），分析时应结合业务判断异常值的合理性。
- 箱体越短、触须越短，说明该组数据离散度越小，越稳定。

### 双样本T检验图

（1）功能简介

可使用双样本 t 检验来比较两个独立组是否存在差异。

（2）设置步骤
- 图表类型：选择“双样本T检验图”。
- 设置指标：选择要比较的数值指标。
- 设置样本、样本1、样本2：通过一个分组字段来定义两个独立的样本组（如“供应商”字段中的“A公司”和“B公司”）。
- 设置排序字段：通常非必需。
- 选择显示图形：可选箱线图（比较分布）、单值图（查看所有数据点分布）或趋势分析图（若数据有顺序）。
- 设置置信水平：通常设为95%。
- 设置假设差值：一般设为0，即检验“两组均值是否相等”。
- 设置备择假设：根据研究目的选择：“不等于”检验是否有差异；“大于”或“小于”检验是否一方显著优于另一方。
- 设置假定方差：选择“假定等方差”，系统会进行相应的检验。

（3）注意事项
- 结果中重点关注p值：p值小于显著性水平（如0.05）时，可认为两组均值存在显著差异。

### 条形图

（1）功能简介

使用水平条形的长度表示数值大小，适用于比较不同类别的数量。

（2）设置步骤
- 图表类型：选择“条形图”。
- 设置Y轴：在条形图中，此字段对应分类，条形将沿垂直轴排列。
- 设置X轴：选择数值字段，决定条形长度。
- 设置统计方式：对Y轴数值进行聚合（如最小值、最大值、求和、平均值、计数）。
- 设置次级分组：可添加第二个分类字段，形成簇状条形图，进行更细致的对比。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。

（3）注意事项
- 次级分组时，图形展示支持分组式、堆叠式、百分比堆叠式。

### 柱状图

（1）功能简介

使用垂直柱子的高度表示数值大小，是最基础、最常用的数据比较图表。

（2）设置步骤
- 图表类型：选择“柱状图”。
- 设置维度（X轴）：选择分类或时间字段，柱子将沿水平轴排列。
- 设置指标（Y轴）：选择数值字段。
- 设置统计方式：对Y轴数值进行聚合（如最小值、最大值、求和、平均值、计数）。
- 设置次级分组：可形成簇状柱状图或堆积柱状图。
- 设置控制线：柱状图支持配置高级控制线（与控制图同类能力），值类型默认为常量，用于在柱形图上标示规格限、目标线等。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。

（3）注意事项
- 次级分组时，图形展示支持分组式、堆叠式、百分比堆叠式。

### 饼图

（1）功能简介

以扇形区域大小表示每一个部分相对于总体的占比，用于显示整体中各部分的构成关系。

（2）设置步骤
- 图表类型：选择“饼图”。
- 设置维度（X轴）：选择作为构成部分的分类字段。
- 设置指标（Y轴）：选择决定各部分大小的数值字段。
- 设置统计方式：对Y轴数值进行聚合（如最小值、最大值、求和、平均值、计数）。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。

（3）注意事项

不适合比较差异细微的多个部分，人眼对角度和大小的判断不如对长度（条形/柱状）精确。

### 散点图

（1）功能简介

研究两个连续数值变量之间是否存在相关关系、分布模式或聚集趋势。每个点代表一个观测值，其位置由两个变量的值决定。

（2）设置步骤
- 图表类型：选择“散点图”。
- 设置维度（X轴）：选择第一个连续变量（自变量）。
- 设置指标（Y轴）：选择第二个连续变量（因变量）。
- 设置排序方式：选择“顺序”或“倒序”，默认按“顺序”排列。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。

（3）注意事项
- 可通过观察点的分布形态（线性、非线性、无规律）判断相关性。

### 折线图

（1）功能简介

以折线连接各数据点，展示指标随维度变化的趋势，并可在同一张图内按分组对比多条折线。与时间序列图的区别在于：时间序列图强调真实时间轴，折线图强调趋势展示。当X轴不是时间字段时，应选用折线图。

（2）设置步骤
- 图表类型：选择“折线图”。
- 设置维度（X轴）：选择横轴字段，支持分类、数值、日期类型。
- 设置指标（Y轴）：选择数值型字段。
- 设置统计方式：同一X值下存在多条记录时的聚合口径。数值型字段可选求和、平均值、最大值、最小值、方差、标准差、中位数；非数值型字段可选计数、去重计数。
- 设置次级分组：【可选】按分组字段把数据拆成多条折线对比，不同分组以不同颜色区分。
- 设置时间颗粒度：X轴为日期或日期时间字段时可用，支持按年、季度、月、周、天聚合，配置规则见「图表基础设置」一节。
- 格式化：可自定义X轴标签与Y轴标签，设置是否在点位显示数值、是否显示图例。

（3）注意事项
- X轴与Y轴均为必填，且Y轴必须是数值型字段。
- 未配置次级分组时显示单条折线。
- 分组过多会影响可读性，此时应通过筛选条件收敛分组数量。

### 刻度盘

（1）功能简介

以半圆仪表盘的形式展示单个数值及其所在区间，适合看板首页、摘要页和管理驾驶舱，用于直观判断当前值是否处于安全区、是否接近上限、是否超过预警线。

（2）设置步骤
- 图表类型：选择“刻度盘”。切换后配置面板只保留与刻度盘相关的配置项。
- 设置指标字段与统计方式：数值型字段可选求和、平均值、最大值、最小值、方差、标准差、中位数；非数值型字段可选计数、去重计数。
- 设置起始值、结束值：必填，用于确定刻度盘的量程范围。
- 设置波段颜色：【可选】按区间配置不同颜色，用于区分区间状态。
- 设置是否显示单位、是否显示当前值：当前值是指针与中心数字的依据，默认显示。

（3）注意事项
- 起始值与结束值必须配置，否则刻度盘无法确定范围。
- 统计后的主值最终必须为数值。
- 查看页、编辑预览与导出的展示结果保持一致。

### 统计数字

（1）功能简介

以卡片形式突出展示单个关键指标（如当前合格率、不合格数、偏差数、批次数），主值居中显示、辅助文案弱化，适合报告摘要、看板卡片以及章节首位展示。

（2）设置步骤
- 图表类型：选择“统计数字”。切换后配置面板只保留与单值相关的配置项。
- 设置指标字段：选择作为主值的字段。
- 设置维度：【可选】配置维度时按维度参与统计，不配置时按全集汇总。
- 设置统计方式：数值型字段可选求和、平均值、最大值、最小值、计数、去重计数；非数值型字段可选计数、去重计数。

（3）注意事项
- 默认按当前筛选条件与权限范围统计，不改变既有的筛选和权限逻辑。
- 无数据时显示明确的空态；统计口径不合法时提示具体原因，不出现空白页。

### 正态能力六合图

（1）功能简介

正态能力六合图（Normal Capability Sixpack）把过程稳定性与过程能力分析组合在一张图中呈现，可一次性完成三件事：确定过程是否稳定受控、确定数据是否服从正态分布、估计潜在（组内）能力 Cp/Cpk 与整体能力 Pp/Ppk。它由均值控制图、波动控制图、能力直方图、正态概率图、子组图、能力图六个子视图组成，分析结果可直接用于质量回顾报告。

（2）设置步骤
- 图表类型：选择“正态能力六合图”。
- 设置指标：选择数据集上数字类型的字段。
- 设置子组分组方式：必填，默认“子组大小”。
    - 子组大小：填写正整数，默认为 1，指定每个子组包含的观测值数量。
    - 子组依据：选择数据集上的字段，按该字段取值自然分组。
- 设置规格上限、规格下限：至少填写其中一个，各自可勾选是否包含边界。
- 设置历史均值、历史标准差：【可选】已知可靠的历史值时填写，留空则由当前数据估计。
- 设置目标值：【可选】填写后才计算 Cpm，不填则不计算。
- 设置检验策略：作用于均值控制图与波动控制图，三选一——进行所有 8 项检验（默认）、不执行检验、选择要进行的特定检验。设置后检验结果显示在结论中。
- 格式化：图表标题默认为“\{指标\} 的正态能力六合图”。

（3）注意事项
- 两张控制图的类型由系统按子组大小自动选择，无需手工指定：子组为 1 时用单值图与移动极差图，2~8 时用均值-极差图，9 及以上时用均值-标准差图。
- 能力分析基于正态分布假设。数据近似正态时正常计算 Cp/Cpk；经正态概率图判定偏离正态（P ≤ 0.05）时，系统提示“结果需谨慎解读”。
- 子组图默认展示分析周期内的全部有效子组，不支持按“最近 N 个子组”裁剪分析数据。
- 与 CPK分析图 的分工：CPK分析图侧重能力指数本身；六合图把稳定性判断、正态性判断与能力评估组合呈现，适合在质量回顾中一次性给出完整结论。

## 图表审核

为确保分析图表的合规性与准确性，新报表模块提供了图表创建与数据更新的审核机制。

### 图表创建审核
- 提交审核： 图表创建或重大修改后，创建者可点击“提交审核”按钮。
- 选择审核人： 通常指定给部门负责人或资深质量工程师。
- 审核任务： 审核人会在其待办任务中收到提醒，可查看图表配置、预览结果。
- 审核决策： 审核人可“批准”或“驳回”。若批准，图表状态变为“已批准”，可被报告等下游模块正式引用；若驳回，需填写意见返回给创建者修改。
- 电子签名： 批准操作通常需要审核人进行电子签名，确保责任可追溯。

### 数据更新审核
- 触发条件： 当图表的数据源（数据集）因源数据更新而重新运行，导致图表结果发生显著性变化（如控制限偏移、CPK值从合格变为不合格）时，系统可触发审核流程。
- 审核通知： 图表负责人或预设的审核人会收到“数据更新待审核”通知。
- 审核与确认： 审核人需评估数据变化的合理性。确认后，图表更新生效；若有疑问，可发起调查。

### 图表作废审核
- 发起作废申请：
    - 操作人： 图表创建者、负责人或有权限的质量人员。
    - 操作： 在目标图表（状态需为“已生效”）的详情页，点击“申请作废”按钮。
- 填写作废原因：
    - 在弹窗表单中，必须清晰、具体地填写申请作废的理由。
    - 选择本流程的审核人。根据应用所在领域的体系要求，通常需提交至相应负责人（如质量体系的 QA） 进行审批。
- 提交与审核：
    - 提交申请后，图表状态变更为“作废审核中”。系统将锁定该图表，防止被修改或被下游引用。
    - 审核人（质量负责人）将在其“待办任务”中收到审批请求。
    - 审核人需审阅作废理由的充分性。
    - 若批准： 审核人需输入密码完成电子签名。当所有必要审核节点均批准后，流程进入下一步。
    - 若驳回： 审核人填写驳回意见。申请将被退回，图表状态恢复为“已生效”。
- 作废生效：
    - 所有审批通过后，系统自动执行以下操作：
        - 将图表状态更新为“已作废”。
        - 在图表界面显示清晰的“已作废”标识。
        - 解除该图表与所有引用方（如 QRS 的报告模板及报告章节）的绑定关系，相关引用位置将显示“图表已作废”的提示。
