# 电子签名（数字身份认证）
> 本文介绍在 Gaia 平台中启用“电子签名 \+ 数字身份认证”后的用户操作方式。当前环境以**集成契约锁身份认证**为例，支持通过**人脸识别**或**手机验证码**完成身份验证后签名。   

---

## 文档信息

| 项目 | 内容 |
|------|------|
| 适用版本 | Gaia 平台 latest |
| 适用角色 | 终端用户（审批人、签署人、复核人） |
| 适用终端 | Web 端、移动端 |
| 预计阅读时间 | 8-10 分钟 |

## 功能简介

在标准电子签名基础上，数字身份认证会在签名前增加身份校验环节。 
当工作流任务已启用“数字身份认证”且用户安全策略已绑定数字身份认证策略时，签名弹窗会进入数字身份认证流程，而不是仅输入密码。
Web 端与移动端均支持数字身份认证签名。

### 支持的认证方式

| 方式 | 说明 | 常见场景 |
|------|------|------------|
| 人脸识别 | 通过人脸核验确认身份 | 高风险审批、关键放行节点 |
| 手机验证码 | 通过短信验证码确认身份 | 常规审批、异地签署 |

---

## 使用前准备

以下准备项通常由管理员完成，建议您在操作前先确认：
1. 系统已集成数字身份认证服务（当前环境为契约锁）。
2. 您的账号已绑定启用数字身份认证的安全策略。
3. 对应工作流任务节点已勾选“启用数字身份认证”。
4. 您可正常接收验证码，或可使用可用的人脸识别终端。
> \[!TIP\]
如果签名时仍只显示密码输入框，通常是“任务节点未启用数字身份认证”或“用户未绑定对应安全策略”。

## 如何完成签名

### 场景一：审批任务中使用数字身份认证签名
1. 打开待处理任务（可从「我的任务」或记录详情页进入）。
2. 点击【批准】、【拒绝】或【完成】等业务动作。
3. 在签名弹窗中进入数字身份认证流程。
4. 选择认证方式： 
    - **人脸识别**：按页面提示完成刷脸校验；
    - **手机验证码**：获取短信验证码并输入。
5. 校验成功后，确认提交签名。

### 场景二：发起审批时使用数字身份认证签名
1. 在记录或文档详情页点击【提交审批】。
2. 完成审批人、到期日期、提交说明等配置。
3. 若流程要求签名并启用数字身份认证，按弹窗完成认证。
4. 认证通过后点击【提交】。

### 场景三：直接扭转状态时使用数字身份认证签名
1. 打开目标记录详情页并选择状态动作（如【扭转状态】）。
2. 选择目标状态并填写必要说明。
3. 若该动作要求签名且启用数字身份认证，完成人脸识别或验证码校验。
4. 提交后确认状态切换结果。

## 移动端使用说明

### 移动端入口
1. 在移动端进入「我的任务」或目标记录详情页。
2. 点击待执行动作（如【批准】、【拒绝】、【完成】或状态动作）。
3. 进入签名弹窗后，按页面提示完成人脸识别或验证码认证。
4. 认证通过后提交签名，并在任务详情中确认处理结果。

### 移动端注意事项
- 使用人脸识别前，请确保移动端已授予摄像头权限。
- 使用手机验证码前，请确认当前账号绑定手机号可正常接收短信。
- 建议在稳定网络下操作，避免认证过程中超时。

---

## 结果核验

签名成功后，建议核对以下结果：
- 任务或记录状态已更新；
- 工作流已推进到下一节点（如有）；
- 签名记录中可看到本次签名；
- 可区分签名方式与认证方式（例如数字身份认证-人脸/短信）。

### 建议核对字段

| 字段 | 说明 |
|------|------|
| 签名人 | 本次签名执行用户 |
| 签名时间 | 签名发生时间 |
| 签名含义 | 本次签名对应业务含义 |
| 签名方式 | 电子签名方式（含数字身份认证） |
| 数字身份认证方式 | 人脸识别或手机验证码 |
| 结果状态 | 成功/失败 |

## 常见问题与处理

### Q1：为什么没有出现人脸识别或验证码入口？

可能原因：
- 当前任务节点未启用数字身份认证；
- 用户未绑定正确的安全策略；
- 当前流程未要求电子签名。

处理建议：联系管理员检查“任务节点设置 \+ 用户安全策略 \+ 电子签名配置”。

### Q2：验证码收不到怎么办？

处理建议：
1. 检查手机号是否为当前账号绑定号码。
2. 检查短信拦截或网络状态。
3. 稍后重试，避免重复请求过快触发频控。
4. 仍失败时联系管理员排查数字身份认证服务状态。

### Q3：人脸识别失败怎么办？

处理建议：
1. 确认光线和摄像头可用。
2. 按页面提示重新采集面部信息。
3. 切换为手机验证码方式（若策略允许）。
4. 仍失败时联系管理员核查身份认证服务和用户实名信息。

### Q4：认证通过但流程未推进怎么办？

可能原因：
- 并行节点仍有其他参与人未处理；
- 前置校验未通过（必填项、业务规则）；
- 仅完成认证但业务动作未提交成功。

处理建议：查看任务时间线与页面提示信息，定位阻塞原因。

### Q5：移动端无法调起人脸识别怎么办？

处理建议：
1. 检查移动端是否已授权摄像头权限。
2. 关闭并重新进入签名页面后重试。
3. 切换到手机验证码方式完成认证（若策略允许）。
4. 若持续失败，请联系管理员排查移动端版本与认证服务状态。

## 合规说明

数字身份认证用于提升签名身份确认强度，适用于关键审批与高风险业务场景。 
在合规审计中，建议重点关注：
- 用户身份与认证结果的可追溯性；
- 认证方式（人脸/短信）与签名记录关联；
- 认证失败原因与重试记录可审计。
