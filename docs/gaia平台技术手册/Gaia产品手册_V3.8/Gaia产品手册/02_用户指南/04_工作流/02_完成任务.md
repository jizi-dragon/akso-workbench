\# 完成任务
> 本指南说明如何在 Gaia 平台中处理分配给您的审批任务。   

---

## 前提条件
- 您有待处理的审批任务
- 您已登录 Gaia 平台

---

## 查看待办任务

### 从首页查看
1. 登录后进入首页
2. 查看 **我的任务** 视图，确认分配给自己的待办任务
3. 重点查看任务责任人、工作流负责人、任务类型、工作流、截止日期、接受时间、移交前责任人和来源业务单元
4. 点击任务名称进入任务详情，或点击关联文档进入文档详情页处理

### 在首页检索任务

如果首页任务较多，可在 **我的任务** 视图中使用搜索或筛选快速定位：
- 按名称搜索具体任务
- 按任务类型、工作流、业务模块或来源业务单元筛选任务范围
- 按关联对象状态缩小任务范围
- 按任务责任人、工作流负责人或移交前责任人确认任务归属
- 按截止日期、接受时间或完成时间筛选时间范围，先查看临近到期或等待时间较长的任务

常用筛选器包括：

| 筛选器 | 用途 |
|---------|------|
| **关联对象状态** | 查看特定状态下对象产生的任务 |
| **业务模块** | 按模块缩小任务范围 |
| **截止日期** | 找出即将到期或已超期的任务 |
| **完成时间** | 查询已完成任务的处理时间 |
| **备注** | 查找带有特定处理说明的任务 |
| **工作流** | 按工作流名称筛选任务 |
| **任务责任人** | 查看指定责任人的任务 |
| **移交前责任人** | 查看由指定人员移交出来的任务 |
| **工作流负责人** | 查看指定负责人跟进的工作流任务 |
| **任务类型** | 按审批、评审、签署、领取等类型筛选任务 |
| **来源业务单元** | 按任务所属业务单元筛选任务 |
| **接受时间** | 按任务接收时间筛选或排序 |
| **名称** | 按任务名称搜索任务 |

### 从任务菜单查看完整列表
1. 点击顶部导航栏的 **任务** 菜单
2. 查看完整的任务列表
3. 使用筛选器按对象状态、业务模块、任务类型、工作流、责任人、来源业务单元或时间范围筛选

### 安排处理优先级

建议按以下顺序处理任务：
1. 先处理已超期或即将到期的任务，避免影响后续流程
2. 再处理关键工作流、关键业务单元或高风险任务类型相关的任务
3. 接受时间较早但仍未处理的任务，应尽快确认是否需要补充信息
4. 对需要他人补充信息的任务，先添加评论或备注，避免长时间搁置
5. 暂时无法处理的任务，应及时移交给合适人员

### 待办任务信息

任务列表通常包含以下信息：

| 字段 | 说明 |
|------|------|
| **任务责任人** | 当前需要处理该任务的人员 |
| **工作流负责人** | 负责跟进该工作流整体推进的人员 |
| **任务类型** | 用于区分审批、评审、签署、领取等不同任务 |
| **工作流** | 任务所属的工作流名称，便于判断业务场景 |
| **截止日期** | 任务应完成的时间，可用于判断是否临近超期 |
| **接受时间** | 当前责任人收到任务的时间，可用于判断等待时长 |
| **移交前责任人** | 任务被移交前的处理人，便于了解流转来源 |
| **来源业务单元** | 任务所属的业务范围或组织来源 |

除完成待办外，具备相应工作流权限的用户还可对任务执行 **取消任务**、**重新分配** 等管理类操作（入口与权限说明见 [管理活动工作流](06_%E7%AE%A1%E7%90%86%E6%B4%BB%E5%8A%A8%E5%B7%A5%E4%BD%9C%E6%B5%81.md)）。日常处理人更常见的是完成或移交任务；取消与重新分配多用于流程管理员或工作流所有者场景。

## 任务类型

| 任务类型 | 说明 | 可选操作 |
|------------|------|------------|
| **审批任务** | 需要批准或拒绝 | 批准、拒绝 |
| **评审任务** | 需要审阅并提供意见 | 完成评审 |
| **签署任务** | 需要电子签名 | 签署 |
| **领取任务** | 需要有人主动领取后处理 | 领取、添加参与人 |

## 处理审批任务

### 步骤一：打开任务
1. 在任务列表中点击任务名称
2. 或点击关联文档打开文档详情页
3. 查看任务详情和相关文档

### 步骤二：审阅内容
1. 仔细阅读文档内容
2. 检查文档字段是否完整
3. 查看其他审批人的意见（如有）
4. 必要时查看文档历史和批注
5. 若关联记录详情页部分较多，可使用 **全部展开 / 全部折叠** 快速浏览各部分内容（详见 [查看对象记录](../02_%E5%AF%B9%E8%B1%A1%E7%AE%A1%E7%90%86/02_%E6%9F%A5%E7%9C%8B%E5%AF%B9%E8%B1%A1%E8%AE%B0%E5%BD%95.md)）

### 步骤三：执行操作

#### 批准文档
1. 点击 **批准** 按钮
2. 输入审批意见（可选或必填，视配置）
3. 如需电子签名，输入密码确认
4. 确认批准

#### 拒绝文档
1. 点击 **拒绝** 按钮
2. 输入拒绝原因（通常必填）
3. 确认拒绝
4. 文档将返回给发起者修改

## 电子签名

当任务需要电子签名时：

### 签名流程
1. 选择签名含义（如有多个选项）
2. 输入您的登录密码

### 签名声明示例
```
我确认已审阅此文档内容，
并以"质量审批人"身份批准此文档。

签署含义：已审核批准
```

🔒 **合规要点**：电子签名具有与手写签名同等的法律效力。请确保您理解签名的含义后再签署。

## 批量处理任务

### 批量审批
1. 系统会依次展示每个文档，方便您查阅文档信息
2. 为每个文档输入审批意见（可选，也可使用统一意见）
3. 在批量流程中便捷切换和审批多个文件
4. 确认操作
> 💡 **批量处理优化**：   

⚠️ **注意**：批量操作前请确保已审阅所有相关文档。

## 移交任务

如果您无法处理任务，可以移交给他人：

### 移交单个任务
1. 打开任务详情
2. 点击 **移交** 按钮
3. 选择移交对象
4. 输入移交原因
5. 确认移交
> 💡 **计划中的任务**：尚未到达执行时间的计划内待办任务，也支持移交，便于提前安排人员。   

## 催办任务

如果工作流配置允许催办，您可以对长时间未处理或临近截止日期的任务发起催办，提醒当前任务责任人尽快处理。

### 发起催办
1. 打开任务详情或相关工作流页面
2. 点击 **催办** 按钮
3. 输入催办说明（如需要）
4. 确认发送催办

催办后，系统会按配置向任务责任人发送提醒。催办入口、可催办次数、提醒方式和提醒对象可能因工作流配置不同而有所差异。

## 任务超时处理

### 查看任务到期时间
- 任务列表显示每个任务的到期时间
- 即将到期的任务会高亮显示
- 已过期的任务显示警告标记

### 超时后果

| 情况 | 可能的处理 |
|------|---------------|
| **提醒** | 系统发送超时提醒 |
| **升级** | 任务升级给上级 |
| **工作流暂停** | 等待人工干预 |

## 添加审批意见

### 添加评论
1. 在任务或文档详情页
2. 找到 **评论** 区域
3. 输入您的意见
4. 点击 **发送**

### 责任人与备注

流程责任人和任务责任人可为工作流或任务添加备注，便于记录处理说明或传递信息，这些备注在工作流时间线和任务详情中展示。

### 审批意见展示

退回和审批意见的展示已优化，可更清晰地区分批准、拒绝、退回等操作及对应意见内容。

### 添加批注
1. 在文档查看器中
2. 使用批注工具添加标注
3. 批注将与文档一起保存

---

### 完成任务时上传附件

在执行 **批准**、**拒绝**、**完成评审** 等完成任务操作时，您可以在提交窗口上传附件，用于补充说明、证据材料或沟通记录。提交后：
- 附件会与本次任务处理记录一并保存
- 在 **工作流时间线** 中可查看该次处理上传的附件
- 具备权限的相关处理人可在时间线中下载并核对附件内容

## 查看任务历史

### 查看工作流进度
1. 在文档详情页点击 **工作流时间线** 标签
2. 查看工作流步骤和状态
3. 查看每个步骤的处理人和时间

### 查看审批历史
1. 在文档详情页查看 **工作流时间线** 面板
2. 查看所有审批操作和意见

## 常见问题

**Q：任务没有出现在我的列表中？**

A：可能原因：
- 任务还未轮到您（等待前一步骤完成）
- 任务已被取消或移交给他人
- 您的权限发生变化

**Q：我能撤回已提交的审批吗？**

A：通常不能撤回。如果发现问题，请联系工作流管理员或系统管理员。

**Q：拒绝后文档会怎样？**

A：文档通常返回草稿状态，发起者需要修改后重新提交审批。
