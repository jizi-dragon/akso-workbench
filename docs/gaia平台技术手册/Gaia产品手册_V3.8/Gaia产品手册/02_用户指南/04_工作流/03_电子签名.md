# 电子签名
> 本文说明在 Gaia 平台中何时会触发电子签名、如何完成签名、如何排查常见问题，以及如何查看签名记录。   

---

## 文档信息

| 项目 | 内容 |
|------|------|
| 适用版本 | Gaia 平台 latest |
| 适用角色 | 终端用户（审批人、评审人、签署人） |
| 预计阅读时间 | 6-8 分钟 |

---

## 功能简介

电子签名用于确认您对某次业务操作的责任与意图，常见于审批、签署、阅读确认等工作流节点。 
签名完成后，系统会把签名与对应记录绑定，并写入审计追踪。

### 典型触发场景

| 场景 | 触发时机 | 常见动作 |
|------|------------|------------|
| 审批任务处理 | 点击批准/拒绝/提交时 | 批准、拒绝、退回 |
| 发起审批 | 发起流程的提交环节 | 提交审批 |
| 用户任务完成 | 任务被配置为需要签名 | 标记完成 |
| 批量审批 | 批量提交审批动作时 | 批量批准/批量处理 |
| 直接扭转状态 | 在详情页直接执行状态切换时 | 状态扭转、状态变更 |

---

## 前提条件
- 您已登录系统，且拥有当前任务或记录的处理权限。
- 当前流程节点已启用电子签名要求。
- 您知晓本次签名含义（如已审核批准、已审阅、已阅读并理解）。

---

## 如何完成电子签名

### 场景一：在审批任务中签名
1. 打开待处理任务（可从「我的任务」或记录详情页进入）。
2. 完成内容审阅后，点击对应操作（如【批准】、【拒绝】、【完成】）。
3. 在签名弹窗中选择签名含义（如系统配置为必选）。
4. 输入签名认证信息（通常为当前登录账号密码）。
5. 确认提交，等待系统返回处理结果。

### 场景二：在发起审批时签名
1. 在记录或文档详情页点击【提交审批】。
2. 完成审批配置（审批人、到期日期、提交说明等）。
3. 若流程要求电子签名，按弹窗提示完成签名： 
    - 阅读签名声明
    - 输入账号密码
    - 选择签名含义
4. 点击【提交】完成发起。

### 场景三：批量处理时签名
1. 在任务列表勾选多个可批量处理的任务。
2. 点击【批量审批】并选择统一动作。
3. 按系统提示完成签名验证并提交。
4. 检查每条任务的处理结果，确认是否全部成功。

### 场景四：直接扭转状态时签名
1. 打开目标记录或文档详情页。
2. 点击状态相关动作（如【扭转状态】、【修改状态】或同类动作）。
3. 选择目标状态并确认业务说明（如页面有要求）。
4. 若该状态动作配置了电子签名，系统会弹出签名窗口。
5. 输入签名认证信息并提交，完成状态切换。
> \[!NOTE\]
签名认证信息通常需要手动输入当前有效凭据。请不要使用过期密码或他人账号执行签名。   

---

## 签名成功后如何确认

签名提交成功后，通常可观察到以下变化：
- 当前任务状态更新（如从「待处理」变为「已完成」）。
- 工作流推进到下一节点，或流程状态发生变化。
- 记录被写入新的签名轨迹和审计日志。

---

## 查看签名记录
1. 打开对应文档或对象记录详情页。
2. 进入签名记录相关区域（如签名页、签名历史或工作流时间线）。
3. 核对关键字段。

### 建议核对字段

| 字段 | 说明 |
|------|------|
| 签名人 | 执行签名的用户 |
| 签名时间 | 签名发生时间 |
| 签名含义 | 本次签名的业务含义 |
| 操作结果 | 批准/拒绝/完成等动作结果 |
| 验证方式 | 密码或已启用的其他认证方式 |

## 常见问题与处理

### Q1：为什么没有弹出签名窗口？

可能原因：
- 当前流程节点未配置电子签名要求。
- 您触发的动作不是需要签名的动作。
- 当前状态动作（直接扭转状态）未配置电子签名。
- 当前权限不足，系统未允许您执行该操作。

处理建议：先确认当前任务类型与节点配置，再联系管理员检查流程配置和权限。

### Q2：电子签名时密码输错怎么办？

电子签名使用的是当前登录密码。若连续输入错误，可能触发账户锁定。 
请确认密码后重试；如已锁定，请按账号策略等待解锁或联系管理员处理。

### Q3：为什么签名后任务没推进？

可能原因：
- 同一流程的前置步骤尚未完成。
- 并行节点仍有其他参与人未处理。
- 本次提交未通过校验（例如必填项未完成）。

处理建议：到工作流时间线查看当前节点状态与阻塞原因。

### Q4：电子签名可以撤销吗？

默认不建议撤销。若确需处理，请由管理员按受控流程执行，并保留完整审计记录。

---

## 合规说明

Gaia 电子签名能力用于支撑受监管场景中的可追溯性要求。 
在合规实践中，电子签名通常需要满足以下原则：
- 签名人与账号唯一绑定
- 签名意图明确（签名含义可识别）
- 签名记录不可与业务记录分离
- 签名操作可审计追踪
