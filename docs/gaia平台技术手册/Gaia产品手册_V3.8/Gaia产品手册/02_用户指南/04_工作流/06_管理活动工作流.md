\# 管理活动工作流
> 本文介绍如何查看活跃工作流，并执行两类操作：工作流级操作（取消工作流程、变更工作流所有者、通知参与者、添加参与者）和任务级操作（重新分配、取消任务、移交任务、更新任务截止时间）。   

---

## 查看活动工作流
1. 打开文档或业务记录详情页。
2. 进入 **工作流** 区域。
3. 在活动工作流面板查看当前进行中的流程。

---

## 从列表入口查看并管理活跃工作流

在**列表**或**相关对象列表**中，若记录的 **生命周期状态** 字段存在活跃工作流，状态位置会显示**活跃工作流图标**。
1. 在列表中找到目标记录的 **生命周期状态** 字段。
2. 看到活跃工作流图标后，点击该图标。
3. 在弹出的活跃工作流面板中查看当前活跃工作流情况。
4. 查看该记录当前活跃的任务，并按权限执行工作流活动管理（如重新分配、取消任务、移交任务、更新任务截止时间、通知参与者、添加参与者等）。
> 说明：仅当记录存在活跃工作流且当前用户具备相应权限时，才会显示图标并可进入管理。   

---

## 工作流状态

| 状态 | 说明 |
|------|------|
| 进行中 | 工作流正在执行 |
| 已完成 | 工作流已结束 |
| 已取消 | 工作流被取消，不再继续推进 |

---

## 查看工作流详情
1. 在活动工作流列表中点击目标流程。
2. 在详情中查看： 
    - 流程发起时间
    - 当前步骤与处理人
    - 任务分配情况
    - 审批意见与历史记录

### 在详情页标题栏查看当前任务列表

在活跃工作流详情页的标题栏区域，可直接查看该流程的当前任务列表。列表会展示 **参与人**、**任务**、**完成状态**、**审批意见**、**动作** 等信息，便于快速判断哪些任务待处理、哪些任务已完成。

![](https://alidocs.dingtalk.com/core/api/resources/img/866277a5-5d80-4cb3-a7eb-8ccca0481f60 "")

### 在工作流时间线查看开启任务

当记录存在活跃工作流时，工作流时间线对应阶段会显示感叹号标记。点击该感叹号后，可查看当前处于开启状态的任务（打开的任务），用于快速识别仍待处理的节点。

![](https://alidocs.dingtalk.com/core/api/resources/img/bdbfa77c-90ad-4c4c-a641-f2d18446e17c "")

## 活跃工作流支持的操作

在活跃工作流面板中打开操作菜单后，可按权限执行以下工作流级操作。

### 1\. 取消工作流程
> \[!WARNING\]
取消工作流程会终止该流程下未完成的任务，请谨慎操作。   
1. 打开目标工作流详情。
2. 点击 **取消工作流程**。
3. 输入取消原因。
4. 点击 **确认**。

操作结果：
- 工作流状态更新为“已取消”。
- 该流程不再继续流转。

### 2\. 变更工作流所有者

适用场景：负责人离岗、组织调整、临时交接。
1. 打开目标工作流详情。
2. 点击 **变更工作流所有者**。
3. 选择新的工作流所有者。
4. 点击 **确认**。

操作结果：
- 工作流所有者更新为新用户。
- 后续流程管理操作由新所有者负责（以权限配置为准）。

### 3\. 通知参与者

适用场景：催办、同步进度、补充说明。
1. 打开目标工作流详情。
2. 点击 **通知参与者**。
3. 选择通知对象（参与该流程的相关人员）。
4. 输入通知内容。
5. 点击 **发送**。

操作结果：
- 系统向所选参与者发送通知消息。
- 通知仅影响消息提醒，不会直接改变流程状态。

### 4\. 添加参与者

适用场景：流程进行中需要补充审批人、会签人或可领取人等参与角色。
1. 打开目标工作流详情。
2. 点击 **添加参与者**。
3. 按页面提示选择参与者及适用的任务/角色范围（以当前流程配置为准）。
4. 点击 **确认**。

操作结果：
- 新参与者加入当前活跃工作流。
- 是否生成新待办、可领取范围如何变化，取决于任务类型与节点配置。
- 是否显示该入口取决于状态权限中的工作流权限（添加参与者）及当前用户角色。

## 活跃工作流任务支持的操作

在活跃工作流详情的任务列表中，打开任务操作菜单后，可按权限执行以下任务级动作：**重新分配**、**取消任务**、**移交任务**、**更新任务截止时间**。

### 1\. 重新分配

适用场景：当前处理人临时不可用，需要将任务改派给其他可处理人员。
1. 在活跃工作流详情中找到目标任务。
2. 打开任务操作菜单，点击 **重新分配**。
3. 选择新的任务责任人（候选人列表会排除当前责任人）。
4. 点击 **确认**。

操作结果：
- 任务责任人更新为新用户。
- 新责任人会在任务列表中看到该任务并可继续处理。

### 2\. 取消任务

适用场景：该任务不再需要执行，或需终止当前任务后由流程其他机制继续处理。
1. 在活跃工作流详情中找到目标任务。
2. 打开任务操作菜单，点击 **取消任务**。
3. 输入取消原因（如页面要求）。
4. 点击 **确认**。

操作结果：
- 该任务状态更新为已取消（以页面状态显示为准）。
- 任务不再由当前责任人继续执行。

### 3\. 移交任务

适用场景：任务需正式交接给其他人员处理。
1. 在活跃工作流详情中找到目标任务。
2. 打开任务操作菜单，点击 **移交任务**。
3. 选择接收人（候选人列表会排除当前责任人），填写移交原因（如页面支持）。
4. 点击 **确认**。

操作结果：
- 任务责任人更新为接收人。
- 任务面板会展示 **移交自** 字段，用于显示移交前责任人。

### 4\. 更新任务截止时间

适用场景：任务期限需要延期或提前，且当前任务允许手工调整截止时间。
1. 在活跃工作流详情中找到目标任务。
2. 打开任务操作菜单，点击 **更新任务截止时间**（页面文案也可能为「修改任务截止日期」）。
3. 选择或输入新的截止时间。
4. 点击 **确认**。

操作结果：
- 任务截止时间更新为新值，待办列表与任务详情同步显示。
- 若任务截止时间由对象日期字段驱动，且配置端启用了「更新对象日期字段时更新活动任务的截止时间」，则部分任务可能不允许在此手工修改，需先改对象字段或调整配置。

---

## 注意事项
- 上述操作仅对活跃工作流（进行中）生效；已完成/已取消流程通常不可再执行这些操作。
- 是否可见和可用，取决于当前用户权限与流程配置（含状态权限中的工作流权限项）。
- 建议在执行“取消工作流程”或“变更工作流所有者”前先通知相关参与者。
- 任务级操作同样受权限与配置限制；并非所有任务都显示「重新分配 / 取消任务 / 移交任务 / 更新任务截止时间」。
