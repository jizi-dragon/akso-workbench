# 发起审批

## 前提条件
- 已登录 Gaia 平台
- 文档/记录处于可提交状态（如"草稿"）
- 具有"提交"权限

## 操作步骤
1. 打开需要提交审批的文档或记录
2. 点击右上角【提交审批】按钮
> 💡 **提示**：如果按钮不可用，请检查当前状态是否允许提交。   
3. 在审批配置页面，设置以下信息：

| 选项 | 说明 |
|------|------|
| **审批人** | 系统自动分配或手动选择；支持为参与人预设职位 |
| **到期日期** | 可选，设置审批截止日期；系统会根据配置的到期策略自动处理超期任务 |
| **提交说明** | 可选，填写提交备注 |
| **附件** | 如果工作流配置了附件字段，可在此上传相关附件文件 |
> 💡 **提示**：   
4. **如果工作流配置了审批矩阵**，弹窗中会额外显示"审批矩阵参与者"区域：
    - 系统根据当前记录的属性自动匹配审批规则，并带出对应的参与人
    - 可按配置排除发起人；启用后，发起人不会被带入参与人
    - 您可以确认预填的参与人，也可以进行调整（添加或移除人员）
    - 如果某条规则要求必须指定参与人但尚未分配，该行会以红色高亮提示，需要补充后才能提交
> 💡 **详细说明**：关于审批矩阵的查看、编辑和发起工作流时的完整操作指引，请参阅 [审批矩阵](08_%E5%AE%A1%E6%89%B9%E7%9F%A9%E9%98%B5.md)。   
5. 确认信息无误，点击【提交】（或【确定】）
6. 如果系统配置了电子签名要求：
    - 阅读签名说明
    - 输入账号密码
    - 选择签名含义（如"我已创建并确认此内容"）

## 结果验证
- 状态从"草稿"变为"审批中"
- 内容被锁定，不可编辑
- 审批人收到任务通知

## 提交后可以做什么

| 操作 | 说明 |
|------|------|
| **查看进度** | 在详情页查看工作流状态 |
| **撤回** | 如尚未处理，可撤回修改后重新提交 |
| **催办** | 发送提醒给审批人 |

## 常见问题

**Q: 没有"提交审批"按钮？**   A: 可能的原因：
- 当前状态不支持提交（如已是"生效"状态）
- 您没有提交权限，请联系管理员

**Q: 可以选择审批人吗？**   A: 取决于审批流程配置。有些流程自动分配审批人，有些允许手动选择。如果配置了审批矩阵，系统会自动带出参与人，您可以在此基础上进行调整。

**Q: 发起时提示"请完成第 N 项的配置"？**   A: 说明审批矩阵中第 N 条规则要求指定参与人但当前为空。请在红色标记的行中选择参与人后再提交。详见 [审批矩阵](08_%E5%AE%A1%E6%89%B9%E7%9F%A9%E9%98%B5.md)。

**Q: 提交后发现内容有误？**   A: 如果审批人尚未处理，可以撤回修改后重新提交。如果已经处理，需要退回后修改。
