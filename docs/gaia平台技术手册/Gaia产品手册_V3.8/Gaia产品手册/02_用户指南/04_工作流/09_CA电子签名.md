# CA电子签名
> 本文介绍在 Gaia 平台中如何使用 CA（Certificate Authority，证书颁发机构）证书完成电子签名，包括前提条件、标准操作流程、结果核验与常见问题处理。

## 功能简介

CA 电子签名用于在关键业务动作中，通过数字证书完成身份认证和签名留痕，替代传统的“仅密码确认”方式。 
当管理员已为用户启用 CA 签名策略后，签名时可选择 **CA-扫码** 或 **CA-UKey**。

### 典型使用场景

| 场景 | 说明 |
|------|------|
| 审批任务签署 | 在批准、拒绝、完成任务时进行证书签名 |
| 直接状态扭转 | 在记录详情页执行状态切换时进行证书签名 |
| 外部签署协作 | 与第三方签署平台协同，保留证书签名轨迹 |
| 合规审计留痕 | 需要按签名方式区分签名记录（密码/CA-扫码/CA-UKey） |

---

## 使用前准备

在您开始签名前，请先确认以下条件：
1. 您已登录 Gaia 平台，且具备当前记录或任务的处理权限。
2. 当前业务动作（如审批、状态扭转）已配置电子签名要求。
3. 管理员已为您配置可用的 CA 电子签名策略。
4. 您的 CA 证书状态有效（未过期、未吊销）。
5. 您具备可用的签名介质： 
    - CA-扫码：可访问签名二维码确认页；
    - CA-UKey：本机已正确识别 UKey 设备。
> \[!TIP\]
如果签名弹窗中看不到 CA 选项，通常是“用户安全策略未绑定 CA 策略”或“当前节点未启用数字身份认证”导致。

## 如何执行 CA 电子签名

### 场景一：在审批任务中使用 CA 签名
1. 打开待处理任务（可从「我的任务」或记录详情页进入）。
2. 点击业务动作按钮（如【批准】、【拒绝】、【完成】）。
3. 在签名弹窗中选择签名方式： 
    - **CA-扫码**：使用扫码方式在证书侧完成确认；
    - **CA-UKey**：插入 UKey 并按提示完成签名。
4. 选择签名含义（如流程要求）。
5. 完成 CA 认证并提交。
6. 等待系统返回签名结果与任务处理结果。

### 场景二：在直接扭转状态时使用 CA 签名
1. 打开目标文档或记录详情页。
2. 点击状态动作（如【扭转状态】、【修改状态】）。
3. 选择目标状态并填写必要说明。
4. 若该动作要求电子签名，系统弹出签名窗口。
5. 选择 **CA-扫码** 或 **CA-UKey**，完成证书认证并提交。
6. 确认状态已成功切换。

### 场景三：在批量处理中使用 CA 签名
1. 在任务列表中勾选需要处理的多条任务。
2. 点击【批量审批】并选择统一动作。
3. 在签名窗口选择 CA 签名方式并完成认证。
4. 提交后逐条检查处理结果，确认是否全部成功。

## 签名结果核验

### 页面结果核验

签名成功后，通常会出现以下结果：
- 当前任务状态更新（如从“待处理”变为“已完成”）。
- 流程推进至下一节点，或记录状态已切换。
- 页面提示签名提交成功。

### 记录结果核验

建议到签名记录或审计日志中核对以下字段：

| 字段 | 说明 |
|------|------|
| 签名人 | 本次签名执行用户 |
| 签名时间 | 签名时间戳 |
| 签名含义 | 本次签名对应的业务含义 |
| 签名方式 | 密码 / CA-扫码 / CA-UKey |
| 结果状态 | 成功、失败或已作废（如启用作废管理） |

## 常见问题与处理

### Q1：为什么签名窗口没有 CA 选项？

可能原因：
- 用户未绑定启用 CA 的安全策略；
- 当前动作未启用数字身份认证；
- CA 策略已停用或无效。

处理建议：联系管理员检查“CA 策略状态、用户安全策略、节点签名配置”三项。

### Q2：CA-扫码提示超时或失败怎么办？

处理建议：
1. 重新发起签名，确保在有效时间内完成扫码确认。
2. 检查网络连接是否稳定。
3. 若持续失败，请联系管理员核对 CA 服务可用性。

### Q3：CA-UKey 无法识别怎么办？

处理建议：
1. 重新插拔 UKey 并刷新页面重试。
2. 确认本机已安装并启用 UKey 驱动。
3. 更换 USB 接口或在其他设备验证 UKey 是否正常。
4. 如仍失败，联系管理员排查证书与设备状态。

### Q4：签名成功但流程未推进怎么办？

可能原因：
- 并行节点尚有他人任务未完成；
- 前置条件未满足（必填项、校验规则）；
- 您仅完成签名，但业务动作提交未成功。

处理建议：在工作流时间线中查看阻塞节点，并核对本次提交返回信息。

## 合规说明

CA 电子签名用于增强签名身份认证强度，适用于对签名可靠性要求更高的场景。 
在合规实践中，建议重点关注：
- 签名身份与用户账号的唯一关联；
- 签名方式可追溯（密码 / CA-扫码 / CA-UKey）；
- 签名记录、审计记录完整且不可篡改；
- 证书有效期与吊销状态持续可核验。
