# 通知消息
> 本文介绍如何在 Gaia 首页查看站内信、进入首页消息列表，以及筛选和清理通知消息。   

---

## 前提条件
- 已登录 Gaia 平台。
- 当前账号可以访问首页。
- 系统已通过消息模板、工作流、作业或其他业务配置向当前用户发送站内信。

---

## 功能简介

通知消息用于接收系统提醒和业务消息。常见消息包括工作流任务提醒、记录变更提醒、系统通知，以及其他用户或系统动作触发的消息。

用户可以通过两个入口查看通知：

| 入口 | 用途 |
|------|------|
| 首页顶部消息图标 | 快速查看最近收到的站内信。 |
| 首页消息列表 | 集中查看、筛选和删除当前账号收到的全部通知消息。 |

---

## 查看站内信

在首页顶部点击消息图标，系统会打开站内信面板。

当有新消息时，消息图标会显示提示标记；没有新消息时不显示。打开面板后，未读消息会用醒目标记区分，便于先处理新的提醒。

### 站内信面板内容

| 内容 | 说明 |
|------|------|
| 消息内容 | 显示消息正文。单条消息最多展示 3 行，超出部分会省略。 |
| 链接 | 如果消息正文包含链接，链接会以可点击样式显示。点击后进入对应业务页面或外部地址。 |
| 发送时间 | 显示消息发送时间，便于判断通知先后顺序。 |
| 加载更多 | 向下滚动可继续加载更多站内信。 |

### 常用操作

| 操作 | 说明 |
|------|------|
| 查看消息 | 点击或展开消息内容，查看该条通知的主要信息。 |
| 删除消息 | 选中一条消息后点击删除图标，删除当前消息。删除后该消息不再出现在当前账号的站内信列表中。 |
| 查看更多 | 点击 **查看更多**，进入首页消息列表，查看全部通知消息。 |

---

## 查看首页消息列表

首页消息列表展示当前账号收到的全部站内信消息。消息按日期分组展示，同一天内按发送时间倒序排列，最新消息显示在前面。

列表中会同时显示消息主题和正文。未读消息会保留醒目标记；已读消息不再显示未读标记。消息中包含链接时，链接会以可点击样式显示。

### 单条操作

首页消息列表支持对单条通知进行处理：

| 操作 | 说明 |
|------|------|
| 标记为已读 | 将选中的未读消息设置为已读。执行后，该消息的未读标记会被清除。 |
| 删除消息 | 删除选中的单条消息。删除后该消息不再出现在当前账号的通知列表中。 |

### 批量操作

首页消息列表支持对通知进行批量处理：

| 操作 | 说明 |
|------|------|
| 全部已读 | 将当前账号的通知消息标记为已读。执行后，未读标记和首页消息图标上的新消息提示会相应更新。 |
| 删除全部 | 删除当前账号的全部通知消息。执行前请确认不再需要保留这些通知。 |

---

## 筛选通知消息

首页消息列表右侧提供筛选器。筛选后，列表只显示符合条件的通知消息。

| 筛选条件 | 说明 |
|------------|------|
| 消息状态 | 可筛选全部、已读或未读消息，并显示不同状态下的消息数量。 |
| 发送时间 | 按消息发送时间筛选。 |
| 标题 | 按消息标题中的关键词筛选。 |
| 内容 | 按消息正文中的关键词筛选。 |

已使用的筛选条件会显示在页面右侧上方，便于确认当前列表范围。筛选条件会保留，下次进入首页消息列表时可继续使用。

---

## 删除通知消息

用户可以在站内信面板或首页消息列表中删除不再需要的通知。

| 操作 | 说明 |
|------|------|
| 删除单条消息 | 选中一条消息后点击删除图标。系统删除当前消息后，列表会刷新。 |
| 删除全部 | 在首页消息列表点击 **删除全部**，清空当前账号的全部通知消息。 |
> 删除通知只影响当前账号的消息列表，不会删除原始业务记录、工作流任务或系统日志。   

---

## 结果验证
- 首页顶部消息图标能显示是否存在新消息。
- 站内信面板可以查看最近收到的通知。
- 点击 **查看更多** 后，能够进入首页消息列表。
- 使用消息状态、发送时间、标题或内容筛选后，列表只显示符合条件的消息。
- 手动将单条消息标记为已读后，该消息的未读标记被清除。
- 点击 **全部已读** 后，未读消息标记被清除。
- 删除消息后，该消息不再出现在当前账号的通知列表中。
- 点击 **删除全部** 后，当前账号的通知消息列表被清空。

## 常见问题

**Q：为什么首页消息图标没有提示标记？**   A：通常表示当前没有新消息，或新消息已经被读取。

**Q：为什么站内信面板里看不到更早的消息？**   A：站内信面板用于快速查看最近消息。需要查看全部消息时，请点击 **查看更多** 进入首页消息列表。

**Q：筛选条件下次进入还会保留吗？**   A：会。首页消息列表会保留上次使用的筛选条件。

**Q：删除通知后会影响业务数据吗？**   A：不会。删除通知只清理当前账号看到的消息，不影响对应记录、任务、审批或日志。
