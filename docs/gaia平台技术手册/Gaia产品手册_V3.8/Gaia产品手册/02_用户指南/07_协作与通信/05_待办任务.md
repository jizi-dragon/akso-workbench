# 待办任务
> 本文介绍如何查看、处理和管理待办任务，包括任务指派、移交、代理及视图刷新等能力。   

---

## 概述

待办任务是 Gaia 平台工作流产生的需要用户处理的事项，包括审批任务、培训任务、阅读确认等。用户可通过首页、任务菜单等入口查看和处理待办。

### 访问入口

| 入口 | 路径 |
|------|------|
| **首页** | 我的任务小部件 |
| **任务菜单** | 顶部导航栏 \> 任务 |

---

## 查看待办任务

### 任务列表信息

| 信息项 | 说明 |
|---------|------|
| **当前责任人** | 任务的当前处理人 |
| **移交前责任人** | 支持显示**移交前的责任人**，便于了解任务来源和流转历史 |
| **到期时间** | 任务完成期限 |
| **超期天数** | 已过期任务的超期天数标识 |

### 视图与数量刷新

完成待办后，系统会**自动更新所有待办视图的任务数量**，确保首页小部件、任务菜单及各视图中的数量显示实时一致，无需手动刷新页面。

### 关联记录已删除时的显示

当待办关联的业务记录随后被删除时，待办列表仍应能正常展示该任务，并尽量显示**原关联实例名称**（或系统保留的名称快照），避免因记录删除导致列表空白、无法识别任务来源。用户可据此联系管理员处理残留任务或从时间线核对历史。

---

## 任务指派与移交

### 重新指派任务
1. 打开工作流任务
2. 点击 **重新分配**
3. 选择新的负责人
4. 确认

### 移交任务
1. 打开工作流任务
2. 点击 **移交**
3. 选择接手人
4. 确认移交
> 💡 **指派与移交优化**：进行重新指派或移交时，**当前责任人会自动排除**在可选范围之外，避免将任务误移交给当前处理人，提升操作合理性。   

### 计划中的任务

尚未到达执行时间的**计划内待办任务**也支持移交或重新分配，便于提前安排人员。

---

## 培训任务的移交与代理

培训任务是否支持**移交**和**代理**，由管理员通过**配置控制**。具体规则以系统配置为准：
- 若已配置允许移交/代理，培训任务可像普通工作流任务一样进行移交或设置代理
- 若已配置禁止移交/代理，则培训任务不显示移交或代理入口
> 💡 **提示**：如需调整培训任务的移交、代理策略，请联系管理员在**系统设置**或**培训设置**中修改配置。
