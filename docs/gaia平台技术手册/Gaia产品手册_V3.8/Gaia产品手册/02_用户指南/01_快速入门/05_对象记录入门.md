## 什么是对象？

在 Gaia 平台中，**对象（Object）** 是存储结构化业务数据的实体。与文档（非结构化内容）不同，对象用于管理您日常工作中的关键业务信息。

**常见对象示例**：

| 对象名称 | 用途 | 示例 |
|------------|------|------|
| 产品（Product） | 管理产品信息 | 阿莫西林胶囊、奥美拉唑片 |
| 国家（Country） | 管理注册国家 | 中国、美国、日本 |
| 部门（Department） | 管理组织架构 | 质量部、生产部、研发部 |
| 供应商（Supplier） | 管理供应商 | XX 原料供应商、YY 包材供应商 |

每个对象中存储的具体数据称为**对象记录（Object Record）**。例如，"阿莫西林胶囊"就是"产品"对象中的一条记录。

## 第一步：访问对象菜单
1. 登录 Gaia 平台
2. 在顶部导航栏中，找到对象菜单（如 **产品**、**供应商** 等）
3. 点击菜单名称进入对象记录列表

💡 **提示**：不同的应用和用户权限可能显示不同的对象菜单。如果您看不到某个对象，请联系系统管理员。

---

## 第二步：浏览对象记录列表

进入对象菜单后，您将看到对象记录列表页面：

### 列表页面组成

| 区域 | 说明 |
|------|------|
| **搜索栏** | 快速搜索特定记录 |
| **筛选面板** | 按字段值筛选记录 |
| **列表视图** | 显示所有记录 |
| **操作菜单** | 创建、导出等操作 |

### 尝试以下操作
1. **搜索记录**：在搜索栏输入关键词，按 Enter 键搜索
2. **排序**：点击列标题按该列排序
3. **筛选**：使用左侧筛选面板缩小范围

---

## 第三步：查看记录详情

点击任意记录名称，进入**记录详情页**：

### 详情页组成

| 面板 | 内容 |
|------|------|
| **基本信息** | 记录的核心字段（名称、编号、状态等） |
| **详细信息** | 扩展字段和分组信息 |
| **关联记录** | 与其他对象的关联关系 |
| **关联文档** | 链接到此记录的文档列表 |
| **审计追踪** | 记录的所有变更历史 |

🔒 **合规要点**：所有对对象记录的查看和修改都会被审计追踪记录，以满足 GxP 合规要求。

---

## 第四步：理解对象与文档的关系

对象记录和文档通过**文档字段**关联：
```
文档 ──引用──> 对象记录
           （通过对象类型字段）
```

**示例**：一份产品规格书文档的"产品"字段可能引用了"阿莫西林胶囊"这条产品记录。

### 从对象记录查找相关文档
1. 打开对象记录详情页
2. 找到 **关联文档** 面板
3. 点击文档名称可直接打开文档

### 从文档查找相关对象
1. 打开文档详情页
2. 在字段面板中找到对象类型字段
3. 点击字段值可跳转到对象记录

---

## 第五步：使用网格视图

Gaia 平台支持**网格视图（Grid View）**，类似电子表格的操作体验：

### 切换到网格视图
1. 在对象列表页，点击视图切换图标
2. 选择 **网格视图**

### 网格视图功能

| 功能 | 操作 |
|------|------|
| **调整列宽** | 拖动列边框 |
| **排序** | 点击列标题 |
| **编辑列** | 通过菜单选择显示的列 |
| **导出** | 导出为 Excel 或 CSV |

💡 **提示**：网格视图适合需要快速浏览大量数据或批量操作的场景。

## 关键概念回顾

| 概念 | 定义 |
|------|------|
| **对象** | 存储结构化业务数据的实体类型 |
| **对象记录** | 对象中的一条具体数据 |
| **对象字段** | 对象记录的属性（如名称、编号、状态） |
| **对象类型** | 对象的分类，不同类型可有不同字段 |
| **对象关系** | 对象之间的层级或引用关联 |

## 常见问题

**Q：为什么我看不到某些对象菜单？**

A：对象菜单的可见性由您的权限集控制。请联系系统管理员申请相应权限。

**Q：我可以修改对象记录吗？**

A：取决于您的权限和记录的生命周期状态。某些状态下的记录可能被锁定无法编辑。

**Q：对象记录会影响文档吗？**

A：对象记录的变更会自动反映到引用它的所有文档中。例如，修改产品名称后，所有引用该产品的文档都会显示新名称。
