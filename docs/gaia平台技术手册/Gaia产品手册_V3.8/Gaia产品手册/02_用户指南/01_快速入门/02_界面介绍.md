# 界面介绍
> 本文用于帮助您快速识别 Gaia 平台常见页面结构，并知道每个区域可以完成什么操作。   

---

## 列表页

列表页是进入业务模块后的默认工作页面，适合查找、筛选和批量处理记录。

### 关键区域

| 区域 | 作用 | 常见操作结果 |
|------|------|------------------|
| 顶部全局栏 | 提供全局搜索与账户入口 | 输入关键词后可快速定位文档或记录 |
| 应用导航栏 | 切换业务模块 | 进入对应模块的列表或首页 |
| 左侧侧边栏 | 管理视图与筛选器 | 先定范围，再缩小结果 |
| 列表头部与操作区 | 展示当前列表名称和操作按钮 | 创建记录、查看已生效筛选条件 |
| 列表内容区 | 展示数据行与关键字段 | 点击名称进入详情，按列查看状态与时间 |
| 分页区 | 控制翻页与每页条数 | 浏览更多记录或快速跳页 |

### 使用顺序建议
1. 先选视图确定数据范围。
2. 再用筛选器缩小结果。
3. 最后按表头排序或筛选定位目标记录。

---

## 详情页

详情页用于查看和维护单条记录，适合执行编辑、流程处理和关联数据维护。

### 关键区域

| 区域 | 作用 | 常见操作结果 |
|------|------|------------------|
| 顶部全局栏 | 保持全局搜索与消息入口 | 不改变当前记录上下文 |
| 应用导航栏 | 切换到其他模块 | 离开当前记录页面 |
| 详情头部区 | 展示记录标题、状态和核心动作 | 返回列表、进入编辑、打开更多操作 |
| 生命周期区 | 展示当前流程阶段 | 判断记录所处阶段与下一步动作 |
| 左侧目录区 | 提供页内导航 | 快速跳到工作流、基础信息、关联列表等区域 |
| 详情内容区 | 展示主信息与关联信息 | 查看、维护、新增或删除关联数据 |

### 进入详情后建议先做的事
1. 先看记录状态和生命周期阶段。
2. 再查看关键字段是否完整。
3. 最后执行编辑、发起流程或关联维护。
