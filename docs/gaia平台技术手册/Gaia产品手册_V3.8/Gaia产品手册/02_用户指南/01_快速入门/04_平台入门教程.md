# 平台入门教程
> **预计时间**：15 分钟   **难度**：初级   **前置条件**：已开通 Gaia 平台账号   

---

## 您将学到什么

完成本教程后，您将能够：
- ✅ 登录 Gaia 平台并了解界面布局
- ✅ 使用导航菜单切换模块
- ✅ 查看和管理个人任务
- ✅ 使用全局搜索查找内容
- ✅ 了解个人设置功能

---

## 第一步：登录系统
1. 打开浏览器，访问您的 Gaia 平台地址（由管理员提供）
2. 在登录页面输入：
    - **用户名**：您的用户名
    - **密码**：初始密码或您设置的密码
3. 点击【登录】按钮
> 💡 **提示**：首次登录时，系统会要求您修改初始密码。密码需满足复杂度要求。   

**验证**：成功登录后，您将看到 Gaia 平台的页面。

---

## 第二步：认识界面布局

登录后，您将看到 Gaia 平台的主界面，包含以下区域：
```
┌─────────────────────────────────────────────────────────────────┐
│  ① 顶部导航栏                                                   │
│  ┌─────────────────────────────────────────────────────────────┐│
│  │ Logo  │ 应用切换 │        全局搜索        │ 通知 │ 用户头像 ││
│  └─────────────────────────────────────────────────────────────┘│
├─────────┬───────────────────────────────────────────────────────┤
│         │                                                        │
│  ②     │                    ③ 主内容区                          │
│  左侧   │                                                        │
│  导航   │    显示当前模块的内容                                   │
│  菜单   │    列表、详情、表单等                                   │
│         │                                                        │
│         │                                                        │
├─────────┴───────────────────────────────────────────────────────┤
│  ④ 底部状态栏（可选）                                            │
└─────────────────────────────────────────────────────────────────┘
```

### 各区域说明

| 区域 | 名称 | 功能 |
|------|------|------|
| ① | 顶部导航栏 | 应用切换、全局搜索、通知、用户菜单 |
| ② | 左侧导航菜单 | 当前应用的模块导航 |
| ③ | 主内容区 | 显示当前模块的具体内容 |
| ④ | 底部状态栏 | 系统状态信息（部分页面显示） |

---

## 第三步：切换应用模块

Gaia 平台支持多个应用模块（如 管理端、打印中心、DMS、QMS、ERS 等）。
1. 点击顶部导航栏左侧的【应用切换器】图标
2. 在弹出的面板中，您将看到已授权的应用列表，如
    - 文档管理 (DMS)
    - 质量管理 (QMS)
    - 培训管理 (TMS)
    - 记录管理 (ERS)
    - ...
3. 点击想要进入的应用
> 💡 **提示**：您看到的应用列表取决于管理员为您分配的权限。   

**验证**：切换后，左侧导航菜单会更新为对应应用的模块列表。

---

## 第四步：查看我的任务

"我的任务"是您的个人工作台，显示待处理的审批和任务。
1. 点击顶部导航栏的【任务】图标（或左侧菜单的"我的任务"）
2. 您将看到任务列表，包含：
    - **待审批**：等待您审批的文档/记录
    - **待处理**：分配给您的任务
    - **已处理**：您已完成的任务
3. 点击任意任务可查看详情并进行处理
> 🔒 **合规要点**：所有任务操作都会记录在审计追踪中，请确保在规定时限内完成处理。   

---

## 第五步：使用全局搜索

全局搜索帮助您快速找到平台中的任何内容。
1. 输入关键词，如：
    - 文档名称：`SOP-001`
    - 批号：`20260202-001`
    - 人员姓名：`张三`
1. 搜索结果会实时显示，按类型分组：
    - 文档
    - 记录
    - 对象
    - 人员
2. 点击结果项可直接跳转
> 💡 **提示**：使用引号可进行精确搜索，如 `"SOP-001"` 只匹配完全一致的内容。   

---

## 第六步：个人设置
1. 点击右上角的用户头像
2. 在下拉菜单中可以：
    - 查看个人信息
    - 修改密码
    - 切换语言
    - 退出登录
3. 点击【个人中心】进入个人信息页面
