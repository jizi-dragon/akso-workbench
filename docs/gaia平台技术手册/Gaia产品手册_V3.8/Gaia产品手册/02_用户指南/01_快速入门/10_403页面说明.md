# 403 页面说明
> **适用对象**：登录后访问页面时看到 403、无权限或访问被拒绝提示的用户403 页面表示系统已识别当前账号，但当前页面不在当前账号的可访问范围内。   

---

## 什么时候会看到 403 页面

403 页面通常会显示无法访问的原因。常见场景包括：

| 场景 | 说明 |
|------|------|
| 直接打开链接 | 链接指向的菜单、记录、文档或报表不在当前账号的访问范围内 |
| 访问未开放模块 | 当前账号不属于该应用、菜单或功能的使用范围 |
| 查看不可见数据 | 记录、文档、报表或仪表板对当前账号不可见 |
| 执行受限操作 | 当前操作不在当前账号可执行范围内 |
| 访问范围变化 | 角色、组织、业务单元或记录共享范围发生变化 |
| 网络访问受限 | 当前访问来源不符合系统网络访问规则 |

403 不一定表示链接失效。它通常表示系统按当前账号、数据范围或网络规则阻止了本次访问。

---

## 看到 403 页面后怎么处理

如果在访问系统过程中进入 403 页面，可点击页面上的【返回】按钮回到上一个页面。

返回后，可继续从菜单、列表、通知或任务入口访问其他可用页面。若是通过收藏链接、他人分享链接或浏览器历史记录进入 403 页面，建议改为从系统菜单或当前业务列表重新进入。

如果页面提供具体原因，以页面提示为准。例如：

| 页面提示 | 处理方式 |
|------------|------------|
| 无权访问该页面 | 点击【返回】，从已授权菜单重新进入 |
| 数据不可见 | 返回列表页，查看当前账号可见范围内的数据 |
| 链接无效或不可访问 | 返回上一页，改从系统导航重新进入 |
| 网络访问受限 | 更换符合要求的网络环境后再访问 |

在 GxP 需要 CSV 验证的系统中，访问范围通常经过预先配置和验证。403 页面是系统按既定访问规则给出的拦截结果，不作为临时申请访问范围的入口。

## 常见问题

### 403 和未登录有什么区别？

未登录通常会进入登录页。403 表示已经登录，但当前账号无权访问目标页面或数据。

### 为什么同事能打开，我打不开？

通常是角色、组织范围、记录共享范围或网络访问规则不同。请以当前账号可见范围为准。

### 为什么以前能打开，现在显示 403？

可能是记录状态、组织范围、共享范围、网络规则或链接目标发生变化。

### 重新登录能解决吗？

如果是会话过期或组织范围选择错误，重新登录可能有用。若重新登录后仍显示 403，请点击【返回】继续访问其他可用页面。
