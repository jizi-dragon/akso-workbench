# 创建仪表盘
> 本文说明如何在 Gaia 平台中创建、编辑、查看和导出仪表盘。   

---

## 概述

仪表盘用于把多个报表以组件方式组合展示。

仪表盘通常包含三类页面：

| 页面 | 说明 |
|------|------|
| 列表页 | 查看所有仪表盘，进入详情，创建新仪表盘 |
| 创建/编辑页 | 配置仪表盘基础信息、筛选和组件 |
| 查看页 | 浏览仪表盘结果，导出或返回编辑 |

---

## 进入页面

### 查看仪表盘列表

进入仪表盘列表页后，可以：
- 查看所有仪表盘
- 使用筛选器查找仪表盘
- 点击 `创建` 新建仪表盘
- 对已有仪表盘执行删除或更多操作

### 进入仪表盘查看页

进入某个仪表盘后，可以：
- 查看图表和指标卡
- 执行筛选查询
- 点击 `编辑` 进入编辑态
- 点击 `导出` 导出仪表盘
- 点击 `返回` 返回列表或上一层

---

## 创建仪表盘并保存

### 1\. 填写仪表盘基础信息

在创建页填写以下内容：
- 名称
- 代码
- 备注

### 2\. 保存并进入编辑

保存后进入仪表盘编辑状态，开始添加筛选和组件。

---

## 编辑仪表盘内容

在编辑状态下，可以对仪表盘进行以下操作：
- 新增筛选
- 新增组件
- 调整组件布局
- 保存修改

---

## 添加筛选器

点击 `新增筛选` 后，会弹出全局筛选器配置窗口。

通常需要配置这些内容：

| 字段 | 说明 |
|------|------|
| 名称 | 筛选器名称 |
| 字段类型 | 筛选字段的类型 |
| 默认值 | 筛选器默认值 |
| 描述 | 筛选器说明 |
| 筛选字段 | 选择关联的报表字段 |
| 影响组件 | 选择会被该筛选器联动的组件 |

配置完成后，筛选器可用于联动仪表盘中的多个组件。

---

## 添加组件

点击 `新增组件` 后，会弹出组件配置窗口。

### 1\. 填写组件基础信息

先填写组件的基础信息，再往下选图表类型。
- `名称`：组件标题
- `报表`：组件数据来源
- `图表类型`：组件的可视化样式

### 2\. 选择图表类型

先根据要看的内容选择图表类型。

| 图表类型 | 适合场景 | 选择建议 |
|------------|------------|------------|
| 仪表盘 | 进度、达成率、阈值监控 | 看单个指标的当前状态 |
| 数字 | 总量、汇总值、关键指标卡片 | 看一个汇总结果 |
| 条形图 | 类别对比、长名称展示 | 看横向对比 |
| 柱状图 | 类别对比、排序展示 | 看纵向对比 |
| 帕累托 | 二八分析、重点项识别 | 看重点贡献项 |
| 折线图 | 趋势变化、时间序列 | 看变化趋势 |
| 饼图 | 构成占比、分类分布 | 看占比分布 |

### 3\. 配置图表数据和样式

选好图表类型后，只看两个区域：
- `图表数据`：选数据和统计方式
- `格式化`：调展示样式

#### 配置图表数据

图表数据页常见字段如下：

| 字段 | 说明 |
|------|------|
| 图表类型 | 选择可视化样式 |
| 维度 | 选择分类轴或分组字段 |
| 指标 | 选择度量字段 |
| 统计方式 | 计数、求和等汇总方式 |
| 次级分组 | 第二层分组字段 |
| 图表分组类型 | `分组式`、`堆叠式`、`百分比堆叠式` |

不同图表类型的字段差异如下：
- 仪表盘：`图表类型`、`指标`、`统计方式`
- 数字：`图表类型`、`维度`、`指标`、`统计方式`
- 条形图：`图表类型`、`维度（Y-轴）`、`指标（X-值）`、`统计方式`、`次级分组`、`图表分组类型`
- 柱状图：`图表类型`、`维度（X-轴）`、`指标（Y-轴）`、`统计方式`、`次级分组`、`图表分组类型`
- 帕累托：`图表类型`、`维度（X-轴）`、`指标（Y-轴）`、`统计方式`
- 折线图：`图表类型`、`维度（X-轴）`、`指标（Y-轴）`、`统计方式`、`次级分组`、`图表分组类型`
- 饼图：`图表类型`、`维度`、`指标`、`统计方式`

#### 设置格式化

格式化页按图表类型调整重点项：
- 仪表盘：`开始`、`结束`、`显示实际值`、`单位标签`、`波段颜色`
- 数字：`显示指标`、`范围1`、`范围2`、`范围3`
- 条形图、柱状图、折线图：`X-轴标签`、`Y-轴标签`、`显示图标数值`、`显示图例`
- 帕累托：`X-轴标签`、`Y-轴标签`、`显示图标数值`、`显示图例`、`标准线`
- 饼图：`显示指标`、`显示百分比`、`显示数字`、`显示图例`

如果某类图表不需要某个开关，可以保持默认值不变。

点击 `预览` 可以先查看组件效果，再点击 `确定` 完成添加。

---

## 调整组件布局

在编辑态下，仪表盘组件支持拖拽和调整大小。

常见操作：
- 拖拽组件调整位置
- 拖拽边框调整大小
- 通过布局方式排列多个组件

---

## 查看仪表盘结果

在查看页，仪表盘会以卡片或图表方式展示组件结果。

常见查看操作包括：
- 在顶部筛选器中查询
- 点击 `查询`
- 点击 `重置`
- 展开或收起图表区域
- 点击组件上的编辑、删除或导出图标

---

## 导出仪表盘文件

点击 `导出` 后，会弹出导出窗口。

通常需要填写或选择：
- 文件名称
- 导出格式

常见导出格式：
- `EXCEL`
- `PDF`

---

## 排查常见问题

### 为什么看不到创建按钮？

通常是权限不足，或者当前账号没有仪表盘创建权限。

### 为什么新增组件时没有可选报表？

通常是报表还未创建，或者当前账号没有查看权限。

### 为什么筛选器没有联动效果？

通常是该筛选器没有绑定到任何组件，或者未在影响组件中选择目标组件。

### 为什么导出后内容不完整？

通常是导出格式不支持当前全部组件，或者部分组件数据受权限限制。
