# 导出数据
> 本文说明如何导出报表、仪表盘和列表数据。   

---

## 概述

导出功能通常出现在以下场景：
- 报表结果导出
- 仪表盘导出
- 列表数据导出

不同页面的导出弹框字段不完全相同，其中报表导出通常会包含数据层级选项，仪表盘导出通常只需要文件名称和导出格式。

---

## 导出报表

点击报表页面的 `导出` 后，通常会打开报表导出弹框。

常见字段包括：

| 字段 | 说明 |
|------|------|
| 文件名称 | 导出文件的名称 |
| 导出格式 | 选择导出格式 |
| 数据层级 | 选择导出的数据层级 |

### 导出格式

报表导出常见格式为：
- `EXCEL`
- `PDF`

### 数据层级

报表导出时，通常可以选择导出的数据层级：
- `分组`
- `次级分组`
- `明细`

常见做法是根据需要选择一个或多个层级。若需要查看完整明细，通常需要勾选 `明细`。

---

## 导出仪表盘

点击仪表盘页面的 `导出` 后，通常会打开仪表盘导出弹框。

当前仪表盘导出主要包含：
- 文件名称
- 导出格式

### 导出格式

仪表盘导出常见格式为：
- `EXCEL`
- `PDF`

导出后可用于分享、归档或离线查看仪表盘内容。

## 导出限制

| 限制 | 说明 |
|------|------|
| 权限控制 | 没有导出权限时不能下载 |
| 数据范围 | 超大结果集可能会受上限限制 |
| 格式限制 | 可选格式由页面和配置决定 |

---

## 常见问题

### 为什么没有“导出”按钮？

通常是权限不足，或者当前页面不支持导出。

### 为什么仪表盘导出没有数据层级选项？

仪表盘导出通常只导出当前仪表盘本身，不提供报表结果的分层级导出选项。

### 为什么报表导出后没有明细？

通常是导出时没有勾选 `明细` 层级，或者当前报表本身没有明细数据。

### 为什么导出的格式和预期不一样？

导出格式由页面能力和租户配置决定，不同模块可能不完全一致。
