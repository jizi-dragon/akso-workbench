# 创建报表实例
> 本文说明如何在 Gaia 平台中创建报表实例，并在查看页进行编辑、订阅简报和导出。   

---

## 概述

报表相关概念分为三层：

| 概念 | 说明 |
|------|------|
| 报表类型 | 管理员配置的数据基础，决定报表可以基于哪些对象或数据视图生成 |
| 报表视图 | 基于报表类型预先配置好的筛选、分组和统计结果 |
| 报表实例 | 用户在业务端创建的报表，用于选择类型、补充配置并查看结果 |

报表实例用于基于已配置好的报表类型，生成可查看、可订阅、可导出的统计结果。

创建报表实例的典型流程是：
1. 在左侧选择报表类型
2. 在右侧填写实例基础信息
3. 点击 `下一步` 进入后续配置

---

## 页面结构

报表实例创建页通常包含两部分：

| 区域 | 说明 |
|------|------|
| 左侧 | 报表类型树，用于选择报表实例所基于的数据基础 |
| 右侧 | 基础信息表单，用于填写名称、Code、备注和报表形式 |

左侧类型树支持展开、收起，以及快速浏览可用类型。

---

## 前置条件
- 已具备报表实例创建权限
- 管理员已配置可用的报表类型
- 如需后续按视图统计，相关报表视图已完成配置

---

## 创建报表实例

### 1\. 选择报表类型

在左侧类型树中选择一个可用的报表类型，作为当前报表实例的数据基础。

报表类型由管理员预先配置，用于定义报表可基于哪些对象或视图生成结果。

### 2\. 填写基础信息

在右侧填写报表实例的基础信息：

| 字段 | 说明 |
|------|------|
| 名称 | 报表实例的展示名称 |
| Code | 报表实例的唯一标识 |
| 备注 | 对报表用途的补充说明 |

### 3\. 选择报表形式

报表形式用于定义结果的展示方式。

当前常见形式为：
- 表格

### 4\. 进入下一步

点击 `下一步` 后，系统进入报表实例的详细配置页面。

后续配置通常包括：
- 属性
- 过滤条件
- 分组
- 展示方式

---

## 配置报表实例

进入详细配置页后，通常需要完成以下操作：

### 属性

查看或调整报表实例的名称。

### 过滤条件

通过过滤条件限定报表返回的数据范围。

常见设置包括：
- 选择条件字段
- 设置条件是否在报表中显示
- 设置是否允许在运行时编辑
- 设置条件是否可选

### 分组

通过分组定义报表的统计层级和汇总方式。

常见配置包括：
- 按字段分组
- 设置分组排序
- 选择汇总函数
- 设置展示方式

---

## 查看报表

保存后进入报表查看页，可以执行以下操作：
- 查看分组结果
- 展开或折叠分组层级
- 返回编辑页继续修改
- 导出当前报表
- 订阅简报

---

## 订阅简报

点击 `订阅简报` 可配置报表的定时推送。

订阅窗口通常包含以下内容：
- 推送时间
- 时区
- 是否按角色推送
- 推送用户
- 推送设置
- 是否在邮件中包含报表
- 是否在邮件中包含报表附件

---

## 导出报表

点击 `导出` 可导出当前报表结果。

导出窗口通常包含以下内容：
- 文件名称
- 导出格式
- 数据层级

常见导出格式：
- `EXCEL`
- `PDF`

常见导出层级：
- `分组`
- `次级分组`
- `明细`

---

## 常见问题

### 为什么没有报表类型可选？

通常是管理员未配置可用报表类型，或当前账号没有对应权限。

### 为什么点击下一步后还需要继续配置？

创建报表实例只是开始，后续还需要补充过滤条件、分组和展示方式，才能形成可用报表。

### 为什么导出没有明细？

通常是导出时未选择 `明细` 层级，或者当前报表没有明细数据。

### 为什么订阅简报没有接收人？

通常是未选择推送用户，或者未启用按角色推送。
