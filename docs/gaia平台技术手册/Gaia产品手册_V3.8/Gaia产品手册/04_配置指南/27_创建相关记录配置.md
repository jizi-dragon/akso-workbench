# 创建相关记录配置
> 本文说明如何在 Gaia 平台中配置“创建相关记录”，并在生命周期状态进入时自动生成相关对象记录。   

---

## 1 概述

创建相关记录用于在源记录进入指定状态后，自动创建目标对象记录，并按映射规则复制字段值。 
配置同时支持两种类型：
- 相关记录配置：目标对象来自源对象的入站关系
- 非相关记录配置：目标对象可直接选择系统中的任意对象

典型场景：
- 记录进入“生效/批准”状态后，自动生成后续执行记录
- 基于主记录信息批量带出下游关联记录，减少重复录入
- 通过字段映射统一关键字段，降低人工配置偏差

核心对象：

| 名称 | 说明 |
|------|------|
| 源对象 | 触发创建动作的对象。 |
| 配置类型 | 用于区分“相关记录配置”与“非相关记录配置”。 |
| 目标对象 | 自动创建记录所属对象。相关记录配置下由入站关系确定；非相关记录配置下可直接选择任意对象。 |
| 字段值映射 | 定义“源字段 → 目标字段”的赋值关系。 |

---

## 2 配置入口

相关记录配置管理入口：

`配置端 > 配置管理 > 对象设置 > 创建相关记录配置`

生命周期触发入口：

`配置端 > 配置管理 > 对象设置 > {对象} > 生命周期 > 状态 > 进入动作 > 创建相关记录`

---

## 3 相关记录配置管理

### 3.1 列表页

列表默认展示已配置的全部相关记录配置，常见列包括：
- 名称
- Code
- 状态
- 源对象
- 相关对象
- 描述
- 操作

筛选器：

| 筛选器 | 说明 |
|---------|------|
| 关键词 | 按名称关键字检索配置。 |

行内操作：

| 操作 | 说明 |
|------|------|
| 编辑 | 进入配置编辑页。 |
| 启用/停用 | 控制配置是否可被生命周期动作选择。 |
| 删除 | 删除配置。已被引用的配置不可删除。 |

### 3.2 创建配置
1. 进入“创建相关记录配置”列表页。
2. 点击 `创建`。
3. 在弹出层选择 `配置类型`： `相关记录配置`（默认） 或 `非相关记录配置`。
4. 在 `详情` 区填写基础信息。
5. 保存后进入配置详情，继续维护字段值映射。

字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| 配置类型 | 是 | 创建时选择。可选：`相关记录配置`、`非相关记录配置`。创建后不可修改。 |
| 名称 | 是 | 配置显示名，建议使用“源对象 \+ 目标场景”命名。 |
| Code | 是 | 配置唯一编码，建议英文小写加下划线。 |
| 状态 | 否 | 默认 `启用`。停用后不可被动作选择。 |
| 源对象 | 是 | 触发自动创建的对象。 |
| 源对象类型 | 条件必填 | 源对象启用对象类型时显示并必选。 |
| 目标对象 | 是 | 相关记录配置下，从源对象入站关系中选择；非相关记录配置下，可从系统对象中选择任意对象。 |
| 相关对象类型 | 条件必填 | 相关对象启用对象类型时显示并必选。 |
| 描述 | 否 | 维护说明，便于后续排查与交接。 |

### 3.3 编辑配置

编辑页中：
- 可编辑：名称、状态、描述
- 只读：配置类型、Code、源对象、源对象类型、目标对象、相关对象类型

## 4 字段值映射

### 4.1 映射区域与操作

字段值映射用于定义“创建相关记录时，哪些值从哪里来”。

页面常用操作：
- `添加字段`：新增一条映射
- `移除`：删除当前映射（枚举类型支持删除整个字段或单个枚举值映射）
- 枚举展开/折叠：查看并逐条设置选项值映射

限制：
- 单个配置最多支持 30 条字段映射

### 4.2 映射规则
1. 源字段与目标字段必须类型兼容。
2. 选项字段仅支持单选映射。
3. 布尔与选项支持“值级别映射”（逐个选项值配置目标值）。
4. 支持使用“源对象的出站关系对象字段”作为源字段。
5. 不支持附件、公式、查找、统计等字段类型映射。
6. 对象/父对象映射时，双方对象定义需一致。

常见支持关系：

| 源字段类型 | 目标字段类型 | 说明 |
|---------------|------------------|------|
| 文本 | 文本 | 系统字段仅支持少量可映射字段（如创建人）。 |
| 数字 | 数字 | 需注意范围与精度。精度不一致时按目标字段精度处理。 |
| 日期时间 | 日期/日期时间 | 高精度向低精度映射时截断，低精度向高精度映射时补齐默认值。 |
| 单选 | 单选 | 支持选项值逐条映射。 |
| 布尔 | 布尔 | 支持值级别映射。 |
| 对象/父对象 | 对象/父对象 | 必须对象类型一致。 |
| 组件（非对象类型） | 组件（非对象类型） | 组件类型需一致。 |
| 出站关系对象字段 | 与源字段同规则 | 按对应基础类型规则校验。 |

### 4.3 源字段默认值

当源字段可能为空但目标字段要求必填时，可为源字段设置映射默认值：
- 源字段有值：按源字段实际值写入
- 源字段为空：按映射默认值写入

默认值规则与字段默认值能力一致，适用于降低自动创建失败率。

### 4.4 映射冲突与优先级
- 多个源字段映射到同一目标字段时，以第一条有效映射为准。
- 若目标字段自身配置了默认值，映射值会覆盖该默认值。

## 5 在生命周期中使用创建相关记录

配置步骤：
1. 进入 `生命周期 > 状态 > 进入动作`。
2. 选择目标动作类型。
3. 在 `相关记录配置` 中选择 1~3 个配置并保存。

动作类型与可选配置范围：

| 进入动作类型 | 可选配置类型 |
|------------------|------------------|
| 创建相关对象记录 | 相关记录配置 |
| 根据相关对象创建相关对象记录 | 相关记录配置 |
| 创建非相关对象记录 | 非相关记录配置 |
| 根据相关对象创建非相关对象记录 | 非相关记录配置 |

选择范围规则：
- 仅展示“源对象与当前生命周期对象一致”的配置
- 仅展示状态为 `启用` 的配置
- 同时按“动作类型对应的配置类型”过滤

执行效果：
- 记录进入目标状态时，系统自动创建目标对象记录并执行字段映射
- 若动作配置多条，系统按配置顺序依次执行

---

## 6 系统字段处理

自动创建相关记录时，系统字段按以下规则处理：

| 字段 | Code | 处理方式 |
|------|----|------------|
| 状态 | `status&#95;id&#95;&#95;sys` | 使用目标对象初始状态。 |
| 记录状态 | `state&#95;&#95;ak` | 默认启用。 |
| 创建时间 | `created&#95;time&#95;&#95;sys` | 记录创建成功时间。 |
| 创建人 | `created&#95;by&#95;&#95;sys` | 若有映射则按映射值；否则默认取源记录创建人。 |
| 更新时间 | `modified&#95;time&#95;&#95;sys` | 初始与创建时间一致。 |
| 更新人 | `modified&#95;by&#95;&#95;sys` | 初始与创建人一致。 |

## 7 复制相关记录配置

使用场景：源对象和目标对象关系一致，仅需调整部分映射字段时，可通过复制减少重复配置。

操作入口：
- 列表页行操作 \> `复制`

复制后默认行为：
- 状态：启用
- 配置类型：与原配置一致
- 源对象/源对象类型/目标对象/相关对象类型：与原配置一致
- 描述：复制原描述
- 字段值映射：复制原映射明细

## 8 常见失败场景与排查

| 现象 | 常见原因 | 处理建议 |
|------|------------|------------|
| 自动创建失败 | 目标对象必填字段未映射且无默认值 | 补齐字段映射或设置源字段默认值。 |
| 自动创建失败 | 目标字段存在唯一性约束冲突 | 调整映射规则，避免重复值写入唯一字段。 |
| 配置不可停用/删除 | 当前配置已被生命周期或流程引用 | 先解除引用，再执行停用或删除。 |
| 自动创建结果不符合预期 | 多条映射写入同一目标字段 | 检查映射顺序与重复目标字段配置。 |
| 进入动作下拉中看不到配置 | 进入动作类型与配置类型不匹配 | 检查动作类型是否应选择“相关对象”或“非相关对象”版本。 |

触发失败时，系统通常提示：`相关记录自动创建失败，请检查配置`。

---

## 9 配置建议
1. 优先保证目标对象“必填且无默认值”字段全部有映射来源。
2. 一条进入动作建议先使用单个相关记录配置，验证通过后再扩展多配置。
3. 使用复制功能时，重点复核 `Code`、状态和关键映射字段，避免误用旧配置。
4. 对数字、日期时间、对象类型字段，保存前先检查类型兼容与格式约束。
