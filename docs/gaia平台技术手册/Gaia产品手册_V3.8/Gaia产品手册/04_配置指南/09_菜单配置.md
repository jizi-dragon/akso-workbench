# 菜单配置
> 本文用于指导配置管理员在 Gaia 平台中创建、编辑、排序和维护菜单（Tab），并说明不同菜单类型的配置差异与生效结果。   

---

## 概述

菜单是业务端主导航入口。通过菜单配置，可以把对象列表、外部链接和菜单分组组织成可用的导航结构。

### 适用场景

| 场景 | 是否适用 |
|------|------------|
| 需要为不同角色提供不同导航入口 | ✅ |
| 需要把对象记录入口放到主导航 | ✅ |
| 需要把外部系统入口放到主导航 | ✅ |

### 管理入口

`管理端 > 配置管理 > 菜单`

---

## 前提条件

在开始配置前，请确保：
- 已具备权限：`管理端 > 菜单：全部`。
- 已明确菜单用途（对象入口、外部链接、还是菜单分组）。
- 若创建对象菜单，目标对象与相关布局已可用。

---

## 页面结构与可执行操作

菜单页面采用“左侧树 \+ 右侧详情”的结构。

### 左侧菜单树

| 操作 | 用途 | 操作结果 |
|------|------|------------|
| **全部展开** | 展开当前菜单树 | 左侧显示全部层级节点 |
| **全部收起** | 收起当前菜单树 | 左侧仅保留收起状态 |
| **创建** | 新增菜单 | 在右侧进入新建流程 |
| **添加子菜单** | 在当前菜单下新增下级菜单 | 新建页自动带入上级菜单 |
| **添加同级菜单** | 在当前菜单同一层级新增菜单 | 新建页自动带入相同上级菜单 |
| **编辑** | 修改当前菜单 | 在右侧进入编辑状态 |
| **删除** | 删除当前菜单 | 触发删除确认与校验 |
| **排序** | 调整菜单顺序与层级 | 进入拖拽排序模式 |

### 右侧详情区

右侧用于查看和维护当前菜单配置，常见字段包括：`名称`、`Code`、`状态`、`来源`、`菜单类型`、`对象`、`列表布局`、`创建表单布局`、`对象类型`、`设置创建记录方式`、`打开记录方式`、`链接地址`、`打开链接方式`、`下级展示方式`。

---

## 数量与结构限制

| 规则 | 说明 |
|------|------|
| 一级菜单数量 | 最多 20 个（包含标准菜单） |
| 标准菜单删除 | 首页菜单不允许删除 |
| 子菜单数量 | 每个父级菜单最多 20 个子菜单 |
| 菜单名称长度 | 最长 20 个字符 |
| 链接长度 | 最长 2000 个字符，保存时校验格式 |

---

## 创建菜单

### 操作步骤
1. 进入 `管理端 > 配置管理 > 菜单`。
2. 点击 **创建**，进入菜单新建状态。
3. 填写基础信息。
4. 根据菜单类型完成对应配置。
5. 点击 **保存**。

### 基础字段说明

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| **名称** | 是 | 菜单显示名称，最长 20 个字符。 |
| **Code** | 是 | 菜单唯一编码。 |
| **状态** | 是 | 控制菜单启用或停用。 |
| **上级菜单** | 否 | 为空表示一级菜单；可选范围仅为“菜单类型=菜单”的菜单项。 |
| **菜单类型** | 是 | 可选：对象 / 链接 / 菜单。 |

### 菜单类型配置

#### 1\. 对象

选择 **对象** 类型后：
- 需要先选择目标对象（必填）。
- 可进一步配置列表布局、创建表单布局、对象类型、创建记录方式与打开记录方式。

对象类型菜单常见字段如下：

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| **对象** | 是 | 选择该菜单对应的业务对象。 |
| **列表布局** | 否 | 指定用户通过菜单进入对象后默认使用的列表布局。 |
| **创建表单布局** | 否 | 指定用户点击创建时默认使用的创建表单布局。 |
| **对象类型** | 否 | 当对象启用对象类型能力时可选，用于限定菜单默认对象类型。 |
| **设置创建记录方式** | 否 | 控制用户从该菜单发起“创建记录”时的交互方式。支持：在新开页面创建、在当前页面创建、在弹出层中创建、在抽屉中创建、不允许创建。 |
| **打开记录方式** | 否 | 控制用户从列表进入记录详情时的打开方式。支持：在当前标签页打开、在新的标签页打开、在弹出层中打开、在抽屉中打开。 |

#### 2\. 链接

选择 **链接** 类型后：
- 需要配置链接地址类型（公式 / 指定常量）。
- 可配置打开链接方式（在新的标签页打开 / 在当前标签页打开）。

链接类型菜单常见字段如下：

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| **链接地址** | 是 | 选择链接地址配置方式。可选：`公式`、`指定常量`。 |
| **打开链接方式** | 否 | 控制点击菜单后链接的打开位置。可选：`在新的标签页打开`、`在当前标签页打开`。 |

链接地址支持两种配置方式：

| 配置方式 | 说明 |
|------------|------|
| **公式** | 通过公式生成链接地址，适用于需要按规则拼接链接的场景。 |
| **指定常量** | 直接配置固定 URL。 |

当使用“指定常量”时，系统会在保存时校验 URL 格式与长度（不超过 2000 字符）。

#### 3\. 菜单

选择 **菜单** 类型后：
- 当前项作为父级菜单分组使用。
- 可在其下继续创建子菜单。
- 可配置下级展示方式，控制子菜单在导航中的呈现形态。

菜单类型菜单常见字段如下：

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| **下级展示方式** | 否 | 控制下级菜单展示形态。可选：`菜单`、`Tab页签`。 |

下级展示方式说明：

| 展示方式 | 说明 |
|------------|------|
| **菜单** | 下级按层级菜单方式展示。 |
| **Tab页签** | 下级以 Tab 页签方式展示，便于同层级快速切换。 |

### 创建记录方式与打开记录方式

对象类型菜单可配置“创建记录方式”：

| 方式 | 用户点击“创建”后的行为 |
|------|------------------------------------|
| **在新开页面创建** | 在新页面打开创建页。 |
| **在当前页面创建** | 在当前页面直接进入创建态。 |
| **在弹出层中创建** | 在当前页面以弹出层方式完成创建。 |
| **在抽屉中创建** | 在当前页面以抽屉方式完成创建。 |
| **不允许创建** | 不显示创建入口 |

“打开记录方式”用于控制用户从对象列表进入记录详情时的展示方式，可选项如下：

| 方式 | 用户点击记录后的行为 |
|------|------------------------------|
| **在当前标签页打开** | 在当前标签页直接进入记录详情。 |
| **在新的标签页打开** | 在浏览器新标签页打开记录详情。 |
| **在弹出层中打开** | 在当前页面以弹出层方式打开记录详情。 |
| **在抽屉中打开** | 在当前页面以抽屉方式打开记录详情。 |

## 查看与编辑菜单

### 查看菜单

点击左侧菜单节点后，右侧展示该菜单详情。可在详情区查看配置值，并从操作入口继续维护。

### 编辑菜单

进入方式：
1. 左侧节点操作菜单点击 **编辑**。
2. 右侧详情区域点击 **编辑**。

编辑行为说明：
- 支持修改上级菜单。
- 对象菜单在切换对象后，关联的列表布局选项会清空，需重新选择。
- 切回此前对象时，可恢复该对象已有的布局选项。

### 添加同级/子级菜单
- **添加同级菜单**：在当前菜单同一层级新增菜单。
- **添加子级菜单**：在当前菜单下新增下级菜单，系统会自动带入上级菜单值，允许手动修改。

---

## 菜单排序
1. 点击 **排序** 进入排序模式。
2. 拖拽菜单项调整顺序。
3. 支持跨父级拖拽，即可通过拖拽改变菜单项上级菜单。
4. 保存后新顺序立即用于导航展示。

---

## 删除菜单

删除入口：
- 左侧菜单树中的 **删除**。
- 详情页中的 **删除**。

删除规则：
- 删除前会弹出确认框。
- 首页等标准菜单不可删除。

---

## 菜单超长显示

当一级菜单在一行内无法完整展示时，系统会自动进入“收起”状态。用户点击收起按钮或收起按钮获得焦点后，可展开查看被收起的菜单项。

---

## 异常处理与审计追踪

当前菜单配置页未提供独立的异常处理和审计追踪说明。

---

## 最佳实践
1. 一级菜单优先按业务域分组，减少平铺数量。
2. 对象菜单命名建议使用“业务名词 \+ 列表/台账/管理”。
3. 链接菜单上线前先验证 URL 可达性与目标系统权限。
4. 调整层级前先梳理导航树，避免频繁跨级拖拽。
