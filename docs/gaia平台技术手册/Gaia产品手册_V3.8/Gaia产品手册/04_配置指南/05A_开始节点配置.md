# 开始节点配置

开始节点用于定义工作流发起时需要补充和确认的信息，并决定发起页是否展示输入控件。

在配置页面中，常见路径为：`工作流 > {工作流名称} > 节点: 开始`。页面结构通常分为 `详情`、`开始设置`、`开始步骤规则` 三个区块。

---

## 页面结构

| 区块 | 用途 | 说明 |
|------|------|------|
| **详情** | 查看与维护节点基础信息 | 用于确认当前节点身份与说明信息。 |
| **开始设置** | 配置发起页控件与输入项 | 决定发起页需要用户填写什么信息。 |
| **开始步骤规则** | 按条件动态控制控件显示 | 根据当前对象字段决定控件显示或隐藏。 |

---

## 详情

`详情` 区块用于维护开始节点的基础信息（如节点名称、说明等）。

这一部分主要用于识别和管理节点本身，不直接决定发起页展示哪些输入项。发起页的实际输入内容由 `开始设置` 和 `开始步骤规则` 共同决定。

---

## 开始设置

`开始设置` 用于配置发起页控件。开始节点可以组合多个控件，发起页最终展示的输入项取决于这里实际添加的控件。

如果开始节点未配置任何控件，流程在发起后会直接进入后续节点，不会停留在发起页等待输入。

### 可添加的控件类型

| 控件类型 | 用途说明 | 典型使用场景 |
|------------|------------|------------------|
| **说明** | 在发起页显示文字说明。 | 提示填写要求、发起条件或注意事项。 |
| **参与者** | 收集或带出流程参与人。 | 指定审批人、会签人、处理人等。 |
| **日期** | 让发起人填写日期类信息。 | 计划完成日期、生效日期、期望完成时间。 |
| **字段** | 展示或采集业务对象字段值。 | 发起时补充或确认对象字段内容。 |
| **变量** | 采集流程运行时变量。 | 为后续判断节点、动作节点或通知模板提供输入值。 |
| **电子签名** | 要求发起人在发起时完成电子签名。 | 需要在发起环节做合规确认或责任确认。 |

### 参与者添加方式

| 类型 | 说明 | 适用场景 |
|------|------|------------|
| **工作流发起人选择参与者** | 发起人启动流程时手工选择参与人。可结合允许/不允许参与角色限制候选范围。 | 需要发起人按业务情况指定审批人。 |
| **使用角色作为参与者** | 系统按角色自动带出用户作为参与人。 | 标准审批流、固定角色分工场景。 |
| **使用自定义动作定义参与者** | 通过自定义动作动态计算参与人。 | 参与人需按业务规则实时计算。 |
| **使用字段作为参与者** | 从当前业务记录中的人员类字段读取参与人。 | 参与人已维护在对象字段中。 |
| **使用审批矩阵作为参与者** | 根据审批矩阵规则匹配参与人。 | 按组织、条件或层级自动匹配审批人。 |

### 参与者控件常见配置项

| 配置项 | 用途说明 | 配置结果 |
|---------|------------|------------|
| **控件类型** | 当前控件类型。参与者控件固定为 `参与者`。 | 用于确认当前编辑的是人员选择控件。 |
| **Code** | 参与者控件系统编码。 | 便于流程内部引用与后续维护。 |
| **参与者名称** | 发起页显示名称。 | 发起人据此判断当前应选择哪类人员。 |
| **添加参与者** | 指定参与者生成方式。 | 决定手工选择或自动带出逻辑。 |
| **允许参与的角色** | 限定候选角色范围。 | 仅允许范围内角色/用户进入候选列表。 |
| **不允许参与的角色** | 从候选范围排除指定角色。 | 被排除角色不会出现在选择结果中。 |
| **选择角色后再选用户** | 先选角色再选具体用户。 | 在角色和人员较多时缩小选人范围。 |
| **支持按用户组选参与人** | 允许按用户组选择参与人。 | 发起人可按用户组快速挑选人员。 |
| **排除工作流发起人** | 将发起人排除出候选范围。 | 发起人不能把自己加入该参与者控件。 |
| **业务单元字段** | 用于按业务单元限制候选范围。 | 系统按当前记录业务单元信息过滤参与人。 |
| **列表布局** | 指定选人弹窗列表布局。 | 候选列表字段列和显示顺序按布局展示。 |
| **过滤条件** | 追加候选筛选条件。 | 仅满足条件的人员进入可选列表。 |

## 开始步骤规则

`开始步骤规则` 用于通过条件动态控制开始节点控件在发起页中的显示或隐藏。规则条件基于**当前对象字段**，规则命中后可对指定控件执行“显示”或“隐藏”动作。

### 规则列表字段

| 列 | 说明 |
|---|------|
| **描述** | 规则说明文字，便于识别规则用途。 |
| **规则** | 规则执行条件，例如 `总是执行` 或字段条件表达式。 |
| **动作** | 命中后执行的动作与目标控件。 |
| **操作** | 编辑、调整或删除当前规则。 |

### 新建规则常见配置项

| 配置项 | 说明 | 配置结果 |
|---------|------|------------|
| **描述** | 规则文字说明。 | 便于在规则列表中快速识别规则作用。 |
| **执行方式** | 可选 `总是执行` 或 `有条件地执行`。 | 决定规则是无条件生效，还是命中条件才生效。 |
| **动作类型** | 选择动作类型（如 `显示`、`隐藏`）。 | 决定规则命中后系统对控件做什么处理。 |
| **操作名称** | 选择动作作用控件。 | 决定具体影响哪个开始节点控件。 |
| **添加动作** | 在同一条规则中继续追加动作。 | 一条规则可同时控制多个控件。 |

说明：
- 当 `执行方式` 选择 `有条件地执行` 时，需要配置字段条件；仅命中条件时才执行动作。
- 在**批量工作流**中，规则按记录集合整体判断：只有所选记录全部命中条件时，规则才生效；只要存在任一记录未命中，规则即不生效。
- 如果需要按业务场景动态展示发起页控件，优先使用 `开始步骤规则`，避免为同一流程重复创建多个近似开始节点。
