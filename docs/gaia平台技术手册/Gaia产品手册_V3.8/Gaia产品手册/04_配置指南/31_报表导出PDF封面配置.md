# 报表导出 PDF 封面配置
> 在页面模板中启用报表封面模版后，导出 PDF 格式报表时，系统会把封面页放在第一页，报表正文从封面后开始。

## 功能说明

报表封面模版用于统一 PDF 报表的首页样式。封面可以展示报表名称、导出用户、导出时间、过滤条件等信息，也可以在模板文件中设置水印、页眉页脚和横版 / 竖版。

该配置只影响 PDF 导出。导出 Excel、CSV 等格式时，不生成封面。

---

## 配置步骤

### 1\. 新建页面模板

进入 `配置端 > 页面模板`，新建页面模板。

填写以下参数：

| 参数 | 说明 |
|------|------|
| 所属业务单元 | 选择模板所属的业务单元。 |
| 名称 | 填写模板显示名称，例如 `PDF 报表封面模板`。 |
| Code | 填写模板编码，页面保存时按平台规则显示 `&#95;&#95;c` 后缀。 |
| 类型 | 选择 `报表封面模版`。该选项位于类型下拉框最后。 |
| 状态 | 需要立即生效时选择 `启用`；暂不使用时选择 `停用`。 |
| 描述 | 可填写模板用途或维护说明。 |

### 2\. 上传默认模板

在 `默认模板` 区域点击 `上传`，选择封面模板文件。上传成功后，文件会显示在默认模板区域；如果仍显示 `暂无数据`，需要重新上传。

模板文件中的字体、段落、表格、图片、水印、页眉页脚和页面方向会在导出时保留。后续需要调整封面样式时，修改模板文件后重新上传即可。

### 3\. 在模板中放置变量

在默认模板文件中放置需要展示的变量。导出 PDF 时，系统按当前报表和导出上下文替换变量值。

| 变量 | 导出时解析为 |
|------|------------------|
| 当前用户 | 执行导出的用户。 |
| 当前时间 | 执行导出的时间。 |
| 属性 | 报表或报表数据中可用于封面展示的属性值。 |
| 过滤条件 | 导出时使用的筛选条件。 |
| 报表名称 | 当前导出的报表名称。 |
| 总页数 | 生成 PDF 后的总页数。 |

### 4\. 保存并启用模板

点击 `保存`。如果模板状态为 `启用`，系统会检查是否已有其他启用的报表封面模版。

系统只允许一个启用状态的报表封面模版。新建模板或把停用模板改为启用时，如果已存在启用模板，保存失败并提示：
```text
只能启用一个报表封面模版。
```

需要启用新的封面模板时，先停用当前启用模板，再启用新的模板。

### 5\. 验证导出效果

打开一个报表并导出 PDF。导出后检查以下内容：
- PDF 第一页是否为封面页。
- 报表正文是否从封面后开始。
- 当前用户、当前时间、过滤条件、报表名称等变量是否已替换。
- 水印、页眉页脚、横版 / 竖版是否符合模板设置。

## 生效规则

| 规则 | 说明 |
|------|------|
| 生效范围 | 仅适用于报表导出 PDF。 |
| 封面位置 | 固定为 PDF 第一页。 |
| 模板数量 | 同一时间只能有一个启用状态的报表封面模版。 |
| 无启用模板 | PDF 报表按原逻辑导出，不增加封面。 |
| 模板修改 | 只影响后续导出的 PDF，已导出的文件不会变化。 |

---

## 常见问题

### Q1：为什么导出的 PDF 没有封面？

检查导出格式是否为 PDF、页面模板类型是否为 `报表封面模版`、状态是否为 `启用`，以及默认模板文件是否已上传。

### Q2：能否为不同报表设置不同封面？

当前为全局报表封面配置。系统只允许一个启用状态的报表封面模版，不支持按单个报表分别指定封面。
