# 查重规则配置
> 本文介绍如何在 Gaia 平台中配置和管理记录查重规则，帮助用户识别同一对象不同记录之间的相似度，减少重复数据。

## 概述

查重规则用于帮助用户识别同一对象中不同记录之间的相似度。系统通过对比字段值计算记录间的相似程度，支持精确匹配和模糊匹配两种方式，并按相似度分层统计结果。

### 典型使用场景
- **重复偏差识别**：调查偏差时，快速发现历史上是否已存在相似偏差，判断是否为重复事件
- **重复事件分析**：在质量事件发起时自动识别与历史事件的重复程度，避免重复调查
- **数据质量管理**：定期检查对象记录，发现潜在的重复数据

### 访问路径

**配置端** \> **配置管理** \> **对象管理** \> **查重规则**

### 配置概览

配置查重功能需要完成以下三个步骤：
1. **创建查重规则**：为目标对象定义匹配字段、匹配方式和结果展示规则
2. **配置用户动作**：为对象添加类型为"查重"的用户动作，供业务端用户触发

## 1\. 查重规则列表

进入查重规则页面后，系统以列表形式展示所有已创建的查重规则。

| 列表字段 | 说明 |
|------------|------|
| **名称** | 规则名称，可点击进入详情页 |
| **Code** | 规则的唯一编码 |
| **状态** | 启用 / 停用 |
| **对象** | 关联的目标对象，可点击进入对象详情 |
| **描述** | 规则的用途描述 |
| **操作** | 编辑、启用/停用、删除 |
> 💡 **提示**：列表支持按名称关键词搜索，按创建时间倒序排列。

## 2\. 创建查重规则

### 2.1 基本信息

| 属性 | 控件类型 | 说明 |
|------|------------|------|
| **名称** | 文本框 | 必填，1-200 字符，规则的显示名称 |
| **Code** | 文本框 | 必填，1-200 字符，唯一编码（保存后不可修改） |
| **状态** | 单选 | 启用 / 停用，默认启用 |
| **对象** | 单选 | 必填，选择要应用查重的目标对象（保存后不可修改） |
| **描述** | 多行文本 | 非必填，0-500 字符 |

### 2.2 范围设置

范围设置用于限定查重的数据对比范围。

| 属性 | 控件类型 | 说明 |
|------|------------|------|
| **对比时间字段** | 单选 | 选择对象上的日期或日期时间字段，用于限定时间范围 |
| **对比时间范围 - 数值** | 数字框 | 0-100 的整数，如"12" |
| **对比时间范围 - 单位** | 单选 | 年 / 月 / 日，默认"年" |
| **允许重新选择** | 复选框 | 勾选后，用户在业务端发起查重时可重新设置数据查询范围 |
| **数据范围** | 条件编辑器 | 设置额外的数据筛选条件 |
> 💡 **示例**：对比时间字段选择"创建时间"，范围设为"1 年"，表示只对比最近 1 年内创建的记录。   

### 2.3 查询条件

查询条件定义了用于对比的字段和匹配方式。**可添加多个查询条件**，每个条件对应业务端的一种查重类型。

| 属性 | 说明 |
|------|------|
| **名称** | 条件名称，会在业务端显示供用户选择（支持多语言） |
| **Code** | 条件的唯一编码 |
| **匹配字段** | 选择参与对比的字段 |
| **匹配方式** | 根据字段类型选择对应的匹配方式（见下表） |
| **空值匹配方式** | 设置双方都为空时的处理方式 |

#### 字段匹配方式

| 匹配方式 | 适用字段类型 | 说明 |
|------------|------------------|------|
| **精确匹配** | 非文本字段 | 值完全相等才算匹配 |
| **模糊匹配** | 文本字段 | 计算文本相似度（基于文本分析算法） |
| **包含下级** | 树形对象字段 | 值相等，或包含所有下级节点均算匹配 |
| **包含子级** | 树形对象字段 | 值相等，或包含直接子级均算匹配 |
| **存在相同选项** | 选项字段 | 值相等，或存在相同的选项 |
| **包含待匹配的选项** | 选项字段 | 值相等，或包含待匹配记录的选项 |
| **包含于待匹配的选项** | 选项字段 | 值相等，或被包含于待匹配记录的选项 |

#### 空值处理方式

| 处理方式 | 说明 |
|------------|------|
| **匹配空值** | 双方字段均为空时纳入查询范围，计算分数为 1（视为匹配） |
| **不匹配空值** | 双方字段均为空时纳入查询范围，但计算分数为 0（不视为匹配） |

### 2.4 查询设置（结果分层统计）

查重结果支持按相似度分层统计，最多可设置 **3 个等级**。

| 属性 | 说明 |
|------|------|
| **识别结果数据量上限** | 必填，1-200，返回的最大匹配记录数（系统上限为 20）。右侧可配置「允许重新选择」 |
| **识别结果相似度下限** | 0-100 整数；相关度阈值下限，`0` 表示无下限要求。右侧可配置「允许重新选择」 |
| **等级显示名称** | 必填，该等级的显示名称（如"高度相似"、"中度相似"、"低度相似"） |
| **最小相似度分值** | 必填，1-100（支持 2 位小数），下一等级不能大于上一等级 |
| **显示** | 复选框，默认选中，控制该等级是否在结果页面显示 |

#### 允许重新选择（业务端可调）

识别结果数据量上限与识别结果相似度下限需同时满足，共同约束返回条数。两项各自独立配置「允许重新选择」：

| 配置项 | 默认 | 说明 |
|---------|------|------|
| 识别结果数据量上限 - 允许重新选择 | 关闭 | 开启后，业务端发起识别时可重新设置显示数量，默认带出管理端当前值 |
| 识别结果相似度下限 - 允许重新选择 | 关闭 | 开启后，业务端发起识别时可重新设置相关度下限，默认带出管理端当前值 |

生效逻辑：
1. 若对应项勾选了「允许重新选择」且用户在业务端重新设置，使用业务端值；否则使用管理端配置值。
2. 按相关度从高到低排序，先按数据量上限截取，再过滤低于相似度下限的候选结果。
3. 开关关闭时，业务端不能重新设置，行为与升级前一致。

## 3\. 编辑与管理规则

### 编辑规则
- **Code** 和 **对象** 字段保存后不可修改
- 其他所有字段均可编辑

### 删除规则
- 删除前需要二次确认
- 如果规则已被用户动作引用，则无法删除，系统提示"该规则已使用，不能删除"

### 启用 / 停用
- 仅**启用**状态的规则可以在业务端使用
- 停用规则不影响已产生的查重结果数据

## 4\. 配置在详情页展示查重记录和结果

配置完成后，用户可以在对象记录详情页中查看查重相关信息。建议在表单布局中同时配置以下两种部分类型：

| 部分类型 | 用途 | 关联关系说明 |
|------------|------|------------------|
| **重复识别发起记录** | 显示当前业务记录发起过的查重任务记录（发起时间、发起人、任务状态等） | 与**当前业务记录**关联，用户可先在这里定位一次查重任务，再进入对应的查重结果 |
| **重复识别结果** | 显示某次查重任务产出的重复识别结果明细（相似度、匹配记录、处理结论等） | 与**重复识别发起记录**关联，通常从“重复识别发起记录”进入某次任务后查看其结果明细 |

#### 表单布局配置建议
1. 在记录详情页先放置 **重复识别发起记录** 部分，作为任务入口。
2. 在同一详情页放置 **重复识别结果** 部分，用于展示所选任务的结果明细。
3. 两者配合后，用户可以按“记录 -\> 任务 -\> 结果”的路径追溯每次查重过程和结论。

---

## 5\. 配置用户动作

创建好查重规则后，需要为对象配置用户动作，使业务端用户可以触发查重。
1. 进入 **配置端** \> **对象配置** \> 选择目标对象
2. 进入 **生命周期** \> 选择目标状态 \> **用户动作**
3. 点击 **创建**，选择动作类型为 **查重**
4. 选择关联的查重规则
5. 保存

配置完成后，拥有权限的用户在业务端可以通过点击该动作按钮发起查重。

---

## 6\. 业务端使用流程

### 6.1 发起查重

用户在业务端记录详情页点击查重动作按钮后，系统会检查当前记录是否已有查重任务：

| 场景 | 系统行为 |
|------|------------|
| **不存在查重任务** | 进入查重设置界面，用户选择条件后发起查重 |
| **存在进行中的任务** | 提示已有任务正在执行，可选择"重新识别"或等待 |
| **存在已完成的任务** | 直接展示上次结果，可选择"重新识别"、"取代最新"或"取代所有" |

#### 查重设置界面
1. **选择类型**：单选，对应查重规则中配置的查询条件
2. **设置数据查询范围**：如果规则勾选了"允许重新选择"，用户可调整时间范围
3. **调整结果数量 / 相关度下限**：若查询设置中对应项勾选了「允许重新选择」，可在发起识别时重新设置识别结果数据量上限或识别结果相似度下限（默认带出管理端配置值）
4. **添加额外条件**：可在已有匹配字段基础上追加查询条件（不可与已有字段重复）
5. 点击 **确认** 后创建查重任务
> ⚠️ **注意**：查重是异步后台任务，同一条记录不能同时发起多个查重任务。   

### 6.2 查看查重结果

查重完成后，结果页面包含以下内容：

**顶部统计区域**：
- 显示各等级的匹配数量（如"高度相似: 3 条，中度相似: 5 条"）
- 统计项可点击，点击后筛选显示对应等级的记录
- 各等级用不同颜色区分

**详情列表**：

| 区域 | 说明 |
|------|------|
| **基本信息** | 相似度分值、记录名称、对比时间字段值、处理结论 |
| **对比字段** | 查询条件中的匹配字段值，文本字段中匹配的部分高亮显示，完全匹配的字段显示匹配图标 |
| **显示字段** | 规则中配置的额外显示字段 |

**处理结论**：
- 在基本信息区域，"处理结论"为行内编辑下拉框
- 可选值来源于规则的关系配置中设置的关系性质
- 选择结论后，系统自动将对应记录的状态修改为关系配置中设置的目标状态

## 7\. 权限说明

查重规则的管理权限属于 **管理端权限**。

| 权限 | 控制内容 |
|------|------------|
| 查重规则：查看 | 查看查重规则列表和详情 |
| 查重规则：全部 | 创建新的查重规则，编辑查重规则配置，包括启用/停用，删除查重规则 |
> 💡 **提示**：业务端用户是否可以发起查重，取决于用户动作的权限配置（在权限集和生命周期状态权限中设置）。

## 8\. 最佳实践
1. **合理选择匹配字段**：选择能有效区分记录的关键业务字段，避免选择过多字段导致匹配度偏低
2. **文本字段用模糊匹配**：描述类文本字段建议使用模糊匹配，系统会自动计算文本相似度
3. **设置合理的时间范围**：根据业务需求设置对比时间范围，避免范围过大影响查重效率
4. **分层统计便于决策**：合理设置相似度等级阈值，如"高度相似 ≥ 80"、"中度相似 ≥ 50"，帮助用户快速定位重点记录
5. **控制结果数量**：识别结果上限不建议设置过大（系统最大 20 条），聚焦高相似度记录

## 9\. 常见问题

**Q: 查重任务需要多长时间？** A: 查重为异步后台任务，执行时间取决于对比范围内的记录数量和匹配字段数量。通常几秒到几分钟不等，用户可以关闭弹窗后继续其他操作，任务会在后台继续执行。

**Q: 同一条记录可以同时发起多个查重任务吗？** A: 不可以。同一条记录同一时间只能有一个查重任务在执行。如需重新查重，需等待当前任务完成后再选择"重新识别"。

**Q: 查重结果最多返回多少条？** A: 通过"识别结果数据量上限"配置，最大不超过 20 条。

**Q: 删除查重规则会影响已有的查重结果吗？** A: 如果规则已被引用（已有用户动作关联），则无法删除。已产生的查重结果数据不受规则停用的影响。

**Q: 选项字段的多种匹配方式有什么区别？** A: 以偏差分类字段为例（假设当前记录值为"A, B"）：
- **存在相同选项**：对比记录含 A 或 B 中任一项即匹配
- **包含待匹配的选项**：对比记录同时包含 A 和 B 才匹配
- **包含于待匹配的选项**：对比记录的选项全部在 A、B 范围内才匹配
