> 本文介绍如何在 Gaia 平台中配置对象本身，重点覆盖对象列表、创建对象、对象详情与对象编辑。字段、关系、布局、对象类型和共享规则等专题已拆分为独立文档。   

---

## 概述

对象是 Gaia 平台中的核心配置单元，用于承载业务实体，并作为字段、关系、布局、动作、生命周期等配置的基础。

在对象设计前，建议先梳理当前对象与其他对象之间的关系：
- 引用关系中的两个对象可以独立存在
- 父子关系中的子对象不能脱离父对象独立存在
- 如果两个对象是多对多关系，通常需要建立中间对象来管理关系

### 访问路径

`配置端 > 配置管理 > 对象管理 > 对象`

---

## 1\. 对象列表

对象列表页用于展示系统中已有对象，并作为创建、查看详情和进入后续管理操作的统一入口。

列表页通常展示以下信息：

| 列 | 说明 |
|---|------|
| 名称 | 对象名称，点击后可进入详情页 |
| Code | 对象唯一编码 |
| 来源 | 标识对象来源，如系统、标准、自定义 |
| 生命周期 | 当前对象关联的生命周期 |
| 父对象 | 当前对象的父对象；仅在存在父子关系时显示 |
| 操作 | 打开对象的管理操作入口 |

对象来源分为 `系统`、`标准`、`自定义`：
- 系统对象由平台创建和维护，不开放常规修改
- 标准对象由平台或应用预置，通常仅开放部分配置能力
- 自定义对象由管理员按业务需要创建和维护

---

## 2\. 创建对象

在对象列表页点击右上角 `创建` 后，可进入对象创建页。

创建对象页面顶部通常提供以下导航和操作：

| 控件 | 作用 |
|------|------|
| 面包屑导航 | 用于显示当前所在路径，通常为 `配置端 &gt; 配置管理 &gt; 对象管理 &gt; 对象 &gt; 创建`，帮助用户确认自己正在对象管理下创建新对象，并可通过前面的层级快速返回上一级页面 |
| `返回` | 返回对象列表页或上一层页面；若当前已填写内容但尚未保存，通常需要先确认是否放弃本次创建 |
| `保存` | 按当前填写内容创建对象；保存成功后，系统会生成新的对象记录，并进入对象详情页或停留在可继续查看结果的页面 |

### 2.1 详情区域

| 属性 | 说明 |
|------|------|
| 对象名称 | 必填，用于定义对象名称 |
| Code | 必填，用于定义对象编码；自定义对象保存后带 `&#95;c` 后缀 |
| 状态 | 默认显示为 `启用` |
| 来源 | 当前页面显示为 `自定义` |
| 对象类别 | 当前页面支持选择，默认显示为 `基础`；不同类别对应不同的平台能力和对象用途 |
| 描述 | 用于补充对象说明 |

#### 对象类别选项说明

对象类别用于标识对象的业务定位。除 `基础` 外，其它类别通常服务于特定平台能力，建议仅在明确知道该能力用途时选择。

| 选项 | 含义 | 适用说明 |
|------|------|------------|
| 基础 | 通用业务对象类别，用于承载常规业务主数据、业务单据或配置对象 | 大多数自定义对象使用该类别；如无专项能力要求，优先选择此项 |
| 用户任务 | 用于承载系统分配给用户的任务/待办数据 | 适用于工作流任务、首页用户任务、任务完成跟踪等系统任务场景 |
| 用户动态角色管理 | 用于动态权限控制（DAC）场景，保存“用户/用户组 \+ 角色 \+ 条件字段”的权限映射关系 | 在产品方案中对应“用户角色设置”类对象；通常与匹配共享规则、自定义共享规则配合使用 |
| 审批矩阵管理 | 用于承载审批矩阵规则数据，按条件组合不同审批角色，形成可匹配的审批矩阵 | 通常由审批矩阵配置自动生成，用于业务侧管理审批矩阵规则 |
| 审批矩阵职位 | 用于承载审批矩阵中的职位/角色明细、顺序和人数约束 | 一般作为审批矩阵管理对象的下层明细对象，用于定义每个矩阵角色如何参与审批 |
| 检验项目 | 用于维护检验项目主数据，如项目名称、检验方法、标准或限度等 | 适用于检验标准、检测项目、项目模板等场景，为检验结果录入提供基础项目定义 |
| 检验结果 | 用于承载具体检验结果数据，支持录入、导入、汇总和后续追溯 | 适用于质量检验结果记录、检验结果批量导入、结果汇总等场景，通常与检验项目配套使用 |

补充说明：
- `用户动态角色管理` 属于专项对象类别，主要用于权限映射，不建议作为普通业务对象使用。
- `审批矩阵管理` 和 `审批矩阵职位` 属于审批矩阵能力相关类别，通常与审批矩阵配置联动。
- `检验项目` 和 `检验结果` 属于检验数据模型相关类别，更适合质量检验、实验室或监测数据场景。
- 如果对象需要使用大容量存储，`对象类别` 仅支持 `基础`。

术语对照说明：
- 界面中的 `用户动态角色管理`，在相关产品方案中更常见的表述是 `用户角色设置`。两者都指向 DAC 场景下用于维护“用户/用户组 \+ 角色 \+ 条件字段”映射关系的这类对象。
- 界面中的 `审批矩阵职位`，在相关产品方案中更接近 `审批矩阵角色` 或 `默认职位管理` 这一组能力概念。手册中按界面名称进行说明，实际使用时可结合审批矩阵配置相关文档一起理解。

### 2.2 设置区域

设置区域用于控制对象能力开关。下表仅在“创建对象”章节统一说明；对象详情页中的设置区域主要用于查看当前配置结果。

| 属性 | 勾选或设置后的作用 | 创建后是否可修改 | 备注 |
|------|---------------------------|------------------------|------|
| 是否大容量 | 对象按大容量对象方式创建，用于大数据量场景；页面会隐藏不支持的大容量能力，且对象类别仅支持 `基础` | `否`。对象保存后，数据存储类型不支持再次切换 | 大容量对象的详细限制见 [18\_大容量对象.md](18_%E5%A4%A7%E5%AE%B9%E9%87%8F%E5%AF%B9%E8%B1%A1.md) |
| 受限查询对象 | 仅限制查询能力，其它功能保持不变；勾选后字段不支持分面统计、最多查询 1000 条数据、文本类型字段不支持模糊匹配 | `是`。可反复开启和关闭 | 勾选后，对象字段上的“禁用分面统计”会变为不可编辑；取消后恢复 |
| 在业务管理菜单中显示 | 当前为保留功能，暂未开发，现阶段无实际业务功能 | `是`。可反复开启和关闭 | 在 DAC 匹配共享规则场景下，选择用户角色设置对象后，该开关会自动开启 |
| 启用电子签名 | 开启后，该对象可使用电子签名能力；系统会自动为当前对象创建一个电子签名子对象，并在相关布局中增加电子签名相关内容 | `否`。一旦启用不可禁用 | 电子签名子对象来源为 `系统`，对象名称通常为`{对象名称}电子签名`，Code 规则为 `{对象Code}&#95;esignature&#95;sys`；启用后，工作流中的电子签名操作才会生效。电子签名的详细信息见 [电子签名.md](../../../../%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88/%E5%B9%B3%E5%8F%B0/%E6%96%87%E4%BB%B6%E7%AD%BE%E6%89%B9%E6%94%AF%E6%8C%81%E6%89%8B%E5%86%99%E7%94%B5%E5%AD%90%E7%AD%BE%E5%90%8D.md) |
| 启用审计追踪 | 开启后，该对象的记录变更会写入审计追踪日志 | `否`。开启后不可关闭 | 仅启用了审计追踪的对象才会记录审计日志 |
| 启用对象类型 | 开启后，才可继续为该对象创建和管理对象类型，并可设置默认对象类型 | `否`。一旦开启后不能关闭 | 对象类型的详细说明见 [01E\_对象类型.md](01E_%E5%AF%B9%E8%B1%A1%E7%B1%BB%E5%9E%8B.md) |
| 用于 QRS 数据源 | 用于将当前对象标识为 QRS 数据来源对象；开启后，该对象可在 QRS 的数据集中作为分析数据源使用 | `是`。可反复开启和关闭 | 未开启时，当前对象不能在数据集中作为分析数据源选择 |
| 生命周期 | 开启后自动生成对象生命周期，并支持后续基于生命周期状态和角色配置权限 | `否`。一旦启用后不可关闭 | 启用生命周期的对象才支持 DAC、生命周期角色权限等能力；详细配置说明见 [04\_对象生命周期配置.md](04_%E5%AF%B9%E8%B1%A1%E7%94%9F%E5%91%BD%E5%91%A8%E6%9C%9F%E9%85%8D%E7%BD%AE.md) |
| 开启动态权限控制 | 开启后，可对对象使用动态权限控制能力，并继续配置共享规则相关能力 | `否`。一旦开启后不能关闭 | 共享规则的详细说明见 [01F\_共享规则.md](01F_%E5%85%B1%E4%BA%AB%E8%A7%84%E5%88%99.md) |
| 动态权限控制：启用自定义共享规则 | 开启后，打开对象的自定义共享规则能力；对象详情和业务端会出现与共享设置相关的配置或管理入口 | `是`。可反复开启和关闭 | 需先启用生命周期 |
| 动态权限控制：启用匹配共享规则 | 开启后，可通过匹配规则和用户角色设置对象建立数据权限控制关系 | `是`。可反复开启和关闭 | 需先启用生命周期 |
| 动态权限控制：用户角色设置对象 | 用于选择对象类别为“用户角色设置”的对象，作为匹配共享规则的数据权限桥梁 | `是`。创建后可重新选择 | 选择后，该对象会自动开启“在业务管理菜单中显示” |
| 使用动作安全来控制审计追踪 | 开启后，可以控制审计追踪的权限 | `是`。可反复开启和关闭 | 通过对象动作权限控制审计追踪相关能力 |
| 使用动作安全来控制共享设置 | 开启后，可以控制共享设置的权限 | `是` | 通常与 DAC 配合使用；系统会自动生成来源为系统、不可编辑的“共享设置”动作，取消后会自动删除该动作及其相应权限设置 |
| 启用实例锁定 | 开启后，可对对象实例应用锁定控制 | `是`。可反复开启和关闭 | 详细说明见 [01I\_对象实例锁定.md](01I_%E5%AF%B9%E8%B1%A1%E5%AE%9E%E4%BE%8B%E9%94%81%E5%AE%9A.md) |
| 以编辑模式显示详情 | 开启后，点击该对象实例时会直接进入编辑模式 | `是`。可反复开启和关闭 | 适用于希望用户打开实例后直接编辑数据的场景 |
| 启用所属业务模块 | 开启后，对象记录可关联所属业务模块，用于按模块组织和使用数据 | `否`。一旦开启后不能关闭 | 启用后，对象会支持使用标准选项集 `业务模块`，并提供标准字段 `模块` 用于表示实例所属的业务模块；常用于按模块进行移交、代理，以及在任务视图中按模块展示 |
| 启用实例多语言 | 开启后，系统会自动为该对象创建“内容翻译”记录动作，并可对实例数据进行多语言翻译；取消后会同步移除该动作 | `是`。可反复开启和关闭 | 该功能当前仍不完善，暂不推荐在正式业务场景中使用 |
| 摘要 | 用于配置对象记录的摘要字段，帮助用户在表单、检查表等场景快速理解当前记录的上下文信息 | `是`。可调整已选字段 | 配置后，摘要字段会显示在表单和检查表中；导出检查表时也会包含摘要字段 |
| 导出序号 | 勾选后，该对象作为列表导出发起对象时，导出数据、列表导出 PDF、列表打印 PDF 三种动作均在结果第一列输出 `序号` | `是`。可反复开启和关闭 | 默认不勾选；三种动作共用一个开关，用户端无单独序号选项。导出结果中的编号规则见 [列表导出](../02_%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97/02_%E5%AF%B9%E8%B1%A1%E7%AE%A1%E7%90%86/09_%E5%88%97%E8%A1%A8%E5%AF%BC%E5%87%BA.md) |
| 数据所有权 | 用于定义对象记录的数据归属维度；当前内置 `部门`、`质量组织` 两个维度，可多选 | `部分可修改`。已添加的数据维度不能删除，但后续可以继续新增新的数据维度 | 选择后会自动创建对应的标准字段，如“所属部门”“所属质量组织” |

### 2.3 创建要点
1. 进入 `配置端 > 配置管理 > 对象管理 > 对象`
2. 在对象列表页点击右上角 `创建`
3. 填写详情区域中的必填信息
4. 根据业务需要配置设置区域
5. 点击右上角 `保存`

关于 `是否大容量`：
- 未开启时，对象默认按标准对象创建
- 开启后，对象按大容量对象创建，页面会隐藏不支持的大容量属性
- 大容量对象仅支持 `基础` 类别
- 大容量对象不支持审计追踪、电子签名、DAC、唯一性校验、工作流时间线、验证规则，以及部分字段类型和查询能力
- 对象保存后，数据存储类型不支持再次切换

补充说明：
- 如果对象需要使用大容量存储，建议在创建前先确认是否会用到审计追踪、电子签名、DAC、验证规则等能力，避免创建后无法切换
- 对于共享规则、对象类型等后续配置能力，建议在开启对应开关后继续结合专项文档完成配置

关于 `启用所属业务模块`：
- 启用后，系统使用标准选项集 `业务模块` 管理模块值
- 对象记录会通过标准字段 `模块` 表示所属的业务模块
- `模块` 字段的值类型为选项，引用 `业务模块` 标准选项集
- 该字段通常通过默认值方式赋值，不由用户直接编辑
- 该能力适用于需要按业务模块进行移交、代理或任务展示的场景

关于 `用于 QRS 数据源`：
- 开启后，当前对象可在 QRS 的数据集中被选择为分析数据源
- 关闭后，当前对象不会出现在数据集的数据源可选范围中，不能作为分析数据源使用
- 该开关适用于需要被 QRS 数据集消费和分析的业务对象

## 3\. 对象详情

从列表页进入对象后，可查看对象的基础信息和配置结果。页面顶部通常提供：

| 控件 | 作用 |
|------|------|
| 面包屑导航 | 用于显示当前所在路径，通常为 `配置端 &gt; 配置管理 &gt; 对象管理 &gt; 对象 &gt; {对象名称}`，帮助用户确认当前查看的是哪个对象，并可通过前面的层级快速返回对象列表或上级页面 |
| `返回` | 返回对象列表页或上一层页面，便于继续查看其他对象 |
| `删除` | 删除当前对象；通常仅在对象满足删除条件时可用，执行后当前对象会从对象管理中移除，因此操作前应先确认该对象未被其它配置依赖 |
| `编辑` | 进入当前对象的编辑模式，用于修改允许调整的基础属性和设置项 |

其中 `基础` 页签主要分为 `详情`、`配置`、`设置` 三个区域。

### 3.1 详情区域属性说明

| 属性 | 含义 |
|------|------|
| 对象名称 | 对象在系统中的显示名称，用于识别和区分对象 |
| Code | 对象的唯一编码，用于系统内部识别和配置引用 |
| 状态 | 对象当前是否启用。停用后通常不再作为正常业务配置对象使用 |
| 来源 | 标识对象由谁提供，常见为系统、标准、自定义 |
| 对象类别 | 标识对象所属类别。不同类别会对应不同的对象用途和能力边界；各选项含义见“创建对象 \> 对象类别选项说明” |
| 描述 | 对对象的补充说明，用于帮助配置人员理解对象用途 |

### 3.2 配置区域属性说明

| 属性 | 含义 |
|------|------|
| 模型 | 说明当前对象在对象模型中的位置，例如是否为某个父对象的子对象 |

### 3.3 设置区域属性说明

对象详情页中的设置区域主要用于查看当前配置结果。

各设置项的作用、勾选后的影响，以及哪些属性在创建后不可修改，统一见“[2.2 设置区域](01_%E5%AF%B9%E8%B1%A1%E9%85%8D%E7%BD%AE.md)”。

部分结果型属性，例如 `生命周期阶段`、`质量组织字段`、`显示字段` 等，会在对象启用相关能力后按页面实际情况显示，后续可再结合专项手册补充。

## 4\. 对象编辑

在对象详情页点击右上角 `编辑` 后，可进入基础页签的编辑模式。页面右上角通常提供：

| 控件 | 作用 |
|------|------|
| 面包屑导航 | 用于显示当前所在路径，通常仍位于 `配置端 &gt; 配置管理 &gt; 对象管理 &gt; 对象 &gt; {对象名称}` 这一对象上下文中，帮助用户确认自己正在编辑哪个对象，并可通过前面的层级返回对象列表或详情路径 |
| `取消` | 放弃本次尚未保存的修改，返回对象详情页或退出编辑状态 |
| `保存` | 保存当前对对象属性和设置项的修改，并刷新为最新配置结果 |

对象编辑页主要关注“哪些属性可以修改、哪些属性不能修改”。以下说明以当前页面展示为准。

### 4.1 可修改的属性

| 区域 | 属性 | 说明 |
|------|------|------|
| 详情 | 对象名称 | 可直接修改 |
| 详情 | 状态 | 可在当前可选状态间切换 |
| 详情 | 描述 | 可直接修改 |
| 设置 | 在业务管理菜单中显示 | 当前页面可勾选或取消；该功能当前为保留功能，暂未开发 |
| 设置 | 用于 QRS 数据源 | 当前页面可勾选或取消；会直接影响当前对象是否可在 QRS 数据集中作为分析数据源选择 |
| 设置 | 使用动作安全来控制审计追踪 | 当前页面可勾选或取消；开启后可控制审计追踪权限 |
| 设置 | 使用动作安全来控制共享设置 | 当前页面可勾选或取消；开启后可控制共享设置权限 |
| 设置 | 启用实例锁定 | 当前页面可勾选或取消 |
| 设置 | 生命周期阶段 | 当前页面可勾选或取消 |
| 设置 | 以编辑模式显示详情 | 当前页面可勾选或取消；开启后点击对象实例会直接进入编辑模式 |
| 设置 | 启用实例多语言 | 当前页面可勾选或取消 |
| 设置 | 摘要 | 可调整已选字段；会影响表单、检查表及检查表导出中的摘要信息展示 |
| 设置 | 导出序号 | 当前页面可勾选或取消；勾选后三种列表导出动作在第一列输出序号。编号规则见 [列表导出](../02_%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97/02_%E5%AF%B9%E8%B1%A1%E7%AE%A1%E7%90%86/09_%E5%88%97%E8%A1%A8%E5%AF%BC%E5%87%BA.md) |
| 设置 | 数据所有权 | 可调整已选数据维度，但已创建的数据维度不能删除 |
| 设置 | 质量组织字段 | 可重新选择 |
| 设置 | 显示字段 | 可重新选择 |

### 4.2 不可修改或受限修改的属性

| 区域 | 属性 | 说明 |
|------|------|------|
| 详情 | Code | 只读显示，创建后不可修改 |
| 详情 | 来源 | 只读显示，创建后不可修改 |
| 详情 | 对象类别 | 只读显示，创建后不可修改 |
| 设置 | 生命周期 | 当前页面显示为生命周期链接，不在此处直接修改 |
| 设置 | 开启动态权限控制 | 一旦开启后不能关闭 |
| 设置 | 启用审计追踪 | 当前页面为灰显状态；按对象规则，启用后不可关闭 |
| 设置 | 启用电子签名 | 创建后属于不可逆能力，启用后不可关闭 |
| 设置 | 是否大容量 | 创建后不可在标准对象和大容量对象之间切换 |
| 设置 | 启用对象类型 | 一旦开启后不能关闭；开启后可继续配置对象类型，详见 [01E\_对象类型.md](01E_%E5%AF%B9%E8%B1%A1%E7%B1%BB%E5%9E%8B.md) |
| 设置 | 启用所属业务模块 | 一旦开启后不能关闭 |

### 4.3 使用说明
- 页面中以文本或链接形式展示的属性，通常表示当前页仅查看，不在此处编辑，例如 `Code`、`来源`、`对象类别`、`生命周期`
- 页面中灰显的复选框表示当前对象在该属性上不支持直接修改
- 某些属性是否可编辑，除了受页面状态影响，也受创建时的初始设置和系统规则影响；如需查看创建后是否允许再次修改，可结合“2.2 设置区域”中的规则一起理解

关于 `显示字段`：
- `显示字段` 在产品方案中也称为 `选择显示属性`
- 该属性为非必填，用于控制“选择当前对象记录时”的展示内容
- 可选范围为当前对象上的字段，但不包括 `统计字段`、`附件字段`、`富文本字段`
- 如果选择的是 `选项` 或 `布尔` 类型字段，页面展示的是字段的显示文本
- 如果未设置显示字段，则保持系统默认展示方式
- 设置后，在下拉选择该对象记录时，会按显示字段的内容进行展示
- 该展示规则不仅会影响对象选择器，也会影响表单、行内编辑、工作流字段编辑、完成任务、移动端等场景
- 根据后续方案补充，筛选器中也会按显示字段格式进行展示，因此这是一个需要重点关注的配置项
