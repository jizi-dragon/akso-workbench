# 页面链接配置

页面链接用于覆写标准对象页面动作（创建、查看、编辑）的默认跳转地址，让业务用户点击标准按钮后进入指定页面。

---

## 概述

在未配置页面链接时，业务端标准按钮会进入系统默认页面。配置页面链接后，可将按钮跳转重定向到你定义的地址。

常见用途：
- 在标准详情页中接入定制化表单页面。
- 将特定对象的编辑入口重定向到专用流程页。
- 将查看入口重定向到外部业务页面（通过 iFrame 承载）。
> \[!NOTE\]
复制模式当前为预留能力，暂未开放。   

---

## 前提条件

开始配置前，请确认：
- 已具备权限：`管理端 > 配置管理 > 页面链接`。
- 已完成目标对象（或对象类型）基础配置。
- 已明确要覆写的页面模式（创建/查看/编辑）和目标 URL。
- 若使用外链，已确认目标站点允许被 iFrame 加载。

---

## 配置决策

### 决策点 1：页面类型选择

| 选项 | 适用场景 | 优点 | 风险/限制 |
|------|------------|------|-------------|
| 对象 | 针对某个对象统一覆写页面模式 | 配置简单，生效范围清晰 | 粒度较粗，无法区分对象类型差异 |
| 对象类型 | 需要在同一对象下按对象类型分别跳转 | 适合复杂业务分型 | 需要额外维护对象类型映射 |

### 决策点 2：URL 类型选择

| 选项 | 适用场景 | 优点 | 风险/限制 |
|------|------------|------|-------------|
| 站内地址 | 跳转到 Gaia 站内页面 | 体验一致，导航完整 | 需要提前规划站内页面路径 |
| 外部地址 | 跳转到外部系统页面 | 可快速集成第三方页面 | 受 iFrame 策略和外站安全策略影响 |
> \[!TIP\]
建议优先使用站内地址。仅在确有外部系统承载需求时使用外链。   

---

## 配置步骤

### 1\. 进入管理入口

路径：`管理端 > 配置管理 > 页面链接`

列表页默认按创建时间倒序展示，支持按关键字（名称）模糊查询。

### 2\. 创建页面链接
1. 在列表页点击右上角`创建`。
2. 填写基础信息并构建 URL。
3. 点击`验证`检查 URL 格式。
4. 点击`保存`完成创建。

关键字段说明：

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 名称 | 是 | 1-200 字符，唯一。建议体现“对象 \+ 模式 \+ 业务用途”。 |
| Code | 是 | 1-200 字符，唯一。建议采用稳定英文编码。 |
| 描述 | 否 | 0-500 字符，说明用途与适用边界。 |
| 页面模式 | 是 | 可选：查看、编辑、创建、复制（预留）。 |
| 页面类型 | 是 | 可选：对象、对象类型。 |
| 对象 | 是 | 当页面类型为对象时必选；若为对象类型，还需进一步选择对象类型。 |
| URL 地址 | 是 | 1-2000 字符，支持 Token 变量。 |

URL 可用 Token：

| 分类 | 可用范围 | 说明 |
|------|------------|------|
| 对象字段 | 当前对象字段、出站对象字段 | 可在 URL 中拼接当前记录值及关联（出站）对象字段值。建议通过变量选择器插入，避免手工输入错误。 |
| 全局变量 | 当前实例、站点服务地址、站点域名、系统名称、AiToken | 可在 URL 中引用系统级通用值。 |

全局变量类型说明：

| 全局变量 | 类型 |
|------------|------|
| 当前实例 | 对象 |
| 站点服务地址 | 链接 |
| 站点域名 | 链接 |
| 系统名称 | 文本 |
| AiToken | 文本 |

保存校验规则：
- `对象 + 页面模式`联合唯一。
- 若冲突，系统提示：`此对象的XX模式已存在。`

### 3\. 查看与编辑页面链接

进入方式：
1. 列表页点击名称进入详情页。
2. 在列表页点击`编辑`，或在详情页点击`编辑`进入编辑页。

编辑时可修改名称、描述、页面模式、页面类型、对象和 URL。保存时会再次进行校验。

### 4\. 删除页面链接

删除入口：
1. 列表页操作列点击`删除`。
2. 详情页点击`删除`。

删除行为：
- 删除前弹出确认框。
- 标准内置页面链接不可删除，但可修改名称和描述。

---

## 生效与验证

完成配置后，业务端点击对应标准按钮会按页面链接跳转：
- 站内地址：直接跳转到目标站内页面。
- 外部地址：通过 iFrame 加载外部页面。

验证建议：
1. 使用测试记录分别点击创建/查看/编辑入口，确认跳转是否符合预期。
2. 检查 URL Token 替换结果，确认参数值正确。
3. 对外链场景验证页面是否可正常加载、返回按钮是否可用。

---

## 常见问题

**Q1：为什么保存时报“此对象的XX模式已存在”？**   A：同一对象下，同一页面模式只能配置一条页面链接。请先停用或调整已有规则。

**Q2：为什么 URL 验证通过，但业务端仍打不开？**   A：常见原因包括外站不允许 iFrame 嵌入、Token 替换后 URL 超长，或目标地址本身不可访问。

**Q3：为什么有些页面链接删不掉？**   A：系统内置标准页面链接不可删除，仅支持改名和改描述。
