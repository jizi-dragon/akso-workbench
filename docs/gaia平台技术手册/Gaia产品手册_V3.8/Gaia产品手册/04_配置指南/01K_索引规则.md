# 索引规则
> 本文说明如何在 Gaia 平台为对象配置索引规则，用于提升查询性能并在需要时保障字段值唯一性。   

---

## 1 概述

索引规则用于控制对象数据表上的索引配置。 
在配置端创建或删除索引规则后，系统会同步处理对应的数据库索引。

索引规则类型：
- 普通索引：用于提升筛选、排序、关联查询等场景性能。
- 唯一索引：用于约束字段值或字段组合值不重复。

系统默认索引：
- 对象默认包含系统索引（如对象 ID、创建时间等系统字段索引）。
- 对象启用对象类型后，系统会提供对象类型相关默认索引能力。
- 对象启用生命周期状态后，系统会提供生命周期状态相关默认索引能力。

### 1.1 访问路径

`配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 索引规则`

### 1.2 关键概念

| 概念 | 说明 |
|------|------|
| 索引名称 | 系统自动生成的索引标识，用于底层索引管理。 |
| 索引备注 | 用于说明索引用途的业务描述，可用于异常提示和维护识别。 |
| 索引方法 | 当前版本默认 `B-Tree`。 |
| 是否唯一 | 控制索引是否为唯一索引。 |
| 索引字段 | 参与索引的字段集合。 |

---

## 2 索引规则列表

在对象详情页切换到“索引规则”页签后，可统一查看和维护当前对象的索引规则。

### 2.1 页面结构

索引规则列表页包含以下区域：
- 面包屑：`所有的对象 > {对象名称}`。
- 对象页签区：包含 `基础`、`对象类型`、`字段`、`搜索字段`、`关系`、`列表布局`、`表单布局`、`动作`、`验证规则`、`索引规则`。
- 当前页签：`索引规则`（高亮状态）。
- 右上角主操作：`创建`。
- 列表区：展示索引规则明细，每条规则在行末提供齿轮操作入口。

### 2.2 列表字段

| 字段 | 说明 |
|------|------|
| 索引名称 | 系统生成的索引名称。 |
| 索引备注 | 索引用途说明。 |
| 索引方法 | 索引类型显示值（如：普通索引）。 |
| 是否唯一 | 标识当前索引是否为唯一索引。 |
| 索引字段 | 当前索引关联字段；多字段时按列表展示。 |
| 操作 | 通过齿轮按钮打开行操作菜单。 |

补充说明：
- `是否唯一` 在列表中以“是/否”展示。
- `索引字段` 支持展示多个字段，便于快速核对字段组合。

### 2.3 列表操作

| 操作 | 说明 |
|------|------|
| 创建 | 新建索引规则。 |
| 齿轮菜单 | 点击行末齿轮按钮，打开当前索引的操作菜单。 |
| 编辑 | 编辑已有索引规则（仅允许修改索引备注）。 |
| 删除 | 删除索引规则，并同步删除数据库索引。 |

## 3 创建索引规则

点击索引规则页签右上角 `创建` 后，系统弹出“创建索引规则”窗口。

### 3.1 弹窗结构

“创建索引规则”弹窗包含以下区域：
- 顶部标题区：显示标题“创建索引规则”，右上角提供关闭按钮。
- 内容区：展示对象信息、索引方式和配置字段。
- 底部按钮区：`取消`、`确定`。

### 3.2 弹窗字段

| 配置项 | 是否必填 | 说明 |
|---------|------------|------|
| 对象名称 | 否（只读） | 仅展示当前对象名称。 |
| 索引方法 | 否（只读） | 当前界面默认显示 `普通索引`。 |
| 是否唯一 | 否 | 复选框，勾选后按唯一索引规则校验。 |
| 索引字段 | 是 | 选择参与索引的字段，支持多选并以标签形式展示。 |
| 索引备注 | 是 | 输入索引用途说明，建议填写明确业务含义。 |

### 3.3 弹窗操作
- `取消`：关闭弹窗，不保存本次输入。
- `确定`：提交并创建索引规则；校验通过后写入索引规则列表。
- 右上角关闭按钮：关闭弹窗，不保存本次输入。

### 3.4 创建规则与限制
- 唯一索引支持多字段组合创建。
- 相同字段或相同字段组合不允许重复创建同类型索引。
- 以下字段不允许创建普通索引：`id`、`is_deleted`，以及公式、文本、长文本、富文本、附件等类型字段。
- 多选选项、对象多选、多选组件字段不支持创建索引。
- 文本字段可用于创建唯一索引。

### 3.5 索引命名规则

索引名称由系统自动生成：
- 普通索引：基于 `表名_列名` 规则生成。
- 唯一索引：基于 `表名_列名_ux` 规则生成。

---

## 4 编辑与删除索引规则

### 4.1 编辑规则

索引创建后，仅允许修改“索引备注”。 
索引方法、是否唯一、索引字段不支持直接修改；如需调整，请删除后重建。

### 4.2 删除规则

删除索引规则后，系统会同步删除对应数据库索引。

关联行为：
- 当对象字段被删除时，引用该字段的索引规则会自动删除。
- 当字段“值必须唯一”属性发生变更时，系统会自动新增或删除对应唯一索引。

---

## 5 执行与异常提示
- 创建记录或编辑记录时，若触发唯一索引冲突，系统将阻止保存。
- 唯一索引异常提示中会包含索引备注，便于快速定位问题规则。
- 唯一索引依赖现有数据质量：若历史数据存在重复值，可能导致唯一索引创建失败。

---

## 6 配置建议
- 为每条索引填写明确的索引备注（建议体现“字段 \+ 业务目的”）。
- 普通索引优先用于高频筛选字段，不建议无差别批量创建。
- 唯一索引上线前先做数据去重检查，避免保存或升级阶段失败。
- 字段模型变更（删除字段、唯一性调整）后，建议复核索引规则列表是否符合预期。
