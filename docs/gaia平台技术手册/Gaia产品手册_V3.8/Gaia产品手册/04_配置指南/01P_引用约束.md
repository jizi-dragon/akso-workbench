# 引用约束
> 本文说明如何为对象字段和父对象字段限制可选择的引用记录范围。   

---

## 概述

引用约束用于限制引用字段可以选择哪些记录。配置完成后，业务端用户在对象选择器中只能看到符合条件的记录，从而减少误选。

引用约束既可以用于控制引用字段的候选记录范围，也会影响相关对象数据的显示范围。

## 适用范围
- 对象字段
- 父对象字段
- 其他需要限制引用记录显示和选择范围的场景

## 配置入口

进入 `配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 字段`，打开对象字段或父对象字段的详情页或编辑页，在“约束引用对象中的记录”中维护引用约束。

## 设置引用约束

可按以下顺序完成引用约束设置：
1. 先确认当前字段是 `对象` 字段或 `父对象` 字段，并且已经选择了引用对象。
2. 进入该字段的详情页或编辑页，在“约束引用对象中的记录”中新增约束条件。
3. 选择筛选条件字段，也就是用来限制候选记录范围的引用对象字段。
4. 选择逻辑运算符。
5. 选择逻辑值类型： `当前对象字段` 适用于需要随当前记录字段值联动的场景； `指定常量` 适用于固定限制范围的场景。
6. 按所选逻辑值类型填写逻辑值：
如果选择 `当前对象字段`，从当前对象中选择同类型字段；
如果选择 `指定常量`，直接输入固定值。
7. 如果需要更复杂的过滤逻辑，可启用高级筛选模式，并填写 SQL 脚本。
8. 保存字段配置，并将相关上游字段放入表单布局，确保业务端录入时可以先填写这些字段。
9. 进入业务端创建或编辑记录，打开引用字段选择器，检查候选记录范围是否已按预期收缩。

如果保存后业务端没有按预期生效，应优先检查筛选条件字段、逻辑值类型、逻辑值，以及相关上游字段是否已经放入表单布局。

## 配置方式

### 静态引用约束

静态引用约束使用固定条件限制候选记录范围。适合“始终只允许选择某一类记录”这类稳定规则。

### 动态引用约束

动态引用约束根据当前记录上的字段值实时收缩候选记录范围。适合“可选记录范围随当前表单内容变化”这类联动场景。

当引用约束使用当前对象字段作为条件值时，被约束的引用字段会随这些字段的值变化而重新计算候选记录范围。

## 条件配置

配置引用约束时，可维护以下内容：

| 配置项 | 说明 |
|---------|------|
| 条件类型 | 选择约束条件的来源，支持关联对象字段和状态等条件 |
| 筛选条件字段 | 选择引用对象中的字段作为筛选依据；支持引用对象自身字段及其出站关系字段；公式字段不参与此处配置 |
| 逻辑运算符 | 不同字段类型支持不同运算符，按字段类型匹配使用 |
| 逻辑值类型 | 支持使用当前对象字段或指定常量 |
| 逻辑值 | 当值类型为当前对象字段时，从当前对象中选择同类型字段；当值类型为指定常量时，直接输入固定值 |

## 业务端生效方式

配置引用约束后，业务端会按以下方式生效：
- 在引用字段选择记录时，只显示满足约束条件的候选记录
- 在显示相关对象数据时，只显示满足引用约束的数据
- 当约束条件来自当前记录字段时，这些条件会在弹出的条件筛选器中自动带出
- 自动带出的约束条件只用于收缩范围，业务端用户不能移除

## 高级筛选模式

复杂场景下，可启用高级筛选模式维护更灵活的引用约束逻辑。

启用高级筛选后：
- 条件编辑器会隐藏
- SQL 脚本编辑器显示为必填
- 系统会对脚本进行语法检查
- 原条件编辑器中配置的条件不再生效

## 使用建议
- 先明确“哪些记录允许被选中”，再决定使用静态约束还是动态约束
- 对业务规则明确、选错成本高的引用字段，优先配置引用约束
- 当约束依赖当前对象字段时，应确保这些字段已经放入表单布局，避免业务端录入时无法触发正确联动
- 条件值需要随页面录入内容变化时，优先使用当前对象字段，不要重复维护多套固定条件
