# 联动规则配置
> 本文说明如何在 Gaia 平台中配置和使用“联动规则”，实现主对象与相关对象之间的自动数据联动。   

---

## 概述

联动规则用于把“主对象联动字段指向对象”中的关系数据，按规则自动写入主对象的相关对象记录。该能力常用于“先选上游对象，再自动带出下游明细”的场景，减少重复录入并保证数据一致性。

联动数据在主对象保存后会落库为相关对象记录。已落库记录默认不随源对象历史数据自动回溯更新，除非再次触发联动。

### 核心概念

| 概念 | 说明 |
|------|------|
| 主对象 | 呈现联动结果的对象。 |
| 联动目标对象 | 主对象上的“相关对象”，用于承接联动写入的数据。 |
| 联动字段 | 主对象上的对象引用字段（父对象/对象），用于指定联动数据来源。 |
| 联动对象 | 联动字段所指对象的入站关系对象，即联动数据来源对象。 |

---

## 访问路径
- 联动规则管理：`配置端 > 配置管理 > 对象设置 > 数据联动规则`
- 规则使用入口（表单布局相关对象部分）：`配置端 > 配置管理 > 对象设置 > {对象} > 表单布局 > 相关对象部分 > 对象联动规则`

---

## 1\. 联动规则列表

联动规则列表用于统一查看和维护规则，常见列包括：
- 名称
- Code
- 对象
- 相关对象
- 联动字段
- 联动对象
- 状态
- 操作

常用操作说明：
- `编辑`：进入规则编辑页，修改可编辑配置。
- `启用/停用`：控制规则是否可在布局中被选择并参与联动。
- `删除`：移除规则定义；删除后该规则不再可用。

---

## 2\. 创建联动规则

### 2.1 前置条件

创建规则前，建议先完成以下配置：
- 主对象、相关对象关系已建立。
- 主对象上已存在可作为联动字段的对象引用字段。
- 联动字段对应的联动对象及其可映射字段已明确。

### 2.2 操作步骤
1. 进入 `配置端 > 配置管理 > 对象设置 > 数据联动规则`。
2. 点击 `创建`，进入规则创建页。
3. 按业务场景填写基本信息、对象关系和联动来源信息。
4. 点击 `保存` 完成创建。

### 2.3 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 名称 | 是 | 规则显示名称，建议使用“对象 \+ 联动目标”命名，便于检索。 |
| Code | 是 | 规则唯一编码，建议使用英文小写加下划线。 |
| 状态 | 否 | `启用/停用`。仅启用规则可在表单布局中选择。 |
| 对象 | 是 | 规则所属主对象。保存后不可修改。 |
| 相关对象 | 是 | 主对象下需要写入联动数据的关系对象。保存后不可修改。 |
| 相关对象类型 | 否 | 用于限定相关对象类型。 |
| 联动字段 | 是 | 主对象上的对象引用字段（父对象/对象）。保存后不可修改。 |
| 联动对象 | 是 | 联动字段对应的入站关系对象（数据来源对象）。保存后不可修改。 |
| 联动对象类型 | 否 | 用于限定联动对象类型。 |
| 描述 | 否 | 规则用途说明，便于后续维护。 |

## 3\. 编辑联动规则

### 3.1 入口与顶部操作

在联动规则列表点击 `编辑` 进入“所有联动规则 \> 编辑”页面。

编辑页顶部常用按钮：
- `取消`：放弃本次未保存修改并返回列表。
- `保存`：保存当前规则修改；保存成功后规则按新配置生效。

### 3.2 详情区（基础信息）

编辑页 `详情` 区用于维护规则基础信息。字段可编辑性如下：

| 字段 | 编辑态 | 说明 |
|------|---------|------|
| 名称 | 可编辑 | 规则显示名称。 |
| Code | 只读 | 规则唯一编码，编辑页仅展示，不可改。 |
| 状态 | 可编辑 | `启用/停用`。停用后布局中不可选择该规则。 |
| 对象 | 只读 | 规则所属主对象。 |
| 相关对象 | 只读 | 联动目标对象关系。 |
| 相关对象类型 | 只读 | 相关对象类型（配置了类型时显示）。 |
| 联动字段 | 只读 | 触发联动的对象引用字段。 |
| 联动对象 | 只读 | 联动数据来源对象。 |
| 联动对象类型 | 只读 | 联动对象类型（配置了类型时显示）。 |
| 表单忽略复制动作 | 可编辑（复选框） | 勾选后，创建/编辑表单中的复制动作不触发该联动规则。 |
| 默认排序设置 | 可编辑 | 通过 `新增` 维护联动数据写入前的排序规则。 |
| 描述 | 可编辑 | 规则用途说明。 |

说明：
- `对象/相关对象/联动字段/联动对象` 属于结构性字段，创建后在编辑页保持只读。
- 若未配置 `默认排序设置`，联动结果按数据源默认顺序处理。

### 3.3 联动字段映射

`联动字段映射` 区用于定义“联动对象字段 -\> 目标对象字段”的赋值关系。

页面操作：
- `添加字段`：新增一行映射。
- 行内下拉：分别选择联动对象字段与目标对象字段。
- 行尾删除图标：删除当前映射行。

映射行规则：
- 每行包含三部分：`联动对象字段`、`字段类型（只读显示）`、`目标对象字段`。
- 字段类型需兼容；不兼容字段不应建立映射。
- 同一目标字段建议只保留一条映射，避免写入冲突。
- 映射时应排除系统字段，以及“相关对象回指主对象”的关系字段。

### 3.4 联动数据范围设置

`联动数据范围设置` 区用于限定可参与联动的数据集合。条件类型支持对联动对象自身字段（字段条件）以及联动对象的入站关系字段（入站关系字段条件）设置过滤。

页面操作：
- `并且`：设置当前条件组逻辑为 AND。
- `+`：新增一条筛选条件。
- 条件行：选择条件类型、字段、运算符和比较值。

#### 对象字段的「等于」运算符

当条件字段为对象类型（Object）或父对象类型（Parent Object）时，运算符除「为空」「不为空」外，还支持「等于」。

「等于」比较按记录 ID 精确匹配：仅保留该字段引用记录 ID 与比较值一致的联动对象记录。

#### 比较值：指定常量与当前对象字段

选择「等于」后，比较值类型可选：

| 值类型 | 说明 |
|---------|------|
| 指定常量 | 通过对象记录选择器固定选择一条记录，配置后不随主记录变化。 |
| 当前对象字段 | 从主对象（联动规则所在对象）上选择字段，运行时取当前主对象记录上该字段的值作为比较值。 |

「当前对象字段」选择器仅展示主对象上、与被比较字段引用同一对象的对象/父对象类型字段。父对象类型与对象类型在本场景按“引用同一对象”兼容处理。若主对象上没有可引用字段，选择器为空。

选择「当前对象字段」时必须选定字段后才能保存。

#### 运行时与限制
- 主对象字段有值时，按「等于」过滤联动数据。
- 主对象字段为空，或所引用记录已被删除时，该「等于」条件跳过不生效（等同于该条件不存在），其他条件仍正常叠加（AND）。
- 「等于」条件与「为空」「不为空」等其他条件取 AND 关系，共同过滤最终联动数据集。
- 本次「等于」与「当前对象字段」仅作用于联动数据范围设置，不改变引用约束、生命周期条件等其他条件场景。

#### 配置示例

发放申请（主对象）通过联动规则关联文件版本，希望只联动与发放申请「产品」相同的文件版本：
1. 条件类型选择「字段」。
2. 字段选择文件版本上的「产品」（对象类型）。
3. 运算符选择「等于」。
4. 值类型选择「当前对象字段」，并选择主对象上的「产品」。

保存后，当发放申请的「产品」为产品 A 时，仅联动「产品 = 产品 A」的文件版本记录。

配置建议：
- 条件优先使用可稳定判断的业务字段（如状态、类型、产品、质量组织）。
- 条件过宽会导致一次创建过多相关记录，建议先在测试环境验证结果数量。
- 条件表达可参考 [字段配置条件设置](01M_%E5%AD%97%E6%AE%B5%E9%85%8D%E7%BD%AE%E6%9D%A1%E4%BB%B6%E8%AE%BE%E7%BD%AE.md) 的运算符与逻辑组合方式；联动数据范围中对象字段的「等于」与「当前对象字段」为本场景扩展能力。

## 4\. 在表单布局中使用联动规则

联动规则当前用于表单相关对象部分。

操作步骤：
1. 进入 `配置端 > 配置管理 > 对象设置 > {对象} > 表单布局`。
2. 编辑目标布局中的“相关对象”或“相关对象（支持行内编辑）”部分。
3. 在 `对象联动规则` 中选择规则并保存布局。

规则可选范围按以下条件自动过滤：
- 规则对象 = 当前表单布局所属对象
- 规则相关对象 = 当前部分选择的相关对象关系
- 若配置了对象类型，还需满足对象类型匹配

### 4.1 创建页面支持范围

联动规则在创建场景支持以下页面与打开方式：

| 创建页面 | 表单模式 | 抽屉模式 | 弹出层模式 |
|------------|------------|------------|---------------|
| 对象创建页面 | 支持 | 支持 | 支持 |
| 文件创建页面 | 支持 | 支持 | 支持 |

说明：
- “文件创建页面”指文档/文件相关对象的创建页面。
- 无论是直接进入创建页，还是通过相关对象部分以抽屉或弹出层方式打开创建页，均可触发联动规则。

## 5\. 业务端联动效果

### 5.1 创建模式

当用户填写联动字段并保存主对象后，系统按规则自动创建/刷新联动目标对象记录。

创建模式覆盖：
- 表单模式（页面创建）
- 抽屉模式（抽屉创建）
- 弹出层模式（弹窗创建）

### 5.2 查看模式

用户可在相关对象部分直接查看联动生成的记录结果。

### 5.3 编辑模式

当相关对象部分启用联动规则后，该部分通常按只读策略展示，避免手工编辑与自动联动相互冲突。 
若用户修改联动字段并保存，联动目标对象记录会按当前规则重新计算并刷新。

### 5.4 历史数据保留说明
- 联动结果以“主对象保存时点”的来源数据为准。
- 来源对象后续新增或变更记录，不会自动回写到既有联动结果。
- 新建主对象并触发联动时，会按当时最新来源数据生成结果。

---

## 6\. 生命周期进入动作联动

在生命周期中可使用进入动作 `数据联动`，在记录进入目标状态时按指定联动规则自动创建联动记录。

参数说明：

| 参数 | 说明 |
|------|------|
| 联动规则 | 必填。仅可选择“所属对象与当前生命周期对象一致”且状态为启用的规则。 |

说明：
- 当场景要求“到达某状态即自动补齐联动数据”时，优先使用该进入动作。
- 支持级联联动：若联动生成的记录本身也配置了联动规则，可继续触发后续联动。

---

## 7\. 不触发或受限场景

以下场景默认不触发表单联动规则：
- 列表行内编辑联动字段
- 批量修改联动字段
- 导入更新联动字段
- 通过“普通进入动作修改字段”间接修改联动字段（需改用进入动作 `数据联动`）

## 8\. 权限与异常处理

### 8.1 管理端权限

| 权限项 | 说明 |
|---------|------|
| 联动规则-查看 | 可访问联动规则列表和详情。 |
| 联动规则-创建 | 可新建联动规则。 |
| 联动规则-编辑 | 可修改规则配置。 |
| 联动规则-删除 | 可删除规则。 |

### 8.2 权限冲突提示

若当前状态下联动字段可编辑，但联动目标对象不可编辑，用户修改联动字段时会被拦截，并提示：  `{XX关系对象}不可编辑，无法修改当前字段的值。`

### 8.3 常见异常
- 若联动生成的目标记录不满足“必填/唯一”等字段规则，系统会按目标对象校验规则报错。
- 若联动目标对象也存在联动规则，且自动创建时直接写入其联动字段，系统会拦截并提示不支持该自动创建链路。
- 若用户先手工添加了相关对象记录，后续再设置联动字段并保存，系统会按规则重建联动结果，已有手工记录可能被替换。
