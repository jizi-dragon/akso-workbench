# 报表配置
> 本文介绍如何在 Gaia 平台配置报表类型、报表视图、报表实例与仪表板，供管理员和配置人员使用。   

---

## 概述

报表用于数据的统计和可视化展示。平台中数据承载在对象上，通过列表和表单布局分别展示；当需要对数据指标进行统计分析时，可使用报表进行可视化展示。

### 核心概念

| 概念 | 说明 |
|------|------|
| **报表类型** | 报表的数据基础，创建来源为：1）对象；2）报表视图 |
| **报表视图** | 通过报表类型创建，可对数据进行筛选、过滤、分组统计 |
| **报表实例** | 通过报表类型创建，选择分组字段和展示数据，可对数据进行二次过滤 |
| **仪表板** | 最终展示数据的页面，由多个报表实例组合而成 |

### 数据流转关系
```
报表类型（数据基础）→ 报表视图（筛选/分组）→ 报表实例（分组与展示）→ 仪表板（多实例组合）
```

---

## 多表联接

**多表联接**是指通过报表视图创建报表类型，将多个报表视图的数据合并到一个数据类型中。类似于 SQL 中的 join 功能。
- 联接以**线性方式**进行：两个视图先联接成新视图，再与右侧视图联接
- 可将不同报表视图的数据按指定字段匹配合并，实现数据整合
- 视图联接关系通常为**左连接**，联接字段为两张视图共有的字段

## 管理端配置入口

### 报表类型

**路径**：管理端 \> 报表设置 \> 报表类型

| 操作 | 说明 |
|------|------|
| 创建 | 新建报表类型，选择数据来源（对象或报表视图） |
| 编辑 | 修改报表类型配置 |
| 删除 | 删除报表类型 |

### 报表视图

**路径**：管理端 \> 报表设置 \> 报表视图

| 操作 | 说明 |
|------|------|
| 创建 | 新建报表视图，基于报表类型进行筛选、分组、统计 |
| 编辑 | 修改报表视图配置 |
| 禁用 | 停用报表视图 |
| 删除 | 删除报表视图 |

### 报表实例

**路径**：首页 \> 报表 \> 所有报表实例

| 操作 | 说明 |
|------|------|
| 创建 | 新建报表实例，选择报表类型和分组字段 |
| 移除 | 移除报表实例 |
| 报表导出 | 导出报表数据 |
| 简报订阅 | 订阅简报，定时接收报表 |

### 仪表板

**路径**：首页 \> 报表 \> 仪表板 \> 所有仪表板

| 操作 | 说明 |
|------|------|
| 移除 | 移除仪表板 |
| 仪表板编辑 | 编辑仪表板布局与组件 |
| 仪表板导出 | 导出仪表板 |

## 配置示例：小组工时统计

### 业务需求

统计某一小组中每个人的工时情况。工时属于某个项目，填报人属于某个小组，项目也分配到小组负责。

### 步骤一：创建报表类型（工时对象）
1. 进入 管理端 \> 报表设置 \> 报表类型 \> 创建
2. 数据来源选择 **工时对象**
3. 若需关联工时填报人信息，关系仅支持**出站对象**

### 步骤二：创建报表视图
1. 进入 管理端 \> 报表设置 \> 报表视图 \> 创建
2. 报表类型选择步骤一创建的报表类型
3. 在添加列中加入统计字段，并设置统计方式
4. 设置过滤条件（如：工时生效状态）
5. 若需多个分组条件而视图仅支持两个，可创建**多个分组视图**，再通过报表类型将视图联接

### 步骤三：创建联接报表类型（多视图）
1. 创建新报表类型，数据来源选择 **报表视图**
2. 选择需联接的报表视图
3. 视图联接关系设为**左连接**，联接字段为两视图共有字段
4. 显示字段选择后续报表和仪表板需要的字段，通常全选视图中统计的字段

### 步骤四：创建报表实例
1. 进入 首页 \> 报表 \> 报表 \> 创建
2. 报表类型选择步骤三中联接视图的报表类型
3. 视图中已做好分组过滤和统计，报表中只需将展示字段添加到列
4. 可添加公式字段进行额外计算

### 步骤五：创建仪表板
1. 在仪表盘中添加组件
2. 报表选择步骤四创建的报表
3. 选择图表类型及统计维度（X 轴、Y 轴数据）
4. 如有需要，设置次级分组
5. 添加筛选组件，对图表数据进行进一步过滤
