# 记录动作配置
> 本文介绍 Gaia 平台中记录动作的配置与管理方式，重点包括动作类型、权限控制、管理入口、对象动作实例管理与使用建议。   

---

## 概述

记录动作是作用于对象记录（Object Record）的可扩展动作能力，既可用于单条记录操作，也可用于多记录批量操作。记录动作基于 SDK 扩展实现，由开发人员实现后注册到平台，再由配置人员分配到具体对象并控制可见与可用范围。

### 核心关系
- **记录动作**：平台级动作定义。
- **对象动作**：记录动作被添加到某个对象后形成的实例。
- **业务端可执行动作**：对象动作在权限与状态条件满足后，最终对用户可见并可执行。

### 访问路径
- 记录动作管理：`管理端 > 配置管理 > 记录动作`
- 对象动作管理：`管理端 > 配置管理 > 对象设置 > {对象} > 动作`

---

## 1\. 记录动作类型

记录动作支持以下用途类型：

| 类型 | 说明 | 常见入口 |
|------|------|------------|
| 用户对象动作 | 用户主动触发的记录动作，可分配到对象类型 | 对象 \> 动作 |
| 批量操作 | 面向多条记录的批量动作 | 列表页 \> 批量操作 |
| 生命周期用户动作 | 生命周期状态内由用户触发的动作 | 生命周期 \> 用户动作 |
| 进入动作 | 进入生命周期状态时自动执行的动作 | 生命周期 \> 进入动作 |
| 事件动作 | 创建、复制等事件触发的动作 | 生命周期 \> 事件动作 |
| 工作流动作节点 | 工作流节点中可调用的扩展动作 | 工作流配置 |
| 工作流取消动作 | 工作流取消时触发的动作 | 工作流配置 |
| 无实例用户动作 | 不生成对象动作实例，通常出现在列表级能力位 | 权限集控制 |
> 说明：并非每个租户都会启用全部类型，实际可用类型以当前环境为准。   

---

## 2\. 动作实例类型与权限控制

从对象使用视角，动作可分为无实例动作、单实例动作、多实例动作，不同类型在显示位置和权限控制上存在差异。

| 实例类型 | 典型动作 | 常见显示位置 | 权限控制重点 |
|------------|------------|------------------|------------------|
| 无实例动作 | 创建、导出等列表能力 | 列表表头 | 权限集 |
| 单实例动作 | 查看、编辑、复制、移除、记录动作 | 详情页 Action Bar、行内操作 | 权限集 \+ 生命周期/状态安全 |
| 多实例动作 | 批量编辑字段、批量更新共享等 | 列表批量操作面板 | 批量操作权限 \+ 动态动作计算 |

### 2.1 对象动作与生命周期权限

对象动作创建后，通常需要同时满足以下条件才会在业务端可执行：
1. 用户具备对应动作权限（权限集）。
2. 当前记录状态满足生命周期允许条件（含状态权限时）。
3. 动作本身处于启用状态。

---

## 3\. 记录动作管理页面

在 `管理端 > 配置管理 > 记录动作` 可查看平台中已注册的记录动作定义。

### 3.1 列表字段（常见）
- 名称
- Code
- 来源（如系统、标准、自定义）
- 对象
- 用途
- 状态
- 创建者

### 3.2 页面行为
1. 列表按动作入库时间倒序展示。
2. 支持关键词查询，常用匹配字段为名称与 Code。
3. 可通过来源与用途快速区分平台内置能力和自定义扩展能力。

---

## 4\. 使用与排查建议
1. 先定动作用途，再定实例范围（单记录/批量/生命周期/工作流）。
2. 命名建议使用“动词 \+ 对象/结果”，例如“批量关闭偏差”。
3. Code 发布后尽量保持稳定，避免影响权限、流程和自动化引用。
4. 上线前在沙箱验证：可见性、权限、状态约束、执行结果和提示信息。
5. 定期清理无效或重复动作，保持动作清单可维护。
