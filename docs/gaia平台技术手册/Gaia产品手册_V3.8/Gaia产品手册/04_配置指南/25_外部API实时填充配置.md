# 外部API实时填充配置
> 本文说明如何在表单布局的字段控件中启用“引用外部数据”，通过外部 API 实时查询并回填当前表单字段。   

---

## 1 概述

外部 API 实时填充用于减少手工录入，在用户填写表单时通过查询外部系统数据，选择记录后自动回填到当前表单。

该能力配置在表单布局的字段控件上，核心包含 3 部分：
- 接口选择：选择可被表单引用的接口应用与接口方法
- 入参映射：将当前表单字段值或用户输入值映射为接口请求参数
- 出参赋值：将接口返回字段映射到当前表单字段

### 1.1 适用场景
- 根据外部主数据快速带出标准字段值
- 在录入时通过搜索选择外部记录，避免重复维护
- 将外部接口返回结果同步到当前对象记录

### 1.2 能力关系

该能力由两段配置共同完成：
- 集成管理侧：维护接口应用、主机地址、接口方法、入参、出参
- 表单布局侧：在字段控件上启用 `引用外部数据`，并完成入参映射与出参赋值

### 1.3 配置路径

集成管理配置路径：

`配置环境 > 集成管理 > 接口应用管理`

表单布局配置路径：

`配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 表单布局 > 目标部分 > 字段控件编辑`

## 2 在集成管理中配置可引用接口

### 2.1 创建接口应用

进入 `集成管理 > 接口应用管理`，点击 `创建`，维护接口应用基础信息。

常用字段如下：

| 字段 | 说明 |
|------|------|
| 名称 | 接口应用名称，建议按业务域命名 |
| 编码 | 接口应用编码，建议全局唯一 |
| 主机地址 | 外部接口主机地址（Host） |
| 描述 | 可选，用于说明用途 |
| 状态 | 建议启用，供表单侧选择 |

### 2.2 在接口应用下创建接口方法

进入目标接口应用详情，在 `接口` 区域创建方法，维护接口调用信息。

| 字段 | 说明 |
|------|------|
| 名称 | 方法名称（业务可读） |
| 编码 | 方法编码（技术识别） |
| 请求方式 | 例如 `GET`、`POST` |
| 请求路由 | 例如 `api/product/get-product-infos` |

说明：
- 最终请求地址通常由 `主机地址 + 请求路由` 组合得到
- 建议先固定方法编码，再在表单侧做映射，避免后续频繁改动

### 2.3 维护入参

在接口方法详情的 `入参` 区域维护参数定义。

| 字段 | 说明 |
|------|------|
| 名称 | 参数显示名称 |
| 字段编码 | 参数编码（供映射识别） |
| 数据类型 | 需与表单映射字段类型匹配 |

使用建议：
- 只保留业务真正需要的查询参数
- 参数编码保持稳定，减少表单映射失效风险

### 2.4 维护出参

在接口方法详情的 `出参` 区域维护返回字段定义。

| 字段 | 说明 |
|------|------|
| 名称 | 返回字段显示名称 |
| 字段编码 | 返回字段编码（供赋值识别） |
| 是否显示 | 控制该字段是否在查询结果中展示 |
| 显示排序 | 控制列表展示顺序 |

使用建议：
- 仅保留需要回填或需要给用户辨识的字段
- 优先展示主标识字段，方便用户在弹层中选中正确记录

### 2.5 启用与可用性检查

完成应用、方法、入参、出参配置后，确认状态为 `启用`，再进入表单布局配置。

## 3 在表单布局中启用外部实时填充

前置条件：
- 已在集成管理中维护可用接口应用和方法
- 表单对象中已准备好需要回填的业务字段

### 3.1 启用引用外部数据

在字段控件编辑面板中，开启 `引用外部数据` 开关。

开启后，系统会显示外部接口相关配置区域。

### 3.2 引用外部数据页签结构

字段控件编辑通常包含 `基础配置` 与 `引用外部数据` 两个页签。外部实时填充相关配置都在 `引用外部数据` 页签完成。

页签中的主配置区包括：

| 区域 | 说明 |
|------|------|
| 接口应用 | 选择可被当前控件引用的接口应用 |
| 接口方法 | 必填。选择接口应用下的查询方法 |
| 入参映射 | 将接口入参与字段值或用户输入值建立映射关系 |
| 赋值 | 将接口出参与当前对象字段建立回填关系 |

说明：
- 先选 `接口应用`，再选 `接口方法`
- 选定接口方法后，`入参映射` 与 `赋值` 才能按该方法参数定义进行配置

### 3.3 选择接口应用与接口方法

| 配置项 | 说明 |
|---------|------|
| 接口应用 | 先选项。选择集成管理中允许被表单引用的应用 |
| 接口方法 | 必填。选择该应用下用于查询的接口方法 |

使用建议：
- 先确认方法入参、出参定义，再做后续映射
- 接口方法变更后，建议重新检查入参映射和出参赋值

### 3.4 配置入参映射（卡片式）

入参映射用于设置“调用接口时带什么条件”。此项可不填。

每条映射规则包含以下信息：

| 项 | 说明 |
|---|------|
| 接口入参 | 来自所选接口方法的入参定义 |
| 参数来源 | 支持 `指定字段`、`用户输入` |
| 值 | 字段值，或用户输入值 |

规则说明：
- 选择 `指定字段` 时，`值` 从当前对象可用字段中选择，且字段类型需与接口入参类型匹配
- 选择 `用户输入` 时，`值` 由业务用户在查询时输入
- 支持新增和删除多条映射规则

卡片内常见控件：

| 控件 | 说明 |
|------|------|
| `入参` | 必填。下拉选择接口方法中定义的入参 |
| `参数来源` | 选择映射值来源，仅支持 `指定字段`、`用户输入` |
| `值` | 必填。根据“参数来源”选择字段或配置用户输入值 |
| `删除` | 删除当前映射卡片 |
| `+ 添加` | 继续新增一条入参映射 |

### 3.5 配置赋值（卡片式）

出参赋值用于设置“接口返回后把哪些值写到表单哪些字段”。

规则说明：
- 仅支持映射到当前表单中的非系统字段
- 目标字段类型需与接口出参类型匹配
- 可配置多条赋值映射

卡片内常见控件：

| 控件 | 说明 |
|------|------|
| `出参` | 必填。下拉选择接口方法中定义的出参 |
| `字段` | 必填。选择当前对象中需要回填的目标字段 |
| `删除` | 删除当前赋值卡片 |
| `+ 添加` | 继续新增一条赋值映射 |

配置建议：
- 一个出参建议只映射到一个目标字段，避免回填含义冲突
- 优先配置业务主标识字段，再配置补充字段

---

## 4 业务端使用方式

配置生效后，用户在业务端填写该字段时会看到查询图标（放大镜）。

操作流程：
1. 点击查询图标
2. 系统按入参映射调用外部接口并展示结果列表
3. 在弹出面板中按可搜索字段筛选目标记录
4. 选中记录并确认
5. 系统按出参赋值规则回填当前表单字段

补充说明：
- 弹出面板可搜索字段范围由接口参数配置决定
- 若未配置入参映射，则接口按默认条件或空条件查询（以接口实现为准）

---

## 5 配置限制与注意事项

| 项 | 说明 |
|---|------|
| 必填项 | 接口方法、入参映射卡片中的 `入参/值`、赋值卡片中的 `出参/字段` 为必填 |
| 字段类型匹配 | 入参映射与出参赋值均要求类型匹配 |
| 系统字段限制 | 出参赋值不支持映射到系统字段 |
| 映射维护 | 接口参数定义变更后需同步检查映射配置 |

---

## 6 常见问题

| 现象 | 排查方向 |
|------|------------|
| 业务端未出现查询图标 | 检查控件是否开启 `引用外部数据`，以及该控件当前是否被隐藏或不渲染 |
| 点击查询后无结果 | 检查入参映射条件是否过严，或接口本身返回为空 |
| 无法选择目标字段做赋值 | 检查字段是否为系统字段，或字段类型与接口出参不匹配 |
