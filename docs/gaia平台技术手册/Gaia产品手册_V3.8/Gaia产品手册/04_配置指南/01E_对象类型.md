# 对象类型
> 本文介绍如何在 Gaia 平台中配置对象类型，重点覆盖对象类型列表、字段矩阵、动作矩阵以及新建和编辑对象类型。   

---

## 概述

对象类型用于在同一对象下区分不同业务子类型，并基于对象类型控制字段与动作的适用范围。
对象启用对象类型后，权限集和生命周期状态安全都支持按对象类型设置字段权限与动作权限。

### 访问路径

`配置端 > 配置管理 > 对象管理 > 对象 > 目标对象 > 对象类型`

使用前提：
- 目标对象已在基础设置中启用 `对象类型`。
- 对象启用 `对象类型` 后，系统会自动创建一个对象类型：`基础类型`。

---

## 1\. 对象类型页签

对象详情页中的“对象类型”页签用于维护“字段/动作”在不同对象类型下的适用范围。

### 1.1 页面入口与页签

在对象详情页进入“对象类型”页签时，页面通常显示如下导航路径：

`所有的对象 > {对象名称} > 对象类型（字段）`

### 1.2 页面操作按钮

对象类型页签右上角提供以下操作入口：

| 按钮 | 说明 |
|------|------|
| 字段动作切换器 | 切换矩阵视图。可选项包括“字段”“动作”。选择“字段”时进入字段矩阵，选择“动作”时进入动作矩阵。 |
| 创建类型 | 新建对象类型记录。 |
| 管理对象字段 | 进入对象字段管理入口，维护当前对象下可用字段。 |
| 管理对象动作 | 进入对象动作管理入口，维护当前对象下动作。 |

### 1.3 字段矩阵

字段矩阵用于维护“对象类型 - 字段”对应关系。页面由“字段行 \+ 对象类型列”组成：
- 左侧为字段列表（字段名）。
- 顶部为对象类型列（展示对象类型名称和 Code）。
- 交叉单元格用于标识该字段是否应用于该对象类型。

矩阵读法：
- 单元格显示 `√`：该字段已分配给对应对象类型。
- 单元格为空：该字段未分配给对应对象类型。
- 支持重写标记时，表示该字段可在对象类型维度做差异化配置。

字段矩阵主要用于：
- 区分“对象通用字段”和“对象类型专属字段”。
- 在同一对象下按对象类型控制字段可见性与适用范围。
- 快速核对不同对象类型之间的字段配置差异。
- 支持覆写的字段类型包括：数字、文本、布尔、日期时间、选项、对象、父对象。

### 1.4 动作矩阵

当右上角下拉切换到“动作”后，页面显示“对象类型 - 动作”矩阵，用于控制动作适用范围。

动作矩阵主要用于：
- 控制某个动作是否对指定对象类型生效。
- 在同一对象下按对象类型区分可执行动作。
- 降低无关动作暴露，减少误操作。

## 2\. 对象类型详情与维护

### 2.1 新建对象类型

对象类型页签支持创建对象类型。

创建页典型面包屑为：`所有的对象 > {对象名称} > 创建对象类型`。

页面“详情”区域包含以下字段：

| 字段 | 是否必填 | 说明 | 配置建议 |
|------|------------|------|------------|
| 名称 | 是 | 对象类型的显示名称。 | 建议使用业务可识别名称，便于在列表、筛选和配置页面快速区分。 |
| Code | 是 | 对象类型编码（API 名称）。界面显示后缀 `&#95;c`。 | 建议使用英文或英文缩写并保持语义清晰；命名规则与唯一性校验规则待补充。 |
| 状态 | 是 | 对象类型状态。 | 新建后通常先设为“启用”；如需灰度发布可先停用。 |
| 排序 | 否 | 控制对象类型在下拉列表等位置的展示顺序。 | 建议按业务常用顺序填写连续数字，便于后续维护。 |

操作步骤：
1. 进入对象的“对象类型”页签，点击“创建对象类型”。
2. 在“详情”区域依次填写名称、Code、状态、排序（可选）。
3. 点击右上角“保存”完成创建。

### 2.2 编辑对象类型

对象类型详情页用于查看对象类型信息，并维护该对象类型关联的字段、布局、动作和验证规则。

详情页典型面包屑为：`所有的对象 > {对象名称} > 编辑{对象类型名称}`。

#### 2.2.1 页面顶部按钮

| 按钮 | 说明 |
|------|------|
| 返回 | 返回对象类型列表页。 |
| 删除 | 删除当前对象类型。 |
| 编辑 | 进入编辑模式，修改对象类型基础信息。 |

#### 2.2.2 详情区域

详情区域展示当前对象类型的基础信息，包含以下字段：

| 字段 | 说明 |
|------|------|
| 名称 | 对象类型名称。 |
| Code | 对象类型编码（示例：`aaa&#95;c`）。 |
| 状态 | 对象类型状态（示例：启用）。 |
| 摘要 | 对象类型摘要信息（未填写时显示 `N/A`）。 |
| 排序 | 对象类型排序值。 |

#### 2.2.3 字段列表

“字段列表”用于查看当前对象类型已关联字段，并从该列表进入字段级配置。列表列如下：

| 列名 | 说明 |
|------|------|
| 字段名称 | 字段显示名称。 |
| Code | 字段编码。 |
| 来源 | 字段来源（如：标准、自定义）。 |
| 数据类型 | 字段数据类型（如：文本、对象、选项、数字、附件、组件等）。 |
| 状态 | 字段状态（启用/停用）。 |
| 操作 | 通过齿轮按钮进入该字段在当前对象类型下的维护入口。 |

#### 2.2.4 表单列表

“表单列表”用于查看当前对象类型可用的表单布局。列表列如下：

| 列名 | 说明 |
|------|------|
| 布局名称 | 表单布局名称。 |
| Code | 表单布局编码。 |
| 对象类型 | 该表单布局归属的对象类型。 |
| 来源 | 布局来源（标准/自定义）。 |
| 最后修改时间 | 布局最后修改时间。 |
| 操作 | 通过齿轮按钮进入布局维护入口。 |

#### 2.2.5 列表布局

“列表布局”用于查看当前对象类型可用的列表布局。列表列如下：

| 列名 | 说明 |
|------|------|
| 列表布局名称 | 列表布局名称。 |
| Code | 列表布局编码。 |
| 来源 | 布局来源（标准/自定义）。 |
| 对象类型 | 布局归属对象类型。 |
| 操作 | 通过齿轮按钮进入布局维护入口。 |

#### 2.2.6 动作列表

“动作列表”用于展示当前对象类型已配置动作。列表列如下：

| 列名 | 说明 |
|------|------|
| 名称 | 动作名称。 |
| 按钮名称 | 前端展示按钮名称。 |
| Code | 动作编码。 |
| 状态 | 动作状态。 |
| 操作 | 通过齿轮按钮进入动作维护入口。 |

当未配置动作时，列表显示“暂无数据”。

#### 2.2.7 验证规则

“验证规则”用于查看与维护当前对象类型验证规则，区域右上角提供“创建”按钮。列表列如下：

| 列名 | 说明 |
|------|------|
| 名称 | 验证规则名称。 |
| Code | 验证规则编码。 |
| 来源 | 验证规则来源（标准/自定义）。 |
| 状态 | 验证规则状态。 |
| 验证字段 | 验证规则关联字段。 |
| 操作 | 通过齿轮按钮进入验证规则维护入口。 |

### 2.3 默认对象类型

启用对象类型的对象支持设置默认对象类型。

规则如下：
- 对象首次启用 `对象类型` 时，系统自动创建 `基础类型`，无需手工创建。
- 默认对象类型默认情况下为基础对象类型。
- 默认对象类型需从启用状态的对象类型中选择。
- 默认对象类型不支持停用。

### 2.4 权限配置联动

对象启用对象类型后，可在以下位置按对象类型配置权限：

| 配置位置 | 可配置权限 |
|------------|---------------|
| 权限集 | 按对象类型设置字段权限、动作权限 |
| 生命周期状态安全 | 按对象类型设置字段权限、动作权限 |

### 2.5 字段覆写

对象类型支持字段覆写。字段分配到对象类型后，可在对象类型详情页的字段列表中，通过行操作进入字段覆写页面。

进入对象类字段覆写页时，页面导航路径示例：

`所有的对象 > {对象名称} > {对象类型名称} > 重写 {字段类型}`

对象类字段覆写页包含以下区域：

| 区域 | 说明 |
|------|------|
| 详情 | 展示字段名称、Code、来源、字段类型。 |
| 设置选项 | 配置该字段在当前对象类型下的可覆写项（如必填、约束引用对象中的记录）。 |
| 默认值 | 配置该字段在当前对象类型下的默认值。 |

规则说明：
- 其他支持覆写的字段类型，使用相同入口进入各自的“重写 \{字段类型\}”页面。
- 不同字段类型的可覆写项会按字段类型显示，配置方式保持一致。

---

## 3\. 使用建议
- 当对象需要区分多种业务子场景，但仍希望复用同一对象时，可优先考虑对象类型。
- 若某些字段只适用于少数业务场景，建议通过对象类型字段矩阵进行隔离。
- 若某些动作只对特定业务子类型开放，建议通过对象类型动作矩阵控制。
