\# 字段配置条件设置
> 本文用于说明在管理端配置条件时，不同字段类型可用的逻辑运算符、逻辑值类型与输入方式。   

---

## 概述

字段配置条件用于控制“规则在什么情况下生效”，常见于生命周期、工作流、引用约束、列表布局过滤等配置场景。

一个完整条件通常由以下部分组成：
- 条件字段
- 逻辑运算符
- 逻辑值类型（如指定常量、指定字段、指定变量）
- 逻辑值

## 配置入口

不同模块入口略有差异，但条件配置区的交互一致。以对象字段相关配置为例，可通过以下路径进入：

`配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 相关配置页（如字段、生命周期、布局、工作流） > 条件设置`

## 名词解释
- `主对象`：在动态约束场景中，为条件提供取值来源的对象。例如在“偏差对象”的用户字段上配置引用约束时，偏差对象即为主对象。

## 典型使用场景
- 列表布局数据过滤
- 生命周期进入条件
- 生命周期进入条件验证
- 生命周期进入动作条件
- 生命周期用户动作条件
- 生命周期事件动作条件
- 工作流动作步骤执行条件
- 工作流判断步骤字段条件
- 工作流参与人筛选条件
- 作业数据筛选条件
- 联动数据范围设置
- 文档生命周期模板条件
- 自定义匹配规则数据条件
- 引用约束
- 表单布局相关对象过滤条件
- 动态用户组动态组员规则条件

## 通用规则
- 部分场景只存在一种逻辑值类型（通常是`指定常量`），此时界面可能不显示“逻辑值类型”控件。
- 不同字段类型支持的运算符、值控件不同，不能跨类型套用。
- `已变更（changed）`仅用于“生命周期事件动作条件：修改记录”，且仅限当前对象字段。
- 日期/日期时间比较会受字段精度影响；比较时间值时使用系统时区。

## 字段类型支持矩阵

| 字段类型 | 常用逻辑运算符 | 逻辑值类型 | 值输入控件/方式 | 关键说明 |
|------------|---------------------|---------------|----------------------|------------|
| 文本/链接 | 等于、不等于、包含、不包含、开始于、结束于、为空、不为空、已变更 | 指定常量、指定字段（为空/不为空/已变更除外） | 文本输入框（常量）、字段选择器 | 文本比较大小写敏感；文本常量最大 200 字符。 |
| 数字 | 等于、不等于、大于、大于等于、小于、小于等于、介于、为空、不为空、已变更 | 指定常量、指定字段（为空/不为空/已变更除外） | 数字输入框、范围输入框、字段选择器 | 精度参与比较，例如 `1` 与 `1.0` 不相等。 |
| 选项/对象类型/生命周期状态/所属质量组织/角色 | 等于、不等于、包含、包含于、不包含于、包含全部、全部包含于、为空、不为空、已变更 | 指定常量、指定字段、指定变量（部分字段可用） | 单选/多选选择器、字段选择器、变量选择器 | 单选选项不支持“包含”；多选选项不支持“包含于”；集合运算见下文。 |
| 用户 | 与对象类条件能力一致（以具体场景实际显示为准） | 指定字段、指定变量 | 字段选择器、变量选择器 | 变量支持`当前用户`。 |
| 日期时间/日期 | 等于、不等于、大于、大于等于、小于、小于等于、在过去、在未来、不在过去、介于、为空、不为空、已变更 | 指定常量、指定字段、指定变量（在过去/在未来/不在过去除外） | 日期选择控件、日期范围控件、偏移量\+单位（天/周/月/年）、字段选择器、变量选择器 | 变量支持`当前日期`（日期字段）和`当前时间`（日期时间字段）；比较按系统时区。 |
| 布尔 | 等于、为空、不为空、已变更 | 指定常量、指定字段（为空/不为空/已变更除外） | 下拉（是/否）、字段选择器 | 常用于开关类状态判断。 |
| 附件 | 为空、不为空、已变更 | 无 | 无 | 不支持常量/字段比对。 |
| 对象（单选） | 为空、不为空、已变更 | 无 | 无 | 主要用于存在性判断。 |
| 对象（多选） | 包含/不包含（按场景）、为空、不为空 | 常量、变量、字段（按场景） | 多选选择器、字段/变量选择器 | 不同场景支持差异较大，见“对象多选场景差异”。 |
| 富文本/长文本 | 为空、不为空、已变更 | 无 | 无 | 主要用于空值与变更判断。 |
| 公式字段/Lookup字段/统计字段 | 由返回类型决定 | 由返回类型决定 | 按返回类型对应控件 | 例如返回数值则按数字字段规则处理。 |

## 选项与集合运算说明

以下说明适用于多选语义字段（如多选选项等）：
- `包含（includes）`：左值与右值有交集即可命中。
- `包含于（in）`：左值必须完全落在右值集合内。
- `不包含于（not in）`：左值不是右值集合的子集。
- `包含全部`：左值必须覆盖右值全部元素（可相等）。
- `全部包含于`：左值全部元素都在右值中（可相等）。

示例（风险来源可选：变更、审计、偏差）：
- 条件 `风险来源 包含 变更,审计`：记录为`审计,偏差`可命中（有交集）。
- 条件 `风险来源 包含于 变更,审计`：记录为`审计,偏差`不命中（含偏差，超出右值集合）。

## 运行时变量说明
- `当前质量组织`：仅在字段对象为质量组织且运算符为等于/不等于/包含等支持变量的场景可用，取值为业务端右上角当前质量组织。
- `当前用户`：在用户相关字段支持变量的场景可用。
- `当前日期`：用于日期字段比较。
- `当前时间`：用于日期时间字段比较。

## 对象多选场景差异

| 场景 | 支持运算符 | 逻辑值类型限制 | 备注 |
|------|---------------|---------------------|------|
| 列表布局数据过滤 | 包含、为空、不为空 | 常量、变量（包含）；为空/不为空无值类型 | 入站关系中的多选字段同样仅支持为空/不为空。 |
| 生命周期进入条件（及进入条件验证、进入动作、用户动作、事件动作） | 包含、不包含、为空、不为空 | 常量、变量、字段（包含/不包含） | 常量仅支持质量组织、用户组、角色；变量与单对象一致（当前质量组织、当前部门、当前用户）。 |
| 工作流动作步骤执行条件、工作流判断步骤字段条件 | 同生命周期进入条件 | 同生命周期进入条件 |  |
| 表单布局相关对象过滤条件 | 包含、不包含、为空、不为空 | 常量、变量、字段 | 与生命周期进入条件一致。 |
| 表单布局规则条件 | 同表单布局相关对象过滤条件 | 逻辑值仅支持字段 |  |
| 文档生命周期模板条件 | 同生命周期进入条件 | 同生命周期进入条件 |  |
| 自定义匹配规则数据条件 | 不支持多选对象字段 | - | 需在配置端屏蔽多选对象字段。 |

## 配置步骤（通用）
1. 在目标配置页新增或编辑一条条件。
2. 选择条件字段。
3. 选择逻辑运算符。
4. 选择逻辑值类型。
5. 输入或选择逻辑值。
6. 保存并在目标业务场景验证命中结果。

## 注意事项
- 日期/日期时间比对前，先确认字段精度与系统时区，避免“同日不同时间”导致误判。
- 使用`指定字段`时，优先选择主对象中语义一致、类型一致的字段。
- 使用集合运算符（包含于/包含全部等）前，先确认字段是单选还是多选。
- `已变更（changed）`不用于普通过滤场景，只用于修改记录事件相关条件。
