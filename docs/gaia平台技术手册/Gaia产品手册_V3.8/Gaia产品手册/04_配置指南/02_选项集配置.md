# 选项集配置
> 本文说明如何在 Gaia 平台中创建、查看和维护选项集，以及如何管理选项集中的选项值。   

---

## 概述

选项集用于统一维护选项字段的可选值。配置人员创建选项字段后，可以为字段引用一个已有选项集，从而在多个字段之间复用同一组选项值。

### 访问路径

进入 **配置环境** \> **配置管理** \> **对象管理** \> **选项集**。

---

## 1\. 选项集列表页

选项集列表页按页展示当前环境中的全部选项集。你可以在这里完成新建、查询、查看和编辑等常用操作。

### 1.1 页面常用入口

列表页分页展示当前环境中的所有选项集。通过右上角的 **创建** 按钮可以新建选项集；通过页面上方的查询框和查询按钮可以按名称等关键字快速检索目标选项集。

在列表内容区中，点击选项集名称可以进入该选项集的查看页面；点击操作列中的操作入口，可以打开当前记录的操作菜单并进入编辑页面。

### 1.2 列表字段说明

| 字段 | 说明 |
|------|------|
| 名称 | 选项集名称 |
| 选项类型 | 当前选项集的类型 |
| 是否系统选项 | 标识该选项集是否为系统内置选项集 |
| 操作 | 操作列显示 `编辑`。点击后进入编辑页面，可修改选项集定义和选项值 |

### 1.3 操作菜单

列表页的操作菜单当前仅提供 `编辑` 操作。点击后会进入当前选项集的编辑页面，用于修改选项集定义和选项值。

---

## 2\. 查看选项集

点击选项集名称后，进入查看页面，可以核对当前选项集的基本信息和选项值列表。

### 2.1 页面结构与按钮

查看页面顶部通过面包屑 `所有的选项集 > {选项集名称}` 标识当前位置。右上角的 `返回` 用于回到选项集列表页，`编辑` 用于进入当前选项集的编辑页面。页面主体的 `详情` 区域用于展示当前选项集的基本信息。

### 2.2 详情区信息

详情区显示当前选项集的 `名称` 和 `Code`，用于确认该选项集的标识信息。

### 2.3 选项值列表

查看页面下方展示当前选项集包含的全部选项值，用于核对该选项集的配置内容。该列表用于查看，不提供行内操作。

| 列 | 说明 |
|---|------|
| 排序 | 选项值在列表中的显示顺序 |
| 名称 | 选项值的显示名称 |
| Code | 选项值的唯一编码 |
| 状态 | 选项值当前是否启用 |

---

## 3\. 创建和编辑选项集

通过列表页右上角的 **创建** 按钮可以新建选项集；通过列表页操作菜单或查看页右上角的 **编辑** 按钮可以修改已有选项集。

### 3.1 编辑页结构与按钮

编辑页面顶部同样通过面包屑 `所有的选项集 > {选项集名称}` 标识当前位置。右上角的 `取消` 用于放弃当前修改并离开编辑页面，`保存` 用于提交本次修改。页面主体的 `详情` 区域用于维护选项集基本信息和选项值列表。

### 3.2 编辑页可维护内容

在编辑页面中，可以直接修改选项集 `名称`；`Code` 在页面中以只读形式展示，用于确认当前选项集编码。

### 3.3 编辑页中的选项值维护

编辑页下方展示当前选项集的选项值列表。你可以直接拖动排序手柄调整顺序，行内修改选项值名称，查看对应的 `Code` 和状态，也可以通过 `停用` 停用单条选项值。列表下方的 `添加选项` 用于新增单条选项值，`批量添加` 用于一次性新增多条选项值。

### 3.4 保存结果
- 保存成功后，系统会更新该选项集定义和选项值列表。
- 字段引用该选项集后，会使用当前启用状态的选项值作为候选项。

---

## 4\. 管理选项值

选项值是选项集中的具体可选项。配置人员可以在编辑页面维护选项值的名称、编码、状态和排序。

### 4.1 选项值状态

| 状态 | 说明 |
|------|------|
| 启用 | 业务端用户可以选择该选项值 |
| 停用 | 业务端用户不能再选择该选项值；已保存数据中的原值保留不变 |

### 4.2 排序

选项值的排序决定其在业务端候选列表中的展示顺序。调整排序后，字段下拉列表会按新的顺序显示。

### 4.3 新增与停用
- 点击 **添加选项** 可新增单条选项值。
- 点击 **批量添加** 可一次性新增多条选项值。
- 点击 **停用** 后，当前选项值不再提供给业务端用户选择。

### 4.4 批量添加

点击 **批量添加** 后，系统会打开批量添加弹窗，用于一次性录入多条选项值。

弹窗中的文本输入框用于录入需要新增的选项值内容；`取消` 用于关闭弹窗且不保留本次输入，`确定` 用于按当前输入内容批量生成选项值。

批量添加的输入规则如下：
- 每行录入一条选项值。
- 名称和 Code 之间使用英文逗号分隔。
- 点击 **确定** 后，系统会按输入内容批量新增选项值到当前选项集。

### 4.5 使用影响
- 修改选项集会影响所有引用该选项集的字段。
- 停用选项值不会清除历史记录中的已有值。

---

## 5\. 与字段配置的关系

配置选项字段时，可以选择一个已有选项集作为字段的数据来源。

### 5.1 字段中的使用方式
1. 创建字段时选择字段类型为 `选项`。
2. 在字段配置中选择要引用的选项集。
3. 保存字段后，业务端会按选项集定义展示可选值。

### 5.2 选项依赖

如果需要根据上游字段值动态控制下游可选项，请结合 [字段选项依赖](01N_%E5%AD%97%E6%AE%B5%E9%80%89%E9%A1%B9%E4%BE%9D%E8%B5%96.md) 一起配置。
