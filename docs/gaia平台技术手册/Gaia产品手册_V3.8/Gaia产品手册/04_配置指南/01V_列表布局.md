# 列表布局
> 本文介绍如何在 Gaia 平台中创建、查看、编辑、删除和复制对象的列表布局。   

---

## 概述

列表布局用于定义对象记录在业务端列表页中的默认展示方式。配置人员可通过列表布局控制显示字段、数据过滤条件、树形列表展示方式，以及是否启用列表行内编辑。

### 访问路径

`配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 列表布局`

---

## 1\. 列表布局列表页

进入 `配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 列表布局` 后，可查看当前对象已配置的列表布局，点击名称进入详情页，并通过操作菜单执行编辑、删除和复制操作。

### 1.1 页面常用入口

| 页面元素 | 作用 |
|------------|------|
| 面包屑导航 | 用于显示当前对象上下文，页面中显示为 `所有的对象 &gt; {对象名称}`，帮助用户确认正在配置哪个对象的列表布局 |
| 对象内页签 | 用于在同一对象下切换 `基础 / 对象类型 / 字段 / 搜索字段 / 关系 / 列表布局 / 表单布局 / 动作 / 验证规则 / 索引规则` 等配置页 |
| `创建` | 新建列表布局 |
| 列表布局名称 | 点击名称可进入对应列表布局详情页 |
| 操作列 | 通过齿轮菜单进入当前列表布局的编辑、删除和复制操作 |

### 1.2 列表主要字段

| 字段 | 说明 |
|------|------|
| 列表布局名称 | 列表布局名称；点击名称可进入详情页 |
| Code | 列表布局唯一编码 |
| 对象类型 | 标识该布局适用的对象类型 |
| 来源 | 标识该布局来自系统自动创建还是手动创建；系统自动创建的列表布局来源显示为 `标准`，手动创建的列表布局来源显示为 `自定义` |
| 操作 | 点击齿轮按钮后打开操作菜单 |

### 1.3 操作菜单

列表页每一行右侧提供齿轮按钮。点击后可打开当前列表布局的操作菜单。当前操作菜单仅提供 `编辑`、`删除` 和 `复制` 3 项操作。

| 操作 | 作用 |
|------|------|
| `编辑` | 进入当前列表布局的编辑页 |
| `删除` | 删除当前列表布局；标准列表布局不允许删除，不允许删除时该操作显示为灰色不可用 |
| `复制` | 复制当前列表布局，生成一份新的列表布局作为调整基础 |

### 1.4 复制列表布局

在列表布局列表页点击某一行右侧的齿轮按钮后，选择 `复制`，系统会打开复制弹窗。复制弹窗用于在保留原有布局配置的基础上，快速生成新的列表布局。

复制弹窗中需要填写或确认以下内容：

| 字段 | 作用 | 备注 |
|------|------|------|
| 名称 | 新列表布局的显示名称 | 必填，在当前对象内唯一 |
| Code | 新列表布局的唯一编码 | 必填，保存后作为新布局的唯一标识 |
| 对象类型 | 新列表布局适用的对象类型 | 必填 |

复制弹窗底部提供以下按钮：

| 按钮 | 作用 |
|------|------|
| `取消` | 关闭复制弹窗，不生成新的列表布局 |
| `确定` | 按当前输入内容生成新的列表布局 |

点击 `确定` 后，系统会复制原列表布局的基础配置、显示字段和数据过滤配置，并生成一条新的列表布局记录，供配置人员继续修改。

## 2\. 创建列表布局

列表布局支持自动创建和手动创建两种方式。

### 2.1 创建方式

| 方式 | 说明 |
|------|------|
| 自动创建（对象） | 创建对象时，系统自动生成标准列表布局，名称为 `所有的{对象名称}`，Code 为 `{对象Code}&#95;table&#95;&#95;ak` |
| 自动创建（对象类型） | 启用对象类型后，系统会为该对象类型自动创建一个列表布局，来源显示为 `标准` |
| 手动创建 | 配置人员在列表布局页签中点击 `创建`，新增自定义列表布局 |

### 2.2 创建页结构与按钮

进入创建页后，页面顶部显示面包屑 `所有对象 > {对象名称} > 列表布局 > 创建`，用于帮助用户确认当前正在为哪个对象创建列表布局。

创建页顶部提供以下按钮和页签：

| 页面元素 | 作用 |
|------------|------|
| 面包屑导航 | 用于显示当前路径，并支持返回上一级对象上下文 |
| `返回` | 放弃本次创建并返回列表布局列表页 |
| `保存` | 保存当前列表布局配置 |
| `基础` | 配置列表布局基本信息 |
| `显示字段` | 配置列表默认显示的字段 |
| `数据过滤` | 配置列表数据过滤条件 |

### 2.3 创建页核心属性

| 属性 | 说明 | 备注 |
|------|------|------|
| 列表布局名称 | 列表布局的显示名称 | 必填，长度为 1-200 字符，在当前对象内唯一 |
| Code | 列表布局唯一编码 | 必填；输入编码主体后，系统按规则拼接完整 Code；保存后不可修改 |
| 对象类型 | 列表布局适用的对象类型 | 必填，从当前对象已启用的对象类型中选择 |
| 状态 | 控制列表布局是否启用 | 创建页默认显示为 `启用` |
| 来源 | 标识布局来源 | 手动创建时显示为 `自定义` |
| 默认排序设置 | 配置列表默认排序字段和排序方向 | 点击 `新增` 后添加排序规则 |
| 描述 | 对列表布局用途的补充说明 | 用于帮助配置人员识别布局用途 |
| 数据权限：以系统账号运行 | 控制列表查询时是否按系统账号方式执行数据权限计算 | 勾选后生效 |
| 仅显示一层标题 | 控制列表标题的显示层级 | 勾选后，列表标题只显示一层标题 |

### 2.4 创建结果
- 自动创建的标准列表布局默认存在，不允许删除。
- 列表布局创建完成后，还需要继续配置显示字段和数据过滤条件，列表布局才能用于业务端展示。

## 3\. 查看列表布局详情

列表布局详情页用于查看当前布局的基础信息和配置结果。

### 3.1 详情页展示内容

| 模块 | 展示内容 |
|------|------------|
| 基本信息 | 名称、Code、来源、对象类型、状态、描述 |
| 配置内容 | 显示字段、数据过滤条件、树形展示设置、行内编辑设置 |

### 3.2 详情页操作

| 按钮 | 作用 |
|------|------|
| `返回` | 返回列表布局列表页 |
| `编辑` | 进入列表布局编辑页 |
| `删除` | 删除当前列表布局；标准列表布局不允许删除 |
| `复制` | 打开复制弹窗，生成一份新的列表布局；复制规则参见 `1.4 复制列表布局` |

---

## 4\. 编辑列表布局

列表布局编辑页用于维护列表展示规则。

### 4.1 可编辑属性

| 分类 | 属性 | 说明 |
|------|------|------|
| 基本信息 | 列表布局名称 | 可修改 |
| 基本信息 | 状态 | 可修改 |
| 基本信息 | 描述 | 可修改 |
| 配置内容 | 显示字段 | 可修改，支持添加、移除和调整顺序 |
| 配置内容 | 数据过滤条件 | 可修改 |
| 配置内容 | 启用列表行内编辑 | 可修改，默认不启用 |
| 配置内容 | 展示为树形列表 | 对象启用树形结构后可修改 |

### 4.2 不可编辑属性

| 属性 | 说明 |
|------|------|
| Code | 列表布局保存后固定，不允许修改 |
| 来源 | 根据创建方式自动生成，不允许修改 |
| 所属对象 | 列表布局创建后归属对象固定 |
| 所属对象类型 | 创建后不支持切换到其它对象类型 |

## 5\. 配置显示字段

显示字段用于控制业务端列表默认展示哪些列。

### 5.1 显示字段页

进入列表布局的 `显示字段` 页签后，页面会按当前字段顺序展示已配置的列表列。

显示字段页包含以下内容：

| 页面元素 | 作用 |
|------------|------|
| `显示字段` 页签 | 用于维护当前列表布局的显示字段 |
| `排序` | 调整显示字段的顺序 |
| `添加列` | 新增列表显示字段 |
| `序号` | 显示字段当前的排列顺序 |
| `字段名称` | 显示字段在界面中的名称 |
| `Code` | 显示字段对应的系统编码 |
| `默认宽度` | 设置该列在列表中的默认显示宽度 |
| 操作列 | 通过齿轮菜单维护当前显示字段的行级操作 |

### 5.2 添加显示字段

点击页面中的 `添加列` 后，可在穿梭框中选择列表默认展示字段。可选字段包括：
- 当前对象的字段
- 当前对象出站关系对象的字段
- 出站关系对象本身及其字段

当选择出站关系字段作为显示字段时，列表列头按 `对象名称 > 字段名称` 的形式显示。

创建列表布局时，字段上已勾选 `在默认列表和悬浮卡中显示` 属性的字段会自动加入当前列表布局的显示字段中。

### 5.3 排序与顺序调整

点击页面右上角的 `排序` 后，可调整字段在列表中的显示顺序。调整后的顺序会直接影响业务端列表列的排列顺序。

### 5.4 默认宽度

`默认宽度` 用于设置列表列的默认展示宽度。配置人员可按字段内容长度设置更合适的宽度，减少业务端列表中出现字段内容被截断的情况。

### 5.5 行级操作

每个显示字段右侧提供齿轮按钮，用于对当前字段执行行级操作。该入口位于 `操作` 列。

显示字段页的行级操作只有 `删除`。点击后，会将该字段从当前列表布局的显示字段中移除，使该字段不再显示在该列表布局对应的业务端列表中；此操作不会删除字段本身，也不会影响对象字段配置。

字段上已勾选 `在默认列表和悬浮卡中显示` 属性时，该字段在创建列表布局时会自动加入显示字段，并且不允许在显示字段页中删除。

### 5.6 业务端自定义列与配置变更

如果用户已在业务端自定义显示列，而配置人员后续修改了列表布局，系统处理方式如下：
- 用户已保存的自定义显示列保持不变
- 用户再次打开自定义列编辑器时，可选字段范围按最新的列表布局配置显示

## 6\. 配置数据过滤

数据过滤用于控制业务端列表中可显示的记录范围。配置后，只有满足条件的记录才会出现在对应列表中。

列表布局中的数据过滤可用于以下场景：
- 对象主列表
- 表单中的相关对象列表
- 对象字段或父对象字段的候选记录列表

### 6.1 数据过滤页

进入 `数据过滤` 页签后，可在当前列表布局中配置记录过滤条件。页面顶部提供以下操作和入口：

| 页面元素 | 作用 |
|------------|------|
| `取消` | 放弃当前未保存的过滤条件修改，并返回上一页面 |
| `保存` | 保存当前列表布局中的数据过滤配置 |
| `过滤条件` | 展开或收起过滤条件编辑区 |
| `并且` | 按并且逻辑组合当前过滤条件 |
| `+` | 在当前条件组中新增一条过滤条件 |

### 6.2 配置过滤条件

在 `过滤条件` 区域中，按以下顺序完成数据过滤配置：
1. 点击 `+`，新增一条过滤条件。
2. 在第一项中选择 `字段`，确定需要参与过滤的对象字段。
3. 继续选择该字段支持的运算符和条件值。
4. 保存列表布局，使过滤条件在业务端列表中生效。

列表布局的数据过滤使用普通过滤模式时，条件之间固定按 `并且` 逻辑生效。只有同时满足全部条件的记录，才会显示在对应列表中。

### 6.3 保存校验

如果过滤条件中仍有未完成配置的项，页面会提示 `请完成所有条件的配置`。处理完成后才能保存当前列表布局。

过滤条件中的运算符、逻辑值类型和字段支持范围，参见 [字段配置条件设置](01M_%E5%AD%97%E6%AE%B5%E9%85%8D%E7%BD%AE%E6%9D%A1%E4%BB%B6%E8%AE%BE%E7%BD%AE.md)。

## 7\. 列表行内编辑

列表布局支持启用行内编辑。开启后，主列表和列表详情页中的相关对象列表都可直接在列表单元格内修改数据。

### 7.1 开启方式

在列表布局的常规设置中开启 `启用列表行内编辑`，默认值为未开启。

### 7.2 行内编辑生效规则
- 用户单击单元格后，系统会判断该字段是否支持编辑，以及当前用户是否具有编辑权限
- 不支持编辑时，单元格显示锁图标
- 双击或再次点击可编辑单元格后，单元格进入编辑模式
- 保存前会执行与表单一致的数据校验
- 引用约束在行内编辑模式下继续生效

### 7.3 不支持行内编辑的字段

以下系统字段不支持行内编辑：
- ID
- 生命周期状态
- 对象类型

以下字段类型不支持行内编辑：
- 公式
- 查找
- 统计

### 7.4 控制字段在行内编辑中的限制
- 如果被控字段设置为必填，则控制字段不允许行内编辑
- 如果被控字段不是必填，且用户修改了控制字段的值，系统会提示清空被控字段的值；确认后才执行保存
- 行内编辑模式下，表单规则不生效
- 移动端不支持列表行内编辑

## 8\. 树形列表展示

当对象启用了树形结构后，列表布局中会出现 `展示为树形列表` 设置项，默认选中。开启后，该列表布局在业务端按树形结构展示数据。

### 8.1 树形列表展示规则
- 列表默认只展示顶级节点数据
- 分页按第一层节点计算
- 点击节点名称旁的展开按钮后，逐层加载下级数据
- 树形结构最大支持 5 层

### 8.2 搜索与筛选

在业务端对树形对象进行搜索或筛选时，列表强制按平铺模式展示。

### 8.3 作为字段候选列表

当其它对象引用启用了树形结构的对象时，如果所使用的列表布局配置为树形展示，则对象选择器按树形结构展示候选记录。

树形结构本身的配置规则，参见 [对象启用树形结构](01S_%E5%AF%B9%E8%B1%A1%E5%90%AF%E7%94%A8%E6%A0%91%E5%BD%A2%E7%BB%93%E6%9E%84.md)。
