\# 更新共享设置节点配置

更新共享设置节点用于在流程运行过程中按规则动态添加或移除共享角色成员。

---

## 更新共享设置节点配置

更新共享设置节点用于在流程运行到该步骤时，按规则更新对象共享设置中的角色成员。常见场景是：在流程中临时把某个参与者组加入共享角色，流程继续推进后再移出。

该节点在新建/编辑页面的`详情`区域常见字段如下：

| 字段 | 说明 |
|------|------|
| **名称** | 节点显示名称。 |
| **Code** | 节点系统编码。 |
| **类型** | 固定为`更新共享设置`。 |
| **描述** | 节点用途说明。 |
| **下一步** | 当前节点执行后流转到的下一节点。 |

`更新共享设置`规则区（如“规则1”）常见配置如下：

| 配置项 | 是否必填 | 说明 |
|---------|------------|------|
| **工作流参与者组** | 是 | 选择要参与共享变更的工作流参与者组。 |
| **动作** | 是 | 选择共享变更动作，常见为`添加`或`删除`。 |
| **角色** | 是 | 选择共享设置中要操作的目标角色。 |

页面操作：
- 点击`添加规则`可继续新增规则块。
- 每条规则块右上角的`×`可删除该条规则。
- 点击右上角`保存`后，节点按已配置规则生效。

说明：
- 该小节描述的是**更新共享设置步骤节点**本身的配置。
- 与`任务节点的更新共享设置`不同，`任务节点的更新共享设置`描述的是工作流任务节点内基于事件触发的共享更新规则。
