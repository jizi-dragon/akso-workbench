\# 公式配置
> 本文说明如何在 Gaia 平台配置公式字段，包括公式编辑器使用方式、可用函数与运算符、异常处理规则和典型配置示例。   

---

## 1 概述

公式字段用于根据表达式自动计算字段值。 
配置后，字段值在业务端自动计算并展示，用户不能手工编辑该字段。

公式是平台内的通用能力，不限于公式字段本身。在多个配置场景下都可以复用同一套公式语法与公式编辑器。

### 1.1 访问路径

`配置环境 > 配置管理 > 对象管理 > 对象 > {目标对象} > 字段 > 创建/编辑`

### 1.2 适用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| 公式字段 | 使用公式计算字段值 | 总价 = 数量 × 单价 |
| 验证规则 | 使用公式表达式判断数据是否有效 | 开始日期 \<= 结束日期 |
| 设置字段默认值 | 使用公式动态生成默认值 | 创建日期 = `Today()` |
| 字段图标/字体样式 | 使用公式按条件返回图标或字体样式 | 状态=通过时显示绿色图标 |
| 工作流动作 | 在流程中使用公式回填或更新字段 | 到期日 = `DateAdd("day",7,today&#95;&#95;c)` |
| 自动计算日期 | 在已有日期基础上推算新日期 | 截止日期 = 当前截止日期 \+ 7 天 |
| 条件分支计算 | 根据字段值返回不同结果 | 根据状态返回不同标签文本 |
| 图标与字体展示 | 在公式结果中返回图标/字体样式 | 通过 `Icon()` 显示通过/不通过图标 |
| 文本拼接与格式化 | 拼接编码、名称或提示信息 | 前缀 \+ 编号 |

### 1.3 关键特性
- 公式字段是只读字段，不能手工输入。
- 公式字段值由表达式实时计算。
- 默认每个对象最多可配置 10 个公式字段。
- 公式字段不用于对象搜索字段索引配置。

---

## 2 公式字段配置步骤
1. 进入目标对象的 `字段` 页签，点击 `创建`。
2. 字段类型选择 `公式`。
3. 选择返回类型（文本、数字、日期、日期时间、布尔等）。
4. 在公式编辑器中编写表达式并执行 `语法检查`。
5. 保存字段配置，返回字段列表验证显示效果。

## 3 公式编辑器

公式字段通过统一公式编辑器进行配置。

![](assets/%E5%85%AC%E5%BC%8F%E7%BC%96%E8%BE%91%E5%99%A8.png "")

### 3.1 编辑器组成
- 编辑区：输入完整公式表达式。
- 语法检查：校验表达式语法是否可执行。
- 字段面板：插入当前对象可用字段。
- 变量面板：插入系统变量。
- 函数面板：按分类插入函数模板。
- 运算符面板：插入常用运算符。
- 图标面板：插入图标函数相关参数。

### 3.2 直接输入规则

| 输入类型 | 写法 | 说明 |
|------------|------|------|
| 字段 | `field&#95;code&#95;&#95;c` | 按字段 code 直接引用当前记录字段值。 |
| 文本常量 | `"文本"` 或 `'文本'` | 单/双引号包裹。 |
| 数字常量 | `100`、`3.14` | 直接输入数字。 |
| 布尔常量 | `true` / `false` | 不区分大小写。 |
| 选项常量 | `{!$picklist.pickcode.&#91;opcode1,opcode2]}` | 返回选项字段的一个或多个选项值。 |
| 系统变量 | 通过变量面板选择 | 支持当前用户、当前用户 Id、当前用户姓名、当前用户登录账号、当前用户所属部门、当前公司等。 |

|---|------|

| 返回类型 | 日期时间 |
| 示例 | `CalcWorkDay("2025-10-17 11:12:10",1)` → `2025-10-20 11:12:10`<br>`CalcWorkDay("2025-10-20 11:12:10",1)` → `2025-10-21 11:12:10` |

#### IsWorkday()

| 项 | 说明 |
|---|------|
| 用法 | `IsWorkday(DateTime&#91;,Calendar])` |

## 5 运算符与异常处理

### 5.1 常用运算符

| 类型 | 运算符 |
|------|---------|
| 数学运算 | `+``-``&#42;``/``%``()` |
| 比较运算 | `=``!=``&gt;``&gt;=``&lt;``&lt;=` |
| 逻辑运算 | `&amp;&amp;``&amp;#124;&amp;#124;` |
| 文本运算 | `&amp;` |

#### 5.1.1 数学运算符

| 运算符 | 名称 | 用法 | 说明 | 示例 |
|---------|------|------|------|------|
| `+` | 加 | `值1 + 值2` | 返回两个数值相加结果。 | `1+1` → `2` |
| `-` | 减 | `值1 - 值2` | 返回两个数值相减结果。 | `2-1` → `1` |
| `&#42;` | 乘 | `值1 &#42; 值2` | 返回两个数值相乘结果。 | `2&#42;2` → `4` |
| `/` | 除 | `值1 / 值2` | 返回两个数值相除结果。 | `8/2` → `4` |
| `%` | 取余 | `值1 % 值2` | 返回除法余数。 | `5%3` → `2` |
| `()` | 括号 | `(表达式)` | 改变计算优先级，优先计算括号内表达式。 | `(3+2)/5` → `1` |

#### 5.1.2 比较运算符

| 运算符 | 名称 | 用法 | 说明 | 示例 |
|---------|------|------|------|------|
| `=` | 等于 | `值1 = 值2` | 判断两个值是否相等。 | `1=1` → `true` |
| `!=` | 不等于 | `值1 != 值2` | 判断两个值是否不等。 | `1!=1` → `false` |
| `&gt;` | 大于 | `值1 &gt; 值2` | 判断左值是否大于右值。 | `2&gt;1` → `true` |
| `&gt;=` | 大于等于 | `值1 &gt;= 值2` | 判断左值是否大于或等于右值。 | `2&gt;=2` → `true` |
| `&lt;` | 小于 | `值1 &lt; 值2` | 判断左值是否小于右值。 | `1&lt;2` → `true` |
| `&lt;=` | 小于等于 | `值1 &lt;= 值2` | 判断左值是否小于或等于右值。 | `1&lt;=1` → `true` |

#### 5.1.3 逻辑运算符

| 运算符 | 名称 | 用法 | 说明 | 示例 |
|---------|------|------|------|------|
| `&amp;&amp;` | 与 | `表达式1 &amp;&amp; 表达式2` | 两个表达式都为 `true` 时返回 `true`，否则返回 `false`。 | `2&gt;1 &amp;&amp; 3&gt;1` → `true` |
| `&amp;#124;&amp;#124;` | 或 | `表达式1 &amp;#124;&amp;#124; 表达式2` | 任一表达式为 `true` 时返回 `true`，都为 `false` 时返回 `false`。 | `2&gt;1 &amp;#124;&amp;#124; 1&gt;3` → `true` |

#### 5.1.4 文本运算符

| 运算符 | 名称 | 用法 | 说明 | 示例 |
|---------|------|------|------|------|
| `&amp;` | 拼接 | `文本1 &amp; 文本2` | 连接两个或多个文本内容。 | `"Hello " &amp; "World"` → `"Hello World"` |

### 5.2 异常处理规则

| 场景 | 处理方式 |
|------|------------|
| 除数为 0（`/`） | 返回 0，不报错。 |
| 取余分母为 0（`%`） | 返回 0，不报错。 |
| 数字溢出 | 按系统可计算范围截断处理。 |
| 文本长度超过 1500 | 自动保留前 1500 个字符。 |
| 计算过程出现 NULL | 返回 NULL。 |

## 7 配置建议
- 先确认目标字段返回类型，再编写公式，避免类型不匹配。
- 条件分支较多时优先使用 `Case()`，可读性高于多层嵌套 `If()`。
- 日期计算统一使用 `DateAdd()` / `DateDiff()`，避免直接对日期做加减。
- 对文本拼接结果预估长度，避免超长被截断影响展示。
- 公式保存前先执行 `语法检查`，再使用典型数据做结果验证。
