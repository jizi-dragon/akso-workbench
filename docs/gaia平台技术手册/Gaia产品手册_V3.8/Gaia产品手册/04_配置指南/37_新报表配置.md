> 本文介绍如何在 Gaia 管理端完成新报表模块三个核心对象（数据集、QRS图表、仪表盘）的配置与数据包迁移，供管理员和实施人员使用。   

---

## **1\. 说明**

本文说明如何在 Gaia **管理端**完成新报表模块三个核心对象的配置，使业务侧可以正常使用：
- 数据集
- QRS图表（下文简称「图表」）
- 仪表盘

配置完成后，实施人员应能：通过菜单创建/打开上述对象，进入设计或查看页，并按顺序用数据包在环境间迁移配置数据。

## **2\. 配置顺序**

管理端对象配置与数据包迁移，均按依赖从前往后：
```
数据集 → QRS图表 → 仪表盘
```

单个对象内部建议顺序：表单布局 → 页面链接 → 列表布局 → 动作 → 菜单。 跨环境迁移时：先数据包迁数据集，再迁图表，最后迁仪表盘。
