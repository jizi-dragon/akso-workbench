# 菜单集配置（Tab Collection）
> 本文说明如何在 Gaia 平台配置菜单集，包括系统菜单集、自定义菜单集、用户首选菜单集与权限控制。   

---

## 概述

菜单集用于组织主导航中的菜单入口，帮助不同角色看到不同的一组菜单。
- `菜单集（Tab Collection）`：一组菜单或菜单项的集合。
- `菜单项（Tab）`：可点击的导航入口，点击后进入对象页面、文档页面或外部链接页面。
- `菜单（Menu）`：菜单项的父级分组，本身不可直接跳转，用于展开下级菜单项。

用户点击主导航左侧的菜单集图标后，可切换到已授权的菜单集。切换后，主导航会按所选菜单集重新渲染。

---

## 管理入口

### 菜单集管理页

`管理端 > 配置管理 > 用户界面 > 菜单集`

在该页面可以查看系统菜单集、创建和维护自定义菜单集。

---

## 系统菜单集

系统菜单集由平台内置，默认只读，不能编辑或删除。

### 所有菜单
- 包含所有非管理端菜单（标准菜单与自定义菜单）。
- 用户点击后进入首页。
- 默认显示在业务端菜单集面板中，可通过系统设置隐藏。

### 业务管理
- 包含对象数据管理、模板管理等业务管理入口。
- 用户点击后进入业务管理导航。

### 管理端
- 包含配置管理、用户与组、日志管理、集成管理、部署管理、系统设置等管理入口。
- 用户点击后进入管理端导航。

### 打印中心（如已启用）
- 可包含“终端”“打印机”“打印任务”等标准菜单项。
- 用于集中访问打印相关对象页面。

---

## 菜单集列表页

路径：`管理端 > 配置管理 > 用户界面 > 菜单集`

列表展示系统菜单集和自定义菜单集，支持按关键词查询菜单集名称。

| 展示列 | 说明 |
|---------|------|
| 名称 | 菜单集显示名称 |
| Code | 菜单集唯一编码 |
| 来源 | 系统 / 自定义 |
| 状态 | 启用 / 停用 |
| 操作 | 编辑、启用、停用、删除（系统菜单集仅支持查看） |

操作结果说明：
- `编辑`：进入该菜单集编辑页。
- `启用`：将菜单集置为启用状态，业务端可见（需同时有权限）。
- `停用`：将菜单集置为停用状态，业务端不再可切换到该菜单集。
- `删除`：删除自定义菜单集（需二次确认）。

## 创建自定义菜单集

路径：`管理端 > 配置管理 > 用户界面 > 菜单集 > 创建`

### 字段说明

| 字段 | 规则 | 结果 |
|------|------|------|
| 名称 | 必填，1-200 字符，唯一 | 显示在菜单集下拉面板与列表页 |
| Code | 必填，1-200 字符，唯一 | 作为菜单集技术标识 |
| 状态 | 启用 / 停用 | 控制菜单集是否可在业务端使用 |
| 帮助内容 | 选填，0-500 字符 | 鼠标悬停菜单集名称时显示帮助文本 |
| 图标 | 选填 | 显示在菜单集名称前 |
| 排序值 | 正整数，可重复 | 控制列表页及业务端菜单集排序；重复时同值顺序不固定 |
| 菜单 | 通过穿梭框选择 | 决定该菜单集包含的菜单/菜单项 |

### 菜单维护规则
- 可以把“菜单”或“菜单项”加入菜单集。
- 若添加“菜单”，需为该菜单配置其下菜单项。
- 不支持将“菜单”再添加到另一个“菜单”内部。

### 数量限制
- 最多可创建 `50` 个自定义菜单集。
- 每个菜单集最多包含 `20` 个菜单或菜单项。
- 每个菜单最多包含 `20` 个菜单项。

### 保存与取消
- 点击 `保存`：系统校验必填、唯一性和长度规则，校验通过后写入数据。
- 点击 `取消`：若有未保存内容，弹出确认框；确认后退出，取消则留在当前页。

## 查看与管理菜单集

### 查看详情

在列表页点击菜单集名称，进入详情页，可查看基础信息和菜单结构。

### 管理菜单

在详情页“菜单”区域，可对菜单执行管理操作：
- 对“菜单”类型：可编辑、可删除。
- 对“菜单项”类型：仅可删除。

编辑菜单时可修改菜单名称、增删菜单项并调整菜单项顺序。

### 菜单排序
- 在详情页点击 `排序` 进入排序模式。
- 仅支持对一级菜单排序。
- 拖拽左侧排序手柄调整顺序。
- 点击 `保存` 生效；点击 `取消` 恢复进入排序模式前的顺序。

---

## 编辑与删除自定义菜单集

### 进入编辑页
- 在列表页点击操作列 `编辑`。
- 在详情页点击右上角 `编辑`。

编辑页可修改：名称、状态、帮助内容，以及菜单内容（新增/移除菜单）。

### 删除
- 仅支持删除自定义菜单集。
- 可从列表页操作列或详情页右上角执行 `删除`。
- 删除前会弹出确认框，确认后执行删除。

---

## 用户首选菜单集与首选菜单

管理员可为用户设置首选菜单集和首选菜单。生效规则如下：
- 首选菜单集可选范围：自定义菜单集。
- 设置首选菜单集后，用户登录优先进入该菜单集；未设置时默认显示“所有菜单”。
- 若设置了首选菜单集但未设置首选菜单，登录后进入该菜单集下可访问的第一个菜单。
- 若设置了首选菜单，登录后优先进入该首选菜单；未设置则默认进入首页。

---

## 权限模型

菜单权限与菜单集权限独立生效，需要分别授权。
- 仅授予菜单权限，不会自动授予其所属菜单集权限。
- 仅授予菜单集权限，也不会自动授予其中菜单权限。
- 用户无菜单集权限时，该菜单集对该用户不可见。
- “所有菜单集”权限包含后续新增的菜单集。

---

## 业务端使用行为

用户点击主导航左侧菜单集图标后，可查看已授权菜单集并切换。菜单集展示顺序为：
1. 所有菜单
2. 自定义菜单集（按管理端排序值）
3. 业务管理
4. 管理端

切换菜单集后，主导航菜单即时刷新，并进入该菜单集下可访问的第一个页面。
