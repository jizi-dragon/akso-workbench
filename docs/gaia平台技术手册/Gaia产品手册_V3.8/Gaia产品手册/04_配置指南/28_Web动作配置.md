# Web动作配置

Web动作用于在业务端提供可点击的跳转入口，支持从当前记录跳转到指定页面，并携带参数完成跨模块操作衔接。

---

## 概述

Web动作主要解决“从当前业务页面快速跳转到目标页面”的配置诉求。配置完成后，Web动作可作为生命周期用户动作被业务用户点击执行。

常见场景：
- 从对象详情页跳转到另一个对象的新建页。
- 从文档场景跳转到外部或其他业务处理页。
- 在跳转时携带当前记录字段值，减少重复录入。

---

## 1\. 管理入口

路径：`管理端 > 配置管理 > 业务逻辑 > Web动作`

在该入口可完成 Web 动作的：
- 新建
- 查询筛选
- 查看详情
- 编辑
- 删除

---

## 2\. Web动作列表页

### 2.1 页面与操作

页面名称：`Web动作`

页面右上角常见操作如下：

| 操作 | 说明 |
|------|------|
| **创建** | 进入创建Web动作页面。 |

列表中每条记录的常见操作如下：

| 操作 | 说明 |
|------|------|
| **名称（可点击）** | 进入该Web动作详情页。 |
| **编辑** | 进入编辑页修改该Web动作。 |
| **删除** | 触发删除确认并执行依赖校验。 |

### 2.2 列表字段

| 字段 | 说明 |
|------|------|
| **名称** | Web动作显示名称。 |
| **Code** | Web动作系统编码。 |
| **对象** | 该Web动作适用对象范围（对象/文档）。 |
| **URL** | 点击后打开的目标地址表达式。 |
| **操作** | 编辑、删除。 |

### 2.3 列表行为
- 默认按创建时间倒序展示。
- 支持按`名称`筛选。
- 支持通过列表表头进行类型筛选。
- 分页展示当前租户的Web动作记录。

## 3\. 创建Web动作

### 3.1 创建页导航与顶部操作

**典型面包屑路径**：

`Web动作 > 创建Web动作`

页面右上角常见操作如下：

| 操作 | 说明 |
|------|------|
| **保存** | 保存当前配置。保存成功后可在生命周期用户动作中被选择。 |
| **返回/取消** | 放弃当前未保存修改并返回列表页。 |

### 3.2 字段配置

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| **名称** | 是 | Web动作显示名称，建议使用“动词 \+ 目标页面/目标对象”命名。 |
| **Code** | 是 | 技术编码，遵循配置数据Code规范。创建后建议保持稳定。 |
| **对象** | 否 | 可选`对象`或`文档`。用于限定该动作可被哪类生命周期引用。默认`对象`。 |
| **打开方式** | 否 | 可选`在新窗口打开`或`在当前窗口打开`。默认`在新窗口打开`。 |
| **URL** | 是 | 目标地址，支持通过URL编辑器选择当前对象字段作为变量。 |

### 3.3 保存校验与结果
- `名称`、`Code`、`URL`未填写时不能保存。
- 保存前系统会执行数据合法性校验。
- 保存成功后，Web动作可用于生命周期中的`用户动作类型 = Web动作`配置。

---

## 4\. 查看与编辑Web动作

### 4.1 详情页

**典型面包屑路径**：

`Web动作 > {Web动作名称}`

页面右上角常见操作如下：

| 操作 | 说明 |
|------|------|
| **编辑** | 进入编辑页。 |
| **删除** | 删除当前Web动作（删除前执行依赖校验）。 |

### 4.2 编辑页

进入方式：
1. 在列表页点击`编辑`。
2. 在详情页点击`编辑`。

编辑规则：
- `Code`不可编辑。
- 其他字段可按需修改并保存。

---

## 5\. 删除规则

删除入口：
1. 列表页`删除`按钮。
2. 详情页`删除`按钮。

删除流程：
1. 点击删除后，系统弹出确认提示。
2. 确认后先执行依赖性检查。
3. 若该Web动作已被生命周期用户动作引用，则阻断删除并提示引用位置。
4. 若无依赖，删除成功后返回列表页。

---

## 6\. 生命周期中的使用

Web动作可作为生命周期中的用户动作类型配置在对象或文档生命周期中。

### 6.1 可选范围规则

| 生命周期类型 | 可选Web动作范围 |
|------------------|---------------------|
| **对象生命周期** | 仅可选择`对象 = 当前对象`的Web动作。 |
| **文档生命周期** | 仅可选择`对象 = 文档`的Web动作。 |

### 6.2 业务端效果

完成生命周期配置后：
- Web动作会出现在业务端对象详情页的动作入口中。
- 用户点击后按配置URL执行跳转。

## 7\. 权限、日志与多语言

### 7.1 权限控制

Web动作管理权限位于：`权限集 > 管理端 > 配置管理 > Web动作`

| 权限 | 说明 | 交互说明 |
|------|------|------------|
| **Web动作：全部** | Web动作全量管理权限 | 勾选后自动包含下列子权限。 |
| **Web动作：查看** | 查看列表与详情 | - |

### 7.2 日志记录
- 管理端对Web动作的创建、编辑、删除等操作会记录系统日志。
- 业务端用户点击Web动作后，会记录对象审计追踪日志。
- 日志描述示例：`点击链接：{Web动作名称}`。

### 7.3 多语言
- Web动作名称支持多语言展示。
- Web动作触发的相关日志描述支持多语言。

---

## 8\. 配置迁移

Web动作属于可迁移的配置组件数据。

迁移与报告能力：
- 在配置迁移组件列表中显示组件类型：`WebAction`。
- 出站配置包支持选择并导出Web动作组件数据。
- 配置报告支持新增Web动作页签并导出对应配置数据。

---

## 9\. 上线前检查建议

| 检查项 | 建议 |
|---------|------|
| **名称与Code规范** | 上线前统一命名规则，避免后续难以维护。 |
| **URL变量取值** | 使用真实业务样本验证变量替换结果，避免空值或非法地址。 |
| **打开方式** | 对外部页面优先评估是否使用新窗口，减少当前页面上下文丢失风险。 |
| **生命周期可选范围** | 检查对象/文档范围是否匹配预期，避免在用户动作里无法选择。 |
| **删除依赖** | 先排查生命周期引用，再执行删除。 |
| **权限验证** | 分别验证查看、创建、编辑、删除权限是否按权限集生效。 |

## 常见问题

**Q1：为什么删除Web动作时提示不能删除？**   A：该Web动作通常已被生命周期用户动作引用。先移除生命周期中的引用，再执行删除。

**Q2：为什么在生命周期用户动作里选不到某个Web动作？**   A：先检查动作的`对象`范围是否匹配当前生命周期类型（对象/文档）。

**Q3：为什么点击后没有按预期跳转？**   A：重点检查URL表达式、变量取值是否为空，以及打开方式是否符合当前业务场景。
