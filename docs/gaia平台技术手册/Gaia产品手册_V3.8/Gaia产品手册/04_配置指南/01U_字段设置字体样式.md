# 字段设置字体样式
> 本文说明如何通过字体样式增强字段值的显示效果，帮助用户更快识别重点信息。   

---

## 概述

字段设置字体样式用于控制字段值在界面中的显示效果，例如字体颜色和粗细。配置完成后，用户在列表、详情或卡片场景中查看记录时，可以更直观地区分重点值、异常值或提示信息。

## 适用范围
- 文本字段
- 长文本字段
- 数字字段
- 布尔字段
- 日期字段
- 日期时间字段
- 查找字段
- 公式字段
- 统计字段
- 列表和详情展示场景

## 配置说明
- 字体样式只影响显示效果，不改变字段原始值。
- 常见样式包括字体颜色、加粗等。
- 在支持公式样式控制的场景中，可根据字段值动态调整显示效果。
- 若未配置字体样式，系统按默认样式显示字段值。

## 设置入口
- 面包屑入口：`所有的对象 > 文件类型`
- 在字段配置页面中，展开 `设置字体样式` 折叠区，即可录入字体样式表达式。
- `设置字体样式` 与 `设置图标`、`设置公式` 位于同一配置区域，建议先完成公式定义，再配置字体样式。

## 公式设置字体函数（Font）

在 `指定公式` 模式下，可使用 `Font()` 函数返回字体结果。

### 用法

`Font(Color[,Weight])`

### 描述

返回字体，字体的颜色为 `Color`，字体加粗为 `Weight`。

### 参数类型

| 参数 | 类型 | 说明 |
|------|------|------|
| `Color` | 文本 | 必填，支持 RGB 十六进制格式（如 `#D9001B`） |
| `Weight` | 文本 | 可选，支持 `normal`（常规）、`bold`（加粗）、`bolder`（更粗） |

### 返回类型

`字体`

### 示例
```formula
Font("#D9001B","bold")
```

## 使用建议
- 仅为需要突出展示的信息配置字体样式，避免页面视觉负担过重。
- 颜色和加粗规则应保持统一，便于用户形成稳定认知。
- 动态样式建议与业务规则保持一致，避免同一含义出现多种表达。
