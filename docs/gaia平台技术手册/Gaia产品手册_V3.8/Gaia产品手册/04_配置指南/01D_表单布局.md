\# 表单布局
> 本文说明如何在 Gaia 平台配置对象表单布局，用于控制对象的创建页、详情页、编辑页的信息展示与交互行为。   

---

## 1 概述

### 1.1 手册范围

本文聚焦对象表单布局的配置与维护，覆盖以下内容：
- 表单布局的管理与常用操作
- 布局结构配置，包括页面容器、部分容器与控件管理
- 部分类型与字段控件配置要点
- 布局生效与分配规则

表单布局适用于以下业务场景：
- 记录创建
- 记录查看
- 记录编辑

补充说明：
- 对象启用对象类型后，可按对象类型分别配置和计算布局。
- 同一对象可配置多个布局，最终展示受布局分配与访问权限共同控制。
- 当前移动端与 PC 端共用同一套表单布局配置。

### 1.2 关键概念

| 概念 | 说明 |
|------|------|
| 表单布局 | 定义对象记录在页面中的结构和展示内容。 |
| 页面容器 | 布局中的一级结构单元，用于组织页面分区。 |
| 部分容器 | 页面容器下的内容区域，用于承载字段、相关对象或扩展部分。 |
| 控件 | 展示和编辑字段的交互单元，可排序、编辑、删除和插入。 |
| 默认布局 | 用户进入记录详情时优先加载的布局。 |
| 用于创建 | 用户新建记录时默认使用的布局。 |
| 布局切换器 | 当用户有多个可访问布局时，用于切换显示布局。 |

### 1.3 访问路径

`配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 表单布局`

## 2 表单布局管理

### 2.1 列表页

进入 `对象 > 目标对象 > 表单布局` 后，可对该对象下的全部表单布局进行统一管理。

列表页常见区域说明：
- 顶部查询区：支持按关键字检索布局。
- 分页区：支持页码切换与每页条数设置。
- `创建`：用于新建表单布局。

列表字段说明：

| 字段 | 说明 |
|------|------|
| 布局名称 | 布局显示名称；若为默认布局，名称后会显示默认标识。 |
| Code | 布局唯一编码，用于技术识别、迁移与排错。 |
| 来源 | 标识布局来源，用于区分标准与自定义布局。 |
| 对象类型 | 当前布局关联的对象类型。 |
| 最后修改时间 | 该布局最近一次变更时间。 |
| 操作 | 通过操作菜单执行维护动作。 |

### 2.2 创建布局

在列表页点击 `创建` 后，填写布局基础信息并保存。

常用配置项如下：

| 配置项 | 说明 |
|---------|------|
| 布局名称 | 表单布局显示名称，用于区分不同布局 |
| Code | 布局编码，建议保持唯一且语义清晰，便于检索与迁移 |
| 所属对象类型 | 指定该布局适用的对象类型 |
| 状态 | 控制布局是否可用 |
| 默认页面 | 指定默认定位的页面容器 |
| 默认部分 | 指定默认定位的部分容器，默认部分的优先级大于默认页面，在页面中打开时（非弹窗），滚动条会自动滚动到默认部分所在位置并展开。 |
| 页面模式 | 指定用户进入记录页时默认进入的模式，可设置查看或编辑模式 |
| 保存时不校验必填 | 布局级开关，默认关闭。开启后，用户在该布局下点击「保存」时不校验字段控件及布局规则产生的必填要求 |

#### 保存时不校验必填

适用于需要先暂存草稿、分阶段补录或多人协作填报的场景。

| 规则 | 说明 |
|------|------|
| 仅影响保存 | 开启后仅跳过表单「保存」时的布局级必填校验 |
| 不影响正式提交 | 工作流提交、用户动作、生命周期流转等仍按原规则校验必填 |
| 不改变显示 | 必填字段仍可显示红色星号 |
| 不跳过其他校验 | 字段格式、长度、唯一性、验证规则、权限、系统级必填等仍执行 |
| 按当前布局生效 | 多布局时，以用户当前渲染的布局配置为准；各布局独立配置 |

建议放置在页面模式附近维护。合规要求较高的正式提交场景，应继续依赖工作流/用户动作侧的必填校验，不宜仅依赖本开关。

### 2.3 编辑布局

在列表页通过 `编辑` 进入布局后，可维护布局基础信息和结构内容。

点击左侧布局标题后，可进入布局级配置界面，通常包括以下页签：
- `基础配置`：维护当前布局的名称、Code、默认页面、默认部分、页面模式、保存时不校验必填等基础信息。
- `规则配置`：维护当前布局下的规则列表与启用状态。

### 2.4 设置默认布局

使用 `设置默认布局` 可将当前布局设置为对象类型默认布局。

规则说明：
- 每个对象类型仅允许一个默认布局。
- 重新设置默认布局后，原默认布局自动变为非默认。

### 2.5 删除布局

`删除` 用于移除当前布局。

使用建议：
- 删除前先确认该布局是否仍被角色或业务场景使用。
- 删除后相关页面展示与操作路径会立即受影响，建议先做影响评估。

### 2.6 复制布局

`复制` 用于基于当前布局生成新布局，适合做差异化配置。

使用建议：
- 批量调整前，建议先复制形成可回退版本，再进行结构性修改。

### 2.7 下载运行报告模板

`下载运行报告模板` 用于导出布局相关模板，便于离线分析和交付留档。

### 2.8 复制到其他布局

`复制到` 用于将当前布局复制到目标布局，以复用布局设计。

## 3 布局结构配置

表单布局的结构层级通常包括：
- 布局（根节点）
- 页面容器
- 部分容器

配置要点：
- 页面容器内至少应包含一个部分，否则保存后空容器会被清理。
- 页面和部分均支持拖拽排序，可按业务阅读顺序组织页面结构。
- 同一布局下可配置多个页面，适用于信息量较大、分主题展示的对象；当对象仅需单页面展示时，可不创建页面，直接在布局下添加部分并配置字段。

### 3.1 页面容器

在左侧页面容器列表中，点击页面容器右侧操作菜单，可执行以下操作：
- `编辑`：修改当前页面容器配置（名称、渲染与显隐等）。
- `添加页面`：在当前布局下新增一个页面容器。
- `添加部分`：在当前页面容器下新增部分容器。
- `删除`：删除当前页面容器。

使用说明：
- 删除页面前建议先确认页面内部分是否已迁移，避免误删布局内容。
- 新增页面后建议立即添加至少一个部分，避免空页面被系统清理。

删除提示说明：
- 选择 `删除` 后，系统会弹出确认提示：删除页面将同时删除该页面中的全部部分。
- 点击 `确定` 后立即生效，当前页面及其下所有部分会被移除。
- 点击 `取消` 则不执行删除，页面结构保持不变。

页面容器编辑配置项如下：

编辑页面弹窗常用配置项如下：

| 配置项 | 说明 |
|---------|------|
| 名称 | 必填。页面容器显示名称，用于左侧导航展示。 |
| Code | 页面容器编码，用于技术识别、迁移与排错。 |
| 是否只读 | 控制页面下内容是否默认只读展示。 |
| 是否渲染 | 强控制项。设为“否”时页面不参与渲染。 |
| 是否隐藏 | 控制页面是否在页面结构中显示。 |

配置建议：
- 页面名称建议与业务主题保持一致，例如“详情”“审批信息”“附件信息”。
- `是否渲染` 与 `是否隐藏` 同时配置时，建议优先明确渲染策略，避免配置冲突理解偏差。

新增页面容器配置项如下：

在页面容器操作菜单中点击 `添加页面` 后，可创建新的页面容器。常用配置项如下：

| 配置项 | 说明 |
|---------|------|
| 名称 | 必填。页面容器显示名称，建议与页面承载内容一致。 |
| Code | 必填。页面容器编码，用于技术识别与迁移；建议保持唯一且稳定命名。 |
| 是否只读 | 控制新页面下内容是否默认只读展示。 |
| 是否渲染 | 强控制项。设为“否”时新页面不参与渲染。 |
| 是否隐藏 | 控制新页面是否在业务端导航中显示。 |

创建建议：
- 新增页面后建议立即添加至少一个部分，避免形成空页面。
- `名称` 建议使用业务语义命名（如“基础信息”“审批信息”“附件信息”），便于后续分配与维护。
- `Code` 一经投产建议避免频繁修改，减少迁移与排障成本。

### 3.2 部分容器

在左侧结构树中，部分容器同样支持通过右侧操作菜单执行以下操作：
- `编辑`：修改当前部分容器配置（名称、显示控制等）。
- `添加页面`：在当前布局下新增页面容器。
- `添加部分`：在当前位置继续新增部分容器。
- `删除`：删除当前部分容器。

使用说明：
- 删除部分仅影响当前部分及其内部控件配置，不会删除对象字段本身。
- 若需在同一页面继续扩展内容，优先使用 `添加部分`，避免在已有部分内堆叠过多控件。
- 建议先完成部分命名再批量添加控件，降低后续重构成本。

### 3.3 控件管理

控件用于在部分内呈现字段并控制交互行为。常见操作如下：
- `添加控件`：向当前部分新增字段控件。
- 拖拽排序：按业务阅读顺序调整控件位置。
- `编辑`：修改控件显示与交互配置。
- `删除`：将控件从当前部分移除，不删除字段本身。
- 前后插入：在指定控件前或后添加新控件，便于局部调整布局。

使用建议：
- 先确定部分分组，再批量添加控件，减少重复调整。
- 删除控件前确认仅为移出布局，避免与“删除字段”混淆。
- 对高频字段优先前置，降低录入和查看成本。

## 4 部分类型配置

### 4.1 详情部分

详情部分用于按业务主题组织字段。建议将高频字段前置，减少滚动与切换成本。

常用配置：
- 部分标题
- 是否隐藏标题（布尔，默认否）
- 每行显示列数（1 列或 2 列）
- 字段顺序
- 字段标题显示宽度（支持设置 1-12，可留空）

详情部分配置项（字段部分）：

| 配置项 | 说明 |
|---------|------|
| 显示宽度 | 设置详情部分按 `一列` 或 `两列` 展示字段。两列适合信息密度较高场景，一列适合长文本或重点信息展示。 |
| 文本列宽度 | 设置字段标题区域宽度（通常按比例控制，支持留空使用默认值）。用于优化“字段标题/字段值”显示占比。 |
| 名称 | 必填。详情部分在配置端与业务端识别用名称。 |
| Code | 部分编码，用于技术识别、迁移和排错。建议稳定维护，不随显示文案频繁变更。 |
| 是否只读 | 控制该部分是否整体只读。开启后，该部分字段默认不可编辑。 |
| 阅读模式 | 控制该部分是否以阅读样式展示。开启后，该部分按阅读模式渲染；字段自身显示模式与规则按就近原则生效。 |
| 是否渲染 | 强控制项。设为“否”时，该部分不参与页面渲染。 |
| 是否隐藏 | 设为“是”时，该部分在页面中隐藏。 |
| 仅在这些生命周期状态下显示 | 多选当前对象生命周期状态。为空时默认不按状态限制；设置后仅在选定状态显示。 |
| 使用样式隐藏 | 以样式方式控制隐藏，常用于与布局规则联动的显隐控制场景。 |
| 仅在这些生命周期状态下展开 | 多选生命周期状态，在选定状态下默认展开该部分；未命中状态按“是否展开”处理。 |
| 是否隐藏锚点 | 控制是否在页面锚点/导航中显示该部分入口。 |
| 是否展开 | 控制该部分首次进入页面时默认展开或折叠。 |
| 是否显示提示文字 | 控制是否显示部分级提示文案。 |
| 提示文字 | 提示文案内容，建议简洁描述填写规则或业务注意事项（常用长度 0-100 字符）。 |
| 帮助内容 | 帮助说明内容，通常在问号提示中展示（常用长度 0-500 字符）。 |

显示控制说明（详情部分）：
- `是否渲染` 设为“否”时，部分不参与渲染，页面不显示，且不提交该部分数据。
- `是否隐藏` 设为“是”时，部分在页面不显示，但仍参与数据提交。
- `是否渲染` 与 `是否隐藏` 任意一个命中都会导致页面不显示；两者的根本区别是是否参与数据提交。
- 生命周期状态显示配置用于静态按状态过滤。
- 若配置了布局规则（Layout Rule），布局规则对最终显示结果具有覆盖能力。

控件管理（详情部分）：
- 详情部分添加到页面后，可通过 `添加控件` 向该部分新增控件。
- 详情部分中的“控件”即对象字段，新增控件时本质是在该部分中引入字段。

控件添加与维护操作：
1. 在详情部分点击 `添加控件`，选择要加入该部分的字段。
2. 控件添加后，可通过拖拽方式调整控件顺序，按业务阅读顺序重新排布。
3. 可对单个控件执行 `编辑`，调整该控件在当前部分中的显示配置。
4. 可对单个控件执行 `删除`，将该控件从当前部分移除（不删除对象字段本身）。
5. 可在指定控件的前或后继续添加新控件，用于局部插入字段而无需整体重排。

配置建议：
- 建议优先放置高频字段与必填字段，再补充低频字段。
- 对字段较多的详情部分，建议先完成分组思路再批量拖拽排序，减少重复调整。
- 删除控件前建议先确认是否仅移出布局，避免与“删除字段”概念混淆。

### 4.2 相关对象部分

相关对象类部分用于展示和维护关联记录。该类部分分为两种类型：`相关对象` 与 `相关对象（支持行内编辑）`，两者配置项不完全相同，建议按实际交互方式分别配置。

#### 4.2.1 相关对象

`相关对象` 适用于“以列表查看 \+ 记录打开/新增”的场景，支持配置记录打开方式与新增入口方式。

配置项说明（相关对象）：

| 配置项 | 说明 |
|---------|------|
| 类型 | 固定为 `相关对象`。 |
| 名称 | 必填。部分名称，用于配置端识别与业务端标题展示。 |
| Code | 必填。部分编码，用于迁移、检索与排错。 |
| 相关对象关系 | 必填。选择当前对象与目标对象的关系，是该部分数据来源的核心配置。 |
| 对象联动规则 | 可选。用于控制当前对象与相关对象之间的联动行为。详见 [联动规则配置](26_%E8%81%94%E5%8A%A8%E8%A7%84%E5%88%99%E9%85%8D%E7%BD%AE.md)。 |
| 列表布局 | 必填。用于定义相关对象记录在部分中的展示列。 |
| 选择列表布局 | 可选。用于“选择已有记录”弹窗中的列表展示。 |
| 是否展示搜索框 | 控制相关对象列表是否显示搜索栏。 |
| 创建记录方式 | 必填。控制在该部分新增关联记录时使用的方式（如新建记录、选择已有记录）。 |
| 打开记录方式 | 控制点击相关记录后打开详情的方式（如在当前页或新窗口打开）。 |
| 添加记录方式 | 控制“添加记录”入口的交互方式。 |
| 创建记录对象类型 | 控制新增相关记录时可创建的对象类型范围。 |
| 直接使用另一个父对象 | 仅多对多关系时显示。开启后，在新增相关记录时可直接复用另一侧父对象建立关系，减少重复录入。 |
| 创建另一个父对象时的对象类型 | 仅多对多关系时显示。用于限定“创建另一个父对象”场景下可创建的对象类型。 |
| 表单布局 | 用于相关对象记录的创建、查看、编辑页面。 |
| 启用表头动作 | 勾选后在部分标题区显示快捷动作，便于快速执行相关对象操作。 |
| 联动刷新部分 | 可选（多选）。选择当前部分刷新后需要同步刷新的其他部分；为空时不触发联动刷新。仅可选同一表单布局内、具备独立刷新能力且非当前部分自身的目标部分。 |
| 允许编辑实例 | 控制是否允许在该部分编辑已存在的相关记录。 |
| 允许删除实例 | 控制是否允许删除相关记录本体（数据删除）。 |
| 允许移除实例 | 控制是否仅移除与主记录的关联关系（不删除记录本体）。 |
| 是否只读 | 控制该部分是否只读展示，开启后不可在该部分直接修改数据。 |

## 5 字段控件配置

### 5.1 通用配置

字段控件用于控制字段在表单中的展示与交互。建议先统一字段通用项，再按字段类型细化控件能力。

通用项通常包括：
- 显示控制：是否只读、是否隐藏、是否渲染、无数据时隐藏。
- 生命周期控制：仅在指定生命周期状态显示。
- 编辑约束：必填、默认值、阅读模式、阅读态显示效果。
- 布局占位：半行/整行。

### 5.2 对象类 多选对象

多选对象字段在详情部分中，创建控件与编辑控件使用同一套配置项。创建时完成字段与控件类型选择，编辑时在原配置基础上调整显示、交互与数据来源设置。

| 是否隐藏 | 控制该控件是否在页面中显示。 |

使用建议（多选对象控件）：
- 列表布局建议优先展示业务主键字段（如编号、名称、状态），提高多选准确率。
- 创建记录方式建议与业务流程一致，若高频新建可优先使用弹出层以减少页面跳转。
- 对重要字段建议同时配置 `必填` 与生命周期显示条件，避免在关键阶段遗漏选择。

附件类型字段在详情部分中用于上传与维护记录附件，适用于正文附件、证明材料、补充文件等场景。创建与编辑共用同一套基础配置，通常使用 `文件上传` 控件。附件上传为异步处理：文件先上传并完成存储，再与当前记录建立附件关联。`附件类型字段` 与 `附件部分` 的关系是“字段级维护”和“列表级展示”的关系：前者用于当前记录附件的上传与编辑，后者用于集中查看和管理附件列表，可按页面目标选择其一或组合使用。

配置项说明（附件类型控件）：

| 配置项 | 说明 |
|---------|------|
| 字段 | 必填。选择字段类型为“附件”的目标字段。 |
| 选择控件 | 必填。通常选择 `文件上传`。 |
| 是否只读 | 控制该控件是否只读展示。 |
| 是否隐藏 | 控制该控件是否在页面中显示。 |
| 仅在这些生命周期状态下显示 | 多选生命周期状态，限定该控件在指定状态下显示。 |
| 无数据时隐藏 | 控制控件无附件时是否自动隐藏。 |
| 是否渲染 | 强控制项；设为“否”时控件不参与页面渲染。 |
| 阅读模式 | 控制控件在阅读态下的展示方式。 |
| 必填 | 控制该控件在编辑态是否必填。 |
| 显示宽度 | 选择 `半行` 或 `整行`，用于控制控件在详情部分中的占位宽度。 |

使用建议（附件类型控件）：
- 对合规必传材料建议开启 `必填`，并结合生命周期状态控制上传时机。
- 若仅在特定阶段需要上传材料，建议配置“仅在这些生命周期状态下显示”，避免无效输入。
- 需要在线预览附件时，建议与“4.3 附件预览”部分配合配置。

### 5.10 富文本

富文本类型字段用于录入带格式内容（如段落、列表、强调文本等），适用于处理说明、审核意见、正文备注等场景。创建与编辑共用同一套配置，重点关注默认值联动与只读态赋值策略。

配置项说明（富文本类型控件）：

| 配置项 | 说明 |
|---------|------|
| 字段 | 必填。选择字段类型为“富文本”的目标字段。 |
| 选择控件 | 必填。通常选择 `富文本编辑器`。 |
| 是否只读 | 控制该控件是否只读展示。 |
| 是否隐藏 | 控制该控件是否在页面中显示。 |
| 仅在这些生命周期状态下显示 | 多选生命周期状态，限定该控件在指定状态下显示。 |
| 无数据时隐藏 | 控制控件无值时是否自动隐藏。 |
| 是否渲染 | 强控制项；设为“否”时控件不参与页面渲染。 |
| 阅读模式 | 控制控件在阅读态下的展示方式。 |
| 必填 | 控制该控件在编辑态是否必填。 |
| 显示宽度 | 选择 `半行` 或 `整行`，用于控制控件在详情部分中的占位宽度。 |
| 默认值 | 设置富文本字段默认值，支持按字段能力配置表达式或依赖字段取值。 |
| 依赖变化时重新赋默认值 | 勾选后，当依赖字段发生变化时重新计算并写入默认值。 |
| 强制赋值 | 控制是否在指定状态下强制写入配置值（如“阅读\+只读状态”）。 |

使用建议（富文本类型控件）：
- 长文本业务场景建议使用 `整行` 展示，减少换行挤压导致的阅读负担。
- 若默认值依赖对象上下文字段，建议开启 `依赖变化时重新赋默认值`，确保内容联动一致。
- 启用 `强制赋值` 前建议先明确覆盖策略，避免误覆盖已录入的业务内容。

## 6 布局生效与分配

### 6.1 用于创建

“用于创建”包含两层配置：
- 部分级：可配置 `在创建模式显示`。开启后，对应部分会在新建记录页面同步展示。
- 布局级：可为对象类型指定“用于创建”的布局，用于控制新建记录的默认布局入口。

规则说明：
- 每个对象类型仅允许一个布局标记为“用于创建”。
- 开启新的“用于创建”布局后，同对象类型下其他布局自动关闭该标记。

---

### 6.2 默认布局

可为对象类型设置默认布局。用户进入记录详情页时，系统优先展示默认布局。

规则说明：
- 每个对象类型仅允许一个默认布局。
- 重新设置默认布局后，原默认布局自动变为非默认。

### 6.3 布局切换器

当满足以下条件时，业务端会显示布局切换器：
- 当前对象（或对象类型）配置了多个表单布局；
- 当前用户具有多个布局的访问权限。

切换后，页面会按所选布局重新渲染内容。

### 6.4 分配规则

表单布局可按不同维度分配给不同业务场景：

| 分配维度 | 说明 |
|------------|------|
| 对象类型 | 不同对象类型可分配不同布局 |
| 生命周期状态 | 不同状态可分配不同布局 |
| 角色/权限策略 | 不同角色可访问不同布局，并影响布局切换可见范围 |

---

## 8 配置建议与风险

### 8.1 推荐顺序
- 先完成对象、字段、关系与生命周期基础配置，再进行布局配置。
- 优先配置“创建路径”所需字段，确保新建流程最短闭环。
- 相关对象部分优先明确过滤规则，再开放创建和行内编辑。
- 多布局场景建议同时维护“默认布局”和“用于创建”布局，减少终端切换成本。
- 上线前请以典型角色验证：创建、查看、编辑、切换布局四类操作是否一致。

---

### 8.2 常见问题
- 删除布局前未确认使用范围，可能导致线上角色找不到目标布局。
- 多布局并行时未配置默认布局与用于创建布局，可能导致用户进入路径不一致。
- 上线前未做角色维度验证，可能出现可见布局与预期不符。
