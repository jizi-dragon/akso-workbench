# 生命周期状态类型配置
> 本指南说明如何创建和维护生命周期状态类型（State Type），并将状态类型映射到生命周期状态。 
状态类型用于统一不同生命周期的语义，是对象生命周期与文档多生命周期复用工作流的关键基础。   

---

## 概述

生命周期中有两层概念：
- **生命周期状态（Status）**：某个生命周期里的具体状态，例如“草稿”“审核中”“已批准”
- **状态类型（State Type）**：跨生命周期复用的标准语义，例如 `初始状态`、`完成状态`、`Draft`、`Approved`

同名状态不一定语义一致；通过状态类型可以把不同生命周期的状态对齐到统一业务语义。

---

## 适用场景

| 场景 | 是否建议配置状态类型 | 说明 |
|------|------------------------------|------|
| 单个对象、单条流程 | 建议 | 可提升可维护性，后续扩展更平滑 |
| 多对象共用审批流程 | 强烈建议 | 通过状态类型对齐后可复用工作流 |
| 文档多生命周期 | 强烈建议 | 是“所有文档生命周期”模式的前提 |
| 跨环境迁移与比对 | 建议 | 可减少“状态名不同但语义相同”带来的偏差 |

---

## 前提条件
- 您具备系统管理员或配置管理员权限
- 已完成生命周期基础配置
- 已定义业务流程中的关键语义节点（例如起草、审核、批准、归档）

---

## 创建状态类型

在状态类型管理页中，可按以下步骤创建并启用状态类型。
1. 进入 **配置管理** → **业务逻辑** → **生命周期**
2. 打开目标生命周期（或进入状态类型管理入口）
3. 在 **状态类型** 相关区域点击【创建】
4. 填写状态类型基本信息
5. 保存并启用状态类型

### 字段说明

| 字段 | 说明 | 配置建议 |
|------|------|------------|
| **名称** | 状态类型显示名称 | 使用统一业务术语，如“初始状态”“完成状态” |
| **Code** | 系统标识 | 建议稳定命名，避免后续频繁修改 |
| **应用范围** | 状态类型生效范围 | 见下文“范围选择” |
| **生命周期** | 当应用范围为“特定生命周期”时，需要指定目标生命周期 | 仅在需要限制适用范围时填写 |
| **状态必填** | 控制该状态类型在映射时是否必须指定状态 | 关键语义类型建议按实际治理要求设置 |
| **状态** | 启用/停用 | 仅启用可用于映射 |
| **来源** | 配置来源，如“自定义” | 用于识别状态类型来源，通常无需修改 |
| **描述** | 用途说明 | 建议写清适用对象与语义边界 |

### 范围选择

| 范围 | 含义 | 适合场景 |
|------|------|------------|
| **适用于全部生命周期** | 自动可用于所有生命周期 | 平台级标准语义（如初始、完成） |
| **可用于全部生命周期** | 可在各生命周期按需选择 | 通用但非强制的语义类型 |
| **特定生命周期** | 只用于某个生命周期 | 特殊流程或局部扩展场景 |

当 **应用范围** 选择 **特定生命周期** 时，页面会额外显示 **生命周期** 字段，要求您指定该状态类型可用的目标生命周期。

---

## 将状态类型映射到生命周期状态
1. 进入目标生命周期详情页
2. 找到 **状态类型** 部分
3. 点击【创建】或编辑行操作，打开 **状态类型** 弹窗
4. 在弹窗中选择“状态类型”和“状态”
5. 保存后验证流程节点是否按预期匹配

### 映射字段说明

在生命周期中新增状态类型映射时，弹窗中只有以下两个字段：

| 字段 | 说明 | 配置建议 |
|------|------|------------|
| **状态类型** | 要映射的标准语义类型 | 选择已启用且语义明确的状态类型，如“初始状态”“完成状态” |
| **状态** | 当前生命周期中的具体状态 | 选择该生命周期下实际存在的状态，如“草稿”“已批准” |

### 映射规则建议
- 每个生命周期至少维护“初始状态”“完成状态”映射
- 一个生命周期状态可承载多个业务语义时，先定义主语义，再补充扩展语义
- 工作流条件优先基于状态类型，而不是硬编码状态名称

---

## 与生命周期配置的关系

状态类型不是独立流程，它与生命周期配置协同生效：
1. 在生命周期中定义具体状态与状态转换
2. 在状态类型中定义跨生命周期语义
3. 在工作流中按状态类型复用规则
> \[!TIP\]
如果生命周期已经上线，新增状态类型后请先在沙箱验证，再推广到生产环境。   

---

## 验证清单
1. 状态类型是否已启用
2. 关键生命周期是否都完成映射
3. 工作流节点在不同生命周期下是否能正确匹配
4. 审批、回退、归档路径是否都保留审计记录
