# 设置字段默认值
> 本文说明对象字段在新建记录时自动带入默认值的配置方式。   

---

## 概述

设置字段默认值用于在业务端创建新记录时，为字段预填初始值，减少重复录入，并帮助用户按预设业务规则快速完成数据填写。

## 配置方式
- 常量：直接填写固定默认值。
- 公式：通过公式编辑器计算默认值。
- URL参数：从创建页 URL 查询参数中读取指定键名的值，适用于需要随入口链接带入上下文的场景。

## 适用说明
- 默认值通常在记录首次创建时生效。
- 不同字段类型支持的默认值能力不同，应以字段类型自身是否支持为准。
- 若同一字段同时存在对象字段级默认值和对象类型字段级默认值，通常以对象类型字段上的配置优先。
- 选择 `URL参数` 时，需要填写参数键名。页面打开后，系统会读取 URL 中同名参数并作为字段初始值；URL 中没有该参数时，字段按原默认值策略处理。
- URL 参数默认值只负责回填初始值，不会绕过字段必填、只读、隐藏、验证规则和关系安全校验。

## 使用建议
- 对高频、稳定、可预判的字段优先配置默认值。
- 对依赖上下文计算的字段，可优先考虑公式方式。
- 若字段值需要在创建后继续被动作或用户修改，应避免把默认值写成强约束。
- 对由入口链接带入的上下文字段，建议先统一 URL 参数键名，再配置字段默认值，避免链接参数与布局配置不一致。
