# 文档标签配置
> 本文介绍如何在 Gaia 平台中配置和管理文档标签，包括标签创建、自动标注、字段联动与日常维护。

## 概述

文档标签用于对文档进行分类，支持在文档详情中手动选择，也支持根据匹配词组自动标注。配置完成后，文档标签会同步为系统选项集，并可通过文档对象字段在业务端展示和编辑。

### 访问路径

`管理端 > 配置管理 > 文档设置 > 文档标签`

### 适用场景

| 场景 | 说明 |
|------|------|
| 文档分类管理 | 通过统一标签体系管理不同主题或业务类型文档 |
| 文档检索筛选 | 在列表或查询条件中按标签快速筛选文档 |
| 自动化打标 | 通过匹配词组对文档内容自动标注 |

---

## 前提条件

开始配置前，请先确认：
- 已具备管理端文档标签相关配置权限
- 已明确文档标签命名规范和使用范围
- 如需业务端可编辑标签，已规划文档对象表单布局中的标签字段位置

---

## 1\. 文档标签列表

进入文档标签页面后，系统按创建时间倒序展示所有标签。

### 1.1 列表字段

| 列 | 说明 |
|---|------|
| 名称 | 标签名称；点击后进入详情页 |
| 状态 | 标签状态，包含`启用`和`停用` |
| 匹配词组 | 当前标签配置的匹配词组摘要 |
| 操作 | 通过操作菜单执行编辑、启用、停用、删除 |

### 1.2 列表操作
- 点击右上角`创建`进入新建页面
- 点击标签名称查看详情
- 通过操作列维护标签状态和内容

---

## 2\. 创建文档标签

在列表页点击`创建`，填写标签基本信息和匹配词组。

### 2.1 基本字段

| 字段 | 类型 | 默认值 | 必填 | 说明 |
|------|------|---------|------|------|
| 名称 | 文本（200） | 无 | 是 | 标签显示名称 |
| 状态 | 选项（启用/停用） | 启用 | 否 | 控制标签是否可用 |
| 设置匹配词组自动标注 | 布尔 | 否 | 否 | 启用后按匹配词组自动标注文档 |
| 匹配词组 | 匹配词组编辑器 | 无 | 否 | 配置用于自动标注的关键词规则 |

### 2.2 匹配词组配置
- 匹配词组支持添加多条
- 每条词组可独立维护，统一用于该标签的自动标注判断
- 建议优先使用含义明确、业务一致的关键词，避免过于宽泛导致误标注
- `设置匹配词组自动标注`默认不勾选；勾选后页面显示匹配词组配置区域，保存后该标签进入自动标注模式

### 2.3 计算匹配文档数

配置匹配词组后，可点击`计算匹配文档数`预估命中范围。

计算规则如下：
- 匹配范围为系统中所有版本文档的全文内容
- 查询方式为全文匹配
- 页面返回匹配文档数量，用于评估词组质量

说明：
- 匹配文档数用于评估，不作为配置字段持久保存
- 刷新页面后可继续重新计算

---

## 3\. 查看与编辑

### 3.1 查看

在列表页点击名称进入详情页，可查看：
- 标签基础信息
- 自动标注开关状态
- 匹配词组内容

### 3.2 编辑

在详情页或列表操作菜单点击`编辑`后，可调整：
- 标签名称
- 状态
- 自动标注开关
- 匹配词组

保存后立即生效，并同步影响后续标注行为。

---

## 4\. 启用、停用与删除

### 4.1 启用与停用
- `启用`：标签可在文档标签字段中被选择，并可参与自动标注
- `停用`：标签不再用于新增或更新场景的标签选择和自动标注

### 4.2 删除

删除标签后，该标签对应的系统选项会同步移除。执行删除前，建议先确认历史文档中是否仍需保留该标签语义。

---

## 5\. 选项集与字段联动

文档标签配置与系统数据结构联动如下：
1. 系统内置选项集`文档标签`
2. 每一条文档标签数据对应选项集中的一个选项
3. 当标签新增、修改、删除时，选项同步新增、修改、删除
4. 文档对象新增共享字段`文档标签（tag__ak）`
5. 字段类型为选项，引用选项集`文档标签`

将该字段加入文档对象布局后，业务端可查看并编辑文档标签。

---

## 6\. 自动标注行为

当标签开启`设置匹配词组自动标注`后，系统会按该标签配置的匹配词组，对文档全文内容执行自动标注。

### 6.1 自动重算时机

系统会在以下场景自动重新计算文档自动标签：
- 文档升版后
- 文档起草后
- 文档签入后
- 在线编辑签入后
- 配置迁移完成后

重算完成后，文档标签结果会按最新匹配规则更新。

### 6.2 业务端编辑限制

对自动标注得到的标签，业务端按以下规则处理：
- 不可手工选择自动标签
- 不可手工移除自动标签

如果需要调整自动标签结果，应在管理端修改匹配词组或自动标注开关，再触发系统重算。

使用建议：
- 先配置少量高确定性词组，验证命中质量后再扩展
- 定期复盘标签命中结果，及时调整词组
- 对同义词较多的场景，可通过多词组覆盖常见表达

## 7\. 常见问题

### Q1：为什么点击“计算匹配文档数”后结果不会保存？

A：该结果用于评估匹配词组效果，不是持久化字段。每次需要时可重新计算。

### Q2：标签停用后，历史文档上的标签值会被清空吗？

A：停用用于控制后续可用性，不用于回写清理历史数据。是否清理历史数据请结合业务规则另行处理。

### Q3：业务端看不到“文档标签”字段怎么办？

A：请确认文档对象字段`tag__ak`已加入对应表单布局，且当前用户具备字段可见和编辑权限。

### Q4：为什么业务端不能删除某些文档标签？

A：如果该标签来自自动标注，业务端不支持手工移除。请在管理端调整对应标签的自动标注配置后重算。
