# 验证规则
> 本文说明如何在 Gaia 平台配置对象验证规则，用于在创建和编辑对象记录时校验字段输入，保障数据质量与业务规则一致性。   

---

## 1 概述

验证规则用于校验对象记录中的字段值是否满足预设条件。 
系统会根据验证表达式返回结果判断输入是否有效：
- 返回 `True`：校验通过，允许继续提交。
- 返回 `False`：校验失败，阻止保存并提示报错信息。

验证规则支持两种配置范围：
- 对象级：对该对象下符合条件的记录生效。
- 对象类型级：按对象类型分别配置，适用于同一对象下不同业务类型的差异化规则。

### 1.1 访问路径

对象级入口： `配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 验证规则`

对象类型级入口： `配置环境 > 配置管理 > 对象管理 > 对象 > 目标对象 > 对象类型 > 编辑{对象类型} > 验证规则`

### 1.2 关键概念

| 概念 | 说明 |
|------|------|
| 验证字段 | 验证规则作用的字段集合，支持多选。 |
| 验证表达式 | 用于判断字段值是否有效的布尔表达式，语法与公式表达式一致。 |
| 报错信息 | 校验失败时展示给用户的提示信息。 |
| 状态 | 控制规则是否生效；停用状态不参与业务端校验。 |

---

## 2 验证规则列表

在对象详情页切换到“验证规则”页签后，可统一查看和维护当前对象的验证规则。

### 2.1 页面结构

根据当前对象验证规则页面，列表页包含以下关键区域：
- 面包屑：`所有的对象 > {对象名称}`
- 对象页签区：包含 `基础`、`对象类型`、`字段`、`搜索字段`、`关系`、`列表布局`、`表单布局`、`动作`、`验证规则`、`索引规则` 等页签。
- 当前页签：`验证规则`（高亮状态）。
- 右上角主操作：`创建`，用于新建对象验证规则。
- 列表区：展示当前对象下的规则明细和操作入口。

### 2.2 列表字段

| 字段 | 说明 |
|------|------|
| 名称 | 验证规则名称。 |
| Code | 验证规则编码（API 名称）。 |
| 来源 | 规则来源，通常为标准或自定义。 |
| 状态 | 规则是否启用。仅启用状态会在业务端执行。 |
| 验证字段 | 规则关联的字段范围。 |
| 操作 | 通过齿轮按钮进入规则操作菜单。 |

### 2.3 列表操作

| 操作 | 说明 |
|------|------|
| 创建 | 点击右上角 `创建`，新建验证规则。 |
| 操作菜单 | 点击列表行末齿轮按钮，进入规则维护动作。 |
| 编辑 | 在操作菜单中进入编辑页，维护基础信息和表达式。 |
| 启用 | 将停用规则改为启用，启用后在业务端参与校验。 |
| 停用 | 将启用规则改为停用，停用后不再参与校验。 |
| 删除 | 删除当前规则。删除后业务端不可再使用该规则。 |

## 3 创建与编辑验证规则

可在对象级验证规则列表点击 `创建`，也可在对象类型详情页的“验证规则”区域点击 `创建`。

### 3.1 创建页结构

创建页包含以下区域：
- 面包屑：`所有的对象 > {对象名称} > {当前页面}`
- 页面操作按钮：右上角 `返回`、`保存`。
- 折叠区块：`详情`、`验证规则`。

### 3.2 详情区字段

| 配置项 | 是否必填 | 界面表现 | 说明与建议 |
|---------|------------|------------|---------------|
| 名称 | 是 | 单行输入框，提示“请输入名称” | 建议按“业务场景 \+ 校验目标”命名，便于检索。 |
| Code | 是 | 单行输入框，提示“请输入Code”，后缀显示 `&#95;c` | 建议语义清晰且稳定，避免频繁改动。 |
| 来源 | 否（只读） | 固定显示 `自定义` | 来源由系统生成，无需人工输入。 |
| 报错信息 | 是 | 单行输入框，提示“请输入报错信息” | 建议直接写明“哪个字段因为什么不通过”。 |
| 验证字段 | 是 | 下拉选择框，提示“请选择” | 仅选择需要参与校验的字段，减少误触发。 |
| 状态 | 否 | 下拉框，默认 `启用` | 新规则可先停用联调，验证后再启用。 |
| 描述 | 否 | 多行文本框，提示“请输入描述” | 建议记录规则意图、边界条件和适用对象类型。 |

验证字段支持类型：日期、日期时间、数字、布尔、选项、文本。

### 3.3 验证规则区（表达式编辑）

验证规则表达式通过**公式编辑器**进行设置。  
在 `验证规则` 区域点击编辑器入口后，系统弹出“公式编辑器”窗口完成表达式编写与校验。

公式编辑器包含以下要素：
- 顶部操作：`可复制公式`、关闭按钮。
- 中央编辑区：输入或粘贴验证表达式。
- 辅助按钮：`语法检查`，用于校验表达式语法是否正确。
- 底部辅助面板： `字段`、`变量`、`函数`、`运算符`、`图标`，支持通过搜索快速插入元素。
- 底部确认按钮：`取消`、`确定`（`确定` 后将表达式回填到验证规则页面）。

推荐操作顺序：
1. 先在 `字段/变量` 中选择校验所需字段。
2. 在 `函数/运算符/图标` 中补齐表达式逻辑。
3. 点击 `语法检查` 确认语法正确。
4. 点击 `确定` 回填表达式，再点击页面右上角 `保存` 完成规则创建或更新。

验证表达式用于定义校验逻辑，需满足以下要求：
- 表达式语法与公式字段表达式一致。
- 返回值必须为布尔类型（`True/False`）。
- 支持引用当前对象字段。
- 支持引用出站关系上的相关对象字段。
- 支持使用公式可用函数与运算符。
- 表达式长度不超过 3900 字符。

公式语法、函数分类和运算符说明请参见： [06\_公式配置.md](06_%E5%85%AC%E5%BC%8F%E9%85%8D%E7%BD%AE.md)

### 3.4 保存与返回
- `保存`：保存当前规则配置并生效（是否参与校验取决于“状态”）。
- `返回`：离开当前页面并返回上一层列表页；若存在未保存修改，建议先保存再返回。

### 3.5 编辑规则

创建后可通过 `编辑` 进入维护页面，修改名称、报错信息、验证字段、状态和表达式。  
建议在修改表达式后，使用典型业务数据做一次创建和编辑回归，确认提示信息与阻断行为符合预期。

---

## 4 执行机制与提示方式

当用户创建记录或保存编辑时，系统会执行相关验证规则：
- 校验通过：允许提交。
- 校验失败：阻止提交，并提示报错信息。

错误提示显示方式：
- 常规场景：在字段位置内嵌显示错误。
- 特殊场景：若相关字段被隐藏，系统会弹出错误对话框统一提示。

---

## 5 配置建议
- 先明确“必须阻断”的规则，再落地为验证表达式，避免将提示类校验配置为强阻断。
- 报错信息优先使用业务语言，避免仅返回技术名词或编码。
- 对象类型存在差异时，优先在对象类型级维护规则，避免单条规则覆盖过宽。
- 上线前至少验证两类路径：新建、编辑。
