# 大容量对象
> 本文介绍 Gaia 平台中的大容量对象。大容量对象适用于数据量大、写入频繁的场景，但可用能力少于标准对象，配置时应优先确认功能边界。   

---

## 概述

大容量对象是一种面向大数据量场景的对象存储方式。相较标准对象，大容量对象在性能上更适合承载高频写入和海量数据，但会限制部分平台能力。旧版文档中的“大对象开关”在当前版本中统一对应“数据存储类型 = 大容量”。

适合使用大容量对象的典型场景包括：
- 检查表实例
- 日志
- 发放记录
- 打印记录
- 其他高频写入、海量存储但流程能力要求较低的对象

### 访问路径

`配置端 > 配置管理 > 对象管理 > 对象`

---

## 1\. 数据存储类型

对象支持配置数据存储类型：

| 类型 | 说明 |
|------|------|
| 标准 | 默认类型，支持完整对象能力 |
| 大容量 | 面向大数据量场景，能力受限 |

使用规则：
- 已存在对象默认使用 `标准` 存储类型。
- 新建对象时可选择是否使用大容量存储。
- 选择大容量后，页面会隐藏不支持的属性和配置项。
- 对象保存后，数据存储类型不支持再次修改。

---

## 2\. 对象配置范围

大容量对象仍在对象管理中创建和维护，但支持的对象属性范围较小。

支持的对象属性包括：
- 对象名称
- Code
- 状态
- 来源
- 对象类别
- 数据存储类型
- 描述
- 在业务管理菜单中显示
- 启用对象类型
- 生命周期
- 数据所有权

补充说明：
- 大容量对象的 `对象类别` 仅支持 `基础`。
- 创建大容量对象时，应优先确认对象是否确实需要大数据量存储能力。
- 大容量对象不支持 `审计追踪`、`电子签名`、`工作流时间线`、`DAC`、`唯一性校验`、`验证规则`、`通知`、`作业` 等能力，创建页中相关设置项不适用。

---

## 3\. 字段支持范围

大容量对象仅支持部分字段类型。

### 3.1 支持的字段类型
- 文本
- 数字
- 布尔
- 选项
- 日期
- 日期时间
- 对象
- 公式

### 3.2 不支持的字段类型与字段能力

大容量对象不支持以下字段类型或字段能力：
- 查找字段
- 统计字段
- 父对象字段
- 附件字段
- 对象（多选）字段
- 选项字段多选
- 设置字段默认值
- 设置字段图标
- 唯一性校验

### 3.3 字段属性限制

| 字段类型 | 不支持的属性 |
|------------|------------------|
| 文本 | 唯一值、默认值、图标 |
| 数字 | 唯一值、默认值、图标 |
| 布尔 | 唯一值、默认值、图标 |
| 选项 | 唯一值、默认值、图标、多选 |
| 日期 | 默认值、图标 |
| 日期时间 | 默认值、图标 |
| 对象 | 唯一值、默认值、图标、引用约束条件、树形展示 |
| 公式 | 默认值、图标 |

### 3.4 编号规则限制
- 大容量对象支持业务编号。
- `name__ak` 字段不支持编号规则。

---

## 4\. 功能限制

大容量对象不支持以下能力：
- 审计追踪
- 电子签名
- 工作流时间线
- DAC（动态访问控制）
- 唯一性校验
- 验证规则
- 生命周期事件动作
- 生命周期进入条件
- 生命周期进入动作
- 通知
- 作业
- 字段：查找字段、统计字段、父对象字段、附件字段、对象（多选）字段
- 字段能力：选项字段多选、设置字段默认值、设置字段图标

查询能力限制：
- 字段不支持分面统计
- 单次最多查询 1000 条数据
- 文本类型字段不支持模糊匹配

补充说明：
- 大容量对象不支持工作流时间线，因此不适合需要完整流程追踪的业务对象。
- 大容量对象不支持 DAC，因此不适合依赖记录级动态权限控制的场景。
- 大容量对象不支持审计追踪和电子签名，因此不适合需要强合规留痕的场景。

使用建议：
- 如果对象依赖审计追踪、电子签名、动态权限、唯一性校验、验证规则或工作流，优先使用标准对象。
- 如果对象主要承担大批量记录存储，且流程、权限、校验要求较低，可优先评估大容量对象。

---

## 5\. 配置步骤

### 5.1 设置对象为大容量
1. 进入 `配置端 > 配置管理 > 对象管理 > 对象`。
2. 新建对象或进入对象编辑页。
3. 在对象基础属性中，勾选 `是否大容量` 。
4. 保存对象。

配置后预期：
- 页面中会自动隐藏大容量对象不支持的配置项。
- 生命周期事件动作、进入条件、进入动作相关高级能力不可用于该对象。

### 5.2 配置自定义过滤索引（可选）

对于记录量较大的对象，建议配置自定义过滤索引提升常用查询的响应速度。
1. 在对象详情页进入 `索引` 或 `自定义过滤索引` 页面。
2. 点击 `创建索引` 或 `添加索引`。
3. 选择高频筛选字段并保存。

索引建议：
- 按状态筛选：优先为状态相关字段建立索引。
- 按日期查询：优先为创建时间、业务日期字段建立索引。
- 组合筛选：为高频组合条件建立复合索引。
- 避免过度索引：索引越多，写入成本越高。

说明：
- 即使配置了索引，大容量对象仍受查询能力限制（分面统计/查询条数/模糊匹配）。

---

## 6\. 验证与最佳实践

验证建议：
- 在测试环境先做批量写入验证，确认写入成功率与耗时。
- 对高频查询条件做对比测试，确认索引优化效果。
- 核对关键业务逻辑是否依赖生命周期动作，避免上线后行为偏差。

最佳实践：
- 高写入、低流程依赖对象优先考虑大容量。
- 强合规、强流程、强权限控制对象优先使用标准对象。
- 在对象说明中记录采用大容量的原因与适用边界，便于后续维护。
