# 多记录工作流

多记录工作流用于在一次发起中纳入多条记录，统一推进审批、任务处理与状态流转，适用于批量审阅、批量更新等场景。

---

## 7\. 多记录工作流

### 7.1 多记录工作流概述

多记录工作流允许同时对多条记录发起工作流，适用于批量审批、批量处理等场景。

**工作流类型对比**：

| 特性 | 单记录工作流 | 多记录工作流 |
|------|------------------|------------------|
| **记录数量** | 单条记录 | 多条记录 |
| **生命周期** | 单个对象/文档生命周期 | 单个对象生命周期或所有文档生命周期 |
| **启动状态** | 支持配置启动状态 | 取交集，所有记录同时满足条件才可选择 |
| **任务分配模式** | 支持系统指派/任务领取 | 仅支持系统指派（默认） |
| **审批意见** | 单个审批意见 | 支持每个记录一个审批意见或所有记录共用一个审批意见 |
| **信封对象** | 无 | 自动创建信封对象记录，用于管理批量工作流 |

### 7.2 多记录工作流配置

**创建工作流时**：
1. 取消勾选【对单个对象记录使用工作流】
2. 选择生命周期： 
    - **对象工作流**：单个对象生命周期
    - **文档工作流**：所有文档生命周期或单个文档生命周期

**开始节点配置**：
- **字段控件**：多对象工作流不支持；多文档工作流支持基础文档字段或文档类型字段（取决于生命周期选择）
- **变量控件**：支持文本、选项、布尔、附件类型
- **参与人控件**：支持“工作流发起人选择参与者”和“使用角色作为参与者”
- **审批矩阵控件**：支持。可在开始节点配置审批矩阵参与人；批量发起时另见下文「基于审批矩阵的批量工作流」
- **开始节点规则**：条件为交集，所有记录同时满足条件才显示控件

**任务节点配置**：
- **审批意见**：可配置"每个记录一个审批意见"或"所有记录共用一个审批意见"
- **填写字段**：字段值应用到所有记录
- **提示例外**：仅所有文档生命周期支持，可配置对特定状态类型的文档进行审批提示

**动作节点配置**：
- **自动移除匹配的项**：支持在工作流执行过程中移除不满足条件的记录
- **修改状态**：所有文档生命周期支持修改状态类型；单个文档生命周期支持修改状态

### 7.3 发起多记录工作流

多记录工作流可从多个列表类入口发起，操作目标一致（批量勾选 → 发起 → 填信封/参与人），但入口场景与可选流程范围略有差异。

#### 发起入口对照

| 入口 | 典型操作 | 说明 |
|------|------------|------|
| **对象记录列表** | 勾选多条记录 → 表头 / 批量操作中的 **发起工作流** | 最常用入口；可选流程须为启用中的多记录工作流，且所选记录状态、权限均满足发起条件 |
| **保存的视图 / 收藏夹中的对象列表** | 同上 | 与对象列表相同，筛选条件来自当前视图或收藏范围 |
| **对象选项卡列表** | 同上 | 在业务模块选项卡打开的对象列表中批量勾选后发起 |
| **记录详情中的相关对象列表** | 在相关列表勾选多条子记录 → **发起工作流** | 表头批量能力与主列表一致；可选流程、权限仍按各子记录校验（取交集） |
> 文档多记录工作流同样从文档列表（或等价列表入口）批量勾选后发起；可选流程范围为文档类多记录工作流。   

#### 通用操作步骤
1. 在上述任一入口批量勾选记录（一次建议不超过系统上限，常见为 50～100 条，以当前环境提示为准）
2. 点击【发起工作流】
3. 系统显示可选的工作流（需满足：工作流处于启用状态、所选记录状态都满足发起状态、用户有发起权限）
4. 选择工作流后，填写多记录信封信息： 
    - 如果配置了信封对象为系统管理，则按规则生成描述信息（只读）
    - 否则出现文本框，让用户填写描述信息
    - 信封默认显示：信封\_
5. 填写开始节点配置的参与者、审批矩阵、日期、字段等信息
6. 确认后发起工作流

**权限检查**：
- 开始节点配置了字段时，需要判断当前用户对字段的权限
- 如果没有权限，会提示用户错误信息
- 完成任务界面也需要判断权限

### 7.4 多记录工作流任务处理

**任务入口**：
- 首页待办任务列表
- 任务详情页显示多记录列表

**任务完成**：
- 左侧展示多记录列表，点击每个记录可查看详情
- 可点击移除按钮从工作流信封中移除记录
- 被移除的记录不再参与后续的工作流任务
- 已完成的工作流任务不会受到影响
- 移除的项可以恢复（仅限本人在当前任务节点移除的项）

**审批意见填写**：
- **每个记录一个审批意见**：需要对所有记录都填写完审批意见后，才可以点击"提交"
- **所有记录共用一个审批意见**：填写一个审批意见即可提交

**筛选条件**：

多记录列表支持筛选，条件项来源于工作流任务节点配置的"审批意见"的选项。

### 7.5 基于审批矩阵的批量工作流

当工作流使用审批矩阵作为参与人时，支持批量发起工作流。

**匹配规则检查**：

批量发起基于审批矩阵的工作流时，系统会检查：
- 所选记录匹配的审批矩阵规则是否一致
- 如果不一致，提示："所选记录的审批矩阵规则条件不相同，无法发起此工作流"

**审批矩阵加载**：
- 如果所选记录匹配的规则一致，正常加载审批矩阵
- 根据审批矩阵规则显示控件，与单记录工作流一致
- 无论所选记录是否已经在布局上设置了审批矩阵成员，此处都不会自动显示表单上的成员

**成员写入**：

成功发起工作流后，将选择的成员全部写入实例审批矩阵中，写入方式为完全覆盖。
