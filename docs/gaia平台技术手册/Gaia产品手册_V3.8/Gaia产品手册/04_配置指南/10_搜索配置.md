# 搜索配置
> 本文介绍如何配置 Gaia 平台的搜索功能，包括搜索字段配置、搜索设置和统一搜索功能。   

---

## 概述

Gaia 平台提供强大的搜索功能，支持对文档、对象记录和附件进行全文检索。通过配置搜索字段、搜索设置和统一搜索，可以优化搜索体验，提高检索效率。

本文中常见匹配模式的含义如下：
- **模糊匹配**：只要字段值中包含搜索词即可命中。示例：搜索“培训”时，可命中“年度培训计划”。
- **精确匹配**：字段值与搜索词完全一致时才命中。示例：搜索“DMS-001”时，仅命中值为“DMS-001”的记录。

---

## 1\. 搜索字段配置

### 功能说明

搜索字段用于配置对象可搜索的字段及匹配模式。默认情况下，对象的 `name__ak` 字段会自动作为搜索字段，且为模糊匹配。

**访问路径**：管理端 \> 对象设置 \> 搜索字段设置

### 创建搜索字段

当前版本中，搜索字段采用**手动创建**方式。系统不会在创建对象字段时自动生成搜索字段，需要管理员按业务需求逐个配置。

**操作说明**：
1. 进入`管理端 > 对象设置 > 搜索字段设置`
2. 点击**配置**，选择目标对象和字段
3. 根据检索场景设置匹配模式、是否作为高级搜索过滤条件、是否作为限定符
4. 保存后生效；如后续业务规则变化，可在列表中编辑、停用或删除
> 说明：对象的 `name__ak` 字段默认作为搜索字段（模糊匹配），无需手动新增。   

### 搜索字段列表

列表分页显示对象下所有的搜索字段，显示列说明如下：

| 列表显示 | 描述 | 备注 |
|------------|------|------|
| 字段 | 对象字段的名称 | 可点击，点击后进入查看模式 |
| 匹配模式 | 模糊匹配/精准匹配 |  |
| 状态 | 搜索字段的状态（启用/停用） |  |
| 操作 | **配置**：进入配置搜索字段页面<br>**编辑**：进入搜索字段编辑页面<br>**停用**：启用时可见，如果停用该字段在搜索时不会生效<br>**启用**：停用时可见，如果启用，字段的符合条件值会在搜索结果中显示<br>**删除**：删除后可以重新在配置字段时选到 |  |

### 配置搜索字段

配置页入口位于对象内，典型面包屑为：`所有的对象 > {对象名称} > 搜索字段 > 创建`（编辑时为“编辑”页）。页面右上角提供**返回**和**保存**按钮。

配置页面分为 3 个区域。

#### 1）详情

| 表单项 | 说明 | 配置建议 |
|---------|------|------------|
| 字段（必填） | 选择要纳入搜索配置的对象字段 | 仅可选择当前对象下可配置字段；已配置字段不可重复选择 |
| 状态（必填） | 控制该搜索字段是否生效（启用/停用） | 新增后建议先“启用”，如需灰度可先停用再按批次开启 |

#### 2）匹配检索设置

| 表单项 | 说明 | 配置建议 |
|---------|------|------------|
| 启用匹配检索 | 控制该字段是否参与关键词匹配检索 | 用于基础检索命中时建议开启 |
| 匹配模式（必填） | `模糊匹配` 或 `精确匹配` | 模糊匹配适合名称/描述类字段；精确匹配适合编码、ID、标准术语等字段 |

#### 3）高级检索设置

| 表单项 | 说明 | 配置建议 |
|---------|------|------------|
| 启用全文检索 | 允许该字段参与全文检索能力 | 适用于文本内容检索；非文本字段通常不启用 |
| 设置为过滤条件 | 在高级搜索中作为可选过滤项 | 建议优先配置业务高频筛选字段；系统最多支持 5 个过滤条件 |
| 设置为限定符 | 在全局搜索中作为限定符使用 | 适合对象类型、状态、分类等结构化字段 |
| 匹配权重 | 控制字段匹配对排序的影响权重 | 默认 `1`；核心字段可适度提高权重 |
| 分词器 | 控制该字段的分词策略 | 按业务语言和检索精度要求选择；示例为“最细力度分词” |

### 分词器选项说明

以下说明基于当前界面命名与已公开分词能力整理，用于配置选型。若实际行为与说明不一致，请以测试环境验证结果为准。

| 分词器 | 适用场景 | 说明 |
|---------|------------|------|
| 最细力度分词 | 中文标题、正文检索，召回优先 | 通常对应 IK `ik&#95;max&#95;word`，会尽可能细粒度切分，召回更高，但可能引入更多噪音词。 |
| 智能分词 | 短语检索、精度优先 | 通常对应 IK `ik&#95;smart`，采用较粗粒度切分，结果更集中。 |
| 拼音分词 | 需要支持拼音/首字母检索 | 支持中文按拼音检索，常见支持全拼与首字母，且通常对大小写不敏感。 |
| 最细力度拼音分词 | 同时需要中文细粒度召回和拼音检索 | 在最细力度分词基础上叠加拼音能力，兼顾中文与拼音搜索。底层组合参数待补充（以研发配置为准）。 |
| 最细力度分词(含同义词) | 专业术语、简称/别名较多 | 在最细力度分词基础上叠加同义词扩展，输入别名也可命中标准术语内容。 |
| 下划线分词 | 编码、技术标识中包含 `&#95;` | 以 `&#95;` 作为分隔符切分，例如 `risk&#95;level&#95;high` 可拆分为 `risk`、`level`、`high`。 |
| 逗号分词 | 单字段保存逗号分隔多值 | 以 `,` 作为分隔符切分，例如 `A,B,C` 可拆分为 `A`、`B`、`C`。 |

### 配置步骤
1. 在对象的**搜索字段**页点击“创建”。
2. 在“详情”区域选择字段并设置状态。
3. 按需勾选“启用匹配检索”，并选择匹配模式。
4. 在“高级检索设置”中按业务场景勾选全文检索、过滤条件、限定符，设置匹配权重与分词器。
5. 点击右上角**保存**生效；点击**返回**将离开当前页。
> 说明：对象 `name__ak` 字段默认作为搜索字段（模糊匹配），无需重复新增。

### 编辑搜索字段

编辑时，所有属性都可以编辑。

### 对象搜索字段详情页动作

在对象搜索字段详情页中，页面提供以下两个索引构建动作：

| 动作 | 作用 | 使用建议 |
|------|------|------------|
| 构建分词索引 | 触发当前搜索字段的分词索引构建/重建，使字段内容可按分词策略参与检索。 | 新增搜索字段、调整分词器或出现命中延迟时优先执行。 |
| 构建推荐词索引 | 触发推荐词索引构建/重建，用于提升搜索输入时的推荐词、联想词效果。 | 调整推荐词策略、批量新增术语或推荐词结果不准确时执行。 |

补充说明：
- 这两个动作只影响搜索索引，不会修改对象字段本身的数据。
- 建议在业务低峰期执行，避免大对象重建时对在线检索体验产生波动。
- 执行后可通过典型关键词做一次检索验证，确认分词命中和推荐词是否符合预期。

## 2\. 搜索设置

### 功能说明

搜索设置用于配置全局搜索行为，包括匹配设置、文档搜索设置和默认搜索选项。

**访问路径**：管理端 \> 系统设置 \> 搜索设置

### 页面配置项（基于当前界面）

当前“搜索设置”页可见配置项如下：

| 区域 | 配置项 | 说明 | 配置建议 |
|------|---------|------|------------|
| 顶部开关 | 启用全文检索 | 控制是否在统一搜索中启用全文索引查询能力。 | 需要检索文档正文/附件内容时建议启用。 |
| 匹配设置 | 启用严格匹配 | 控制多关键词检索时的命中门槛。 | 检索精度要求高时启用；希望扩大召回时关闭。 |
| 默认搜索选项卡 | 默认搜索选项卡（必填） | 设置业务端统一搜索默认落地的对象/菜单选项卡。 | 建议设置为使用频次最高的对象 |
| 文档搜索设置 | 文件摘要权重 | 控制“文件摘要”字段对结果排序的影响程度。 | 摘要质量较高时可适当提高；取值范围待补充。 |
| 文档搜索设置 | 文件摘要分词器 | 控制“文件摘要”字段的分词策略。 | 中文场景默认可用“最细力度分词”；专业术语多时可结合同义词分词。 |
| 文档搜索设置 | 文件内容权重 | 控制“文件内容”字段对结果排序的影响程度。 | 正文命中优先时可提高；取值范围待补充。 |
| 文档搜索设置 | 文件内容分词器 | 控制“文件内容”字段的分词策略。 | 通常与“文件摘要分词器”保持一致，便于结果稳定。 |
> 说明：页面示例中“文件摘要权重”“文件内容权重”示例值均为 `99`。权重允许范围和边界校验规则待补充。   

### 配置步骤（按当前页面）
1. 在“搜索设置”页按需勾选**启用全文检索**。
2. 展开“匹配设置”，按需勾选**启用严格匹配**。
3. 在“默认搜索选项卡”区域选择默认选项卡（必填）。
4. 在“文档搜索设置”区域依次设置摘要/内容的权重与分词器。
5. 点击页面右上角**保存**使配置生效。

### 全文检索

全文检索表示全文检索模式，开启后才会基于全文索引进行查询。默认不开启。开启后在业务端统一搜索时，将在全文索引中查询，同时显示高级检索的远望镜图标。

### 匹配设置

#### 严格匹配

**如果启用了严格匹配**：
- 使用一个或两个搜索词执行搜索时，要求匹配同一字段中的所有词语
- 使用三个或四个搜索词执行搜索时，要求除了同一字段中的一个搜索词以外，所有搜索词都匹配
- 使用五个或更多搜索词执行搜索时，要求除了同一字段中的两个搜索词以外，所有搜索词都匹配

**如果没启用严格匹配**：
- 系统只要求一个搜索词匹配，因此会得到不太精确的搜索结果

### 默认搜索选项卡

默认情况下通常以文档作为搜索选项卡。若要修改默认项，可在“默认搜索选项卡”中选择其他对象菜单。

可选项范围为所有启用状态、且类型为对象的菜单。
