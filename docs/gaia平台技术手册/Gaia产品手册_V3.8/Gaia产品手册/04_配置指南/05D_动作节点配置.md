# 动作节点配置

动作节点用于在流程中自动执行系统动作，如修改状态、回写字段或联动相关记录。

---

## 动作节点配置

动作节点用于需要系统自动执行的工作流任务。

**典型面包屑路径**：

`工作流 > {工作流名称} > 节点: {动作节点名称}`

页面右上角常见操作如下：

| 操作 | 说明 |
|------|------|
| **删除** | 删除当前动作节点（仅在可编辑版本中可用）。 |
| **取消** | 放弃当前未保存修改，返回上一状态。 |
| **保存** | 保存当前动作节点配置。 |

### 1.1 详情区配置

`详情` 区用于维护动作节点的基础信息。

| 字段 | 说明 |
|------|------|
| **名称** | 动作节点显示名称。 |
| **Code** | 动作节点系统编码，建议使用稳定英文标识。 |
| **类型** | 当前节点类型，动作节点通常显示为`动作`。 |
| **描述** | 补充说明该动作节点的用途、适用条件或维护备注。 |
| **下一步** | 动作执行后流转到的下一个节点。可配置一个或多个候选节点。 |

### 1.2 动作设置区配置

`动作设置` 区用于配置“执行方式”与“具体动作条目”。

#### 执行方式

| 执行方式 | 说明 | 使用建议 |
|------------|------|------------|
| **总是执行** | 节点到达后直接执行动作。 | 适用于所有记录都应执行同一动作的场景。 |
| **有条件地执行** | 仅在满足规则条件时执行动作。 | 适用于需要按字段值、分支结果等条件控制动作执行的场景。 |

#### 动作条目配置项

| 配置项 | 说明 |
|---------|------|
| **动作类型** | 选择当前条目要执行的动作能力（如`修改状态`、`修改记录字段`等）。 |
| **状态** | 当动作类型为`修改状态`时，指定目标生命周期状态。 |
| **当前对象字段** | 当动作类型涉及字段回写时，指定要更新的字段。 |
| **值** | 指定字段回写值（例如固定值、指定为空等）。 |
| **添加动作** | 在同一动作节点中继续新增动作条目，按配置顺序依次执行。 |
| **删除动作（垃圾桶图标）** | 删除当前动作条目。 |

### 1.3 配置示例：修改为暂时关闭

以截图中的节点为例，可配置为以下两条动作：
1. `执行方式 = 总是执行`
2. 动作条目 1：`动作类型 = 修改状态`，`状态 = 暂时关闭`
3. 动作条目 2：`动作类型 = 修改记录字段`，`当前对象字段 = DW`，`值 = 指定为空`

该配置保存后，节点命中时会先把记录状态改为“暂时关闭”，再将字段 `DW` 清空，最后按`下一步`流转到后续节点。

### 1.4 常见动作类型速查

#### 1.4.1 基础记录动作

| 动作类型 | 说明 | 使用建议 |
|------------|------|------------|
| **修改附件字段** | 修改当前记录中的附件字段。 | 适合流程推进后，需要替换、补充或更新当前记录附件的场景。 |
| **修改相关对象附件字段** | 修改相关对象记录中的附件字段。 | 适合联动更新关联记录上的附件内容。 |
| **修改状态** | 修改当前记录的生命周期状态。 | 适合流程完成某一步后，直接推动当前记录进入下一状态。 |
| **设置字段为空** | 将当前记录中的指定字段清空。 | 适合清理流程中的临时值、重置字段或撤销前序自动回写结果。 |
| **创建相关对象记录** | 创建一条与当前记录相关联的新对象记录。 | 适合流程中自动生成后续业务记录。 |
| **根据相关对象创建记录** | 基于已关联对象的数据创建新记录。 | 适合以现有关联对象为来源，继续派生新业务记录。 |
| **修改状态为工作流启动时状态** | 将当前记录状态恢复为流程启动时的状态。 | 适合撤回、退回或补偿处理场景。 |
| **修改相关对象记录** | 修改相关对象记录。 | 适合需要联动调整关联记录内容，但具体修改方式不止单字段回写的场景。 |
| **修改相关对象生命周期状态（废弃）** | 旧版动作类型，用于修改相关对象的生命周期状态。 | 已标记为废弃，新流程不建议继续使用。 |
| **修改相关对象生命周期状态** | 修改相关对象记录的生命周期状态。 | 适合当前记录推进后，需要同步推动关联对象状态的场景。 |
| **修改记录字段** | 更新当前记录中的单个字段值。 | 适合回写一个明确结果，例如审批日期、状态标记或处理结论。 |
| **修改记录字段(多字段)** | 一次更新当前记录中的多个字段值。 | 适合在同一动作里批量回写多个结果字段。 |
| **修改相关对象记录字段（废弃）** | 旧版动作类型，用于修改相关对象记录的单个字段。 | 已标记为废弃，建议优先使用非废弃版本。 |
| **修改相关对象记录字段** | 更新相关对象记录中的单个字段值。 | 适合联动回写关联记录中的某一个字段。 |
| **修改相关对象记录字段（多字段）(废弃)** | 旧版动作类型，用于一次更新相关对象记录中的多个字段。 | 已标记为废弃，新流程不建议继续使用。 |
| **修改相关对象记录字段（多字段）** | 一次更新相关对象记录中的多个字段值。 | 适合在一个动作里同步回写多个关联字段。 |

#### 1.4.2 批量与辅助动作

| 动作类型 | 说明 | 使用建议 |
|------------|------|------------|
| **批量修改相关对象生命周期状态** | 批量修改多条相关对象记录的生命周期状态。 | 适合一条主流程需要同时推动多条关联记录状态的场景。 |
| **批量修改相关对象记录字段** | 批量修改多条相关对象记录的字段值。 | 适合统一回写一组关联记录的处理结果。 |
| **批量生成相关对象编号** | 为相关对象记录批量生成编号。 | 适合在流程中统一补齐或生成关联记录编码。 |
| **文件打印替换最新版本** | 将文件打印结果替换到最新版本。 | 适合文档类或文件类流程中的打印归档场景。 |
| **检查是否存在活跃的导入数据任务** | 检查当前是否存在仍在执行中的导入数据任务。 | 适合在流程继续推进前做前置校验，避免和导入任务冲突。 |
| **使电子签名记录作废** | 将相关电子签名记录标记为作废。 | 适合流程撤回、取消或签名失效后的补偿处理。 |
| **移除任务电子签名记录** | 删除或移除任务上的电子签名记录。 | 适合任务重置、撤回后清理任务签名痕迹。 |

#### 1.4.3 模块专用动作

以下动作通常只会在对应模块已启用、且当前租户具备相关能力时出现在下拉框中：

| 动作类型 | 说明 | 使用建议 |
|------------|------|------------|
| **\[DMS\]文件委托** | DMS 模块中的文件委托类动作。 | 适合文件处理责任转交或委托场景。 |
| **\[DMS\]计算培训完成率** | DMS 模块中的培训完成率计算动作。 | 适合文档培训流程中自动回写培训结果。 |
| **\[DMS\]批量计算平衡表** | DMS 模块中的批量平衡表计算动作。 | 适合批量处理后统一生成或更新平衡表结果。 |
| **\[DMS\]生成批量下载附件** | DMS 模块中的批量附件下载生成动作。 | 适合需要汇总导出附件的场景。 |
| **\[TMS\]发布测验** | TMS 模块中的测验发布动作。 | 适合培训流程推进到测验发放环节时自动执行。 |
| **\[TMS\]执行影响决策** | TMS 模块中的影响决策动作。 | 适合培训或影响评估流程中的系统决策处理。 |
| **\[TMS\]角色的学员生成至直接分配请求-学员** | 按 TMS 角色生成直接分配请求中的学员。 | 适合培训直接分配场景下批量生成目标学员。 |

说明：
- 动作类型名称中带`废弃`的选项表示旧能力仍可见，但不建议在新配置中继续使用。
- 新建流程或调整流程时，优先选择不带`废弃`标记的对应类型，后续维护会更清晰。
- 如果下拉框中出现带模块前缀的动作，通常表示该动作依赖对应产品模块能力，不属于所有工作流都会看到的通用动作。

### 1.5 废弃动作使用建议
- 所有名称中带废弃标记的动作，仅用于兼容历史流程中的旧配置。
- 在新建流程或新增动作配置时，不推荐继续选择任何废弃动作。
- 在实施配置优化、版本升级或流程改造时，建议将已使用的废弃动作逐步替换为对应的非废弃动作。
