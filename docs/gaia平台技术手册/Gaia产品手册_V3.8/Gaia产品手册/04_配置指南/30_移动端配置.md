# 移动端配置
> 本文说明如何在 Gaia 平台配置“移动端设置”，用于管理移动端工作台菜单的展示内容、展示顺序和入口行为。

## 1\. 页面入口与作用

### 1.1 访问路径

`管理端 > 配置管理 > 移动端设置`

### 1.2 页面作用

移动端设置用于维护移动端工作台菜单，包括：
1. 创建和维护菜单项
2. 控制菜单是否在移动端展示
3. 调整菜单在移动端的展示顺序
4. 维护菜单名称、图标和颜色
5. 配置扫码批量提交流程（用于发起收回申请等场景）

---

## 2\. 配置范围与生效规则

### 2.1 菜单层级

移动端菜单当前为单层结构，不支持多级子菜单。

### 2.2 生效规则
- 菜单状态为`启用`时，菜单会在移动端工作台展示。
- 菜单状态为`停用`时，菜单不会在移动端展示。
- 菜单排序以配置端排序结果为准，移动端按该顺序展示。
- 菜单名称、图标、颜色会同步影响移动端工作台显示效果。
- 选择`扫码批量提交`类型后，系统会按动作类型展示额外配置字段。

## 3\. 创建移动端菜单
1. 进入`移动端设置`页面。
2. 点击`创建`。
3. 在右侧创建区域填写菜单信息。
4. 保存后菜单进入列表，并按当前排序规则参与展示。

### 3.1 字段说明

| 字段 | 必填 | 说明 | 生效结果 |
|------|------|------|------------|
| 名称 | 是 | 菜单显示名称，唯一。 | 在移动端作为菜单标题展示。 |
| Code | 是 | 菜单唯一标识，唯一。 | 用于系统识别该菜单配置。 |
| 状态 | 是 | 可选`启用/停用`，默认`启用`。 | 决定该菜单是否在移动端可见。 |
| 来源 | 否 | 可见值：`系统/标准/自定义`；创建时默认`自定义`，只读。 | 决定菜单可执行的维护操作范围。 |
| 类型 | 是 | 可选`Web菜单/链接/扫码批量提交`；默认`Web菜单`。 | 决定点击菜单后的跳转或动作行为。 |
| 菜单 | 条件必填 | 仅在类型为`Web菜单`时显示；可选 PC 端“对象类型菜单”。 | 点击后进入对应业务页面。 |
| 链接地址 | 条件必填 | 仅在类型为`链接`时显示；支持`公式`或`指定常量`两种取值方式。 | 点击后按配置地址跳转。 |
| 动作类型 | 条件必填 | 仅在类型为`扫码批量提交`时显示；可选`创建出站对象/修改状态`。 | 决定扫码后提交动作的处理方式。 |
| 扫码对象 | 条件必填 | 仅在动作类型为`修改状态`时显示；可选“已启用且启用了生命周期”的对象；仅创建时可编辑。 | 作为扫码解析与后续动作执行的目标对象。 |
| 提交动作 | 条件必填 | 仅在动作类型为`修改状态`时显示；可选扫码对象生命周期状态中定义的用户动作；仅创建时可编辑。 | 移动端底部提交按钮文案与该动作文案保持一致；若动作要求电子签名，移动端提交时也要求签名。 |
| 启动时允许不选择批量操作的数据 | 条件可选 | 仅在类型为`扫码批量提交`时显示的复选框。 | 勾选后点击动作按钮时，不校验是否已预先选择批量数据。 |
| 相关对象 | 条件显示 | 仅在特定扫码类能力中显示（如领取/回收记录与文件）。 | 用于扫码后定位目标对象记录。 |
| 图标 | 否 | 选择系统图标。 | 移动端菜单显示对应图标。 |
| 颜色 | 否 | 颜色枚举值。 | 移动端菜单图标按配置颜色展示；不设置时使用默认蓝色。 |

### 3.2 类型行为说明

| 类型 | 点击后行为 |
|------|---------------|
| Web菜单 | 跳转到所选菜单对应页面。 |
| 链接 | 跳转到配置的链接地址。 |
| 扫码批量提交 | 进入扫码批量提交流程；支持连续扫描记录并发起提交动作。 |

### 3.3 不同菜单类型字段对照

| 菜单类型 | 必填字段 | 可选字段 | 说明 |
|------------|------------|------------|------|
| Web菜单 | 名称、Code、状态、类型、Web菜单 | 图标、颜色 | `Web菜单`字段用于选择要打开的业务菜单。 |
| 链接 | 名称、Code、状态、类型、链接地址 | 图标、颜色 | `链接地址`支持`公式`和`指定常量`两种方式。 |
| 扫码批量提交 | 名称、Code、状态、类型、扫码对象、提交动作 | 图标、颜色 | 当前截图下以“提交动作”直接配置；若界面出现“动作类型”，再按动作类型控制后续字段显隐。 |

### 3.4 扫码批量提交（收回申请）配置要点
1. 菜单类型选择`扫码批量提交`后，先配置`动作类型`。
2. 若动作类型为`修改状态`，继续配置`扫码对象`和`提交按钮动作`。
3. `扫码对象`变化时，系统会清空与批量提交关联的字段（如创建对象、对象类型、提交按钮动作），需重新确认提交逻辑。
4. 若提交按钮动作配置为需要电子签名，移动端提交时会同步要求输入电子签名。
5. 按需勾选`启动时允许不选择批量操作的数据`，决定是否在点击动作按钮时做预选数据校验。

## 4\. 菜单维护

### 4.1 齿轮操作

菜单列表中的齿轮提供`编辑`和`移除`操作。

### 4.2 编辑

进入编辑模式后，可维护以下字段：
- 名称
- 状态
- 菜单类型
- Web菜单 / 链接地址（按类型显示）
- 动作类型（当类型为`扫码批量提交`）
- 图标
- 颜色

说明：
- `扫码对象`和`提交按钮动作`在动作类型为`修改状态`时，仅创建阶段可编辑，保存后不支持修改。

### 4.3 移除

点击`移除`后，系统会弹出二次确认提示。确认后菜单被删除，删除操作不可撤销。

### 4.4 来源与可操作范围

| 来源类型 | 可执行操作 |
|------------|---------------|
| 系统 | 编辑 |
| 标准 | 编辑 |
| 自定义 | 编辑、移除 |

---

## 5\. 排序与移动端展示
1. 点击列表顶部`排序`进入排序模式。
2. 拖拽菜单项调整顺序。
3. 保存后移动端按新顺序展示。

移动端首页工作台会按配置顺序展示菜单。

### 5.1 扫码批量提交页面行为
- 进入页面后可调用企业应用扫码能力（如钉钉、企业微信、飞书容器）。
- 支持连续扫描多条受控记录，并在页面中展示已扫描列表。
- 列表以卡片形式展示记录，卡片标题为受控号（`name__ak`）。
- 支持删除单条已扫描记录。
- 页面提供`提交收回`与`清空`操作。
- 系统提供扫描成功、扫描失败、重复扫描、提交成功/失败等反馈提示。

系统内置标准菜单包含：
- 文件
- 培训

标准菜单支持维护：
- 名称

## 7\. 权限控制

移动端设置受权限集控制。未授予对应权限时，用户在管理端看不到“移动端设置”入口。

## 8\. 常见问题

### Q1：菜单已创建但移动端看不到？

先检查菜单`状态`是否为`启用`，再确认菜单排序是否正确，以及当前用户是否有对应菜单访问权限。

### Q2：为什么有些菜单不能删除？

来源为`系统`或`标准`的菜单仅支持编辑，不支持移除；仅`自定义`菜单支持移除。

### Q3：和怎么选？

如果要进入 Gaia 内业务菜单，选择`Web菜单`；如果要跳转到外部地址，选择`链接`。

### Q4：为什么看不到“动作类型/扫码对象/提交按钮动作”字段？

`动作类型`仅在菜单类型为`扫码批量提交`时显示；`扫码对象`和`提交按钮动作`仅在动作类型为`修改状态`时显示。

### Q5：移动端提交时为什么要求电子签名？

当“提交按钮动作”对应的生命周期用户动作启用了电子签名时，移动端会沿用同一校验规则，提交前必须完成签名。
