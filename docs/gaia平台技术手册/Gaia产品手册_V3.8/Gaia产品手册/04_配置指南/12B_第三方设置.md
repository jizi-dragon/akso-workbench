> 本文档说明 Gaia 平台“第三方设置”页面的配置项与联调方式，用于支撑通知渠道的实际投递能力。

## 1\. 页面入口与结构

### 1.1 访问路径

`管理端 > 系统设置 > 第三方设置`

### 1.2 页面布局

页面右上角提供`编辑`按钮；进入编辑状态后可维护各渠道参数。

根据当前界面，第三方设置包含以下分组：
1. 微信配置
2. 钉钉配置
3. 邮件配置
4. 短信配置
5. 平台消息配置
6. 外部协作专用邮件配置
7. WeLink
8. 飞书配置

各分组通常以折叠面板呈现，按需展开配置。

---

## 2\. 分组配置说明

### 2.1 微信配置

用于配置微信渠道所需的应用参数（如应用标识、密钥、回调地址等）。

配置建议：
- 参数命名与第三方平台保持一致。
- 保存后先在测试环境触发一条通知验证可达性。

### 2.2 钉钉配置

用于配置钉钉渠道所需的应用参数（如应用标识、密钥、AgentId、回调参数等）。

配置建议：
- 优先使用专用测试应用联调，确认权限与回调可用后再切正式应用。

### 2.3 邮件配置

用于配置 SMTP 发信能力。界面提供`邮箱测试`按钮，可用于连通性验证。

常见配置项：

| 配置项 | 说明 |
|---------|------|
| 发件服务器地址 | SMTP 地址 |
| 发件服务器端口 | 常见端口 465/587 |
| 加密方式 | SSL/TLS |
| 发件人邮箱地址 | 系统发件地址 |
| 邮箱授权码 | SMTP 授权码（非邮箱登录密码） |

### 2.4 短信配置

用于配置短信服务商接入参数。

前置要求：
- 先在短信供应商侧完成短信模板备案。
- 准备可用模板 ID、签名名称、通道号等参数。

常见配置项：

| 配置项 | 说明 |
|---------|------|
| APP\_Key / APP\_Secret | 平台应用密钥 |
| 接入地址 | 平台 API 地址 |
| 签名名称 / 通道号 | 由短信平台分配 |
| 模板 ID | 对应外部短信模板 |

### 2.5 平台消息配置

用于维护平台内消息通道参数与投递策略（如消息入口、基础推送开关等）。

配置建议：
- 先保证站内消息可投递，再叠加外部渠道联调。

### 2.6 外部协作专用邮件配置

用于外部协作场景下的邮件通道配置。界面提供：
- `发件邮箱测试`
- `收件邮箱测试`

建议先分别执行发件与收件测试，确认双向链路可用后再启用生产发送。

### 2.7 WeLink

用于 WeLink 渠道参数维护（应用标识、密钥、回调参数等）。

### 2.8 飞书配置

用于飞书渠道参数维护（应用标识、密钥、回调参数等）。

---

## 3\. 推荐配置顺序
1. 进入`第三方设置`并点击`编辑`。
2. 先完成邮件与短信基础能力配置（便于快速验证）。
3. 再配置微信、钉钉、WeLink、飞书等协作渠道。
4. 执行页面提供的测试按钮（邮箱测试、发件邮箱测试、收件邮箱测试）。
5. 返回`通知配置`创建模板并做端到端联调。

---

## 4\. 常见问题

### Q1：模板配置正常，但外部渠道未送达，先查什么？

优先检查第三方设置中的渠道参数是否保存成功、测试按钮是否通过、渠道侧应用权限是否完整。

### Q2：邮件可发但外部协作专用邮件不可用，怎么排查？

分开执行`发件邮箱测试`和`收件邮箱测试`，确认收发链路是否都通过。
