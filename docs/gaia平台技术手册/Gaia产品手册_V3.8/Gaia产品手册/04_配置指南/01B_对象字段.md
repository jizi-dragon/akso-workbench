\# 对象字段
> 本文介绍如何在 Gaia 平台中创建、查看、编辑和使用对象字段，重点覆盖字段页操作、通用字段属性，以及当前平台支持的字段类型。   

---

## 概述

对象字段用于承载业务数据，是对象配置中的核心组成部分。配置人员可在对象的 `字段` 页签中维护字段，并根据字段类型设置录入方式、显示方式、筛选能力、默认值、引用关系和结果计算方式。

### 访问路径

`配置端 > 配置管理 > 对象管理 > 对象 > 目标对象 > 字段`

---

## 1\. 字段页概览

### 1.1 页面顶部导航与按钮

在 `配置环境` 中，进入 `配置管理 > 对象管理 > 对象` 后，可在目标对象的 `字段` 页签中管理字段。页面顶部和侧边用于帮助用户定位当前对象、切换配置页签和创建字段：

| 控件 | 作用 |
|------|------|
| 顶部模块导航 | 用于在 `配置环境` 中切换 `管理端 / 配置管理 / 用户管理 / 日志管理 / 运维管理 / 部署管理 / 集成管理 / 系统设置` 等一级模块；字段配置位于 `配置管理` 模块下 |
| 左侧功能导航 | 用于在配置管理中切换不同配置域。字段页所在位置为 `对象管理 &gt; 对象`，便于用户确认自己正在对象配置范围内操作 |
| 面包屑导航 | 用于显示当前对象上下文。字段列表页显示为 `所有的对象 &gt; {对象名称}`，帮助用户确认当前正在维护哪个对象，并可快速返回对象列表或当前对象主页 |
| `创建` | 位于页面右上角，用于进入字段创建页，为当前对象新增字段 |

### 1.2 对象内页签

字段页并不是独立模块，而是当前对象配置中的一个页签。打开对象后，可通过以下页签切换不同配置内容：

| 页签 | 作用 |
|------|------|
| `基础` | 查看和维护对象本身的基础属性 |
| `对象类型` | 维护对象类型及其相关配置 |
| `字段` | 查看、查询、创建和维护当前对象字段 |
| `搜索字段` | 配置对象在搜索场景中可使用的字段 |
| `关系` | 维护对象与其它对象之间的关系 |
| `列表布局` | 配置对象列表页展示字段和布局方式 |
| `表单布局` | 配置对象详情页和编辑页的表单展示结构 |
| `动作` | 维护对象级动作、记录动作或相关进入动作 |
| `验证规则` | 管理对象数据校验规则 |
| `索引规则` | 管理对象查询或检索相关的索引规则 |

字段页签高亮时，表示用户当前正在该对象下维护字段配置，而不是浏览对象的其它配置能力。

### 1.3 列表工具区、字段表格与常用入口

字段列表页由查询区、分页区和字段表格组成：

| 区域 | 作用 |
|------|------|
| 查询输入框 | 用于按关键字查询字段，可按字段名称、Code 等信息缩小结果范围 |
| 查询按钮 | 对输入条件执行查询，刷新当前列表结果 |
| 记录总数 | 用于显示当前对象下字段总量，例如 `当前第1页 共74条`，帮助用户判断字段规模 |
| 分页控件 | 用于在不同页之间切换字段记录 |
| 每页条数 | 用于调整每页显示的记录数量，例如 `20条/页` |
| 跳页输入框 | 用于直接跳转到指定页码，适合字段较多时快速定位 |

字段表格展示以下信息：

| 列名 | 作用 |
|------|------|
| `字段名称` | 字段在界面中的显示名称；点击名称可进入该字段的详情页 |
| `Code` | 字段唯一编码，用于配置引用和系统识别 |
| `来源` | 用于区分字段是 `标准` 还是 `自定义`，帮助用户识别字段来源 |
| `数据类型` | 用于显示字段类型，例如文本、布尔、日期时间、对象、对象多选、组件等 |
| `状态` | 用于显示字段当前是 `启用` 还是 `停用` |
| `操作` | 以齿轮菜单显示，用于打开当前字段的可执行操作列表 |

常用入口包括：
- 点击字段名称：进入字段详情页，查看字段的完整配置结果
- 点击列表列头中的筛选或排序控件：按当前列缩小结果或调整显示顺序
- 点击行尾齿轮菜单：打开当前字段的操作菜单，常见操作包括查看详情、进入编辑或删除字段
- 删除字段前：应确认该字段未被布局、规则、动作、工作流、生命周期或其它配置依赖

### 1.4 字段详情页与编辑页

字段详情页顶部提供以下导航和操作：

| 控件 | 作用 |
|------|------|
| 面包屑导航 | 用于显示当前所在路径，显示为 `配置端 &gt; 配置管理 &gt; 对象管理 &gt; 对象 &gt; {对象名称} &gt; 字段 &gt; {字段名称}`，帮助用户确认当前查看的是哪个字段 |
| `返回` | 返回字段列表页，继续查看或维护其它字段 |
| `删除` | 删除当前字段；执行前应确认该字段未被其它配置引用 |
| `编辑` | 进入当前字段的编辑模式，用于修改允许调整的字段属性 |

字段编辑页顶部提供以下导航和操作：

| 控件 | 作用 |
|------|------|
| 面包屑导航 | 用于显示当前仍处于 `对象 &gt; 字段 &gt; {字段名称}` 的上下文中，帮助用户确认正在编辑哪个字段 |
| `取消` | 放弃本次尚未保存的修改，返回字段详情页或退出编辑状态 |
| `保存` | 保存当前字段修改，并刷新为最新配置结果 |

## 2\. 创建与管理字段

### 2.1 创建流程
1. 进入目标对象的 `字段` 页签。
2. 点击右上角 `创建`。
3. 选择字段类型。
4. 填写字段基础属性和该类型的专属配置项。
5. 点击 `保存` 完成创建。

### 2.2 通用字段属性

除字段类型专属能力外，大部分字段在创建和编辑时都涉及以下通用属性：

| 属性 | 说明 | 备注 |
|------|------|------|
| 字段名称 | 字段在界面上的显示名称 | 必填，长度为 1-200 字符 |
| Code | 字段唯一编码，用于配置引用和系统识别 | 必填、唯一，长度为 1-200 字符；创建后不可修改 |
| 状态 | 控制字段是否启用 | 可选值为 `启用`、`停用`；默认值为 `启用`。只有启用状态的字段才能被添加到其它配置中 |
| 必填 | 控制业务端录入时是否必须填写 | 启用后，业务端必须填写该字段后才能保存记录；该属性仅在支持必填设置的字段类型上显示 |
| 可编辑 | 控制字段在业务端是否允许编辑 | 关闭后，字段在业务端通常以只读方式展示；适用于需要锁定值的场景 |
| 开启行内编辑 | 控制字段是否支持在列表中直接编辑 | 启用后，用户可在列表页行内修改该字段值；仅在支持行内编辑的字段类型上显示 |
| 不可见 | 控制字段在业务端是否隐藏 | 启用后，字段在业务端页面中不显示；常用于仅供规则或系统逻辑使用的字段 |
| 输入提示 | 面向业务端用户的填写提示信息 | 用于说明字段填写规则、示例或注意事项，降低误填概率 |
| 值必须唯一 | 控制字段值是否允许重复 | 适用于编号、主数据标识等场景 |
| 在默认列表和悬浮卡中显示 | 控制字段是否默认出现在列表和悬浮卡中 | 启用后，字段会显示在默认列表和悬浮卡中，并自动出现在对象业务端列表视图页面的筛选区域 |
| 复制记录时不复制该字段 | 控制复制记录时是否带出原字段值 | 常用于避免复制敏感值或结果值 |
| 帮助内容 | 面向业务端用户的填写提示 | 多行文本，长度为 0-500 字符 |
| 默认值 | 新建记录时自动带入的初始值 | 支持 `文本`、`数字`、`布尔`、`日期时间`、`选项`、`对象`、`父对象` 和 `状态` 字段；`查找`、`统计`、`公式`、`name&#95;&#95;ak` 及其它系统字段不支持。详见下文“设置字段默认值” |
| 图标 | 为字段值增加图标展示 | 支持设置图标的字段在业务端列表页和详情页显示图标；创建、编辑、复制模式不显示图标，导出时不导出图标。详见下文“字段设置图标” |

- `日期和时间输入约束` 用于 `日期` 和 `日期时间` 字段，控制业务端可选择的时间范围。
- `对象启用树形结构` 用于 `对象` 字段中的自引用场景，使对象记录按层级结构展示和选择。

### 2.4 设置字段默认值

字段默认值用于在业务端创建新记录时，自动为字段预置初始值，减少重复录入，并帮助用户在进入表单时就看到建议值或系统推导值。
- 默认值在字段首次赋值时生效；记录保存后，该字段的值只会随着用户操作或程序更新而变化。
- 默认值支持 `常量` 和 `公式` 两种配置方式。选择 `常量` 时，输入格式需要与字段类型保持一致；选择 `公式` 时，使用方式与公式构造器一致，保存前可先执行验证。
- 当前支持设置默认值的字段类型包括 `文本`、`数字`、`布尔`、`日期时间`、`选项`、`对象`、`父对象`，以及 `状态` 等系统字段。
- `查找`、`统计`、`公式`、`name__ak` 及其它系统字段当前不支持设置默认值。
- 如果同一字段同时存在对象字段级默认值和对象类型字段级默认值，则对象类型字段上的默认值会覆盖对象字段上的默认值。
- 在创建记录过程中，如果字段值经过用户手工输入、创建记录动作更新或公式计算后仍为空，系统才会回退使用静态默认值作为兜底值。

详细规则、交互样式和异常提示，参见 [设置字段默认值(Default Value)](01O_%E8%AE%BE%E7%BD%AE%E5%AD%97%E6%AE%B5%E9%BB%98%E8%AE%A4%E5%80%BC.md)。

### 2.5 引用约束

引用约束用于限制引用字段在业务端可显示、可选择的记录范围，避免用户在对象选择器中看到不符合业务规则的对象记录。
- 适用于 `对象`、`对象多选` 和 `父对象` 字段；配置入口位于字段详情和编辑页中的“约束引用对象中的记录”区域。
- 引用约束分为 `静态引用约束` 和 `动态引用约束`。静态引用约束使用预先设定的固定值筛选可选记录；动态引用约束则根据当前对象记录上的控制字段值，动态限制可选记录范围。
- 在条件编辑模式下，约束由 `条件类型`、`筛选条件字段`、`逻辑运算符`、`逻辑值类型`、`逻辑值` 组成。其中逻辑值类型支持 `当前对象字段` 和 `指定常量`。
- 业务端打开引用选择器时，系统会自动带出已经配置好的约束条件，用户可以看到筛选结果，但不能移除这些强制条件。
- 当前支持高级筛选模式。启用后，条件编辑器会隐藏，改为通过脚本编辑器维护高级筛选表达式；在高级模式下，原有条件编辑器中的条件不再生效。

详细字段、交互和高级模式说明，参见 [引用约束（Reference Constraints）](01P_%E5%BC%95%E7%94%A8%E7%BA%A6%E6%9D%9F.md)。

### 2.6 控制字段

控制字段用于在 `对象` 和 `对象多选` 字段之间建立联动关系。当用户先为控制字段选择值后，被控制的对象字段只显示与该值相关的记录，从而在业务端提供更精确的可选数据范围。
- 控制字段基于 `父子关系` 和 `多对多关系` 生效。本质上，是利用当前对象上已存在的对象字段，去控制另一个对象字段的候选记录集合。
- 创建或编辑 `对象`、`对象多选` 字段时，先选定引用对象，系统会根据当前对象上已有的关系字段，自动提供可作为控制字段的候选项。
- 控制字段对应的对象是当前字段所引用对象的父对象；在多对多场景下，也可以通过中间关系对象实现联动筛选。
- 当前平台最多支持 3 层关系，因此最多支持 2 级级联控制。
- 若某个对象字段已经设置控制字段，但该控制字段没有被放入页面布局，业务端使用时被控制字段可能没有可选值。
- 如果希望配置控制字段，需要先建立父对象字段或相关上游对象字段，再建立被控制的对象字段。

详细示例和适用关系说明，参见 [控制字段(Controlling Field)](01Q_%E6%8E%A7%E5%88%B6%E5%AD%97%E6%AE%B5.md)。

### 2.7 日期和时间输入约束

日期和时间输入约束用于限制 `日期`、`日期时间` 字段在业务端的可选范围，帮助用户只选择符合业务规则的时间值，减少录入错误。
- 输入约束在管理端的字段创建和编辑页中配置，生效后会影响表单编辑、列表行内编辑、工作流发起和任务填写等场景中的日期选择范围。
- 当逻辑运算为空时，业务端不会限制日期时间的可选范围；当逻辑运算为 `介于`、`在过去`、`在未来` 时，系统会按照配置限制可选时间。
- `介于` 需要同时配置开始日期和结束日期；`在过去` 需要配置开始日期；`在未来` 需要配置结束日期。
- 开始日期和结束日期的值类型支持 `变量`、`字段`、`常量`。其中变量可使用当前日期类运行时变量，字段可引用当前对象中的日期字段，变量和字段都支持设置偏移量。
- 偏移量单位支持 `月`、`周`、`天`，适合表达“当前日期后 10 天内”“某日期前 1 周内”这类业务限制。
- 对于 `介于` 规则，保存时系统需要校验开始日期小于等于结束日期；若不满足，系统会提示输入约束配置错误。

详细配置方式、交互和校验说明，参见 [日期和时间输入约束](01R_%E6%97%A5%E6%9C%9F%E5%92%8C%E6%97%B6%E9%97%B4%E8%BE%93%E5%85%A5%E7%BA%A6%E6%9D%9F.md)。

### 2.8 对象启用树形结构

对象启用树形结构用于在 `对象` 字段的自引用场景中，将同一对象下的记录组织成父子层级，并在业务端以树形方式展示和选择。
- 该能力只出现在 `对象` 字段中，且仅当字段引用对象与当前对象是同一个对象时才会出现，也就是自引用场景。
- 一个对象只能基于一个自引用关系启用树形结构；如果系统检测到该对象已经存在启用树形结构的自引用字段，则不能再重复启用。
- 启用树形结构后，该字段属性在创建完成后不能直接修改；如需调整，需要新建新的自引用字段重新配置。
- 启用树形结构后，业务端引用该对象时会按树形选择器展示；若相关列表布局配置为树形展示，则用户会按层级浏览记录。
- 树形结构数据不允许形成环路，用户不能把自己或自己的下级节点选为自己的上级节点；保存时系统会校验并阻止这类数据。
- 树形结构最多支持 5 层；在树形列表场景中，分页按第一层节点计算，搜索和筛选时会切换为平铺模式显示结果。

详细交互、列表展示和选择逻辑，参见 [对象启用树形结构](01S_%E5%AF%B9%E8%B1%A1%E5%90%AF%E7%94%A8%E6%A0%91%E5%BD%A2%E7%BB%93%E6%9E%84.md)。

## 3\. 字段类型参考
> 本章按字段类型说明其用途、页面表现、配置项和使用限制。若某项能力未在本章单独展开，可直接按页面中可见的配置项进行设置。   

### 3.1 文本（Text）

**用途**：用于存储单行文本内容，适合名称、编码、简短说明等场景。   **页面表现**：创建和编辑模式下显示为文本框；查看模式显示为静态文本。   **配置项**：
- 最大长度，最多支持 1500 字符
- 输入格式，可通过正则表达式限制输入
- 错误提示语，失焦和提交时都会校验
- 加密存储，用于按加密方式保存字段值
- 默认值、图标、必填、唯一值

**编辑时可调整**：
- 名称、状态、必填、唯一值、列表显示、复制时不复制
- 最大长度、输入格式、帮助内容、默认值、图标

**使用限制与说明**：
- 支持排序、筛选、条件配置、公式引用、被查找 Lookup
- 不支持引用约束
- 启用加密保存后，系统会以加密方式保存该字段值，适用于需要保护敏感文本内容的字段

- 错误提示语支持多语言

### 3.2 长文本（Long Text）

**用途**：用于存储多行描述性内容，适合备注、说明、详细补充信息。   **页面表现**：表单中以多行文本框显示，查看模式为静态文本。   **配置项**：
- 最大长度，最多支持 32000 字符
- 必填、默认值、列表显示、复制时不复制、图标

- 名称、状态、必填、列表显示、复制时不复制
- 最大长度、帮助内容、默认值、图标

**使用限制与说明**：
- 不支持排序
- 不支持唯一值
- 支持在任务中编辑，也支持在生命周期、工作流和相关动作中修改字段值
- 支持筛选、条件配置、公式引用、被查找 Lookup

### 3.3 富文本（Rich Text）

**用途**：用于存储带格式的文本内容，支持字体、对齐、列表、链接等格式能力。   **页面表现**：表单中显示为富文本编辑器；查看模式保留格式展示。   **配置项**：

**编辑时可调整**：
- 名称、状态、必填、列表显示、复制时不复制
- 最大长度、帮助内容、默认值

**使用限制与说明**：
- 富文本字段默认值不允许添加多媒体资源文件
- 在生命周期动作、工作流中以常量方式修改富文本值时，也不支持设置多媒体资源
- 不支持排序、Lookup、统计、翻译文件名式多语言

### 3.4 数字（Number）

**用途**：用于存储整数或小数，适合数量、金额、分值、计算结果等场景。   **页面表现**：创建和编辑模式下显示为数字输入框；查看模式显示为静态文本。   **配置项**：

### 3.5 日期（Date）

**用途**：用于存储只包含日期的信息，如生效日期、失效日期、计划日期。   **页面表现**：创建和编辑模式下显示为日期选择控件。   **配置项**：

### 3.6 日期时间（DateTime）

**用途**：用于存储包含日期和时间的字段，如计划完成时间、签署时间、触发时间。   **页面表现**：创建和编辑模式下显示为日期时间选择控件；查看、列表等页面展示时会显示时区信息。   **配置项**：
- 输入约束
- 必填、默认值、列表显示、复制时不复制、图标

**编辑时可调整**：
- 名称、状态、必填、列表显示、复制时不复制
- 帮助内容、默认值、输入约束、图标

**使用限制与说明**：
- 支持排序、筛选、条件配置、公式引用、被查找 Lookup、统计字段
- 支持通过输入约束限制业务端可选择的日期时间范围，逻辑运算支持 `介于`、`在过去`、`在未来`
- 输入约束会在表单编辑、列表行内编辑、工作流发起和任务填写时生效

### 3.7 布尔（Boolean）

**用途**：用于表示 `是/否`、`真/假` 这类二值状态。   **页面表现**：可配置为复选框或单项选择器；查看模式显示为静态文本。   **配置项**：
- 显示为复选框
- 必填、默认值、列表显示、复制时不复制、图标

**编辑时可调整**：
- 名称、状态、必填、列表显示、复制时不复制
- 是否显示为复选框、帮助内容、默认值、图标

**使用限制与说明**：
- 支持排序、筛选、条件配置、公式引用、被查找 Lookup、统计字段
- 多语言展示为中文 `是/否`、英文 `Yes/No`

### 3.8 选项（Picklist）

**用途**：用于从标准选项集中选择一个或多个值。   **页面表现**：根据是否允许多选，在表单中显示为单选或多选选择器。   **配置项**：
- 选项集
- 是否允许多选
- 必填、唯一值、默认值、图标

- 依赖关系配置详见 [字段选项依赖(Picklist Dependency)](01N_%E5%AD%97%E6%AE%B5%E9%80%89%E9%A1%B9%E4%BE%9D%E8%B5%96.md)
- 与选项值本身相关的维护详见 [选项集配置](02_%E9%80%89%E9%A1%B9%E9%9B%86%E9%85%8D%E7%BD%AE.md)

### 3.9 对象（Object）

**用途**：用于建立引用关系，在当前对象中选择另一个对象的记录。   **页面表现**：创建和编辑模式下显示为对象选择器；查看模式显示为静态文本。   **配置项**：
- 引用对象
- 启用树形结构（仅自引用时可见）
- 查询规则（引用树形对象并用于查询条件时可配置）
- 控制字段
- 启用关系安全设置
- 允许创建新的记录
- 只有一个可选值时自动填充
- 默认值、唯一值、图标

**编辑时可调整**：
- 名称、状态
- 入站关系名称、删除规则
- 控制字段、允许创建新的记录、唯一值、列表显示、自动填充
- 引用约束、帮助内容、默认值、图标

**使用限制与说明**：
- 创建字段后会自动生成当前对象的出站关系
- 当 `对象` 字段是自引用字段时，可启用树形结构，将对象记录按父子层级管理
- 一个对象只能启用一个树形结构自引用字段；启用后该能力不可直接改回
- 若引用对象启用了树形结构，业务端按树形选择器展示该对象记录；搜索和筛选时改为平铺展示
- 树形结构数据不允许形成环路，用户不能把当前记录或其下级记录选为当前记录的上级节点
- 当 `对象` 字段引用树形对象并用于查询条件时，可配置查询规则控制层级匹配范围。
- `相等`：仅匹配当前选中节点。
- `相等且仅包含子级`：匹配当前节点的直接子级，不包含当前节点。
- `相等且包含所有下级`：匹配当前节点及其全部下级。
- `相等且仅包含父级`：匹配当前节点的直接父级，不包含当前节点。
- `相等且包含所有上级`：匹配当前节点及其全部上级。
- 若需要按部门、文件夹、文件类型等整棵分支检索数据，建议优先使用 `相等且包含所有下级`
- 控制字段适用于父子关系和多对多关系场景，可用于在业务端联动筛选可选记录
- 如果已设置控制字段，业务端需先为控制字段赋值，被控制字段才会显示对应范围内的候选记录
- 平台最多支持 3 层关系，因此控制字段最多支持 2 级级联控制
- 若控制字段未配置到页面布局中，被控制字段可能没有可选值
- 若引用对象启用了树形结构，可配置“只能选择叶子节点”
- 支持通过引用约束限制可选对象记录范围，可使用静态条件、动态条件或高级筛选模式
- 支持筛选、条件配置、公式引用、被查找 Lookup
- 不支持统计字段

### 3.10 对象多选（Object Multi Select）

**用途**：用于在当前对象中一次引用多个目标对象记录，适用于多对多关联、多人协作、标签化关联等场景。   **页面表现**：创建和编辑模式下显示为多选对象选择器；查看模式下显示为多值静态文本。   **配置项**：
- 引用对象（仅支持启用的非大对象）
- 控制字段
- 允许创建新的记录
- 必填
- 在默认列表和悬浮卡中显示
- 复制记录时不复制该字段
- 只有一个可选值时自动填充
- 不可见
- 禁用分面统计
- 启用行内编辑
- 引用约束
- 帮助内容、图标

**编辑时可调整**：
- 名称、状态
- 控制字段、允许创建新的记录、必填、列表显示、自动填充
- 复制时不复制、不可见、禁用分面统计、行内编辑
- 引用约束、帮助内容、图标

**使用限制与说明**：
- 字段用于动态引用多个对象实例，默认最多可选择 `100` 个；可在系统设置中通过“对象(多选)字段选择上限”调整为 `1-1000`
- 不允许引用大对象
- 不支持引出属性（即不支持 `字段(多选) > 属性`）
- 支持通过引用约束限制候选记录范围，也支持通过控制字段联动筛选候选记录
- 当前版本中，当控制字段值变化时，被控制的对象多选字段会清空已选值
- 支持导入与导出多值数据；导出时多值以 `|` 分隔
- 支持列表行内编辑和筛选，不支持排序
- 当前版本不支持默认值、统计字段和被查找 Lookup

### 3.11 父对象（Parent Object）

**用途**：用于建立父子关系，子对象不能脱离父对象独立存在。   **页面表现**：创建和编辑模式下显示为对象选择器；查看模式为静态文本。   **配置项**：
- 引用对象
- 启用关系安全设置
- 允许创建新的记录
- 允许深度复制
- 默认值、唯一值、图标

**编辑时可调整**：
- 名称、状态
- 入站关系名称、删除规则
- 允许创建新的记录、允许深度复制、唯一值
- 列表显示、复制时不复制、引用约束、帮助内容、默认值、图标

**使用限制与说明**：
- 创建字段后会自动生成当前对象的出站关系
- 系统限制父子关系层数不超过 3 层
- 若目标对象已存在三层父子关系，字段不允许保存
- 支持通过引用约束限制父对象可选记录范围，可使用静态条件、动态条件或高级筛选模式
- 支持筛选、条件配置、公式引用、被查找 Lookup

### 3.12 查找（Lookup）

**用途**：用于将父对象或引用对象上的字段值同步到当前对象，作为只读显示字段使用。   **页面表现**：创建、编辑、查看模式下均表现为静态文本，不支持手工录入。   **配置项**：
- 查找关系，只能从当前对象的出站关系中选择
- 查找源字段
- 图标、帮助内容

**编辑时可调整**：
- 名称、状态、列表显示
- 帮助内容、图标

**使用限制与说明**：
- Lookup 字段不可编辑，字段值异步更新
- 不支持公式字段再次引用，也不支持互相 Lookup
- 关系限制包括： 
    - 一个对象最多 5 条查找关系
    - 每条关系最多 8 个查找字段
    - 一个源对象最多被 8 条查找关系引用
- 是否支持排序和筛选，取决于查找返回值类型

### 3.13 统计（Statistics）

**用途**：用于在一对多关系中，从“一”的对象上统计“多”的对象数据。   **页面表现**：页面中显示为静态文本结果。   **配置项**：
- 统计来源关系
- 统计方式：`COUNT / SUM / AVG / MAX / MIN`
- 统计字段
- 统计范围
- 返回值格式，例如小数位数、最大值、最小值、处理结果方式

**编辑时可调整**：
- 名称、状态
- 统计范围、最大值、最小值、小数位数
- 处理结果方式、日期格式、帮助内容

**使用限制与说明**：
- 一个对象最多创建 10 个统计字段
- 统计字段有延时，不适合依赖“即时刷新”的页面场景
- 支持统计附件字段上传的附件个数
- 支持被统计 Lookup 字段，但不支持在公式字段中继续引用
- 新建、修改或迁移统计字段后，会触发数据初始化

### 3.14 公式（Formula）

**用途**：用于根据字段、常量和变量表达式计算结果值。   **页面表现**：为只读结果字段。   **配置项**：
- 返回类型
- 公式表达式
- 提示文字

**编辑时可调整**：
- 公式表达式及相关提示信息

**使用限制与说明**：
- 不支持再被公式字段引用
- 不支持被查找 Lookup
- 不支持排序，但支持筛选和条件配置
- 支持通过图标函数返回图标结果，适合在列表和详情中展示状态、提醒或趋势标识
- 图标公式使用 `Icon(code, color, [width], [text])` 形式，其中 `code` 为图标编码，`color` 为颜色值，`width` 为可选尺寸，`text` 为可选替代文本
- 在公式编辑器中既可以手工输入图标函数，也可以通过图标选择器生成对应表达式；未显式配置时，图标尺寸和替代文本会使用系统默认值
- 公式语法、函数和编辑器使用详见 [公式配置](06_%E5%85%AC%E5%BC%8F%E9%85%8D%E7%BD%AE.md)
- 图标函数的参数规则、默认值和选择方式详见 [公式配置](06_%E5%85%AC%E5%BC%8F%E9%85%8D%E7%BD%AE.md)

### 3.15 附件（Attachment）

**用途**：用于在记录上上传一个或多个附件文件，并支持预览与下载。   **页面表现**：表单中显示为附件控件；支持上传、预览、下载和下载全部。   **配置项**：

- 数量限制、大小限制、格式限制、帮助内容、导出数据格式、图标

**使用限制与说明**：
- 不支持默认值
- 不支持公式、Lookup、统计、多语言翻译文件名
- 支持审计追踪
- 支持在生命周期进入动作、事件动作和工作流动作节点中修改值

### 3.16 组件（Component）

**用途**：用于承载复合型界面内容或组合展示能力。当前版本中保留该字段类型入口，但可配置能力仍需以实际界面为准。   **当前已确认信息**：
- 当前版本中已预留与条件筛选、过滤、默认值、图标等相关能力入口
- 具体支持范围、创建属性和编辑规则请以当前环境中的实际配置项为准

**使用建议**：
- 如需在正式业务场景中使用组件字段，建议先在测试环境完成完整验证，再推广到正式配置
