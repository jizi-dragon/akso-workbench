# 文档工作流

文档工作流用于对文档记录执行审批与状态流转，支持按文档生命周期配置起始条件、任务处理与状态控制。

---

## 8\. 文档工作流

### 8.1 文档工作流特点

文档工作流专门用于文档对象的审批流程，具有以下特点：

| 特性 | 说明 |
|------|------|
| **生命周期** | 单个文档生命周期或所有文档生命周期 |
| **创建草稿时保持在当前版本** | 允许"创建草稿"操作增加版本号，而工作流仍然使用在以前的主要文档版本上 |
| **签批表显示** | 支持在签批表上显示电子签名 |
| **状态类型控制** | 所有文档生命周期支持通过状态类型控制流程 |

### 8.2 文档工作流与对象工作流对比

| 模块 | 文档工作流 | 对象工作流 |
|------|---------------|---------------|
| **生命周期** | 单个文档生命周期 | 单个对象生命周期 |
| **开始节点-字段控件** | 支持当前文档的文档类型下的所有字段 | 支持当前对象的所有字段（排除 lookup） |
| **任务节点-任务分配模式** | 无（默认系统指派） | 系统指派/任务领取 |
| **动作节点-修改状态** | 修改状态 | 修改状态 |
| **判断节点-条件类型** | 任务、字段、变量、状态 | 任务、字段、变量、状态 |

### 8.3 文档工作流特殊配置

**创建草稿时保持在当前版本**：
- 勾选后，当文档存在活跃的工作流时，文档升版后，活跃工作流关联的文档会自动变成最新的版本
- 未勾选时，当文档存在活跃的工作流时，文档升版后，活跃工作流关联的文档还是发起时的版本
- 该选项仅在工作流**未启用**时可修改；工作流启用后不可再更改（不能反复打开和关闭）

**签批表显示电子签名**：
- 在任务节点中勾选【在签批表上显示电子签名】
- 审批意见内的电子签名只会针对当前审批意见生效
- 如果在审批意见外设置了电子签名，则表示所有的审批意见都需要电子签名
