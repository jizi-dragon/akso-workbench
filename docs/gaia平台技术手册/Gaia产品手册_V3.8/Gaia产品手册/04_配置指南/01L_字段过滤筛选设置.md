# 字段过滤筛选设置
> 本文说明如何配置字段在业务端的筛选运算符和输入控件，帮助用户在列表、视图、搜索场景中更准确地过滤数据。   

---

## 概述

字段过滤筛选设置（Filter Rule）用于定义“某个字段在业务端可用哪些筛选运算符，以及对应如何输入筛选值”。

配置完成后，业务用户在查询时看到的筛选项将按该规则生效，包括：
- 可选运算符（如 `等于`、`大于`、`介于`、`为空`）
- 值输入方式（如数字输入框、日期控件、下拉多选、对象选择器）

该配置只影响筛选行为，不改变字段本身的数据存储。

## 生效范围
- 对象记录列表筛选
- 视图筛选
- 搜索条件筛选
- 其他基于字段条件的业务端查询场景

## 支持作为筛选条件的字段类型

以下字段类型可作为业务端筛选条件：
- 日期
- 日期时间
- 数字
- 对象
- 父对象
- 对象（多选）
- 选项
- 附件
- 富文本
- 长文本

补充说明：
- 支持来源为 `系统`、`标准`、`自定义` 的字段。
- 部分 `组件` 类型字段也可用于筛选，例如文档类型、状态等。
- 公式字段（不含返回类型为图标）、Lookup 字段、统计字段，按其返回类型决定支持的运算符和输入控件。
- 在业务端过滤条件中，`选项`、`对象类型`、`生命周期状态` 字段仅支持 `聚类筛选` 模式。
- `对象`、`父对象`、`对象（多选）` 字段支持按聚类方式显示候选值；只有在受限查询场景下，页面才显示对应过滤条件。

---

## 各字段类型的筛选规则

## 1\. 数字字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `等于 (equals)` | 数字输入框 | 要求字段值与输入值完全相等。精度参与比较，`1` 与 `1.0` 不视为相等。 |
| `不等于 (is not equal to)` | 数字输入框 | 与 `等于` 相反。 |
| `大于 (is greater than)` | 数字输入框 | 匹配字段值大于输入值的记录。 |
| `大于等于 (is greater than or equal to)` | 数字输入框 | 匹配字段值大于或等于输入值的记录。 |
| `小于 (is less than)` | 数字输入框 | 匹配字段值小于输入值的记录。 |
| `小于等于 (is less than or equal to)` | 数字输入框 | 匹配字段值小于或等于输入值的记录。 |
| `介于 (between)` | 数字范围输入框 | 输入起始值与结束值，且结束值需大于等于起始值；匹配区间包含边界值。 |
| `为空 (is blank)` | 无 | 匹配 `Null` 或空值。 |
| `不为空 (is not blank)` | 无 | 与 `为空` 相反。 |

## 2\. 选项 / 对象类型 / 生命周期状态字段
- `选项`、`对象类型`、`生命周期状态` 字段在业务端筛选器中支持 `聚类筛选` 模式。

## 3\. 日期 / 日期时间字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `等于 (equals)` | 日期选择控件 | 按字段日期格式精度比较；日期时间按用户所在时区计算。 |
| `不等于 (is not equal to)` | 日期选择控件 | 与 `等于` 相反；同样按精度与时区比较。 |
| `大于 (is greater than)` | 日期选择控件 | 匹配晚于输入时间的记录。 |
| `大于等于 (is greater than or equal to)` | 日期选择控件 | 匹配晚于或等于输入时间的记录。 |
| `小于 (is less than)` | 日期选择控件 | 匹配早于输入时间的记录。 |
| `小于等于 (is less than or equal to)` | 日期选择控件 | 匹配早于或等于输入时间的记录。 |
| `最近 (is in the last)` | 数字输入框 \+ 单位选择（天/周/月/年） | 匹配最近一段时间内的数据。 |
| `在未来 (is in the next)` | 数字输入框 \+ 单位选择（天/周/月/年） | 匹配未来一段时间内的数据。 |
| `处于接下来的 (is not in the last)` | 数字输入框 \+ 单位选择（天/周/月/年） | 表示不在最近区间内，通常包含更早时间或未来时间。 |
| `介于 (between)` | 日期范围控件 | 输入开始和结束时间，按区间匹配（含边界）。 |
| `为空 (is blank)` | 无 | 匹配 `Null` 或空值。 |
| `不为空 (is not blank)` | 无 | 与 `为空` 相反。 |

## 4\. 布尔字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `等于 (equals)` | 下拉选项（单选） | 匹配 `是/否`（或 `true/false`）值。 |
| `不等于 (is not equal to)` | 下拉选项（单选） | 与 `等于` 相反。 |
| `为空 (is blank)` | 无 | 匹配 `Null` 或空值。 |
| `不为空 (is not blank)` | 无 | 与 `为空` 相反。 |

## 5\. 附件字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `为空 (is blank)` | 无 | 匹配未上传附件的记录。 |
| `不为空 (is not blank)` | 无 | 匹配已上传附件的记录。 |

## 6\. 对象 / 父对象 / 对象（多选）字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `等于 (equals)` | 对象选择器（单选） | 匹配引用该对象记录的结果。 |
| `不等于 (is not equal to)` | 对象选择器（单选） | 与 `等于` 相反。 |
| `包含 (includes)` | 对象选择器（多选） | 匹配引用值包含任一所选对象记录的结果。 |
| `为空 (is blank)` | 无 | 匹配未引用对象记录的数据。 |
| `不为空 (is not blank)` | 无 | 匹配已引用对象记录的数据。 |

补充说明：
- 以上字段在业务端筛选器中支持聚类展示，便于按分组快速定位候选对象。
- 若当前查询不属于受限查询场景，则不展示该类过滤条件。

## 7\. 富文本 / 长文本字段

| 运算符 | 输入控件 | 说明 |
|---------|------------|------|
| `为空 (is blank)` | 无 | 匹配 `Null` 或空值。 |
| `不为空 (is not blank)` | 无 | 与 `为空` 相反。 |

---

## 注意事项
- 不同字段类型的运算符能力不同，切换字段类型后应重新检查筛选配置。
- `between` 场景建议明确业务上的边界是否应包含起止值。
- 若筛选结果明显偏少或偏多，优先排查运算符语义是否选错（如 `等于` 与 `包含`）。
