# 生命周期阶段组配置
> 本指南说明如何在 Gaia 平台中配置生命周期阶段组，用于在业务端展示对象或文档记录的阶段进度。 
生命周期阶段组用于可视化表达流程进展，不用于承载工作流条件、进入条件或其他业务规则。   

---

## 概述

生命周期阶段组用于把生命周期状态按业务阶段进行分组，并按顺序展示给业务用户。 
配置完成后，业务端可以看到“当前处于哪个阶段、哪些阶段已完成、下一阶段是什么”。

当用户在记录详情页点击当前活动阶段时，系统会展示该记录关联的工作流信息（包括打开中的任务），便于追踪执行进展。

---

## 适用场景

| 场景 | 配置价值 |
|------|------------|
| 对象或文档审批链条较长 | 让业务用户快速理解当前进度与下一步 |
| 同一生命周期含多个业务里程碑 | 把状态聚合为更易理解的阶段 |
| 需要在详情页展示阶段轨迹 | 提供统一的阶段可视化视图 |

---

## 配置边界

生命周期阶段组只负责“展示阶段”，不直接驱动流程逻辑。建议遵循以下边界：
- 工作流触发与流转条件：在 [工作流配置](05_%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%85%8D%E7%BD%AE.md) 中维护
- 生命周期状态与转换：在 [对象生命周期配置](04_%E5%AF%B9%E8%B1%A1%E7%94%9F%E5%91%BD%E5%91%A8%E6%9C%9F%E9%85%8D%E7%BD%AE.md) 或 [文档生命周期配置（多生命周期）](04B_%E6%96%87%E6%A1%A3%E7%94%9F%E5%91%BD%E5%91%A8%E6%9C%9F%E9%85%8D%E7%BD%AE.md) 中维护
- 生命周期阶段组：仅负责“阶段分组 \+ 展示顺序 \+ 状态归属”

---

## 前提条件
- 您具备系统管理员或配置管理员权限
- 已完成生命周期及状态定义
- 已明确该对象类型需要展示的阶段里程碑
- 已在目标对象上开启 **生命周期阶段** 开关

---

## 访问路径
1. 进入 **管理端** → **配置管理**
2. 在左侧导航进入 **业务逻辑** → **对象生命周期阶段组**
3. 打开生命周期阶段组列表页

---

## 查看阶段组列表

列表页用于查询、定位和进入生命周期阶段组配置。

### 列表特征
- 默认按创建时间倒序展示
- 固定行高显示
- 支持分页浏览

### 筛选器说明

| 筛选器 | 类型 | 说明 |
|---------|------|------|
| **对象生命周期** | 单选选择器 | 可选“全部生命周期”或具体生命周期（含文档生命周期）；选择后立即查询；支持输入关键词搜索选项 |
| **关键词** | 文本（0-200） | 匹配阶段组名称；留空表示查询全部 |

多个筛选器可同时生效，按组合条件返回结果。

### 权限说明

如无特殊配置，该页面权限受“权限集 → 管理端 → 生命周期阶段组”控制。

---

## 创建生命周期阶段组

### 新建步骤
1. 在阶段组列表点击【创建】
2. 填写详情信息
3. 保存后进入阶段组详情页
4. 在阶段组下继续新增阶段并维护顺序

### 详情字段说明

| 字段 | 说明 | 规则 |
|------|------|------|
| **名称** | 阶段组名称 | 必填，需唯一，仅用于管理员配置识别 |
| **Code** | 阶段组系统标识 | 必填，需唯一 |
| **对象生命周期** | 关联生命周期 | 必选，单选，来源于系统中可用生命周期 |
| **对象类型** | 生命周期对应对象的对象类型 | 必选，单选；同一对象类型只能绑定一个阶段组 |
| **状态** | 阶段组启停状态 | 默认启用，可选“启用/停用” |
| **来源** | 配置来源 | 手动创建时为“自定义” |
| **描述** | 阶段组说明 | 选填，建议写明适用范围和维护责任 |

### 阶段管理
- 一个阶段组可包含多个阶段
- 阶段将直接展示在业务端记录详情页
- 阶段显示顺序按阶段列表从上到下排列
- 可点击【排序】后拖拽调整阶段顺序

---

## 创建生命周期阶段

阶段用于承载具体状态集合。一个阶段可以关联多个生命周期状态。

### 新建步骤
1. 在目标阶段组中点击【创建阶段】
2. 填写阶段详情信息
3. 保存后添加或移除关联状态
4. 按业务顺序调整阶段位置

### 阶段字段说明

| 字段 | 说明 | 规则 |
|------|------|------|
| **名称** | 阶段名称 | 必填，在同一阶段组内唯一；会展示给业务用户 |
| **Code** | 阶段系统标识 | 必填，在同一阶段组内唯一 |
| **状态** | 阶段启停状态 | 默认启用，可选“启用/停用” |
| **来源** | 配置来源 | 手动创建时为“自定义” |
| **描述** | 阶段说明 | 选填 |

### 状态归属规则
- 当前阶段可关联多个生命周期状态
- 同一个生命周期状态只能归属于一个阶段
- 调整状态归属后，业务端阶段展示会按新归属即时更新

---

## 业务端效果

配置生效后，在对象或文档记录详情页可看到阶段进度展示：
- 已完成阶段：显示为已完成
- 当前阶段：显示为活动状态
- 未到达阶段：显示为待执行

点击当前活动阶段，可查看该记录关联的工作流信息与打开任务，便于业务追踪。

---

## 生命周期阶段系统字段

对于已配置生命周期阶段组且已在对象上开启 **生命周期阶段** 开关的对象，系统会提供系统字段 **生命周期阶段**（Code：`stage__sys`），用于表示当前记录所属的阶段。

该字段可直接用于读取记录当前处于哪个业务阶段，也可在需要判断阶段的配置场景中作为条件字段使用。

### 创建前提

`生命周期阶段` 不是默认创建的系统字段。只有在对象配置中勾选 **生命周期阶段** 开关后，系统才会为该对象创建 `stage__sys` 字段。

如果对象未开启该开关，即使已经配置生命周期阶段组，记录上也不会生成 `生命周期阶段` 系统字段。

### 字段规则

| 项目 | 说明 |
|------|------|
| **字段名称** | 生命周期阶段 |
| **Code** | `stage&#95;&#95;sys` |
| **字段类型** | 系统字段 |
| **适用范围** | 对象 |
| **取值来源** | 当前对象所关联生命周期阶段组中的全部阶段 |
| **去重规则** | 若阶段组中存在同名阶段，字段可选值按阶段名称去重 |

### 使用说明
- 需要先在对象上开启 **生命周期阶段** 开关，系统字段才会创建并参与后续配置。
- 该字段的可选值来源于对象对应的生命周期阶段组，而不是直接来源于生命周期状态。
- 当业务规则需要判断“记录当前处于哪个阶段”时，优先使用 **生命周期阶段**，避免直接按底层状态名称逐个判断。
- 该字段可用于各类条件判断场景，例如规则条件、流程条件、筛选条件等。

---

## 配置建议
1. 先定“阶段里程碑”，再做状态归类，避免阶段含义频繁调整。
2. 阶段数量保持适中（建议 3-7 个），过多会降低可读性。
3. 阶段命名使用业务语言，避免技术术语。
4. 阶段顺序调整后，建议回归验证业务端展示与流程认知是否一致。
5. 如果后续需要按阶段驱动查询、规则或流程判断，建议先统一阶段命名，再配置生命周期阶段组，减少条件维护成本。
