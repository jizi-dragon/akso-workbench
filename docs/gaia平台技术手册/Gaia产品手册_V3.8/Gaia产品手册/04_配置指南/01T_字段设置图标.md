# 字段设置图标
> 本文说明如何为字段值配置图标显示，帮助用户在列表和详情中更直观地识别记录状态。   

---

## 概述

字段设置图标用于为字段值增加前置图标显示。配置完成后，用户在列表、卡片或详情页中查看字段值时，可以通过图标更快识别状态、提醒或类型信息。

## 适用范围
- 所有字段类型
- 列表和详情展示场景

## 配置说明
- 图标通常与字段值一起展示，不改变字段本身的数据存储结果。
- 所有字段类型均支持设置图标。
- 图标可用于状态标识、风险提醒、趋势提示等场景。
- 对于公式字段，可通过图标函数动态返回图标结果。
- 若未配置图标，字段仍按普通文本或数值方式显示。

## 设置方式

字段设置图标支持以下三种方式：

| 方式 | 说明 | 适用场景 |
|------|------|------------|
| `指定图标` | 直接为当前字段配置一个固定图标 | 字段图标长期不变的场景，如固定类型标识 |
| `指定字段` | 使用当前对象中的其他字段值决定图标显示结果 | 需要随某个状态字段联动展示图标的场景 |
| `指定公式` | 使用公式表达式计算并返回图标结果 | 需要根据多条件动态判断图标的场景 |

如果业务规则简单且稳定，优先使用 `指定图标`；如果需要根据数据变化自动切换图标，优先使用 `指定字段` 或 `指定公式`。

## 图标显示位置

图标会显示在字段值的最开始位置（前置显示），再显示字段文本内容。

## 公式设置图标函数（Icon）

在 `指定公式` 模式下，可使用 `Icon()` 函数返回图标结果。

### 用法

`Icon(Name,Color[,Size][,Text])`

### 描述

返回图标 `Name`，图标颜色为 `Color`，大小为 `Size`，描述文本为 `Text`。

### 参数类型

| 参数 | 类型 | 说明 |
|------|------|------|
| `Name` | 图标名 | 必填，指定图标名称 |
| `Color` | 文本 | 必填，使用 RGB 十六进制格式（如 `#FF0000`） |
| `Size` | 数字 | 可选，支持 `12~100`，单位 `px`，默认 `12` |
| `Text` | 文本 | 可选，图标描述文本 |

### 返回类型

`图标`

### 示例
```formula
Icon("感叹号","#FF0000")
```

上例返回一个红色“感叹号”图标。

## 使用建议
- 为高频查看、需要快速识别状态的字段优先配置图标。
- 图标表达应保持简洁，避免同一页面使用过多不同语义的图标。
- 若图标由公式动态生成，建议同时配置可读文本，方便用户理解。
