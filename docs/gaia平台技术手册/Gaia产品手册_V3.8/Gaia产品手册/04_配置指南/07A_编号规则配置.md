\# 编号规则配置
> 本文介绍如何在 Gaia 平台配置业务编号规则，包括编号段类型、流水号设置、编号依据及与对象、生命周期的集成使用。   

---

## 概述

业务数据通常需要唯一且易于识别的编号。编号规则用于根据既定规则自动生成编号；同一对象的同一类数据可使用相同规则，不同对象或不同类别的数据可分别配置不同规则。

**访问路径：** 配置环境 \> 配置管理 \> 对象管理 \> 编号规则

---

## 编号规则管理

### 编号规则列表

编号规则列表分页展示系统中所有编号规则，默认按创建时间倒序排列。

进入编号规则页面后，可查看系统中已有的编号规则，按名称进入详情页，并通过操作菜单执行编辑和启用、停用操作。

**页面常用入口：**

| 页面元素 | 作用 |
|------------|------|
| 页面标题 | 当前页面标题为 `编号规则` |
| 查询输入框 | 输入查询条件，按名称查找目标编号规则 |
| 查询按钮 | 执行查询 |
| 分页区 | 查看当前页码、总记录数，并切换页码 |
| 每页条数 | 设置每页显示的记录数量 |
| 跳页 | 输入页码后快速跳转到指定页面 |
| `创建` | 新建编号规则 |
| 名称 | 点击名称进入对应编号规则详情页 |
| 操作列 | 点击齿轮按钮打开当前编号规则的操作菜单 |

**显示列：**

| 列 | 说明 |
|---|------|
| **名称** | 规则名称 |
| **Code** | code |
| **对象** | 编号规则服务对象 |
| **状态** | 当前规则状态，包括 `启用` 和 `停用` |
| **使用位置** | 编号使用位置，如 `name&#95;&#95;ak` 字段、生命周期进入动作；规则被使用后自动记录 |
| **操作** | 通过齿轮按钮打开操作菜单 |

**列表操作规则：**
- `编辑`：进入当前规则的编辑页
- `停用`：仅启用状态下显示；停用后规则不可继续被使用，已使用的规则不允许停用
- `启用`：仅停用状态下显示；启用后规则才能重新被选择和使用

## 创建编号规则

进入 `配置环境 > 配置管理 > 对象管理 > 编号规则` 后，点击右上角的 `创建`，进入创建编号规则页面。

### 创建页结构与按钮

创建页顶部显示面包屑 `规则列表 > 创建`，用于帮助用户确认当前正在新增编号规则。

页面顶部提供以下按钮和区域：

| 页面元素 | 作用 |
|------------|------|
| 面包屑导航 | 显示当前路径，并支持返回规则列表上下文 |
| `返回` | 放弃本次创建并返回编号规则列表页 |
| `保存` | 保存当前编号规则配置 |
| `详情` | 维护编号规则基础信息 |

### 创建页核心属性

在 `详情` 区域中填写基础信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| **名称** | 1-200 字符，唯一 | ✓ |
| **Code** | 输入编码主体后，系统自动拼接完整编号规则编码；编码唯一 | ✓ |
| **对象** | 选择服务对象，一个对象可创建多个规则 | ✓ |
| **状态** | 启用/停用，默认启用 | ✓ |
| **描述** | 0-500 字符 | ✗ |

完成基础信息后，继续配置编号段（见下文），再点击 `保存`。

## 编号段类型

编号规则由流水号、固定字符、日期、字段、相关对象字段等编号段组成。

### 流水号

自增长编号，可设定起始值和递增步幅。

| 字段 | 说明 | 默认值 |
|------|------|---------|
| **位数** | 流水号位数，1-10 位 | 8 |
| **起始值** | 取值范围：0 至设置位数的最大值 | 1 |
| **步长** | 递增间隔值 | 1 |

一个编号规则只能添加一个流水号，编号按十进制增长。

### 固定字符

固定不变的字符，用于编号前缀或后缀。最大长度 10，支持中文、英文和符号。当前支持的常用符号包括：
- `-`
- `_`
- `.`
- `@`
- `?`
- `%`
- `+`
- `=`
- `<`
- `>`
- `/`
- `\`
- `&`

### 日期

按设定格式生成编号。

| 格式 | 说明 | 示例 |
|------|------|------|
| YYYYMMDD | 4位年\+2位月\+2位日 | 20230420 |
| YYYYMM | 4位年\+2位月 | 202304 |
| YYYY | 4位年 | 2023 |
| MM | 2位月 | 04 |
| YY | 2位年后两位 | 23 |

### 对象字段

支持将对象字段值作为编号段。支持字段类型：文本、数字、选项（取 Code）、对象类型（取 Code）、日期、日期时间、状态、公式（返回类型为文本、数字、选项）。

### 相关对象字段

支持将父对象或引用对象的字段值作为编号段，字段选取规则与对象字段一致。当字段类型为日期或日期时间时，需设置格式。

### 关联文档字段

支持以基于文件关系的关联文档字段作为编号段。仅对象为文档时才有此类型，当前仅支持关系数量为 1 的关系类型。

### 添加、排序和删除编号段

编号规则中的每个编号段都需要先选择类型，再完成主体内容配置。主体内容未配置完成时，保存编号规则会提示输入校验信息。
- 添加编号段：点击添加编号段按钮，选择需要的编号段类型
- 排序编号段：拖动编号段顺序，系统按排序后的顺序拼接最终编号
- 删除编号段：点击当前编号段的删除按钮，移除该编号段

### 编号预览

编号段配置区下方会显示编号预览。预览用于帮助配置人员确认编号组成方式，以及重置依据是否配置正确。

| 编号段类型 | 预览规则 |
|---------------|------------|
| 流水号 | 起始值加占位符 `0` |
| 固定字符 | 按输入的固定字符显示 |
| 日期 | 按所选日期格式显示 |
| 对象字段 | 按 `{字段Code}` 显示 |
| 相关对象字段 | 按 `{对象字段Code.字段Code}` 显示 |

## 编号依据（重置依据）

日期、对象字段、相关对象字段可设置为编号依据。设置为编号依据后，流水号会根据所选依据的值不同重新生成新的流水号序列。

| 选项 | 说明 |
|------|------|
| **仅显示** | 只作为编号的构成部分显示 |
| **显示且设为重置依据** | 在编号中显示，且作为流水号重置依据 |
| **仅设为重置依据** | 不在编号中显示，仅作为流水号重置依据 |
> \[!NOTE\]
公式类型字段不能作为重置依据。   

#### 按业务单元管理流水号

当编号段类型为「对象字段」或「相关对象字段」，所选字段属于**业务单元**对象，且该编号段已设为重置依据（「显示且设为重置依据」或「仅设为重置依据」）时，编号段区域会显示「按业务单元管理流水号」开关。

| 属性 | 说明 |
|------|------|
| 默认状态 | 不勾选 |
| 勾选后 | 保存编号规则后，业务编号流水号设置按业务单元隔离管理（见下文） |
| 与重置依据联动 | 编号段取消重置依据时，开关自动关闭并隐藏；重新设为重置依据后开关再次显示（默认不勾选） |
| 多编号段 | 仅对业务单元类型的重置依据字段生效；多个业务单元重置依据可各自独立开关 |

未启用该开关的编号规则，流水号设置行为与原有逻辑一致（不新增业务单元列、不按业务单元过滤）。关闭开关后，已创建的流水号设置记录保留不删除，列表恢复原有展示方式。

## 编辑与删除编号规则

### 编辑编号规则

可通过以下方式进入编辑模式：
- 在编号规则列表页点击操作列中的 `编辑`
- 点击规则名称进入详情页后，再点击 `编辑`

### 编辑页结构与按钮

编辑页顶部显示面包屑 `规则列表 > {编号规则名称}`，用于帮助用户确认当前正在编辑哪一条编号规则。

页面顶部提供以下按钮和区域：

| 页面元素 | 作用 |
|------------|------|
| 面包屑导航 | 显示当前路径，并支持返回规则列表上下文 |
| `取消` | 放弃当前未保存的修改并返回上一页面 |
| `保存` | 保存当前编号规则修改 |
| `详情` | 维护编号规则基础信息 |
| `编号规则` | 维护编号段、重置依据和编号预览 |

### 编辑页可维护内容

编辑页中可维护以下内容：
- 名称
- 状态
- 描述
- 编号段配置

### 编辑页中的编号段维护

在 `编号规则` 区域中，可继续维护当前规则的编号段：
- 新增编号段：点击 `添加规则`
- 调整顺序：拖动编号段左侧排序手柄
- 删除编号段：点击当前编号段右侧删除按钮
- 查看预览：在编号段配置区下方查看 `预览`

保存前，应确保每个编号段的主体内容已填写完成。

### 删除编号规则

删除前，系统会检查该编号规则是否已被使用。已被使用的编号规则不允许删除，并提示 `此编号规则正在使用，不能删除。`

## 编号流水号设置

**访问路径：**`配置环境 > 运维管理 > 业务编号监控 > 业务编号流水号设置`

用于设置不同属性业务数据下的流水号起始值。仅当编号规则设置了流水号重置依据时，才可创建流水号设置。

### 编号流水号设置列表

编号流水号设置列表页用于集中维护已经创建的流水号起始值。页面支持按关键字查询，也支持通过分页浏览全部设置。右上角的 `创建` 用于新增一条流水号设置，`批量导入` 用于一次性导入多条流水号起始值。

列表中会展示标签、流水号起始值、编号规则、创建时间、状态和是否使用，方便配置人员快速判断某条设置对应的是哪组重置依据、当前从哪个号码开始，以及这条设置是否已经被实际使用。

其中：
- `标签` 用于展示当前流水号设置对应的重置依据值
- `状态` 用于控制这条流水号设置是否生效
- `是否使用` 用于标识这条流水号设置是否已经被实际使用过

当对应编号规则启用了「按业务单元管理流水号」后：
- 列表新增 `业务单元` 列（位于名称/标签相关列之后）
- 右上角业务单元选择为**特定业务单元**时，列表仅显示该业务单元下的流水号设置
- 右上角选择为**全局**时，显示所有业务单元的流水号设置

每条记录的操作集中在操作菜单中：
- `编辑`：修改当前流水号设置的内容
- `启用` 或 `停用`：按当前状态切换这条设置是否生效

只有启用状态的流水号设置才会参与编号生成。

### 批量导入流水号设置

如果需要一次性补入多条流水号初始值，可以使用列表页右上角的 `批量导入`。

导入时，先选择编号规则，再下载 Excel 模板并按模板填写数据，最后上传填写完成的 `.xlsx` 文件并点击 `导入`。系统会按当前模板内容批量创建业务编号流水号设置。

当编号规则启用了「按业务单元管理流水号」时，导入同样受业务单元隔离约束：
- 模板中业务单元重置依据字段预填充当前用户所属业务单元对应值
- 导入行中该字段值必须属于当前用户所属业务单元，否则该行导入失败
- 右上角选择「全局」时，仍以当前用户实际所属业务单元为校验基准，不能为其他业务单元导入

上传文件时需要满足以下限制：
- 仅支持 `.xlsx` 格式
- Excel 中不能存在合并单元格
- 文件大小不能超过 5MB
- 行数不能超过 2000 行
- 列数不能超过 200 列

详细步骤见 [07B\_业务编号流水号批量导入.md](07B_%E4%B8%9A%E5%8A%A1%E7%BC%96%E5%8F%B7%E6%B5%81%E6%B0%B4%E5%8F%B7%E6%89%B9%E9%87%8F%E5%AF%BC%E5%85%A5.md)。

### 创建流水号设置

从流水号设置列表页点击右上角的 `创建` 后，可以新增一条业务编号流水号设置。页面右上角提供 `返回` 和 `保存` 两个操作：
- `返回`：放弃本次创建并返回流水号设置列表页
- `保存`：保存当前填写的流水号设置

创建页需要依次完成以下内容：
- `编号规则`：选择当前流水号设置对应的编号规则
- `状态`：设置这条流水号设置是否立即生效
- `流水号起始值`：填写该规则下的起始流水号

当编号规则启用了「按业务单元管理流水号」时：
- 业务单元重置依据字段自动填充当前用户所属业务单元在该字段上的值，且不可修改
- 不允许为其他业务单元创建流水号设置；否则保存失败并提示不能为其他业务单元创建
- 右上角选择「全局」时，仍自动填充当前用户实际所属业务单元对应值（不填充“全局”）
- 若当前用户不属于任何业务单元且处于全局视角，业务单元重置依据字段不自动填充，需手动选择有效业务单元值

页面下方的 `预览` 会根据当前选择的编号规则和输入的流水号起始值实时展示编号效果，便于保存前确认结果。

保存时，流水号起始值需要满足当前编号规则的编号位数要求；如果该编号规则配置了重置依据，相关依据字段的组合仍需保持唯一。

### 编辑流水号设置

从流水号设置列表页的操作菜单中点击 `编辑` 后，可以进入当前流水号设置的编辑页面。页面右上角提供 `返回` 和 `保存` 两个操作：
- `返回`：放弃当前未保存的修改并返回流水号设置列表页
- `保存`：保存当前修改后的流水号设置

编辑页中的 `编号规则` 为只读显示，用于帮助配置人员确认当前正在维护的是哪一条规则下的流水号设置，不能在编辑时改成其它编号规则。

当前页面可调整的内容主要包括：
- `状态`：控制这条流水号设置是否启用
- `流水号起始值`：重新设置当前流水号的起始号码

当编号规则启用了「按业务单元管理流水号」时，业务单元重置依据字段在编辑时同样不可修改，保存时仍校验业务单元归属。非本业务单元的流水号设置不可被其他业务单元用户调整。

页面下方的 `预览` 会根据当前输入的起始值实时展示编号效果，便于保存前确认设置结果。

保存校验与创建时一致。如果当前流水号设置带有重置依据，相关依据字段的组合仍然必须保持唯一。

### 权限与 FAQ

本能力复用现有权限，不新增独立权限项：

| 功能 | 权限 |
|------|------|
| 创建/编辑编号规则 | 管理端 \> 编号规则 \> 创建/编辑 |
| 查看编号流水号设置 | 业务端 \> 编号流水号设置 \> 查看 |
| 创建/编辑编号流水号设置 | 业务端 \> 编号流水号设置 \> 创建/编辑 |
| 批量导入 | 与创建权限相同 |

**Q：为什么看不到「按业务单元管理流水号」开关？**   A：仅当编号段为对象字段或相关对象字段、字段属于业务单元对象、且该段已设为重置依据时才显示。

**Q：全局视角下能否为其他业务单元创建设置？**   A：不能。创建与导入仍绑定当前用户实际所属业务单元；全局仅扩大列表可见范围。

**Q：关闭开关后历史流水号设置会丢失吗？**   A：不会。记录保留，列表不再显示业务单元列，后续创建/导入恢复为无业务单元隔离行为。

## 业务编号监控

**访问路径：**`配置环境 > 运维管理 > 业务编号监控 > 业务编号监控`

业务编号监控页用于查看当前环境中哪些对象已经配置了编号规则，以及每个对象当前对应的是哪一条编号规则。页面支持按关键字查询，也支持分页浏览全部监控记录。

列表中会显示 `对象`、`编号规则` 和 `操作`。通过这几个信息，可以快速定位目标对象当前使用的编号规则。

当前页面提供的操作为：
- `详情`：进入该对象对应编号规则的监控详情页，继续查看具体监控信息

### 查看业务流水明细

在业务编号监控页点击 `详情` 后，系统会打开对应编号规则的业务流水明细面板。这里用于查看该编号规则已经生成过的编号记录，帮助配置人员确认编号是否已被使用、生成到了什么值，以及编号写入了哪条业务数据。

业务流水明细中会展示 `编号`、`重置标签`、`状态`、`实例名称`、`字段` 和 `创建时间` 等信息。通过这些内容，可以判断某个编号是在哪条记录上生成的、当前是否已使用，以及它对应的是哪个字段。

如果记录较多，可通过分页继续查看后续流水号记录；查看完成后，点击面板左上角的关闭按钮即可返回业务编号监控列表。

## 使用场景

### name\_\_ak 字段使用编号规则

当对象的 `name__ak` 字段启用 `由系统管理字段值(只读)` 时，需要选择该对象的编号规则。此时编号规则为必填。

如果当前对象还没有可用的编号规则，可直接在该配置入口创建编号规则。关闭 `由系统管理字段值(只读)` 后，`name__ak` 会变为可输入字段，历史数据不受影响。

### 生命周期进入动作使用编号规则

在生命周期进入动作中选择 `生成编号` 动作类型后，先选择文本类型字段，再选择适用于该对象的编号规则。

如果当前对象还没有编号规则，可在该入口直接创建编号规则。

## 生成规则说明
1. 当设置的起始编号小于已存在编号时，将以已有编号的最大值为起始值往后计算
2. 当设置的起始编号大于已存在编号时，将从新的起始值开始计算后续编号
3. 编号允许重复，系统不再对编号重复进行提示
4. 流水号超过设置位数但未超过 10 位时，流水号自动增加一位；超过 10 位时提示「流水号溢出」
5. 编号规则变更后，不修改历史数据
6. 生命周期生成编号时，若编号长度超过字段长度，会忽略字段长度设置生成完整编号
7. 当字段有值时，不再生成编号

### 字段编号段处理规则
- 当字段作为编号段时，系统不会检查该字段是否为必填
- 系统不会按字段长度限制编号段输入过程，而是直接读取字段值参与编号生成
- 生成编号时，会先去除字段值首尾空格，再写入编号
- 当字段值长度超过系统支持的最大长度时，会截取到最大长度
- 当字段值包含中文字符时，中文字符会直接写入编号
- 当数字字段值包含小数点或负号时，系统不做特殊处理，按原值写入编号
- 当字段值中包含空格或不支持的特殊符号时，系统会自动移除这些字符
- 当公式字段作为编号段时，只能选择返回类型为文本、数字或选项的公式字段
- 当公式字段计算结果为 `Null` 时，按空字符串处理

## 操作权限

### 编号规则权限

编号规则属于配置端页面，权限在权限集的 `管理端` 页签中配置。

| 权限项 | 作用 |
|---------|------|
| `查看` | 允许进入编号规则页面，并查看列表页、详情页等内容 |
| `全部` | 允许查看，并执行创建、编辑、启用、停用、删除等管理操作 |
