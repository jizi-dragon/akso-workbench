> 本文介绍如何在 Gaia 平台配置和管理输出模板，包括运行报告模板、文档模板和电子签名模板的创建与使用。

## 概述

Gaia 平台支持多种输出模板类型，用于从对象记录或文档生成格式化的输出文档。合理配置输出模板可提升报告生成效率，确保输出格式统一，并满足合规场景下的文档输出需求。

### 输出模板类型

| 类型 | 说明 | 典型用途 |
|------|------|------------|
| **运行报告模板** | 基于 Word 模板，从对象记录动态生成 Word/PDF 报告 | 批次报告、验证报告、审计摘要 |
| **文档模板** | 创建新文档时可选的预定义文档模板 | 标准 SOP 模板、记录模板 |
| **受控文档模板** | 带版本控制的文档模板 | 需审批的正式文档模板 |
| **电子签名模板** | 电子签名页的输出格式定义 | 审批签名页、培训确认页 |

### 访问路径

**配置端** \> **文档配置** \> **输出模板**

## 前提条件

在配置输出模板前，请确保满足以下条件：
- 您具有配置端访问权限及输出模板相关配置权限
- 已明确输出内容的业务对象或文档类型
- （运行报告模板）目标对象已定义所需字段
- （运行报告模板）已准备好 Word 模板文件（.doc 或 .docx 格式）
- （电子签名模板）已了解电子签名页的格式要求

## 3\. 运行报告模板

运行报告模板允许您基于 Word 模板文件，将对象记录的字段值动态合并到文档中，生成格式化的 Word 或 PDF 报告。

### 3.0 配置流程概述

运行报告配置建议遵循以下流程：**需求收集** → **模板拟定** → **审核** → **系统配置** → **测试** → **上线**。
1. **需求确定**：与需求提出方沟通，明确运行报告中需出现的字段、页眉页脚、Logo 等
2. **模板拟定**：在 Word 中设计模板，使用合并字段预留动态内容位置
3. **模板审核**：将初稿提交审核，通过后在测试环境配置并验证
4. **系统配置**：创建运行报告模板、配置数据源、绑定生命周期动作
5. **测试**：在生命周期相应状态点击生成，检查字段填充和附件是否正确
6. **上线**：确认无误后部署至生产环境

### 3.0.1 运行报告模板基本属性

创建或编辑运行报告模板时，可配置以下基本属性：

| 属性 | 说明 | 备注 |
|------|------|------|
| **所属对象** | 数据来源对象（支持自定义对象和标准对象） | 创建后不可修改 |
| **状态** | 模板的启用状态 | 启用 / 停用 |
| **字段和部分无数据时显示为 N/A** | 当合并字段或区域无数据时的显示方式 | 勾选后显示 "N/A"，未勾选则显示为空 |
| **启用版本控制** | 是否启用模板版本管理 | 启用后可创建多个版本，并为每个版本设置生效时间 |
| **运行报告名称** | 生成报告时的命名格式 | 用于生成到附件字段时的文件名，支持变量 |
| **模板格式** | 支持的模板文件格式 | 支持 .doc 格式 |

### 3.1 创建 Word 模板
1. 使用 Microsoft Word 创建或编辑 .doc 或 .docx 格式的模板文件
2. 在需要插入动态内容的位置使用 **合并字段**（merge field）预留占位符
3. 保存为 Word 2007 及以上兼容格式（.docx）
4. 确保模板排版、样式符合业务要求
> \[!NOTE\]
Word 模板中的占位符需使用 Gaia 约定的合并字段语法，详见下节。具体字段获取方法请参考平台提供的模板字段参考文档。   

### 3.2 配置合并字段与模板表达式

合并字段用于在模板中插入对象字段的值。在 Word 模板中，使用以下语法：

| 语法 | 说明 | 示例 |
|------|------|------|
| `&lt;&lt;&#91;C7472&#95;&#95;c]&gt;&gt;` | 插入当前对象字段值 | FormValue 下字段值 |
| `&lt;&lt;&#91;C7937&#95;&#95;c.YP&#95;QUA&#95;NAME&#95;&#95;c]&gt;&gt;` | 插入出站对象字段值 | FormValue 下出站对象的字段 |
| `&lt;&lt;&#91;signature&#95;time&#95;&#95;sys]:"yyyy-MM-dd"&gt;&gt;` | 时间格式转换 | 转换为年月日格式 |

**模板表达式语法**（支持条件与循环）：

| 表达式 | 说明 | 示例 |
|---------|------|------|
| `&lt;&lt;foreach &#91;in 集合]&gt;&gt;&lt;&lt;&#91;字段]&gt;&gt;&lt;&lt;/foreach&gt;&gt;` | 遍历集合 | 循环输出相关对象列表 |
| `&lt;&lt;if &#91;条件]&gt;&gt;&lt;&lt;else&gt;&gt;...&lt;&lt;&lt;/if&gt;&gt;` | 条件判断 | 根据字段值输出不同内容 |
| `.Where(p=&gt;p.xxx=="value")` | 筛选条件 | 仅输出满足条件的数据 |
| `.OrderBy(p=&gt;p.字段)` | 升序排序 | 按时间或序号排序 |
| `.OrderByDescending(p=&gt;p.字段)` | 倒序排序 | 按时间倒序 |

**配置步骤：**
1. 进入 **配置端** \> **文档配置** \> **输出模板** \> **运行报告模板**
2. 点击 **创建**
3. 填写基本信息：

| 属性 | 说明 | 必填 |
|------|------|------|
| **标签** | 模板显示名称 | ✓ |
| **名称** | API 名称 | ✓ |
| **关联对象** | 数据来源对象 | ✓ |
| **描述** | 用途说明 | ✗ |
4. 上传 Word 模板文件
5. 在 **合并字段** 区域确认或映射字段对应关系
6. 点击 **保存**

💡 **建议**：合并字段名称需与对象字段的 API 名称精确匹配，大小写敏感。

### 3.3 配置条码字段

运行报告模板支持在输出文档中生成条码和二维码，适用于批次号、追溯码、设备标识等场景。

**配置步骤：**
1. 在运行报告模板的 **条码字段** 区域点击 **添加**
2. 选择要生成条码的字段
3. 配置条码属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| **条码类型** | 条码或二维码格式 | Code 128、QR Code |
| **显示文本** | 是否在条码下方显示原文 | 是/否 |
| **尺寸** | 条码高度与宽度（可选） | 自动/自定义 |
4. 在 Word 模板中，使用条码合并字段语法，例如：`{{barcode:batch_number__c}}` 或按平台约定配置
5. 点击 **保存**

⚠️ **注意**：条码字段引用的必须是文本或数值类型字段，确保数据格式符合所选条码类型的编码规则。

### 3.4 配置数据源与相关对象报告

#### 数据源

数据源定义生成运行报告时所使用的数据范围：

| 配置项 | 说明 |
|---------|------|
| **主对象** | 与所属对象一致，作为报告生成的主数据来源 |
| **相关对象层级** | 支持最多 3 层相关对象的字段引用 |
| **出入站关系** | 涉及该对象**出入站关系**的数据源，需在「数据源」配置区域**手动配置**；若模板中数据为对象字段，系统会自动匹配，无需额外配置 |

配置数据源时，主对象必须与模板的所属对象一致。您可通过合并字段语法引用主对象及其 3 层内的相关对象字段。

#### 相关对象报告

可为**相关对象**单独生成报告：

| 配置项 | 说明 |
|---------|------|
| **适用场景** | 当主对象关联多个子记录时，可为每个子记录生成独立的报告 |
| **层级限制** | 无层级限制，可递归为任意层级的相关对象生成报告 |

相关对象报告使用相同的模板结构和合并字段语法，数据来源于各相关对象记录。

### 3.5 系统设置：运行报告名称

在 **管理端** \> **系统设置** \> **常规设置** \> **运行报告名称设置** 中，可配置：

| 配置项 | 说明 |
|---------|------|
| **压缩包名称格式** | 下载多个报告时，压缩包的文件名格式，支持变量 |
| **运行报告名称格式** | 单份报告的文件名格式，支持变量 |

合理搭配变量可满足不同客户的命名规范需求。

### 3.6 下载格式设置

在生命周期 **用户动作** 中，选择「下载运行报告」动作时，可在 **下载格式** 中选择希望的输出格式。目前支持 **PDF** 和 **Word** 格式。

### 3.7 版本控制与模版版本选择

运行报告模板支持版本控制，适用于模板变更需要追溯历史版本的场景。

**为什么需要版本控制**：

当运行报告模板配置变更后（如增加或减少了字段），历史变更数据需要使用之前的报告模板版本，确保历史数据的报告格式与当时一致。

**配置步骤**：
1. 在运行报告模板的基本属性中，启用 **启用版本控制**
2. 启用后，每次模板变更可创建新版本，并为每个版本设置生效时间
3. 在生命周期用户动作【下载运行报告】上，勾选属性 **当运行报告启用版本控制后允许用户选择模版版本**
4. 启用后，用户生成或下载报告时可选择模板的特定版本

💡 **提示**：版本控制功能确保历史数据的报告格式一致性，提升系统可靠性。

### 3.8 生命周期动作配置

运行报告需在对象生命周期的相应状态中配置「生成运行报告」或「下载运行报告」动作后，用户方可使用。

**配置步骤：**
1. 进入目标对象的 **生命周期**，找到需要添加动作的状态
2. 在 **用户动作** 中点击 **创建**
3. 选择动作类型为 **生成运行报告** 或 **下载运行报告**
4. 选择对应的运行报告模板，配置下载格式（PDF/Word）等
5. 若在系统设置中配置了运行报告名称，需在此处关联或确认
6. 保存后，用户在该状态下可点击生成/下载按钮；运行报告生成成功后以站内信等形式通知用户

### 3.9 绑定到对象/文档类型

将运行报告模板绑定到对象或文档类型后，用户可在记录详情页或文档页执行"生成报告"操作。

**配置步骤：**
1. 打开目标对象或文档类型的配置
2. 进入 **输出模板** 或 **报告模板** 相关标签页
3. 点击 **添加**，选择已创建的运行报告模板
4. 设置模板的适用条件（如按对象类型、生命周期状态筛选）
5. 配置输出选项：

| 选项 | 说明 |
|------|------|
| **默认输出格式** | Word (.docx) 或 PDF |
| **文件名规则** | 使用对象字段定义生成的文件名 |
| **可用操作** | 生成、下载、另存为文档等 |
6. 点击 **保存**

### 3.10 对象动作与批量下载

运行报告支持通过对象动作和批量操作直接下载，提升用户操作效率。

**对象动作：下载运行报告**

可将「下载运行报告」配置为对象动作，绑定到目标对象后，用户可在记录详情页通过操作按钮直接下载生成的报告，无需进入报告列表或单独执行生成操作。

**记录动作：下载运行报告**

在记录动作中新增「下载运行报告」动作类型，配置参数与生命周期用户动作一致。配置后，用户可在记录详情页通过记录动作直接下载运行报告，简化配置流程。

**批量下载运行报告**

在列表视图或搜索结果中，支持勾选多条记录后执行批量下载操作：
1. 勾选多条记录后，系统自动计算并显示 **下载运行报告** 批量操作
2. 选择要使用的运行报告模板
3. 系统将依次为每条记录生成对应的运行报告
4. 所有报告打包为 ZIP 文件下载

压缩包名称格式：`{对象名称}-运行报告-{YYYY-MM-DD hhmmss}`，例如：`偏差-运行报告-20260121155002`

**表单布局集成**

在表单布局中，可为对象配置「下载运行报告」按钮或操作区域。用户查看记录详情时，可直接在表单上点击下载，无需切换至其他页面。表单布局中的下载操作支持选择运行报告模板及输出语种（见下节）。

**配置步骤：**
1. 进入对象配置，在 **对象动作**、**记录动作** 或 **页面布局** 中添加「下载运行报告」动作
2. 选择适用的运行报告模板
3. 设置显示条件（如按生命周期状态、用户角色）
4. 在表单布局中将该动作拖入布局区域

### 3.11 运行报告多语言与语种选择

运行报告支持多语言输出，适用于需要向不同地区或语言用户分发的场景。

**多语言运行报告**

运行报告模板可配置支持的语言列表。生成报告时，系统根据所选语种将模板中的静态文本、合并字段等内容转换为目标语言输出。

**翻译内容范围**

翻译内容包括：
- 主对象报告
- 相关对象报告

**用户动作配置：目标语言**

在生命周期用户动作的配置中，可设置 **目标语言** 属性：
1. 在用户动作【下载运行报告】或【生成运行报告】配置中，找到 **目标语言** 属性
2. 选择目标语言（非必填）
3. 配置后，导出时自动导出选定语言的报告

**预览功能**

如果启用了预览功能：
1. 预览界面默认显示目标语言的语种
2. 在预览界面支持切换目标语言，实时查看不同语言的报告效果

**表单布局中的语种选择**

在表单布局中配置下载运行报告模版时，可提供语种选择控件。用户在执行下载前可选择期望的输出语言，系统按所选语种生成报告。

**配置步骤：**
1. 在运行报告模板配置中，启用 **支持翻译**
2. 维护各语言对应的模板内容或翻译映射
3. 在生命周期用户动作配置中，设置 **目标语言** 属性（可选）
4. 在表单布局的下载运行报告配置中，勾选 **允许用户选择语种**，并设定可选语言列表

### 3.12 附件合并

运行报告支持将主对象或其相关对象的附件合并到生成的报告中，实现报告与附件的统一输出。

**适用场景**

| 场景 | 说明 |
|------|------|
| 批次检验报告 | 将检验记录、检验报告附件按顺序合并到批次放行报告中 |
| 验证报告 | 将验证方案、验证记录等附件合并为完整验证报告 |
| 审计摘要 | 将证据附件按章节合并到审计报告中 |

**配置步骤：**
1. 在运行报告模板的 **数据源** 或 **合并选项** 中启用 **附件合并**
2. 选择要合并的附件来源（主对象附件字段或相关对象附件）
3. 配置附件在报告中的插入位置（如按章节、按对象关系顺序）
4. 设定附件格式要求（支持合并的格式类型）

⚠️ **注意**：附件合并会增加报告生成时间，且合并后的报告体积可能较大，建议根据业务需要选择性启用。

### 3.13 组织隔离

运行报告模板支持按业务单元隔离，确保不同组织仅能使用和维护本组织范围内的模板。

| 配置项 | 说明 |
|---------|------|
| **组织隔离** | 启用后，模板仅对所属业务单元可见、可用，其他组织无法查看或引用 |
| **适用范围** | 适用于多组织、多工厂部署场景，满足数据隔离与合规要求 |

在运行报告模板的基本属性中，可配置 **按业务单元隔离**。启用后，模板的可见性与使用权限将严格限制在配置的所属组织内。

### 3.14 报表运行时条件编辑

报表在执行时支持动态编辑查询条件，使用户可根据实际需要灵活筛选数据后再生成报告。

**配置与使用：**
1. 在报表或运行报告模板中，将部分筛选条件标记为 **可在运行时编辑**
2. 用户执行「生成报告」或「运行报表」时，系统展示条件编辑区域
3. 用户可修改日期范围、对象类型、状态等条件后，再触发生成
4. 条件变更仅作用于当次运行，不保存到模板配置

适用于需临时调整查询范围、按不同维度生成多份报告的灵活场景。

### 3.15 数据源设置界面

运行报告模板的数据源配置支持放大窗口显示，便于在复杂对象关系中配置主对象、相关对象及字段映射。

**配置步骤：**
1. 进入运行报告模板 \> **数据源** 区域
2. 点击 **放大窗口** 或类似入口，在独立大窗口中打开数据源配置界面
3. 在放大窗口中可更清晰地查看对象层级、字段列表及映射关系
4. 配置完成后保存，关闭窗口返回模板编辑页

### 3.16 生成失败错误提示

当运行报告生成失败时，系统在消息通知中显示具体失败原因，便于用户快速定位问题。

**常见失败原因示例：**

| 失败原因 | 说明 | 建议处理 |
|------------|------|------------|
| 合并字段无数据 | 必填合并字段在记录中为空 | 检查记录数据或调整模板占位符 |
| 模板格式错误 | Word 模板结构异常 | 检查模板文件，确保格式正确 |
| 附件不存在 | 引用的附件字段无文件 | 确认记录中已上传所需附件 |
| 权限不足 | 用户无权访问相关数据 | 检查对象及字段的权限配置 |

用户在执行生成或下载操作后，若失败，可在消息中心或操作反馈区域查看详细错误信息，便于排查和修正。

## 4\. 文档模板

文档模板用于在创建新文档时提供预定义的文档结构或占位内容。

### 4.1 创建文档模板
1. 进入 **配置端** \> **文档配置** \> **文档模板**
2. 点击 **创建**
3. 填写模板属性：

| 属性 | 说明 | 必填 |
|------|------|------|
| **标签** | 模板显示名称 | ✓ |
| **名称** | API 名称 | ✓ |
| **适用文档类型** | 可选用此模板的文档类型 | ✓ |
| **描述** | 用途说明 | ✗ |
4. 上传模板文件（Word/PDF 等）或使用在线编辑器创建内容
5. 配置模板在创建文档时的显示顺序和默认选择逻辑
6. 点击 **保存**

### 4.2 配置受控文档模板

受控文档模板具备版本控制能力，适用于需要审批、变更控制的正式文档模板。

**配置步骤：**
1. 在文档模板创建或编辑界面，启用 **受控文档** 选项
2. 为模板分配生命周期，以管控模板的生效与停用
3. 配置模板的审批工作流（如需要）
4. 设置版本号规则
5. 保存后，模板变更将遵循版本控制流程

💡 **建议**：受控文档模板变更应纳入变更控制流程，确保模板更新的可追溯性。

## 5\. 电子签名模板

电子签名模板定义电子签名页在输出时的版面、字段布局和签名块格式。

**配置步骤：**
1. 进入 **配置端** \> **文档配置** \> **电子签名模板**
2. 点击 **创建**
3. 填写模板属性：

| 属性 | 说明 | 必填 |
|------|------|------|
| **标签** | 模板显示名称 | ✓ |
| **名称** | API 名称 | ✓ |
| **适用场景** | 文档审批、培训确认等 | ✓ |
| **描述** | 用途说明 | ✗ |
4. 设计签名页布局： 
    - 定义签名块数量与位置
    - 配置签名者姓名、角色、日期等显示字段
    - 设置签名框样式与合规标识
5. 绑定到相应的文档类型或工作流
6. 点击 **保存**

⚠️ **注意**：电子签名模板的设计需符合相关法规对电子签名的要求，包括签名者标识、时间戳等要素。

## 6\. 验证配置

配置完成后，建议按以下步骤验证输出模板是否正常工作。

### 6.1 运行报告模板验证
1. 打开一条目标对象的测试记录
2. 执行 **生成报告** 操作
3. 检查生成的文档： 
    - 合并字段是否正确替换为实际值
    - 条码/二维码是否能正确扫描
    - 格式、排版是否符合预期
4. 分别测试 Word 和 PDF 输出格式

### 6.2 文档模板验证
1. 进入文档创建界面
2. 确认目标文档类型下能看到配置的文档模板
3. 选择模板创建新文档，检查初始内容是否正确带入

### 6.3 电子签名模板验证
1. 发起需要电子签名的流程
2. 完成签名后，检查生成的签名页输出
3. 确认签名者、日期、角色等信息完整且格式正确

## 7\. 最佳实践

### 7.1 命名规范

| 类型 | 建议格式 | 示例 |
|------|------------|------|
| 运行报告模板 | `&#91;对象]&#95;&#91;报告用途]&#95;Report` | `batch&#95;release&#95;report&#95;&#95;c` |
| 文档模板 | `&#91;文档类型]&#95;&#91;模板用途]&#95;Template` | `sop&#95;master&#95;template&#95;&#95;c` |
| 电子签名模板 | `&#91;场景]&#95;Signature` | `approval&#95;signature&#95;&#95;c` |

### 7.2 模板管理
- **版本管理**：Word 模板文件变更时，建议在模板名称或描述中注明版本日期
- **测试先行**：在生产环境应用前，在沙箱或测试环境中充分验证
- **字段映射文档**：为复杂模板维护字段映射说明，便于后续维护和交接
- **权限控制**：仅授权必要人员编辑输出模板，避免误改影响业务

### 7.3 性能与合规
- 合并字段较多或文档较大时，生成报告可能需要一定时间，可在界面上给予用户适当提示
- 涉及 GxP 场景时，确保输出模板的变更符合变更控制要求
- 条码字段需确保数据质量，避免空值或格式错误导致条码无法生成

## 8\. 常见问题

### Q1：合并字段显示为空白或原文，未替换为字段值？

**A**：请检查：
1. 合并字段语法是否正确，对象 API 名称和字段 API 名称是否与配置一致
2. 当前记录中该字段是否有值
3. 字段是否被正确映射到模板

### Q2：生成的 PDF 排版与 Word 预览不一致？

**A**：PDF 渲染可能与 Word 存在细微差异，建议：
1. 使用标准字体，避免特殊字体
2. 简化复杂表格和嵌套结构
3. 在 Word 中直接另存为 PDF 对比效果

### Q3：条码无法扫描或显示异常？

**A**：请确认：
1. 条码类型与数据格式匹配（如 QR Code 对字符长度有限制）
2. 字段值符合该条码的编码规则
3. 输出分辨率足够，条码尺寸不过小

### Q4：文档模板在创建时不可见？

**A**：检查：
1. 文档模板是否已激活
2. 适用文档类型是否包含当前要创建的文档类型
3. 当前用户角色是否有权使用该模板

### Q5：电子签名模板输出不符合合规要求？

**A**：请对照法规要求，确保模板包含：
- 签名者唯一标识（如姓名、工号）
- 签名时间
- 签名含义（如"批准"、"审核"）
- 与主文档的关联标识
