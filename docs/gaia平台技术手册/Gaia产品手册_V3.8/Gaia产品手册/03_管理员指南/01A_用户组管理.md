\# 用户组管理
> **所需权限**：系统管理员 或 用户管理员   

---

## 概述

用户组用于批量管理权限一致的用户，便于统一分配角色、维护成员范围。

系统中常见三类用户组：
- **普通用户组**：成员由管理员手动添加或移除。
- **动态用户组**：成员由规则自动计算和维护。
- **DAC 自动映射用户组**：在数据权限管理（DAC）中由系统自动创建并维护，用于承载数据权限映射关系。

---

## 使用入口

进入【用户管理】\>【用户组】后，可查看用户组列表并执行创建、查看、编辑等操作。

---

## 创建用户组

点击【创建】后，进入用户组创建页。

### 页面顶部操作
- **返回**：离开当前页面，不保存本次填写内容。
- **保存**：校验必填项后保存用户组。

### 字段说明

| 字段 | 必填 | 说明 | 填写建议 |
|------|------|------|------------|
| 名称 | ✓ | 用户组显示名称，用于列表、详情和成员分配场景 | 建议使用清晰业务名称，如“QA审核组” |
| 编码 | ✓ | 用户组唯一标识，用于系统内部识别和配置引用 | 建议使用稳定编码，如 `QA&#95;REVIEW&#95;TEAM` |
| 来源 |  | 当前页面显示为“自定义” | 通常保持默认值 |
| 类型 |  | 控制成员维护方式（动态/普通） | 创建前先确认是否需要自动维护成员 |
| 描述 |  | 记录用户组用途和适用范围 | 建议写明“谁会被加入、用于什么权限场景” |
> 说明：DAC 自动映射用户组由系统在【数据权限管理】中创建，不通过本页面手工新建。   

### 操作步骤
1. 进入【用户管理】\>【用户组】。
2. 点击【创建】。
3. 填写“名称”“编码”等基本信息。
4. 在“类型”中选择用户组类型： 
    - 选择“普通”：后续在【组员】页签手动维护成员。
    - 选择“动态”：后续配置组员规则，由系统自动维护成员。
5. 点击【保存】。

### 保存后结果
- 用户组会出现在用户组列表中。
- 可进入用户组详情页继续维护。
- 普通用户组可手动添加/移除组员。
- 动态用户组需配置规则后，系统才会按规则自动计算组员。
- DAC 自动映射用户组由数据权限配置驱动，成员与映射关系由系统维护。

---

## 用户组详情

在用户组详情页可执行以下操作：
- 查看用户组基本信息（名称、编码、类型、描述等）。
- 编辑用户组基础信息。
- 在【组员】页签管理成员（仅普通用户组支持手动管理）。
- 对动态用户组维护组员规则并查看自动计算结果。

---

## 动态用户组

动态用户组适用于“成员范围经常变化”的场景（如按部门、职位、状态自动归组）。

### 动态组特点
- **自动维护**：满足规则的用户自动加入，不满足规则的用户自动退出。
- **实时更新**：用户字段变更后，系统按规则更新成员关系。
- **规则驱动**：通过条件编辑器定义成员范围（支持 AND/OR 组合）。

### 动态组配置步骤
1. 创建用户组时将“类型”选择为“动态”。
2. 保存后进入动态组规则配置入口（如【动态组员规则管理】）。
3. 配置筛选条件并保存规则。
4. 系统自动重算成员并持续维护。

### 自动加入/退出触发时机
- 新用户创建时：若满足规则，自动加入动态组。
- 用户信息变更时：系统重新判断是否继续满足规则。
- 规则保存时：系统重新计算并更新动态组成员。
> 注意：动态用户组不支持手动添加或手动移除成员。   

---

## DAC 自动映射用户组

DAC 自动映射用户组用于承接数据权限管理中的“主体-权限范围”映射。该类用户组不是手工维护组，而是由系统根据 DAC 配置自动生成和更新。

### 使用特征
- **创建来源**：在【数据权限管理】配置并保存映射规则后，系统自动创建对应用户组。
- **成员维护**：成员关系由数据权限映射自动维护，不建议在用户组页面手工干预。
- **用途定位**：主要用于数据可见范围和数据操作范围控制，不作为日常业务分组使用。

### 管理建议
- 需要调整这类用户组时，优先在【数据权限管理】中修改映射规则。
- 若用户组页面可见该类用户组，建议仅做识别和排查，不直接改动其核心映射配置。

---

## 常见问题

**Q: 动态用户组和普通用户组怎么选？**   A: 若成员范围稳定、需要人工控制，选普通用户组；若成员范围依赖组织字段且变动频繁，选动态用户组。

**Q: DAC 自动映射用户组在哪里创建？**   A: 不在【用户组】页面创建。它由【数据权限管理】中的配置触发，系统自动创建并维护。

**Q: 保存后看不到成员，是否异常？**   A: 普通组需要手动添加成员；动态组需要先配置规则并等待系统计算。
