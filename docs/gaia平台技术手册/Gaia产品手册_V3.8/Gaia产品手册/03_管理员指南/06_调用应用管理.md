# 调用应用管理
> 本文介绍如何在 Gaia 平台中维护调用应用，用于允许外部系统通过 Gaia API 读取数据、同步状态或触发业务流程。   

---

## 1\. 适用范围

调用应用表示一个被允许调用 Gaia API 的外部系统。创建调用应用后，系统会生成 AppId 和 AppSecret，外部系统需要在接口调用时使用对应密钥完成身份识别。

常见使用场景包括：
- 外部系统调用 Gaia API，同步对象记录、文档数据或业务状态。
- 第三方系统通过受信任方式跳转到 Gaia，实现单点登录或嵌入式访问。
- 外部平台根据业务事件触发 Gaia 中的流程或后台任务。

---

## 2\. 访问入口

访问路径：`管理端 > 集成管理 > 调用应用管理`

如果当前账号看不到入口，请先确认是否已具备集成管理相关的管理员权限。调用应用会影响外部系统访问 Gaia API 的身份识别和访问状态，建议仅开放给系统管理员或集成维护人员。

---

## 3\. 查看调用应用列表

调用应用列表展示当前环境中已经注册的外部调用方。

| 列 | 说明 |
|---|------|
| 名称 | 调用应用的显示名称。 |
| AppId | 系统自动生成的应用标识符，用于外部系统调用 Gaia API 时识别调用方。 |
| 密钥 | 调用应用的访问密钥信息。AppSecret 只在创建或刷新密钥后展示一次，关闭弹窗后无法再次查看。 |
| 描述 | 应用用途说明。建议写明系统名称、调用范围和维护团队。 |
| 状态 | 控制该应用是否允许继续调用 Gaia API。 |
| 创建者 | 创建该调用应用的用户。 |
| 创建时间 | 调用应用首次保存的时间。 |
| 操作 | 可执行编辑、删除等管理动作。 |

---

## 4\. 创建调用应用
1. 进入 `管理端 > 集成管理 > 调用应用管理`。
2. 点击 `创建`。
3. 填写调用应用信息。
4. 点击 `保存`。

创建调用应用时，需要填写以下字段：

| 字段 | 是否必填 | 说明 | 示例 |
|------|------------|------|------|
| 名称 | 是 | 调用应用的显示名称。建议使用外部系统名称或接口项目名称。 | MES 系统数据同步 |
| 状态 | 是 | 控制应用是否启用。启用后外部系统可按授权方式调用 Gaia API；禁用后不再允许继续调用。 | 启用 |
| 描述 | 否 | 说明应用用途、调用范围和维护责任人。 | 用于 MES 系统同步生产批次数据 |

保存成功后，系统会自动生成密钥，并弹出 `查看密钥` 窗口。窗口中包含 `AppId` 和 `AppSecret`，管理员可以点击 `复制密钥` 将密钥信息提供给负责外部系统对接的人员。
> \[!IMPORTANT\]
AppSecret 只在创建或刷新密钥后展示一次。关闭 `查看密钥` 窗口后，系统不会再次在界面中展示该 AppSecret。请在窗口关闭前完成复制和安全保存。   

系统会存储密钥中的 AppSecret，用于后续接口调用校验，但不会允许管理员反复查看明文 AppSecret。这是防止系统界面泄漏密钥的保护措施。

---

## 5\. 查看和刷新密钥

调用应用创建完成后，外部系统通常需要同时使用 `AppId` 和 `AppSecret` 完成调用认证。管理员应将密钥交付给外部系统对接人员，并要求对方按凭证类信息保存。

### 5.1 查看新建密钥

创建调用应用并保存成功后，系统会打开 `查看密钥` 窗口。

窗口中显示以下信息：

| 字段 | 说明 |
|------|------|
| AppId | 调用应用的应用标识，用于识别调用方。 |
| AppSecret | 调用应用的密钥，用于配合 AppId 完成接口调用认证。 |

窗口中的 `复制密钥` 用于一次性复制当前密钥信息。关闭该窗口后，管理员不能再从系统界面查看本次生成的 AppSecret。

### 5.2 刷新密钥

如果 AppSecret 丢失、疑似泄露，或外部系统需要更换调用凭证，管理员可以在调用应用详情页点击 `刷新密钥` 重新生成密钥。

刷新密钥后，系统会生成新的 AppSecret，并再次打开 `查看密钥` 窗口。新的 AppSecret 同样只展示一次，关闭窗口后无法再次查看。

刷新密钥前，请先确认外部系统对接人员可以同步更新调用配置。密钥刷新后，旧密钥可能不再适用于后续接口调用，未及时更新外部系统配置可能导致接口调用失败。

---

## 6\. 启用、禁用和删除调用应用

调用应用的状态会直接影响外部系统是否能继续访问 Gaia API。
- `启用`：允许外部系统继续使用该应用身份调用 Gaia API。
- `禁用`：停止该应用的后续调用。适用于联调暂停、应用下线、凭证疑似泄露等场景。
- `编辑`：修改应用名称、状态或描述。修改描述不会影响接口调用；修改状态会立即影响后续调用。
- `刷新密钥`：重新生成调用应用密钥。适用于 AppSecret 丢失、疑似泄露或计划轮换密钥的场景。
- `删除`：移除调用应用记录。删除前应确认外部系统已停止使用该 AppId，否则可能导致接口调用失败。

生产环境中，建议优先使用 `禁用` 暂停访问，确认没有业务影响后再删除。

---

## 7\. 第三方应用接入

第三方应用接入用于支持外部系统跳转到 Gaia 时的受信任访问，例如企业门户入口、外部业务系统嵌入 Gaia 页面等。

### 7.1 单点登录

配置完成后，用户从已集成的外部系统进入 Gaia 时，可以减少重复登录操作。典型表现为：用户在外部系统中点击 Gaia 链接后，系统根据已建立的信任关系识别用户身份，并进入对应页面。

使用单点登录前，需要确认：
- 外部系统和 Gaia 之间已经建立可信任的身份传递方式。
- 用户在 Gaia 中存在对应账号，且具备目标页面所需权限。
- 跳转链接指向的页面、对象或文档对当前用户可见。
- 生产环境启用前已经完成测试账号、异常账号和权限不足场景验证。

如果用户从第三方系统跳转后仍然需要重新登录，通常需要检查信任配置、用户映射关系、会话有效期和网络访问规则。

---

## 8\. 安全与排查

调用应用涉及外部系统访问 Gaia API，建议遵循以下规则：
- 对外部调用应用定期复核，停用已经下线或长期不使用的应用。
- AppId 和 AppSecret 应按凭证类信息管理，不应写入公开文档、截图或普通沟通群。
- AppSecret 只展示一次。关闭 `查看密钥` 窗口后，如果未保存或已经丢失，应通过 `刷新密钥` 重新生成。
- 人员变更、系统下线或疑似凭证泄露时，应及时禁用对应调用应用，或刷新密钥并通知外部系统同步更新。
- 调用应用的创建、编辑、删除等操作会记录审计日志，便于后续追踪配置变更。

当外部系统无法调用 Gaia API 或第三方应用无法访问 Gaia 时，可按以下顺序排查：
1. 确认调用应用是否处于启用状态。
2. 确认外部系统使用的 AppId 和 AppSecret 是否与当前调用应用的有效密钥一致。
3. 确认外部系统网络是否可访问 Gaia。
4. 确认目标 API、对象、文档或页面对调用方具备访问权限。
5. 查看审计日志或接口调用日志，定位失败时间、调用方和错误信息。
