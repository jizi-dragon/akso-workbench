# 翻译控制台
> 本文面向 Gaia 平台系统管理员，介绍如何在翻译控制台中查询、编辑、导入、导出和刷新多语言译文。翻译控制台维护的是系统界面、组件、按钮、字段、提示语和帮助文本等用户可见文案，保存后的译文会影响终端用户在对应语言环境下看到的页面文字。   

---

## 文档信息

| 项目 | 内容 |
|------|------|
| 适用版本 | Gaia 平台 latest |
| 适用角色 | 系统管理员、实施顾问、多语言内容维护人员 |
| 相关模块 | 系统设置、语言与地区设置、多语言翻译 |

---

## 概述

翻译控制台用于维护 Gaia 平台的多语言译文。管理员可以先按语言、组件和组件下级类型限定范围，再查看完整路径、原文和译文；也可以通过关键字定位具体文案，直接编辑译文，或使用导入、导出和 AI 翻译处理批量内容。

翻译控制台通常用于以下场景：

| 场景 | 说明 |
|------|------|
| 首次启用新语言 | 为新启用的语言补齐系统界面、按钮、字段和帮助文本译文 |
| 日常译文维护 | 修正术语、语气、上下文不准确的译文 |
| 批量翻译 | 导出未翻译内容，在线下完成翻译后再导入 |
| AI 辅助生成初稿 | 对当前筛选范围内的内容生成初始译文，再由管理员复核 |
| 缓存刷新 | 保存译文后清除翻译缓存，使业务页面加载最新文案 |
> \[!IMPORTANT\]
翻译内容会直接影响用户界面。正式环境中执行批量导入或 AI 翻译后，建议先抽查登录页、导航菜单、关键业务页面、按钮、字段名、帮助文本和错误提示，再清除缓存并交付给用户使用。   

---

## 访问入口

进入路径：**管理端 \> 系统设置 \> 翻译控制台**。

进入页面后，左侧导航中会高亮显示 **翻译控制台**。主区域由 **设置选项** 和 **翻译内容** 两部分组成：设置选项用于限定语言和组件范围，翻译内容用于搜索、导入、导出、编辑和保存译文。

---

## 权限要求

管理员需要具备系统设置或翻译控制台相关权限，才能访问和维护译文。实际权限名称可能随客户环境配置而不同，请以权限集中的菜单和操作权限为准。

| 权限 | 说明 |
|------|------|
| 翻译控制台：查看 | 可以进入页面，按语言和组件查询翻译项 |
| 系统设置：全部 | 通常包含翻译控制台的查看、编辑、导入导出和缓存刷新能力 |

如果当前账号没有访问权限，左侧菜单中通常不会显示 **翻译控制台**。如果只有查看权限，页面可以查询翻译内容，但编辑、导入、AI 翻译、保存或清除缓存等操作可能不可用。

## 页面结构

### 顶部操作区

| 按钮 | 说明 |
|------|------|
| 返回 | 返回上一页面。返回不会自动保存译文修改，离开前应先点击 **保存**。 |
| 清除翻译缓存 | 清除系统已缓存的翻译结果。译文已经保存但业务页面仍显示旧文案时，使用该按钮刷新缓存。 |
| AI翻译 | 对当前筛选范围内的翻译项生成译文。点击前应先确认语言、组件、下级类型和关键字筛选条件，避免处理不需要变更的内容。 |
| 保存 | 保存当前页面已编辑或生成的译文。保存后译文写入系统翻译数据；业务页面是否立即显示新译文，取决于缓存状态和页面刷新情况。 |

### 设置选项

设置选项用于限定翻译内容的维护范围。筛选范围越准确，后续搜索、导出、AI 翻译和导入后的核对工作越可控。

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 语言 | 是 | 选择要维护的目标语言。切换语言后，页面会按所选语言加载对应译文。只有需要对该语言补充或修订译文时，才应在该语言下进行编辑。 |
| 组件 | 否 | 选择翻译内容所属组件。未选择时，页面按当前语言显示可维护的翻译内容；选择后，只显示该组件下的翻译项。 |
| 组件下级类型 | 条件显示 | 当所选组件存在下级分类时显示，用于继续缩小范围。例如选择 **检查表类型** 后，可继续选择 **帮助文本** 等分类。 |
> \[!TIP\]
不确定文案属于哪个组件时，可以先只选择语言，再使用关键字搜索。定位到完整路径后，再按组件筛选进行批量维护。   

### 翻译内容区

翻译内容区包含关键字输入框、搜索按钮、导入导出按钮和翻译表格。

| 控件 | 说明 |
|------|------|
| 关键字输入框 | 输入要查找的文字。关键字可用于定位原文、译文或完整路径中包含该文字的翻译项。 |
| 搜索 | 按当前语言、组件、下级类型和关键字刷新表格结果。 |
| 导入 | 导入线下维护好的翻译文件。导入后应检查表格内容，并按系统提示完成提交或点击 **保存**。 |
| 导出未翻译 | 导出当前筛选范围内尚未维护译文的内容，适合交给翻译人员集中补齐。 |
| 导出 | 导出当前筛选范围内的翻译内容，适合备份、审阅、归档或迁移到其他环境。 |

翻译表格字段如下：

| 字段 | 说明 |
|------|------|
| 完整路径 | 翻译项在系统中的位置，用于判断文案来自哪个模块、页面、组件或字段。编辑前应结合完整路径确认上下文。 |
| 原文 | 系统中的源语言文本。通常不在翻译控制台中编辑。 |
| 译文 | 当前目标语言的翻译文本。管理员在此维护最终显示给用户的文案。 |

当筛选条件下没有可显示的数据时，表格区域显示 **暂无数据**。可以清空关键字、切换组件或扩大筛选范围后重新搜索。

## 查询翻译内容
1. 进入 **管理端 \> 系统设置 \> 翻译控制台**。
2. 在 **语言** 下拉框中选择目标语言。
3. 根据需要选择 **组件**。
4. 如果页面显示组件下级类型字段，继续选择具体类型。
5. 在关键字输入框中输入要查找的文字。
6. 点击 **搜索**。
7. 在表格中查看匹配结果的完整路径、原文和译文。

如果搜索不到结果，可以清空关键字后重新搜索，或扩大组件筛选范围。对于按钮、字段名和提示语等短文本，建议同时尝试原文关键字和译文关键字。

---

## 编辑并保存译文
1. 按语言、组件或关键字查询需要维护的翻译项。
2. 在表格中定位目标行。
3. 根据 **完整路径** 判断该文案的使用场景。
4. 在 **译文** 列补充或修改目标语言文本。
5. 检查同一页面或同一组件下的相近文案，保持术语、标点和语气一致。
6. 点击页面右上角 **保存**。
7. 保存成功后，进入相关业务页面抽查显示效果。
8. 如果业务页面仍显示旧文案，返回翻译控制台点击 **清除翻译缓存**，再刷新业务页面。
> \[!NOTE\]
按钮、字段名、状态值、帮助文本和错误提示的翻译要求不同。短文本应优先保持简洁和术语一致；帮助文本和提示语应说明用户下一步要做什么，避免逐字翻译导致含义不清。

## 使用 AI 翻译

AI 翻译适合生成初稿，尤其适用于首次启用某个语言或批量补齐未翻译内容。AI 生成结果不应直接作为最终合规文案发布。
1. 选择目标 **语言**。
2. 选择需要处理的 **组件** 和下级类型。
3. 如只想处理部分内容，先输入关键字并点击 **搜索**。
4. 确认表格结果只包含本次需要翻译的内容。
5. 点击 **AI翻译**。
6. 等待系统生成译文。
7. 抽查译文列中的术语、语气、上下文和业务含义。
8. 必要时手工修订译文。
9. 点击 **保存**。
10. 清除翻译缓存，并到相关页面检查显示效果。

涉及电子签名、审计追踪、生命周期状态、权限控制、偏差、CAPA、变更、培训和质量回顾等 GxP 场景的文案，应由熟悉业务和合规要求的人员复核。对于会影响用户操作判断的按钮、警告和错误提示，应逐条确认后再发布。

---

## 导入翻译

导入适合在线下完成翻译，或从其他环境迁移翻译内容。正式环境导入前，建议先导出当前译文作为备份。
1. 在页面中选择目标 **语言**。
2. 根据需要选择 **组件** 或下级类型。
3. 点击 **导入**。
4. 按系统提示选择翻译文件并提交。
5. 导入完成后，使用关键字或组件筛选检查导入结果。
6. 点击 **保存** 或按系统提示完成提交。
7. 清除翻译缓存后，到相关页面验证译文显示。

导入前应确认文件与当前语言、组件范围匹配。导入错误语言或错误组件的文件，可能导致译文显示在不正确的业务位置。批量导入后，应重点抽查高频菜单、对象详情页、流程操作按钮、电子签名提示和错误提示。

## 导出翻译

### 导出未翻译内容

当需要集中补齐缺失译文时，使用 **导出未翻译**。
1. 选择目标 **语言**。
2. 选择需要处理的组件范围。
3. 点击 **导出未翻译**。
4. 如果按钮提供下拉选项，按需要选择导出格式或范围。
5. 将导出的文件交给翻译人员维护。
6. 翻译完成后通过 **导入** 回传。

导出未翻译内容只导出当前筛选范围内尚未维护译文的翻译项。导出前应确认筛选范围，避免遗漏需要一起处理的组件。

### 导出当前翻译内容

当需要备份、审阅或迁移已有译文时，使用 **导出**。
1. 设置语言、组件和关键字筛选条件。
2. 点击 **导出**。
3. 如果按钮提供下拉选项，选择需要的导出范围或格式。
4. 将导出的文件用于审阅、归档、差异比对或其他环境导入。

正式环境批量调整前，建议先导出当前翻译内容并保留导出时间、语言和组件范围，便于异常时比对和恢复。

## 清除翻译缓存

系统可能缓存已加载的翻译结果，以提高页面访问速度。以下情况建议清除翻译缓存：
- 批量导入翻译并保存后。
- 使用 AI 翻译并保存后。
- 手工修改关键页面文案并保存后。
- 保存成功但业务页面仍显示旧译文时。

操作步骤：
1. 确认当前译文已点击 **保存**。
2. 点击页面右上角 **清除翻译缓存**。
3. 返回相关业务页面并刷新浏览器页面。
4. 检查最新译文是否显示。

清除缓存只刷新翻译显示，不替代保存操作。未保存的表格修改不会因为清除缓存而生效。

---

## 生效范围

翻译控制台维护的是目标语言下的显示文案，不会修改用户个人语言偏好，也不会自动启用或停用语言。

| 项目 | 影响范围 |
|------|------------|
| 语言选择 | 决定本次维护的目标语言。用户能否选择该语言，取决于语言与地区设置中的语言启用状态。 |
| 译文修改 | 影响使用该语言时显示的界面文案、按钮、字段、提示语或帮助文本。 |
| 导入翻译 | 按导入文件内容批量更新译文，影响范围取决于文件和当前筛选条件。 |
| AI 翻译 | 对当前筛选范围生成译文，保存后写入系统翻译数据。 |
| 清除翻译缓存 | 使已保存译文重新加载，不改变译文本身。 |

如需启用或停用某种语言，或调整默认语言和语言显示顺序，请在 [语言与地区设置](23_%E8%AF%AD%E8%A8%80%E4%B8%8E%E5%9C%B0%E5%8C%BA%E8%AE%BE%E7%BD%AE.md) 中维护。

## 审计追踪

译文维护属于系统配置变更，建议在正式环境中记录变更原因、范围和复核结果。系统如已开启相关审计能力，可结合日志管理查看翻译控制台的操作记录。

| 日志属性 | 说明 |
|------------|------|
| 用户 | 执行编辑、导入、AI 翻译、保存或清除缓存的管理员账号 |
| 操作时间 | 操作发生的时间 |
| 操作模块 | 系统设置 - 翻译控制台 |
| 操作类型 | 编辑、导入、导出、AI 翻译、保存、清除缓存等 |
| 操作对象 | 语言、组件、组件下级类型、翻译项或缓存 |
| 描述 | 记录变更范围、关键译文变化或处理结果 |

如需排查译文变更或缓存刷新问题，请结合 [日志管理](04_%E6%97%A5%E5%BF%97%E7%AE%A1%E7%90%86.md) 查看对应时间段的操作记录。

## 管理建议
- 在测试环境完成翻译维护、导入和 AI 翻译复核后，再同步到正式环境。
- 对按钮、菜单、字段名、状态值等短文本建立统一术语表，避免同一术语在不同页面出现不同译法。
- 对帮助文本、提示语和错误信息，优先保证用户能理解下一步操作，不要只做逐字翻译。
- 批量导入前先导出当前翻译作为备份，便于异常时比对和恢复。
- 修改系统高频页面文案后，应通知业务管理员或关键用户抽查。
- 对 GxP 关键操作相关文案保留复核记录，尤其是电子签名、审计追踪、生命周期、权限、质量事件和培训相关提示。

## 常见问题

**Q：为什么选择组件后页面多了一个字段？** A：部分组件包含下级分类。选择这类组件后，系统会显示对应的下级类型字段，用于进一步缩小翻译范围。例如选择 **检查表类型** 后，可以继续选择 **帮助文本**。

**Q：保存后页面为什么仍然显示旧翻译？** A：可能是翻译缓存尚未刷新。确认译文已保存后，点击 **清除翻译缓存**，再刷新相关业务页面。

**Q：什么时候使用“导出未翻译”？** A：当需要补齐缺失译文时使用。该操作只导出当前筛选范围内未维护译文的内容，便于翻译人员集中处理。

**Q：AI 翻译可以直接发布吗？** A：不建议直接发布。AI 翻译应作为初稿，管理员需要复核术语、上下文和合规含义后再保存并发布。

**Q：翻译控制台可以启用新语言吗？** A：不可以。翻译控制台用于维护译文。语言启用、停用、默认语言和语言显示顺序应在 **语言与地区设置** 中维护。

**Q：导入翻译前为什么建议先导出备份？** A：批量导入会一次性影响多个翻译项。导入前保留备份，可以在发现译文错位、术语不一致或文件范围错误时进行比对和恢复。
