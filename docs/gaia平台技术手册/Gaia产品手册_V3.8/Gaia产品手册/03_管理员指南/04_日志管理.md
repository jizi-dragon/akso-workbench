# 日志管理
> 本文介绍如何查看和管理 Gaia 平台的审计日志与运维类日志，确保操作可追溯、运维可排查，满足 GxP 合规要求。   

---

## 概述

日志按用途分为两类：

| 分类 | 入口 | 说明 |
|------|------|------|
| **审计日志** | `管理控制台 &gt; 日志管理 &gt; 审计日志` | 面向合规审计，仅保留审计类日志 |
| **运维日志** | `管理控制台 &gt; 运维管理 &gt; 日志管理` | 面向运维排障与集成排查 |

### 审计日志（5 类）

| 日志类型 | 主要用途 |
|------------|------------|
| 系统审计日志 | 系统配置与管理端关键变更追踪（原「系统设置审计日志」） |
| 域设置审计日志 | 域设置下安全与认证类配置的字段级变更追踪 |
| 对象记录审计日志 | 业务对象操作与变更记录（已合并原操作日志内容） |
| 文件审计日志 | 文件操作及数字签署 |
| 登录审计日志 | 登录、登出及认证事件 |

### 运维日志（非审计类）

以下日志位于运维管理，不再出现在审计日志菜单中：

| 日志类型 | 主要用途 |
|------------|------------|
| 系统日志 | 运行时技术事件；支持按「受影响项」等列头筛选 |
| 组织架构同步日志 | 组织架构同步过程 |
| 外部协作任务日志 | 外部任务协作记录 |
| 文件上传日志 | 文件上传技术信息 |
| CA 签名日志 | CA 数字签名调用 |
| 数字身份认证日志 | 数字身份认证操作 |
| 文件转档日志 | 文件转档全过程 |
> 原独立「操作日志」菜单已取消，相关内容并入对应对象的对象记录审计日志，按时间统一查看。   

### 通用功能
- 审计类对象/登录/文件日志等支持按创建时间倒序查看（以页面为准）。
- 各日志页提供帮助说明，便于理解列含义与记录范围。
- 运维类日志普遍采用**列头筛选**（筛选控件在表头），支持多列条件组合。

## 审计日志

访问路径：

**管理控制台 \> 日志管理 \> 审计日志 \> \[选择具体日志类型\]**

### 审计日志覆盖范围

管理端以下模块中的操作会记入相应审计日志：

| 模块 | 说明 |
|------|------|
| **用户管理** | 用户、用户组、角色等的新增、修改、删除 |
| **业务管理** | 对象、选项、编号规则、联动、生命周期、流程、菜单、视图、翻译控制台等配置变更 |
| **域设置** | 安全策略、密码策略、LDAP、OAuth2.0、CA、网络访问规则、数字身份认证等（见域设置审计日志） |
| **日志管理** | 查看、导出审计日志等操作 |
| **运维管理 / 部署管理** | 相关配置与部署操作（记入系统审计日志等，以实际记录为准） |

### 1\. 系统审计日志

展示系统级配置与管理端关键变更，用于追踪管理员对系统配置的修改。页面标题与菜单名称为 **系统审计日志**（原「系统设置审计日志」）。

| 信息项 | 说明 |
|---------|------|
| 操作时间 | 配置变更发生的时间（含时区信息） |
| 用户 | 执行操作的用户 |
| 账号 | 操作用户的登录账号 |
| 受影响的项 | 被修改的配置项 |
| 操作类型 | 新增、修改、删除等 |
| 操作明细 | 具体变更内容（含字段旧值/新值，以页面为准） |

说明：
- 翻译控制台的新增、修改、删除、批量导入/导出等变更，统一记入系统审计日志。
- 业务管理菜单下的配置变更亦记入系统审计日志（以实际覆盖范围为准）。

| 功能 | 说明 |
|------|------|
| **导出** | 支持导出 CSV、PDF |
| **筛选** | 操作时间、用户、操作类型等 |

### 1A. 域设置审计日志

集中查看域设置相关配置变更，记录精确到字段级，页面能力与系统审计日志一致。

访问路径：`管理控制台 > 日志管理 > 审计日志 > 域设置审计日志`（位于系统审计日志下方）。

**记录范围**（域设置下配置项，含创建、编辑、删除及字段变更）：

| 域设置项 | 说明 |
|------------|------|
| 安全策略 | 策略创建、参数编辑、删除 |
| 密码策略设置 | 复杂度、有效期、锁定等 |
| LDAP 设置 | AD/OpenLDAP 对接配置 |
| OAuth2.0 策略设置 | SSO / OpenID Connect 等 |
| CA 策略设置 | 第三方 CA 电子签名集成 |
| 网络访问规则 | IP 黑白名单等 |
| 数字身份认证策略设置 | 数字身份认证相关策略 |

| 信息项 | 说明 |
|---------|------|
| 操作时间 | 变更时间（含时区） |
| 用户 / 账号 | 操作人 |
| 受影响的项 | 被修改的域设置项 |
| 操作类型 | 新增、修改、删除等 |
| 操作明细 | 字段级旧值 / 新值 |

| 功能 | 说明 |
|------|------|
| **导出** | 支持导出 CSV、PDF |
| **筛选** | 与系统审计日志一致（操作时间、用户、操作类型等） |

权限：受权限集中管理端日志相关权限控制，方式与系统审计日志相同。

### 2\. 对象记录审计日志

展示所有对象审计日志，记录业务对象的创建、修改、删除等操作。

| 信息项 | 说明 |
|---------|------|
| 操作时间 | 操作发生的时间（含时区信息） |
| 用户 | 执行操作的用户 |
| 账号 | 操作用户的登录账号 |
| 被代理人 | 工作代理期间以被代理人名义完成的操作，记录被代理人信息 |
| 受影响的项 | 被操作的对象（格式：\{对象名称\}:\{对象实例名称\}） |
| 操作类型 | 创建、更新、删除等 |

**详情页**可查看：事件描述、操作时间、操作者、操作类型、**字段值变化**（字段名称、原值、新值）。字段值的展示已优化，便于阅读和追溯。

**附件操作与在线预览**：
- 涉及附件添加、删除、下载、查看等操作时，事件描述中的附件文件名可点击。
- 点击后在当前审计上下文中**在线预览**文件内容，无需跳回对象详情页查找附件。
- 出于安全考虑，审计日志中的附件查看**仅支持预览，不提供下载**。
- 文件审计日志中同类附件操作同样支持点击预览（以页面实际能力为准）。

**相关对象附件审计**：
- 在主对象详情页的审计 / 日志区域，可查看**相关对象**上附件字段的上传、下载、删除、查看等操作记录，无需逐个打开相关对象详情页。
- 相关对象附件日志仍按权限与关系安全过滤；无权限查看的相关记录不会展示其附件审计。
- 本能力自功能上线后开始记录，不回溯迁移历史附件操作。

**与原操作日志的关系**：原「操作日志」中归属业务对象的记录，已并入本对象记录审计日志，按时间轴统一排列查看；系统不再提供独立的操作日志菜单。

**操作人显示规则**：
- 用户编辑保存、用户动作、对象动作等对实例字段的直接修改，显示为当前操作用户
- 进入动作、事件动作、定时作业、查找、公式、统计等对实例字段的修改，显示为 system
- 导入时的批量修改，操作人显示为导入操作人

**字段筛选**：在筛选条件中可选择"字段"筛选器，该筛选器依赖于对象，在选择对象后才有可选的值。选择后，查询结果中只出现该字段有变化情况的记录。在使用了字段筛选条件后，在详细面板中只显示此字段变化信息。

| 功能 | 说明 |
|------|------|
| **筛选** | 操作时间、用户、对象、事件、字段 |
| **排序** | 支持按创建时间倒序 |
| **导出** | 支持导出 CSV、PDF |

### 8\. 文件上传日志
> **入口变更**：请到 `管理控制台 > 运维管理 > 日志管理 > 文件上传日志` 查看。   

记录文件上传操作的详细技术信息，用于追溯和排查上传问题。

| 信息项 | 说明 |
|---------|------|
| 文件名称 | 上传文件的原始文件名，包括格式后缀 |
| 上传时间 | 上传发生的时间（格式：YYYY-MM-DD hh:mm:ss） |
| 桶名称 | 上传文件的 OSS 桶名称 |
| OSS 对象名称 | 上传文件的 OSS 对象名称，包含格式后缀 |
| 文件大小 | 文件大小，保留2位小数点，显示单位（B、KB、MB、GB等） |
| 分片数 | 文件分片数量 |
| MD5 | 文件的 MD5 值，由实体文件计算得出，同一个文件 MD5 值相同（系统中不允许重复上传相同文件，因此 MD5 是唯一的） |
| 来源 | 包括以下来源：<br>（1）文件：通过文件组件上传的文件<br>（2）附件：附件字段上传的文件<br>（3）其它：除文件与附件字段外上传的文件 |
| 是否解密 | 包括以下值：<br>（1）是：系统开启解密，且解密成功<br>（2）否：系统开启解密，且解密失败<br>（3）N/A：系统未开启解密 |

**记录范围**：系统中所有上传的文件都会记录文件上传日志，包括通过移动端和 PC 端上传的文件。如果系统开启了文档加解密，还需记录文件解密情况。

**解密功能**：当系统开启了文档加密功能后，解密按钮会显示。点击解密按钮后，系统会进行解密，解密成功后，对应数据的是否解密变成"是"。如果解密过程中出现错误，系统会提示解密失败及失败原因。

| 功能 | 说明 |
|------|------|
| **筛选** | 文件名称（模糊匹配）、上传时间、OSS 对象名称（精确匹配）、MD5（精确匹配）、来源、是否解密 |
| **解密** | 支持对已加密文件执行解密操作（仅在系统开启文档加密功能后显示） |
| **导出** | 支持导出 CSV、PDF |
| **排序** | 默认按上传时间倒序排列 |

## 记录级审计追踪

### 查看对象的操作历史

在任意对象记录的详情页，可以查看该记录的完整操作历史：

**记录详情页 \> 相关列表 \> 审计追踪**

显示内容：
- 谁在什么时间做了什么操作
- 字段级变更（修改前后的值）
- 状态变更历史
- 工作流操作记录
- **电子签名记录**：电子签名操作会同步记录到审计追踪日志中，便于完整追溯审批、签字等关键操作

### 审计追踪筛选功能

在对象或文档的审计追踪中，新增筛选条件：**字段**。可以选择该对象下所有的字段（单选）。选择后筛选该字段相关的变化情况。在使用了字段筛选条件后，在详细面板中只显示此字段变化信息。

### 审计追踪导出

支持从业务端实例数据的审计追踪面板导出日志，导出格式包括 CSV 和 PDF。导出的文件名格式为：`{对象名称}_{实例name}_{导出时间YYYYMMDDhhmmss}.{格式}`。

## 日志导出

### 导出权限

仅具有**审计管理员**角色的用户可以导出审计日志。

### 导出格式

| 格式 | 说明 |
|------|------|
| **CSV** | 便于在 Excel 中分析 |
| **PDF** | 带时间戳和签名，用于监管提交 |

导出的审计日志文件包含**用户**、**账号**列，操作时间显示时区信息。

### 导出限制
- CSV 格式：单次导出最多 1,000,000 条记录
- PDF 格式：单次导出最多 10,000 条记录
- 超大数据量请分批导出或联系系统管理员

### PDF 导出配置

PDF 导出支持设置页眉页脚和水印，同时可以设置导出日志的封面。

**导出日志页面模板**：
- 在业务管理 \> 模板管理中可配置"导出日志页面模板"模板类型
- 此模板在日志列表【导出PDF】动作时使用
- 可以不设置，不设置时将不应用 PDF 模板
- 系统最多只支持配置一个启用的导出日志页面模板

**导出日志封面页面模板**：
- 在业务管理 \> 模板管理中可配置"导出日志封面页面模板"模板类型
- 此模板在日志列表【导出PDF】动作时使用
- 可以不设置，不设置时将不应用封面模板
- 系统最多只支持配置一个启用的导出日志封面页面模板

**封面模板支持的全局变量**：
- `${auditTrailName}`：日志类型名称（如对象审计日志、登录审计日志）
- `${eventFilterList}`：操作类型过滤条件列表
- `${exportDate}`：导出日期（用户时区）
- `${exportDateTime}`：导出时间（用户时区）
- `${exportEndDate}`：导出日志截止时间
- `${exportStartDate}`：导出日志开始时间
- `${exportedByUsername}`：导出用户名
- `${exportedByName}`：导出用户姓名
- `${object}`：对象名称（仅对象记录审计日志）
- `${userFilterList}`：用户过滤条件列表

### 导出入口

日志有两个导出入口：
1. 管理端日志管理下所有类型的日志列表
2. 业务端实例数据审计追踪面板日志列表

### 导出文件名格式
- **管理端**：`{日志类型}_{导出时间YYYYMMDDhhmmss}.{格式}`
- **业务端**：`{对象名称}_{实例name}_{导出时间YYYYMMDDhhmmss}.{格式}`

## 转档日志

转档日志记录文件归档（转档）的全过程，确保数据归档的完整性和可追溯性。
> **入口变更**：请到 `管理控制台 > 运维管理 > 日志管理 > 文件转档日志` 查看（不再位于审计日志下的独立「转档日志」一级入口）。   

### 13\. 文件转档日志

记录文件从活动状态转为归档状态的全过程，确保数据归档的完整性和可追溯性。

| 信息项 | 说明 |
|---------|------|
| 转档类型 | 转档操作类型 |
| 状态 | 转档成功或失败 |
| 文档名称 | 被转档的文档名称 |
| 实例 ID | 文档实例唯一标识 |
| 异常消息 | 转档失败时的异常信息 |
| 创建时间 | 转档记录创建时间 |

| 功能 | 说明 |
|------|------|
| **筛选** | 标题、实例 ID |
| **排序** | 支持按创建时间倒序 |

## 日志保留策略

| 日志类型 | 保留期限 |
|------------|------------|
| **系统审计日志** | 永久保留 |
| **域设置审计日志** | 永久保留 |
| **对象记录审计日志** | 永久保留 |
| **登录审计日志** | 3 年 |
| **文件审计日志** | 永久保留 |
| **组织架构同步日志** | 1 年 |
| **外部协作任务日志** | 1 年 |
| **文件上传日志** | 3 年 |
| **数字身份认证日志** | 3 年 |
| **CA 签名日志** | 永久保留 |
| **文件转档日志** | 永久保留 |
| **系统日志** | 由部署环境配置 |
| **第三方接口请求日志** | 由部署环境配置 |
| **第三方接口接收日志** | 由部署环境配置 |
> 🔒 **合规要点**：审计日志一经记录不可删除、不可修改，确保数据完整性符合 21 CFR Part 11 要求。
