# 水印设置
> 本文面向系统管理员和安全管理员，介绍 Gaia 平台页面水印的配置入口、字段含义、生效范围和权限要求。页面水印用于在系统页面上显示用户与时间等识别信息，帮助降低截图、拍照和页面外传带来的信息泄露风险。   

---

## 1\. 适用范围

水印设置是系统级配置。开启后，水印会在 Web 端和移动端页面同时生效，用于在用户访问系统页面时显示可追溯的水印内容。

页面水印适用于系统页面和弹出层。登录页、隐私页等允许匿名访问的页面通常不显示水印。页面水印只作用于页面展示，不会写入系统中上传或下载的文件内容。

---

## 2\. 配置入口

访问路径：`管理端 > 系统设置 > 水印设置`

进入页面后，系统默认显示查看模式。具备编辑权限的管理员可以点击页面右上角的 `编辑` 进入编辑模式；只有查看权限时，页面不显示编辑按钮。

---

## 3\. 查看页面

查看模式用于确认当前水印配置和预览效果。页面会显示水印状态，以及在水印开启时生效的水印内容、字体、颜色、大小、透明度、旋转角度和密度等信息。

| 字段 | 说明 |
|------|------|
| 水印状态 | 显示当前是否启用页面水印。关闭时，页面不显示后续水印属性。 |
| 水印内容 | 显示当前配置的水印文本和变量。 |
| 对齐方式 | 显示多行水印内容的文本对齐方式。 |
| 水印字体 | 显示水印使用的字体。 |
| 水印颜色 | 显示水印文字颜色。 |
| 水印大小 | 显示水印字号，单位为 px。 |
| 透明度 | 显示水印透明度，单位为 `%`。 |
| 旋转角度 | 显示水印旋转角度，单位为度。 |
| 水印密度 | 显示水印在页面中的行列密度。 |
| 水印预览 | 按当前配置展示水印效果，便于保存前后核对。 |

---

## 4\. 配置水印

### 4.1 操作步骤
1. 进入 `管理端 > 系统设置 > 水印设置`。
2. 点击 `编辑`。
3. 勾选 `水印状态`，开启页面水印。
4. 在 `水印内容` 中输入固定文本，或插入当前用户姓名、账号、当前时间、当前业务单元、换行符和空格等变量。
5. 按需要设置对齐方式、字体、颜色、大小、透明度和旋转角度。
6. 选择水印密度；如选择 `自定义`，继续填写 Web 端和移动端的行数、列数。
7. 在 `水印预览` 中确认显示效果。
8. 点击 `保存`，使配置生效。

点击 `取消` 会放弃本次编辑，页面返回查看模式并保留原配置。

### 4.2 配置项说明

| 配置项 | 说明 | 默认值 / 限制 |
|---------|------|------------------|
| 水印状态 | 控制是否启用页面水印。开启后显示并允许维护下方水印属性；关闭后不显示水印，也不显示下方配置项。 | 默认未开启 |
| 水印内容 | 配置页面上显示的水印文本。支持固定文本和系统变量，最多 500 个字符。开启水印时必填。 | 支持当前用户姓名、账号、当前时间、当前业务单元、换行符和空格 |
| 对齐方式 | 当水印内容分多行显示时，控制每行文本的对齐方式。 | 默认居中对齐 |
| 水印字体 | 控制水印文字使用的字体。实际显示效果取决于浏览器和设备是否支持该字体。 | 默认微软雅黑 |
| 水印颜色 | 控制水印文字颜色。 | 默认黑色 |
| 水印大小 | 控制水印字号。 | 支持 1-100 的整数，单位 px；默认 14 |
| 透明度 | 控制水印可见程度。数值越小越浅，数值越大越明显。 | 支持 1-100 的整数，单位 `%`；默认 50% |
| 旋转角度 | 控制水印文字倾斜角度。 | 支持 -360 至 360 的整数；默认 45 |
| 水印密度 | 控制页面中水印的行列分布。 | 默认标准 |
| 水印密度详细设置 | 仅在水印密度选择 `自定义` 时可编辑，用于分别设置 Web 端和移动端的行数、列数。 | 每个输入框支持 1-10 的整数 |
| 水印预览 | 根据当前编辑内容实时展示水印效果。 | 配置变化后自动更新 |
> \[!TIP\]
水印内容建议包含用户身份和时间信息，例如当前用户姓名、账号和当前时间。这样在截图或拍照外传时，管理员可以更快定位来源。   

---

## 5\. 水印密度

水印密度决定水印在页面中的分布。Web 端和移动端屏幕比例不同，同一个密度选项在两端对应的行列数不同。

| 密度 | Web 端显示 | 移动端显示 | 说明 |
|------|-------------|---------------|------|
| 稀疏 | 1 行 1 列 | 1 行 1 列 | 页面干扰最小，适合只需要低频标识的场景。 |
| 标准 | 3 行 3 列 | 3 行 1 列 | 默认推荐配置，兼顾可读性和可追溯性。 |
| 密集 | 4 行 4 列 | 4 行 2 列 | 水印覆盖更明显，适合敏感数据页面较多的环境。 |
| 自定义 | 由管理员填写 | 由管理员填写 | 可分别配置 Web 端和移动端的行数、列数。 |

选择 `自定义` 时，系统会默认带入标准密度的行列值。管理员可以按实际页面宽度和水印内容长度调整，避免水印过密影响正常阅读。

---

## 6\. 生效行为

### 6.1 开启水印

开启 `水印状态` 并保存后，系统按当前配置在页面和弹出层显示水印。水印状态会同时作用于 Web 端和移动端，普通用户无需刷新配置或执行额外操作。

### 6.2 关闭水印

关闭 `水印状态` 并保存后，系统页面不再显示水印。关闭状态下，水印内容、样式和密度配置不会在页面上生效。

### 6.3 实时预览

编辑水印内容、字体、颜色、大小、透明度、角度或密度时，水印预览会随配置变化更新。保存前建议先检查预览，确认水印既能识别来源，又不会遮挡主要业务内容。

---

## 7\. 权限要求

水印设置由权限集中的管理端设置权限控制。

| 权限项 | 控制范围 |
|---------|------------|
| 水印设置:全部 | 授予水印设置的全部权限。勾选后，系统会自动包含查看和编辑权限。 |
| 水印设置:查看 | 允许进入水印设置页面并查看当前配置。仅具备该权限时，不显示编辑按钮。 |

建议只向系统管理员、安全管理员或经过授权的配置负责人授予编辑权限。水印属于全局安全设置，修改前应确认业务影响，并在必要时先在测试环境验证显示效果。

---

## 8\. 注意事项
- 水印设置是全局配置，开启或关闭后会影响 Web 端和移动端页面。
- 页面水印用于页面展示防护，不会自动写入导入、上传、下载或导出的文件内容。
- 水印内容过长、字号过大或密度过高时，可能影响页面阅读。建议在典型页面和移动端页面上确认效果后再用于生产环境。
- 透明度不宜设置过低，否则截图中可能难以识别；也不宜设置过高，以免遮挡业务字段。
- 自定义密度的行数、列数应结合屏幕尺寸设置。移动端建议避免过高列数，减少文字重叠。

---

## 9\. 常见问题

**Q：开启水印后，哪些页面会显示水印？** A：除登录页、隐私页等匿名访问页面外，系统页面和弹出层通常都会显示水印，移动端页面也会按移动端密度规则显示。

**Q：水印会写入下载的文件吗？** A：不会。页面水印只作用于页面显示，不会改变系统中的文件内容，也不会自动加到下载文件中。

**Q：为什么关闭水印后看不到其他配置项？** A：水印状态关闭时，下方水印内容、样式、密度等配置不会生效，页面会隐藏这些配置项，避免误以为仍在显示水印。

**Q：只有查看权限的管理员能修改水印吗？** A：不能。只有 `水印设置:查看` 权限时可以查看当前配置；需要同时具备编辑权限才会显示编辑入口并允许保存修改。

**Q：水印内容可以显示当前用户信息吗？** A：可以。水印内容支持插入当前用户姓名、账号、当前时间、当前业务单元等变量，适合用于追溯截图来源。
