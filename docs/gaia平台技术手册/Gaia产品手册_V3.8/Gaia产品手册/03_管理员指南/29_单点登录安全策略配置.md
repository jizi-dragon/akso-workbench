# 单点登录安全策略配置

### 一、安全策略配置

#### 配置路径

1、登录系统，打开管理端-系统设置-安全策略

2、选择单点登录安全策略——启用

![](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl659QxJBdKOke/img/445f1d33-7ec8-4293-9530-f09fba011df2.png?Expires=1789982797&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=FpcEituj7I0czt21Jfp1AYEW1iQ%3D "")

3、点击**单点登录安全策略**，进入编辑模式。下方的安全设置—策略类型，选择OAuth2.0策略；

配置策略，选择单点登录安全策略

![](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl659QxJBdKOke/img/015e423e-04c3-4139-8c8e-a2d3c087a8ce.png?Expires=1789982797&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=pn%2Fwn8xqfkOw9QewwJZndOk%2BJ5I%3D "")

4、打开Oauth2.0策略设置，点击单点登录安全策略（sso\_security\_policy\_config\_\_ak）

**配置详情**

1、服务商：兼容自建服务平台的配置，无则不填

2、授权中心的基地址：授权中心地址

3、授权地址：跳转到登录页面的路由地址，只需要填写路由部分

4、应用ID：授权中心创建的应用Id

5、应用密钥：授权中心创建的应用密钥

6、授权类型：AuthorizationCode

7、授权类型Code：authorization\_code

7、响应类型：Code

8、Token端点：获取授权中心token的路由地址

9、用户信息端点：获取授权中心用户信息的路由地址

10、Scope：查询授权中心用户信息的字段范围（openid username），自建平台按需传递

11、回调地址：http://test.aksoegmp.com/sso-login?\*

12、用户作用域名称：与sso授权中心用户信息的账号字段映射（默认值：username）

其余参数使用系统生成的默认内容

### 二、退出时同步结束 SSO 会话

启用单点登录后，用户通过 SSO 进入平台再执行退出时，系统会在清除平台本地会话的同时，按 SSO 配置联动结束统一身份认证平台侧的 SSO 会话（需已配置有效的 SSO 注销地址；未配置时仅清除平台本地会话）。

联动退出生效后，用户再次访问平台需重新完成企业认证，不会因 SSO 会话仍有效而自动登录。

最终用户操作说明见 [登录系统](../02_%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97/01_%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/01_%E7%99%BB%E5%BD%95%E7%B3%BB%E7%BB%9F.md) 中的「主动退出登录」。管理员配置 SSO 策略后，建议使用测试账号验证：SSO 登录 → 退出 → 再次访问需重新认证。

### 三、相关说明
- 登录页是否展示单点登录入口，取决于用户安全策略是否启用对应 SSO 策略，详见 [用户安全策略](17_%E7%94%A8%E6%88%B7%E5%AE%89%E5%85%A8%E7%AD%96%E7%95%A5.md)。
