# 用户安全策略
> 本文面向 Gaia 平台系统管理员和安全管理员，介绍如何创建、维护和启用用户安全策略。用户安全策略是系统级认证配置，决定登录页面展示用户名密码、LDAP 或单点登录等认证入口，也影响电子签名时的身份验证方式。   

---

## 概述

用户安全策略用于规定系统登录入口和身份认证规则。管理员启用不同类型的安全策略后，登录页面会展示对应的认证方式，例如用户名密码登录、LDAP 登录或单点登录按钮。

典型访问路径：

**管理端 \> 系统设置 \> 域设置 \> 安全策略**

系统登录页面会根据已启用的安全策略展示可用认证入口：启用基础安全策略时，用户可以使用用户名和密码登录；启用 AD 域安全策略时，系统使用 LDAP 完成账号认证；启用单点登录策略时，登录页面显示单点登录按钮，用户点击后跳转到对应身份提供方完成认证。若全站只允许一种认证方式，也可以结合系统登录模式做统一配置。

| 认证类型 | 适用场景 | 登录方式 | 是否支持重置密码 | 电子签名验证 |
|------------|------------|------------|------------------------|------------------|
| 密码验证 | 基础账号登录、外部协作用户、`admin` 账号 | 输入用户名和密码 | 支持 | 与登录验证一致 |
| LDAP 验证 | 对接 AD 域、OpenLDAP 等企业目录 | 通过 LDAP 服务验证账号 | 取决于策略配置和对接能力 | 与登录验证一致 |
| 单点登录验证 | 对接 SAML、OAuth 2.0、OpenID Connect 等统一认证平台 | 跳转到 SSO 平台认证 | 不支持 | 与登录验证一致，也可配置在 iFrame 或弹出层中完成签名验证 |
> \[!IMPORTANT\]
安全策略会直接影响用户能否登录系统。生产环境调整前，应先确认至少保留一个可用的管理员登录方式，并在测试环境完成登录、自动退出、电子签名和账号锁定场景验证。   

## 登录入口展示逻辑

安全策略按系统级配置生效。登录页面不会先读取某个用户关联的安全策略，而是根据当前启用的策略和系统登录模式展示可用登录入口。

| 已启用策略 | 登录页面表现 | 说明 |
|---------------|------------------|------|
| 基础安全策略 | 显示用户名和密码登录入口 | 适用于本地账号、外部协作用户和应急管理员登录 |
| LDAP 验证策略 | 允许通过 LDAP 服务验证账号 | 适用于已对接 AD 域或 OpenLDAP 的环境 |
| 单点登录策略 | 显示单点登录按钮，或按配置自动跳转到 SSO 平台 | 适用于 SAML、OAuth 2.0、OpenID Connect 等统一身份认证平台 |

用户登录时，系统按以下逻辑处理：
1. 根据已启用的安全策略和系统登录模式展示登录入口。
2. 用户选择用户名密码、LDAP 或单点登录入口。
3. 系统按所选认证方式完成账号校验。
4. 验证成功后进入系统；验证失败时按对应策略处理错误次数、锁定或重试。

## 页面结构

安全策略页面位于 **管理端 \> 系统设置 \> 域设置 \> 安全策略**。页面主体是安全策略列表，管理员可以在这里查看当前系统启用了哪些登录认证方式，并进入具体策略进行维护。

列表重点关注三类信息：
- **策略是什么**：通过“名称”识别策略，例如 **基础安全策略**、**AD 域验证安全策略**、**单点登录安全策略**。名称为蓝色链接，点击后进入该策略详情。
- **策略是否生效**：通过“状态”判断策略是否启用。状态为 **启用** 时，该策略可参与登录入口展示或认证流程。
- **策略如何认证**：通过“来源”和“认证类型”判断策略性质。来源包括系统、标准和自定义；认证类型包括密码验证、LDAP 验证和单点登录。

页面右上角的 **创建** 用于新建安全策略。进入创建页后，需要先选择认证类型，再填写名称、Code、状态、描述和对应认证设置。列表最右侧的齿轮按钮用于维护单条策略，可进入查看、编辑、启用、停用或删除等操作；实际可用操作取决于策略来源、策略状态和当前账号权限。

安全策略列表中内置以下类型的策略：
- **基础安全策略**：系统来源，认证类型为密码验证。启用后，登录页面可使用用户名和密码登录。该策略属于系统内置策略，可以编辑部分设置，但不可删除，也不建议停用，以免影响管理员应急登录入口。
- **AD 域验证安全策略**：标准来源，认证类型为 LDAP 验证。启用后，系统可通过 AD 域或其他 LDAP 服务完成账号认证。
- **单点登录安全策略**：标准来源，认证类型为单点登录。启用后，登录页面显示单点登录按钮；如果策略开启自动跳转，用户访问登录页时会直接跳转到 SSO 平台。

如果某条策略的“描述”为空，列表中该列不会显示额外说明。建议为自定义策略补充清晰描述，方便后续管理员判断策略用途。

## 创建安全策略

### 操作步骤
1. 进入 **管理端 \> 系统设置 \> 域设置 \> 安全策略**。
2. 点击 **创建**。
3. 选择认证类型：**密码验证**、**LDAP 验证** 或 **单点登录验证**。
4. 填写名称、Code、状态和描述。
5. 按认证类型完成对应的安全设置。
6. 点击 **保存**。
7. 保存后到登录页面验证对应认证入口和登录流程是否符合预期。

保存成功后，新策略出现在安全策略列表中。策略只有处于 **启用** 状态时才会影响登录页面和登录认证流程。

### 基本字段

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 名称 | 是 | 安全策略的显示名称，用于在安全策略列表、详情页和审计记录中识别该策略。建议使用能说明用途的名称，例如“外部协作用户密码登录”或“内部员工 AD 域登录”。 |
| Code | 是 | 安全策略的唯一标识。创建时输入主体编码，系统会在字段末尾显示 `&#95;&#95;c` 后缀；保存后 Code 通常不再修改，后续配置引用和审计记录会使用该标识。 |
| 状态 | 是 | 选择策略创建后的状态。选择 **启用** 时，保存后该策略可参与登录入口展示或认证流程；选择 **停用** 时，策略仅保存为配置记录，不影响当前登录方式。 |
| 描述 | 否 | 记录策略用途、适用用户范围、维护负责人或变更背景。描述会帮助后续管理员判断该策略是否仍需要启用。 |
| 来源 | 否 | 只读字段。新建自定义安全策略时，创建页显示为 **N/A**；保存后系统会按策略来源记录为系统、标准或自定义等类型。 |

### 安全设置字段

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 认证类型 | 是 | 选择该安全策略使用的认证方式。可选项通常包括密码验证、LDAP 验证和单点登录验证。认证类型会决定下方可选择的配置策略范围。 |
| 策略类型 | 取决于认证类型 | 认证类型为 **单点登录** 时显示并必填，用于选择单点登录协议或策略类别，例如 **OAuth2.0策略**。选择后，配置策略下拉框只显示该策略类型下可用的配置。 |
| 配置策略 | 是 | 选择与认证类型匹配的具体配置。选择 LDAP 验证时，应选择已配置并验证通过的 LDAP 策略；选择单点登录验证时，应先选择策略类型，再选择对应的 SSO 配置策略；选择密码验证时，应选择适用的密码策略或基础认证配置。 |
| 电子签名策略 | 否 | 选择电子签名时使用的身份验证策略。若业务流程需要电子签名，应选择与登录认证方式和合规要求一致的签名策略；未选择时，相关签名验证行为以系统默认配置或流程配置为准。 |
| 是否自动跳转 | 取决于认证类型 | 认证类型为 **单点登录** 时显示。关闭时，登录页按系统登录入口规则展示单点登录按钮；开启时，用户访问登录页或非匿名页面会按该策略跳转到 SSO 平台。正式启用前应确认管理员登录入口仍可使用。 |
> \[!TIP\]
建议在描述中写明策略用途，例如“内部员工 AD 域登录”“外部供应商密码登录”“Azure AD SSO 登录”。后续排查登录问题时，管理员可以更快判断当前登录页面入口和认证流程是否符合预期。

## 密码验证策略

密码验证策略适用于使用 Gaia 本地账号密码登录的用户。该类型支持密码重置，常用于基础安全策略、外部协作用户或应急管理员账号。

可维护内容通常包括密码复杂度、密码有效期、密码历史、连续错误锁定、自动解锁、登录有效时长、自动锁屏和验证码等。具体参数请结合系统设置中的密码策略配置查看。

密码类安全策略需要先完成密码策略参数维护，再在创建安全策略时选择对应配置。密码复杂度、有效期、锁定规则等配置项的填写方式，参见 [密码策略](25_%E5%AF%86%E7%A0%81%E7%AD%96%E7%95%A5.md)。

### 使用建议

| 场景 | 建议 |
|------|------|
| 外部协作用户 | 使用独立密码策略，避免外部用户依赖客户内部目录服务 |
| `admin` 账号 | 保留密码验证方式，并定期更新强密码 |
| 生产环境 | 设置合理的连续错误锁定和自动解锁规则，降低暴力尝试风险 |
| GxP 场景 | 密码有效期、密码历史和电子签名验证应符合客户合规要求 |

提高复杂度、缩短有效期或调整锁定规则前，建议提前通知用户，避免集中出现密码过期、登录失败或账号锁定。

## LDAP 验证策略

LDAP 验证策略用于对接企业目录服务，例如 AD 域或 OpenLDAP。用户登录时，系统通过关联的 LDAP 设置向目录服务发起认证。

创建 LDAP 验证策略时，需要选择可用的 LDAP 策略。LDAP 策略本身通常包含服务器地址、端口、基础 DN、用户资源 DN、过滤器、用户映射字段、SSL 连接和同步规则等配置。

AD 域场景下，建议先完成 LDAP 连接、用户映射和同步规则配置，再回到安全策略中选择该 LDAP 配置策略。LDAP 安全策略的字段填写和 AD 域对接步骤，参见 [LDAP 安全策略配置（AD域）](28_LDAP%E5%AE%89%E5%85%A8%E7%AD%96%E7%95%A5%E9%85%8D%E7%BD%AE%EF%BC%88AD%E5%9F%9F%EF%BC%89.md)。

### 操作要点

| 配置项 | 说明 |
|---------|------|
| LDAP 策略 | 选择已经配置并测试通过的 LDAP 设置 |
| 是否支持重置密码 | 取决于 LDAP 对接能力和策略配置；未支持时，用户应到企业目录中修改密码 |
| 用户映射 | 确认登录账号能正确匹配 Gaia 用户资料 |
| 状态 | LDAP 验证策略启用后，登录页可使用 LDAP 认证能力 |

启用前应完成 LDAP 连接测试，并使用测试账号验证登录、密码错误、目录用户停用和用户资料同步等场景。

## 单点登录验证策略

单点登录验证策略用于接入企业统一身份认证平台。用户访问系统时，通常会跳转到 SSO 平台完成认证，认证成功后再返回 Gaia。

单点登录策略可关联以下配置：

| 配置 | 作用 |
|------|------|
| OAuth 2.0 / OpenID Connect 策略 | 规定 OAuth 2.0 或 OIDC 登录认证方式 |

单点登录验证不支持在 Gaia 内直接重置密码。用户密码、MFA 或账号状态通常由企业身份提供商维护。

创建单点登录安全策略前，应先完成 SAML、OAuth 2.0 或 OpenID Connect 等身份提供商配置，并确认回调地址、证书和用户映射规则可用。单点登录策略的配置步骤和字段说明，参见 [单点登录安全策略配置](29_%E5%8D%95%E7%82%B9%E7%99%BB%E5%BD%95%E5%AE%89%E5%85%A8%E7%AD%96%E7%95%A5%E9%85%8D%E7%BD%AE.md)。

### 自动跳转到 SSO 平台

单点登录类型策略可配置自动跳转。该开关默认关闭。

| 状态 | 行为 |
|------|------|
| 关闭 | 用户访问登录页时，按系统登录页规则展示登录入口 |
| 开启 | 用户访问登录页或非匿名页面时，系统按单点登录策略跳转到 SSO 平台 |

开启后，系统按以下规则处理：
1. 用户直接访问登录页时，会跳转到 SSO 平台；登录成功后进入首页。
2. 用户访问非匿名页面时，会跳转到 SSO 平台；登录成功后返回登录前访问的页面。
3. 用户访问可匿名访问页面时，不触发 SSO 跳转。
4. `admin` 账号因登录过期或长时间未操作返回登录时，会回到管理员登录页，不跳转到 SSO 平台。
5. 非 `admin` 账号自动退出后重新认证时，会跳转到 SSO 平台。

可匿名访问页面通常包括隐私协议页面和管理员登录页。管理员登录页用于保留直接登录入口，不受自动跳转设置影响。
> \[!IMPORTANT\]
同一系统中只能有一个单点登录策略开启自动跳转。保存、编辑或启用策略时，如果系统已存在其他开启自动跳转的单点登录策略，会提示“已存在其它单点登录策略开启了自动跳转”。

## 验证安全策略生效

创建或调整策略后，应从登录页面验证系统是否按预期展示认证入口，并确认对应认证流程可以正常完成。

### 操作步骤
1. 退出当前登录会话，或使用无会话的浏览器窗口访问登录页面。
2. 确认登录页面是否展示预期入口，例如用户名密码输入框、LDAP 登录入口或单点登录按钮。
3. 使用测试账号完成对应认证流程。
4. 若启用了单点登录自动跳转，验证普通登录访问是否会跳转到 SSO 平台，并确认管理员登录入口仍可使用。
5. 验证登录失败、账号锁定、自动退出和电子签名等相关场景是否符合预期。

若登录页面没有出现预期入口，应检查对应安全策略是否启用、LDAP 或 SSO 配置是否完整，以及系统登录模式是否限制了可用认证方式。

## 启用、停用和删除

| 操作 | 结果 | 注意事项 |
|------|------|------------|
| 启用 | 策略对应的认证方式可以在登录流程中使用 | 启用前应确认关联配置可用 |
| 停用 | 策略不再生效 | 停用前应确认系统仍保留可用的登录入口 |
| 删除 | 删除策略记录 | 仅适用于允许删除的自定义策略；基础安全策略不可删除 |
| 编辑 | 修改策略基本信息和安全设置 | 调整认证类型或关联配置后，应重新验证登录入口和认证流程 |

停用或删除策略前，建议先确认登录页面仍保留至少一种可用认证方式，尤其要保留可进入管理端的管理员入口。否则后续登录或重新认证时可能无法进入系统。

## 变更前检查

在正式环境修改安全策略前，建议完成以下检查：

| 检查项 | 建议 |
|---------|------|
| 管理员入口 | 确认 `admin` 或至少一个系统管理员账号仍可通过基础安全策略或应急入口登录 |
| 登录入口 | 确认本次调整后登录页面会展示哪些入口，是否需要隐藏或保留用户名密码登录 |
| SSO 配置 | 验证 SAML、OAuth 2.0 或 OIDC 配置、回调地址和证书有效性 |
| LDAP 配置 | 验证服务器连接、账号映射、过滤器和 SSL 配置 |
| 电子签名 | 验证登录认证方式变更后，电子签名验证仍符合流程和合规要求 |
| 回退方案 | 记录修改前配置，准备可恢复的基础安全策略、系统登录模式和应急管理员账号 |

涉及生产环境或客户统一身份认证时，建议先在测试环境完成全流程验证，再安排变更窗口。

## 审计追踪

安全策略的创建、编辑、启用、停用和删除操作应记录操作日志，便于追踪认证配置变更。

| 日志属性 | 说明 |
|------------|------|
| 用户 | 执行操作的管理员账号 |
| 操作时间 | 操作发生时间 |
| 操作模块 | 系统设置 - 安全策略 |
| 操作类型 | 创建、编辑、启用、停用或删除 |
| 操作对象 | 安全策略名称和 Code |
| 描述 | 记录关键字段或安全设置的变更 |

排查登录异常时，可结合 [日志管理](04_%E6%97%A5%E5%BF%97%E7%AE%A1%E7%90%86.md) 查看安全策略变更记录，并与用户登录日志、SSO 或 LDAP 服务日志交叉核对。

## 权限要求

管理员需要具备安全策略相关权限，才能查看或维护策略。

| 权限 | 说明 |
|------|------|
| 安全策略：查看 | 查看安全策略列表和详情 |
| 安全策略：全部 | 创建新的安全策略，修改安全策略，包括启用、停用和调整认证设置，删除允许删除的自定义安全策略 |

若当前账号只有查看权限，页面会显示策略信息，但不会显示可用的创建、编辑、删除入口，或操作时被系统拒绝。

## 常见问题

**Q：用户为什么被跳转到 SSO 平台，无法看到账号密码登录页？** A：系统可能启用了单点登录自动跳转，或系统登录模式已配置为 SSO。管理员可以通过管理员登录页进入系统，检查单点登录策略和系统登录模式。

**Q：为什么登录页面仍然显示用户名密码入口？** A：系统启用了基础安全策略，或系统登录模式允许用户名密码登录。若需要只允许统一身份认证，应检查基础安全策略、单点登录策略和系统登录模式的组合配置。

**Q：停用安全策略会立即影响用户吗？** A：会影响后续登录认证。已登录用户是否立即退出取决于当前会话机制，但下次登录或重新认证时会按最新策略判断。

**Q：单点登录策略可以开启多个自动跳转吗？** A：不可以。同一系统只能有一个单点登录策略开启自动跳转，避免系统无法判断应跳转到哪个身份提供商。

**Q：LDAP 用户可以在 Gaia 中重置密码吗？** A：取决于 LDAP 对接能力和策略配置。多数情况下，LDAP 用户应在企业目录或统一账号平台中修改密码。
