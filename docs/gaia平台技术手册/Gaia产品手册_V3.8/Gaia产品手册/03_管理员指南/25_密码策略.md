# 密码策略
> 本文面向 Gaia 平台系统管理员，说明如何查看和维护密码策略设置。密码策略会影响本地账号的初始密码、密码复杂度、密码到期提醒、登录失败锁定、会话超时以及多因子认证方式。   

---

## 概述

密码策略设置用于统一控制用户登录和密码使用规则。管理员可以在同一页面查看当前策略，并通过 **编辑** 调整密码策略、登录策略和多因子认证设置。
> \[!NOTE\]
本地密码策略作用于平台本地账号。域账号（LDAP / AD）的密码复杂度、有效期和历史密码等规则由域侧（AD 或企业目录）管理，不以本页本地密码策略为准。域账号的密码维护说明另见 [LDAP 安全策略配置（AD域）](28_LDAP%E5%AE%89%E5%85%A8%E7%AD%96%E7%95%A5%E9%85%8D%E7%BD%AE%EF%BC%88AD%E5%9F%9F%EF%BC%89.md)。   

典型访问路径：

**管理端 \> 系统设置 \> 密码策略设置**

页面顶部提供以下操作：

| 操作 | 说明 |
|------|------|
| 返回 | 返回上一层设置页面，不修改当前策略 |
| 编辑 | 进入编辑状态，允许修改各折叠区中的策略字段 |
| 保存 | 保存本次修改，后续登录、修改密码、重置密码等场景按新策略执行 |
| 取消 | 放弃本次修改并回到详情页 |
> \[!IMPORTANT\]
密码策略会直接影响用户能否登录系统。生产环境调整前，建议先使用测试账号验证登录、修改密码、密码错误锁定、自动解锁和重新认证等流程。   

---

## 页面结构

密码策略设置页面按折叠区组织。管理员可以展开对应区域查看或维护配置。

| 区域 | 说明 |
|------|------|
| 详情 | 查看策略基础信息。该区域用于确认当前配置对象，不承载密码规则本身 |
| 密码策略 | 维护初始密码、复杂度、有效期、历史密码、重置密码等规则 |
| 登录策略 | 维护登录失败锁定、自动退出、自动锁屏、图片验证码和单一设备登录等规则 |
| 多因子认证(MFA)设置 | 维护手机认证、邮箱认证等二次认证方式 |

## 密码策略

密码策略区域用于控制用户密码本身的生成、校验和使用期限。

| 配置项 | 说明 |
|---------|------|
| 用户初始密码 | 新建用户或管理员重置密码后使用的初始密码。页面以掩码显示，避免明文暴露 |
| 密码复杂要求 | 勾选后，新密码必须包含对应字符类型。可选项包括数字、大写字母、小写字母和特殊字符 |
| 密码最小长度 | 限制新密码的最短字符数。当前页面显示为 6 |
| 密码不符合要求强制修改密码 | 启用后，用户当前密码不符合策略要求时，需要按新规则修改密码 |
| 密码有效期(天) | 控制密码可连续使用的天数。选择“设置有效期”后，用户密码到期前后会按策略触发提醒或限制 |
| 密码修改提醒(天) | 在密码到期前提前提醒用户修改密码。当前页面显示为到期前提醒 3 天 |
| 不活跃用户锁定(天) | 控制长期未登录或未使用系统的账号是否自动锁定。选择“不限制”时，不按不活跃天数锁定账号 |
| 自动锁定后允许用户重新认证 | 启用后，用户在自动锁定后可以按系统提示重新认证，继续当前会话或操作 |
| 禁用历史密码 | 启用后，用户不能重复使用近期使用过的密码。选择“不禁用”时，不校验历史密码重复 |
| 强制修改初始密码 | 启用后，用户使用初始密码登录后必须设置个人密码 |
| 允许记住账户 | 启用后，登录页可记住用户账号，减少重复输入 |
| 登录时允许查看密码 | 启用后，用户可在登录页临时显示已输入的密码，用于核对输入内容 |
| 允许用户重置密码 | 启用后，登录页或相关入口允许用户自助发起密码重置 |
| 账号区分大小写 | 启用后，登录账号按大小写精确匹配；停用后，账号大小写不影响匹配 |

建议至少结合 **密码最小长度** 和必要的 **密码复杂要求** 设置本地账号密码规则。若系统主要使用 LDAP 或单点登录，密码本身通常由外部身份系统管理，但登录页体验、会话和重新认证相关设置仍可能在 Gaia 侧生效。域账号（LDAP / AD）不套用本页本地密码复杂度、有效期等规则，密码规则以域侧为准。

## 登录策略

登录策略区域用于控制登录失败后的处理方式，以及用户无操作时的会话行为。

| 配置项 | 说明 |
|---------|------|
| 密码错误锁定账号 | 设置连续输错密码达到上限后的处理方式。当前页面显示为设置错误次数上限 10 次 |
| 连续错误间隔(分钟) | 判断两次密码错误是否属于同一轮连续错误。当前页面显示为 5 分钟 |
| 账号锁定时长 | 设置账号被锁定后的恢复方式。当前页面显示为自动解锁 5 分钟 |
| 密码错误时提示剩余次数 | 启用后，用户输错密码时会看到剩余可尝试次数 |
| 未操作自动退出时长(分钟) | 设置用户无操作多久后自动退出登录。当前页面显示为 0，表示不按该项自动退出 |
| 登录会话超期倒计时提示时间(分钟) | 控制会话超期前是否提示倒计时。选择“不提示”时，页面不显示倒计时提醒 |
| 自动锁屏时间(分钟) | 设置用户无操作多久后自动锁屏。选择“不限制”时，不启用自动锁屏 |
| 图片验证码 | 控制登录页是否展示图片验证码。选择“关闭”时，登录页不要求输入图片验证码 |
| 单一设备登录 | 启用后，同一账号只允许保留一个有效登录会话，新的登录可能会使旧会话失效 |

密码错误锁定可以降低暴力尝试风险，但次数上限和锁定时长不宜过严。若上限过低或锁定时间过长，正常用户输错密码后也可能频繁被锁定，需要管理员介入。

## 多因子认证(MFA)设置

多因子认证用于在账号和密码之外增加二次验证。页面支持按认证方式启用。

| 认证方式 | 说明 |
|------------|------|
| 手机认证 | 启用后，用户登录或重新认证时可能需要通过手机号完成校验 |
| 邮箱认证 | 启用后，用户登录或重新认证时可能需要通过邮箱完成校验 |

启用 MFA 前，应先确认用户资料中已维护可用的手机号或邮箱。若用户缺少对应联系方式，可能无法完成认证。

---

## 配置步骤
1. 进入 **管理端 \> 系统设置 \> 域设置 \> 密码策略设置**。
2. 展开需要维护的区域，例如 **密码策略**、**登录策略** 或 **多因子认证(MFA)设置**。
3. 点击 **编辑**。
4. 按安全制度调整对应字段。
5. 点击 **保存**。
6. 使用测试账号验证登录、修改密码、输错密码锁定、自动解锁、重新认证等流程。

保存后，新策略通常会影响后续登录、修改密码、重置密码和重新认证。已登录用户是否立即受影响，取决于具体会话状态和触发场景。

## 变更前检查

| 检查项 | 建议 |
|---------|------|
| 管理员入口 | 确认至少一个管理员账号仍可登录系统 |
| 初始密码 | 避免在生产环境长期使用弱初始密码 |
| 复杂度和最小长度 | 确认用户能够理解并满足新密码要求 |
| 密码有效期 | 避免大量用户在同一天集中密码到期 |
| 错误锁定 | 评估错误次数上限和自动解锁时间，减少正常用户被锁定的概率 |
| 自动退出与锁屏 | 验证长表单、审批、文档编辑等场景是否会被意外打断 |
| MFA | 启用前确认用户手机号或邮箱已维护完整 |

## 常见问题

**Q：用户修改密码时提示不符合要求，应检查什么？** A：检查密码复杂要求和密码最小长度。若勾选了多个字符类型，新密码必须同时满足所有已勾选项。

**Q：账号为什么会被锁定？** A：常见原因包括连续密码错误达到上限、长期不活跃、管理员手动锁定，或密码到期后的策略限制。

**Q：账号锁定后会自动解锁吗？** A：取决于账号锁定时长配置。若配置为自动解锁，达到设定时间后系统会解除锁定；若配置为永久锁定，则需要管理员处理。

**Q：启用 MFA 后用户无法登录怎么办？** A：先检查用户资料中的手机号或邮箱是否可用，再确认当前策略启用了哪一种认证方式。必要时由管理员修正用户联系方式或临时调整认证方式。

**Q：域账号（LDAP / AD）是否受本地密码策略约束？** A：不受。本地密码策略不作用于域账号；域账号的密码复杂度、有效期和历史密码等规则以 AD 或企业目录侧为准。平台侧仍可能按登录策略控制会话超时、验证码等登录体验相关项。
