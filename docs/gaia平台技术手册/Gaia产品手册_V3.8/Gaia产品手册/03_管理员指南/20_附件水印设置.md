# 附件水印设置
> 本文面向系统管理员和安全管理员，介绍 Gaia 平台附件水印的配置入口、字段含义、生效范围和权限要求。附件水印用于在用户下载 PDF 附件时写入可追溯的水印内容，帮助降低附件外传后的信息泄露风险。   

---

## 1\. 适用范围

附件水印是独立于页面水印的系统安全配置。页面水印只显示在系统页面上，不会写入下载文件；附件水印会在附件下载时按配置写入文件内容。

附件水印适用于附件字段类型，目前支持 PDF 格式附件。非 PDF 附件、页面截图和系统页面展示不受附件水印配置影响。

---

## 2\. 配置入口

访问路径：`管理端 > 系统设置 > 水印设置 > 附件水印设置`

进入页面后，系统默认显示查看模式。具备编辑权限的管理员可以点击页面右上角的 `编辑` 进入编辑模式；只有查看权限时，页面不显示编辑按钮。

---

## 3\. 查看页面

查看模式用于确认当前附件水印配置和预览效果。页面会显示水印状态，以及在水印开启时生效的水印内容、字体、颜色、大小、透明度、旋转角度、对齐位置、边距和水印密度等信息。

| 字段 | 说明 |
|------|------|
| 水印状态 | 显示当前是否启用附件水印。关闭时，页面不显示后续水印属性，下载附件时也不会写入水印。 |
| 水印内容 | 显示当前配置的水印文本和变量。 |
| 对齐方式 | 显示多行水印内容的文本对齐方式。 |
| 水印字体 | 显示水印使用的字体。 |
| 水印颜色 | 显示水印文字颜色。 |
| 水印大小 | 显示水印字号，单位为 px。 |
| 透明度 | 显示水印透明度，单位为 `%`。 |
| 旋转角度 | 显示水印旋转角度，单位为度。 |
| 水平对齐 | 显示水印在 PDF 页面中的水平位置。 |
| 左右边距 | 当水印靠左或靠右显示时，用于控制水印与页面左右边缘的距离。 |
| 垂直对齐 | 显示水印在 PDF 页面中的垂直位置。 |
| 上下边距 | 当水印靠顶部或底部显示时，用于控制水印与页面上下边缘的距离。 |
| 水印密度 | 显示当前水印排布疏密档位及对应行列数。 |
| 水印预览 | 按当前配置展示水印效果，便于保存前后核对。 |

---

## 4\. 配置附件水印

### 4.1 操作步骤
1. 进入 `管理端 > 系统设置 > 水印设置 > 附件水印设置`。
2. 点击 `编辑`。
3. 勾选 `水印状态`，开启附件下载水印。
4. 在 `水印内容` 中输入固定文本，或插入当前用户、当前时间、当前业务单元、所属对象字段、换行符和空格等变量。
5. 按需要设置对齐方式、字体、颜色、大小、透明度和旋转角度。
6. 设置水印在 PDF 页面中的水平对齐、垂直对齐；如选择靠左、靠右、顶部或底部显示，按需要填写对应边距。
7. 按需要选择 `水印密度`。选择稀疏、标准或密集时，页面会显示对应行列数；选择自定义时，再填写行数和列数。
8. 在 `水印预览` 中确认显示效果。
9. 点击 `保存`，使配置生效。

点击 `取消` 会放弃本次编辑，页面返回查看模式并保留原配置。

### 4.2 配置项说明

| 配置项 | 说明 | 默认值 / 限制 |
|---------|------|------------------|
| 水印状态 | 控制是否在附件下载时写入水印。开启后显示并允许维护下方水印属性；关闭后不写入水印，也不显示下方配置项。 | 默认未开启 |
| 水印内容 | 配置写入 PDF 附件的水印文本。支持固定文本和系统变量，最多 500 个字符。开启水印时必填。 | 支持的变量详见下方“4.3 支持的变量”说明。 |
| 对齐方式 | 当水印内容分多行显示时，控制每行文本的对齐方式。 | 默认居中对齐 |
| 水印字体 | 控制水印文字使用的字体。实际写入效果取决于系统可用字体和 PDF 处理能力。 | 默认微软雅黑 |
| 水印颜色 | 控制水印文字颜色。 | 默认黑色 |
| 水印大小 | 控制水印字号。 | 支持 1-100 的整数，单位 px；默认 14 |
| 透明度 | 控制水印可见程度。数值越小越浅，数值越大越明显。 | 支持 1-100 的整数，单位 `%`；默认 50% |
| 旋转角度 | 控制水印文字倾斜角度。 | 支持 -360 至 360 的整数；默认 45 |
| 水平对齐 | 控制水印在 PDF 页面中的水平位置，可选择左对齐、居中或右对齐。 | 默认居中 |
| 左右边距 | 当水印选择左对齐或右对齐时，用于调整水印与页面边缘的水平距离。 | 按页面显示单位填写 |
| 垂直对齐 | 控制水印在 PDF 页面中的垂直位置，可选择顶端对齐、居中或底端对齐。 | 默认居中 |
| 上下边距 | 当水印选择顶端对齐或底端对齐时，用于调整水印与页面边缘的垂直距离。 | 按页面显示单位填写 |
| 水印密度 | 控制 PDF 附件水印在页面上的排布疏密。可选 **稀疏**、**标准**、**密集**、**自定义**。稀疏为 1 行 1 列；标准为 3 行 3 列（新建配置的推荐默认）；密集为 4 行 4 列；自定义时可分别设置行数和列数（均为 1–10 的整数）。密度只影响水印分布数量，不改变水印文本、字体、颜色、透明度和旋转角度。 | 新建配置默认 **标准**；从旧版本升级的环境通常保持 **稀疏**，可按需改为标准或更高密度 |
| 水印预览 | 根据当前编辑内容实时展示水印效果。 | 配置变化后自动更新 |
> \[!TIP\]
附件水印内容建议包含下载人身份和下载时间，例如当前用户姓名、账号和当前时间。PDF 文件被转发后，管理员可以根据水印信息追溯来源。   

### 4.3 支持的变量

编辑 `水印内容` 时，可以在固定文本中插入变量。用户下载 PDF 附件时，系统会按下载当时的用户、时间、业务单元和附件所属记录信息替换变量，再写入文件水印。

| 变量类别 | 可选变量 | 写入结果 |
|------------|------------|------------|
| 当前用户信息 | 当前用户姓名、账号 | 写入执行下载操作的用户信息，用于追溯下载人。 |
| 当前上下文 | 当前时间、当前业务单元 | 写入下载发生的时间和用户当前所在业务单元。 |
| 所属对象字段 | 名称、状态、记录状态、创建人、创建时间、更新人、更新时间 | 写入附件所属记录的对应字段值，便于在水印中标识文件来源和记录状态。 |
| 排版变量 | 换行符、空格 | 调整水印内容的换行和间距。 |

所属对象字段取值来自附件所在记录。若记录中对应字段为空，下载文件中的水印也不会显示该字段值；如需稳定追溯附件来源，建议至少组合使用所属对象 `名称`、当前用户信息和当前时间。

---

## 5\. 生效行为

### 5.1 开启附件水印

开启 `水印状态` 并保存后，用户下载 PDF 附件时，系统会按当前配置在文件中写入水印。水印会随下载文件一起流转，适用于需要控制 PDF 附件外传风险的场景。水印密度保存后立即作用于后续下载；已下载到本地的旧文件不会追溯更新。

### 5.2 关闭附件水印

关闭 `水印状态` 并保存后，下载 PDF 附件时不再写入水印。关闭状态下，水印内容、样式、位置、边距和密度配置不会生效。

### 5.3 实时预览

编辑水印内容、字体、颜色、大小、透明度、角度、对齐位置、边距或水印密度时，水印预览会随配置变化更新。保存前建议先检查预览，确认水印既能识别来源、覆盖主要阅读区域，又不会过度遮挡 PDF 正文、签名、页眉页脚等关键内容。

---

## 6\. 权限要求

附件水印设置由权限集中的管理端设置权限控制。不同环境的权限项名称可能与页面水印共用，也可能独立配置，请以权限集中的实际权限项为准。

| 权限项 | 控制范围 |
|---------|------------|
| 附件水印设置:全部 | 授予附件水印设置的全部权限。勾选后，系统会自动包含查看和编辑权限。 |
| 附件水印设置:查看 | 允许进入附件水印设置页面并查看当前配置。仅具备该权限时，不显示编辑按钮。 |

建议只向系统管理员、安全管理员或经过授权的配置负责人授予编辑权限。附件水印会影响用户下载 PDF 附件后的文件内容，修改前应确认业务影响，并在必要时先在测试环境验证下载效果。

---

## 7\. 注意事项
- 附件水印与页面水印是两类配置。需要同时覆盖页面查看和附件下载场景时，应分别配置 [水印设置](19_%E6%B0%B4%E5%8D%B0%E8%AE%BE%E7%BD%AE.md) 和附件水印设置。
- 附件水印目前仅支持 PDF 附件。其他格式附件下载时不会按本配置写入水印。
- 水印内容过长、字号过大、透明度过高或角度不合适时，可能遮挡 PDF 正文。建议用典型附件验证后再用于生产环境。
- 透明度不宜设置过低，否则下载后的 PDF 中可能难以识别；也不宜设置过高，以免影响阅读。
- 当水印靠近页面边缘显示时，应结合 PDF 页边距设置左右边距或上下边距，避免水印被裁切。
- 附件水印用于追溯和提示，不等同于文件权限控制。敏感附件仍应配合权限配置、审计日志和文件加解密能力使用。

## 8\. 常见问题

**Q：附件水印和页面水印有什么区别？** A：页面水印显示在系统页面上，不会写入下载文件；附件水印会在 PDF 附件下载时写入文件内容。两者需要分别开启和维护。

**Q：开启附件水印后，所有附件都会加水印吗？** A：不会。附件水印作用于附件字段类型，目前支持 PDF 格式附件。非 PDF 附件不按本配置写入水印。

**Q：为什么关闭水印状态后看不到其他配置项？** A：水印状态关闭时，下方水印内容、样式、位置等配置不会生效，页面会隐藏这些配置项，避免误以为下载时仍会写入水印。

**Q：水印内容可以显示下载用户信息吗？** A：可以。水印内容支持插入当前用户姓名、账号、当前时间、当前业务单元，也支持插入附件所属对象字段，例如名称、状态、记录状态、创建人、创建时间、更新人和更新时间，适合用于追溯附件下载和外传来源。

**Q：修改配置后需要用户重新登录吗？** A：通常不需要。配置保存后，后续下载 PDF 附件时会按新配置写入水印；已下载到本地的旧文件不会自动更新。

**Q：水印密度有什么作用？选择哪一档更合适？** A：水印密度控制水印在 PDF 页面上的排布疏密，提高任意截取区域出现水印的概率。一般场景建议使用标准；对图片扫描类 PDF 或高敏附件，可使用密集或自定义提高覆盖；需要兼顾阅读时可使用稀疏。密度不改变水印文字和样式本身。
