# 打印水印设置
> 本文面向系统管理员和安全管理员，介绍 Gaia 平台文档打印水印的配置入口、字段含义、生效范围和权限要求。打印水印用于在用户打印文档时生成可追溯的水印内容，帮助降低纸质文档外传后的追溯难度。   

---

## 1\. 适用范围

打印水印是系统级安全配置，作用于文档打印场景。开启后，用户打印文档时，系统会按当前配置在打印内容中生成水印；关闭后，系统按未开启打印水印时的原有方式处理打印输出。

打印水印与页面水印、附件水印是不同的配置项。页面水印用于系统页面展示，附件水印用于 PDF 附件下载，打印水印用于文档打印输出。需要覆盖多个外传场景时，应分别维护对应配置。

---

## 2\. 配置入口

访问路径：`管理端 > 系统设置 > 水印设置 > 附件水印设置 > 打印水印`

`打印水印` 菜单位于 `附件水印设置` 菜单下方。进入页面后，系统默认显示查看模式。具备编辑权限的管理员可以点击页面右上角的 `编辑` 进入编辑模式；只有查看权限时，页面不显示编辑按钮。

---

## 3\. 查看页面

查看模式用于确认当前打印水印配置和预览效果。页面会显示水印状态，以及在水印开启时生效的水印内容、字体、颜色、大小、透明度、旋转角度、对齐位置和边距等信息。

| 字段 | 说明 |
|------|------|
| 水印状态 | 显示当前是否启用打印水印。关闭时，打印文档不按本页面配置生成水印。 |
| 水印内容 | 显示当前配置的水印文本和变量。 |
| 对齐方式 | 显示多行水印内容的文本对齐方式。 |
| 水印字体 | 显示水印使用的字体。 |
| 水印颜色 | 显示水印文字颜色。 |
| 水印大小 | 显示水印字号，单位为 px。 |
| 透明度 | 显示水印透明度，单位为 `%`。 |
| 旋转角度 | 显示水印旋转角度，单位为度。 |
| 水平对齐 | 显示水印在打印页面中的水平位置。 |
| 左右边距 | 当水印靠左或靠右显示时，用于控制水印与页面左右边缘的距离。 |
| 垂直对齐 | 显示水印在打印页面中的垂直位置。 |
| 上下边距 | 当水印靠顶部或底部显示时，用于控制水印与页面上下边缘的距离。 |
| 水印预览 | 按当前配置展示水印效果，便于保存前后核对。 |

---

## 4\. 配置打印水印

### 4.1 操作步骤
1. 进入 `管理端 > 系统设置 > 水印设置 > 附件水印设置 > 打印水印`。
2. 点击 `编辑`。
3. 勾选 `水印状态`，开启打印水印。
4. 在 `水印内容` 中输入固定文本，或插入打印人姓名、打印人账号、打印时间、当前业务单元、换行符和空格等变量。
5. 按需要设置对齐方式、字体、颜色、大小、透明度和旋转角度。
6. 设置水印在打印页面中的水平对齐、垂直对齐；如选择靠左、靠右、顶部或底部显示，按需要填写对应边距。
7. 在 `水印预览` 中确认显示效果。
8. 点击 `保存`，使配置生效。

点击 `取消` 会放弃本次编辑，页面返回查看模式并保留原配置。

### 4.2 配置项说明

| 配置项 | 说明 | 默认值 / 限制 |
|---------|------|------------------|
| 水印状态 | 控制是否在文档打印时生成水印。开启后显示并允许维护下方水印属性；关闭后不按本页面配置生成水印，也不显示下方配置项。 | 默认未开启 |
| 水印内容 | 配置打印输出中显示的水印文本。支持固定文本和系统变量，最多 500 个字符。开启水印时必填。 | 支持打印人姓名、打印人账号、打印时间、当前业务单元、换行符和空格 |
| 对齐方式 | 当水印内容分多行显示时，控制每行文本的对齐方式。 | 默认居中对齐 |
| 水印字体 | 控制水印文字使用的字体。实际打印效果取决于浏览器、打印服务和打印设备对字体的支持情况。 | 默认微软雅黑 |
| 水印颜色 | 控制水印文字颜色。 | 默认黑色 |
| 水印大小 | 控制水印字号。 | 支持 1-100 的整数，单位 px；默认 14 |
| 透明度 | 控制水印可见程度。数值越小越浅，数值越大越明显。 | 支持 1-100 的整数，单位 `%`；默认 50% |
| 旋转角度 | 控制水印文字倾斜角度。 | 支持 -360 至 360 的整数；默认 45 |
| 水平对齐 | 控制水印在打印页面中的水平位置，可选择左对齐、居中或右对齐。 | 默认居中 |
| 左右边距 | 当水印选择左对齐或右对齐时，用于调整水印与页面边缘的水平距离。 | 按页面显示单位填写 |
| 垂直对齐 | 控制水印在打印页面中的垂直位置，可选择顶端对齐、居中或底端对齐。 | 默认居中 |
| 上下边距 | 当水印选择顶端对齐或底端对齐时，用于调整水印与页面边缘的垂直距离。 | 按页面显示单位填写 |
| 水印预览 | 根据当前编辑内容实时展示水印效果。 | 配置变化后自动更新 |
> \[!TIP\]
打印水印内容建议包含打印人身份和打印时间，例如打印人姓名、打印人账号和打印时间。纸质文档被拍照、复印或转交后，管理员可以根据水印信息追溯打印来源。   

---

## 5\. 水印内容变量

打印水印的水印内容与附件水印保持一致，但打印场景使用打印相关变量描述。管理员配置时应优先选择能直接定位打印行为的变量。

| 变量 | 说明 |
|------|------|
| 打印人姓名 | 打印操作人的姓名。适合在水印中标识具体责任人。 |
| 打印人账号 | 打印操作人的系统账号。适合与审计日志、用户管理信息进行核对。 |
| 打印时间 | 用户发起打印时的系统时间。适合追溯纸质文档的生成时间。 |
| 换行符 | 将水印内容拆成多行显示。 |
| 空格 | 调整固定文本和变量之间的间隔。 |

从旧配置或相邻配置复制水印内容时，请注意变量名称的含义：`账号` 对应打印场景中的 `打印人账号`，`姓名` 对应打印场景中的 `打印人姓名`。

---

## 6\. 生效行为

### 6.1 开启打印水印

开启 `水印状态` 并保存后，用户打印文档时，系统会按当前打印水印配置生成水印。打印水印会出现在打印输出内容中，适用于需要追溯纸质文档来源的场景。

### 6.2 关闭打印水印

关闭 `水印状态` 并保存后，文档打印不再按本页面配置生成水印。关闭状态下，水印内容、样式、位置和边距配置不会生效。

### 6.3 与原有打印行为的关系

未开启打印水印时，系统按原有方式生成打印输出。开启打印水印后，系统优先使用本页面配置生成打印水印。管理员修改配置后，后续发起的打印任务会按新配置处理；已打印出的纸质文件不会自动变化。

### 6.4 实时预览

编辑水印内容、字体、颜色、大小、透明度、角度、对齐位置或边距时，水印预览会随配置变化更新。保存前建议先检查预览，并用典型文档测试打印效果，确认水印既能识别来源，又不会遮挡正文、签名、页眉页脚、版本号等关键内容。

---

## 7\. 权限要求

打印水印设置由权限集中的管理端设置权限控制。不同环境的权限项名称可能与水印设置共用，也可能独立配置，请以权限集中的实际权限项为准。

| 权限项 | 控制范围 |
|---------|------------|
| 打印水印设置:全部 | 授予打印水印设置的全部权限。勾选后，系统会自动包含查看和编辑权限。 |
| 打印水印设置:查看 | 允许进入打印水印设置页面并查看当前配置。仅具备该权限时，不显示编辑按钮。 |
| 打印水印设置:编辑 | 允许修改并保存打印水印配置。该权限依赖查看权限。 |

建议只向系统管理员、安全管理员或经过授权的配置负责人授予编辑权限。打印水印会影响文档打印输出，修改前应确认业务影响，并在必要时先在测试环境验证打印效果。

---

## 8\. 注意事项
- 打印水印与页面水印、附件水印相互独立。需要同时覆盖页面查看、附件下载和文档打印场景时，应分别配置 [水印设置](19_%E6%B0%B4%E5%8D%B0%E8%AE%BE%E7%BD%AE.md)、[附件水印设置](20_%E9%99%84%E4%BB%B6%E6%B0%B4%E5%8D%B0%E8%AE%BE%E7%BD%AE.md) 和打印水印设置。
- 打印水印只影响保存后新发起的打印任务，已经打印出的纸质文件不会自动更新。
- 水印内容过长、字号过大、透明度过高或角度不合适时，可能遮挡文档正文或签名区域。建议用典型文档验证后再用于生产环境。
- 透明度不宜设置过低，否则打印输出中可能难以识别；也不宜设置过高，以免影响阅读。
- 当水印靠近页面边缘显示时，应结合文档页边距设置左右边距或上下边距，避免水印被裁切。
- 打印水印用于追溯和提示，不等同于打印权限控制。敏感文档仍应配合权限配置、审计日志、文件加解密和审批流程使用。

## 9\. 常见问题

**Q：打印水印和附件水印有什么区别？** A：附件水印用于用户下载 PDF 附件时写入文件内容；打印水印用于用户打印文档时生成水印。两者配置入口相邻，但生效场景不同，需要分别开启和维护。

**Q：开启打印水印后，页面上会显示水印吗？** A：不会。页面显示由 [水印设置](19_%E6%B0%B4%E5%8D%B0%E8%AE%BE%E7%BD%AE.md) 控制。打印水印只作用于文档打印场景。

**Q：为什么打印水印内容里有“打印人账号”和“打印人姓名”？** A：打印水印用于追溯打印行为，因此变量名称直接对应打印操作人。管理员可以用打印人账号、打印人姓名和打印时间定位纸质文件来源。

**Q：修改配置后，需要用户重新登录吗？** A：通常不需要。配置保存后，后续发起的打印任务会按新配置生成水印；保存前已经生成或已经打印的内容不会自动更新。

**Q：打印水印能替代打印权限控制吗？** A：不能。打印水印用于标识和追溯纸质输出，不能阻止无权限人员获取文档。需要限制打印行为时，应结合权限配置和流程控制一起使用。
