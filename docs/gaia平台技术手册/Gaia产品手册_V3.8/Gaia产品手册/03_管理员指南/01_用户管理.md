\# 用户管理
> **所需权限**：系统管理员 或 用户管理员   

---

## 概述

用户管理用于维护 Gaia 平台中的用户账号与组织信息，包括创建、编辑、停用、密码重置和批量导入。
在集团化场景中，用户还可关联业务单元，并按授权范围进行管理。

---

## 使用入口与管理范围

### 菜单入口
- 管理端入口：`【管理端】>【用户管理】>【用户】`
- 业务端入口（按客户配置）：部分租户会在业务端提供“用户管理”菜单，用于按业务单元管理用户

### 管理范围说明
- 从管理端进入时，通常可管理授权范围内的全部用户
- 从业务端入口进入时，通常按业务单元管理用户
- 实际可见范围以角色权限和租户配置为准

## 创建用户

### 前提条件
- 具有用户管理权限
- 了解用户所需的角色和权限

### 操作步骤
1. 通过可用入口进入【用户】列表页面
2. 在用户列表页面，点击右上角【创建】按钮
3. 填写用户信息：

| 字段 | 用途说明 | 配置要点 | 必填 |
|------|------------|------------|------|
| 用户名 | 登录账号，通常为邮箱 | 建议使用可长期维护的唯一标识 | ✓ |
| 姓名 | 用户显示名称 | 用于任务、审批、审计等场景展示 | ✓ |
| 邮箱 | 接收通知和找回密码 | 建议填写可正常收信邮箱 | ✓ |
| 手机号 | 接收短信通知 | 是否启用短信能力取决于租户配置 | 按配置 |
| 部门 | 归属组织 | 影响组织视图、统计与部分权限判断 | ✓ |
| 业务单元 | 集团化场景下的数据隔离与管理范围控制 | 多业务单元场景建议明确默认业务单元 | 按配置 |
| 职位 | 标识组织岗位 | 常用于通讯录、审批路由或授权辅助 | 按配置 |
| 直线上级 | 建立汇报关系 | 常用于审批链路、任务分发和代理关系 | 按配置 |
| 首选菜单 | 登录后的默认进入菜单 | 用于减少高频用户的进入路径 | 按配置 |
| 首选菜单集 | 默认菜单集合偏好 | 用于按角色/场景切换菜单工作区 | 按配置 |
| 状态 | 控制账号生命周期 | 启用/停用/待激活/已过期/已注销 | ✓ |
| 其他扩展字段 | 满足客户个性化管理要求 | 由租户管理员按需配置 | 按配置 |
> 说明：不同租户的字段、必填规则和可编辑范围可能不同，请以当前环境的页面配置为准。   
> 相关设置：请在用户详情页的【角色】相关区域完成角色分配。角色规则详见：[角色管理](01H_%E8%A7%92%E8%89%B2%E7%AE%A1%E7%90%86.md)。   
4. 点击【保存】

### 保存后的结果
- 保存成功后，系统创建用户账号并写入审计日志
- 若账号状态为“启用”，且用户状态为在职，且登录策略满足，用户可直接登录
- 若账号状态为“待激活”或“停用”，用户无法直接以正常流程登录

### 账号状态说明

系统支持以下账号状态，便于精细化管理用户生命周期：

| 状态 | 说明 |
|------|------|
| **启用** | 账号正常可用，可登录系统 |
| **停用** | 账号已禁用，无法登录 |
| **待激活** | 新创建用户尚未完成首次登录或激活流程 |
| **已过期** | 账号有效期已过，需联系管理员续期 |
| **已注销** | 账号已注销，不可再登录 |
> 合规要点：用户创建、编辑、停用等操作会记录审计日志，包含操作人、时间和变更内容。

## 编辑用户
1. 在用户列表中找到目标用户
2. 点击用户名进入详情页
3. 点击【编辑】按钮
4. 修改需要变更的信息
5. 点击【保存】

### 编辑后的影响

| 变更项 | 影响 |
|---------|------|
| 角色与权限 | 保存后生效，用户后续操作按新权限执行 |
| 部门/业务单元/职位/上级 | 影响组织归属、管理范围及部分流程路由 |
| 首选菜单/首选菜单集 | 影响用户登录后的默认工作入口 |
> 注意：字段是否可编辑取决于租户配置与当前用户权限。   

## 添加角色

在用户详情页中，可通过【角色】相关区域为用户分配角色。
1. 在用户列表中找到目标用户
2. 点击用户名进入详情页
3. 在【角色】相关部分点击【添加角色】或【分配角色】
4. 选择需要分配的角色并确认保存

### 添加后的影响

| 影响项 | 说明 |
|---------|------|
| 功能访问范围 | 用户可访问新增角色授权的菜单与功能 |
| 业务操作权限 | 用户可执行新增角色允许的操作 |
| 数据可见范围 | 可能随角色授权规则发生变化 |
| 生效时间 | 一般在保存后生效，具体以系统配置为准 |
> 相关说明：角色定义与授权规则详见 [角色管理](01H_%E8%A7%92%E8%89%B2%E7%AE%A1%E7%90%86.md)。   

## 用户详情与登录控制

以下能力通常在用户详情页中查看或配置：

### 登录 IP 白名单

系统支持为用户设置登录 IP 白名单。
- 设置白名单后：仅白名单范围内 IP 可登录
- 不在白名单中的 IP：登录请求将被拒绝
- 是否启用该能力以及白名单规则格式，以租户安全策略配置为准

### 按配置可见的信息

根据系统配置和权限范围，在用户详情页中还可以查看以下信息：

| 信息项 | 说明 |
|---------|------|
| 第三方账号 | 查看用户已绑定的第三方身份账号 |
| 未完成的待办任务 | 用于停用前评估任务移交和处理风险 |
| 许可信息 | 查看用户许可证占用和授权情况 |
| 工作代理 | 查看用户当前代理关系与生效范围 |
| 工作移交信息 | 查看用户发起或接收的移交记录 |

## 停用用户

当用户离职或不再需要访问系统时，应停用而非删除用户账号。
1. 在用户列表中找到目标用户
2. 点击【更多】\>【停用】
3. 确认停用操作

### 停用后的影响

| 影响 | 说明 |
|------|------|
| **登录** | 用户无法登录系统 |
| **任务** | 待处理任务需要重新分配 |
| **数据** | 用户创建的数据保留 |
| **审计** | 审计记录保留，仍可追溯 |
> 合规要点：为保持审计追踪完整性，系统不支持删除用户，只能停用。

## 重置密码

### 管理员重置
1. 在用户详情页点击【重置密码】
2. 系统将用户密码重置为初始密码，并向其发送通知消息，用户下次登录需要修改密码

### 重置后的结果
- 原密码立即失效
- 用户需使用新密码登录并按策略完成后续安全操作

## 批量导入用户

可通过以下入口进入用户导入：
- 入口一（按客户配置）：`【用户管理】>【批量导入】`
- 入口二（按客户配置）：`【导入导出工具】>【导入】`

若当前环境未显示 `【用户管理】>【批量导入】`，请联系管理员确认菜单配置，或使用 `【导入导出工具】>【导入】` 入口。
1. 进入用户导入页面
2. 下载导入模板
3. 按模板格式填写用户信息
4. 上传填写好的 Excel 文件
5. 系统校验数据：
    - ✅ 校验通过的用户会被创建
    - ❌ 校验失败的行会显示错误原因
6. 确认并执行导入

### 导入建议
- 先小批量试导入，确认字段映射和必填规则
- 涉及业务单元、部门、职位等组织字段时，建议先完成主数据维护
- 导入失败后按错误提示修正，再重新导入
- 导入模板、字段映射与错误处理规则，详见：[导入导出](33_%E5%AF%BC%E5%85%A5%E5%AF%BC%E5%87%BA.md)

## 内置用户

系统内置以下用户账号：

| 用户名 | 说明 |
|---------|------|
| `admin` | 平台管理员内置账号，用于系统管理。 |
| `system` | 系统后台处理账号，用于系统级操作和自动流程。 |
| `job` | 任务执行账号，用于定时任务、批处理等作业运行。 |
| `application` | 应用集成账号，用于应用间调用和系统集成场景。 |
> 建议：内置用户主要用于系统运行和管理，请勿作为普通业务用户长期使用。

## 常见问题

**Q: 用户忘记密码且无法收到重置邮件？** A: 管理员可以手动重置密码并告知用户临时密码。

**Q: 如何批量停用用户？** A: 在用户列表中多选用户，然后点击【批量操作】\>【停用】。

**Q: 停用的用户可以恢复吗？** A: 可以，在用户详情页点击【启用】即可恢复。
