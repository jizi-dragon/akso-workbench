# 登录设置
> **适用角色**：系统管理员、安全管理员   

---

## 概述

登录设置用于维护用户进入系统前看到的登录页内容，以及允许使用的登录方式。管理员可以在这里上传登录阅读协议、设置登录页背景图，并控制是否启用手机号登录、邮箱登录、业务单元选择和第三方应用账号自动登录。

典型入口：

**管理端 \> 系统设置 \> 登录设置**

---

## 登录页面设置

登录页面设置通常包含以下配置项：

| 设置项 | 作用 | 配置后效果 |
|---------|------|---------------|
| 登录阅读协议 | 上传用户登录前需要阅读的协议文件 | 登录页可展示对应协议入口，用户可查看协议内容 |
| 登录页面背景图 | 上传 Web 端登录页面背景图片 | 保存后，登录页使用新的背景图展示 |
| 登录时选择业务单元 | 控制用户登录时是否需要选择业务单元 | 勾选后，登录过程会出现业务单元选择；未勾选时，系统按默认规则进入 |
| 启用手机号登录 | 控制是否允许用户使用手机号登录 | 勾选后，登录页提供手机号登录方式 |
| 启用邮箱登录 | 控制是否允许用户使用邮箱登录 | 勾选后，登录页提供邮箱登录方式 |
| 账号绑定第三方应用后自动登录 | 控制已绑定第三方应用账号的用户是否可直接进入系统 | 勾选后，如果用户已绑定第三方应用账号，可通过第三方应用账号直接登录系统 |

---

## 上传登录阅读协议

登录阅读协议用于在登录页向用户展示需要阅读或确认的协议内容。管理员可以上传协议文件，系统会在登录页使用该文件作为协议内容来源。

支持的文件扩展名：

`doc`、`docx`、`pdf`、`jpg`、`png`、`jpeg`

操作步骤：
1. 进入 **登录页面设置**。
2. 在 **登录阅读协议** 后点击 **上传**。
3. 选择符合格式要求的文件。
4. 保存设置。

保存成功后，登录页会按当前配置展示协议入口。若需要替换协议，重新上传文件并保存即可。

---

## 设置登录页面背景图

登录页面背景图用于控制 Web 端登录页的视觉背景。管理员可以上传企业品牌图、产品图或统一登录背景图。

支持的文件扩展名：

`jpeg`、`jpg`、`png`、`svg`

操作步骤：
1. 进入 **登录页面设置**。
2. 在 **登录页面背景图** 后上传图片。
3. 确认页面显示已选择的文件名。
4. 保存设置。
5. 打开或刷新登录页，确认背景图显示效果。

建议使用清晰的横向图片，并预留登录表单区域，避免重要文字或图形被登录框遮挡。

---

## 登录方式开关

### 登录时选择业务单元

勾选后，用户登录过程中需要选择业务单元。该设置适用于一个账号可进入多个业务单元的场景，便于用户在进入系统前确认本次工作的业务范围。

未勾选时，系统按照当前账号的默认业务单元或既有规则进入系统。

### 启用手机号登录

勾选后，用户可以在登录页使用手机号登录。该方式通常要求用户账号中已维护可用手机号，并且当前环境已配置对应的验证方式。

未勾选时，登录页不提供手机号登录入口。

### 启用邮箱登录

勾选后，用户可以在登录页使用邮箱登录。该方式通常要求用户账号中已维护可用邮箱，并且当前环境已配置对应的验证方式。

未勾选时，登录页不提供邮箱登录入口。

### 账号绑定第三方应用后自动登录

勾选后，如果用户已经绑定第三方应用账号，系统允许用户通过已绑定的第三方应用账号直接登录 Gaia。

该设置常用于企业统一入口、第三方工作台或移动端应用集成场景。用户是否能够直接登录，还取决于账号绑定关系、第三方应用认证结果、账号状态和当前登录安全策略。

未勾选时，即使用户已绑定第三方应用账号，也不会按该方式自动进入系统，需要使用当前环境允许的登录方式登录。

---

## 保存后的影响

登录设置保存后，会影响后续进入登录页的用户。已经打开登录页的用户，可能需要刷新页面后才能看到新的背景图、协议入口或登录方式。

| 变更内容 | 影响范围 |
|------------|------------|
| 修改登录阅读协议 | 影响登录页展示的协议内容 |
| 修改登录页背景图 | 影响 Web 端登录页背景显示 |
| 开启或关闭业务单元选择 | 影响用户登录过程中是否需要选择业务单元 |
| 开启或关闭手机号登录 | 影响登录页是否显示手机号登录方式 |
| 开启或关闭邮箱登录 | 影响登录页是否显示邮箱登录方式 |
| 开启或关闭第三方应用账号自动登录 | 影响已绑定第三方应用账号的用户能否直接登录系统 |

---

## 注意事项
- 调整登录方式前，应确认用户账号中的手机号、邮箱或第三方应用绑定关系已经维护完整。
- 上传图片后如登录页未立即变化，可刷新浏览器或重新打开登录页。
- 登录设置属于全局入口配置，正式环境调整前建议先在测试环境确认显示效果和登录流程。
- 如同时配置单点登录、安全策略或网络访问规则，最终登录结果以完整登录链路校验为准。
