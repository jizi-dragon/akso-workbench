# 网络访问规则
> 本文面向 Gaia 平台系统管理员和安全管理员，介绍如何通过网络访问规则限制可访问系统的 IP 地址范围。网络访问规则可配置白名单、黑名单或二者组合，用于降低非授权网络来源访问系统的风险。

## 概述

网络访问规则用于控制哪些 IP 地址可以访问 Gaia。管理员可以创建一条或多条 IP 地址范围规则，并将规则标记为 **白名单** 或 **黑名单**。

典型访问路径：

**管理端 \> 系统设置 \> 域设置 \> 网络访问规则**

规则生效后，系统会根据当前启用的保护模式判断访问请求是否允许进入：

| 保护模式 | 允许访问 | 拒绝访问 |
|------------|------------|------------|
| 未开启 | 所有 IP 地址 | 无 |
| 白名单 | 白名单范围内的 IP 地址 | 白名单范围外的 IP 地址 |
| 黑名单 | 黑名单范围外的 IP 地址 | 黑名单范围内的 IP 地址 |
| 黑白名单 | 白名单范围内且不在黑名单范围内的 IP 地址 | 白名单范围外，或命中黑名单范围的 IP 地址 |
> \[!IMPORTANT\]
网络访问规则会影响所有用户访问系统。生产环境启用白名单或黑白名单前，应先确认管理员当前网络出口 IP 已包含在允许范围内，并准备应急访问方案，避免规则保存后管理员也无法进入系统。

## 权限要求

管理员需要具备网络访问规则相关权限，才能查看或维护规则。

| 权限 | 说明 |
|------|------|
| 网络访问规则：查看 | 查看网络访问规则列表和详情 |
| 网络访问规则：全部 | 新建白名单或黑名单规则，修改规则名称、状态、类型、IP 地址范围和描述，删除不再使用的规则 |

若当前账号只有查看权限，页面可以展示规则内容，但创建、编辑、启用、停用和删除入口不可用，或操作时被系统拒绝。

## 页面结构

网络访问规则页面以列表方式展示当前系统中的规则，并在页面上方显示当前保护模式。

| 页面区域 | 说明 |
|------------|------|
| 保护模式 | 显示当前系统是否处于未开启、白名单、黑名单或黑白名单保护状态。点击 **去设置** 可进入保护模式设置 |
| 搜索 | 按规则名称等条件筛选列表，便于定位目标规则 |
| 规则列表 | 分页展示网络访问规则，包含名称、起始 IP 地址、结束 IP 地址、描述、状态和类型 |
| 名称 | 点击规则名称进入详情页，查看完整配置 |
| 创建 | 新建一条网络访问规则 |
| 编辑 | 修改现有规则。保存后，规则按最新配置参与访问判断 |
| 启用/停用 | 控制单条规则是否参与访问判断。停用规则不会被系统应用 |
| 删除 | 删除规则记录。删除前应确认该规则不再用于保护生产访问 |

停用状态的规则仍保留在列表中，但不会参与访问控制。管理员可以先停用规则观察影响，再决定是否删除。

## 创建网络访问规则

### 操作步骤
1. 进入 **管理端 \> 系统设置 \> 域设置 \> 安全设置 \> 网络访问规则**。
2. 点击 **创建**。
3. 填写规则名称。
4. 选择 IP 版本：**IPv4** 或 **IPv6**。
5. 选择状态：**启用** 或 **停用**。
6. 选择类型：**白名单** 或 **黑名单**。
7. 填写起始 IP 地址和结束 IP 地址。
8. 根据需要填写描述。
9. 点击 **保存**。

保存成功后，新规则出现在网络访问规则列表中。若规则状态为 **启用**，且对应保护模式已开启，系统会按该规则判断访问请求。

### 字段说明

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 规则名称 | 是 | 规则的显示名称。名称应能说明适用范围，例如“总部办公网白名单”或“异常来源黑名单”。同一列表中名称必须唯一 |
| 版本 | 是 | 选择 IP 地址版本。IPv4 使用点分十进制地址；IPv6 使用冒号分隔地址 |
| 状态 | 是 | 可选 **启用** 或 **停用**。启用后规则参与访问判断；停用后规则仅保留记录，不参与判断 |
| 类型 | 是 | 可选 **白名单** 或 **黑名单**。白名单表示允许访问范围，黑名单表示拒绝访问范围 |
| 起始地址 | 是 | IP 地址范围的起点 |
| 结束地址 | 是 | IP 地址范围的终点。结束地址应大于或等于起始地址 |
| 描述 | 否 | 记录规则用途、适用部门、网络出口、维护负责人或变更原因 |
> \[!TIP\]
建议在描述中写明 IP 来源，例如“上海办公室固定出口”“供应商 VPN 出口”或“临时封禁来源”。后续排查登录异常时，管理员可以更快判断访问请求是否命中预期规则。

## IP 地址填写规则

### IPv4 地址

IPv4 地址按 4 段填写，每段取值范围为 0 到 255。页面只允许输入数字和英文句号。

| 行为 | 说明 |
|------|------|
| 单段输入 | 每段最多输入 3 位数字 |
| 超出范围 | 若单段数字超过 255，失焦后系统按 255 处理 |
| 自动跳转 | 某段输入 3 位数字后，焦点自动进入下一段 |
| 快捷输入 | 光标位于当前段末尾时，输入英文句号可跳到下一段 |

### IPv6 地址

IPv6 地址按分段填写，每段最多 4 位十六进制字符。页面允许输入数字和 A-F 字母，不区分大小写。

| 行为 | 说明 |
|------|------|
| 单段输入 | 每段最多输入 4 位数字或 A-F 字母 |
| 字符限制 | 不支持的字符会被页面拦截，不能键入 |
| 自动跳转 | 某段输入满 4 位后，焦点自动进入下一段 |
| 快捷输入 | 光标位于当前段末尾时，输入冒号可跳到下一段 |

起始地址和结束地址必须使用同一种 IP 版本。若结束地址小于起始地址，保存时系统会提示结束地址应大于起始地址。

## 设置保护模式

规则本身只定义 IP 地址范围和名单类型。系统是否按白名单、黑名单或黑白名单生效，取决于网络访问规则页面中的保护模式设置。

| 设置状态 | 系统行为 |
|------------|------------|
| 未开启 | 系统不按网络访问规则拦截访问请求 |
| 仅开启白名单 | 只有启用状态的白名单规则范围内 IP 可以访问系统 |
| 仅开启黑名单 | 启用状态的黑名单规则范围内 IP 不能访问系统，其他 IP 可以访问 |
| 同时开启黑白名单 | 访问 IP 必须命中启用状态的白名单规则，且不能命中启用状态的黑名单规则 |

### 操作建议
1. 先创建并停用目标规则，确认名称、类型和 IP 范围正确。
2. 在非生产环境验证白名单和黑名单组合。
3. 在生产环境启用前，确认管理员、运维人员和必要集成来源的出口 IP 均已纳入允许范围。
4. 启用保护模式后，使用不同网络来源验证允许访问和拒绝访问是否符合预期。

若访问请求被网络访问规则拒绝，用户会进入无权限页面或被阻止继续访问系统。此时应检查访问来源 IP、保护模式、规则状态和规则类型。

## 查看和编辑规则

点击列表中的规则名称可进入详情页。详情页以只读方式展示规则名称、版本、状态、类型、起始地址、结束地址和描述。

如需修改规则，点击 **编辑**。编辑页面的字段和创建页面一致。保存成功后：

| 进入编辑的来源 | 保存后的返回位置 |
|---------------------|------------------------|
| 从列表点击编辑 | 返回网络访问规则列表 |
| 从详情页点击编辑 | 返回该规则详情页 |

编辑启用状态的规则可能立即影响访问判断。调整生产规则前，建议先记录原配置，并安排低峰期或变更窗口执行。

## 启用、停用和删除

| 操作 | 结果 | 注意事项 |
|------|------|------------|
| 启用 | 规则参与访问判断 | 启用前应确认 IP 范围、名单类型和保护模式均符合预期 |
| 停用 | 规则不再参与访问判断，但记录保留在列表中 | 适合临时排查或暂缓使用某条规则 |
| 编辑 | 修改规则内容 | 修改 IP 范围或类型后，应重新验证访问结果 |
| 删除 | 删除规则记录 | 删除不可直接恢复。删除前建议确认该规则没有用于生产访问控制 |

删除规则时，系统会弹出确认提示。确认后规则被删除；取消则关闭提示并保留规则。

## 变更前检查

在正式环境创建、启用或调整网络访问规则前，建议完成以下检查：

| 检查项 | 建议 |
|---------|------|
| 管理员访问 | 确认管理员当前出口 IP 在允许范围内，且至少保留一种应急访问方式 |
| IP 来源 | 确认办公网、VPN、堡垒机、集成服务器和客户网络出口 IP 是否固定 |
| 名单类型 | 确认规则应作为白名单还是黑名单，避免把允许来源误配置为拒绝来源 |
| 地址范围 | 核对起始地址和结束地址，避免范围过大或遗漏关键地址 |
| 保护模式 | 确认当前启用的是未开启、白名单、黑名单还是黑白名单模式 |
| 关联业务 | 评估用户登录、接口调用、移动端访问和外部协作访问是否受影响 |
| 回退方案 | 记录修改前配置，准备可回退的规则状态或保护模式设置 |

涉及客户生产环境、跨区域办公网络或第三方系统集成时，建议先在测试环境验证，再安排生产变更窗口。

| 日志属性 | 说明 |
|------------|------|

| 操作时间 | 操作发生时间 |

| 操作类型 | 创建、编辑、启用、停用或删除 |
| 操作对象 | 网络访问规则名称 |
| 描述 | 记录关键字段变化，例如 IP 范围、状态、类型和保护模式 |

## 常见问题

**Q：启用白名单后，用户为什么无法访问系统？** A：请先确认用户当前网络出口 IP 是否在启用状态的白名单规则范围内，再检查保护模式是否为白名单或黑白名单。如果用户通过 VPN、代理或移动网络访问，实际出口 IP 可能与预期不同。

**Q：同时配置白名单和黑名单时，黑名单是否会覆盖白名单？** A：会。黑白名单同时生效时，访问 IP 必须在白名单范围内，并且不能命中黑名单范围。若同一个 IP 同时命中白名单和黑名单，系统按拒绝访问处理。

**Q：停用一条规则后会立即影响访问吗？** A：会影响后续访问判断。停用后，该规则不再参与白名单或黑名单判断。已登录用户是否立即受影响，取决于系统当前会话和访问校验机制，但后续新访问会按最新规则处理。

**Q：为什么规则保存时提示结束地址应大于起始地址？** A：结束地址必须大于或等于起始地址。请检查 IP 地址版本是否一致，并确认每一段地址填写正确。

**Q：生产环境不小心把管理员挡在系统外怎么办？** A：优先使用预留的应急网络或应急管理员访问方式恢复配置。若无法通过前台进入系统，需要联系运维人员按客户应急流程处理。为避免此类问题，生产环境启用前应先确认管理员出口 IP 已在允许范围内。
