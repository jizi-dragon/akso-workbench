# 语言与地区设置
> 本文面向 Gaia 平台系统管理员，介绍如何查看和维护系统默认语言、默认时区以及可用语言环境。语言与地区设置会影响新用户和未设置个人偏好的用户看到的默认界面语言，也会影响系统解释、展示和记录时间时采用的默认时区基准。   

---

## 概述

语言与地区设置位于系统设置模块中，用于维护当前 Sphere 的默认语言、默认时区和可用语言列表。管理员通常在环境初始化、客户上线前、多语言启用或跨地区使用场景中维护该配置。

| 管理项 | 说明 |
|---------|------|
| 默认语言 | 设置新用户或未单独指定语言偏好的用户默认使用的界面语言 |
| 时区 | 设置系统默认时区，用于页面时间展示、任务时间、日志时间等场景的默认解释 |
| 语言环境 | 查看当前支持的语言，启用或停用某种语言，并调整语言显示顺序 |

典型访问路径：

**管理端 \> 系统设置 \> 语言与地区设置**

进入页面后，系统按 **基本信息** 和 **语言环境** 两个区域展示当前配置。页面右上角显示 **编辑** 按钮；进入编辑状态后，按钮变为 **取消** 和 **保存**。
> \[!IMPORTANT\]
默认语言和时区属于全局设置。正式环境调整前，建议先确认客户主要使用地区、已有用户语言偏好、外部集成的时间处理规则、审批期限计算方式以及审计查看习惯，避免保存后造成界面语言或时间展示理解偏差。   

---

## 权限要求

管理员需要具备系统设置相关权限，才能查看或修改语言与地区设置。

| 权限 | 说明 |
|------|------|
| 语言与地区设置：查看 | 可以进入页面并查看当前默认语言、时区和语言环境列表 |
| 系统设置：全部 | 通常包含语言与地区设置的查看和编辑能力 |

如果当前账号只有查看权限，页面会显示当前配置，但不会显示可用的编辑入口，或点击编辑时被系统拒绝。若完全没有访问权限，左侧菜单中通常不会显示 **语言与地区设置**。

---

## 页面结构

语言与地区设置页面由左侧菜单和右侧配置区组成。左侧位于 **系统设置** 分类下，当前菜单项高亮显示为 **语言与地区设置**；右侧显示配置详情。

| 页面区域 | 说明 |
|------------|------|
| 页面标题 | 显示当前页面名称“语言与地区设置”，用于确认正在维护的系统设置项 |
| 基本信息 | 查看或编辑默认语言和系统默认时区 |
| 语言环境 | 查看当前可用语言列表；编辑状态下可启用、停用和调整语言顺序 |
| 编辑 | 进入编辑状态。进入后页面显示可修改的下拉框、语言拖拽排序控件和启用开关 |
| 保存 | 保存本次修改。保存成功后页面回到查看状态 |
| 取消 | 放弃本次修改并回到查看状态，不保存页面上的临时调整 |
| 保存排序 | 仅保存语言环境列表的显示顺序，适用于只调整语言排列的场景 |

查看状态下，**基本信息** 区域以文本方式展示当前默认语言和时区，例如“默认语言：简体中文”“时区：(GMT\+08:00) 中国标准时间（Asia/Shanghai）”。**语言环境** 区域以列表展示已配置语言，例如“简体中文（默认）”和“English”。

---

## 设置关系

语言与地区设置是系统默认值，不一定覆盖每个用户的个人偏好。理解以下关系，可以避免上线后误判配置是否生效。

| 层级 | 作用 |
|------|------|
| 系统默认语言 | 作为新用户、未设置个人语言偏好用户、语言回退场景的默认界面语言 |
| 用户个人语言偏好 | 当用户已设置个人语言时，部分页面会优先使用用户个人偏好 |
| 可用语言环境 | 决定用户可以选择哪些界面语言；未启用的语言通常不会出现在选择项中 |
| 翻译资源 | 决定语言切换后页面文案是否有对应译文；语言启用不等于所有文案都已翻译完成 |
| 系统默认时区 | 作为系统解释和展示时间的默认基准；具体页面是否使用用户个人时区，取决于对应功能设计 |
> \[!TIP\]
启用新语言前，应同步检查翻译资源是否完整。若语言已启用但翻译未维护，用户可能看到原始文案、默认语言文案或混合语言界面。

## 查看当前设置
1. 进入 **管理端 \> 系统设置 \> 语言与地区设置**。
2. 在 **基本信息** 区域查看当前默认语言和时区。
3. 在 **语言环境** 区域查看当前已配置的语言列表。
4. 确认带有“默认”标识的语言是否符合当前 Sphere 的默认使用语言。

查看状态不会修改系统配置。管理员可以用该页面确认当前环境的语言和时区，或在变更前记录现有配置。

---

## 修改基本信息

### 操作步骤
1. 进入 **管理端 \> 系统设置 \> 语言与地区设置**。
2. 点击页面右上角 **编辑**。
3. 在 **基本信息** 区域选择 **默认语言**。
4. 在 **时区** 下拉框中选择系统默认时区。
5. 点击页面右上角 **保存**。

点击 **保存** 后，系统提交默认语言和时区配置。保存成功后，页面回到查看状态，并显示新的默认语言和时区。点击 **取消** 时，系统放弃本次编辑内容，页面恢复到进入编辑前的配置。

### 字段说明

| 字段 | 是否必填 | 说明 |
|------|------------|------|
| 默认语言 | 是 | 作为系统默认界面语言。默认语言应从已启用的语言环境中选择 |
| 时区 | 是 | 作为系统默认时区。建议按客户主要运营地区选择，例如 **(GMT\+08:00) 中国标准时间（Asia/Shanghai）** |

默认语言必须从已启用的语言环境中选择。如果某个语言被停用，不建议将其设为默认语言；如系统不允许保存，请先启用该语言后再选择为默认语言。
> \[!TIP\]
跨地区使用时，应在上线前统一说明系统默认时区和用户个人时区的关系，尤其是审批期限、任务触发时间、培训截止时间、审计追踪和集成时间字段。

## 管理语言环境

语言环境区域用于维护系统可用语言。编辑状态下，每个语言项左侧显示拖拽手柄，右侧显示 **启用** 开关。

### 启用或停用语言
1. 进入 **管理端 \> 系统设置 \> 语言与地区设置**。
2. 点击 **编辑**。
3. 在 **语言环境** 区域找到目标语言。
4. 打开或关闭该语言右侧的 **启用** 开关。
5. 点击 **保存**。

启用后，该语言可作为系统可用语言。停用后，用户通常不能再选择该语言作为界面语言；已使用该语言的用户可能在下次进入系统或刷新页面后，按系统规则回退到默认语言。

默认语言不建议停用。如果需要停用当前默认语言，请先在 **基本信息** 中切换默认语言，再停用原语言。

### 调整语言显示顺序
1. 点击 **编辑**。
2. 在 **语言环境** 区域，按住语言项左侧的拖拽手柄。
3. 将语言拖动到目标位置。
4. 点击 **保存排序** 或页面右上角 **保存**。

语言顺序用于控制语言列表的展示先后。调整排序不会改变默认语言，也不会自动启用或停用某个语言。
> \[!NOTE\]
如果只调整语言顺序，可以使用 **保存排序** 单独提交排序结果。如果同时修改了默认语言、时区或启用状态，建议点击页面右上角 **保存**，确保本次变更一次性提交。   

---

## 保存与取消

编辑状态下，页面提供两类提交动作：

| 操作 | 结果 |
|------|------|
| 保存 | 保存默认语言、时区、语言启用状态等本次编辑内容，成功后回到查看状态 |
| 取消 | 放弃本次未保存修改，回到查看状态 |
| 保存排序 | 保存语言环境列表的排序结果，通常用于只调整语言顺序的场景 |
| 语言项启用开关 | 打开或关闭某个语言是否可用；最终是否生效取决于是否完成保存 |

如果管理员已经修改了页面内容但尚未保存，离开页面前应确认是否需要提交。未保存的修改不会写入系统配置。

---

## 生效范围

语言与地区设置会影响系统默认行为，但不等同于修改每个用户的个人偏好。

| 设置项 | 影响范围 |
|---------|------------|
| 默认语言 | 影响未设置个人语言偏好的用户、新建用户的默认界面语言，以及系统需要回退默认语言的场景 |
| 时区 | 影响系统默认时间展示和解释。具体页面是否使用用户个人时区，取决于对应功能设计 |
| 启用语言 | 影响用户可选择的界面语言范围 |
| 语言排序 | 影响语言列表展示顺序，不改变语言内容或翻译结果 |

修改默认语言或时区后，已登录用户可能需要刷新页面或重新登录后才能看到完整效果。涉及集成、定时任务、审批期限和审计追踪的时间字段时，应结合相关业务场景核对展示结果。

---

## 变更前检查

在正式环境修改语言与地区设置前，建议完成以下检查：

| 检查项 | 建议 |
|---------|------|
| 默认语言 | 确认目标语言已启用，并且关键页面、菜单、按钮和消息提示已完成翻译 |
| 默认时区 | 确认客户主要运营地区、法规记录习惯和审计查看习惯 |
| 用户影响 | 确认是否有用户已设置个人语言或时区偏好，避免误以为全局设置会覆盖全部用户 |
| 集成影响 | 核对外部系统传入或接收时间字段时使用的时区规则 |
| 业务影响 | 重点检查审批期限、培训截止时间、任务计划、通知时间和报表时间 |
| 回退方案 | 记录修改前配置，必要时可以快速恢复默认语言和时区 |

如果本次变更属于上线准备或生产变更，建议将修改前后的配置截图、配置报告或审计日志一并归档。

## 常见问题

**Q：为什么看不到语言与地区设置菜单？** A：当前账号可能没有语言与地区设置或系统设置相关权限。请检查权限集是否包含查看或编辑权限。

**Q：修改默认语言后，为什么部分用户界面没有立即变化？** A：已登录用户可能需要刷新页面或重新登录。若用户设置了个人语言偏好，页面可能优先使用个人偏好，而不是系统默认语言。

**Q：可以停用默认语言吗？** A：不建议停用默认语言。需要停用时，请先选择另一个已启用语言作为默认语言，再停用原语言。

**Q：启用语言后，为什么页面仍然出现默认语言文案？** A：语言启用只表示该语言可被选择，不代表所有页面文案都已完成翻译。请到翻译控制台检查菜单、字段、按钮、提示消息等翻译资源是否完整。

**Q：调整语言排序会影响用户当前使用的语言吗？** A：不会。排序只影响语言列表展示顺序，不会改变默认语言，也不会修改用户已选择的语言。

**Q：时区修改会改变历史日志时间吗？** A：时区设置主要影响时间展示和解释方式。历史日志的原始记录通常不会被重写，但查看时的显示方式可能受系统或用户时区规则影响。
