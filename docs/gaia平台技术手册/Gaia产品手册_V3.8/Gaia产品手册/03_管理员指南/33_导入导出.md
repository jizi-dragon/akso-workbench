# 导入导出
> **适用角色**：系统管理员、业务管理员本文说明 Gaia 平台导入导出能力的管理方式、使用范围和关键操作。导入与导出均基于 Excel 文件执行，适用于初始化加载、历史数据迁移、批量维护和结果核对等场景。   

---

## 概述

Gaia 平台提供统一的导入导出能力，用于批量处理对象记录、文档元数据以及相关附件/文件。

当前版本中：
- 导入文件格式为 Excel（`.xls`、`.xlsx`）
- 导出结果文件格式为 Excel（`.xlsx`）
- 导入导出均以异步作业方式执行
- 导入结果支持返回成功/失败明细，便于修正后再次导入

该能力适用于以下场景：
- 系统初始化时批量加载基础数据
- 外部系统历史数据迁移
- 对现有数据进行批量补录或修正
- 按对象或筛选条件批量导出数据进行核对、归档或离线分析

---

## 访问与权限

导入导出的访问入口不是固定菜单路径，而是由当前环境中的菜单配置决定。
- 管理员通过菜单配置开放导入导出入口
- 菜单是否可见、是否可用，由权限集中的授权决定
- 不需要通过单独的系统开关启用该功能

使用前建议确认以下事项：
- 当前环境已完成对应菜单配置
- 目标用户已获得相关菜单权限
- 相关对象、字段和模板配置已准备完成

---

## 使用范围与限制

### 支持范围

导入导出能力支持以下数据类型或场景：
- 业务对象记录
- 文档对象及其元数据
- 附件或文件型字段
- 文档迁移场景下的版本信息保留

### 限制说明

| 限制项 | 说明 |
|---------|------|
| 导入文件大小 | 受系统参数控制 |
| 导入数据条数 | 受系统参数控制 |
| 导出数据条数 | 受系统参数控制 |
| 执行方式 | 异步作业 |
| 临时文件保留 | 导入/导出产生的临时文件会按系统策略自动清理 |

说明：
- 实际上限以当前环境配置为准
- 当导入包含附件或文件时，应确保文件内容可被系统正常读取和处理

## 导入

### 导入准备

执行导入前，建议先完成以下准备：
1. 明确本次导入的目标对象和业务范围。
2. 在导出时选择`仅导出标题`，获取当前对象可用的导入模板。
3. 基于该 Excel 文件填写列头和数据。
4. 如涉及更新类导入，提前确认标识字段。
5. 如涉及附件或文件导入，提前整理文件目录与引用关系。

### 文件要求

| 项目 | 说明 |
|------|------|
| 文件格式 | Excel（`.xls`、`.xlsx`） |
| 表头要求 | 首行应包含列标题，建议与对象字段名称或 code 对齐 |
| 模板获取 | 通过导出时选择`仅导出标题`获取导入模板 |
| 数据填写 | 按导出的标题模板填写，不建议擅自修改模板结构 |
| 编码/编号字段 | 建议在 Excel 中按文本格式处理，避免被自动转换 |

### 基本流程
1. 进入当前环境中已配置的导入入口。
2. 选择目标对象。
3. 上传 Excel 文件。
4. 根据需要设置动作类型、标识字段、文件处理项等参数。
5. 配置字段映射。
6. 提交导入任务。
7. 系统校验文件并创建异步作业。
8. 作业执行完成后，通过通知或作业历史查看结果。

### 动作类型

导入时可根据业务需要选择不同动作类型：

| 动作类型 | 说明 |
|------------|------|
| 创建 | 仅创建新记录 |
| 更新 | 仅更新已存在记录，找不到目标记录则更新失败 |
| 更新与创建 | 找到记录则更新，未找到则创建 |

当选择更新或更新与创建时，应同步设置用于识别记录的标识字段。

### 字段映射

字段映射用于建立 Excel 列与目标对象字段之间的对应关系。
- 系统可根据列头名称或 code 自动尝试匹配字段
- 管理员可手动调整映射关系
- 仅已映射字段会参与导入处理
- 可保存并复用映射规则，减少重复配置

建议优先核对以下字段：
- 主键或标识字段
- 必填字段
- 引用关系字段
- 文件或附件字段
- 状态、编号、日期等格式敏感字段

### 迁移模式

当导入用于历史数据迁移时，可根据场景启用迁移模式。

迁移模式适用于：
- 大批量历史数据迁入
- 需要保留历史编号或版本信息
- 原始数据无法完全满足当前在线校验规则

在迁移模式下，系统会跳过部分在线处理逻辑。根据平台方案，通常包括但不限于：
- 生命周期进入动作
- 生命周期进入条件
- 对象验证规则
- 引用约束校验
- 生命周期状态控制
- 部分自动编号逻辑

因此，迁移模式只建议用于数据迁移或初始化场景，导入后应安排人工核对。

### 文档迁移

文档迁移是导入能力中的特殊场景，适用于保留历史文档信息的迁移任务。

典型特点包括：
- 可迁移文档元数据
- 可保留文档编号、版本等历史信息
- 可配合文件内容一起迁移

如需迁移文档版本、格式副本或历史文件，请在执行前确认模板字段、文件准备方式及目标环境约束。

### 导入结果

导入完成后，系统会生成结果日志，通常包含：
- 行号
- 执行状态
- 成功写入后的记录标识
- 失败原因

管理员可根据失败原因修正原始 Excel 后再次导入失败数据。

## 导出

### 导出范围

导出支持按对象维度或按当前筛选条件提取数据，适用于：
- 数据核对
- 业务分析
- 离线备份
- 对外共享前的数据准备

### 基本流程
1. 进入当前环境中已配置的导出入口。
2. 选择目标对象。
3. 选择需要导出的字段。
4. 根据需要设置筛选条件。
5. 提交导出任务。
6. 系统创建异步作业并生成 Excel 结果文件。
7. 作业完成后下载导出文件。

### 导出配置

| 配置项 | 说明 |
|---------|------|
| 对象 | 指定导出的目标对象 |
| 导出字段 | 选择需要输出的字段 |
| 条件 | 用于控制导出范围 |
| 包含系统字段 | 按需要导出系统字段 |
| 文档相关项 | 文档场景下可按配置包含源文件或格式副本信息 |

### 数据处理说明

导出结果通常遵循以下原则：
- 导出内容与当前用户可见数据范围保持一致
- 导出字段名称、选项显示值会尽量按界面语义输出
- 导出结果统一生成 Excel 文件
- 超出当前环境导出上限的数据不会被全部导出

---

## 作业与结果查看

导入导出都以异步作业方式执行，管理员可通过当前环境中已配置的作业历史或监控入口查看执行情况。

通常可关注以下信息：
- 作业名称
- 作业类型
- 执行状态
- 提交时间
- 执行人
- 结果文件或错误日志

建议在大批量任务执行后重点核查：
- 是否存在大量失败行
- 是否存在文件上传失败
- 是否存在字段映射遗漏
- 是否存在迁移后状态或编号异常

## 常见注意事项

| 场景 | 建议 |
|------|------|
| 首次导入 | 先使用少量样本数据验证模板、字段映射和结果日志 |
| 更新类导入 | 先确认标识字段是否唯一且可准确定位记录 |
| 迁移模式 | 仅用于迁移/初始化场景，导入后务必安排人工复核 |
| 文档导入 | 先核对文件路径、版本字段和目标对象约束 |
| 大批量导出 | 先设置筛选条件，避免一次导出过多无关数据 |
