\# 表单布局权限
> **所需权限**：系统管理员或具备用户与权限管理能力的管理员角色   

---

## 概述

表单布局权限用于控制用户在对象记录详情页可见的表单布局。
当同一对象存在多个布局时，系统会根据“角色绑定 \+ 布局权限策略”决定最终展示结果。

生效逻辑：
- 用户被分配了角色，且角色关联到某个表单布局权限策略时，按该策略中的布局配置展示页面。
- 用户未命中任何表单布局权限策略时，系统显示对象的默认布局。
- 用户同时命中多个策略时，优先使用权重更高且状态为启用的策略。

---

## 页面入口与适用场景

进入路径：`管理端 > 用户管理 > 表单布局权限`

典型场景：
- 同一对象需要按角色展示不同详情布局。
- 需要为“创建模式”指定不同对象类型的默认布局。
- 需要通过权重控制多策略冲突时的生效优先级。

---

## 页面结构与关键操作

### 列表区

列表区用于查看和维护所有表单布局权限策略，支持分页展示。

### 查询与展示
- 支持按关键词搜索策略名称。
- 默认按创建时间倒序排列。
- 支持固定行高和自动行高切换（默认固定行高）。

### 页头操作
- `创建`：进入创建页并新增策略。

### 行内操作
- `编辑`：进入编辑页，修改允许编辑字段。
- `启用/停用`：切换策略状态。
- `删除`：删除前二次确认；删除后策略与其绑定关系失效。

### 列表字段

| 字段 | 说明 |
|------|------|
| 名称 | 策略显示名称；可点击进入详情页 |
| Code | 策略唯一编码 |
| 来源 | 策略所属对象来源 |
| 状态 | 启用或停用 |
| 权重 | 策略优先级，数字越大优先级越高 |
| 描述 | 策略说明 |
| 操作 | 编辑、启用/停用、删除等操作入口 |

## 创建与编辑策略

点击 `创建` 后进入“创建表单布局权限策略”页面。

### 顶部操作
- `取消`：放弃当前填写内容，离开前提示未保存确认。
- `保存`：校验必填和唯一性后保存策略。

### 字段说明

| 字段 | 必填 | 唯一 | 说明 |
|------|------|------|------|
| 名称 | ✓ | ✓ | 策略名称，建议使用可识别业务语义命名 |
| Code | ✓ | ✓ | 策略编码，建议遵循统一编码规范 |
| 来源 | ✓ | ✓ | 来源对象，创建时按系统规则生成，不可编辑 |
| 状态 |  |  | 默认启用，可改为停用 |
| 权重 | ✓ |  | 正整数，默认 `1`，值越大优先级越高 |
| 描述 |  |  | 补充策略适用范围与边界说明 |

### 编辑范围

保存后可进入详情页执行 `编辑`、`删除` 等操作。编辑时通常可修改：`名称`、`描述`、`状态`、`权重`。

---

## 绑定角色

在策略详情页进入 `角色` 页签，维护当前策略关联角色。

### 可执行操作
- `添加`：从角色选择框中选择一个或多个角色并确认。
- `移除`：从当前策略中移除角色绑定关系。

### 操作结果
- 被绑定角色的用户，在满足其他权限约束前提下，可按该策略查看表单布局。
- 解除绑定后，该角色不再通过此策略获得布局可见性。

---

## 绑定表单布局

在策略详情页进入 `表单布局` 页签，维护对象级和对象类型级的布局可见性。

### 添加布局步骤
1. 点击 `添加布局`。
2. 在对象选择框中选择目标对象。
3. 确认后进入布局选择页。
4. 勾选需要纳入策略的布局（至少选择一个）。
5. 在已勾选布局中，按对象类型设置唯一的“用于创建”布局。
6. 点击 `保存` 完成添加。

### 添加时规则
- 仅可选择启用状态对象。
- 已添加到当前策略的对象不会重复出现在可选列表。
- “用于创建”仅能在已勾选布局中设置。
- 同一对象类型下只能有一个“用于创建”布局；开启一个后，同类型其他布局自动关闭。

### 列表管理
- 按对象分组展示，可展开或收起对象与对象类型。
- 支持 `全部展开` 快速查看全量内容。
- 支持按布局名称搜索，搜索结果自动展开。
- 可移除某个对象下全部绑定布局，移除前二次确认。

### 编辑对象下布局
- 基础对象类型：可选择 0 到多个布局，并在勾选范围内指定一个“用于创建”布局。
- 非基础对象类型：默认显示本类型布局；可勾选“显示基础对象类型的布局”并一并选择。
- 来自基础对象类型的布局带来源标识，便于区分。

### 排序
- 点击 `排序` 进入排序模式，可拖动布局顺序并保存。
- 排序结果影响该对象类型下布局展示顺序。

## 历史经验与管理建议
- 先定“角色职责边界”，再做布局策略绑定，避免后期频繁改权重。
- 发生策略冲突时，先排查“状态 \+ 权重 \+ 角色绑定”三项，再排查其他权限层。
- “用于创建”建议按对象类型明确唯一责任布局，减少创建页入口不一致导致的培训成本。
- 大版本发布前，建议做一次策略基线复核：新增策略、停用策略、权重调整、角色映射变更。

## 常见问题

**Q1：用户为什么仍看到默认布局？**   A：通常是该用户未命中任何启用状态策略，或角色未正确绑定到策略。

**Q2：同一用户命中多个策略时用哪个？**   A：系统按权重优先级处理，权重值更高的启用策略优先生效。

**Q3：“用于创建”可以设置多个吗？**   A：不可以。同一对象类型下只能设置一个“用于创建”布局。

**Q4：删除策略前需要注意什么？**   A：先确认该策略是否仍被角色使用，及是否影响现网对象创建/详情展示。
