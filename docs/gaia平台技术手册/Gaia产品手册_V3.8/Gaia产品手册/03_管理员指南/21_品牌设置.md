# 品牌设置
> 本文面向 Gaia 平台系统管理员，介绍如何配置 Web 端和移动端登录相关的品牌图片、电脑端顶部背景色，以及如何检查权限、上传限制和审计记录。品牌设置用于让客户在自己的 Sphere 中使用企业 Logo、登录页背景图和顶部导航颜色，提升登录页和系统顶部导航的品牌一致性。   

---

## 概述

品牌设置支持管理员维护以下展示内容：

| 设置项 | 显示位置 | 典型用途 |
|---------|------------|------------|
| 电脑端顶部 Logo | Web 端页面顶部导航栏左侧 | 显示企业或系统 Logo |
| 电脑端顶部背景色 | Web 端页面顶部导航栏背景 | 设置电脑端 Sphere 顶部导航区域的背景颜色 |
| 电脑端登录页背景图片 | Web 端登录页背景区域 | 展示企业品牌背景、产品视觉或统一登录背景 |
| 电脑端登录页 Logo | Web 端登录页 Logo 区域 | 在登录页显示企业 Logo |
| 移动端登录页 Logo | 移动端登录页 Logo 区域 | 在移动端登录入口显示企业 Logo |
| 浏览器标签页图标 | 浏览器标签页、收藏夹等浏览器 chrome 区域 | 用客户或项目标识替换平台默认 Favicon，便于区分环境与品牌 |

典型访问路径：

**管理端 \> 系统设置 \> 品牌设置**

也可在系统设置相关入口进入品牌设置（以当前环境实际菜单为准）。

进入页面后，系统按设置项分区展示当前配置。每个分区可以单独编辑，管理员可以选择继续使用默认图片或默认图标，也可以上传自定义图片或自定义标签页图标；电脑端顶部背景色可以单独维护颜色值。保存成功后，对应登录页、Web 顶部导航或浏览器标签页会显示新的品牌配置。
> \[!IMPORTANT\]
品牌设置会影响用户看到的登录入口、Web 顶部导航和浏览器标签页图标。正式环境调整前，建议先在测试 Sphere 中确认图片比例、清晰度、顶部背景色、标签页图标和显示效果，避免 Logo 拉伸、背景裁切、顶部文字对比度不足、图标辨识度不足或颜色与登录表单冲突。

## 权限要求

品牌设置权限位于权限集的管理模块中。管理员能否看到菜单、进入页面或编辑图片，取决于被授予的权限。

| 权限 | 说明 |
|------|------|
| 品牌设置：全部 | 可以查看品牌设置页面，并编辑所有品牌配置 |
| 品牌设置：查看 | 可以查看当前品牌设置，但不能编辑；页面中的编辑按钮不可见 |
| 品牌设置：编辑 | 可以查看品牌设置，并使用编辑按钮修改品牌图片或颜色 |

如果用户没有品牌设置相关权限，系统不会向该用户显示品牌设置菜单。用户直接通过 URL 访问时，系统显示 403。

---

## 页面结构

品牌设置页面由多个配置分区组成。每个分区通常包含当前使用方式、当前图片预览和右侧的 **编辑** 按钮。

| 页面区域 | 说明 |
|------------|------|
| 页面标题 | 显示当前页面为“品牌设置”，帮助管理员确认所在位置 |
| 设置分区 | 按电脑端顶部 Logo、电脑端顶部背景色、电脑端登录页背景图片、电脑端登录页 Logo、移动端登录页 Logo、浏览器标签页图标分区显示 |
| 图片或颜色预览 | 显示当前生效的默认图片、自定义图片、顶部背景色或标签页图标缩略预览 |
| 编辑 | 进入当前分区的编辑状态，只修改该分区对应的图片、颜色或标签页图标设置 |

每个分区互不影响。例如，只修改电脑端登录页背景图片，不会改变电脑端顶部 Logo、电脑端顶部背景色、移动端登录页 Logo 或浏览器标签页图标。

## 设置品牌项

### 操作步骤
1. 进入 **管理端 \> 系统设置 \> 品牌设置**。
2. 找到需要调整的设置分区。
3. 点击该分区右侧的 **编辑**。
4. 如果编辑图片类设置或浏览器标签页图标，选择 **默认 Logo / 默认图片 / 默认图标** 或 **自定义 Logo / 自定义图片 / 自定义图标**；如果编辑电脑端顶部背景色，填写或选择需要使用的颜色值。
5. 如果选择自定义图片或自定义图标，点击文件选择按钮并上传文件。
6. 点击 **保存**。
7. 刷新登录页、Web 页面或浏览器标签页，确认图片、顶部背景色或标签页图标显示效果。

点击 **保存** 后，系统会检查图片或图标格式、大小、是否已选择文件，或检查颜色值是否符合要求。检查通过后，系统保存当前分区配置；保存成功后，该分区回到查看状态。点击 **取消** 时，系统会提示确认放弃本次修改；确认后返回查看状态，取消确认则继续停留在编辑状态。

### 默认与自定义

| 方式 | 结果 |
|------|------|
| 默认 Logo / 默认图片 / 默认图标 | 使用平台内置图片或内置标签页图标。适合新环境、测试环境或尚未准备品牌素材的场景 |
| 自定义 Logo / 自定义图片 / 自定义图标 | 使用管理员上传的图片或标签页图标。保存成功后，对应位置显示上传后的品牌素材 |

选择自定义方式后，页面会显示上传控件、文件要求和文件选择按钮。选择文件后，文件名会显示在按钮旁，管理员可以在保存前确认是否选中了正确文件。

电脑端顶部背景色不需要上传图片。管理员可以填写颜色值，或使用页面提供的颜色选择控件选择颜色；保存成功后，Web 端页面顶部导航背景会使用新的颜色。

## 图片与颜色要求

不同设置项的显示位置不同，建议按展示场景准备图片和颜色。顶部 Logo 更适合横向透明底图片，顶部背景色应与 Logo 和导航文字保持足够对比度；登录页背景图片应避免把重要文字放在边缘区域，防止不同屏幕尺寸下被裁切；浏览器标签页图标建议使用正方形、小尺寸素材，便于在标签栏中识别。

| 设置项 | 建议与限制 |
|---------|---------------|
| 电脑端顶部 Logo | 建议尺寸为宽 164px、高 36px；系统会按高度自适应显示 |
| 电脑端顶部背景色 | 建议使用与顶部 Logo、导航文字和操作按钮对比度足够的颜色；颜色值通常使用十六进制格式，例如 `#1e2358` |
| 电脑端登录页背景图片 | 建议使用清晰的横向背景图，并预留登录表单区域的可读性 |
| 电脑端登录页 Logo | 建议使用清晰 Logo，避免过宽或过高导致登录页布局拥挤 |
| 移动端登录页 Logo | 建议使用适合小屏展示的 Logo，避免包含过细文字 |
| 浏览器标签页图标 | 建议使用正方形 PNG 或 ICO，推荐 16×16、32×32 或 48×48 像素，背景透明更佳；支持 PNG、ICO、JPG、GIF；单文件不超过 2MB |

上传校验如下：

| 情形 | 系统提示 | 处理方式 |
|------|------------|------------|
| 未选择文件 | 请选择文件 | 重新选择图片或图标后保存 |
| 文件格式不支持（品牌图片） | 仅支持 PNG、JPG、GIF 格式，请重新选择文件。 | 更换为支持的图片格式 |
| 文件格式不支持（标签页图标） | 仅支持 PNG、ICO、JPG、GIF 格式，请重新选择文件。 | 更换为支持的图标格式 |
| 文件大小超过限制（品牌图片） | 最大支持上传 30M 的文件，请重新选择文件。 | 压缩图片或更换较小文件 |
| 文件大小超过限制（标签页图标） | 最大支持上传 2M 的文件，请重新选择文件。 | 压缩图标或更换较小文件 |
| 颜色值格式不正确 | 请输入正确的颜色值 | 按页面要求重新填写颜色值，例如 `#1e2358` |
| 上传过程出错 | 文件上传失败，失败原因： | 根据提示检查网络、文件或稍后重试 |
| 设置过程出错 | 系统异常，请稍后重试。 | 稍后重新保存；多次失败时联系技术支持 |
> \[!TIP\]
如果品牌图片或标签页图标已经保存成功，但页面或标签页显示仍未变化，请先刷新页面或重新打开登录页。浏览器缓存可能会短时间保留旧图片或旧图标。

## 预览登录页背景图

电脑端登录页背景图片通常尺寸较大。品牌设置页面会显示缩略图，方便管理员快速确认当前配置。

将鼠标移动到缩略图上时，页面会提示可查看完整大图。点击缩略图后，系统打开完整图片预览；点击预览区域右侧的关闭按钮后返回品牌设置页面。

完整预览只用于查看图片，不会修改当前配置。如果发现背景图主体被裁切、文字被登录框遮挡或颜色影响登录表单识别，请重新准备图片后再上传。

## 各设置项效果

### 电脑端顶部 Logo

电脑端顶部 Logo 会显示在 Web 端页面顶部导航栏左侧。保存自定义 Logo 后，已登录用户刷新页面即可看到新的 Logo。系统会根据高度自适应显示图片，因此建议使用清晰、留白合理的横向 Logo。

### 电脑端顶部背景色

电脑端顶部背景色会显示在 Web 端页面顶部导航栏。保存后，已登录用户刷新页面即可看到新的顶部背景色。建议选择与顶部 Logo、导航文字和右侧操作按钮对比度足够的颜色，避免顶部区域内容难以识别。

### 电脑端登录页背景图片

电脑端登录页背景图片会显示在 Web 登录页。保存后，用户重新打开登录页即可看到新的背景。背景图应与登录表单保持足够对比度，避免影响用户名、密码、按钮和错误提示的可读性。

### 电脑端登录页 Logo

电脑端登录页 Logo 会显示在 Web 登录页 Logo 区域。保存后，用户重新打开登录页即可看到新的 Logo。若图片比例过大，系统会在可显示范围内自适应处理。

### 移动端登录页 Logo

移动端登录页 Logo 只影响移动端登录页。保存后，移动端用户重新打开登录入口即可看到新的 Logo；电脑端登录页背景图、电脑端顶部 Logo、电脑端顶部背景色和浏览器标签页图标不受影响。

### 浏览器标签页图标

浏览器标签页图标用于替换当前 Sphere 在浏览器标签页中的 Favicon。管理员可在「浏览器标签页图标」分区选择默认图标或自定义图标；选择自定义时需上传图标文件并保存。

保存后，同一 Sphere 内的 Web 登录页、业务端和管理端等通过统一前端壳加载的页面，会使用同一套标签页图标。将使用方式改回默认图标并保存后，用户刷新页面即可恢复平台内置图标。

浏览器标签页图标与浏览器标签页标题相互独立：图标只负责标签栏中的小图标展示；标签页标题仍按系统名称、页面名称和「显示环境类型」等现有规则生成，本配置不会修改标题拼接逻辑。管理员可用图标区分客户或项目品牌，同时用标题区分页面与环境。

浏览器标签页图标不通过配置包跨环境迁移，各 Sphere 需单独维护。配置报告中可审阅当前为默认图标或自定义图标。

## 审计追踪

管理员修改品牌设置后，系统会记录操作日志。日志可用于追踪谁在什么时间修改了哪个品牌设置项，以及修改后的使用方式。

| 日志属性 | 说明 |
|------------|------|
| 用户 | 执行修改操作的用户账号 |
| 操作时间 | 执行操作的时间，格式为 `YYYY-MM-DD hh:mm:ss 时区` |
| 操作模块 | 系统设置 - 品牌设置 |
| 操作对象 | Web Logo、电脑端顶部背景色、Web 登录页背景图片、移动端 Logo、浏览器标签页图标等被修改的设置项 |
| 操作类型 | 编辑 |
| 描述 | 记录修改为默认 Logo / 默认图标，或修改为自定义 Logo / 自定义图标及对应文件路径 |

如需排查品牌设置变更，请结合 [日志管理](04_%E6%97%A5%E5%BF%97%E7%AE%A1%E7%90%86.md) 查看对应时间段的操作记录。

## 配置迁移与配置报告

品牌设置不通过配置迁移执行跨环境迁移。不同 Sphere 需要分别上传图片、标签页图标并保存顶部背景色等品牌配置。

如果在 [配置报告](16_%E9%85%8D%E7%BD%AE%E6%8A%A5%E5%91%8A.md) 中勾选了系统设置，报告中应包含品牌设置相关内容，便于管理员审阅当前环境使用默认图片、自定义图片、自定义顶部背景色，还是默认/自定义浏览器标签页图标。配置报告仅用于查看和归档，不会把品牌配置同步到其他环境。

## 常见问题

**Q：为什么看不到品牌设置菜单？** A：当前账号可能没有品牌设置权限。请检查权限集是否包含“品牌设置：查看”“品牌设置：编辑”或“品牌设置：全部”。

**Q：保存后为什么登录页没有立即变化？** A：请刷新登录页或重新打开浏览器页面。如果仍显示旧图，可能是浏览器缓存或图片上传未成功，请回到品牌设置页面确认当前预览。

**Q：只想修改移动端 Logo，会影响 Web 端吗？** A：不会。移动端登录页 Logo 只影响移动端登录入口，电脑端顶部 Logo、电脑端顶部背景色、电脑端登录页 Logo 和背景图片不会随之变化。

**Q：设置电脑端顶部背景色后为什么顶部文字不清楚？** A：顶部背景色与导航文字、Logo 或按钮颜色对比度不足时，可能影响识别。请换用更深或更浅的颜色，并刷新 Web 页面确认显示效果。

**Q：可以把品牌设置迁移到其他 Sphere 吗？** A：品牌设置不进行配置迁移。目标 Sphere 需要由管理员单独进入品牌设置页面上传图片和标签页图标，并保存顶部背景色等配置。

**Q：上传文件提示格式或大小不符合要求怎么办？** A：品牌图片请转换为支持的 PNG、JPG 或 GIF 格式，并确保文件大小不超过系统限制；浏览器标签页图标另支持 ICO，且单文件不超过 2MB。建议压缩后再上传。

**Q：浏览器标签页图标和浏览器标题有什么区别？** A：标签页图标只替换 Favicon；标签页标题仍按系统名称、页面信息和环境类型等现有规则显示，二者独立配置、互不影响。

**Q：自定义标签页图标后，哪些页面会生效？** A：保存后对当前 Sphere 的 Web 登录页、业务端和管理端等统一前端页面生效。未配置过的环境升级后仍使用默认图标，可按需改为自定义。
