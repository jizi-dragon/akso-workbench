# 批量导入导出
> **所需权限**：系统管理员   

---

## 概述

Gaia 平台提供**批量导入导出**能力，支持通过 Excel 文件批量加载和提取数据。该功能适用于数据迁移、环境初始化、批量数据维护等场景。
> \[!IMPORTANT\]
导入导出的入口由管理员通过**菜单配置**开放给对应用户，菜单访问权限由权限集控制。 **配置说明：** 无需通过系统开关单独启用导入导出功能；如需使用，请先完成菜单配置并分配相应权限。   

### 限制说明

| 限制项 | 限制值 |
|---------|---------|
| **导入文件大小** | 最大 1024 MB |
| **导入数据条数** | 单次最多 50,000 条 |
| **导出数据条数** | 单次最多 100,000 条 |

### 主要能力

| 能力 | 说明 |
|------|------|
| **批量加载工具** | 支持 Excel 格式的批量导入与导出，实现数据的高效迁移和维护 |
| **多种导入模式** | 标准导入、文档迁移模式、记录迁移模式，满足不同场景需求 |
| **并发作业** | 支持多个加载作业并行执行，提高处理效率 |
| **结果日志** | 导入完成后生成 Excel 格式的成功/失败日志，便于问题排查 |
| **列表视图切换** | 列表视图切换器支持多选，可同时切换多个视图进行对比查看 |
| **导出格式** | 导出结果统一为 Excel 文件，支持合并主对象、空值显示为 N/A |

## 批量导入

### 准备导入文件

#### 文件格式要求

| 要求 | 说明 |
|------|------|
| **格式** | Excel（`.xlsx`） |
| **首行** | 必须包含列标题，对应对象字段的 code |
| **工作表** | 按模板要求填写指定工作表，不要修改表头结构 |
| **特殊字符** | 单元格内容可直接填写文本；涉及长数字、编号时建议设置为文本格式 |

#### 模板获取
1. 进入【批量导入导出】页面
2. 选择目标对象类型
3. 点击【下载导入模板】
4. 按模板格式填写数据
> 💡 **提示**：使用模板可确保列名和格式正确，减少导入失败。   

---

### 标准导入模式

标准模式适用于常规数据导入，会执行对象的触发器和验证规则。

#### 操作步骤
1. 点击【新建导入作业】
2. 填写作业信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 作业名称 | 便于识别的作业标识 | ✓ |
| 对象类型 | 要导入的目标对象 | ✓ |
| 导入文件 | 上传 Excel 文件（`.xlsx`） | ✓ |
| 导入模式 | 选择「标准导入」 | ✓ |
| 错误处理 | 遇错继续/遇错中止 | ✓ |
3. 点击【开始导入】
> ⚠️ **注意**：标准模式下，若某行数据验证失败，根据「错误处理」设置，作业可能继续处理剩余行或立即中止。   

---

### 文档迁移模式

文档迁移模式用于跨 Sphere 迁移文档时，**保留原始版本号和编号**，适用于数据迁移、备份恢复等场景。

#### 适用场景
- 从其他 Sphere 迁移文档至当前 Sphere
- 需要保持文档 ID、版本号与源系统一致
- 文档历史追溯要求严格

#### 操作步骤
1. 点击【新建导入作业】
2. 选择对象类型（文档对象）
3. 在【导入模式】中选择 **文档迁移模式**
4. 上传包含文档元数据及版本信息的 Excel 文件（`.xlsx`）
5. 点击【开始导入】

#### 字段要求

| 字段 | 说明 | 必填 |
|------|------|------|
| `id` | 文档主键 ID | ✓ |
| `name&#95;&#95;v` | 文档名称 | ✓ |
| `document&#95;number&#95;&#95;v` | 文档编号 | ✓ |
| `version&#95;&#95;v` | 版本号 | ✓ |
| `lifecycle&#95;&#95;v` | 生命周期状态 | ✓ |
| `file&#95;&#95;v` | 文件字段路径或 URL | ✓ |
> 🔒 **合规要点**：文档迁移模式会保留原始版本信息，导入前请确认源数据合规，迁移后需进行数据核对和审计验证。   

---

### 记录迁移模式

记录迁移模式用于批量导入业务对象记录时，**跳过触发器和验证规则**，适用于从外部系统迁移历史数据。

#### 适用场景
- 从外部系统迁移历史业务数据
- 需要导入不符合当前验证规则的历史记录
- 批量数据修复或补录

#### 操作步骤
1. 点击【新建导入作业】
2. 选择目标对象类型（业务对象）
3. 在【导入模式】中选择 **记录迁移模式**
4. 上传 Excel 文件（`.xlsx`）
5. 点击【开始导入】
> ⚠️ **注意**：记录迁移模式绕过验证规则，仅应由系统管理员在数据迁移场景下使用。导入后请人工核查关键数据。

### 导入结果查看

导入完成后，系统生成**结果日志**供查看和下载。

#### 日志内容

| 列 | 说明 |
|---|------|
| 行号 | 导入文件中的行序号 |
| 状态 | 成功 / 失败 |
| 记录 ID | 成功时系统分配的主键 |
| 错误信息 | 失败时的具体原因 |

#### 查看步骤
1. 进入【批量导入导出】\>【作业历史】
2. 找到目标作业，点击【查看结果】
3. 可在线查看或下载 Excel 日志
> 💡 **提示**：失败行可根据错误信息修正后，重新导出失败行子集再次导入。   

#### 错误提示优化

批量导入的**错误提示**已优化，便于快速定位和修正问题：

| 优化项 | 说明 |
|---------|------|
| **错误定位** | 明确标识失败行号及对应字段，减少排查时间 |
| **原因说明** | 错误信息更具可读性，便于理解验证失败原因 |
| **修正建议** | 常见错误类型附带简要修正建议，提高数据修正效率 |

## 批量导出

### 按对象导出

支持按**对象类型**导出该类型下的全部或筛选后的数据。

#### 操作步骤
1. 点击【新建导出作业】
2. 填写导出配置：

| 字段 | 说明 | 必填 |
|------|------|------|
| 作业名称 | 便于识别的作业标识 | ✓ |
| 对象类型 | 要导出的对象 | ✓ |
| 导出字段 | 选择需要导出的字段（默认全部） | ✓ |
| 筛选条件 | 可选，见下文 | - |
3. 点击【开始导出】
4. 作业完成后下载生成的 Excel 文件

---

### 列表视图导出

在对象列表页面，支持直接导出当前视图数据，提供多种格式和显示选项。

#### 视图切换器多选
- **列表视图切换器** 支持**多选**，用户可同时勾选多个视图，在视图间快速切换或对比查看
- 适用于需要频繁在不同筛选条件下查看数据的场景

#### 导出为 Excel

| 选项 | 说明 |
|------|------|
| **合并主对象** | 导出包含相关对象时，支持将主对象数据合并显示，便于阅读和统计分析 |
| **空值显示** | 导出数据中的空白单元格统一显示为 **N/A**，便于区分「未填写」与「填写了空字符串」 |

### 导出筛选条件

导出时可设置筛选条件，仅导出符合条件的数据。

#### 支持的筛选方式

| 筛选类型 | 说明 | 示例 |
|------------|------|------|
| **字段等于** | 字段值等于指定值 | `生命周期状态 = 已批准` |
| **字段包含** | 文本字段包含指定字符串 | `文档名称 包含 SOP` |
| **字段范围** | 数值或日期在范围内 | `创建时间 在 2025-01-01 至 2025-12-31` |
| **字段为空** | 字段值为空或非空 | `负责人 为空` |
| **组合条件** | 多个条件 AND/OR 组合 | `状态=已批准 AND 创建人=张三` |
> 💡 **提示**：合理使用筛选可减少导出数据量，加快导出速度并便于后续处理。

## 作业管理

### 并发作业

Gaia 平台支持**多个导入/导出作业并行执行**。

| 说明 | 详情 |
|------|------|
| **并行数量** | 可同时运行多个作业（数量受租户配额限制） |
| **独立性** | 各作业互不影响，可分别监控进度 |
| **资源分配** | 系统自动分配计算资源 |

### 状态监控

#### 作业状态

| 状态 | 说明 |
|------|------|
| **排队中** | 作业已提交，等待执行 |
| **执行中** | 作业正在处理 |
| **已完成** | 作业成功完成 |
| **部分成功** | 导入作业部分行成功、部分行失败 |
| **已失败** | 作业执行失败 |
| **已取消** | 用户手动取消 |

#### 监控操作
1. 进入【批量导入导出】\>【作业历史】
2. 查看作业列表中的状态、进度、开始/结束时间
3. 执行中的作业可点击【取消】中止
4. 已完成的作业可【查看结果】或【下载文件】

## 常见问题

**Q: 导入的 Excel 文件内容显示异常怎么办？** A: 请优先使用系统下载的 Excel 模板，并保持文件格式为 `.xlsx`。若编号、长数字或日期显示异常，建议在 Excel 中将对应列设置为文本或按模板要求填写后重新导入。

**Q: 部分行导入失败，如何快速定位？** A: 下载导入结果日志 Excel，筛选「状态=失败」的行，根据「错误信息」列修正数据后重新导入。

**Q: 文档迁移模式与标准模式的区别？** A: 文档迁移模式保留原始版本号和编号，适用于跨 Sphere 文档迁移；标准模式会生成新的版本号和编号，适用于常规文档创建。

**Q: 记录迁移模式是否会跳过审计？** A: 不会。记录迁移模式仅跳过触发器和验证规则，所有数据变更仍会完整记录在审计追踪中。

**Q: 导出数据量很大时如何处理？** A: 建议使用筛选条件分批次导出，或联系管理员调整导出配额。单次导出建议不超过 10 万行。

**Q: 是否支持命令行批量导入？** A: 当前版本仅支持通过管理控制台界面操作，不支持独立的命令行工具（CLI）。

## 列表导入

### 概述

列表导入功能支持在对象列表和相关对象列表上直接导入数据，实现列表和相关对象数据的快速录入。

**访问路径：** 对象列表页面 \> 操作栏 \> **数据导入**

### 功能特点
- 基于现有导入导出工具实现，屏蔽页面左侧菜单
- 自动携带对象信息，对象属性显示为查看模式
- 动作类型限定为创建，显示为查看模式
- 隐藏迁移模式选项
- 导入的数据限定在当前业务单元

### 权限控制

导入数据需考虑以下权限：
- 用户必须具有对象的创建权限
- 必须具有关系权限才允许写入
- 导入的数据只能限定在当前业务单元，导入其它业务单元的数据会失败

### 进入动作：检查活跃导入任务

在对象和文档生命周期新增进入动作类型：「检查是否存在活跃的导入数据任务」。

配置参数：

| 属性 | 值说明 | 控件 | 是否必填 |
|------|---------|------|------------|
| **关系** | 当前对象的关系 | 关系选择控件 | ✓ |
| **存在活跃任务提示语** | 文本（500字符） | 多行文本框 | ✓ |

作用：配置后如果存在未导入完成的任务，则抛错回滚，回到上一状态，同时提示设置的错误信息。

## 导出配置报告

### 概述

配置报告生成包含配置信息的 Excel 报告，其中包括配置迁移数据包组件、非组件类型，以及组件使用的引用数据。此功能可用于在任何配置项目之前和之后跟踪及记录系统的配置。

**访问路径：** 管理端 \> 部署管理 \> 配置报告

### 创建配置报告
1. 进入 **管理端** \> **部署管理** \> **配置报告**
2. 点击 **创建**
3. 配置导出选项：

| 字段 | 说明 | 必填 |
|------|------|------|
| **组件类型** | 选择要导出的组件类型（穿梭框，默认所有组件类型都在已包含列表中） | ✓ |
| **对象数据** | 选择要导出的对象数据（本次暂不实现） | ✗ |
| **系统设置** | 控制在报告中是否包括系统设置 | ✗ |
| **文档模板** | 控制在报告中是否包括文档模板（当组件包含页面模板、叠加层模板、标签模板、运行报告时有效） | ✗ |
| **已停用组件** | 选中后，导出包含组件实例状态为停用的组件实例 | ✗ |
| **空结果** | 当组件实例无数据时，不生成对应的sheet | ✗ |
| **仅包含指定时间之后修改过的组件** | 输入日期，以便仅包括指定日期当天或之后修改的组件和子组件 | ✗ |
4. 点击 **生成** 按钮，系统创建导出配置报告任务并执行导出

### 报告生成逻辑

报告生成逻辑如下：
1. **报告格式**：报告主体是一个 Excel 文件，如果包含了附件，则附件是单独的文件，整个导出的结果为一个 ZIP 压缩包
2. **报告名称**：格式为「配置报告」\+YYYYMMDD
3. **报告结构**：由封面页、目录页、组件实例内容页构成
4. **组件Sheet**：每个组件的实例数据写入一个Sheet，组件Sheet的名称为对象的名称，子组件Sheet名称为\{父组件名称\}.
5. **封面页**：展示产品Logo和报告概要说明，包括域名、Sphere 类型、版本、组件、生成时间等信息

### 报告状态

| 状态 | 说明 |
|------|------|
| **待执行** | 导出任务已创建，但是还未执行 |
| **生成中** | 正在提取数据 |
| **打包中** | 数据提取完成，正在打包文件 |
| **完成** | 报告打包完成，可以正常下载 |
| **失败** | 导出过程中出现错误 |
| **取消** | 任务被取消 |

### 操作功能

不同状态下的记录可以有不同的操作：

| 操作 | 适用状态 |
|------|------------|
| **下载报告** | 完成 |
| **取消** | 待执行、生成中、打包中 |
| **重试** | 失败 |
