## 功能概述

UI设置用于统一控制租户内页面交互行为。配置保存后，对应行为会在前端页面立即生效或在刷新后生效。

适用场景：
- 统一对象列表交互体验
- 优化对象详情打开方式
- 控制创建页按钮显示逻辑
- 管理移动端扫码统一入口
- 控制业务平台右上角是否显示帮助中心图标

## 访问入口

进入 `管理控制台 > 系统设置 > 常规设置 > 用户界面选项`。
进入 `管理控制台 > 系统设置 > 常规设置 > UI设置`。

## 配置项说明

### 一、用户界面选项

| 配置项 | 开启后的效果 | 关闭后的效果 |
|---------|------------------|------------------|
| 启用对象列表中的行内功能 | 列表行内显示快捷操作，用户可直接在当前行处理常用动作。 | 行内快捷操作不显示，需要通过详情页或其他入口处理。 |
| 展示可点击文本的跳转链接 | 可跳转文本以链接形式展示，点击后进入目标记录。 | 文本仅展示，不提供跳转。 |
| 列表开启斑马纹显示 | 列表行交替底色显示，提高多行数据可读性。 | 列表使用统一底色显示。 |
| 启用面包屑 | 页面顶部显示面包屑路径，便于返回上级页面。 | 不显示面包屑路径。 |
| 启用列表行内编辑 | 允许在列表中直接编辑可修改字段。 | 需要进入详情页或编辑页修改字段。 |
| 启用列表操作列 | 列表显示独立“操作列”，集中展示编辑/删除等动作。 | 不显示独立操作列，按页面默认方式展示操作入口。 |
| 分页控件显示在列表下方 | 分页器固定显示在列表底部。 | 分页器按系统默认位置显示。 |
| 列表启用分组 | 列表可按分组字段进行分组查看。 | 列表不按分组方式展示。 |

### 二、UI设置

| 配置项 | 配置值/状态 | 说明 |
|---------|----------------|------|
| 相关对象详情打开方式 | 在抽屉中打开 | 点击相关对象记录时，在当前页以抽屉方式打开详情。 |
| 无数据显示方式 | N/A | 当前租户该项显示为 N/A。 |
| 不启用表单版本校验 | 未勾选 | 勾选后将不执行表单版本校验；未勾选时按标准规则校验。 |
| 启用表头筛选 | 已勾选 | 列表表头显示筛选入口，可直接按列筛选。 |
| 树形对象列表显示视图切换器 | 已勾选 | 树形对象列表可切换不同视图模式。 |
| 隐藏保存并继续创建按钮 | 已勾选 | 创建页不显示“保存并继续创建”按钮。 |
| 移动端扫码统一入口 | 已勾选 | 移动端使用统一扫码入口。 |
| 显示帮助中心 | 勾选后生效 | 勾选并保存后，业务平台右上角显示帮助中心图标；关闭后不显示该图标。图标位置见 [首页导航](../02_%E7%94%A8%E6%88%B7%E6%8C%87%E5%8D%97/01_%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/03_%E9%A6%96%E9%A1%B5%E5%AF%BC%E8%88%AA.md)。 |

## 配置步骤
1. 进入 `管理控制台 > 系统设置 > 常规设置 > UI设置`。
2. 按业务要求调整“页面基础项”和各开关项。
3. 点击保存。
4. 刷新业务页面，验证列表、详情和创建页行为是否符合预期。

---

## 使用建议
- 在生产环境变更前，先在测试环境验证关键对象列表的展示和编辑流程。
- 若开启“列表行内编辑”，建议同步检查角色权限，避免超范围修改。
- 若开启“不启用表单版本校验”，建议设置变更窗口并在完成后恢复标准校验规则。

## 常见问题

### 1\. 开启了某个 UI 开关但页面没有变化，怎么办？

先确认是否已保存；再刷新页面或重新登录。若仍无变化，检查该页面是否受对象级配置或权限配置覆盖。

### 2\. 什么时候建议隐藏“保存并继续创建”？

当业务更强调单条数据质量、需要逐条复核，或不希望用户连续快速创建时，建议开启“隐藏保存并继续创建按钮”。
