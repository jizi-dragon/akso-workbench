# 系统设置
> 本文介绍 Gaia 平台的系统级配置项，包括常规设置、水印设置（页面/附件/打印）、搜索设置、安全设置、品牌设置、语言与地区、第三方配置、翻译控制台、数字签名策略、安全策略与域设置（密码策略、LDAP、OAuth2.0、CA、数字身份认证、网络访问规则）等。   

---

## 概述

系统设置控制平台的全局行为，影响所有用户和应用。管理员可通过系统设置集中管理和调整各项配置，系统会定期进行**设置项整理优化**，保持配置结构的清晰与可维护性。**管理端部分交互展示**持续优化，提升配置操作效率。

**访问路径**：管理控制台 \> 系统设置

---

## 1\. 常规设置

常规设置页面包含了系统运行所需的核心配置项。覆盖模块包括：运行报告名称设置、系统信息、许可证信息、对象设置、UI设置、活页夹（活动夹）选项、批量动作、评论、配置管理、委托访问、文件资料、注解、用户资料、用户界面选项、用户对象、导入导出、工作流、XML生成、暂存箱、登录页面设置、接口设置、文档加解密设置、培训设置、AI设置、消息设置、助手设置、审计追踪设置等。以下按照界面显示顺序逐一说明：
> **无效配置项清理**：随版本迭代，部分已废弃或重复的配置项已从系统设置中移除（例如活页夹相关废弃项、重复的批量动作项、已移除的配置包迁入迁出项、已移除的委托访问项、XFA 表单映射等）。页面仅保留当前仍生效的配置；若升级后找不到旧开关，通常表示该项已清理，无需再配置。   

### 1.1 运行报告名称设置

定义配置包和运行报告的生成命名规则。支持使用变量（如 `{!record.name__ak}`）来自动生成标准化的文件名称。

### 1.2 系统信息

显示当前系统的基础身份信息，包括：
- **系统ID/名称**：系统的唯一标识及显示名称。
- **版本信息**：当前平台版本 (v3.6) 及配置版本 (e.g., 1.0.x)。系统会**正确显示程序版本号**，便于管理员确认当前运行版本及进行配置迁移时的兼容性校验。
- **服务器地址**：当前环境的物理或逻辑服务器地址。

### 1.3 许可证信息

在系统设置中可查看 License **基础信息**，包括 License 状态、有效期、允许的用户数量及启用的功能模块限制等授权详情。**环境信息和 License 信息界面**已进行调整优化，信息展示更清晰，便于管理员快速掌握系统授权状态。

### 1.4 对象设置

控制系统对象的全局行为：
- **代码编辑**：是否允许在界面上直接编辑对象代码。
- **引用链接**：配置对象引用字段在界面上的链接跳转样式。
- **统计字段加速**：统计字段在执行统计时会有延迟，开启后可降低延迟、加快统计速度。建议在使用统计字段时开启。

### 1.5 检查表设计设置

配置检查表（Checklist）模块的基础规则：
- **ID设置**：定义检查表项的 ID 生成逻辑。
- **题库配置**：管理智能题库或结构化检查项的默认属性。

### 1.6 UI设置

控制全局界面的基础显示样式：
- **行高设置**：表格的默认行高（如紧凑、标准）。
- **滚动条**：全局滚动条的显示行为。
- **分组显示**：默认的表格分组展示样式。
- **字体大小**：系统支持设置**全局字体大小**，用户可根据阅读习惯调整界面显示字号。
- **移动端允许创建/编辑的对象**：按对象维护白名单；仅列入名单的对象在移动端开放创建与编辑入口。未列入的对象在移动端通常仅可查看，不提供创建/编辑。详见 [32\_UI设置.md](32_UI%E8%AE%BE%E7%BD%AE.md)。

### 1.7 活页夹/活动夹选项

配置活页夹（活动夹/Binder）的功能：
- **显示设置**：定义活动夹在列表和详情里的默认视图。
- **管理权限**：控制谁可以创建或修改活动夹结构。

### 1.8 批量动作

控制列表页面的批量操作权限：
- **批量检出**：允许用户批量检出文档。
- **批量下载**：允许批量下载源文件。
- **批量审核**：允许对多条记录进行批量审批/审核。

### 1.9 评论

系统的全局评论开关。启用后，用户可以在文档或记录的详情页发表评论和批注。

### 1.10 配置管理

管理系统配置包 (Configuration Package) 的生命周期：
- **迁出/迁入**：控制是否允许配置包的导入导出操作。
- **配置模式**：启用后允许修改系统级元数据。
- **部署策略**：是否允许部署包含“阻止”级别错误的步骤。
- **版本校验**：**配置迁移的校验程序**会**读取系统设置中的程序版本**，确保配置包与目标环境版本兼容，避免迁移冲突。
- **生产环境隔离**：**生产环境禁止访问配置管理模块**。在生产环境中，配置管理相关功能不可用，以降低误操作风险，确保生产配置稳定。配置变更需在沙箱或测试环境完成，通过部署包迁移至生产。

### 1.11 委托访问

配置权限委托规则：
- **系统委托**：管理员视角的全局委托设置。
- **用户委托**：允许用户自行设置短期委托（如休假期间的审批代理）。

### 1.12 文件资料

管理文件上传与处理策略：
- **上传限制**：单文件大小限制 **2048MB**，单次批量上传限制 **10** 个文件。
- **文件处理**：配置 Linux 下的文件转换服务、PDF 合并策略。
- **盲审与版本**：盲审模式开关及文件版本控制规则。

### 1.13 注解

配置文档或记录上的批注功能。启用后，用户可在预览界面添加文字标注、高亮等批注，用于协作审阅。

### 1.14 用户资料

控制用户个人信息的管理权限：
- **更新权限**：是否允许用户自行更新个人资料（如头像）。
- **布局设置**：定义个人中心的默认布局模板（如区分内部员工与外部人员布局）。

### 1.15 用户界面选项

细化控制列表和详情页的交互体验：
- **列表功能**：启用斑马纹、面包屑导航、行内编辑、侧边操作列。
- **列表启用分组**：勾选后在列表视图中启用分组显示，便于按分组字段组织数据。
- **交互逻辑**：设置分页控件位置（底部）、无数据时的状态显示（空状态/加载中）。
- **详情打开方式**：关联对象的详情页是在当前窗口、抽屉还是对话框中打开。
- **备注高度**：支持**缩小备注区域高度**，使界面更紧凑，适合需要更多可见内容区域的场景。

### 1.16 用户对象

配置用户 (User) 对象的特定扩展属性或行为规则，用于满足特定的用户管理需求。

### 1.17 导入导出

控制全系统的数据交换能力。新建系统需由管理员手动启用导入导出，导入导出的菜单权限由权限集控制。
- **文件大小限制**：最大 **2048MB**。
- **数量限制**：单次导入限制 **50000** 条记录，导出限制 **100000** 条记录。

### 1.18 工作流

配置工作流引擎的全局表现：
- **任务管理**：待办任务列表的显示列与排序规则。
- **按钮设置**：流程操作按钮的尺寸及在详情页的显示逻辑。
- **以角色作为参与人不使用用户默认列表布局的过滤条件**：工作流参与人中以角色作为参与人的控件，默认会使用用户默认列表布局的过滤条件（用于基础筛选或组织隔离）。在需要跨组织协作、参与人需选择其他组织人员的场景，可勾选此项，使参与人不使用用户默认列表布局的过滤条件；过滤需求可通过控件上的过滤条件单独配置。
- **取消工作流时输入电子签名**：全局开关，默认关闭。开启后，业务端取消工作流（含首页活动工作流、时间线、多记录工作流等入口）时须完成电子签名；可配置电子签名类型、签名含义、是否要求填写签名备注。签名记录写入该对象对应的电子签名对象。若工作流详情已配置取消动作，电子签名在取消动作执行前完成校验。升级后默认关闭，不影响既有取消行为。

### 1.19 XML生成

配置 XFA 表单与 XML 数据之间的映射规则，用于处理特殊的表单渲染与数据提取需求。

### 1.20 暂存箱

配置暂存箱 (Draft Box) 功能。启用后，允许用户在未完成记录创建时保存草稿，防止数据丢失。

### 1.21 登录页面设置

自定义系统登录页的视觉与逻辑：
- **登录方式**：支持使用**用户名**、**邮箱**或**手机号**登录，管理员可配置允许的登录方式。
- **外观**：上传自定义背景图片。
- **协议**：编辑登录时需同意的用户协议/隐私条款。
- **组织**：多租户环境下的默认组织选择逻辑。
- **隐藏公司名称**：可配置在登录页**隐藏公司名称**的显示，满足部分场景的展示需求。

### 1.22 接口设置

配置系统的全局 API 接口地址，用于对外提供服务或与其他系统集成。

### 1.23 文档加解密设置

控制文件存储的安全性。启用后，系统会对上传的文档进行加密存储，下载时自动解密。

### 1.24 培训设置

配置培训管理模块的逻辑：
- **启用公开课**：开启后相关公开课内容可供使用。
- **防盲学**：勾选后系统采取措施防止学员盲目学习。
- **培训完成率是否仅计算专属培训任务**：勾选后，培训完成率只统计专属培训任务的完成情况。
- **启用智能出题**：启用 AI 辅助生成考试题目。
- **防止盲目完成错题回顾任务**：勾选后系统采取措施避免学员不认真对待错题回顾任务。
- **禁用题型**：设置禁止使用的题型类别。

### 1.25 AI设置

配置系统的 AI 智能服务：
- **状态**：**已启用**。
- **接口地址**：指向 AI 服务端点（如 `ai-service.example.com`）。
- **AI 对话 Agent**：支持启用 **AI 对话 Agent**，为用户提供智能问答、操作指引、内容辅助等 AI 辅助能力。

### 1.26 消息设置

**全局消息开关**：控制是否一键关闭系统内所有的通知消息（通常用于系统维护期间）。

### 1.27 助手设置

启用系统的智能助手功能。（如“智能助手”。启用后，用户可获得智能助手提供的法规查询、操作指引等辅助服务。

### 1.28 审计追踪设置

**已启用**。开启相关对象的详细审计日志 (Audit Trail) 功能，确保所有关键操作可追溯。审计日志中**显示时区信息**，便于跨时区场景下的操作时间精确追溯。

### 1.29 ERS设置

**ERS（电子记录系统）** 是系统的一项功能特性。
- 启用后，该功能特性即可使用。

### 1.30 工作日历管理

系统支持**工作日历管理**，用于定义组织的工作日、节假日及特殊日期。工作日历可被工作流、任务调度、到期提醒等模块引用，确保时间计算准确。管理员可配置：
- **工作日**：默认周一至周五为工作日，可自定义调整。
- **节假日**：配置法定节假日及企业自定义假日。
- **特殊日期**：设置调休、补班等特殊安排。

## 2\. 水印设置

系统提供三类水印配置，分别作用于不同场景：

| 类型 | 作用范围 | 主要用途 |
|------|------------|------------|
| **页面水印** | 电脑端、移动端页面 | 防止屏幕内容泄密 |
| **附件水印** | 下载的附件（仅 PDF 格式） | 防止下载文件外传 |
| **打印水印** | 文件打印输出 | 防止纸质文档未授权传播 |

---

### 2.1 页面水印设置

设置电脑端和移动端页面的屏幕水印，实时叠加在系统界面上，用于防止屏幕内容泄密。支持实时预览。

#### 2.1.1 水印状态

| 配置项 | 说明 |
|---------|------|
| **开启水印** | 全局控制页面水印的启用/关闭。启用后，系统将在电脑端和移动端所有页面上叠加水印。 |

#### 2.1.2 水印内容

支持插入动态变量，构建个性化的水印文本：

| 变量标签 | 说明 | 示例输出 |
|------------|------|------------|
| **缩号** | 插入编号或序号 | 001 |
| **当前时间** | 插入当前日期时间 | 2026-02-03 17:12 |
| **当前时间戳记录** | 插入时间戳 | 1738577534 |
| **姓名** | 插入当前用户姓名 | 张三 |
| **字色值** | 插入水印颜色值 | #333333 |
| **字数行** | 插入水印文本行数 | 3 |

#### 2.1.3 样式设置

| 配置项 | 可选值/单位 | 说明 |
|---------|----------------|------|
| **对齐方式** | 左对齐、居中对齐、右对齐 | 水印文本的对齐方式 |
| **水印字体** | 微软雅黑、宋体、黑体等 | 水印文本的字体 |
| **水印颜色** | 十六进制色值 | 水印文本颜色（如 #333333） |
| **水印大小** | px | 水印文字的字号 |
| **不透明度** | % | 水印透明度（0-100%） |
| **旋转角度** | ° | 水印文本的旋转角度，45° 为常用页面水印设置 |

#### 2.1.4 水印密度

选择水印在页面上的分布密度：

| 密度模式 | 说明 |
|------------|------|
| **稀疏** | 水印间距较大，视觉干扰较小 |
| **标准** | 默认密度，平衡安全性与可读性 |
| **密集** | 水印间距较小，安全性更高但可能影响阅读 |
| **自定义** | 手动设置电脑端和移动端的水印行列数 |

**自定义密度配置**：

| 设备类型 | 配置项 | 默认值 | 说明 |
|------------|---------|---------|------|
| **电脑端** | 行数 × 列数 | 3行 × 3列 | 设置电脑屏幕上水印的分布网格 |
| **移动端** | 行数 × 列数 | 3行 × 1列 | 设置移动设备屏幕上水印的分布网格 |

#### 2.1.5 实时预览

配置页面底部提供实时预览区域，可直观查看当前水印设置在不同设备上的最终效果。

| **缩率** | 插入文档缩放比例 | 100% |
| **当前时间** | 插入当前日期时间 | 2026-02-03 17:09 |

| **姓名** | 插入当前用户姓名 | 张三 |
| **文件名称** | 插入附件文件名 | 技术规格书.pdf |
| **字色值** | 插入水印颜色值 | #333333 |
| **字数行** | 插入水印文本行数 | 3 |

#### 2.2.3 样式设置

| 配置项 | 可选值/单位 | 说明 |
|---------|----------------|------|
| **对齐方式** | 左对齐、居中对齐、右对齐 | 水印文本的对齐方式 |
| **水印字体** | 微软雅黑、宋体、黑体等 | 水印文本的字体 |
| **水印颜色** | 十六进制色值 | 水印文本颜色 |

| **不透明度** | % | 水印的透明度（0-100%） |

#### 2.2.4 位置布局

| 配置项 | 说明 |

| **水平对齐** | 水印在水平方向的对齐方式（左/居中/右） |
| **垂直对齐** | 水印在垂直方向的对齐方式（上/居中/下） |
| **上下边距** | 水印与页面上下边缘的间距（px） |
| **左右边距** | 水印与页面左右边缘的间距（px） |

#### 2.2.5 实时预览

配置页面底部提供实时预览区域，可直观查看当前附件水印设置的最终效果。

### 2.3 打印水印设置

控制文件打印时的水印策略，用于防止纸质文档的未授权传播。支持实时预览。

#### 2.3.1 水印开关

| 配置项 | 说明 |
|---------|------|
| **透明度从服务端获取** | 控制是否从服务端获取水印透明度。启用后，水印透明度由服务端统一控制，确保打印输出的一致性。 |
| **开启水印** | 启用后，文件打印时将自动添加水印。 |
| **开启预览效果的防伪水印** | 启用后，文档预览界面将显示防伪水印。 |
| **开启透明效果水印** | 启用后，打印输出将自动添加透明水印。 |

#### 2.3.2 水印内容

支持插入动态变量，构建个性化的打印水印文本：

**默认模板示例**：   `打印人Print Operator：{{printUser}}{{time}}打印时间Print Time：{{printTime}}`

| 变量标签 | 说明 | 示例输出 |
|------------|------|------------|
| **打印时间** | 插入打印时的日期时间 | 2026-02-03 17:13 |

- 默认值：不勾选

## 10\. 安全策略与域设置 (Domain Setting)

### 10.1 安全策略

配置域级别的安全策略列表，每个策略可定义不同的身份认证方式和访问控制规则。系统支持**同时启用多个安全策略**，管理员可根据组织单元或租户配置差异化的安全规则。

#### 安全策略列表

| 列名 | 说明 |
|------|------|

| **状态** | 策略的启用状态（启用/已禁）。 |
| **来源** | 策略的来源类型（系统、标准等）。 |
| **认证类型** | 该策略使用的身份认证方式（见下表）。 |
| **描述** | 策略的详细说明。 |
| **操作** | 编辑、删除等管理操作。 |

**列表功能**：
- 支持关键词搜索，匹配名称字段
- 默认按创建时间倒序排列
- 分页展示所有安全策略

#### 支持的认证类型

系统支持以下三种认证类型，并可启用\*\*多因子身份认证（MFA）\*\*增强账户安全：

| 认证类型 | 功能说明 | 子类型 | 是否支持重置密码 | 电子签名 |
|------------|------------|---------|------------------------|------------|
| **密码验证** | 用户通过输入用户名和密码方式进行登录 | 无 | 支持 | 和登录验证一致 |
| **LDAP验证** | 用户通过 LDAP 协议登录 | AD域、OpenLDAP等 | 在策略中可以设置是否支持，如需支持，需要进行开发对接 | 和登录验证一致 |
| **单点登录验证** | 通过 SSO 进行登录，一般会跳转到 SSO 统一登录平台 | SAML、OAuth2.0等 | 不支持 | 和登录验证一致，可设置在 iFrame 或者弹出层中输入电子签名 |

#### 策略配置详情

点击"编辑"按钮可进入策略的详细配置页面，包含以下配置项：

**基本信息**

| 配置项 | 字段类型 | 说明 |
|---------|------------|------|
| **名称** | 字符串（1-200字符） | 策略的唯一标识名称，必填，在列表中可点击进入详情页 |
| **Code** | 字符串（1-200字符） | 策略的代码标识符（如 API 名称），必填，保存后不可修改 |
| **状态** | 枚举 | 策略的启用状态（启用/停用），默认值：启用 |
| **描述** | 文本（0-500字符） | 策略的详细描述信息 |
| **来源** | 枚举（只读） | 策略来源类型（自定义/标准/系统），默认值：自定义 |
| **认证类型** | 枚举 | 选择该策略使用的身份认证方式（密码验证、LDAP验证、单点登录验证） |

**安全设置** 根据选择的认证类型，配置相应的详细参数：

| 配置项 | 说明 | 可选项 |
|---------|------|---------|
| **认证类型** | 选择该策略使用的身份认证方式 | 密码验证、LDAP验证、单点登录 |
| **配置策略** | 根据选择的认证类型，配置相应的详细参数 | - |
| **电子签名策略** | 配置该策略下的电子签名要求 | - |

#### 策略类型详解

**1\. 密码验证策略**

使用密码验证，包含密码复杂度、登录策略、多因子认证（MFA）等配置。详见下方「10.2 密码策略设置」。

**2\. LDAP 验证策略**

通过 LDAP/AD 域进行统一身份认证。可关联 LDAP 设置，详见下方「10.3 LDAP 设置」。

**3\. 单点登录验证策略**

使用 OAuth2.0、SAML 等协议实现单点登录，支持自动跳转。

**SAML SSO 策略**：
- 可设置项来自 SAML 设置，详见下方「SAML 设置说明」
- 用于规定登录验证方式

**SAML 电子签名策略**：
- 可设置项也来自 SAML 设置
- 用于规定电子签名验证方式

**OAuth2.0/OpenID Connect 策略**：
- 详见下方「10.4 OAuth2.0 策略设置」

**单点登录自动跳转设置**：
- 该开关默认未打开
- 打开后，按单点登录策略跳转到 SSO 平台
- 直接访问可匿名访问的页面时，则不跳转
- 可匿名访问页面包括：隐私协议页面、管理员登录页
- **重要**：该开关只能在系统中其中一个单点登录类型的策略上启用。在保存、编辑、启用时，都要进行检查，如果已经存在开启的单点登录策略，提示："已存在其它单点登录策略开启了自动跳转"

#### SAML 设置说明

SAML 设置主要用于管理单点登录策略，包括登录策略和电子签名策略。

**SAML 配置参数**：

| 参数 | 值说明 | 控件 | 说明 |
|------|---------|------|------|
| **SAML版本** | 1.0, 2.0 | 选项 | SAML 协议版本 |
| **用户标识** | 与 SSO 平台用户信息进行关联的字段 | 选项，来自用户对象的字段 | 用于关联 SSO 平台用户与系统用户 |
| **IdP登录URL** | 身份提供商的登录地址 | 单行文本 | IdP 的登录端点 URL |
| **IdP退出URL** | 身份提供商的退出地址 | 单行文本 | IdP 的退出端点 URL |
| **IdP证书** | 身份提供商的证书文件 | 文件 | 用于验证 SAML 响应的证书 |
| **SP初始请求URL** | 服务提供商的初始请求地址 | 单行文本 | 系统作为 SP 的初始请求 URL |
| **签名摘要算法** | 签名算法类型 | 选项 | SAML 签名的摘要算法 |
| **电子签名展示方式** | iframe, 弹出层 | 选项 | 电子签名时的展示方式 |

**注意事项**：
- SAML 模式下不支持重置密码
- 需要先在身份提供商处配置应用，获取相关参数
- 证书文件需要正确上传，确保 SAML 通信安全

### 10.2 密码策略设置

定义用户密码的复杂度要求、有效期管理和登录安全策略，确保账户安全。

#### 详情

| 配置项 | 说明 |
|---------|------|
| **名称** | 密码策略的名称（如"基础安全策略"）。 |
| **Code** | 策略的唯一标识符（如 `basic&#95;security&#95;policy&#95;config&#95;&#95;ak`）。 |
| **版本** | 策略的版本号（如 N/A 表示无版本控制）。 |
| **来源** | 策略来源类型（系统/自定义）。 |

#### 密码策略

**密码复杂度要求**

| 配置项 | 说明 |
|---------|------|
| **初始密码** | 设置初始密码或默认密码，支持**密码输入框**方式配置。首次登录后，系统默认**强制修改初始密码**以提升安全性。 |
| **密码复杂度要求** | 勾选密码必须包含的字符类型组合。系统支持**密码复杂度前端校验**，在用户输入时实时校验是否符合要求。 |

**强制修改策略**

| 策略 | 说明 |
|------|------|
| **强制修改初始密码** | 默认开启，用户首次登录后必须修改初始密码后方可继续使用。 |
| **密码不符合要求时强制修改** | 当检测到用户密码不符合最新复杂度要求时，强制用户修改密码。 |
| **密码过期后强制修改** | 当密码超过有效期时，强制用户修改密码后方可继续登录。 |

**修改密码与找回密码**

| 配置项 | 说明 |
|---------|------|
| **修改密码界面显示密码要求** | 用户修改密码时，界面会**显示当前密码策略要求**，便于用户按要求设置新密码。 |
| **找回密码验证码** | 用户通过邮箱或手机找回密码时，需**输入验证码**完成身份验证。 |

密码复杂度选项：
- ☑ **数字** \- 密码必须包含数字字符（0-9）
- ☑ **大写字母** \- 密码必须包含大写字母（A-Z）
- ☑ **小写字母** \- 密码必须包含小写字母（a-z）
- ☑ **特殊字符** \- 密码必须包含特殊符号（如 !@#\$%）

**密码长度与有效期**

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **密码最小长度** | 6 | 用户密码的最小字符数（建议至少 8 位）。 |
| **密码是否有会添加密码有效期** | 启用 | 是否启用密码定期过期机制。 |
| **密码有效期限天数** | 不限制 | 密码的有效天数，到期后强制用户修改（如 90 天）。 |
| **密码过期提醒天数** | 不限制 | 密码到期前多少天开始提醒用户修改。 |
| **不该段用户修改密码** | 不限制 | 限制用户在特定时段内不能修改密码（如强制使用初始密码一段时间）。 |

**密码历史与锁定**

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **自动解锁是否开启密码重置后立即可** | 启用 | 密码重置后账户是否自动解锁。 |
| **禁用密码重复** | 不限制 | 防止用户重复使用最近使用过的密码（如保留最近 5 次）。 |
| **接受做放弃检测密码** | 启用 | 是否检测并拒绝弱密码或常见密码。 |

#### 登录策略

**1\. 密码错误锁定账号**

| 配置项 | 说明 |
|---------|------|
| **密码错误锁定账号** | 设定是否开启连续密码错误后锁定账号功能。若选择【不限制】，则不开启【连续密码错误后锁定账号】功能。若选择【设定错误次数上限】，则开启【连续密码错误后锁定账号】功能。用户在输入密码时，若错误次数超过上限，则自动锁定账户，并提示【账号已锁定】。可选范围：3（默认）、5、10 次，或自定义输入（1-10 次）。用户在输入密码时，若密码错误，则提示剩余错误次数。 |

**2\. 连续错误间隔（分钟）**

| 配置项 | 说明 |
|---------|------|
| **连续错误间隔** | 前置：【密码错误锁定账号】选择为【设定错误次数上限】时，该控件才可用。设定定义连续错误的间隔。若用户连续两次登录密码错误的间隔少于**此设定间隔**，则密码错误次数\+1。超过此设定间隔，则该用户密码错误次数清空。可选内容：1、3、5（默认）、10、15、30、60 分钟。 |

**3\. 账号锁定时长**

| 配置项 | 说明 |
|---------|------|
| **账号锁定时长** | 前置：【密码错误锁定账号】选择为【设定错误次数上限】时，该控件才可用。设定因**连续密码错误次数**超过上限而锁定账户的锁定时长。若设定为永久锁定，则账号不会自动解除锁定。若设定为自动解锁，则在对应时间后，账号自动解锁。当用户在锁定期间登录，系统提示【您将在\{剩余时间\}后解锁】，剩余时间需实时更新。可选内容：5分钟、10分钟、30分钟、1小时（默认）、6小时、12小时、24小时、72小时、永久。 |

**4\. 登录有效时长**

| 配置项 | 说明 |
|---------|------|
| **登录有效时长** | 设置登录有效时长。用户未操作时间超过有效时长，系统自动退出登录。可选内容：5、10、30、60、120 分钟。 |

**5\. 自动锁屏时间（分钟）**

| 配置项 | 说明 |
|---------|------|
| **自动锁屏时间** | 设定是否开启自动锁屏功能。若选择【不限制】，则不开启【自动锁屏】功能。若选择【设定时长】，则开启【自动锁屏】功能。若用户未操作本系统的时间超过设定时长，则自动锁屏，要求用户再次输入密码，输入密码成功后恢复当前页面。可选范围：1、3、5（默认）、15、30、60 分钟，或自定义输入（1-60 分钟）。 |

**6\. 图片验证码**

| 配置项 | 说明 |
|---------|------|
| **图片验证码** | 设定是否开启图片验证码功能。若选择【关闭】，则不开启【图片验证码】功能。若选择【一直开启】，则一直开启【图片验证码】功能。若选择【根据密码错误次数启动】，若连续密码错误次数超过设定值，则启动【图片验证码】功能。可选范围：1（默认）、3、5、10 次，或自定义输入（1-10 次）。 |

**7\. 登录会话超期提醒**

| 配置项 | 默认值 | 说明 |

| **登录会话超期提醒** | 启用 | 在会话即将超时前提醒用户，用户可选择延长会话或保存工作后退出，避免专注阅读或编辑时因超时被强制退出导致未保存数据丢失。 |

**8\. 唯一浏览器登录**

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **唯一浏览器登录** | 启用 | 是否限制用户只能在一个浏览器会话中登录。 |

### 10.3 LDAP 设置

配置与 AD 域通信的参数，实现统一身份认证和组织架构同步。系统**支持多个 LDAP 设置**，可同时对接多个域。支持**链接测试**和**手动同步 AD 域用户**。

#### 详情

| 配置项 | 说明 |
|---------|------|
| **名称** | LDAP 策略的名称（如"AD域验证安全策略"）。 |
| **Code** | 策略的唯一标识符（如 `ad&#95;domain&#95;security&#95;policy&#95;config&#95;&#95;ak`）。 |
| **版本** | 策略的版本号（如 N/A 表示无版本控制）。 |
| **来源** | 策略来源类型（标准/自定义）。 |

#### 启用 LDAP

配置 LDAP 集成的功能开关和行为策略。

| 配置项 | 说明 |
|---------|------|
| **新用户资料关联** | 启用后，LDAP 认证成功的新用户将自动在系统中创建对应的用户资料。 |
| **同步维护用户** | 启用后，系统将定期同步 LDAP 中的用户信息（如姓名、邮箱、部门等）到平台。 |
| **启用复审验证** | 启用后，LDAP 认证成功的用户需要经过额外的审核流程才能访问系统。 |
| **验证时如果用户输入错误名则** | 配置当用户输入的用户名在 LDAP 中不存在时的处理策略（如提示错误、禁止登录等）。 |
| **从服务器开启验证** | 启用后，系统将使用 LDAP 服务器进行用户身份验证（推荐启用）。 |

#### 服务器信息

配置 LDAP 服务器的连接参数。

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **域名称** | N/A | Active Directory 的域名称（如 `example.com`）。 |
| **服务器地址** | N/A | LDAP 服务器的 IP 地址或主机名（如 `ldap.example.com` 或 `192.168.1.100`）。 |
| **端口** | 0 | LDAP 服务器的端口号（标准端口：389 for LDAP, 636 for LDAPS）。 |
| **基础DN** | N/A | LDAP 目录树的基础 DN（Distinguished Name），如 `DC=example,DC=com`。 |
| **用户资源DN** | N/A | 用户对象所在的 DN 路径（如 `OU=Users,DC=example,DC=com`）。 |
| **过滤器** | N/A | LDAP 用户查询的**过滤条件**。支持设置精细的过滤规则（如 `(&amp;(objectClass=user)(sAMAccountName=&#42;))`），限定同步和认证的用户范围。 |
| **SSL 连接** | 关闭 | 是否启用 SSL/TLS 加密连接（启用后使用 636 端口，推荐启用以提高安全性）。 |
| **基准DN用户映射ID** | N/A | LDAP 用户属性与系统用户 ID 的映射字段（如 `sAMAccountName`）。 |
| **基准DN用户密码** | - | 用于绑定 LDAP 服务器的管理员账号密码（加密存储）。 |

#### 多因子认证MFA设置

| 配置项 | 说明 |
|---------|------|
| **认证方式** | 选择多因素认证的类型（单机认证/邮箱认证） |

认证方式选项：
- ☐ **单机认证** \- 仅使用本地认证方式
- ☐ **邮箱认证** \- 使用邮箱验证码作为第二因素

#### 配置步骤与测试

**配置步骤**：
1. 填写 LDAP 服务器基本信息（域名称、服务器地址、端口）
2. 配置 Base DN 和用户资源 DN
3. 设置用户过滤器和映射规则
4. （推荐）启用 SSL 连接以加密传输
5. 配置绑定账号和密码
6. 启用所需的 LDAP 功能开关

**测试连接**：配置完成后，使用页面顶部的"连接测试"按钮验证 LDAP 配置的正确性。测试成功后即可保存配置。

**手动同步**：支持手动触发 AD 域用户同步，将 LDAP 中的用户和组织信息导入系统。

### 10.4 OAuth2.0 策略设置

配置第三方身份提供商（IdP）的 OAuth2.0 / OpenID Connect 单点登录（SSO）集成。系统**支持多个 OAuth2.0 策略**，由安全策略关联启用。

#### 详情

| 配置项 | 说明 |
|---------|------|
| **名称** | OAuth2.0 策略的名称（如"单点登录安全策略"）。 |
| **Code** | 策略的唯一标识符（如 `sso&#95;security&#95;policy&#95;config&#95;&#95;ak`）。 |
| **描述** | 策略的详细描述信息。 |
| **来源** | 策略来源类型（标准/自定义）。 |

#### OAuth2.0 / OpenID Connect 设置

**基本配置**

| 配置项 | 说明 |
|---------|------|
| **服务名** | OAuth2.0 / OpenID Connect 服务提供商的名称（如 "Azure AD SSO"）。 |
| **授权代码认证地址** | OAuth2.0 授权端点的 URL，用户将被重定向到此地址进行身份验证。 |
| **获取地址** | （可选）用户信息获取地址。 |
| **应用ID** | 在 OAuth2.0 提供商处注册的应用程序客户端 ID（Client ID）。 |
| **应用密钥** | 应用程序客户端密钥（Client Secret），用于服务器端安全通信。 |

**授权类型与参数**

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **授权类型** | 授权码 | OAuth2.0 授权流程类型（授权码模式、隐式授权、客户端凭证等）。 |
| **授权访问Code** | - | 授权码（Authorization Code）的字段名。 |
| **发起授权链** | - | 用于发起授权请求的 URL 链接。 |

**Token 端点配置**

| 配置项 | 说明 |
|---------|------|
| **Token端点地址** | 用于交换授权码获取访问令牌的 API 端点地址（如 `https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token`）。 |
| **用户资源地址** | 用于获取用户信息的 API 端点地址（如 `https://graph.microsoft.com/v1.0/me`）。 |

\| **Scope** \| 请求的权限范围（如 `openid profile email`），多个 scope 用空格分隔。 \|

**回调与跨域配置**

| 配置项 | 说明 |
|---------|------|
| **授权地址** | OAuth2.0 授权回调地址，用户认证成功后将跳转到此地址。 |
| **跨域地址** | CORS（跨域资源共享）允许的域名地址。 |
| **提示** | 授权页面的提示信息或参数（如强制重新登录、选择账户等）。 |

#### Token 与用户属性映射

**Token 配置**

| 配置项 | 默认值 | 说明 |
|---------|---------|------|
| **Access Token** | access\_token | 访问令牌的字段名称。 |
| **Id Token** | id\_token | OpenID Connect ID 令牌的字段名称。 |
| **Token实现** | Bearer | Token 的实现方式（通常为 Bearer Token）。 |

**用户属性映射**

将 OAuth2.0 / OpenID Connect 提供商返回的用户属性映射到 Gaia 平台的用户字段：

| Gaia 平台字段 | IdP 字段名 | 说明 |
|-----------------|-------------|------|
| **开放ID内部源标识** | sub | OpenID Connect 的唯一用户标识符（Subject Identifier）。 |
| **开放ID传给用户名** | openid | OpenID 用户名字段。 |
| **外部ID内部源标识** | externalId | 外部系统的用户 ID 标识。 |
| **邮件内部源标识** | email | 用户的邮箱地址。 |
| **电话内部源标识** | phone\_number | 用户的电话号码。 |
| **用户内部源标识名** | username | 用户的登录用户名（内部）。 |
| **用户外部源标识** | username | 用户的登录用户名（外部）。 |

#### 配置步骤
1. **在 IdP 处注册应用**：在 OAuth2.0 提供商（如 Azure AD、Okta、Google）的管理控制台注册应用，获取 Client ID 和 Client Secret。
2. **配置回调地址**：在 IdP 中配置授权回调地址，确保与系统中的"授权地址"一致。
3. **填写基本信息**：在系统中填写服务名、应用ID、应用密钥等基本信息。
4. **配置端点地址**：填写授权端点、Token 端点、用户资源端点地址。
5. **设置 Scope**：根据需要访问的用户信息，配置合适的权限范围（如 `openid profile email`）。
6. **映射用户属性**：配置用户属性映射规则，确保 IdP 返回的用户信息能正确映射到 Gaia 平台的用户字段。
7. **保存并测试**：保存配置后，使用 SSO 登录测试功能验证配置的正确性。

**支持的 IdP**：Azure AD、Google Workspace、Okta、Keycloak、Auth0 等主流 OAuth2.0 / OpenID Connect 提供商。

**免密访问**：配置 SSO 后，用户**从第三方应用访问系统时无需输入账号密码**，认证成功后自动跳转进入系统，提升使用体验。

### 10.5 CA 策略设置

配置第三方数字证书颁发机构（CA）服务的集成参数，用于数字身份认证和证书管理。主要参数包括：供应商、Host、AppID、AppSecret 等。

#### 详情

| 配置项 | 说明 |
|---------|------|
| **名称** | CA 策略的名称（如"企业CA认证策略"）。 |
| **Code** | 策略的唯一标识符。 |
| **描述** | CA 策略的详细描述信息。 |
| **状态** | 策略的启用状态（启用/禁用）。 |
| **来源** | 策略来源类型（自定义/标准）。 |

#### CA 设置

配置第三方 CA 服务的 API 集成参数。

| 配置项 | 说明 |
|---------|------|
| **CA供应商** | 选择 CA 供应商。 |
| **Host** | CA 服务提供商的 API 服务器地址（如 `https://ca-api.example.com`）。 |
| **AppID** | 在 CA 服务提供商处注册的应用程序 ID。 |
| **AppSecret** | 应用程序密钥，用于 API 请求的身份验证和加密通信。 |
| **uniqueId** | CA 服务中的唯一标识符字段名称。 |
| **oid** | 对象标识符（Object Identifier），用于标识证书中的特定属性或用途。 |
| **启用主动同键获取名称单** | 启用后，系统将主动从 CA 服务同步证书和用户名称列表。 |

#### 配置说明

**配置步骤**：
1. 在第三方 CA 服务提供商处注册企业账号并创建应用。
2. 获取服务提供商分配的 **AppID** 和 **AppSecret**。
3. 在系统中填写 CA 服务的 Host 地址、AppID 和 AppSecret。
4. 配置 uniqueId 和 oid 字段映射规则。
5. 根据需要启用主动同步功能。
6. 保存配置并进行连接测试。

**安全提示**：
- AppSecret 应妥善保管，避免泄露。
- 建议使用 HTTPS 协议确保 API 通信的安全性。

**应用场景**：适用于需要集成第三方 CA 服务进行数字身份认证、电子签名或证书管理的场景，如政府、金融、医疗等高安全性要求的行业。

### 10.6 网络访问规则

配置系统的**黑白名单**，通过 IP 地址范围规则控制网络访问权限。网络访问规则用于限制系统或应用程序的访问权限，只允许特定 IP 地址的用户或设备访问，提高系统安全性，防止未经授权的访问和攻击。

#### 列表管理

系统以列表形式管理多个网络访问规则，支持以下功能：

| 功能 | 说明 |
|------|------|
| **搜索** | 支持关键词搜索，匹配规则名称字段 |
| **分页** | 分页展示所有网络访问规则 |
| **创建** | 点击"创建"按钮创建新的网络访问规则 |
| **编辑** | 点击"编辑"按钮编辑现有规则 |
| **启用/停用** | 点击切换规则状态，系统不应用停用状态的规则 |
| **删除** | 点击删除规则，删除前会弹出确认提示 |

**保护模式显示**：
- 未开启：没有任何保护模式，去设置
- 黑名单：黑名单保护中，去设置
- 白名单：白名单保护中，去设置
- 黑白名单：黑/白名单保护中，去设置

#### 创建/编辑规则

**基本信息**

| 配置项 | 字段类型 | 说明 |
|---------|------------|------|
| **规则名称** | 字符串（1-200字符） | 网络访问规则的名称，必填，在规则列表中必须保持唯一。保存校验失败提示【名称已存在】。 |
| **版本** | 枚举 | 选择 IP 地址协议版本（IPv4 或 IPv6），默认值：IPv4 |
| **状态** | 枚举 | 该 IP 范围规则的启用状态（启用/停用），默认值：启用。系统不应用停用状态的规则。 |
| **类型** | 枚举 | 定义 IP 范围的用途类型（白名单/黑名单），默认值：白名单 |
| **起始IP** | IP 地址 | IP 地址范围的起始地址（如 `192.168.1.1`），必填 |
| **结束IP** | IP 地址 | IP 地址范围的结束地址（如 `192.168.1.255`），必填。地址值应大于等于起始地址，否则提示【结束地址应大于起始地址】 |
| **描述** | 文本（1-500字符） | IP 范围规则的详细说明（如用途、部门、备注等） |

**IPv4 输入规则**：
- 输入框最多支持输入 3 位数字，且超过 255 的数字在失焦的时候会被转换为 255
- 只支持数字、英文句号
- 当输入框内的数字是 3 位的时候自动聚焦到下一个输入框
- 按下箭头左键以及右键鼠标光标依次按顺序跳动
- 当鼠标光标位于输入的末尾时，按下句号键跳转到下一个输入框

**IPv6 输入规则**：
- 输入框最多支持输入 4 位数字/英文字符
- 只支持数字、英文字符（A、B、C、D、E、F，不区分大小写）
- 其他字符前端自动屏蔽，不允许键入
- 当输入框内的字符达到 4 位的时候自动聚焦到下一个输入框
- 按下箭头左键以及右键鼠标光标依次按顺序跳动
- 当鼠标光标位于输入的末尾时，输入冒号键跳转到下一个输入框

#### 访问控制规则

**1\. 只开启白名单**
- **允许访问**：白名单内的 IP 地址
- **禁止访问**：白名单以外的 IP 地址访问本系统时，跳转至【无权限页面】

**2\. 只开启黑名单**
- **允许访问**：黑名单外的 IP 地址
- **禁止访问**：黑名单内的 IP 地址访问本系统时，跳转至【无权限页面】

**3\. 同时开启黑白名单**
- **允许访问**：白名单内且黑名单外的 IP 地址
- **禁止访问**：白名单外或黑名单内的 IP 地址访问本系统时，跳转至【无权限页面】

**4\. 不开启黑白名单**

若黑名单和白名单均未开启，则所有 IP 地址均可访问本系统。

**访问控制优先级**：
1. **黑名单** \- 最高优先级，黑名单中的 IP 将被直接拒绝访问
2. **白名单** \- 次优先级，只有白名单中的 IP 可以访问
3. **默认策略** \- 如果既无黑名单也无白名单规则，则允许所有 IP 访问

#### 配置建议
- 对于高安全性要求的系统，建议使用白名单模式，仅允许已知安全的 IP 段访问
- 黑名单模式适用于需要屏蔽特定恶意 IP 段的场景
- 定期审查和更新 IP 范围规则，确保访问控制策略的有效性
- 可通过起始IP和结束IP定义一个连续的IP段（如 `192.168.1.0` \- `192.168.1.255` 表示整个 C 类网段）
