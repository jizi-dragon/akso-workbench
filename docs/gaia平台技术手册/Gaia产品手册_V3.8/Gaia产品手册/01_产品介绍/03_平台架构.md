# 平台架构
> 本文介绍 Gaia 平台的技术架构设计，包括配置驱动模型、运行时引擎和配置迁移机制。   

---

## 概述

Gaia 是一个**配置驱动的应用平台（aPaaS）**。平台通过配置定义应用行为，而非传统的代码开发方式。
```
┌─────────────────────────────────────────────────────────────────┐
│                      Gaia 平台架构                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   管理端 → 配置管理                                              │
│   ─────────────────                                              │
│   • 对象定义、字段配置                                          │
│   • 生命周期、工作流                                            │
│   • 权限规则、验证规则                                          │
│   • 产出物：组件配置定义（元数据）                              │
│                    │                                             │
│                    │ 导出为 ACP                                  │
│                    ▼                                             │
│   ┌───────────────────────────────────────┐                     │
│   │       配置定义（Configuration）        │                     │
│   │   • 结构化的元数据定义                 │                     │
│   │   • 可版本化、可迁移                   │                     │
│   │   • ACP (Akso Configuration Package) 格式            │                     │
│   └───────────────────────────────────────┘                     │
│                    │                                             │
│                    │ 装载 → 解析 → 执行                          │
│                    ▼                                             │
│   ┌───────────────────────────────────────┐                     │
│   │       平台运行时引擎（Runtime）        │                     │
│   │   • 装载配置定义                       │                     │
│   │   • 解析配置逻辑                       │                     │
│   │   • 执行业务功能                       │                     │
│   └───────────────────────────────────────┘                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

---

## 核心设计理念

### 配置即应用

| 传统开发 | Gaia 配置驱动 |
|------------|-----------------|
| 编写代码定义业务逻辑 | 配置元数据定义业务逻辑 |
| 编译部署 | 配置即时生效 |
| 代码版本管理 | 配置版本管理 |
| 开发→测试→生产 | 配置迁移（ACP） |

### 三层架构

| 层级 | 职责 | 角色 |
|------|------|------|
| **配置层** | 定义应用结构和行为 | 配置人员 |
| **管理层** | 系统设置和用户管理 | 系统管理员 |
| **业务层** | 使用应用完成业务 | 业务用户 |

### 访问路径

Gaia 平台支持丰富的可配置组件，覆盖应用构建的各个方面：

| 组件 | 说明 |
|------|------|
| **对象（Object）** | 数据结构定义 |
| **对象类型（Objecttype）** | 对象类型 |
| **字段（Field）** | 对象属性定义 |
| **编号规则（Number Rule）** | 编号规则定义 |
| **索引（Index）** | 字段索引定义 |
| **选项集（Picklist）** | 下拉选项定义 |
| **对象关系（Relationship）** | 对象间关联 |

#### 生命周期

| 组件 | 说明 |
|------|------|
| **生命周期（Lifecycle）** | 状态和转换定义 |
| **生命周期状态（State）** | 状态定义 |
| **生命周期角色（Role）** | 状态相关角色 |
| **生命周期权限（Permission）** | 状态权限控制 |
| **阶段组（Stage Group）** | 状态分组 |
| **进入动作（Entry Action）** | 进入状态时的动作 |
| **用户动作（User Action）** | 状态内可执行动作 |
| **事件动作（Event Action）** | 事件触发的动作 |

#### 工作流与自动化

| 组件 | 说明 |
|------|------|
| **工作流（Workflow）** | 审批流程定义 |
| **工作流步骤（Step）** | 流程步骤定义 |
| **作业（Job）** | 定时/批量作业 |
| **通知模板（Notification Template）** | 通知内容模板 |
| **消息（Message）** | 消息定义 |

#### 布局与界面

| 组件 | 说明 |
|------|------|
| **页面（Page）** | 页面定义 |
| **表单布局（Form Layout）** | 记录详情页布局 |
| **列表布局（List Layout）** | 列表页显示配置 |
| **标签页（Tab）** | 标签页定义 |
| **菜单（Menu/Tab Collection）** | 导航菜单配置 |
| **仪表盘（Dashboard）** | 数据可视化面板 |
| **报表（Report）** | 报表定义与展示 |

#### 权限与安全

| 组件 | 说明 |
|------|------|

| **安全策略（Security Profile）** | 安全策略 |
| **权限集（Role Permission Set）** | 角色与权限关联 |

| 组件 | 说明 |
|------|------|

## 平台运行时引擎

Gaia 平台是配置的**装载、解析、执行引擎**：

### 运行时流程
```
配置定义 ──→ 装载 ──→ 解析 ──→ 执行
              │        │        │
              ▼        ▼        ▼
         读取元数据  构建逻辑  响应请求
```

### 引擎职责

| 阶段 | 职责 |
|------|------|
| **装载** | 从存储读取配置定义 |
| **解析** | 将配置转换为可执行逻辑 |
| **执行** | 响应用户请求，执行业务功能 |

### 即时生效

配置变更后**即时生效**，无需重启或部署：
- 新增字段 → 立即可用
- 修改工作流 → 新流程立即生效
- 调整权限 → 权限立即更新

## 配置迁移

### ACP（Akso Configuration Package）

配置可导出为 **ACP（Akso Configuration Package）** 格式，在不同环境之间迁移。

### 迁移流程
```
开发环境                    测试环境                    生产环境
    │                           │                           │
    │  导出 ACP                 │  导出 ACP                 │
    └──────────→ 导入 ACP ──────┴──────────→ 导入 ACP ──────┘
```

### ACP 内容

| 内容 | 说明 |
|------|------|
| **对象配置** | 对象定义、字段、关系 |
| **生命周期** | 状态和转换规则 |
| **工作流** | 流程定义 |
| **权限规则** | 角色和共享规则 |
| **布局** | 表单和列表布局 |

### 迁移策略

| 策略 | 说明 |
|------|------|
| **增量导入** | 仅导入变更的配置 |
| **覆盖导入** | 完全替换现有配置 |
| **冲突处理** | 检测并处理配置冲突 |
