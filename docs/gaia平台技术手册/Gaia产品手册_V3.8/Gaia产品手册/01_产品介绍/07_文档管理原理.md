# 文档管理原理
> 本文解释 Gaia 平台的文档管理核心原理，包括统一对象模型、版本控制、文档渲染等机制。   

---

## 概述

Gaia 平台采用**统一对象模型**进行文档管理：
> **文档是一种标准对象，非结构化内容（如 Word、PDF 文件）通过文件字段存储。**   

这一设计使文档能够使用与业务对象相同的字段、生命周期、工作流和权限机制，提供一致的管理体验。

### 核心能力

| 能力 | 说明 |
|------|------|
| **统一对象模型** | 文档是标准对象，与业务对象使用相同机制 |
| **文件字段** | 非结构化内容作为对象字段存储 |
| **版本控制** | 完整的版本历史和受控变更 |
| **文档渲染** | 服务器端渲染确保一致性 |
| **权限控制** | 与其他对象相同的权限机制 |
| **协同编辑** | 多人实时协作 |
| **审计追踪** | 完整的操作历史 |

---

## 文档对象结构

### 文档作为对象

在 Gaia 中，文档是 **Document 对象**的记录，其结构如下：
```
┌─────────────────────────────────────────────────────────────┐
│              文档对象记录（Document Object Record）          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌──────────────────────────────────────────────────────┐  │
│   │                  标准对象字段                         │  │
│   │  ID、名称、编号、类型、状态、版本、创建者...         │  │
│   └──────────────────────────────────────────────────────┘  │
│                                                              │
│   ┌──────────────────────────────────────────────────────┐  │
│   │                  业务字段                             │  │
│   │  产品（引用）、部门（引用）、生效日期...             │  │
│   └──────────────────────────────────────────────────────┘  │
│                                                              │
│   ┌──────────────────────────────────────────────────────┐  │
│   │             📄 文件字段（File Field）                 │  │
│   │  存储非结构化内容：Word、Excel、PDF、图片等          │  │
│   │  → 系统自动渲染为可预览格式                          │  │
│   └──────────────────────────────────────────────────────┘  │
│                                                              │
│   ┌──────────────────────────────────────────────────────┐  │
│   │                  附件字段                             │  │
│   │  关联的辅助文件（作为独立的文件字段或子对象）        │  │
│   └──────────────────────────────────────────────────────┘  │
│                                                              │
│   + 生命周期状态 + 工作流任务 + 权限角色 + 审计追踪      │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 统一对象模型的优势

| 优势 | 说明 |
|------|------|
| **一致性** | 文档和业务数据使用相同的配置和管理方式 |
| **灵活性** | 可以为文档对象添加任意自定义字段 |
| **关联性** | 文档可以像其他对象一样建立引用关系 |
| **查询能力** | 使用统一的 VQL 查询语言查询文档和数据 |
| **简化开发** | API 和 SDK 对文档和对象使用相同的接口 |

## 版本控制

### 版本号格式

Gaia 采用**主版本.次版本**的版本编号方式：

| 版本类型 | 格式 | 含义 |
|------------|------|------|
| **主版本** | 1.0, 2.0, 3.0 | 正式发布版本 |
| **次版本** | 1.1, 1.2, 1.3 | 修订草稿版本 |

### 版本状态

| 状态 | 说明 |
|------|------|
| **草稿版本** | 正在编辑的版本 |
| **稳态版本** | 已批准的正式版本 |
| **过期版本** | 被新版本替代的历史版本 |

### 版本生命周期
```
创建文档 (v0.1)
    │
    ▼
编辑草稿 (v0.1 → v0.2 → v0.3)
    │
    ▼
提交审批
    │
    ▼
批准生效 (v0.3 → v1.0) ◄─── 升级主版本
    │
    ▼
创建新版本 (v1.0 → v1.1) ◄─── 开始次版本
    │
    ▼
编辑草稿 (v1.1 → v1.2)
    │
    ▼
批准生效 (v1.2 → v2.0) ◄─── 再次升级主版本
```

### 版本对比

Gaia 支持对比不同版本之间的差异：

| 对比类型 | 说明 |
|------------|------|
| **字段对比** | 显示元数据字段的变更 |
| **内容对比** | 显示文档内容的差异（仅限支持的格式） |
| **渲染对比** | 并排显示两个版本的渲染效果 |

## 文档渲染

### 什么是文档渲染？

**文档渲染**是 Gaia 将上传的源文件（Word、Excel 等）自动转换为可在浏览器中查看的格式（PDF）的过程。

### 渲染优势

| 优势 | 说明 |
|------|------|
| **无需客户端** | 无需安装 Office 即可查看 |
| **一致性** | 所有用户看到相同的效果 |
| **安全性** | 可禁止下载源文件 |
| **水印** | 可自动添加安全水印 |
| **批注** | 直接在渲染件上批注 |

### 支持的渲染格式

| 源格式 | 渲染格式 |
|---------|------------|
| Word (.docx, .doc) | PDF |
| Excel (.xlsx, .xls) | PDF |
| PowerPoint (.pptx, .ppt) | PDF |
| PDF | 直接显示 |
| 图片 (.jpg, .png, .gif) | 直接显示 |
| 视频 (.mp4, .webm) | 直接播放 |

### 渲染水印

管理员可配置文档渲染时自动添加水印：

| 水印类型 | 说明 |
|------------|------|
| **用户水印** | 显示查看者用户名 |
| **时间水印** | 显示查看时间 |
| **状态水印** | 显示文档状态（如"草稿"） |
| **自定义水印** | 配置自定义文本 |

## 协同编辑

### 在线编辑

Gaia 支持直接在浏览器中编辑 Office 文档：

| 功能 | 说明 |
|------|------|
| **实时协作** | 多用户同时编辑 |
| **自动保存** | 编辑自动保存到 Gaia |
| **锁定机制** | 可选择锁定防止冲突 |
| **版本记录** | 编辑产生版本历史 |

### 检出/检入

对于需要长时间编辑的场景，支持**检出/检入**机制：

| 操作 | 说明 |
|------|------|
| **检出** | 锁定文档，下载到本地编辑 |
| **检入** | 上传修改后的文件，解除锁定 |
| **撤销检出** | 放弃修改，解除锁定 |

🔒 **合规要点**：检出期间其他用户只能查看，不能编辑，确保变更受控。

## 批注管理

### 批注类型

| 类型 | 说明 |
|------|------|
| **文档批注** | 在文档渲染件上添加标注 |
| **永久批注** | 保存到文档，所有用户可见 |
| **临时批注** | 仅当前会话可见 |
| **回复** | 对批注进行回复讨论 |

### 批注工具

| 工具 | 用途 |
|------|------|
| **高亮** | 高亮标记文本 |
| **注释** | 添加文字注释 |
| **下划线** | 强调特定内容 |
| **删除线** | 标记需删除的内容 |
| **矩形/椭圆** | 圈出区域 |
| **自由画笔** | 手绘标注 |

## 文档关系

### 关系类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **引用关系** | 文档引用另一文档 | SOP 引用法规文件 |
| **支持关系** | 文档作为另一文档的支持 | 附件支持主文档 |
| **版本关系** | 同一文档的不同版本 | 自动建立 |
