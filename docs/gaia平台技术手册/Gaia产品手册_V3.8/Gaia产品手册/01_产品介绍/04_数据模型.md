# 数据模型
> 本文解释 Gaia 平台的数据模型架构，包括对象、字段、关系等核心概念。   

---

## 概述

Gaia 平台采用\*\*统一对象模型（Unified Object Model）\*\*架构：
> **在 Gaia 中，一切皆对象。文档也是一种标准对象，非结构化内容（如 Word、PDF 文件）作为文档对象的文件字段来存储。**   
```
┌────────────────────────────────────────────────────────────────────┐
│                    Gaia 统一对象模型                                │
├────────────────────────────────────────────────────────────────────┤
│                                                                     │
│                        ┌─────────────┐                             │
│                        │    对象     │                             │
│                        │  (Object)   │                             │
│                        └──────┬──────┘                             │
│                               │                                     │
│           ┌───────────────────┼───────────────────┐                │
│           │                   │                   │                │
│           ▼                   ▼                   ▼                │
│   ┌───────────────┐   ┌───────────────┐   ┌───────────────┐       │
│   │  文档对象     │   │  业务对象     │   │  系统对象     │       │
│   │  (Document)   │   │  (Business)   │   │  (System)     │       │
│   │               │   │               │   │               │       │
│   │ 标准对象      │   │ 标准/自定义   │   │ 标准对象      │       │
│   │ 含文件字段    │   │ 结构化数据    │   │ 平台内置      │       │
│   └───────────────┘   └───────────────┘   └───────────────┘       │
│           │                   │                   │                │
│           └───────────────────┼───────────────────┘                │
│                               │                                     │
│                        统一的字段、生命周期、工作流、权限          │
│                                                                     │
└────────────────────────────────────────────────────────────────────┘
```

### 统一对象模型的优势

| 优势 | 说明 |
|------|------|
| **一致性** | 文档和业务数据使用相同的配置和管理方式 |
| **灵活性** | 文档可以像其他对象一样添加自定义字段 |
| **统一流程** | 文档和业务数据使用相同的生命周期、工作流机制 |
| **关联能力** | 业务对象可以通过文档引用字段关联文档 |
| **简化开发** | API 和 SDK 对文档和对象使用相同的接口 |

## 对象（Objects）

### 什么是对象？

**对象**是 Gaia 平台中**唯一的数据实体类型**。所有数据——无论是结构化的业务数据还是包含非结构化内容的文档——都通过对象来管理。

### 对象的组成

| 组件 | 说明 |
|------|------|
| **对象** | 对象的名称、Code、类别等基本信息 |
| **对象字段** | 对象包含的属性（如名称、Code、状态、文件内容） |
| **对象类型** | 对象的子分类，不同类型可有不同字段和动作 |
| **对象关系** | 与其他对象的层级或引用关联 |
| **生命周期** | 对象记录的状态流转规则 |
| **权限设置** | 访问控制和共享规则 |

### 对象分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **系统对象** | 平台核心对象，不可删除 | 电子签名 |
| **文档对象** | 包含文件字段的标准对象 | Document（文档） |
| **标准业务对象** | 应用预置的业务对象 | 用户任务、信封、文件类型、职位、部门 |
| **自定义对象** | 用户创建的业务对象 | CAPA、变更、偏差 |

## 对象字段

### 字段类型

Gaia 平台支持丰富的字段类型：

| 字段类型 | 说明 | 示例值 |
|------------|------|---------|
| **文本** | 单行文本 | "阿莫西林胶囊" |
| **长文本** | 多行文本 | 产品描述 |
| **数字** | 整数或小数 | 100, 3.14 |
| **日期** | 日期值 | 2026-02-01 |
| **日期/时间** | 日期和时间 | 2026-02-01 10:30:00 |
| **是/否** | 布尔值 | 是 / 否 |
| **选项** | 单选下拉 | 已激活 / 已停用 |
| **父对象** | 引用其他对象记录，建立父子关系 | \[业务单元-部门\] |
| **对象** | 引用其他对象记录；引用文档对象时支持版本绑定 | → SOP-001 v2.0 |
| **查找字段** | 从父对象或引用对象同步字段值（只读） | 自动带出：产品.持有人 |
| **统计字段** | 对关联记录进行聚合统计（计数、求和等） | CAPA 数量 = 12 |
| **附件** | 直接存储文件（无版本/生命周期） | 支持性文件、图片证据 |
| **公式** | 计算字段 | = 单价 × 数量 |
| **富文本** | 带格式的文本 | HTML 内容 |
| **组件** | 特有能力字段（可用能力以当前版本为准） | 状态 |
| **文件** | 非结构化内容存储（文档对象专用） | Word、PDF、图片等 |

💡 **重要**：**文件字段**是 Gaia 统一对象模型的关键。文档对象通过文件字段存储非结构化内容（如 Word、PDF 文件），使文档成为对象的一种，而非独立实体。

### 文档引用字段

**文档引用字段**是一种特殊的引用字段，用于从任意对象关联到文档对象。与普通对象引用不同，文档引用字段具有额外的**版本控制属性**。

#### 版本绑定模式

| 模式 | 说明 | 适用场景 |
|------|------|------------|
| **当前版本** | 绑定到文档的指定版本（如 v1.0），即使文档有更新版本也不变 | 需要引用特定历史版本时 |
| **最新版本** | 始终指向文档的最新版本（包括草稿） | 需要自动跟踪最新内容时 |
| **最新稳定版本** | 指向最新的已批准/生效版本（忽略草稿和审核中的版本） | 确保引用的是正式发布的内容 |

#### 配置示例
```
培训记录对象
├── 培训课程（对象引用 → 课程对象）
├── 学员（对象引用 → 用户对象）
├── 培训材料（文档引用 → 文档对象）
│   └── 版本设置：最新稳态版本
└── 培训记录附件（文档引用 → 文档对象）
    └── 版本设置：特定版本
```

#### 文档引用的行为

| 行为 | 说明 |
|------|------|
| **版本显示** | 引用字段显示文档名称和版本号 |
| **快速预览** | 点击可直接预览引用的文档 |
| **版本跟踪** | 根据版本模式自动更新或保持锁定 |
| **权限检查** | 需要有权限才能查看引用的文档 |
| **完整性约束** | 可配置是否允许删除被引用的文档 |

### 字段属性

| 属性 | 说明 |
|------|------|
| **必填** | 创建记录时必须填写 |
| **唯一** | 值在对象中不能重复 |
| **只读** | 用户无法直接编辑 |
| **系统管理** | 由系统自动维护 |
| **可搜索** | 包含在搜索索引中 |
| **可审计** | 变更被审计追踪记录 |

## 对象类型

**对象类型**允许在同一对象中管理结构相似但字段略有不同的数据。

### 示例：产品对象的类型
```
产品（Product）对象
├── 药品（Pharmaceutical）类型
│   ├── 通用字段：名称、编号、状态
│   └── 特有字段：剂型、规格、适应症
├── 医疗器械（Medical Device）类型
│   ├── 通用字段：名称、编号、状态
│   └── 特有字段：分类、注册证号、使用期限
└── 原辅料（Raw Material）类型
    ├── 通用字段：名称、编号、状态
    └── 特有字段：CAS号、供应商、检验标准
```

## 对象关系

### 关系类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **层级关系（Parent-Child）** | 父子关系，子记录依赖于父记录 | 部门 → 子部门 |
| **引用关系（Reference）** | 非层级关联 | 文档 → 产品 |
| **自引用关系** | 对象内部的层级 | 区域 → 子区域 |

### 关系的行为

| 行为 | 说明 |
|------|------|
| **级联删除** | 删除父记录时自动删除子记录 |
| **限制删除** | 存在子记录时禁止删除父记录 |
| **字段继承** | 子记录自动继承父记录的某些字段值 |

## 文档对象（Document Object）

### 文档是一种标准对象

在 Gaia 平台中，**文档（Document）是一种标准对象**，与其他业务对象使用相同的底层机制。文档对象的特殊之处在于它包含一个**文件字段**，用于存储非结构化内容。
```
┌─────────────────────────────────────────────────────────────────┐
│                    文档对象（Document Object）                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   标准对象字段                        特殊字段                   │
│   ──────────────                      ────────                   │
│   • 名称                              • 📄 文件内容（File）     │
│   • 文档编号                            └─ 存储 Word/PDF/Excel  │
│   • 状态                                └─ 自动渲染为可预览格式 │
│   • 版本                                └─ 支持版本控制         │
│   • 创建者                                                       │
│   • 创建日期                                                     │
│   • 产品（引用字段）                                             │
│   • 部门（引用字段）                                             │
│   • ...自定义字段                                                │
│                                                                  │
│   + 生命周期 + 工作流 + 权限（与其他对象完全一致）              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 文档对象类型（三级分类）

文档对象通过**对象类型**实现分类，采用三级分类体系：
```
文档类型（Type）
└── 文档子类型（Subtype）
    └── 文档分类（Classification）
```

### 示例
```
标准操作规程（SOP）
├── 生产 SOP
│   ├── 片剂生产 SOP
│   ├── 胶囊生产 SOP
│   └── 注射剂生产 SOP
├── 质量 SOP
│   ├── QC 检验 SOP
│   ├── QA 审核 SOP
│   └── 偏差处理 SOP
└── 设备 SOP
    ├── 设备操作 SOP
    └── 设备维护 SOP
```

### 文档对象类型的作用
- 决定文档的**可用字段**
- 决定文档的**生命周期**
- 决定文档的**权限规则**
- 决定文档的**模板**

## 文档对象的字段

### 字段来源

| 来源 | 说明 |
|------|------|
| **共享字段** | 所有文档类型共有的字段 |
| **类型字段** | 特定文档类型的专属字段 |
| **系统字段** | 系统自动维护的字段 |
| **文件字段** | 存储非结构化内容的特殊字段 |

### 核心系统字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 文档 ID | 系统 | 系统自动生成的唯一标识 |
| 名称 | 文本 | 文档显示名称 |
| 文档编号 | 文本 | 业务编号（可自动生成） |
| 状态 | 选项列表 | 当前生命周期状态 |
| 版本 | 文本 | 主版本.次版本 |
| **文件内容** | **文件** | **存储非结构化内容（Word、PDF等）** |
| 创建者 | 引用 | 创建文档的用户 |
| 创建日期 | 日期/时间 | 文档创建时间 |
| 最后修改者 | 引用 | 最后修改的用户 |
| 最后修改日期 | 日期/时间 | 最后修改时间 |

## 数据完整性

### ALCOA\+ 原则

Gaia 平台的数据模型设计遵循 **ALCOA\+** 数据完整性原则：

| 原则 | 实现方式 |
|------|------------|
| **Attributable（可归属）** | 所有操作关联用户身份 |
| **Legible（清晰可读）** | 数据以标准格式存储和显示 |
| **Contemporaneous（及时）** | 操作时间由系统自动记录 |
| **Original（原始）** | 保留原始数据，不可篡改 |
| **Accurate（准确）** | 验证规则确保数据准确性 |
| **Complete（完整）** | 审计追踪记录完整操作历史 |
| **Consistent（一致）** | 数据格式和规则保持一致 |
| **Enduring（持久）** | 数据安全存储，长期可访问 |
| **Available（可用）** | 需要时可快速检索和访问 |
