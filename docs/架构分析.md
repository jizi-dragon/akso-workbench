# Akso Workbench 架构分析

> 更新于 2026-09-10，对应 **v0.2.2**。本文取代 2026-09-08 删除的旧版架构分析/模块契约/迁移台账三件套（旧文描述 pywebview + 纯 Python 单体架构，已不反映现状）。
> 配套阅读：`docs/SESSION-DIGEST.md`（会话速查）、`extensions/quick-login/docs/PROJECT-STATUS.md`（扩展六平面隔离详解）。

## 一、总体架构

三个进程面 + 一个扩展执行面，业务全部收敛在 FastAPI 服务：

```
┌─────────────────────────────────────────────────────────────────────┐
│  Electron 壳（desktop/main.js）—— 只做"壳"，不做业务                   │
│  主窗(加载 18765) · 透明轮盘窗(Alt+Q) · 托盘 · 全局热键 · 自动更新        │
│  ├─ spawn 服务端 sidecar：打包态 AksoServer.exe --server              │
│  │                        开发态 .venv python -m uvicorn workbench.api │
│  ├─ 控制服务 :18767 —— /windows 开户(每账号 persist: 分区)             │
│  │                     /windows/focus · /windows/close · /health      │
│  └─ remote-debugging-port :18766（app ready 前设置，供 CDP 挂接）      │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ CDP connect_over_cdp
┌──────────────────────────────▼──────────────────────────────────────┐
│  FastAPI 服务（workbench/，127.0.0.1:18765）                          │
│  api/routes_*（12 路由域）+ services（browser_pool/autologin/accounts）│
│  + services/egmp/（insight 读路径 · writers 写路径 · orchestrate ·     │
│    generate · monitor）+ db.py（SQLite，_sqlx_migrations 1-11）       │
└───────┬───────────────────────────────────┬─────────────────────────┘
        │ /extension 同步蓝图                │ browser_pool(CDP 模式)
┌───────▼───────────────────────┐   ┌───────▼─────────────────────────┐
│ quick-login 扩展（执行面）      │   │ 内置 Chromium（Electron 壳持有）  │
│ 用户 Chrome 里跑：六平面隔离、   │   │ 监听/自动化专用：Monitor 录制、   │
│ 会话切换、自动填表              │   │ 自动登录、storage_state 免密     │
└───────────────────────────────┘   └─────────────────────────────────┘
```

**浏览器分配政策（用户定稿，0.2.2）**：
- **快捷登录 / 打开账号** = 用户 Chrome：桌面写扩展指令（`par.open` + launch-chrome），扩展执行面做会话切换与自动填表——要的是"以该身份操作的真实效果"；
- **监听 / 自动化** = 应用内置 Chromium：`browser_pool` 经 CDP 挂接 Electron 壳开户的窗口——要的是可控、可录制、不污染用户浏览器。

### 四条设计底线

1. **窗口只做壳，业务全在服务**：Electron 主窗/轮盘/会话窗都只是加载 FastAPI 页面或空壳分区；关闭窗口即整体退出并回收服务（`before-quit` → `taskkill /T /F`）。
2. **运行时零依赖原仓库与 Node**：akso-cc/akso-auto/quick-login 能力全部内化到 Python（`services/egmp/`）与扩展；原仓库只读参考（`adapters/*.json` 为对照存档）。
3. **Playwright sync 单线程单实例**：`browser_pool` 是专职工作线程，一切浏览器操作走 Future 队列；**事件回调内禁止连接调用**（`response.text()`/`page.evaluate` 重入 = worker 死锁）——事件只入队，worker 作业间隙统一 drain。
4. **凭据不落明文**：SQLite 存 Fernet 密文（密钥在 settings 表）；给扩展下发"密文+密钥"经 127.0.0.1 回环，扩展内存解密后交其本地 AES-GCM 存储落盘。

## 二、端口与进程分工

| 端口/进程 | 归属 | 职责 |
|---|---|---|
| 18765 | FastAPI（uvicorn / AksoServer.exe） | 全部业务 HTTP + 静态页；扩展同步蓝图也在此 |
| 18766 | Electron 内置 Chromium | CDP 调试端口，`browser_pool` connect_over_cdp 用；**必须在 app ready 前用 `app.commandLine.appendSwitch` 设置** |
| 18767 | Electron 控制服务（Node http） | 代持会话窗生命周期：按 windowId 开户（`persist:<windowId>` 独立持久分区）/聚焦/关闭；browser_pool CDP 模式"先开户后连接" |

### 3.2 桌面壳 `desktop/`（Electron 33，~250 行 JS）

- `main.js`：spawn 服务 → 控制服务 :18767 → 托盘 → Alt+Q 轮盘窗（无边框透明 560×640，加载 `/static/pages/wheel-picker.html?transparent=1`）→ waitReady 后开主窗；打包态 `electron-updater` 按 `latest.yml` 自动更新。
- `package.json`：electron-builder NSIS 配置（`extraResources` 带 `../dist/AksoServer`）；version 由 `bump.py` 三写同步。
- 轮盘单例 toggle、js_api 关闭/拖动等早期 pywebview 交互已随壳换代重做。

### 3.3 扩展执行面 `extensions/quick-login/`（TS，~6.3k 行）

MV3 扩展，跑在**用户 Chrome**里。四平面→六平面隔离（存储/AUTH/COOKIE/CACHE/SW/IDB）、Token 双通道捕获、Cookie 登录快照回放、四象限泄漏分层修复——详见其 `docs/PROJECT-STATUS.md`。与桌面的连接：

- `background/sync.ts`：每 2s 轮询桌面快照（snapshotId 内容哈希幂等）→ WebCrypto Fernet 解密 → 直连 `parallelStore` 增删改；拉取指令（wheel.toggle/par.open）→ `parallelSession.open`；桌面不可达时静默跳过（离线回退，本地数据仍可用）。
- 构建产物 `packages/extension/dist/`（esbuild），装载即测；**更新 dist 后必须在扩展卡片点"重新加载"**。

### 3.4 工具与测试

- `tools/bump.py`：版本规则 A（push=PATCH+1，build=MINOR+1 且 PATCH 重置 1）；**三写** pyproject + `workbench/__init__.py` + `desktop/package.json`（+ `.version.json` 缓存）。
- `tools/build.ps1`（v3）：bump build → release commit+push → uv sync → PyInstaller（`workbench/server.spec` → `dist/AksoServer` onedir，含 chromium 本体）→ electron-builder NSIS → `desktop/dist/AksoWorkbench-<ver>-setup.exe` + `latest.yml`。
- `tools/setup.ps1` 环境自检；`tools/import_accounts.py` 原项目 env 导入。
- `tests/`（**50 项**）：`test_app/accounts/modules/proc`（服务层）、`test_autologin`（节奏门控 9 断言）、`test_browser_parallel`（双账号并行/免密/自愈）、`test_browser_state`（storage_state 持久化 5 项）、`test_native`（egmp 原生链路 12 项，FakeEgmpClient 内存平台离线验收）；`fakes.py` + `conftest.py`。

## 四、三条关键数据流

1. **快捷登录（用户 Chrome）**：轮盘/卡片 → 桌面 `dispatch_command(par.open)` → 扩展 2s 轮询拉到指令 → `parallelSession.open`（六平面规则绑定 + 自动填表）→ 平台登录态就绪。
2. **托管自动化（内置 Chromium）**：卡片"打开" → `routes_browser` → browser_pool 队列 → CDP 模式：先 POST :18767 `/windows` 开户 → `connect_over_cdp(:18766)` 接管 → autologin 节奏门控 → 登录成功 storage_state 落盘（重开免密、跨进程重启有效）；被踢回登录页 → 自愈重跑（heal_count≤2）。
3. **监听录制**：卡片"开始监听" → `routes_monitor` → `monitor_start`（复用/新建托管会话）→ MonitorSession 挂 page → 事件只入队、worker 间隙 drain → 三级降噪（dropped/trimmed/full）→ 产物落 `runtime/monitor/`。真机验收：248 请求捕获（238/2/8）。

## 五、数据层

- SQLite 单文件（`%APPDATA%/AksoWorkbench/workbench.db`，兼容接管 mogul.db）；迁移账 1-11：
  - 1-6：mogul 时代（含已下线的知识库/钉钉表）——**不可变纪律，仅留存不再读写**；

  - 10-11：扩展同步/监听相关增量。

## 六、版本与发布

- 版本真源 `pyproject.toml`，`tools/bump.py push|build|show` 三写同步（**改版本只走 bump.py，勿手改三处**——漏写 desktop/package.json 会导致安装包命名与产物校验错位）。
- 发布：`powershell -File tools\build.ps1`（自动 bump build + release commit + 推送）；发布到 GitHub Releases 时上传 exe + `latest.yml`（electron-updater 增量检查）。
- 远端推送注意：全局 git 代理常失效，用 `git -c http.proxy= push`。

## 八、排障速查与环境坑（高价值，勿重踩）

| 症状 | 根因/处置 |
|---|---|
| 浏览器操作全部挂起 | browser_pool worker 死锁——检查是否在事件回调里调了 `response.text()`/`page.evaluate`（必须入队 drain） |
| CDP 挂接失败 | 必须先 :18767 开户再 connect；remote-debugging-port 必须在 app ready 前设置；Electron33 挂接怪癖见"先开户后连接" |
| 页面停在"加载中" | ES 模块重复函数声明 = 整模块加载失败（accounts.js isOnline 事故） |
| pydantic 传参静默失效 | BaseModel 默认忽略多余字段（AccountPatch 漏 box 事故）——请求体显式建模 |
| PS5.1 脚本异常 | .ps1 必须 UTF-8 BOM；不支持 `??`；build.ps1 禁用 `$ErrorActionPreference=Stop` |
| 扩展改了没生效 | Chrome 缓存 SW 脚本——扩展卡片点"重新加载"，必要时删档案 `Default/Service Worker/` |
| push 失败 | 全局 git 代理 127.0.0.1:7890 常失效 → `git -c http.proxy= push` |
| 自愈计数 | 成功时不可清零（掩盖已自愈事实）；上限 2 防死循环 |
| 桌面双开 | 只支持单实例；第二实例端口冲突只出窗口不连服务 |
| 安装包版本错位 | 走 `tools/bump.py` 三写，勿手改单一文件 |

## 九、维护红线

1. 原 四项目仓库**只读**：任何情况下不修改 `adapters/*.json` 指向的仓库。
2. DB 迁移只增不改：历史迁移（尤其 1-6）不可变。
3. browser_pool 单线程纪律：新增浏览器能力一律走队列作业，不在线程外碰 Playwright。
4. 凭据链路：任何新通道不得落明文；扩展下发保持"密文+密钥"回环语义。
5. Monitor 回放：DANGEROUS 操作永不回放，API_MAP 对位 writers 常量需实证来源。
6. 版本三写 + CHANGELOG 同步：feature 合入前补 Unreleased 条目。
